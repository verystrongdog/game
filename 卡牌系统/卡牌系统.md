游戏的名字：面具
    随笔：
        有些卡牌垂涎着你的血肉，有些卡牌发掘着你的欲望，而有些......渴望着你的灵魂
        如果你很难阻止负面的情绪出现在自己身上，那么你仍然可以选择使用什么样的态度去面对它

    
卡牌：是的这是一个卡牌游戏，卡牌分为三种，分别是认知、情绪，和行为，而认知+情绪+行为=态度
    认知：一个人如何看待世界的角度，可以细分为以下几种
        知觉：大脑接受感知之后对信息处理的步骤，他会组织、解释并赋予信息意义
        注意力：人在一定时间内接收的信息是有限的，所以选择哪些信息去处理是很关键的问题
        记忆：基本上参与所有认知活动的认知过程，从持续的时间长短大致可以分为感觉记忆，短时记忆与长时记忆
        语言：某种意义上讲，语言是人类思维的边境
        思考与推理：带有特定目的的认知过程
    情绪：一个人的大脑面对外界环境变化产生的暂时性心里反应
        恐惧：人类最古老的情绪
        愤怒：穿着铠甲的恐惧
        内疚：一颗鞋子里的石头，一根塞在牙缝里面的菜叶
        焦虑：对未来的恐惧
        悲痛：看不见的伤口
        共情：可以传递其它情绪，不管是积极的还是消极的
        快乐：幸福的碎片
        爱：疯狂的别称
        厌恶：希望这个讨厌的东西从世界上消失
    行为：虽然说行为离不开人的主观意识，但是在特定条件下还是可以将其剥离出复杂的成因机制，回归简单的逻辑上
        反射：摆脱危险接触的简单动作
        惩罚机制：为了避免接受惩罚所采取的措施
        奖励机制：为了主动得到奖励所采取的措施
        道德驱动：为了符合自身价值观所采取的措施
        文化习俗：处在特定文化中的人会根据相应习俗决定自身行为
        价值驱动：有时候人会为了更有价值的事情或者东西，违背自身生理反应，拒绝奖励，接受惩罚，抛弃道德和文化
    
    随笔：
        我要做的就是根据上面三种认知过程的特点抽象出对应的卡牌，进而使用卡牌的组合反过来表示游戏中人物的行为
        这个模型非常优秀，但是游戏中会出现问题，因为三种态度卡片总会有不能同时出现在手上的可能性，有没有可能，我们可以利用别人的态度
        他人与环境会影响你的认知，情感，和行为(在这里抽象为敌人会将自己的态度卡牌塞给你，比如医生，老师，父母会交给你认知，但是你可以选择是否接受；亲人之间会共享情感；有些人会强迫你做出一些行为)
        抽象，抽象，抽象真是个好东西，因为它们的本质源于现实，所以它们会按照原有的逻辑自动产生联系
        再者，情绪结构搭建好了，那么怎么才能算得上击败敌人呢？(让敌人情绪崩溃)
        孩子，你说的确实对，但是知道道理和做事是两码事。
        我觉得不好实现，因为如果给卡牌赋予过多的颜色会让游戏显得过于臃肿(但是使用原色解决的话，就可以使用少量的颜色构建出丰富的效果)
        敌人和玩家公用一套卡牌库？
        
游戏背景：
    故事发生在一家存在超自然现象的心理治疗中心。
    首先这个地方的空间结构被扭曲，体现为不管尝试从什么地方离开，都会近似于绕地球一周方式从治疗中心的另一端返回。
    其次这里的观察者效应没有被局限在微观世界，角色观察到的现象可能与其它npc看到的不同。
    一轮诡异的月亮挂在空中，无论身处何处都能看到月光（”月光“干扰了物质之间不断发生的相互作用，导致了宏观物体处于量子叠加态中）
    观察者效应脱离微观世界的另一个后果就是心想事成在一定程度上是可以被实现的，这并不是什么好事。
    精神病患者们的怪诞思想在这种特殊环境下被具象化了，因为相较于普通人，精神病患者更愿意无条件的相信自身的幻觉（这些思想，乃至患者本身就是游戏中的敌人以及npc了）
    
游戏机制：
    基于游戏背景设定
    既然敌人是基于观察者效应产生，那么也可以被其打败，只要相信敌人被打败了就可以。
    那么这样的方式就有很多种了，可以相信自己有足够的武力，将敌人的血量削减到0；也可以通过说服敌人的方式来达到目的；甚至可以控制自己的认知来强行认为眼前的东西不存在
    敌人的强弱应该跟玩家当前的精神状态关联，对应想象中的怪物越强大，应观察者效应产生的怪物也越强大。
    敌人与玩家共用一套卡牌逻辑与牌库
    敌人与玩家拥有san值与血量，在特定情况下二者可以相互转化（比如低san值时通过自残回复san值，通过做一些降低san值的事情回复血量，比如吃怪物肉）
    态度数量取决于7行为驱动×情绪PAD空间的组合，当前态度模型以75种态度为基础（27种离散晶体已废弃）
    
    ### 行动力（AP）规则
    - 认知卡：不消耗行动力（认知是"怎么看"，看清不需要费力）
    - 情绪卡：不消耗行动力（情绪是"感觉到什么"，感受本身不费力）
    - 行为卡：消耗行动力（行为是"做什么"，落地需要精神能量）
    - 各行为卡的基础 AP 消耗不同，正面/负面 buff 可影响 AP 消耗
    - 打出完整态度（认知+情绪+行为）的瓶颈在行为卡的 AP

    ### 手牌与抽牌
    - 手牌上限：13 张（暂定，后续可能调整）
    - 每回合抽牌：6 张（暂定，后续可能调整）
    - 认知卡与行为卡储存在背包（牌库）中，战斗间持久保留
    - 情绪卡为暂时性卡牌，来源为态度/两类组合/环境/NPC，战斗结束后消失

    ### 卡牌组合
    - 完整态度（认知+情绪+行为）：三类组合逻辑比较健全，可能附带抽牌/产牌效果
    - 两类卡牌组合（认知+行为、认知+情绪、情绪+行为）：详见 **[卡牌组合逻辑](./卡牌组合逻辑.md)**
    - 组合效果参照具体态度效果表（当前未完成）

    ### 胜负条件
    - 基础胜负条件：清空敌人血量
    - 扩展路径（说服/欺骗/安抚/威慑/观察者效应）可叠加贡献
    

数值计算：
    卡片有积极、消极、中性三种类别
    认知+情绪+行为=态度
    将认知、情绪、行为看作长度为1的单位向量，积极、消极、中性看作是否沿对应轴正方向、负方向、取零。
    态度不再是27个离散晶体，而是基于PAD情绪空间+7行为驱动的连续态度模型。
    参见 态度系统/态度模型可视化.html。
    根据得到的态度晶体可以扩展出诸多计算。
    


角色（暂定）：
    医生：有时候病人与医生的界限并不明显，但是你终究知道的更多，不是吗：在态度结算时可以将行为卡转变为任意颜色
    正常人：我为什么会在这里(这个世界上真的有正常人吗？)
    躁狂症：易怒(造成和受到的伤害增加,具体数值依赖精神值)：在态度结算时可以将任意态度卡转变为红色
    抑郁症：悲观(造成和受到的伤害减少,具体数值依赖精神值)：在态度结算时可以将任意态度卡转变为蓝色
    双向情感障碍：在经历负面情绪之后，下一次情绪变化一定为正面情绪，连续正面情绪后会陷入负面情绪
    人格分裂：在负面情绪和正面情绪下可以召唤另一个自己
    创伤后应激障碍(PTSD)：进入负面情绪时会出现幻觉，敌人的行为与态度会发生改变
    自闭症：善于和卡牌交朋友(满足一定条件可以修改卡牌数值，包括敌人的卡牌)
    胆小鬼：容易受到惊吓(陷入恐惧状态会增加行动力，但是过度恐惧会造成惊厥并失去行动能力)
    拖延症：没有使用的行动点数和卡牌可以积攒到下一个回合
    健忘症：所有精神状态都只会持续一回合

# 卡牌 UI 设计规范

> 解决一个问题：复杂的后端计算怎么不让玩家看见，但让玩家理解。

---

## 一、三层信息架构

```
第一层：卡面（永远不变）
  ─ 玩家拿起卡就知道它做什么
  ─ 不被任何状态修改

第二层：动态叠加（实时变化）
  ─ 手牌中每张卡显示当前 AP 消耗 + 标签
  ─ 后台 g_i、α_i、PAD 全部算完后叠上来

第三层：悬停（按需展开）
  ─ 鼠标/光标停在卡上→ 显示 "为什么"
  ─ 一行文字，不是公式
```

---

## 二、行为卡

### 卡面（静态）

```
┌──────────────────────┐
│ ⚡ 逃跑       [反射] │  ← 类型标签
│                      │
│ 避开下一次敌方攻击。   │  ← 效果描述
│                      │
│ 基础 AP: 1           │  ← 参考值
└──────────────────────┘
```

### 手牌中（动态叠加）

状态 A — 恐惧中（α_reflex = 0.93）：

```
┌──────────────────────┐
│ ⚡ 逃跑       [反射] │
│ ★ 优势               │  ← 驱动高激活
│ AP: 0                │  ← 实际消耗
└──────────────────────┘
```

状态 B — 不恐惧（α_reflex = 0.08）：

```
┌──────────────────────┐
│ ⚡ 逃跑       [反射] │
│                      │  ← 无标签，正常消耗
│ AP: 1                │
└──────────────────────┘
```

状态 C — 恐慌强制（α_reflex = 0.88）：

```
┌──────────────────────┐
│ ⚡ 逃跑       [反射] │
│ ‼ 强制               │  ← 必须打出
│ AP: 0                │
└──────────────────────┘
```

### 悬停

状态 A 悬停：

```
"反射驱动高度激活。恐惧让你身体快过大脑——逃跑毫不费力。"

状态 B 悬停：
"当前反射驱动未激活。你可以正常选择逃跑，但身体不推着你走。"

状态 C 悬停：
"恐惧已超出生理承受阈值。你必须打出一张反射卡。花 3 意志力可压制。"
```

### 惩罚卡（硬解锁）

状态 — α_value = 0.35，低于阈值 0.50：

```
┌──────────────────────┐
│ ◈ 牺牲       [价值] │
│ ⚠ 惩罚               │  ← 需要意志力
│ AP: 3 + 意志力 1     │  ← 额外代价
└──────────────────────┘
```

悬停："你还没找到做这件事的信念。硬做需要意志力。"

---

## 三、情绪卡

### 卡面（静态）

```
┌──────────────────────┐
│ ~ 恐惧       [情绪]  │
│                      │
│ 打出: 强烈恐惧爆发    │
│ 留在手牌: 轻度恐惧压力 │
│ 战末残留: 惊觉倾向 ↑  │
└──────────────────────┘
```

不需要 PAD 坐标。不需要 "P=-0.70, A=+0.75, D=-0.65"。玩家只需要知道 "打出" 和 "不打出" 分别意味着什么。

### 手牌中（动态）

```
┌──────────────────────┐
│ ~ 恐惧       [情绪]  │
│ 压力: ███░░ 中等      │  ← 当前累积了几个回合
└──────────────────────┘
```

悬停："每回合在手牌中产生轻度恐惧。已累计 3 回合。战斗结束后未处理将对惊觉倾向造成负面影响。"

---

## 四、认知卡

### 卡面（静态）

```
┌──────────────────────┐
│ ◇ 明察秋毫  [知觉]  │  ← 模块标签
│                      │
│ 揭示敌人一个隐藏属性。 │  ← 效果
│                      │
│ 基础效果: 揭示 1 属性 │
└──────────────────────┘
```

### 手牌中（动态）

认知卡通常没有 AP 波动。但认知质量可能被情绪扭曲：

```
┌──────────────────────┐
│ ◇ 明察秋毫  [知觉]  │
│ ⚡ 注意窄化           │  ← 当前情绪对认知的负面干扰
│ 效果: 揭示 0~1 属性   │  ← 可能不完整
└──────────────────────┘
```

悬停："恐惧窄化了你的注意力。你可能会漏掉一些细节。"

相反——快乐情绪下：

```
┌──────────────────────┐
│ ◇ 明察秋毫  [知觉]  │
│ ☀ 注意拓宽           │  ← 正面干扰
│ 效果: 揭示 1~2 属性   │
└──────────────────────┘
```

## 五、统一的标签体系

六种标签，玩家一眼识别卡牌当前状态：

| 标签 | 含义 |
|------|------|
| ★ 优势 | 驱动高度激活，AP 降低，效果可能增强 |
| ⚠ 惩罚 | α_i 低于阈值，需花意志力硬解锁 |
| ‼ 强制 | 超过恐慌阈值，必须打出（可用意志力压制） |
| ⚡ | 情绪对认知有负面干扰 |
| ☀ | 情绪对认知有正面增益 |
| — | 正常，无特殊状态 |

## 六、玩家需要理解什么

| 玩家需要知道的 | 在哪里看到 |
|-------------|----------|
| 这张卡做什么 | 卡面（静态） |
| 这张卡现在要花多少 AP | 手牌动态数字 |
| 为什么这么贵/这么便宜 | 悬停（一行文字） |
| 这张卡现在能不能打 | 标签或无标签 |
| 不选这张卡有什么后果 | 悬停（仅强制标签时） |

| 玩家不需要知道的 | 放在哪 |
|---------------|--------|
| g_reflex = σ(2.0·max(0,A-0.3) + ...) | 后端 |
| α_reflex(t) = α_reflex(t-1) + λ(...) - μ(...) | 后端 |
| 当前 PAD 坐标 (−0.70, +0.75, −0.65) | 后端 |
| θ_play 阈值 | 后端 |
| 惯性时程 τ | 后端 |

---

## 七、AP 显示的规则

```
基础 AP：      卡面上印的数字（参考值）
当前 AP：      max(0, round(base × cost_modifier))
cost_modifier: 1 + β_i × (1 - α_i)  → 限制在 [0.3, 2.5]

显示：
  AP: 0       → 免费（驱动在推着你）
  AP: 1       → 正常
  AP: 2~3     → 费力（驱动不够）
  AP: 4+      → 极难（接近硬解锁的边界）
  AP: N + 意志力 M  → 硬解锁（α_i < θ_play）
```

## 八、态度体现在哪里

态度 = 认知卡 + 情绪卡 + 行为卡，三张同时打出。

态度本身没有卡——它是三卡组合的**结果**。结算时：

```
本回合态度:
  认知: 明察秋毫（看清了威胁）
  情绪: 恐惧（但我仍然害怕）
  行为: 面对（我选择不逃）

结算效果:
  认知→揭示属性
  情绪→PAD 爆发
  行为→硬接敌方攻击 + 反击

"逆流而上"
  你看清了威胁，你感受到了恐惧，你没有逃。
  你花了 2 意志力。
  你对敌人造成了 ⸸ 心灵震慑。
```

三卡的机械效果各自结算。态度的叙事名称（如 "逆流而上"）可以在结算动画中展示，作为 flavor。完整态度（三类组合）的逻辑比较健全，可能附带抽牌/产牌效果。两类卡牌组合（认知+行为、认知+情绪、情绪+行为）详见 **[卡牌组合逻辑](./卡牌组合逻辑.md)**。态度效果参照具体态度效果表（当前未完成）。
