## 一、Boss 层级分类

### 决策 D1：三层 Boss 体系

| 层级 | 范围 | 生产方式 | 独有机制 |
|------|------|---------|---------|
| **杂兵** | 普通敌人 | Part 1 管线 | 无 |
| **小 Boss/头目** | 楼层小头目、护士站小头目 | 管线 + 阶段切换 | 有阶段，无独有链路/跨战斗记忆/规则修改 |
| **最终 Boss** | A/B/C 三个 | 手工设计 | 阶段切换 + 跨战斗记忆 + 场相变 |

### 决策 D2：头目来源 = 职位驱动

头目来自：主治大夫、科室主管、队长、护士长、祭司。这些职位在"医院生态中拥有管辖范围"——被更多人观察、依赖、服从，社会权重使月光对他们的坍缩更深。不排除非高职称个体因月光暴露程度极高成为头目。

### 决策 D3：敌人强度根因 = 月光坍缩强度

CGI-S 严重度和髓鞘化 m 值是坍缩的下游表现。坍缩越深 → 病情越被放大 → 敌人越强。

## 二、月光场物理模型

### 决策 D4：场源 = 零号病人

Reality Field 由医院内的点源激发。源 = 一个在精神病院出生的孩子，从未接触外界。她没有精神疾病——她的"正常"建立在与所有人不同的观察基线上。她不自觉地激发了第一个场。

**零号病人位置**：不可见，已将自己关起来。

### 决策 D5：传染模型

```
零号病人激发初始场 → 接触者在场中暴露足够久 → 成为新源 →
多源的场分量通过相位同步整合为统一相干场
```

每个感染者的大脑都是 Reality Field 的一个局域源。多个源的场整合为覆盖全医院的宏观相干场——类似 BEC 凝聚。

### 决策 D6：昼夜 = 场相变表观

白天和夜晚不是外部天体运动——是 Reality Field 在对称相（白天）和破缺相（夜晚）之间的周期转换。太阳是场在对称相下的视觉表观，月亮是场在破缺相下的视觉表观。周期由感染者集体的生物节律驱动。

### 决策 D7：月相 = 集体生物节律拍频

~29.5 天周期来自多个感染者源的相位同步中自然涌现的拍频。人体内嵌的天体节律印记（月经周期 ≈ 月相周期）为这一周期提供了生物学基底。

### 决策 D8：玩家 = 感染者

玩家是感染者。NPC 行为使用预烘焙查表是 CPU 性能的妥协——理想设计中 NPC 应无限接近真人的行为能力。

## 三、Boss A — 院长（物理场）

### 决策 D9：人设

精神科医生出身，建院目的就是研究精神疾病的生物学基础。门诊楼顶有半个楼层的实验室——远超常规精神卫生中心配置。思维实体化现象出现后，好奇心驱动他主动研究。

### 决策 D10：反噬机制（两点）

1. **双向观察**：思维造物也会观察——他测量造物时，造物也在测量他。观察者效应是双向的。
2. **无物理脑节点**：思维造物不像人类有 89 脑区作为稳定锚。当源头的思潮（院长的认知框架）因双向观察而波动 → 造物结构不稳定 → 不稳定造物反过来冲击源头 → 恶性循环。

**反噬结果**：院长的认知被造物残片寄生——他无法区分自己的思维和寄生碎片。不是疯子——可能还能逻辑对话——但他的认知模型已不可逆地与 Reality Field 中的异常结构耦合。

### 决策 D11：NPC 阶段

玩家首次遇到院长时他是正常人——在门诊楼顶层实验室继续研究。他提供：

- **精神伤害方向的装备**：场测量仪器、认知防护装置
- 也可讨论 Reality Field 的本质（对话选项可能影响他的转变速度）

### 决策 D12：NPC→Boss 转变条件

累积性触发。变量包括：

- 玩家频繁使用他的实验室/仪器（增加他的实验频率）
- 玩家把战场上的造物残片带给他分析（大幅度暴露）
- 长时间不互动（他仍在自行实验 → 缓慢自动推进）
- 特定对话（可能动摇他的科学框架 → 加速或延迟）

临界点：他无法再区分自己的思维和寄生碎片时 → NPC 关闭 → Boss 战触发。

### 决策 D13：Boss 战斗方向

物理场极化。核心张力：**试图测量的东西反过来吞噬测量者**。战斗主题待后续细化。

## 四、Boss B — 传销头子（神明）

### 决策 D14：人设

为了躲避法律制裁伪装精神病入院。月光现象发生后，发现"信徒越多 → 力量越真实"。一开始是清醒的投机者——但当那个他编造的神开始真正回应祈祷、降下神谕，**他是第一个跪下去的**。骗子被自己的骗局转化成虔信者。

### 决策 D15：神明实体 = 集体思维造物

当足够多独立观察者以足够高的相位一致性相信同一个东西——那个东西就坍缩为真实实体。这是思维造物的集体版本。

| 属性 | 描述 |
|------|------|
| 信息整合容量 Φ | 远超单个人类——"脑"是所有信徒的脑通过 Reality Field 的相位同步构成的分布式网络 |
| 自我观察 | 有递归坍缩回路——神明的自我观察本身会改变神明的形态 |
| 对信徒的观察 | 直接场层感知——信徒的真实信念（场分量相位锁定度）对神明完全透明。没有伪信徒能伪装 |

### 决策 D16：重影与分裂

集体造物的结构不是均匀的。信徒的信念偏差 → 神明的不同"面"之间存在相位不完全锁定的区域 → **重影**（半自主的子结构）。

当信徒间的信念偏差超过临界相位差 → 重影脱离核心 → **神明分裂**。裂出的实体可能是独立的次级神明、"异端"、或对传销头子充满敌意的"被错误描述的邪面"。

人脑想象力的局限 → 先天盲人无法想象色彩 → 他的神明投射中没有"颜色" → 神明结构中该维度的重影是空白的 → 凝聚出的神明在视觉层面可能不完整、有缺口。

### 决策 D17：战斗方向

多路径：

- **硬打**：传统 HP 击败
- **信念偏差路径**：玩家利用/放大信徒之间的信念分歧 → 催生重影积累 → 最终触发神明分裂 → 分裂后的实体可能互相攻击、或反叛传销头子

## 五、Boss C — 退伍军人（催化媒介）

### 决策 D18：人设

- **1979**：越南战场，19-22 岁。丛林夜间伏击幸存者。学会把恐惧塞进盒子。
- **退役后**：转业安排到精神卫生中心保卫科。从制服失控病人的工作中积累了三十年的身体控制经验。
- **被提拔为队长**：提前找回逃跑病人，没有引起社会影响。
- **现象发生后**：立即组织人手尝试逃离。意识到空间扭曲后，带领受控人群退守供应中心等待救援。当病人的思维造物逸散到病房外后，率剩余人群撤退到供应中心。

### 决策 D19：PTSD 在催化媒介下的恶化

催化媒介不加方向——只放大已有。

| PTSD 症状 | 场放大后的表现 |
|----------|-------------|
| **过度警觉** | 几乎不睡觉。在供应中心永远在巡逻。每一丝声音都被放大为威胁信号 |
| **闯入性回忆** | 场催化使越南的碎片具象化——供应中心角落可能弥漫丛林气味、潮湿热度 |
| **情绪麻木** | 面对死亡时表情是平的。剩下的人怕他——以为他不在乎。不是不在乎——是"在乎"被压在盒子里太深 |
| **幸存者内疚** | 越南活下来而战友死了 + 供应中心里手下的人一个个消失。催化媒介把内疚放大 → 他可能**主动想死在战场上** |

### 决策 D20：NPC 阶段

玩家首次进入供应中心时他还活着，在组织幸存者。他提供：

- **物理伤害方向的装备和护甲**
- **身体控制的训练**（近战强化）

装备体系因此按 Boss 分化：
- 院长（门诊楼顶）= 精神伤害/精神护甲方向
- 队长（供应中心）= 物理伤害/物理护甲方向

### 决策 D21：NPC→Boss 转变条件

累积性触发。变量包括：

- 折损人数（每失去一个幸存者 → 恶化推进）
- 玩家带来的信息（"外面没有救援"可能加速崩溃或坚定纪律）
- 物资耗尽 → 群体现恐慌 → 他的控制压力增加
- 长期睡眠剥夺

临界点：他的盒子裂开——三十年前丛林中的恐惧和供应中心积累的绝望同时涌出。

### 决策 D22：Boss 战斗方向

催化媒介极化。核心张力：**战场上唯一能控制情绪的人，被场放大的恰恰是他长期训练压制的东西。** 战斗主题：**战场回响**——供应中心的物理空间被他内在世界的记忆（越南丛林 + 三十年夜班走廊 + 每一个掉队者的情绪残影）覆盖。

## 六、共性机制框架

### 决策 D23：多阶段触发

**HP 双阈值**作为初步框架（后续可按 Boss 分化）：

| 阶段 | 阈值 | Boss A | Boss B | Boss C |
|------|------|--------|--------|--------|
| 阶段 1 | 100-67% | 认知完整，可预测 | 完整信徒网络，神明稳定 | 纪律主导，战术清晰 |
| 阶段 2 | 66-34% | 寄生碎片显现，测量不准确 | 信徒动摇，神明重影显现 | 盒子裂开，记忆覆盖战场 |
| 阶段 3 | ≤33% | 认知崩溃，无法区分自身和寄生碎片 | 神明可能分裂，传销头子可能献祭融合神格 | 盒子全开，越南+供应中心叠加 |

阶段过渡时战斗暂停 2-3 秒，Boss 自身发生场相变表观。

### 决策 D24：跨战斗记忆

**记模式不记回合，调整行为偏好不直接加属性。**

| 记忆类型 | 具体内容 |
|---------|---------|
| 链路偏好 | 玩家上次战斗中使用频率最高的链路层级分布 |
| 行动模式 | 物理/精神攻击/防御的比例 |
| SAN 管理习惯 | 何时用内省、是否用过 HP↔SAN 互转 |
| 上次结果 | 谁赢了，怎么赢的 |

**Boss 差异**：
- A 院长：记忆链路偏好最精确（科学方法 = 观测 = 记录）
- B 传销头子：记忆最弱（力量来自信徒不是自身）
- C 队长：记忆行动模式最精确（军人本能 = 学习敌人）

**衰减规则**：
- 记住最近一次战斗的完整模式
- 前一次战斗 50% 效果
- 更早的遗忘
- 击败 Boss 后记忆清零

### 决策 D25：髓鞘化成长

归入剧情/任务系统设计。Boss 是否成长、如何成长取决于玩家选择和剧情发展。

## 七、数值基线

### 决策 D26：HP/SAN 基准

所有数值 ×5 作为基准（后续模拟验证时迭代）。

| Boss | HP | SAN | 逻辑 |
|------|-----|------|------|
| **A 院长** | 600-800 | 90-110 | 低物理/高精神。三十年认知训练 → SAN 超玩家基线。精神攻击对他效果差 |
| **B 传销头子** | 400-600 | 60-80 | 自身弱。力量来自信徒网络。信徒全清后极脆 |
| **C 队长** | 1000-1300 | 40-60 | 高物理/低精神。退伍军人+警卫三十年。PTSD 和长期暴露使精神脆弱。精神攻击有效 |

战斗长度目标：**16-20 回合**。

## 八、被否决项

| 项 | 原因 |
|----|------|
| **独有链路**（Boss 专属，不在 364 条中） | 364 条链路 × 89 脑区的组合空间足够搭建任何需要的大脑活动。Boss 独特性来自他们如何配置和极化已有链路，不是额外硬件。与敌我同构原则一致 |
