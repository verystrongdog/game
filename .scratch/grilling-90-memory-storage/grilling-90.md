## 话题

从 #87（NPC 人生自主起草功能）拆出的独立议题（#87-D10，2026-08-19 用户决策）。**记忆物理储存 = 运行时基础设施**（管线维度），服务对象远超创伤记忆：

**现状核查结论（2026-08-19，引用即读取已执行）**：

- 现有设计只有记忆**功能层**（脑区定位：海马 CA1 回忆/CA3 辨别/海马旁回识景/后扣带内省/峡部扣带回溯/颞极识人，[脑功能层级模型.md §四-五](../../规则/技能树系统/脑功能层级模型.md)），**无记忆内容层**（无「一条记忆」的数据结构/存储位置/写入管线/检索接口）
- 91 运行时状态变量全是动力学变量（[运行时状态模型.md §三](../../规则/技能树系统/运行时状态模型.md)），无记忆实体；m 是链路强度非内容
- **先例**：敌人跨战斗记忆（[敌人与事件.md §4.6](../../实体/敌人与事件.md)：链路偏好/行动模式/SAN 习惯/上次结果，带衰减 完整→50%→遗忘→清零）——唯一内容层记忆
- **需求方**：创伤记忆（#87/#88）、NPC 跨战斗记忆、DID 记忆区隔化（[解离性身份障碍.md](../../实体/疾病目录/解离性身份障碍.md)）、健忘症搁置角色（[角色与面具.md §6](../../实体/角色与面具.md)，搁置原因 = 「需建立海马记忆链路直接修改框架」）、玩家叙事记忆

## 已知待讨论问题（清单，grilling 逐题展开）

1. **数据结构**：记忆内容实体的 schema——字段（内容/时间锚/来源/关联人物/强度/访问状态）？与创伤记忆载体 `{烈度 I, 表征 N/F/R, 事件快照, 总负荷 L}` 的关系
2. **存储位置**：存哪一层——战斗状态（combat_state）/ 角色构建层（NPC 参数）/ 全局档案？与 91 动力学变量、m（构建层慢变量）的边界
3. **写入管线**：记忆如何被创建（可塑性巩固/生成功能产出/事件记录）→ 如何进入存储
4. **检索接口**：θ_mem 检索（现有 σ(mean(MTL)−θ_mem)）与内容检索的对接；g 触发（情境相似度 s）如何读存储
5. **生命周期**：创建-强化-区隔（DID）-遗忘-清零（Boss 战）的状态机；访问层遗忘（不作用于 m）的实现
6. **统一性 vs 专用**：统一记忆 schema 覆盖全部需求方，还是分专用类型（创伤/策略/叙事）
