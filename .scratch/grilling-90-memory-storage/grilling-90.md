## 话题

从 #87（NPC 人生自主起草功能）拆出的独立议题（#87-D10，2026-08-19 用户决策）。**记忆物理储存 = 运行时基础设施**（管线维度），服务对象远超创伤记忆：

**现状核查结论（2026-08-19，引用即读取已执行）**：

- 现有设计只有记忆**功能层**（脑区定位：海马 CA1 回忆/CA3 辨别/海马旁回识景/后扣带内省/峡部扣带回溯/颞极识人，[脑功能层级模型.md §四-五](../../规则/技能树系统/脑功能层级模型.md)），**无记忆内容层**（无「一条记忆」的数据结构/存储位置/写入管线/检索接口）
- 91 运行时状态变量全是动力学变量（[运行时状态模型.md §三](../../规则/技能树系统/运行时状态模型.md)），无记忆实体；m 是链路强度非内容
- **先例**：敌人跨战斗记忆（[敌人与事件.md §4.6](../../实体/敌人与事件.md)：链路偏好/行动模式/SAN 习惯/上次结果，带衰减 完整→50%→遗忘→清零）——唯一内容层记忆
- **需求方**：创伤记忆（#87/#88）、NPC 跨战斗记忆、DID 记忆区隔化（[解离性身份障碍.md](../../实体/疾病目录/解离性身份障碍.md)）、健忘症搁置角色（[角色与面具.md §6](../../实体/角色与面具.md)，搁置原因 = 「需建立海马记忆链路直接修改框架」）、玩家叙事记忆

## 已知待讨论问题（清单，grilling 逐题展开）

1. **数据结构**：记忆内容实体的 schema——字段（内容/时间锚/来源/关联人物/强度/访问状态）？与创伤记忆载体 `{烈度 I, 表征 N/F/R, 事件快照, 总负荷 L}` 的关系
2. **存储位置**：存哪一层——战斗状态（combat_state）/ 角色构建层（NPC 参数）/ 全局档案？与 91 动力学变量、m（构建层慢变量）的边界
3. **写入管线**：记忆如何被创建（可塑性巩固/生成功能产出/事件记录）→ 如何进入存储
4. **检索接口**：θ_mem 检索（现有 σ(mean(MTL)−θ_mem)）与内容检索的对接；g 触发（情境相似度 s）如何读存储
5. **生命周期**：创建-强化-区隔（DID）-遗忘-清零（Boss 战）的状态机；访问层遗忘（不作用于 m）的实现
6. **统一性 vs 专用**：统一记忆 schema 覆盖全部需求方，还是分专用类型（创伤/策略/叙事）

## Comments

- **#90-D4 存储位置分层确认（2026-08-20）**：**构建层持久 + 战斗层快照**。构建层（NPC 参数/角色档案）：`MemoryRecord[]` 持久记忆库（index/access/payload 全字段，与 m 同层——都是构建层慢变量）；战斗层（combat_state 扩展）：`battle_active_memories` 只存本场被勾起/新写入的记录 **id 快照 + 激活强度**，不存记忆内容（黑箱边界：战斗层不存记忆内容，避免 91 动力学变量被记忆实体污染），战斗结束并入构建层。已排除：A 战斗状态单层（combat_state 每战重建，放不下跨战生命周期——巩固 T_sys 跨天/遗忘幂律跨年/Boss 清零均超单场战斗）、C 单层（每回合读写档案不现实）。

- **#90-D3 容量机制确认（2026-08-20）**：容量 = 纯游戏参数（方案 B），**去神经化**：`cost_j = α/a_j`，`Σ_j cost_j ≤ Cap_max`（α = 单位成本、Cap_max = 记忆库总容量，均 [NEW]）；`a_j = |T_j|/D`（index 稀疏度，内容层自有量）。**黑箱语义确认**：记忆内容层不调用海马内部结构——不建 CA3 回返网络、不引 DG 数据（DK 图谱无亚区分割，CA1/CA3 共享 1 个 OBJ）、内容层公式零解剖数据依赖；引擎侧对海马维持正典现状（limbic 环路输入节点 + θ_mem MTL 激活均值）。已否决：Treves-Rolls 容量公式（`C_slot/(a·ln(1/a))`，借神经形式但游戏无 CA3 内部网络 → 语义漂移风险，复刻 #25「引用不存在数据」教训）；Hopfield 0.138N（N 映射无意义）。**海马内部环路建模 = 推迟项**（若未来需 CA3 模式完成精细建模，单开 issue，不阻塞 #90）。

- **#90-D2 再巩固适用范围确认（2026-08-20）**：提取 = 写操作（再巩固）应用于**全部记忆类型**（结构统一，无类型特判——所有记录同一状态机，提取后进入 RECONSOLIDATING），**改写幅度按烈度分级**（A+ 方案）：创伤/高烈度记录可大幅改写（治疗/闪回改写，叙事核心），普通记忆仅轻微改写（防意外篡改）。窗口 `T_re ≤ 6h × τ_scale`；窗口内未稳定化 → WEAKENED；测试效应 `P_acc += δ_test` 全类型适用（只读收益）。与 #87-D8 兼容（访问层）。

- **#90-D1 勾起概率函数形式确认（2026-08-20）**：`P_trigger,j = σ(κ·s_j³ − θ_g)`（§6.3）。指数 n 固定 = 3（Minerva 2 激活结构特征，非自由参数；4/5/更高次幂向硬阈值退化——半概率点 s*=(θ/κ)^(1/n) 位移杀死阈下触发，与 #87-D7 冲突）；κ（相似度缩放）/θ_g（勾起阈值）= [NEW] 待 #35 校准。已否决：线性+σ（判别弱）、硬阈值（阈下触发清零）、聚合回声 σ(κ·I−θ_g)（不能逐条定位勾起哪条记录）。内容层相似度 s_j = (P·T_j)/N 确定为勾起函数唯一输入；s 的构成（TCM 情境成分权重 w₁/w₂）随 Q4 检索接口讨论。数学依据：`数学建模-记忆过程.md` §6.3 + 半概率点/导数/退化极限论证（2026-08-20 对话记录）。
