## 一、模型总览：六阶段状态机

记忆记录 R 的生命周期 = 六阶段状态机，每阶段一个数学映射：

```
事件 e ──E──→ R(新生) ──C──→ R(稳定) ──S──→ 双结构存储（en 侧记录 ‖ 皮层 m 权重）
                 │                       ↑
                 │                       │ 提取（线索 P）
                 └── R(检索) ──RC(再巩固) ─┘ → 稳定 / 减弱 / 改写
   任意阶段 ──F──→ 可提取性衰减 → 遗忘(访问失败) / 区隔(DID) / 清零(Boss 战)
```

**设计原则**（全部有文献或正典依据，见 §十二）：

1. **内容层与权重层分离**：记忆 = 离散记录对象（engram 侧，可寻址）+ 分布式权重 m（皮层侧，不可寻址）双结构并存——文献：engram 稀疏细胞群（Liu 2012）+ 互补学习系统 CLS（McClelland 1995），非二选一。
2. **遗忘默认作用于可提取性，不作用于 m**——正典 #87-D8；文献：遗忘 = 可提取性衰减 + 干扰（Wixted 2004 / Anderson & Hanslmayr 2014）。
3. **提取 = 写操作**：每次提取打开再巩固改写窗口——文献：Nader & Hardt 2009。
4. **所有文献时窗均为现实时间尺度**，映射到游戏内时间需乘时间缩放系数 `τ_scale`（`[NEW]`，见 §十一）。

## 三、E 编码：事件 → 记忆记录

**输入**：事件 `e`；**输出**：记录 `R`（含 index 向量 `T_j`、强度 `I_mem`、总负荷 `L`）。

### 3.1 强度写入

单次事件强度增量（正典 #88 输入约定）：

```
ΔI = k × A
```

- `A` = 事件烈度（#87-D6 烈度特征集合：侵入性/现在感/碎片化/生动性/生理反应/牢固度，开放集合）
- `k` = 强度系数（人物/情境调制，`[NEW]` 待 #88 定义）

### 3.2 总负荷累积

剂量-反应累积（正典 #87-D6，Kolassa 2010）：

```
L = Σ_i ΔI_i × g
```

- 同类型重复挫折按剂量-反应累积；`g` = 心智成熟系数（g 小 → 同样创伤事件负荷低）

### 3.3 写入条件：Hebbian 与门

写入发生当且仅当（文献：LTP Hebbian 特性，Bliss & Collingridge 1993）：

```
写入(R) ⟺ (事件模态激活 α ≠ 0) ∧ (参与节点激活 a_j ≥ a_write)
```

`a_write` = 写入激活阈值 `[NEW]`。缺线索（α = 0）或节点未激活 → 不写入——对应 SAM 强度相乘规则「任一线索为 0 则整体为 0」（数学综述 §三 3.1）。

### 3.4 索引写入（海马索引理论）

记录本体轻量：只存**稀疏索引** + 元数据，内容在皮层侧（文献：Teyler & DiScenna 1986）：

```
T_j = threshold_s(f(e_j))      — 取 f(e) 中激活超阈值的特征子集（稀疏化）
index_j = { T_j 的非零坐标集 }
```

稀疏化由模式分离驱动（文献：DG 稀疏编码，Rolls 2013）：相似经历去相关为独立记录。

### 3.5 突触标签捕获（弱记忆升级）

事件写入后开标签窗口（文献：Frey & Morris 1997，`T_tag < 3 h` 现实时间）：

```
若 ∃ 强化事件 e_s ∈ [t_e, t_e + T_tag] 且 A_s > A:
    ΔI_eff = max(ΔI, k × A_s)     — 弱事件被强事件捕获升级
```

与正典可塑性巩固（标记/增强）兼容：游戏内巩固窗口的神经依据。

## 四、C 巩固：双尺度 + 回放蒸馏

**输入**：新生记录；**输出**：稳定记录（海马依赖结束 → 皮层可提取）。

### 4.1 双尺度巩固

（文献：Dudai 2004）

```
T_syn ∈ [分钟, 小时]     — 突触巩固：写入后立即开始，数小时内定型
T_sys ∈ [天, 年]        — 系统巩固：跨游戏内多日，记忆重组
```

记录状态 `CONSOLIDATING` 持续到 `T_sys` 完成（或图式加速提前结束，§4.4）。

### 4.2 回放蒸馏（非一次性拷贝）

迁移 = 多次重激活逐步写入皮层（文献：McClelland 1995 CLS）：

```
每次睡眠/休息触发 N_replay 次回放
每次回放：皮层增量 Δm_cortex = η × φ(R_j)        — η = 回放学习率 [NEW]
迁移完成度：P_hip(t) = 1 − exp(−n_replay_done / N_replay_target)
```

`P_hip` = 海马依赖剩余度；`P_hip → 0` ⇒ 记录海马独立（皮层可提取）。回放不足 → 迁移不完整（皮层痕迹弱）。

### 4.3 睡眠触发

睡眠/休息 = 巩固触发事件（文献：Walker & Stickgold 2004）。游戏正典「休息驱动时间」天然承担此角色：**不休息 → 记录停留易失状态**（结合 §八 8.1：易失期受干扰竞争 → 更易遗忘）。

### 4.4 图式加速

事件与既有图式重叠度高 → 巩固极快（文献：Tse 2007，单次试训 24-48h 海马独立）：

```
γ(e) = 1 + γ_max × overlap(e, schema(e))          — 图式系数，γ_max [NEW]
T_hip' = T_hip / γ(e)
```

### 4.5 巩固完成判定

```
STABLE ⟺ P_hip ≤ ε_hip                          — ε_hip = 迁移完成阈值 [NEW]
```

## 五、S 存储：双结构 + 容量

**输入**：稳定记录；**输出**：双结构存储布局。

### 5.1 双结构并存

| 层 | 结构 | 可寻址性 | 文献 |
|----|------|---------|------|
| en 侧（内容层） | 离散记录对象（index + 元数据 + 载荷） | 可寻址（玩家/剧情/系统可按 id 引用） | engram（Liu 2012；Tonegawa 2015） |
| 皮层侧（权重层） | 分布式权重 m（不可寻址，只能整体激活） | 不可寻址 | CLS（McClelland 1995） |

### 5.2 容量上限（黑箱语义）

> 🔧 2026-08-20（#90-D3）：容量机制**去神经化**——海马内部环路（CA3 回返网络）不建模，容量公式为纯内容层游戏参数，不引用任何解剖结构。

```
cost_j = α / a_j                 — 记录 j 的容量成本（α = 单位成本 [NEW]）
约束：Σ_j cost_j ≤ Cap_max       — 记忆库总容量 [NEW]
a_j = |T_j| / D                  — index 稀疏度（内容层自有量，Q1 schema 字段）
```

- 稀疏记忆（a_j 小）→ cost 高（占位多）；`a_j → 0` 时 cost → ∞（祖母细胞式极端稀疏 = 禁入）
- **超载 → 检索质量整体下降**（超载惩罚函数 `[NEW]`，与 Hopfield 相变类比——量级交叉印证仅作叙事参考）
- 创伤记忆设计为高稀疏：占容量大、抗相似记忆污染（§6.1 干扰小）
- 输入只有 `a_j`、`D`——均为内容层字段，**零解剖数据依赖**（不读 brain_regions.json / tripartite_model.json）
- **海马内部环路建模 = 推迟项**（若未来需 CA3 模式完成精细建模，单开 issue，不阻塞 #90）
- 已否决：Treves-Rolls `C_slot/(a·ln(1/a))`（借神经形式但游戏无 CA3 内部网络 → 语义漂移风险）、Hopfield `0.138N`（N 映射无意义）

### 5.3 自传体例外（MTI）

自传体记忆**不执行**「迁移即删除海马副本」（文献：Cabeza & St Jacques 2007）：远记忆仍保留海马痕迹，删除海马只损失最新痕迹、不损失老痕迹——多重痕迹理论 MTI。

## 六、R 检索：相似度 → 激活 → 阈值判定

**输入**：线索 `P`；**输出**：触发概率 `P_trigger`、检索成功率 `P_success`、提取内容。

### 6.1 相似度与回声（Minerva 2）

（文献：Hintzman 1988；公式核验见数学综述 §二）

```
s_j = (P · T_j) / N                  — 归一化点积，N = 特征数
a_j = s_j³                           — 激活（相似度立方，突出高相似、压制低相似）
I   = Σ_j a_j                        — 回声强度（熟悉度证据）
C_i = Σ_j a_j T_ji / Σ_j a_j         — 回声内容（提取 = 多条相似痕迹加权平均）
```

- 回声内容公式 ⇒ **相似记忆互相「渗入」**：提取一条记忆时相似记忆混入内容（泛化/混淆来源）——模式分离失败的表现
- `s_j ∈ [0,1]` 即正典 `P = f(s)` 的输入 s

### 6.2 情境成分（TCM）

相似度含时序情境项（文献：Howard & Kahana 2002）：

```
s_j = w₁ × (P·T_j)/N + w₂ × (c_R · c_E,j)        — w₁ + w₂ = 1 [NEW]
```

`c_R` = 提取时情境向量、`c_E,j` = 编码时情境向量。情境 = 时间 + 地点 + 情绪 + 在场人物的组合向量 `[NEW]`。效果：时间/地点/情绪自动成为检索维度（同一天/同地点/同情绪事件互相勾起）。

### 6.3 勾起触发概率

正典 `P = f(s)` 的具体函数形式（`[NEW]`，由 Minerva 激活 + SDT 阈值合成）：

```
P_trigger,j = σ(κ × s_j³ − θ_g)       — 逐条触发概率
```

- `κ` = 相似度缩放 `[NEW]`；`θ_g` = 勾起阈值 `[NEW]`
- 部分线索（s 低但非零）→ 仍可能触发（CA3 模式完成补全，正典 #87-D7 阈下触发兼容）

### 6.4 检索成功率（正典公式，SDT 解释）

正典公式不改，解释为 SDT 判定概率（数学综述 §八：`θ_mem` = 判据 c）：

```
P_success = σ( mean(a of MTL nodes) − θ_mem )
```

- `mean(MTL)` = 被线索激活的索引节点（记录 j 的 index 坐标）激活均值 = 信号强度
- `θ_mem` = 提取判据 c：c 高（保守，少提取——PTSD 回避）vs c 低（宽松，频繁勾起）
- 与 Hopfield 重叠度视角同构：`mean(a)` 可解释为收敛状态与记忆吸引子的重叠度 `m = (1/N)Σ_i s_i s_i^μ`

### 6.5 采样循环（SAM，可选结构）

连锁勾起（一个线索勾起一串记忆）：逐项采样 + 恢复判定（文献：Raaijmakers & Shiffrin 1981）：

```
P_s(i) = S(i, context) / Σ_k S(k, context)      — Luce 采样
P_r(i) = 1 − e^(−S(i, context))                 — 恢复判定
多线索：S_total = S_情境 × S_人物 × S_情绪       — 强度相乘，缺一为 0
```

## 七、RC 再巩固：提取 = 写操作

**输入**：被成功提取的记录；**输出**：改写后的记录 / 减弱 / 保持不变。

### 7.1 再巩固窗口

提取后记录进入 `RECONSOLIDATING`，开改写窗口（文献：Nader 2000，`T_re ≤ 6 h` 现实时间；Schiller 2010 人类侧有复现争议，默认取动物侧）：

```
T_re = 6 h × τ_scale       — 游戏内窗口时长 [NEW]
```

### 7.2 改写规则

窗口内干预（治疗/新事件/叙事）可改写强度：

```
I_mem ← I_mem + ΔI_int       — ΔI_int 可正（强化）可负（治疗/消退）
窗口外干预 → 无效
```

与正典联动：窗口内高 A 事件 → 创伤记忆强度改写；未稳定化（窗口内受干扰且无巩固）→ 记忆变弱甚至丢失。

### 7.3 测试效应（提取正增益）

成功提取本身增强保持（文献：Roediger & Butler 2011）：

```
每次成功提取：P_acc ← P_acc + δ_test            — δ_test > 0 [NEW]
```

回忆次数越多越牢固（复习机制），而非消耗记忆。

## 八、F 遗忘：可提取性衰减（不作用于 m）

**输入**：任意记录；**输出**：`P_acc` 下降（记录保留、访问变难）。

### 8.1 幂律衰减

遗忘 = 可提取性衰减，非存储删除（文献：Wixted 2004 / Anderson & Hanslmayr 2014；曲线：Murre & Dros 2015）：

```
P_acc(t) = P_acc(0) × (t / t_ref)^(−b)        — t 为记录年龄（游戏内时间），t_ref = 1 天
```

- 数据锚点：1 天剩 ≈ 0.34（Ebbinghaus 原始数据 0.337，Murre & Dros 2015 Table 3）
- `b` = 遗忘指数 `[NEW]`（b 越大忘得越快；Ebbinghaus 数据 31 天剩 0.211 ⇒ b ≈ 0.14，待游戏内校准）
- 幂律慢尾：跨年记忆仍保留非零可提取性（长剧情伏笔可用）
- **时间不进创伤记忆判定**（正典 #87-D2）：创伤记忆的 `I_mem` 不衰减，仅 `P_acc` 层衰减

### 8.2 遗忘的工程实现

两种等价实现（均与正典 σ 公式兼容）：

```
方案 A：θ_eff(t) = θ_mem + Δθ × (1 − t^(−b))      — 阈值随时间抬高
方案 B：mean(MTL)(t) = mean(MTL)(0) × t^(−b)      — 激活随时间衰减
```

### 8.3 主动遗忘（PFC 抑制）

主动遗忘 = 提高检索阈值/降低可提取性，记录仍在（文献：Anderson & Hanslmayr 2014）：

```
P_acc ← P_acc × (1 − Δ_forget)                   — Δ_forget = 抑制强度 [NEW]
```

与正典 #87-D8 兼容：抑制能力 C 随应激/病情下降 → 主动遗忘成功率下降（想忘忘不掉）。

### 8.4 干扰

相似新记忆写入 → 旧记忆检索竞争（模式分离失败）：

```
s_j(旧) 被 s_k(新) 压制 ⟺ overlap(T_j, T_k) > θ_confuse     — θ_confuse = 混淆阈值 [NEW]
```

### 8.5 铁律

**遗忘不作用于 m**（正典 #87-D8）：m 是构建层慢变量，髓鞘化不衰退；疾病遗忘（DID 区隔/解离性遗忘/敌人跨战斗衰减）全部在访问层实现。

## 九、记录状态机（生命周期）

### 9.1 状态集

```
R ∈ { NEW, CONSOLIDATING, STABLE, RECONSOLIDATING, WEAKENED, FORGOTTEN, COMPARTMENTALIZED, RESET }
```

### 9.2 转移表

| 当前状态 | 触发条件 | 下一状态 | 机制 |
|---------|---------|---------|------|
| — | 写入完成（§三） | NEW | E 编码 |
| NEW | T_syn 完成 | CONSOLIDATING | C 巩固开始 |
| CONSOLIDATING | `P_hip ≤ ε_hip`（§4.5） | STABLE | C 完成（含图式加速） |
| STABLE | 成功提取（§6.4） | RECONSOLIDATING | R + RC 开窗 |
| RECONSOLIDATING | 窗口内稳定化 | STABLE | RC 完成（可能已改写） |
| RECONSOLIDATING | 窗口内未稳定化/受干扰 | WEAKENED | RC 失败 |
| WEAKENED | 再次成功提取 + 稳定化 | STABLE | 恢复 |
| STABLE / WEAKENED | `P_acc < ε_forget` | FORGOTTEN | F 可提取性归零（访问层） |
| STABLE | DID 区隔标记置位（正典 DID 行为覆盖：切换后遗忘） | COMPARTMENTALIZED | 区隔 |
| 任意 | Boss 战击败清零（正典 敌人与事件 §4.6） | RESET | 清零 |

### 9.3 关键语义

- **FORGOTTEN 非删除**：记录保留、不可访问（访问层遗忘，正典 #87-D8）；可被强线索再触发（恢复——对应临床「记忆恢复」叙事）
- **COMPARTMENTALIZED**：特定身份状态下不可访问（DID，正典 解离性身份障碍.md：海马旁回区隔化）
- **RESET**：敌人跨战斗记忆清零（正典 敌人与事件.md §4.6：击败 Boss 后记忆清零）

## 十、与 schema 的映射（Q1 桥接）

六阶段模型的变量 ↔ 记录 schema 字段（统一记录 + 类型化载荷）：

| 模型变量 | schema 字段 | 说明 |
|---------|-----------|------|
| `T_j`（index 向量） | `index` | 检索相似度 s 的计算源（§6.1/6.2） |
| `P_acc` | `access.可提取性` | 遗忘挂载点（§八）；主动遗忘/干扰/测试效应都写这里 |
| `I_mem`, `L`, `N/F/R`, 快照 | `payload.trauma` | 创伤记忆载体（正典 #87-D6，直接嵌套不重定义） |
| `c_t`, `t_anchor` | `created_at` + `index` 情境成分 | 时间锚 = 情境向量时间分量 |
| 写入阶段（E/C） | `source` | 写入管线来源（事件记录/生成功能/巩固窗口/剧情脚本） |
| 区隔标记（DID） | `access.区隔标记` | 生命周期 §9.2 |
| 类型分型 | `type` | trauma / behavioral / narrative |
| `I` 回声强度（熟悉度） | 不落盘，检索时计算 | 由 index 集合即时计算（§6.1） |

**结论**：数学模型与 Q1 推荐 schema 结构一一对应——`index` 字段承载检索模型、`access.可提取性` 承载遗忘模型、`payload` 承载编码模型、`type` 承载分型。schema 决策 = 数学模型的落盘形态。

**缺口声明（建模假设，非文献定论）**：

1. `P = f(s)` 的函数形式 `σ(κ·s³ − θ_g)` 为本次建模合成（Minerva 立方激活 + SDT σ 阈值），文献无此具体形式——`[NEW]` 建模假设
2. `s_j` 的 TCM 情境成分权重 `w₁/w₂` 为建模假设
3. 容量公式取 Treves-Rolls（`C_slot/(a·ln(1/a))`）为主、Hopfield（0.138N）为交叉印证——两者量级一致但常数不同
4. 遗忘指数 b 的 0.14 由 Ebbinghaus 数据点（1 天 0.337 / 31 天 0.211）反推，游戏内需重校准
5. 人类侧再巩固时程有复现争议（Schiller 2010 勘误），默认取动物侧 Nader 2000 的 6h 窗口
6. 所有现实时窗 → 游戏内时间需乘 `τ_scale`，`τ_scale` 取值待定
7. 提取 = 写操作（再巩固）是否应用于**所有**记忆类型（含普通叙事记忆）还是仅创伤/高烈度记忆——留待 grilling 讨论（Q4/Q5 相关）
