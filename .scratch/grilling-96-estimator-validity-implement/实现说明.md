## ⚠️ 科学后果（实现中发现，需用户知晓；按合同未偷改冻结参数）

**plug-in 在 m_ij ≥ 11 的边上永不可能 present。**

- 冻结参数组合：B_perm=999（#98 Q4b）→ 最小可报告 p = 1/1000 = 0.001；
  边内 Bonferroni α_edge = α/m_ij = 0.01/m_ij（#95 Q14）。
- 当 m_ij ≥ 11：α_edge ≤ 0.0009 < 0.001 → 任何条件对都无法拒绝 H0 → 边恒 absent。
- 实测：R_corr/F8′ 高覆盖格（reach 大、条件对多）plug-in 全 absent（A_pair=0）。
- 这是**冻结统计参数的数学后果**，非实现 bug——按「超预算/性能问题不得偷改冻结参数」铁律如实呈现。
- 若要解决（提高 B_perm / 换校正方式 / 精确置换 p 值）→ 属重审 #98 Q4b/Q14 → **标记设计越界，另开轮**。
