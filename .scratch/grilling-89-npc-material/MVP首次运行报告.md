## 二、MVP 验证了什么 ✅

1. **五阶段流水线真实跑通**：Matrix → SoilSampler → EventGenerator → MemoryBuilder → Transformer(资格门) → ArtifactDeriver → gen.json + 完整 trace
2. **资格门真实工作**（样例验证）：
   - SUD ELIGIBLE（SUBSTANCE=1 全条件过）
   - MDD INELIGIBLE（DEPRESSIVE=0 一票否决）
   - MDD INELIGIBLE（MANIA=1 排除原子拦截——正典正确：躁狂史者非 MDD）
   - BD-II INELIGIBLE（HYPOMANIA=1 但 DEPRESSIVE=0——正典正确：BD-II 需轻躁狂+抑郁双史）
   - ~19 未核验病 UNDETERMINED（正典现状真实反映）
3. **每步可追溯**：每个患者 trace 回答"为什么这个出生年/事件/资格判定"
4. **MDD 主导**（31%）符合 Kendler 共同终点临床事实——事件均匀采样下抑郁谱天然最多

## 三、归因分析（第一轮不优化，只记录）

### 发现 1：38% 患者"病理化但五病全 INELIGIBLE"

两类模式：
- **模式 A（临床史有躁狂但事件召回不含双相谱）**：临床史 MANIA=1，但触发记忆全为性创伤/社会伤害类 → 候选集 {PTSD/DID/BPD/...} 无 BD-I 可落 → 有躁狂史却无从落病
- **模式 B（BD-II 缺双史）**：HYPOMANIA=1 但 DEPRESSIVE=0 → BD-II 必要原子不全 → 正确拦截

**归因**：不是资格门 bug（门逻辑正确），是**候选召回与临床史声明的交互缝隙**——MVP 事件采样纯随机，未保证"有躁狂史的人也会经历诱发事件（丧失/慢性）"。真实世界躁狂史患者必有抑郁/压力事件。**这指向正典一个待决问题：躁狂史声明与事件召回的关联规则**（是否需保证 MANIA=1 患者的事件池含诱发类型）。

### 发现 2：UNDETERMINED 100%（每患者召回 ~19 未核验疾病）

- 正典现状真实反映（~19 病资格未核验）
- **确认病种同质化的机制根因**：资格池只有 5 病 → 生成器疾病分布被压到 5 病内（MDD 主导）——这**首次用生成器数据证明**（而非人工猜测）"病房为什么都一样"
- PTSD 等高频召回（63/100）却全部 UNDETERMINED——正是 #113 后续批次要解锁的对象

## 四、结论与移交

1. **MVP 成功**：证明"结构化输入 → 合法/可追溯/过资格门的 artifact"可行
2. **首个生态分布数据**：MDD 主导 + 5 病受限——生成器自证病种同质化的机制
3. **移交 #113 后续批次**：①躁狂史与事件召回关联规则（发现 1）②~19 病资格核验（发现 2）③PTSD F 阈值
4. **MVP 已知简化**（非缺陷，标注）：主病选择用"L_agg 最高"代替完整 N/F/R sim；临床史声明用概率采样代替叙事依据（MVP 演示用）；g/k 独立采样未与叙事绑定

## 五、一致性约束修复结果（2026-09-03，第 2 轮）

**改动**：clinical_history 采样前置（#113 Q2-3 正向：声明先于事件）→ EventGenerator 保证"MANIA/HYPOMANIA=1 → 事件序列含 ≥1 丧失/慢性诱发"。

**验证**：18/18 例 MANIA/HYPOMANIA=1 均含诱发事件 —— **一致性约束 100% 生效** ✓（#87 Q3 移交问题的修复已验证）

**但"无主病"升至 69%**——归因变化，暴露第二个正典张力：

| 模式 | 案例 | 含义 |
|------|------|------|
| DEPRESSIVE=MISSING 泛滥 | seed=43：MDD/BD-II 全 UNDETERMINED | MISSING 语义正确（无资料→不判定），但 MVP 采样 MISSING 15% + 无诱发关联 → 大量悬空 |
| 临床史全 0 + 负荷够 | seed=47：4 条生理事件 L≥1.0 但五病全 INELIGIBLE | **创伤负荷与临床史声明独立 → 负荷高≠有发作史 → 资格门正确拦截** |

**新归因（指向正典待决）**：真实世界"负荷高的患者通常有过发作"（否则不病理化），但 #113 让负荷(L)与声明(clinical_history)正交、MVP 独立采样放大了错配。**待决问题：病理化(L) 与 临床史声明 的相关性规则**——声明概率是否应随 L 提升（负荷高→更可能有 DEPRESSIVE 发作史），属 #87 Q3 生成规则 + #113 证据域交互。

**遵守第一轮不优化原则**：一致性修复已验证成功即止；负荷×声明相关性作为第二个归因点移交，不继续调参。
