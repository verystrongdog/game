# 叙事多样化维度定义 — 打破"苦命人→崩溃→住院"单一模子

> Grilling #89 素材库内容生产 · 病种同质化 + 叙事同质化双问题 · 线②产出
> **定位**：诊断确认 6 患者弧线高度同构（4/6 高光→跌落、3/6 经济崩溃、3/6 亲人丧失、4/6 被动危机入院）。本文定义"叙事多样化的轴"，作为后续患者生产与存量审视的约束清单。
> 状态：草案（待用户确认方向后生效）

---

## 一、诊断回顾：现有模子

```
[事业高光 4/6] → [经济崩溃或亲人丧失 5/6] → [长期慢性煎熬 4/6] → [危机事件→被动入院 4/6]
```

6 人中唯一异类：王淑芬（无高光、无经济崩溃、家属发现入院非危机）——她的差异化价值已验证"换模子"可行。

## 二、多样化轴（六轴，非互斥）

### 轴 1：入院方式（动机轴）

| 方式 | 现有患者 | 缺口 |
|------|---------|------|
| 被动危机入院（崩溃/吞药/抽搐被送医） | 顾维扬/孙嘉禾/林小满/陈国强（4 人） | 过剩 |
| 家属发现送医 | 王淑芬 | — |
| 强制送医 | 高远（首次） | — |
| 自愿/自知入院 | 高远（二次复发） | 缺**首次就清醒求医**的患者（非复发） |
| **求一个"说法"入院** | 无 | **缺**——主动入院不是为了治病，是为了讨个理/证明自己没疯 |

### 轴 2：入院时的功能状态

| 状态 | 现有 |
|------|------|
| 严重失能（无法自理/社会功能崩坏） | 顾维扬/孙嘉禾/林小满 |
| 慢性恶化（长年累积） | 陈国强/王淑芬 |
| **功能完好但主动求医** | 缺——"最正常的人却住院了"，制造认知反差 |

### 轴 3：叙事功能（人物在病房生态中的角色）

| 功能 | 现有 | 缺口 |
|------|------|------|
| 受难者（中心悲剧） | 顾维扬/孙嘉禾/林小满/高远 | 过剩 |
| 对照系（健康/轻症） | 郑晓敏（护士，健康） | — |
| **病中发光者**（像《寻找百忧解》"春姨"——病房里最温暖有力的人） | 无 | **缺** |
| **疾病愤怒者/否认者**（拒绝标签，与疾病对抗而非和解） | 高远（部分，合理化躁狂） | 缺完整的"对抗型" |
| **疾病利用者/扮演者**（住院换取某种利益/逃避） | 无 | **缺**——注意：2013 精神卫生法自愿住院原则下"想住院就能住院"的现实缝隙 |

### 轴 4：弧线结构（打破"高光→跌落"）

| 结构 | 现有 | 缺口 |
|------|------|------|
| 高光→跌落 | 顾维扬/孙嘉禾/陈国强/高远（4 人） | 过剩 |
| 平缓→晚变 | 王淑芬 | — |
| 低开→稳走 | 林小满（相对） | — |
| **低开→高走→骤停** | 无 | 缺 |
| **无高光的一生**（从无事业成就，病与人一起长大） | 无 | 缺（区别于林小满——她至少有婚姻/孩子） |

### 轴 5：创伤通道（打破"经济+丧失"主通道）

| 通道 | 现有 |
|------|------|
| 经济/剥夺 | 顾维扬/孙嘉禾/陈国强/林小满（4 人） |
| 丧失/哀悼 | 顾维扬/孙嘉禾/林小满（3 人） |
| 慢性冲突/高压 | 顾维扬/陈国强/王淑芬/林小满 |
| 生理/疾病 | 林小满/杨秀兰（骨架） |
| 威胁/暴力 | 周卫国（骨架，PTSD）/杨秀兰 E6 |
| **性创伤** | **完全缺**——24 病分类里独立通道，临床高烈度跨域 |
| **控制剥夺/完美主义压迫** | 完全缺 |
| **公开羞辱/失败** | 完全缺 |

### 轴 6：人物亮度光谱

| 光谱 | 现有 |
|------|------|
| 黯淡（抑郁/酗酒/躁后低落） | 6 人全在 |
| 明亮（病中仍有光/温暖） | 缺（郑晓敏是健康对照不算） |
| 中性（平静接受/幽默） | 缺 |

## 三、约束清单（生产新患者时至少满足一条新轴）

新患者/存量改造，至少命中一个"缺口"格子：

1. 入院动机 ≠ 被动危机（求说法/首次自愿/为守护某人）
2. 或入院时功能完好（制造反差）
3. 或叙事功能 = 病中发光者 / 否认对抗者 / 扮演利用者
4. 或弧线 ≠ 高光→跌落
5. 或创伤通道用未使用过的类型（性创伤/控制剥夺/公开羞辱）
6. 或亮度光谱 ≠ 黯淡

**防回归**：同一患者命中 ≥2 条新轴为优；存量患者（顾维扬等）不强改（已达标），差异靠新增补充。
