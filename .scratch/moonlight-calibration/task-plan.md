## 一、核心公式链

```
η = g_0 × c(SAN) × κ

  η        — 语义维度激活权重 ∈ [0, 0.9]
  g_0      — 场本征耦合常数，月相调制
  c(SAN)   — 归一化相干性基线，分段线性
  κ        — 认知结构效率，实体类型查表，默认 = 1.0
```

c 和 d_0 的关系已在推导中消去：C = c × log(d_0)，η = g_0 × c × log(d_0) × κ / log(d_0) = g_0 × c × κ。d_0 不进入运行时 η 计算。

## 二、c(SAN) 归一化相干性基线

```
c(SAN) — 分段线性:

  SAN ≥ 90  → c = c_min = 0.03
  SAN = 60  → c = c_60  = 0.08    ← 线性插值: (90-SAN)/30
  SAN = 30  → c = c_30  = 0.50    ← 线性插值: (60-SAN)/30
  SAN = 0   → c = c_0   = 1.00    ← 线性插值: (30-SAN)/30
```

锚点从实体类型表（`月光场-标量场模型.md` §7.3）反推：c = η / g_0。动物/碎片造物/正常人/玩家在 κ=1 时验证通过。

## 三、g_0 月相调制

```
g_0(lunar) = 0.9 × lunar

lunar ∈ {0.75, 0.88, 1.00}  — 新月/弦月/满月，三档
```

| 月相 | lunar | g_eff |
|------|-------|-------|
| 新月 | 0.75 | 0.675 |
| 弦月 | 0.88 | 0.792 |
| 满月 | 1.00 | 0.900 |

月相承载 ~29.5d 集体生物节律拍频（M4），独立于昼夜的 C 振荡（M3）。

## 四、κ 认知结构效率

```
κ ∈ [0.6, 4.5]  — 默认 = 1.0

物理含义: C_effective = C × κ
  C 度量非对角元总信息量（BCP 相对熵相干性）
  κ 修正: 环境只分辨足够集中/持久的非对角元对
  分散弱相干 < 环境噪声阈值 → 不可区分于随机标记

实体类型 κ 值从 η 目标值反推:
  动物/碎片造物/正常人/玩家/医疗人员 — κ = 1.0
  轻度病人 — κ ≈ 0.74
  中度病人 — κ ≈ 0.65
  重度病人 — κ ≈ 0.88
  拜月教徒 — κ ≈ 0.68
  完整体造物 — κ ≈ 0.66
  零号病人 — κ ≈ 4.3（显式例外: C 锁定在 0.95×C_max）
```

NPC 创建时查表。玩家运行时 κ = 1.0（无极端标签极化/疾病固化时不偏离）。κ 的动态计算（κ_label × κ_disease 公式）留给后续独立 grilling——当前实体类型模板查表已覆盖所有需求。

## 五、相变阈值 η_crit

```
η <  η_crit  → 经典现实（环境监控基 = {|x⟩}，语义不可见）
η ≥ η_crit  → 月光现实（语义维度参与环境监控）

η_crit ≈ 0.3  — 思维造物产生阈值（来自 #19）
```

**昼夜 = η 的自然相变**，不设独立的 f_day 昼夜参数：

- 白天：C_baseline 低（ρ_O 与 Q⁰ 对齐）→ η 全线 < η_crit → 经典现实
- 夜晚：C_baseline 恢复 → η 突破 η_crit → 月光现实激活
- 不是 "超自然变弱"——在临界点以下超自然不存在。水在 0°C 以下结冰，不是"更冷的水"。

白天玩家无法逃出——不是因为 η=0，是因为经典现实下：物理门锁着 + 社会秩序完好 + 你的话是"症状"。

## 六、多观察者场叠加

```
φ(point) = Σ η_i × e^(-r_i / R) / r_i

  r_i  — 观察者 i 到场中点的距离
  R    — 场相干半径（Yukawa 衰减长度，3-20m，实体类型表）
```

**同轴方向**：

```
对齐（dir_A = dir_B）→ η_叠加 = η_A + η_B
反向（dir_A = −dir_B）→ η_净 = |η_A − η_B|
```

**正交方向**：

```
dir_A ⊥ dir_B → 各自独立，不干扰
→ 月光三重叠加的物理基础：同一空间三套现实同时为真
```

**η_crit 空间判定**：

```
场点 η_total ≥ η_crit → 该点进入月光现实
  主导方向 = 该点 max(η_i × e^(-r_i/R)) 的观察者的 ρ_off
```

已实现在 `sim_moonlight_v2_sanity.py` §4 `multi_observer()`。

## 七、ρ_off 坍缩方向

```
方向向量:    V = T + D
  T = [t_1..t_6] — 性格标签偏移向量，t_i ∈ [-0.5, 0.5]
  D = [d_1..d_6] — 疾病语义权重，从疾病文件链路 m 偏移模式提取

主导方向:    axis = argmax(|V_i|)              — 6选1
方向集中度:  conc = |V_axis| / Σ|V_i|          — [0, 1]

6标签 → 6语义方向:
  axis=1 敏化-威胁 → "威胁"
  axis=2 敏化-奖励 → "渴求"
  axis=3 抑制不足 → "冲动"
  axis=4 过度抑制 → "自否定"
  axis=5 反刍     → "过去创伤"
  axis=6 社交钝化 → "疏离"
```

**三路输出**，全部离线：

| 输出 | 计算 | 时机 |
|------|------|------|
| 情境偏移 | conc × η × Δ_situation_max[axis] | 预烘焙 |
| NPC rel 权重 | baseline_rel × (1 + conc × η × direction_weight[axis]) | 预烘焙 |
| 叙事标签 | semantic_label[axis] | 设计师手配 |

运行时唯一新增：η 乘法和 φ 叠加。每实体每回合两次乘法。空间叠加与现有场感知半径 R 共用循环。

## 八、HP / SAN

```
SAN = SAN_base(entity_type) + equipment_SAN + component_SAN
HP  = HP_base(entity_type)  + equipment_HP  + component_HP
```

`SAN_base` / `HP_base` 从实体类型表查表。`equipment` / `component` 提供浮动修正。

**阈值保持绝对值**：SAN ≥ 60 稳定 / < 30 恐慌 / =0 随机。低上限角色更容易恐慌是 build 差异化的特性。
