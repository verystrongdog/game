## 试点边界声明

- **SchemaVersion 不进入 IActionProvider**：纯内存契约无数据版本敏感，加版本字段 = 凑字段反模式（外审 Q5/Q6 定案）。
- **不加 `[Module]` 标记**：标记无机器可验证语义（对比 #106 `[JsonRequired]` 有反序列化拦截语义），装饰性噪音。
- **active ≠ 全面实施**：`插件化`术语 active 仅表示「项目内术语定义已确定」；当前被验证的实施事实只有本试点。
- **不含**：运行时热插拔 / HMR 生产装配 / 运行时三态降级 / loader 版本协商 / Symbol isolate 作故障隔离。
