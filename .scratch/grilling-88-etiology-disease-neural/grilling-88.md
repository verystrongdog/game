## 话题

从 #87（NPC 人生自主起草功能）拆出的独立议题。用户（2026-08-19）决定：**病因-疾病-神经系统模型三者之间的关系**需单独详细讨论，不并入生成功能设计。

**现状核查结论（2026-08-19，引用即读取已执行）**：

- 疾病定义**从病理链路向上建**：「病 = 三体模型上的病理链路异常」——4 类病理链路（跨层短路/过度耦合/解耦沉默/结构异常，[角色与面具.md §8.8 [8.8.1]](../../实体/角色与面具.md)）+ 19 疾病 + 6 父类（[疾病目录/](../../实体/疾病目录/)）
- 疾病文件**无「发病前病因」字段**：以 PTSD 为例（[创伤后应激障碍.md](../../实体/疾病目录/创伤后应激障碍.md)），有创伤记忆的**机制后果**（闪回/情境匹配权重×2/记忆重播），但**创伤事件本身、创伤记忆如何形成、如何变成 link_312 的 +0.5 m 偏移——无字段**
- 病因设计**从生活事件向下建**（#87 讨论中）：病因 = 心智不成熟 × 重复挫折 → 创伤记忆（非病理化前体）
- **两者在「创伤记忆 → 病理链路 m 偏移」转化接口处相遇——该接口当前不存在**

## 已知待讨论问题（清单，grilling 逐题展开）

4. **文献约束冲突**：病理链路铁律「必须有文献依据 + 只能从已定义疾病推导」（[角色与面具.md §8.8 [8.8.2]](../../实体/角色与面具.md)）——病因转化是否受此约束、如何处置

### Q0 系列决策记录（2026-08-20，重映射前定）

- **Q0 前提核查**：4 类病理链路（跨层短路/过度耦合/解耦沉默/结构异常）诞生于旧 364 链路时代（决策树 :128-140，破旧四规则，原例含 L6）；三体模型（#26）后 §8.8.1 文字改为"三体模型连接"但疾病文件数据（link_312 等）仍挂已废弃 link_registry.json；tripartite_model.json 无 link ID、无病理边表达；validate_disease.py 校验器仍查 link_registry.json（废弃注册表）。**结论：疾病→脑区映射处于"文字半迁移、数据悬空"状态，需以 DK 解剖数据为准重映射。**
- **Q0 重映射决定**：重设计 19+ 疾病的脑部映射，以 DK 解剖数据为准 + 文献驱动。映射锚点待 Q0.1 裁定（A DK82 / B 50实体 / C 双轨，推荐 C）。
- **Q0.3 分类学锚定**：确认体系收敛——称呼层 DSM-5 命名 + 表现层 PANSS 五因子（修正 敌人与事件.md §2.2 误标"ICD-11 症状域"，真实来源为 PANSS 五因子，文献数据源 §五 Fountoulakis 2019）+ 机制层解剖域三体边。ICD-11 完全退出（决策树 :1041 佐证：5 症状域降级为表现维度、功能域为结算层）。
- **Q0.4 命名标准**：D 方案——DSM-5 诊断名为正式称呼（复刻 D25 三层 ID：疾病ID 唯一主键 → 解剖域标签 机制映射 → zh_name 显示），19+扩种全部入库 term_registry。黑箱原则（决策树 :51）约束：玩家只见装饰+效果描述，不见机制分类。
