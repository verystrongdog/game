# Integrated Information Theory: Φ as a Mathematical Measure of Consciousness

> Oizumi, Albantakis & Tononi, "From the Phenomenology to the Mechanisms of Consciousness: Integrated Information Theory 3.0" — PLOS Comp Bio 10(5): e1003588, 2014
> Kleiner & Tull, "The Mathematical Structure of Integrated Information Theory" — arXiv:2002.07655, Frontiers 2021

## Core Claim

Consciousness IS integrated information. A physical system is conscious if and only if it forms a **complex** — a set of elements with a local maximum of **integrated conceptual information Φ^Max**. The quantity of consciousness = Φ^Max; the quality = the shape of the **maximally irreducible conceptual structure (MICS)**.

## I. The Five Phenomenological Axioms → Physical Postulates

### Axioms (from phenomenology of experience)
1. **Existence**: Consciousness exists — "I experience therefore I am"
2. **Composition**: Each experience consists of multiple aspects in various combinations
3. **Information**: Each experience differs in its particular way from other possible experiences
4. **Integration**: Each experience is strongly irreducible to non-interdependent components
5. **Exclusion**: At any given time there is only ONE experience having its full content with definite borders

### Postulates (translated to physical mechanisms)
Corresponding postulates at mechanism level AND system level, with the **central identity**: MICS generated by a complex = its experience.

## II. Mechanism-Level Mathematics (φ — small phi)

### 2.1 Cause-Effect Repertoire
For mechanism M in state s, purview P:
- **Cause repertoire** 𝖼𝖺𝗎𝗌_s(M, P): probability distribution over possible past states of P constrained by M's current state
- **Effect repertoire** 𝖾𝖿𝖿_s(M, P): probability distribution over possible future states of P constrained by M's current state
- **Unconstrained repertoire** p_uc: uniform distribution (past) or distribution with unconstrained inputs (future)

### 2.2 Information
```
ci = D(p_c ∥ p_uc)        (cause information)
ei = D(p_e ∥ p_uc)        (effect information)
cei = min(ci, ei)         (cause-effect information — the "intrinsic information bottleneck")
```

D = Earth Mover's Distance (Wasserstein metric), chosen because "it should make a difference if two system elements, rather than just one, differ in their state."

### 2.3 Integration (MIP = Minimum Information Partition)
```
φ_past   = D(p_c(whole) ∥ p_c(MIP))
φ_future = D(p_e(whole) ∥ p_e(MIP))
φ = min(φ_past, φ_future)
```

The MIP is found by evaluating all possible partitions of the mechanism. At the MIP, the connections between parts are "injected with independent noise."

### 2.4 Exclusion → Concept
```
φ^Max = max_{purview P} φ(P)
MICE = the cause-effect repertoire at the purview achieving φ^Max
```

A mechanism with φ^Max > 0 constitutes a **concept**. The φ^Max value specifies "how much" the concept exists intrinsically.

## III. System-Level Mathematics (Φ — big phi)

### 3.1 Conceptual Structure
The set of ALL concepts (one per mechanism in the power set) with their φ^Max values forms a **conceptual structure** C — a constellation of points in high-dimensional concept space (one axis per possible past/future state of the system).

### 3.2 Conceptual Information
```
CI(C) = D(C ∥ p_uc)   — distance from the null concept (φ = 0)
```

### 3.3 Integrated Conceptual Information
```
Φ(C) = D(C ∥ C_MIP)   — distance to the partitioned constellation
```

System-level partitions are **unidirectional cuts**: connections from subset M to S\M are noised; both directions (M→S\M and S\M→M) are evaluated; the minimum is taken. This enforces **strong (bidirectional) integration**: a unidirectionally connected subset is "merely an 'appendix'."

### 3.4 Exclusion → Complex → Experience
```
Φ^Max = local maximum of Φ over elements, space, and time
Complex = the set of elements achieving Φ^Max
MICS = the conceptual structure of the complex = the experience (quale)
```

**Key consequence**: Complexes cannot overlap. At each point in time, an element belongs to at most ONE complex.

## IV. Kleiner-Tull Generalized Axiomatization

### 4.1 System Class
A system class **Sys** provides:
- States St(S)
- Subsystems Sub_s(S) with induced states
- Decompositions D_S with trivial decomposition 1
- For each decomposition z: cut system S^z with cut state s^z

### 4.2 Experience Space (Abstraction of Qualia Space)
An **experience space** E = (E, ‖·‖, d, ·) where:
- ‖·‖: E → ℝ⁺ — **intensity function**
- d: E × E → ℝ⁺ — **distance function**
- ·: ℝ⁺ × E → E — **scalar multiplication** (‖r·e‖ = r·‖e‖, r·(s·e) = (rs)·e, 1·e = e)

**Classical IIT instantiation**: E = 𝒫(S) × ℝ⁺ where 𝒫(S) is the space of probability distributions, d is the Wasserstein metric.

### 4.3 Integration (Generalized)
For e ∈ E with decomposition over D:
```
φ(e) = min_{1≠z∈D} d(e, ē(z))     — integration level
ι(e) = φ(e)·ê                      — integration-scaled element (ê = e/‖e‖)
```

For pairs: φ(e₁, e₂) = min(φ(e₁), φ(e₂)), ι(e₁, e₂) = (φ·ê₁, φ·ê₂)

### 4.4 Core Operation (Exclusion, Generalized)
Given a collection indexed by subsystems, the **core** = subsystem with maximal φ; if no maximum exists → empty system.

### 4.5 The Full IIT Map
```
For each system S and state s:
  - Q-shape ℚ_s(S) = all concepts (one per mechanism)
  - Decompose over system decompositions: ℚ̄_{S,s}: D_S → E(S)
  - Experience E(S,s) = Core(ℚ̄_{S,s})  — the major complex's experience
  - Quantity: Φ(S,s) = ‖E(S,s)‖
  - Quality: Ê(S,s) = E(S,s)/Φ(S,s)
```

### 4.6 Quantum IIT (Special Case)
Elements are qubits (finite-dim Hilbert spaces ℋ_i). Evolution is a CPTP (or unital CP) map. Cut operations replace subsystems with maximally mixed states I/d. Proto-experiences use trace distance extended by scalar multiplication.

## V. Key Structural Results

1. **Panpsychism-lite**: Any system with Φ^Max > 0 is conscious — even simple two-element systems (φ^Max = 1)
2. **Zombie theorem**: Strictly feed-forward systems have Φ = 0 and are unconscious, even if functionally equivalent to a conscious system
3. **Self-referentiality**: Concepts are always about the complex itself, relating only indirectly to the external environment
4. **Composition without exclusion**: Within a complex, elementary AND higher-order mechanisms coexist as distinct concepts — no exclusion between them
5. **Inactivity doesn't preclude consciousness**: A complex can generate a MICS even if all its elements are inactive

## VI. Critical Properties (for our question)

### What IIT CAN mathematically define:
- **Integrated information** Φ — a scalar measure of consciousness quantity
- **Conceptual structure** — the shape/distances defining quality
- **Complex boundaries** — which elements participate in an experience
- **Causal selectivity** — the specific "differences that make a difference"

### What IIT CANNOT mathematically define (inherently):
- **Why Φ > 0 feels like anything** — this is axiomatic (Existence postulate), not derived
- **The specific qualitative character** — this is measured (by the MICS shape), not predicted — the distance metric d must be calibrated by phenomenology (e.g., CIEDE2000 for color space)

### The Hard Problem within IIT:
IIT posits an **identity** between Φ^Max and consciousness. This identity is not proven — it's the theory's central postulate. The mathematical structure describes the *structure* of consciousness if the identity holds, but does not derive the identity from more fundamental principles.
