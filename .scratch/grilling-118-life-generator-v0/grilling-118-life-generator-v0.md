**目标形式化**：`G: S₀ → P(τ)`，`τ = (S₀, E₁, S₁, …, E_T, S_T)`；需求 R1（非退化）：固定 `S₀` 下 `|supp P(τ|S₀)| ≥ 2`。

**已锁定（本会话 2026-09-06）**：

- **对象层 = 双通道轨迹律**：被动通道 `E_t ~ P_W(E | S_t, R_t, G_t)`（事件发生在人身上）⊕ 主动通道 `A_t ~ π(S_t, R_t, G_t; 驱力)`（人选择，世界回应）；状态依赖切换规则 v0 候选：`决策点 ⟺ 重大外部事件后 ∨ 驱力状态越阈值`（依据：真实人生两模式交错，选择集中在拐点——用户经历反例证伪 A/B 二元分叉）

## 决策记录

### Q1（2026-09-06）— V0 时间/抽象层级
**裁决**：A——t 取无量纲抽象事件步，S_t 不含年龄/阶段；阶段结构（幼年→老年、发育/衰老）显式声明为 V1/Phase-2 第一扩展（本 issue 不静默丢失）。理由：R1（非退化分化）与双通道/记忆反馈机制验证不依赖日历语义；阶段/发育参数在 Phase-2「可信」轨（需先定指标族 M 与基线 B）才需要；A 下机制不成立则 B/C 下也不成立（避免重配置混淆归因——#117 D4 随机源分离纪律同构）。

### Q2（2026-09-06）— 状态空间 S_t 轴集
**裁决**：A——5 轴离散版：外部 c_t = {经济 E, 社会关系 R}，内部 i_t = {健康 H, 驱力-生存 D₁, 驱力-社会 D₂}，各 3 离散档（低/中/高）。判据：①②被动/主动可改 ③路径依赖（经济/关系/健康选择后难回退）④映射量可控。声明扩展（不入 v0 轴）：外部风险/机遇轴（与事件发生器职责重叠，违反单一职责）、能力轴（v0 无消费者）。

### Q3（2026-09-06）— 事件 E_t 表示
**裁决**：A——`E_t = (type ∈ 原型枚举, s ∈ [0,1], ΔS ∈ {−1,0,+1}^5·s)`；v0 原型池 6 类 {经济冲击, 经济机遇, 关系冲突, 关系增益, 健康事件, 复合重大事件}，稀疏效应模式显式映射表（开放可扩）。三类职责齐挂：轴改变 / 重大性判定输入（原型类别 ∨ s 阈值）/ 记忆标签可读类别。

### Q4（2026-09-06）— 动作 A_t 表示
**裁决**：B——动作空间 = `A_t ∈ {∅} ∪ {E,R,H × 投入档 l ∈ {1,2}} ∪ {D₁ 消费, D₂ 消费}`；成功概率归世界通道（π 不带结果噪声）；副作用表制造权衡；短视消费 = 即时降驱力缺口、代价健康/关系/经济（酗酒/暴食/冲动消费/放纵类，具体代价映射入规格参数表）；∅ = 维持现状。

### Q5（2026-09-06）— 切换规则形式
**裁决**：B——双触发（重大事件 ∨ 驱力缺口 ≥ θ_D）后开启**连续决策窗口 k 步**（v0 默认 k = 3，入参数表可校准）；窗口内每步仍采样被动事件（世界不因人在抉择而暂停），A_t 可用（∅ 允许）；窗口满 k 步关闭（除非再次触发）。模式差异的唯一语义 = A_t 是否可用。
**结构性推论（未被打断即视为默认）**：窗口步 = 事件照常 + 动作可选，二者同一步内先后结算（先事件后动作，或先动作后事件——具体顺序入规格，默认先事件后动作）。

### Q6（2026-09-06）— 驱力动力学与 π v0
**裁决**：A——两段式静态策略：段 1 驱力贪心（指向缺口最大结果轴）+ ε 探索 `π(A) ∝ (1−ε)·exp(β·V_drive(A,S)) + ε/|A|`；段 2 记忆调制（决策点检索同情境结果标签 → 调整动作权重）。关键对比设计 = 无记忆组 vs 有记忆组，检验「分歧主要在决策点累积、记忆放大分歧」。否决可学习策略（RL）：需标量回报 rₜ = U（D3 外部依赖未定义）+ 长时程信用分配不可行 + 最优性杀死 R1 多样性——v0 目标 = 有限理性的合理性非最优性。驱力动力学：缺口随缺失源轴递增、由结果轴改善/消费动作/健康事件满足；越阈值 θ_D 触发决策窗。

### Q7（2026-09-06）— 记忆对象 schema
**裁决**：A——结果记录 schema：`r_j = (id, t, 类别 c ∈ 事件原型∪动作∪消费, s ∈ [0,1], ΔS ∈ {−1,0,+1}^5, 情境 S_before（5 轴检索键）, 结果标签 v ∈ {−1,0,+1}, 记忆强度 m ∈ (0,1])`；v 的 RPE 语义：决策动作 v = 实际 − 预期成功概率 p 的符号；被动事件 v 由 ΔS 净方向。否决叙事字段（无消费者）。

### Q8（2026-09-06）— 记忆操作规则包 v0
**裁决**：A——全包规则：δ（被动 s·‖ΔS‖ / 决策 |v|）≥ θ_sal 才入记忆；f_θ 确定性编码（编码随机 = 0）；sim（同类别 ∧ 情境轴距 ≤ θ_ctx）≥ θ_merge → merge 否则 create；ξ^R 随机位 = sim ∈ [θ_create, θ_merge) 以 p_merge 选 merge；m 每步衰减 (1−λ)，m < θ_forget 删除；ρ v0 = 时间邻近（步差 ≤ τ_near）∨（同类别 ∧ 同 v 方向）；决策点检索 = 情境轴距 ≤ θ_ctx 的加权 v 均值（权重 m_j）→ w_mem(A) = ζ·mean_v；检索噪声小量级。参数 {θ_sal, θ_ctx, θ_create, θ_merge, p_merge, λ, θ_forget, τ_near, ζ} 全入规格参数表。

### Q9（2026-09-06）— 随机源分配与初始条件
**裁决**：A——双维初始：θ_ind = (S₀ 五轴初值, ε_i, β_i) 从总体先验采样；R1 **强式**检验（固定 (S₀, θ_ind) 仍分化，分化来自 ξ^W/ξ^A/ξ^R + 状态依赖反馈）；消融组 ξ^W=0 / ξ^A=0 / ξ^R=0 / 全关确定性对照 → 分化来源归因表。

### Q10（2026-09-06）— 检验设计与门禁
**裁决**：A——条件矩阵 ≈6 条件 × N=200/条件；T 扫参 {200,1000,5000}；主度量 D̄ + ΔD_decision，辅度量事件序列相似度；门禁 G1 非退化 / G2 不坍缩 / G3 消融可归因（指标锁数值不锁）；科学检验 H1 记忆放大（报告效应量，不设 PASS/FAIL）。
