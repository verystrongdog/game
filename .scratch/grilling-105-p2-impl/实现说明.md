## 冻结设计未明示处的机械实现（解释，非越界）

1. **TNeg 用 double 而非 float**：`rdoc_profile.negative_valence` JSON 源为 double，若阈值 t_neg 用 float（0.2f = 0.200000003），边界值 0.2 的原型（social_confrontation/identity_crisis/cognitive_overload/sensory_deprivation 4 个）会被 float 比较精度排除，G 组实测 17 → 13。改为 double 后恢复 17 成员（与 #108 事实核查一致）。这是实现层精度选择，非设计变更。
2. **静息 trace 保持 s=0 纯静息**：`CombatState.Create(environment: null)` 显式跳过情境初始化——`--trace-resting` 的 M1 锚点区间 [0.535, 0.772]（csharp-tone AC-15 静息验证方法）不能被 s_env 注入污染；只有显式 environment 才初始化情境。Q14 默认 ward 不变（RunBattle/--demo-situation 走默认）。
3. **m_field 通道默认关闭**（Q12）：`_mfieldInjected = AllowPlaceholderDemo || CalibrationStatus == "CALIBRATED"`——默认 PLACEHOLDER 非 demo 时 m_field 不注入，`s_total = SPending + s_env` 正常运行；门禁 `CalibrationGate.EnsureCalibrated` 挂 MFieldComposer.Compute 注入点，非 demo 直接调用会 fail-fast（测试锁定）。
4. **λ(D) 表值修正**：D=14 → λ=0.9936（非 1.0——连续满月峰值在 D=14.75，D=15 为离散近满月），测试断言按解析值锁定。
5. **moonlight_landing W_active 校验走 fid→dk**：`LocusCoeruleusRight`（无边节点，∉ 48 端点）作为 supp⊆W_active 反例锚点；HippocampusCA1/CA3 同 dk `Hippocampus`、ACC 双 fid 同 dk `caudalanteriorcingulate` 的映射在加载期校验中实测通过（#108 事实核查复现）。
6. **`CombatState.Create` 加 `environment` 可选参数**（Q14 默认 ward）：现有 13 处测试调用零改动（可选参数默认值），`environment: null` 语义仅 RunResting 使用。
