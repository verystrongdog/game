## 一、目标修正——我们在追求什么

### 我们不是在追求

- 阻止环境退相干（方案 C 原始方向——有数量级硬伤）
- 让宏观物体处于位置叠加态
- 让椅子同时出现在两个房间

### 我们在追求

**物质因为人的主观意愿发生改变。**

物理翻译：环境仍然在退相干系统。退相干的结果——系统往哪个经典态坍缩——**可以被观察者的精神状态偏转。** 场的角色：使观察者的认知状态耦合进环境选择指针基的过程。

### 为什么不需要抵抗退相干

正常世界：环境标记 → 退相干 → pointer state 被锁定在位置基底 → 经典现实以确定的空间位置为基础 → "迫害者不存在"是唯一的客观事实。

月光场中：场提供了一个额外的耦合通道 → 系统-环境交互通道的有效形式被改变 → 指针基的选择不是唯一的 → 观察者认知状态耦合进选择过程 → "迫害者存在"成为病人版本的客观事实。

**退相干照常发生。叠加态照常死亡。但死在哪一边——月光场让它变得可偏转。**

## 二、理论入口——退相干不唯一确定指针基

### 2.1 标准图景（Zurek einselection）

```
系统 ──H_SM──→ 仪器 ──H_MB──→ 环境
                 ↑                  ↑
            P（仪器指针基）    Q（环境锁定指针基）
```

环境通过连续监控仪器 → 仪器的某些态（pointer states）存活、其余退相干 → Q 被唯一确定 → 系统被"强制"进入 Q 的本征态之一 → 经典现实涌现。

### 2.2 Kofman & Kurizki (2022) 的修正

**如果允许广义测量（POVM 而非仅投影测量），Q 不是唯一的。**

三类基底存在于测量过程中：

| 基底 | 符号 | 来源 | 是否唯一 |
|------|------|------|---------|
| 仪器指针基 | P | 系统-仪器相互作用 H_SM | 是（由物理耦合决定） |
| 环境锁定基 | Q | 仪器-环境退相干 H_MB | **否。存在多个替代 Q，只要提供相同的被测可观测量信息** |
| 观察者米尺基 | R | 观察者对仪器的读数方式 | 否。观察者可以任意选择——不受环境约束 |

**核心结论**：退相干确定了"哪些信息被保留"（被测可观测量），但**不唯一确定"信息以什么基底被编码"**（指针基）。观察者可以通过选择 R 来打开从系统提取信息的通道——这些通道不受环境约束。

### 2.3 月光场在公式中的位置

Kofman & Kurizki 的模型没有"场"——替代 Q 的存在性是 POVM 数学的必然，不需要外部场。但**哪个替代 Q 被实际使用**——论文没有指定——这在标准量子测量理论中留给"观察者的选择"。

**月光场的角色**：提供一个物理耦合机制，使观察者的宏观认知状态**自动地、非选择性地**耦合到系统-环境交互通道中 → 观察者不需要"选择" R——场替他们做了——不同认知状态的观察者自动被路由到不同的替代 Q。

```
正常世界：
  H_SM → P → H_MB → 唯一 Q → 所有观察者共享同一客观现实

月光场中：
  H_SM → P → H_MB + H_field(observer_cognitive_state) → 多个替代 Q
  → 不同认知状态的观察者 → H_field 贡献不同 → 被路由到不同的替代 Q
  → 不同观察者 → 不同的坍缩结果 → 不同版本的现实
```

## 三、月光场如何介入 einselection

### 3.1 物理机制（假设层——待量化）

场的存在修改了仪器-环境的有效相互作用：

```
H_MB^eff = H_MB + H_field−meter + H_field−observer
```

- **H_field−meter**：场与仪器的耦合。修改了仪器的有效自哈密顿量 → 改变了 P 的简并结构
- **H_field−observer**：场与观察者认知状态的耦合。将观察者的宏观态作为 H_MB 的一个参数引入

两者的联合效果：**H_MB^eff 的本征基（即 Q）不是唯一的——是一个依赖于观察者宏观态的简并流形。** 不同观察者对应流形上的不同点 = 不同的有效 Q。

### 3.2 "认知状态"的操作定义（假设层——待量化）

> ⚠️ 本节纯假设——需要后续 grilling 定义

在 Kofman & Kurizki 的框架中，R 是观察者任意选择的。在月光场模型中，R 不是"选择"出来的——它由观察者的宏观认知状态**自动确定**。

认知状态的物理载体候选：
- **(a)** 脑区链路的髓鞘化模式——50 解剖实体 × 三体模型连接（CSTC环路+皮层-皮层+脑干广播）的 m 值分布构成一个高维向量 → 场耦合到这个向量的特定投影
- **(b)** SAN 值——精神稳定度作为耦合强度的调制因子
- **(c)** 性格参数——4 tone baseline + 3 CSTC bias（7参数化性格）定义认知状态的"方向"

无论选哪个——关键是**认知状态在场中有物理表达**，不是抽象的"信念"——是一个可以被 H_field−observer 读取的物理量。

### 3.3 为什么随机标记不受影响

环境随机标记（空气分子碰撞、光子散射）在 H_field−observer 中**没有结构化的投影**——它们在场-观察者耦合通道上近似各向同性 → 场对它们的效应与正常世界无异 → 它们照常退相干。

**这就是"擦除"的物理基础——不是场"抹掉"了随机标记——是场对它们的指针基选择没有偏转效果。** 偏转只对有结构化投影的源（人类凝视/信念/期待）生效。

## 四、与 M1-M5 的映射

> M1-M5 已在 `决策树.md` 中决策。以下为新框架下的物理映射。

### M1: 场源 = 零号病人

零号病人的不同观察基线 = **第一个非平凡的 H_field−observer 耦合中心。** ta 从未接触外界 → ta 的认知状态对环境基线的偏离是全开放的（没有受过"环境唯一 Q"的训练）→ ta 的 H_field−observer 有最大的简并度 → 最多替代 Q。ta 的存在启动了第一个 H_field 的非零值——此后场有了非平凡的指针基流形。

### M2: 传染模型

耦合个体在场中暴露 → 他们的认知状态被 H_field−observer 耦合进场 → 每个新耦合者**扩展指针基流形**（不是"传播疾病"——是增加流形的维度和结构）。耦合者越多 → 流形越丰富 → 可选的替代 Q 越多 → 场的"可偏转性"越强。

### M3: 昼夜 = 场相变表观

白天（对称相）：清醒理性认知 → H_field−observer 的耦合被抑制（认知状态接近环境基线 → 各向同性 → 结构化投影弱）→ 替代 Q 之间的间隔小 → 偏转效果弱 → 几乎所有人共享同一现实。

夜晚（破缺相）：睡眠/非理性 → H_field−observer 耦合被释放 → 替代 Q 之间的间隔增大 → 偏转效果强 → 超自然现象。

**场相变 = H_field−observer 耦合强度的昼夜振荡**。生物节律驱动，而非天体。

### M4: 月相 = 集体生物节律拍频

~29.5 天周期 = H_field−observer 耦合强度的长期调制包络。不是月亮在变——是集体生物节律的周期共振在调制场的偏转能力。

### M5: 玩家 = 感染者

玩家已耦合进场 → 玩家的认知状态成为指针基流形的一部分 → 玩家看到的现实版本由 ta 自己的 H_field−observer 贡献决定。

**SAN 的角色**：SAN 高 → 认知状态接近环境基线 → H_field−observer 投影接近各向同性 → 流形上的位置接近"唯一 Q"（正常世界的指针基）→ 看到客观现实。SAN 低 → 认知状态特异化 → H_field−observer 投影远离各向同性 → 流形上的位置偏离 → 看到偏转后的现实（幻觉具象化、思维造物）。

## 六、暴露的待解决问题

1. **H_field−observer 的形式**：场如何耦合到观察者的认知状态？耦合的是什么物理量？（脑区链路 m 值分布？SAN？PAD 向量？）耦合哈密顿量的函数形式？

2. **指针基流形的维度**：替代 Q 有多少个？由什么决定？（耦合人数 N？场强？零号病人的初始简并度？）

3. **多观察者的一致性**：如果两个观察者的 H_field−observer 贡献导向不同的替代 Q，他们看到不同的现实版本。他们之间的交互规则是什么？
   - 各看各的（孤立的现实分支）→ 群体交互时需要"分歧解析"机制
   - 谁的耦合更强谁赢（竞争坍缩）→ 需要定义比较规则
   - 叠加（两人看到的东西可以重叠）→ 需要定义冲突解决

4. **坍缩强度的量化**：不同观察者的偏转效率如何度量？用什么参数表达？（与旧框架中的 g 是什么关系？）

5. **场相变的物理量**：H_field−observer 耦合强度昼夜振荡的驱动机制是什么？振幅和周期的定量关系？

6. **与 DFS 框架的遗产关系**：Kofman & Kurizki 的方向和 DFS 不是互斥的——DFS 可以存在于**每个替代 Q 定义的子空间内**。两者的分工和耦合方式待确定。
