### 2026-09-18 — 施耐庵的鼻子：一次真实受击 vs 拳打镇关西的「三通道」比喻（知乎答主「笑笑不可爱」）

**形态**：知乎答主的幽默自嘲帖（用户转述），切入点是**一个关于写作的观察**——**施耐庵把"挨打"写得那么真，大概率因为他本人被狠狠揍过**。答主拿自己的亲身经历做证据：

> 因睡眠不好去**精神科门诊取药**，**被同候诊区一名有暴力倾向的患者从背后一掌拍在太阳穴上**。挨打的一瞬：**世界碎成马赛克和光斑**（视觉）· **鼻子发酸、喉咙发苦**（味/嗅）· **脑子发麻** · **耳边锅碗瓢盆齐炸**（听觉）。意识模糊之际闪回**课本插图**画面，最后"怀着对施耐庵的敬佩"晕过去。
> 事后：诊断**轻微脑震荡**；打人者**因精神疾病无法追究刑责**，家属态度诚恳并赔偿。

**与原文的逐拳对照**（《水浒传》第三回「史大郎夜走华阴县 鲁提辖拳打镇关西」，通行本/人教版节选用字）：

| 第几拳 | 落在哪 | 原文比喻 | 感官通道 |
|:--:|---|---|---|
| 第一拳 | 鼻子（"鲜血迸流，鼻子歪在半边"） | 「却便似开了个**油酱铺**，咸的、酸的、辣的一发都滚出来」 | **味/嗅** |
| 第二拳 | 眼眶际眉梢（"眼棱缝裂，乌珠迸出"） | 「也似开了个**彩帛铺**，红的、黑的、绛的都绽将出来」 | **视觉** |
| 第三拳 | **太阳**（太阳穴）——与答主挨的**同一位置** | 「却似做了一个**全堂水陆的道场**，磬儿、钹儿、铙儿一齐响」 | **听觉** |

⇒ 三拳 = **味觉 → 视觉 → 听觉**三通道**依次击穿**，恰好逐项对上答主那一掌的体感序列。⚠️ 两处须留意：**① 用字**——"绛"（人教版节选）与"紫"（部分本子）版本不一，引用时须标版本；**② 称谓**——第三回他尚是**鲁提辖（鲁达）**，「鲁智深」是第四回出家后的法名，章回标题即作"鲁提辖拳打镇关西"。

**素材价值**：

1. ⭐ **这是一条"写作工艺"素材，不是人物素材**：**"一击三通道"给"受击"立了一个可执行的语言样板**。本作的攻击**一半以上是看不见的**（精神武器 / 言语压迫 / 凝视威压），而它当前的受击反馈只有**单型通用动画 + 数值**——**写不清"被打到"是什么感觉，就等于把最需要体感的时刻交给了数字**。⇒ 直接对接 [素材起草规范](../design/rules/skill-tree/素材起草规范.md) §三 **B5（五感细节 ×5，含 ≥2 创伤锚定感官）**：可把它从"气味/声音绑定创伤事件"升级为**"按通道排布受击序列"**（味→视→听）；对应缺口见 [动作系统分解 §T2/T3](../design/engineering/动作系统分解-2026-09-12.md)（**受击多态呈现形态未设计**）。
2. ⭐ **它是「威胁/暴力」事件类型的真实实例，而且同时踩在"器质"这条腿上。** [创伤记忆转化接口 §一](../design/rules/skill-tree/创伤记忆转化接口.md) 的健康判据原文是「**无创伤 + 无器质 + 非发育 → 健康**」——这一掌**既是威胁/暴力事件**（§3.2.1 候选集 C(e) = {PTSD 主, 惊恐, 特定恐惧, 偏执型 SZ 卫}）**又造成了器质性损伤**（脑震荡）。⇒ 正典目前**只把"器质"写在健康判据里，没有对应的处理通道**；本条即该空白的现实样本：**器质损伤（TBI）与创伤记忆是两条入口，还是同一条？** 现实里两者还高度重叠（脑震荡后综合征与 PTSD 症状交叉）——⚠️ 属模型变更，**登记为待裁，不动正典**。
3. ⭐ **资格门的又一个活例，而且比前两个更锋利**（接本收件箱 2026-09-01 马小宝、堂兄两条）：[§3.2.2](../design/rules/skill-tree/创伤记忆转化接口.md) 的 PTSD 签名是 `∃ m: event_type ∈ {威胁/暴力, 性创伤} ∧ F ≥ 0.80 ∧ N ≤ 0.40`，**并明写"F 低/N 高（记忆已叙事化）→ INELIGIBLE"**。答主这一掌的 A 与 I_max 都够（太阳穴、意识中断、闪回插图），**但把这件事讲成了一个段子 = N 高 = 记忆已叙事化** ⇒ 资格门应判**候选含 PTSD、签名不满足 → INELIGIBLE（健康）**。**"最重的一拳 + 最完整的叙事 + 不发病"**，这正是 #113「创伤负荷 ≠ 疾病资格」要的样本形态。
4. **场景层：精神科门诊候诊区 = 本作已有、却还没用起来的空间。** [空间与关卡设计](../design/space/空间与关卡设计.md) 的门诊楼有 **1F–3F（门诊/影像/急诊/心理门诊）**，而"**出门诊大门**"被写成**第一个"走出去"的挑战**。这条素材给这个空间一个真实的危险面——**患者打患者**（不是医护与患者的冲突）：开放式候诊区里，**有暴力倾向的人与只是来取安眠药的人坐在同一排椅子上**，而风险是**结构性、无人负责的**（打人者无刑责）。它与 [敌人与事件 §五](../design/entities/敌人与事件.md) 医护「压抑-反噬」并列，构成**"暴力在院内的两个方向"**。
5. **法规层的另一半（接 [现实合理性审计 §D R13](../design/spec/material/现实合理性审计.md)）**：R13 捡到的钩子是**《精神卫生法》自愿住院原则 ⇒ "你本来就能走"（权利在纸上成立、现实里失效）**；这条补上镜面的另一半——**不能辨认/控制自己行为时造成危害、经法定程序鉴定确认的，不负刑事责任，而是责令家属或监护人严加看管和医疗，必要时由政府强制医疗**（[全国人大：精神病人有刑法规定的犯罪行为是否负刑事责任？](http://www.npc.gov.cn/zgrdw/npc/////flsyywd/flwd/2002-04/17/content_292729.htm)；⚠️ 条文措辞引用前须核现行法原文）。⇒ **同一套制度，一头给你出口，一头把他护住**：可作 R13 的姊妹段（若采纳，主题从"被困"再加一层"**责任无法落地**"）。
6. **语调资产：一条不卖惨的患者第一人称声音。** 本作写精神病院极易滑向苦情；这条素材证明**"用自嘲讲一记真实的耳光"既不失真也不廉价**——可作患者侧叙事视图的**语调反例样本**（对照 [素材起草规范 §二](../design/rules/skill-tree/素材起草规范.md) 的"开场场景"写法）。

### 2026-09-18 — 杠杆、运气与归因错误：第一代企业家财富神话的解构

**形态**：用户提供的一则网文/答主观点（对**中国第一代企业家财富神话**的解构），核心立场——**这批人的暴富并非源于个人勤奋或天赋，而是「杠杆 × 运气」的叠加产物**：杠杆加速积累，运气决定谁能从这场豪赌里活下来；而**把运气误读为天命**的归因错误，最终把他们推向毁灭。

**原帖的展开层级**（用户转述，保留其结构）：

1. **高杠杆同时放大收益与风险**——能活下来的不过是"千军万马中的幸运儿"；
2. **案例**：许家印被定性为"把杠杆拉到最高的职业赌徒"；万达名言「**清华北大不如胆子大**」被视为对杠杆的盲目崇拜；
3. **成瘾的心理机制**——以小博大的快感让人无法戒断，失败时还试图"**用杠杆解决杠杆**"，加速崩溃；
4. **悲剧根源不是物质破产，而是精神信仰坍塌**——当他们发现自己并非"天选之人"、唯一技能失效、东山再起的幻想破灭，绝望才真正降临。

**核心金句（原话保留）**：

> "**把幸存者偏差解读为上天的偏爱，这便是他们最后走向悲剧的根本原因，即归因错误。**"

**概念锚点**：
- **杠杆**（金融语境）：借入资金放大投资规模，收益与亏损同比例放大；10 倍杠杆下 **10% 的跌幅即本金归零**。
- **幸存者偏差（Survivorship Bias）**：只看到"活下来"的样本、忽略大量被淘汰者，从而得出偏差性结论（经典原型：二战飞机装甲 —— 该加固的是**没飞回来的那些飞机的中弹部位**）。
- **归因错误**：与心理学的**自利性偏差（Self-serving bias）**高度吻合——成功归自己，失败归外部；相邻概念还有**基本归因错误（FAE）**、**控制错觉（illusion of control, Langer 1975）**、赌徒谬误与沉没成本。

**素材价值（为什么对本项目重要）**：

1. ⭐ **这个世界会奖励归因错误——这是本作最锋利的一处同构。** `世界观与叙事` §心想事成：信念在月光下会**被具象化**；§拜月教：**"拜月教不是迷信——它是自我实现的预言"**。⇒ ⇒ ⇒ 在临水，**"把运气当本事"的人真的会得到回应**。所以归因错误在这里**不是认知缺陷，而是一种有效但致命的操作**：越信，越灵；越灵，越信；最后被自己的信念吞掉。
2. ⭐ **它就是 Boss 生命史的心理机制模板。** `游戏循环` §8.3 逐字：「Boss 战是**见证一种月光思潮的生命史**：它如何从一个人的信念开始，膨胀成有自我意识的存在，在月光下变得强大，**最终被自己的信念吞噬走向疯狂**」。⇒ "信念 → 放大 → 成瘾 → 崩塌"这条曲线的现实版，正好是杠杆叙事；Boss A（院长，"建院目的就是研究"的信念扩张）与投机者阵营可直接套用。
3. **已有三份素材正是"第一代创业者失败样本"，这条灵感可以给它们加一层骨架**：
   - **顾维扬**（`drafts/顾维扬-叙事视图.md`，MDD）——外贸创业 → 负债 → 跑出租；**他的"账本"就是杠杆的具象物**（每一笔都画着圈、"账就是账，要还"）。可加一层：他当年那笔生意**赢在哪里、输在哪里**，他自己怎么归因。
   - **高远**（`drafts/高远-叙事视图.md`，BD-I）——连续创业、轻躁狂期扩张、停药复发。**躁狂 = 生理版的"以小博大快感"**，与杠杆成瘾的心理机制同构。
   - **孙嘉禾**（`drafts/孙嘉禾-叙事视图.md`，BD-II）——广告总监 → 创业失败；她的"高光→跌落"弧线缺的正是**归因那一层**。
   - ⇒ 三人恰好组成**"杠杆成瘾的三种下场"**：破产跑车（顾）· 反复加注（高）· 高光后崩盘（孙）。
4. **与"确定的痛苦 vs 不确定的希望"（本收件箱既有条目）接续**：杠杆的本质是**把不确定的希望放大成确定的债务**——这条给那个条目补了一个**金融解释**：为什么人不肯止损（确定的痛苦已兑现，而"再赌一次"是不确定的好）。
5. **可玩表达候选（未定）**：玩家的**自问层**（`任务目标系统` §2.3）可否记录"归因倾向"？冲突的胜利条件可否做成**让对方信念崩塌**而非削血（与 `世界观与叙事` §战斗逻辑"相信被打败就可以赢"同向）？

**⚠️ 一条自我审查提示（我提出来，不是辩解）**：

> 这条灵感的核心是**"别把运气当本事"**。而本项目在 2026-09-18 刚把 NPC **"为什么有人病、有人不病"** 的部分原因交给**"自身的选择"**（[疾病特长 §1.2](../design/entities/%E7%96%BE%E7%97%85%E7%89%B9%E9%95%BF.md)、[NPC人生生成器 §4.2](../design/events/NPC%E4%BA%BA%E7%94%9F%E7%94%9F%E6%88%90%E5%99%A8%E8%AE%BE%E8%AE%A1.md) 微观层两步化）。
>
> **两者并不矛盾，但边界必须守住**：`疾病特长` §1.2 的原文是"**你无法选择出现什么，只能选择怎么面对**"——**处境（外部，含运气/时代/β 易感性）与反应（内部，可归因给个人）被显式分开**。若将来把"选择"扩写成"你病成这样是你选的"，那就是**同一个归因错误换了个方向**（把结构性处境的产物算到个体头上），本作的主题会当场塌掉。**⇒ 登记为一条写作红线候选。**

**待确定**：
- 是否把"幸存者偏差 / 归因错误"立为**主题关键词**（进 `世界观与叙事` 或 `疾病特长`），还是只作为 Boss/患者素材的写法骨架；
- 是否给三位创业者（顾/高/孙）加"归因层"（改稿成本小，收益是让"高光→跌落"不再只是命运）；

### 2026-09-18 — 双重束缚：话都让你说了（现实原型：高校科研考核）

**形态**：用户口述的真实处境，原话保留（不改写）：

> 「一堆基金项目卡年龄的是你，让我们坐冷板凳的也是你，资源向帽子疯狂倾斜的是你，让我们不浮躁的也是你，宣传顶刊的是你，论文写在祖国大地的也是你，很多项目没帽子就报不了的是你，破五唯的也是你，提倡奋斗的是你，防止内卷的还是你——话都让你说了，你嘴咋这么甜呢？……我不浮躁，我坐冷板凳，你替我过聘期考核？我不发文章不申项目不接横向不评职称不带学生，然后跟院长说我这是不浮躁、我在坐冷板凳、我在厚积薄发——你猜院长是会拍拍我的肩膀说你真牛逼我们学院就该多向你学习，还是直接飞起一脚让我滚蛋，后面一堆博士等着别占着坑不拉屎？」

**结构**（把骂声翻译成机制）：同一个权威主体**同时**发出两条互斥的合法指令，且**没有第三条路**——

- **指令 A**：不要浮躁、坐冷板凳、破五唯（反对可计量产出）
- **指令 B**：必须有可计量产出（年龄卡口、聘期考核、帽子决定申报资格）
- 违反 A 或违反 B 都要付代价；**而指出这两条互斥本身，也不构成一条出路**（"话都让你说了"）

**理论锚点**：Bateson 等 (1956) 的 **double bind（双重束缚）** 教科书形态——①两条互相矛盾的指令 ②受方无法逃离该关系 ③受方无法评论/指出矛盾。Bateson 最初用它解释精神分裂症的家庭沟通结构（后世对该归因有争议），但"矛盾指令 + 不可逃离 + 不可评论"这三件套在家庭与组织研究中一直有效。

**素材价值**：
- **它是"为什么同一处境下有人病有人不病"的一种具体处境类型**——不是"遭遇了一次大事件"，而是**长期被要求同时满足互斥条件**。可作为 [创伤记忆转化接口](../design/rules/skill-tree/创伤记忆转化接口.md) §3.2.1 事件池中「慢性冲突/高压」通道的一个子类：**`矛盾指令`**（与一般高压的区别 = **任何选择都违规**）。
- **与「反应/选择」层直接咬合**（[NPC人生生成器 §4.2](../design/events/NPC人生生成器设计.md) 两步化 + `反应史` 字段）：双重束缚把"选择"逼成一个**必输的选择**——这是既有条目「确定的痛苦 vs 不确定的希望」的现实版（已知的坏 vs 未知的好），但更狠一层：**两个选项都是确定的坏**。
- **院内已有三处同构实例，可直接复用为人物线**：
  1. **医护**：[敌人与事件 §5.2](../design/entities/敌人与事件.md) 的压抑-反噬 = 制度要求"不许有情绪" × 职业要求"必须共情" —— 医护的**压抑计数本质是双重束缚的计数器**；
  2. **郑晓敏**（[drafts/郑晓敏-叙事视图](../design/spec/material/drafts/郑晓敏-叙事视图.md) v1.1）：护理记录写"拒药"还是写"扛得住"——她每天都在"规矩"与"人情"之间被判一次违规；
  3. **拜月教**（[世界观与叙事 §拜月教](../design/events/世界观与叙事.md)）：权力逻辑原文「不信的人 = 在削弱神 → 有义务纠正（或消灭）不信者」——**神学版本的双重束缚**。
- **角色素材落点**：一个"两条路都走不通的人"。**中层管理者最容易承载**——他们既是发指令的一方，也是被指令的一方（双重束缚的**双向性**）。对应 [NPC生态台账](../design/spec/material/NPC生态台账.md) 的 C 组（科研/实验岗：温雪梅、姚承志）与 B 组管理层（何秀云）。

**待确定**：
- 是否把 **`矛盾指令`** 立为**独立事件类型**（进十类池），或只作「慢性冲突/高压」的一个标记位；
- 是否用作 **L2 患者世界的关卡结构**——场景内两个角色同时给出互斥要求，玩家的任何回应都被判错，**出路在于拒绝进入对方设定的二选一**（可否作为"认知压制"胜利路径的一种）；
- ⚠️ **它会给「选择 = 第二道门」的待裁项出一个最锋利的测试用例**：**当所有选项都违规时，"选择"还成立吗？** 这个问题可能需要 owner 直接裁定（[疾病特长 §六 待办 1](../design/entities/疾病特长.md)）。

- 关联：创伤记忆转化接口 §3.2.1（十类事件池）、敌人与事件 §5.2（压抑-反噬）、世界观与叙事 §拜月教、NPC人生生成器 §4.2（反应史）、本收件箱「确定的痛苦 vs 不确定的希望」条目
- 来源：用户口述（2026-09-18）；现实指涉 = 高校科研考核制度
- 理论文献：Bateson, G., Jackson, D. D., Haley, J., & Weakland, J. (1956). *Toward a theory of schizophrenia*. Behavioral Science, 1(4).

## 🆕 确定的痛苦 vs 不确定的希望

> "人宁愿要确定的痛苦，也不要不确定的希望。"

### 心理学锚点

这是一个经过大量实证检验的现象：

- **Ambiguity Aversion (Ellsberg 1961)**：人在已知概率的坏结果和未知概率的好结果之间，系统性地偏好前者。即使期望值相同。
- **Temporal Discounting + Uncertainty**：未来奖励不仅要被折扣（delay discounting），还要被不确定性再次折扣。两次折扣叠加后，眼前的确定痛苦比未来的不确定希望"便宜"得多。
- **Learned Helplessness (Seligman 1972)**：反复失败后，"尝试"本身变成了不确定的痛苦——不做尝试反而成了确定的解脱。
- **Depressive Realism (Alloy & Abramson 1979)**：抑郁者在评估自身控制力时比正常人更准确。正常人的"乐观偏见"是一种保护性的认知扭曲——抑郁者失去了这层滤镜。

### 与游戏系统的接口

这条洞察可以穿透多个子系统：

**1. EVC 公式的"不确定性罚金"**

当前 EVC = benefit − C_control − effort_discount + ε。但 benefit 在 helplessness > 0.5 时显示为 ???。可以加一个"确定性偏好"参数：

```
如果 benefit 不可见（???状态）:
  有效 benefit = 已知 benefit × (1 − uncertainty_penalty)
  
uncertainty_penalty 随 helplessness 增长:
  helplessness = 0.0 → penalty = 0.1（轻微厌恶模糊性）
  helplessness = 1.0 → penalty = 0.5（极度厌恶不确定性）
  helplessness = 2.0 → penalty = 0.8（几乎把希望折到零）
```

这样，"确定的痛苦"（C_control 可见、已知代价）会比"不确定的希望"（benefit 显示为 ???）在 EVC 中更有竞争力——准确地模拟了玩家的感性偏好。

**2. 心境漂移的方向性不对称**

```
确定痛苦 → 心境快速下行（η_mood × 1.5？）
不确定希望 → 心境缓慢上行（η_mood × 0.5？）

不对称比率 3:1 —— 一次确定的失败需要三次不确定的成功来抵消。
```

这与临床观察一致：负面事件对心境的影响强度约为正面事件的 3 倍（Baumeister et al., 2001, "Bad is stronger than good"）。

**3. 照护驱动的悖论**

照护驱动（读他人 PAD）在此框架下产生一个有趣矛盾：你共情到对方正在"确定痛苦"中 → 照护驱动激活 → 你想帮。但如果你自己也处于不确定希望中（benefit=???），你帮的代价是放弃自己仅有的"确定"——即使那是痛苦。

这就是"共情疲劳"的计算路径：照护驱动反复激活 + 自身 benefit 不可见 → EVC 倾向于不帮 → 玩家选择"袖手旁观" → 认知失调 → SAN 下降。

**4. 心境的"确定性偏倚"参数**

不同角色的心境设定点（PAD_set）可以隐含一个"确定性偏好"参数：

| 角色类型 | 确定性偏好 | 行为表现 |
|---------|-----------|---------|
| 焦虑症 | 极高 | "不确定的希望比确定的痛苦更可怕"——宁可回避一切不确定性 |
| 抑郁症 | 高 | "反正希望也是假的"——把不确定性全部折成零 |
| 正常人 | 中等 | 正常的不确定性厌恶 |
| 躁狂症 | 低 | "不确定才刺激"——拥抱不确定性，甚至低估风险 |
| PTSD | 极高（特定领域）| 对与创伤相关的希望极度不信任 |

这个参数可以直接作用在 EVC 的 `uncertainty_penalty` 上。

**5. 作为叙事工具**

"确定的痛苦"是治疗中心里很多角色不离开的原因——不是因为他们喜欢痛苦，而是因为痛苦是他们唯一确定的东西。月光下的希望是危险的——你相信了，它可能成真，也可能不。但痛苦是可靠的。

一个关键叙事节点：角色必须在"确定的痛苦"和"不确定的希望"之间做出选择。这个选择的时刻就是镜子房间的核心功能之一——你选择如何叙述你的处境，月光就会响应你的叙述。

## 2026-07-27: 忍无可忍 — 忍耐超限后的被动爆发

**核心机制**: 忍耐的本质不是免疫——是**延迟**。5-HT 系统不删除威胁，它把它们搁置。搁置的东西会积累。

**被动触发条件**: 忍耐·主动 在一场战斗中使用了 3 次 → "你已经忍了三次了。身体不再请示大脑。"

**效果:**
- 忍耐·被动 SAN 减免从 -1 变为 0（防线崩溃——5-HT 系统超载）
- PAG 防御方向反转: 逃离/冻结 → **反击**（dlPAG 驱动的不再是逃跑而是攻击）
- 本回合物理攻击 × 1.5, 命中强制 100%
- 激活点 +2 但只能分配给 L0 操作（"身体接管了决策"）
- 下回合: 忍耐进入 4 回合冷却 + 获得 2 层失望标记

**感知透明度**: 无 L2 内感受 → 看不到触发前兆（隐藏计数器）。解锁内感受 → HUD 显示忍耐压力条。

**图鉴关键词**: 反击、爆发、超限、被动触发

### 2026-08-09 — 大象（怪物）

**形态**：拥有粗壮的四肢、巨大的皮膜、长鼻子、长牙——但身体各部分**随意堆叠在一起**，无机体逻辑。四肢和躯体为**放大版裸露无皮的人类肢体**——你能看到肌肉纹理、血管、关节——但它们属于一只"大象"。

**可能的分类归属**：完整体造物或碎片造物（取决于是否有独立认知）。倾向于碎片造物——随意堆叠暗示其创造者的认知本身就是破碎的、拼凑的，无法维持一个有机整体。

**可能的机制方向**：
- 体型巨大 → 占据多个格子（大型单位）
- 人类肢体放大 → 关节反向弯曲？手指代替脚趾？→ 移动模式异常（跛行/爬行/不对称步态）
- 无皮 → 肌肉外露 → 对物理攻击脆弱但可能再生
- 长鼻 → 抓取/绞杀攻击（类似战棋中的"拉扯"机制）
- 皮膜 → 部分身体被膜覆盖 → 膜可能是防御部位（减伤）或弱点（撕裂后露出更脆弱的内部）

**临床锚点方向**：身体畸形知觉（body dysmorphic perception）——对肢体比例和排列的认知扭曲。或躯体失认症（autotopagnosia）——无法正确识别和定位身体部位，放大后表现为肢体被随意拼接。

**分类归属**：敌人设计 → 思维造物/碎片造物。关联：[敌人与事件](../design/entities/%E6%95%8C%E4%BA%BA%E4%B8%8E%E4%BA%8B%E4%BB%B6.md)、月光场模型 ⚠️ v2 已废弃 → 垃圾桶（`reference/deprecated/moonlight-field/月光场-标量场模型.md` §八）。
