# 照护驱动 — 以态度替代亲疏标量

> 纠正方向。S（Attachment_strength）作为标量丢失了关系的质性差异和内部矛盾。
> 角色对另一个角色的关系，本身就是一种态度——该由态度体系来承载。

---

## S 标量的问题（回顾）

1. 队友和陌生小孩可能算出相同的 S，但关系性质完全不同
2. 因子不独立——同一个人在同一段关系里被多次计分
3. 被背叛不是 "S 降低了"——是两种相反的力同时存在
4. 标量无法表达 ambivalence

---

## 替代方案：关系 = 态度

角色 A 对 NPC B 的关系，不是一个 S 值，是一个态度。

```
Attitude_A→B = {
  认知:  我对 B 的认知评估（我知道她是什么样的人）
  情绪:  我对 B 的情绪反应（我在她面前感受到什么）
  行为:  我对 B 的行为倾向（我想靠近还是远离、帮还是回避）
}
```

三个维度互相独立。可以同时存在 +1 认知和 −1 情绪。这就是关系中的矛盾——不需要被 "净值化"。

---

## 对行为系统的影响

当前 v2.1：驱动激活 → 行为卡可用。

照护驱动的特殊之处：它的触发源是**对另一个角色的态度**。

```
旧（S 标量）:
  g_care = f(Vulnerability_signal, S)
  S 是一个数 → 照护激活或不激活 → 照护行为卡全部同质化

新（态度替代）:
  g_care = f(Vulnerability_signal, Attitude_A→B)
  Attitude_A→B 是一个三维状态 → 照护行为卡有条件激活 → 激活的卡因态度内容而异
```

态度的三个维度各自影响照护行为卡的可用性：

```
认知维度 → 决定照护行为的方向:
  认知 +1 (我理解她): 解锁 "安抚" "理解她为什么这样做"
  认知 −1 (我看不清她): 锁定 "精准帮助" → 只能做粗略的照护行为

情绪维度 → 决定照护行为的情绪底色:
  情绪 +1 (我对她有正面感情): 照护卡带有爱/温暖的附加效果
  情绪 −1 (我对她有负面感情): 照护卡仍然可用但带有痛苦的附加效果
     (帮一个你怨恨的人——这是困境，不是不能帮)
  情绪矛盾 (同时存在 +1 和 −1 的情绪): 照护卡效果增强但 SAN 消耗增加
     (撕裂中仍然选择帮她——这是昂贵的善)

行为维度 → 决定照护行为的烈度:
  行为 +1 (我倾向于接近): 照护卡折扣
  行为 −1 (我倾向于回避): 照护卡加价——多付的成本就是 "克服回避" 的代价
  行为 0 (我还没决定): 照护卡标准价格
```

## 态度如何形成——关系结算

态度不是凭空给定的。每次战斗或关键事件后，进行关系结算：

```
事件: 陈姐在战斗中替智空挡住了敌人的一击

结算:
  认知:
    知识表征模块: "陈姐" 归入 "可以信赖的人" → +0.3
    记忆模块: 提取 "她曾经也这样做过" → 确认信号
    
  情绪:
    PAD 变化: P+ (感激的愉悦), D+ (有人在乎我 → 控制感上升)
    形成的情绪分量: 感激 +0.4, 信任 +0.3
    
  行为:
    对陈姐的行为倾向: 趋近 +0.3, 照护倾向 +0.2
```

关系结算不修改 S 因子——它直接更新 A 对 B 的态度向量。态度向量会累积，最终趋近于一个稳定值（就像你对一个人的看法会稳定下来，但不会完全固化）。

## 回到照护驱动

照护驱动的激活函数变成：

```
g_care = σ( 
  w_vuln · Vulnerability_signal                        ← 对方当前的状态
  + w_cog · Attitude_A→B.cognition                    ← 我怎么看对方
  + w_emo · |Attitude_A→B.emotion|                    ← 我有多在乎（方向不重要，强度重要）
  + w_act · max(0, Attitude_A→B.behavior)             ← 我是否倾向于靠近
  − θ_care
)
```

关键变化：情绪分量取绝对值 |emotion|。意思是对一个人有强烈感情——不管是爱还是恨还是复杂的混合——都在**增强**照护驱动的激活潜力。

- 强烈爱她 → g_care 高 → 照护卡亮、折扣 → 顺水推舟
- 强烈恨她 → g_care 也会激活（你在意） → 但情绪维度 −1 让照护卡带有痛苦标记，且行为维度如果是 −1 会让照护卡加价 → 昂贵的照护
- 对她没感觉 → |emotion| ≈ 0 → g_care 低 → 照护卡不亮

**你恨一个人不代表你不想帮她——代表你帮她的时候每一下都在痛。**

## 和态度体系的关系

这个问题最终会把态度体系拉回来。之前搁置态度晶体是因为 ±1/0 框架太粗糙。但 S 标量方案证明了一件事：**如果不让态度体系来承载人际关系，你就会被迫在行为系统里建造一个更糟糕的态度体系。**

态度体系需要被重新设计——不是作为 "27 种离散晶体"，而是作为 "认知 + 情绪 + 行为在一个连续空间中的状态点"。然后把 "角色 A 对 NPC B 的态度" 和 "角色 A 当前回合的整体态度（对世界/对当前情境）" 统一在这个框架下。

这不是现在要做的。但 S 标量的失败给出了明确信号：不要再在行为系统内部建造关系模型。把关系的复杂性还给态度。
