## ✅ 已解决

### 3. 行为抑制缺失

**解决：意志力属性。** 玩家消耗意志力 → 硬解锁灰色行为卡 / 主动压制 S1 驱动。
意志力 = 消耗性精神能量（类比星灵能量），SAN = 精神护盾（类比星灵护盾）。
两个池子不抢生态位。

### 4. 覆盖代价

**解决：覆盖消耗意志力。** S2 压制 S1 驱动、价值驱动逆反反射 → 花意志力。
意志力耗尽 → 无法覆盖 → 行为系统回到纯驱动约束。

### 6. 冲突度公式

**不存在于 v2.1。** 冲突度是 v2 揉球架构的遗留需求（系统揉球出净值，需要标签说明内部撕裂）。
v2.1 不揉球——玩家直接看到两张方向相反的行为卡同时亮着，不需要数字。

## 🔧 已定方向，待落地

### 5. 认知对情绪的调制方向

v2 的 `λ_raw = exp(-cog_progress)` 随 v2 架构废弃。情绪卡的新设计解决了核心问题：
- 手牌中的情绪卡 → 每回合轻度 PAD 压力（慢性底色）
- 打出情绪卡 → 强 PAD 爆发后消耗（急性体验后消退）
- PAD 衰减由卡消耗机制处理，不需要额外的认知→PAD 反向调制线

### 7. 参数无实证锚定

行为模型没有 NRC VAD 级别的实测数据。改善方向：
- 保序约束（反射快于惩罚快于奖励快于道德快于价值）
- DSM-5 端点锚定（正常人和患者的行为剖面差异反推参数）
- Godot `@export` 暴露为可调参数
- 不需要决策，需要开发中的测试和校准

### 8. 表达性行为缺失

不纳入驱动 / 行为卡系统。PAD → 表达包（面部/姿势/声音）自动生成，平行于行为卡池。
玩家可花意志力压制外在表达（面具脸）。Ekman FACS 作为映射参考。

## 🔴 仍在讨论中

### 1. 跨遭遇学习 — 参数漂移机制

**方案：三层混合模型。** [跨遭遇参数漂移-讨论.md](../behavior-system/%E8%B7%A8%E9%81%AD%E9%81%87%E5%8F%82%E6%95%B0%E6%BC%82%E7%A7%BB-%E8%AE%A8%E8%AE%BA.md)

- 第 1 层：后台自动漂移（玩家不可见）
- 第 2 层：镜子房间倾向感知（质化呈现）
- 第 3 层：主动干预（面具调整 / 治疗行为 / 卡牌策略）

**衍生：归因问题。** [归因问题-讨论.md](../behavior-system/%E5%BD%92%E5%9B%A0%E9%97%AE%E9%A2%98-%E8%AE%A8%E8%AE%BA.md)
归因即叙事选择。战斗层不解释 → NPC 归因提议（可能对可能错）→ 镜子房间选择如何叙述自己的变化 → 治疗会话引导准确归因。

待定：漂移量级、天花板/地板、角色差异、失败处理、多人关系漂移、月光效应对叙事选择的定量、错误归因的后果、归因选择是否可逆。

### 2. 共情→利他通路断裂

**方案：加第七种驱动——照护驱动 (Caregiving)。** [共情到利他通路-讨论.md](../behavior-system/%E5%85%B1%E6%83%85%E5%88%B0%E5%88%A9%E4%BB%96%E9%80%9A%E8%B7%AF-%E8%AE%A8%E8%AE%BA.md)
[照护驱动-亲疏计算.md](../behavior-system/%E7%85%A7%E6%8A%A4%E9%A9%B1%E5%8A%A8-%E4%BA%B2%E7%96%8F%E8%AE%A1%E7%AE%97.md)：S 拆为 6 因子叠加（先天纽带/并肩经历/脆弱性共鸣/互惠债务/相似性/负面纽带）

待定：S 的可见性、S 衰减速度、角色差异、反照护、正面情绪传递时是否激活。
已定：关系结算频率 = 每场战斗/特殊事件后批量结算。

### 3/4 遗留的 SAN/意志力待定项

- 意志力战斗中恢复源（认知卡？队友？照护爆发？）
- SAN 归零的叙事效果
- 低 SAN + 低意志力的保底机制
- 敌我同构——敌人是否有意志力？
- 意志力基础池大小、面具差异、透支机制
