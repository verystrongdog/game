## 一、设计目标

针对 v1 行为模型的核心缺陷：

| v1 问题 | v2 解决 |
|---------|---------|
| 6 种驱动是离散分类，输出 ±1/0 标量 | 每种驱动有连续激活函数，输出连续行为向量 |
| PAD 激活阈值硬编码、无实证依据 | 阈值换成**PAD 敏感度剖面**，从 PAD 分量连续计算 |
| "上层覆盖下层"机制模糊 | 换成**双系统并联 + 不确定性仲裁** |
| 无行为过渡模型 | 增加**行为惯性方程**，驱动激活有上升/衰减速率 |
| 无病情-行为系统互动 | 增加**病情扭曲矩阵**，每种精神病理对应特定的驱动畸变参数 |
| 与认知的接口未定义 | 明确定义**认知模块前置条件**——哪些驱动需要认知的哪些模块先完成 |

## 二、核心公式

```
行为向量 B(t) = Σ_i [a_i(t) · s_i]  /  Σ_i a_i(t)

其中:
  a_i(t) = α_i(t) · g_i(PAD) · c_i(C) · φ_i(认知前置, θ_i)

  B(t)    — 最终行为向量 (valence, intensity, autonomy)
  a_i(t)  — 驱动 i 在时刻 t 的有效激活强度
  s_i     — 驱动 i 的行为拉力方向 + 模态 (单位向量，见第三节)
  α_i(t)  — 驱动 i 的自身激活水平 (带惯性，见第五节)
  g_i()   — PAD 敏感度函数 (从当前PAD坐标计算驱动力)
  c_i()   — 文化上下文调制 (标量 0~1，文化线索的强弱)
  φ_i()   — 门控函数 (认知前置是否满足 + 阈限值)
```

**关键性质：**

1. **乘法门控**：任一项 → 0，该驱动对 B(t) 无贡献。不满足认知前置 → φ=0 → 驱动不表达。
2. **加权平均**：多个驱动并联激活，按强度加权求和，归一化后得到最终行为向量。不存在"覆盖"——强驱动压制弱驱动是自然结果。
3. **连续输出**：所有分量连续。不存在 ±1/0 离散化。

## 三、六种驱动的计算定义

每种驱动定义五个属性：
- **PAD 敏感度剖面** (g_i)：当前 PAD 坐标如何转化为该驱动的激活贡献
- **行为拉力** (s_i)：该驱动指向的方向
- **认知前置条件**：需要认知的哪些模块先完成评估
- **惯性与时程**：激活/衰减速率
- **可被压制条件**：什么时候会输给其他驱动

### 3.1 反射 (Reflex)

```
PAD 敏感度:
  g_reflex = σ( w_A·A' + w_D·|D'|  -  θ_reflex )
  其中:
    A' = max(0, A - 0.3)       — 唤醒度超出基线部分
    |D'| = max(0, 0.5 - D)     — 控制感低于阈值的"失控度"
    w_A = 2.0, w_D = 1.5       — 权重 (唤醒度比失控度更重要)
    θ_reflex = 0.5             — 基础阈限
    σ(x) = 1/(1+e^{-5x})       — sigmoid, 斜率5

认知前置: 无 —— 可以绕过认知评估直接触发 (S1通道)
行为拉力 s:  s_valence = -0.8, s_intensity = 0.9, s_autonomy = -0.8
  (强回避 + 高烈度 + 被动性 — "身体替你做决定")

惯性与时程:
  上升半衰期: 0 回合 (瞬间激活——PAD条件满足即触发)
  衰减半衰期: 1 回合 (威胁消失后快速消退，但见第五节惯性)

病情畸变:
  PTSD: θ_reflex ↓ (降低阈限), 衰减半衰期 ↑↑ (卡住)
  惊恐障碍: w_A ↑ (唤醒度权重放大)
```

---

### 3.2 惩罚机制 (Punishment Mechanism)

```
PAD 敏感度:
  g_punish = σ( w_P·(-P') + w_A·A' - θ_punish )
  其中:
    P' = min(0, P)             — 只取负效价部分 (P<0时有贡献，P≥0时为0)
    A' = max(0, A - 0.2)       — 唤醒度超出低基线部分
    w_P = 2.5, w_A = 1.0       — 权重 (负效价是主驱动，唤醒度放大)
    θ_punish = 0.3             — 较低阈限 (轻微负面预期即可激活)

认知前置:
  至少需要: 知识表征与分类模块完成 (将当前情境归入"有威胁的"类别)
  完整激活还需要: 记忆模块 (提取过去的惩罚经验)

行为拉力 s:  s_valence = -0.7, s_intensity = 0.5, s_autonomy = 0.2
  (回避 + 中等烈度 + 轻度自主——"我自己选择避开")

惯性与时程:
  上升半衰期: 1 回合 (需要认知评估)
  衰减半衰期: 3 回合 (经验驱动的回避消退慢)
  特殊: 如果记忆模块提取到了强烈的惩罚经验，衰减半衰期进一步延长

病情畸变:
  抑郁症: w_P ↑ (负面信号放大), 衰减半衰期 ↑↑ (泛化到安全情境)
  焦虑症: θ_punish ↓ 甚至为负 (假阳性——中性信号也被当成威胁)
  OCD:    g_punish 与 g_moral 耦合 (惩罚预期 + 道德义务 → 强迫检查循环)
```

---

### 3.3 奖励机制 (Reward Mechanism)

```
PAD 敏感度:
  g_reward = σ( w_P·P' + w_A·A' - θ_reward )
  其中:
    P' = max(0, P)             — 只取正效价部分 (P>0时有贡献)
    A' = max(0, A - 0.2)       — 适度的唤醒增强追求
    w_P = 2.5, w_A = 0.8       — 权重 (正效价是主驱动)
    θ_reward = 0.35            — 需稍强正效价

认知前置:
  至少需要: 知识表征与分类 (识别奖励源) + 推理与决策 (前向模拟奖励获取的可能性)
  注意: 奖励机制的认知前置比惩罚机制重——"这事有好处"需要比"这事有危险"更多的推演

行为拉力 s:  s_valence = 0.7, s_intensity = 0.6, s_autonomy = 0.3
  (趋近 + 中等偏上烈度 + 轻度自主——"我想要")

惯性与时程:
  上升半衰期: 1~2 回合 (需要推演奖励获取路径)
  衰减半衰期: 2 回合
  特殊: 认知推理模块算出高概率成功 → 上升加速

病情畸变:
  抑郁症: g_reward 整体×0.2 (快感缺失——PAD条件满足但激活极弱)
  躁狂:   θ_reward ↓↓ (阈限极低), 认知前置被短路 (不分青红皂白追求)
  ADHD:   g_reward 上升快但衰减也快 (对即时奖励敏感，延迟奖励无效)
```

### 3.4 道德驱动 (Moral Drive)

```
PAD 敏感度:
  g_moral = σ( w_D·D' + w_A·(1 - A') - θ_moral )
  其中:
    D' = max(0, D - 0.1)       — 有控制感才能选择"做对的事"
    (1 - A') = 低唤醒度的贡献  — 道德判断在冷静状态下更清晰
    w_D = 2.0, w_A_inv = 1.0   — 权重
    θ_moral = 0.4

  注意: D很低 (失控) 时 g_moral 趋近于0——"我自己都保不住了怎么讲道德？"
        但有一个例外通道: 内疚情绪 (见下)

认知前置:
  需要完整 CPM 四步: 关联性→意涵→应对→规范性评估
  尤其是"规范性评估"——必须判断当前行为是否违反了内化标准
  需要模块: 知识表征 (归类情境) + 推理 (判断对错) + 记忆 (提取道德经验/榜样)

行为拉力 s:  s_valence = ±0.6 (取决于道德内容), s_intensity = 0.7, s_autonomy = 0.9
  (方向可变 + 高烈度 + 高自主——"这是我选的")

惯性与时程:
  上升半衰期: 2~3 回合 (慢——需要规范性推演)
  衰减半衰期: 极长 (道德标准不会说变就变)

特殊激活通道 — 内疚耦合:
  当前情绪的内疚分量 > 阈值 → θ_moral ↓↓, 上升半衰期 → 0.5 回合
  "我做错了"的情绪可以直接短路道德驱动的正常激活路径
  结果为: 道德驱动 + 内疚 = 将功补过行为

病情畸变:
  OCD:   θ_moral ↓↓ (极低阈限), 与 g_punish 耦合 → 强迫检查/清洗循环
  反社会人格: g_moral 整体×0.05 (几乎不激活)
  抑郁症: 内疚耦合过度活跃 (总是觉得自己做错了→道德驱动指向自我惩罚)
```

### 3.5 文化习俗 (Cultural Custom)

```
PAD 敏感度:
  g_culture = σ( w_D·(1 - |D|) + w_context·C_score - θ_culture )
  其中:
    (1 - |D|) = D 接近 0 时有最大贡献——不掌控也不失控，"顺着走"
                D 绝对值大时贡献降低——太自主或太被动都不走文化脚本
    C_score  = 当前情境的文化脚本匹配度 (由认知的知识表征模块提供)
    w_D = 1.5, w_context = 2.0, θ_culture = 0.3

认知前置:
  需要: 知识表征与分类 (识别"当前是什么场合"→匹配文化脚本)
       + 表象与语言 (提取对应的仪式模板/话术)

行为拉力 s:  s_valence = 0.1 (微偏正向——"照常"一般是趋近社会互动),
              s_intensity = 0.3 (低烈度——按部就班),
              s_autonomy = -0.4 (轻度被动——脚本来自外部，不是自己的选择)

惯性与时程:
  上升半衰期: 0.5 回合 (脚本是预存的，调用快)
  衰减半衰期: 随情境变化 (舞会结束→舞会脚本立即停用)

特殊性质 — 脚本缓存:
  文化习俗是 S1 通道的行为模板——一旦 g_culture 激活且认知前置满足，
  可以**跳过后续推理**直接输出行为。这使它速度快但容易被误用（在不恰当的场合用旧脚本）。

病情畸变:
  自闭谱系: C_score 计算不准 (情境识别困难)→ 脚本错配
  社交焦虑: g_culture 激活异常高 + 惩罚机制同时激活 → "我是不是做错了？"
  精神分裂: 脚本被内部生成的内容覆盖 (幻觉替代文化模板)
```

### 3.6 价值驱动 (Value Drive)

```
PAD 敏感度:
  g_value = σ( w_D·D' + w_over·Override_signal - θ_value )
  其中:
    D' = max(0, D - 0.4)       — 需要高控制感 (阈值高于道德驱动)
    Override_signal = 来自认知"意义建构"层的覆盖信号:
      当 推理模块 判定了"此事涉及核心价值" → signal = 1.0
      当 记忆模块 提取了"价值受威胁"的经验 → signal = 0.8
      当 表象与语言 构造了"不可不为之"的叙事 → signal = 0.7
    w_D = 1.5, w_over = 3.0    — 覆盖信号权重远大于 PAD 分量
    θ_value = 0.7              — 高阈限，确保不轻易触发

  特殊: 覆盖信号可以无视 PAD 条件。
  恐惧(P<0, D<0) + 覆盖信号 = 仍然可以激活价值驱动 —— "我害怕但我还是要做"

认知前置:
  需要全部 5 个认知模块:
    知觉与注意 — 完整的情境感知
    记忆 — 提取"我为什么在乎这个"
    知识表征 — 对价值对象的准确归类
    表象与语言 — 构造"为什么必须做"的叙事
    推理 — 在所有替代方案被否决后确认"只有这条路"

行为拉力 s:  s_valence = ±1.0 (方向完全由价值内容决定, 不受PAD约束),
              s_intensity = 1.0 (最大烈度——全身心投入),
              s_autonomy = 1.0 (完全自主——"这是我自己认定的")

惯性与时程:
  上升半衰期: 可变 —
    紧急威胁: 0 回合 (肾上腺危机——价值被攻击时的即时反应)
    深思熟虑: 3~5 回合 (殉道/长期坚守——"我已经想清楚了")
  衰减半衰期: 极长——可能持续整场战斗/整章

  g_value 一旦激活:
    可以抑制所有其他驱动的行为拉力 (压制惩罚机制、拒绝奖励、无视文化、超越道德)
    但压制不是屏蔽——被压制的驱动仍然产生 α_i，只是在加权平均时被稀释

病情畸变:
  抑郁症: 覆盖信号生成困难 (无法感受到"什么东西比我自己重要")
  躁狂:  θ_value ↓↓, 覆盖信号在认知前置未完成时就生成 → 宏大妄想→冲动行为
  偏执:   覆盖信号基于错误知觉 (把不相关的事判定为价值受威胁)
  虚无妄想: 无价值对象可以被识别 → g_value 永远为0
```

## 四、双系统仲裁

六种驱动分属两个通道，它们以不同速度、不同认知代价并行运算：

```
System 1 (模型自由 / 快速通道):
  反射, 惩罚机制, 文化习俗

  特点:
  - 运算快 (0~1回合)
  - 认知代价低 (不需要完整CPM)
  - 依赖缓存/习惯/预存模板
  - 难以被意识干预 ("我不是故意的")

System 2 (模型依赖 / 慢速通道):
  奖励机制, 道德驱动, 价值驱动

  特点:
  - 运算慢 (1~5回合)
  - 认知代价高 (需要完整或部分CPM)
  - 依赖前向模拟/规范推演/意义建构
  - 可被意识干预 ("我选择这样做")
```

### 仲裁规则

每回合的最终行为来自两套系统的**并行输出加权混合**：

```
B(t) = w₁ · B_S1(t) + w₂ · B_S2(t)

其中 B_S1 = 反射,惩罚,文化 三项按各自 a_i 加权平均
    B_S2 = 奖励,道德,价值 三项按各自 a_i 加权平均
    w₁ = S1_dominance, w₂ = S2_confidence
    归一化: w₁ + w₂ = 1
```

S1 主导性 (w₁) 由以下因素决定：

```
w₁ = σ( β_A·A + β_time·time_pressure + β_fatigue·cognitive_fatigue - β_D·D )
  其中:
    A = 当前 PAD 唤醒度 (高唤醒 → S1 接管)
    time_pressure = 回合时间压力 (越来越短的决策窗口)
    cognitive_fatigue = 连续使用 S2 驱动的累积疲劳
    D = 当前 PAD 控制感 (高控制感 → S2 更强)
```

这解释了为什么：
- 惊恐发作时（高 A + 低 D）→ 反射和惩罚机制主导 → 逃跑/僵住
- 冷静思考时（低 A + 高 D）→ 道德和价值主导 → 坚持/牺牲
- 决策疲劳时（累积 cognitive_fatigue 高）→ 文化习俗接管 → "就这样吧，照常做"

### S2 对 S1 的压制

当 w₂ > 0.5 (S2 占优) 且某个 S1 驱动的 a_i 超过抑制阈值时：

S2 可以**主动压制**S1 中的特定驱动：
- 价值驱动压制反射："我怕但我上"
- 道德驱动压制惩罚机制："即使被惩罚我也要做对的"
- 奖励机制压制文化习俗："这次不按规矩来，我要争取更多"

压制不是删除——被压制的驱动 a_i 仍然存在，只是在加权中被降权（乘抑制因子 0.1~0.3）。如果 S2 的压制力下降（cognitive_fatigue 上升 → w₂ 下降），被压制的 S1 驱动立即恢复。

## 五、行为惯性

驱动的激活水平不是阶跃变化的——有动量：

```
α_i(t) = α_i(t-1) + λ_i · (α_i_target(t) - α_i(t-1)) - μ_i · α_i(t-1)

其中:
  α_i_target(t) = g_i(PAD_t) · c_i(C_t) · φ_i(cog_t, θ_i)   —— 当前理想激活
  λ_i           = 1 - exp(-Δt / τ_rise_i)                   —— 上升速率
  μ_i           = 1 - exp(-Δt / τ_decay_i)                  —— 衰减速率
  Δt            = 回合间隔 (1回合 = 1单位)
```

τ 参数表：

| 驱动 | τ_rise (上升时程) | τ_decay (衰减时程) | 行为表现 |
|------|-------------------|---------------------|---------|
| 反射 | 0.1 回合 | 1 回合 | 来得快去得快（但PTSD时τ_decay ↑↑） |
| 惩罚机制 | 1 回合 | 3 回合 | 经验驱动的回避消退慢 |
| 奖励机制 | 1.5 回合 | 2 回合 | 追求消退稍快（奖励未出现→怀疑） |
| 道德驱动 | 2.5 回合 | 极长 | 道德标准稳定 |
| 文化习俗 | 0.5 回合 | 情境结束时即时消退 | 脚本绑定情境 |
| 价值驱动 | 可变 (0~5) | 极长 | 可能是瞬间（危机）或漫长（坚守） |

### 惯性产生的游戏效应

1. **创伤残留**：一次强烈的反射激活（PAD条件触发）→ α_reflex 瞬间升高 → 即使威胁消失，μ 缓慢衰减 → 角色在接下来几个回合仍然"一惊一乍"
2. **道德惯性**：一旦道德驱动被激活（τ_decay 极长），后续回合即使 PAD 条件不再满足，道德驱动仍然活跃
3. **冲动的代价**：反射/惩罚机制快速激活 → S1 在一两个回合内接管 → 玩家丧失精细控制
4. **"信念危机"的玩法**：价值驱动 τ_decay 极长——如果你对某个价值产生了怀疑（认知模块提供了矛盾的证据），它不会立即消失，而是缓慢衰减 → 角色在几个回合内陷入撕裂

## 六、行为输出规范

### 6.1 输出格式

```
行为输出包 {
  vector: {
    valence:   float ∈ [-1, 1],   // 趋近/回避
    intensity: float ∈ [0, 1],    // 行为烈度
    autonomy:  float ∈ [-1, 1],   // 被动(-1) / 主动(+1)
  },
  profile: {
    reflex:    float ∈ [0, 1],    // 反射激活度
    punish:    float ∈ [0, 1],    // 惩罚机制激活度
    reward:    float ∈ [0, 1],    // 奖励机制激活度
    moral:     float ∈ [0, 1],    // 道德驱动激活度
    culture:   float ∈ [0, 1],    // 文化习俗激活度
    value:     float ∈ [0, 1],    // 价值驱动激活度
  },
  dominant:    enum { Reflex, Punish, Reward, Moral, Culture, Value },
  system:      enum { S1, S2, Mixed },
  conflict:    float ∈ [0, 1],    // 驱动冲突度 (0=调和, 1=严重撕裂)
}
```

### 6.2 对下游的语义

- **态度形成** (将来重新设计时)：态度不再用 ±1/0 网格，而是 `(认知C⁵状态, 情绪PAD, 行为vector+profile)` 的联合状态。行为提供的不再是一个标量轴，而是一个包含方向、烈度和驱动构成的向量包。
- **战斗结算**：`vector.valence` 和 `vector.intensity` 决定行为对敌人态度的推力；`profile` 决定敌人（或玩家自身）可以识别出"你为什么会这样做"——为叙事和诊断提供素材。
- **卡牌效果判定**：一张"抑制惩罚机制"的卡可以直接对 `profile.punish` 施加抑制因子，不需要定义"行为 -1 → 0"这种丢失信息的映射。

## 八、与 PAD 和认知的接口

### 8.1 PAD → 行为 (前向)

> 详细因果链见 **[情绪到行为因果链.md](../behavior-system/%E6%83%85%E7%BB%AA%E5%88%B0%E8%A1%8C%E4%B8%BA%E5%9B%A0%E6%9E%9C%E9%93%BE.md)**。以下为接口层面的摘要。

情绪对行为的影响有三条通路，同时运作：

```
通路 A (直接推力): PAD → B_raw = {val=P, int=|A|, aut=D}
                   不经过驱动系统，速度快但粗糙

通路 B (驱动门控): PAD → 各驱动 g_i(PAD) → B_drive
                   经过驱动系统，速度慢但精细

间接通路:          PAD → 扭曲认知模块 → 改变驱动前置条件 → 改变行为
                   跨越 2~4 回合，影响持久
```

每回合的最终行为是通路 A 和通路 B 的认知进度加权混合：

```
B(t) = λ_raw · B_raw + λ_drive · B_drive
λ_raw = exp(-cog_progress)      认知越深入 → 原始推力退化
λ_drive = 1 - exp(-cog_progress) 认知越深入 → 驱动系统接管
```

关键推论：
- 刺激出现的瞬间（cog_progress=0）→ 行为 = 纯情绪推力 → "身体先动"
- 反射可以短路这条时间线 → A 极高+D 极低时，反射在 t=0 就产生巨大 α，且 B_raw 也指向回避 → 行为立即锁定
- 价值驱动的覆盖信号可以反转 B_raw 的方向 → "我害怕(P<0)但我选择面对(valence=+1)"

### 8.2 认知 → 行为 (前置条件)

```
认知模块完成状态 → φ_i 门控:

  知觉与注意:        完成 → 放松 φ 对所有驱动的基础约束
  记忆:             完成 → 释放惩罚/奖励/价值的经验信号
  知识表征与分类:    完成 → 解锁惩罚/奖励/文化/道德的 φ (情境识别)
  表象与语言:       完成 → 解锁文化脚本/价值叙事的 φ
  推理与决策:       完成 → 解锁奖励(前向模拟)和道德(规范性评估)的完整激活

  认知 C⁵ 空间中的 加工深度 α (双加工标量乘子):
    低 α (System 1 加工) → S1 驱动受益 (反射/惩罚/文化)
    高 α (System 2 加工) → S2 驱动受益 (奖励/道德/价值)
```

### 8.3 行为 → 情绪的反馈

```
行为执行后 → 更新 PAD:

  S2 行为成功执行 → D + δ (控制感上升)
  驱动被外部压制   → D - δ (控制感下降) + A + ε (挫败/唤醒上升)
  驱动冲突         → P - δ (不愉快)
  价值驱动激活     → P + δ 或 P - δ (取决于价值内容——殉道可能是痛苦的)
```

### 8.4 行为 → 认知的反馈

```
行为结果 → 更新认知:

  行为结果被记忆模块编码 → 影响后续回合的记忆提取
  行为后果被知识表征归类 → "我做了这件事"→更新自我图式
  语言模块命名行为 → "我刚才那是逃跑"/"我在坚守"→改变后续叙事的可用性
```

## 九、工作实例

### 9.1 正常状态下的日常决策

```
情境: 角色在走廊遇到一个陌生但看起来无害的人

PAD: p=0.1, a=-0.2, d=0.3  (微正、稍镇静、略有控制感)
认知: 知识表征完成(归为"陌生人"), 推理未完成

各驱动激活:
  反射:     A=-0.2, D=0.3 → g_reflex ≈ 0.05    (几乎不激活)
  惩罚机制: P=+0.1 → P'=0, g_punish → 0          (没有负面预期)
  奖励机制: P=+0.1, 但 φ(cog)未满足(推理未完成) → φ=0, a_reward=0
  道德驱动: D=0.3 → g_moral ≈ 0.2, 但 φ(cog)未满足(规范性评估未完成)
  文化习俗: D≈0 → |D|小, g_culture ≈ 0.6, φ 满足(知识表征完成→识别了"走廊遇人"脚本) ✓
  价值驱动: D=0.3 < 0.4 → g_value ≈ 0.05

行为输出:
  B ≈ 文化习俗主导
  vector: valence=+0.1, intensity=0.3, autonomy=-0.4
  结果: 点头/微笑/按社会常规互动 —— "照常打个招呼"
```

### 9.2 恐惧场景中的行为竞争

```
情境: 角色被一个具象化的幻觉实体追逐

PAD: p=-0.7, a=0.8, d=-0.6  (极恐惧、高唤醒、完全失控)
认知: 知觉与注意完成(锁定威胁), 知识表征完成(归为"致命危险"),
       推理未完成(没时间想)

各驱动激活:
  反射:     A=0.8, D=-0.6 → g_reflex ≈ 0.93    (强激活!身体先于意识)
  惩罚机制: P=-0.7 → g_punish ≈ 0.85             (强激活!远离威胁)
  奖励机制: P<0 → g_reward ≈ 0                    (没有正面预期)
  道德驱动: D=-0.6<0 → g_moral ≈ 0.05            (失控状态下几乎不激活)
  文化习俗: |D|=0.6大 → g_culture ≈ 0.1           (无暇顾及社交规范)
  价值驱动: D<0.4 → g_value ≈ 0.03               (除非有覆盖信号——这里没有)

双系统仲裁:
  A=0.8高 → w₁≈0.9 (S1 主导)
  D=-0.6低 → w₂≈0.1 (S2 几乎离线)

行为输出:
  B ≈ S1 驱动混合 (反射+惩罚)
  vector: valence=-0.75, intensity=0.9, autonomy=-0.7
  profile: reflex=0.93, punish=0.85, 其余接近0
  dominant: Reflex
  system: S1
  结果: 逃跑或僵住 —— 不受意识控制，身体比大脑快
```

### 9.3 价值驱动覆盖恐惧

```
情境: 同上追逐场景，但角色看到: 身后的门后面有另一个需要保护的人

认知: 知觉与注意捕捉到了"需要保护的人"→
       记忆提取了"这是我承诺要保护的人"→
       推理模块生成了覆盖信号: "如果我逃了，这个人会死"→
       signal = 1.0

PAD: 仍然 p=-0.7, a=0.8, d=-0.6  (恐惧未变)

但价值驱动:
  g_value = σ(1.5×0 + 3.0×1.0 - 0.7) ≈ σ(2.3) ≈ 0.99
  覆盖信号压倒了 PAD 条件约束

行为输出(价值驱动激活后):
  profile: reflex=0.93, punish=0.85, value=0.99
  S2_confidence = 0.99 (虽然 w₂ 从 PAD 角度很低，但价值驱动的确定性极高)
  加权后 B ≈ 价值驱动主导:
    vector: valence=+0.8 (转身面对威胁), intensity=1.0, autonomy=1.0
    conflict = 0.87 (高冲突——恐惧想让角色逃，价值让角色上)
  结果: "我害怕，但我转身面对它" —— 赴汤蹈火
```
