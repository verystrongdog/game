## 一、认知分类与 5 模块

- 认知不等于单纯的"观点"
- 认知更接近：
  - 获取信息
  - 理解信息
  - 处理信息
  - 形成判断
  - 调整判断
- 在游戏中，认知卡不直接代表结论，而是代表`形成看法的过程`

### 核心定义

- 认知卡：改变信息选择、事件理解、记忆调用、时间判断或行动组织方式的卡牌

### 基于教材目录整理出的认知主线

- 参考书目：
  - 《认知心理学：认知科学与你的生活（原书第5版）》
- 从目录结构看，这本书将认知核心主题大致组织为：
  - `知觉`
  - `注意`
  - `工作记忆`
  - `长时记忆`
  - `知识表征与概念分类`
  - `表象与空间认知`
  - `语言`
  - `问题解决`
  - `推理与决策`
- 如果直接把这些全部做成并列大类，战斗系统会过散
- 更适合游戏落地的做法是：保留教材提供的认知依据，再压缩成少量可操作模块

### 当前采用的认知卡骨架

- 认知卡暂时按 5 个功能模块来设计：
  - `知觉与注意`
  - `记忆`
  - `知识表征与分类`
  - `表象与语言`
  - `推理、问题解决与决策`
- 这 5 类既能覆盖教材中的主干认知过程，也能较稳定地映射到战斗机制

### 分类方案

- `知觉与注意`
  - 心理学来源：知觉、模式识别、选择性注意、分散注意
  - 核心问题：我看见了什么，忽略了什么，当前被什么牵引
  - 运作方式：知觉将感官输入组织为有意义的模式——不是被动接收而是主动建构。注意决定了哪些信号进入知觉加工、哪些被过滤。在月光下（观察者效应），**你注意什么，什么就更真实**。选择性注意可以保护 SAN 值（忽略不可解释的刺激），但也可能让你错过关键线索。注意偏差（总是注意威胁/总是忽略威胁）塑造了角色的认知风格。
  - 与态度体系的交互：知觉与注意的向量值取决于信息处理的偏向——+1 意味着准确捕捉了关键信息，0 意味着中性扫视，-1 意味着选择性忽略或过度聚焦。恐惧会窄化注意（管中窥豹），快乐会拓宽注意（见微知著），愤怒会将注意锁定在侵犯来源上。
  - 古典参照系：管中窥豹（狭窄注意）、视而不见（选择性忽略）、明察秋毫（知觉敏锐）、一叶障目（被单一信息占据注意）
  - 适合的机制：
    - 抽牌
    - 检索
    - 揭示隐藏信息
    - 锁定目标
    - 强制关注某个对象
    - 改变敌方意图的可见性

- `记忆`
  - 心理学来源：工作记忆、长时记忆、提取、遗忘、错误记忆
  - 核心问题：过去的什么内容正在影响现在，我此刻能提取什么
  - 运作方式：记忆不是录像回放——每次提取都是一次重建，每次重建都可能引入偏差。创伤记忆尤其特殊：它绕过正常的叙事编码（海马体），以碎片化感官片段储存在杏仁核中，导致闪回——不请自来、身临其境。虚假记忆与真实记忆在主观体验上无法区分，因为两者的神经编码过程相同。月光下问题更严重：被错误记忆反复强化的东西会获得现实性。
  - 与态度体系的交互：记忆的向量值取决于提取内容的质量——+1 是准确提取有用的经验（教训），0 是中性回忆，-1 是创伤闪回或虚假记忆。情绪状态影响记忆提取：悲伤使人更容易回忆起负面事件（情绪一致性效应），恐惧使威胁记忆更容易被激活。在态度组合中，记忆经常与内疚（对错误的反复回放）、悲痛（对丧失的反复体验）、愤怒（对旧日不公的反复咀嚼）搭配。
  - 古典参照系：刻舟求剑（固守旧标记）、惊弓之鸟（创伤扭曲当下感知）、温故知新（提取智慧）、念念不忘（记忆反复侵入）
  - 适合的机制：
    - 回收弃牌
    - 重复结算上一回合效果
    - 触发闪回
    - 遗忘指定卡牌
    - 保留上一回合的某种状态
    - 植入或扭曲某段记忆

- `知识表征与分类`
  - 心理学来源：知识表征、概念形成、分类、图式/脚本
  - 核心问题：我把眼前的人和事归到哪一类，我套用了什么图式
  - 运作方式：大脑通过将新信息归类到已有图式中来理解世界——这是一次判断："这个人是朋友还是敌人""这个情境是安全的还是危险的""这个行为是帮助还是干扰"。分类是自动的、不可遏制的——你必须在几毫秒内将对象归入一个类别，否则无法与之互动。问题在于：一旦归类完成，图式会过度解释后续信息——如果你把某人归为"威胁"，他的所有行为都会被你解读为威胁。改变已有的分类比形成新分类困难得多。
  - 与态度体系的交互：知识表征的向量值取决于分类的准确性——+1 是准确匹配了合适的图式，0 是照常归类不加判断，-1 是图式误用（将无害归为威胁、将威胁归为无害）。它是认知模块中**最容易被情绪污染的**——恐惧让人将中性刺激归为威胁，爱让人将危险信号忽略。在态度组合中，知识表征与评价情绪（厌恶、愤怒、内疚）高度互动：你把对方归为"恶人"之后，厌恶随之而来。
  - 古典参照系：指鹿为马（强行错误归类）、疑邻盗斧（预设类别歪曲证据）、非我族类（类别排斥）、三人成虎（社会共识扭曲分类）
  - 适合的机制：
    - 改变事件含义
    - 改变某张牌的判定
    - 把敌方行为识别为威胁/帮助/干扰
    - 为对象添加或改写标签
    - 把"同一个对象"临时视为另一类目标

- `表象与语言`
  - 心理学来源：视觉表象、空间认知、语言理解、语言产生
  - 核心问题：我脑中浮现了什么，我如何命名和描述当前情境
  - 运作方式：表象系统在脑中构建了"不在眼前的世界"——你想象中的声音、画面、触感。语言是表象的外化——你给事物命名的那一刻，就为它赋予了一个解释框架。同一件事，叫"挑战"还是叫"灾难"，产生的后续情绪和行为完全不同。在月光下，语言有创造现实的重量——你说出口的东西，如果足够坚信，就会在观察者效应下获得实体。这就是为什么陈姐教苟智空"给它起个名字，它就不一样了"——命名的力量在月光下被放大了。
  - 与态度体系的交互：表象与语言的向量值取决于它是否扭曲了现实——+1 是用恰当的语言准确描述情境，0 是按惯例描述不加扭曲，-1 是用虚假或扭曲的语言定义现实。它在态度组合中的独特角色是**作为认知与外部世界的中介**——你如何给事物命名，决定了其他人（以及你自己）如何对它做出反应。表象与语言可以创造不存在的东西（望梅止渴），也可以让存在的东西变得无法言说（噤若寒蝉）。
  - 古典参照系：望梅止渴（语言唤起生理反应）、指桑骂槐（语言表面与实质分离）、众口铄金（集体语言重塑现实感）、画饼充饥（虚假表象替代真实）
  - 适合的机制：
    - 触发幻象或再现
    - 让某物"像"另一物
    - 重新表述当前事件
    - 改变一句话或一个行为的语义框架
    - 通过命名来放大、缓和或转移态度

- `推理、问题解决与决策`
  - 心理学来源：思维、推理、问题解决、决策
  - 核心问题：我如何从现有信息得出结论，并决定下一步怎么做
  - 运作方式：推理将知觉输入、记忆素材和知识归类整合为因果链条——"因为A所以B，如果B则需要C"。人类推理有系统性偏差：确认偏误（只搜索支持已有结论的证据）、可用性启发（容易想起的事被高估概率）、动机性推理（倾向于推出让自己舒服的结论）。在月光下，错误的推理不仅是思维偏差——如果足够坚信，它会扭曲观察结果，形成自我实现的闭环。
  - 与态度体系的交互：推理的向量值取决于推演质量——+1 是准确推演出了有效的因果链和行动方案，0 是未深入思考，-1 是推导出了错误结论。推理是认知模块中**最耗费行动点的**——深度思考消耗资源，但产出也最丰富。在态度组合中，推理 + 价值驱动可以产生"为了更高目标而精准规划"的高效态度，而推理 -1（自欺式推理）+ 快乐 +1 则产生"自鸣得意"的自欺欺人。
  - 古典参照系：未雨绸缪（推演式准备）、纸上谈兵（脱离现实的空洞推理）、自相矛盾（逻辑内部崩塌）、运筹帷幄（精准推演指导行动）、守株待兔（错误归纳导致错误决策）
  - 适合的机制：
    - 预览敌方下一步
    - 延后某张牌的结算
    - 提前触发未来效果
    - 将当前状态延续到下一回合
    - 调整出牌顺序
    - 降低或提高行动点消耗
    - 连携奖励
    - 强制按顺序打出某类牌
    - 储存行动点或延迟行动

### 与旧分类思路的对应关系（已废弃的简单分类）

card.md 中曾使用更简单的 5 分类（知觉 / 注意力 / 记忆 / 语言 / 思考与推理），当前已展开为上述 5 模块骨架：
- 旧的`注意`，并入`知觉与注意`
- 旧的`记忆`，保留并扩展为更完整的记忆模块
- 旧的`理解`，主要拆分进`知识表征与分类`以及`表象与语言`
- 旧的`时间`，主要并入`推理、问题解决与决策`
- 旧的`组织`，主要并入`推理、问题解决与决策`

### 时间角度的进一步拆分

- `过去导向`
  - 关键词：回忆、闪回、遗憾、经验、创伤、复盘
  - 主要归属：`记忆`
  - 机制方向：从弃牌堆取牌、重复上回合效果、让旧情绪再次生效

- `现在导向`
  - 关键词：觉察、聚焦、判断、当下处理
  - 主要归属：`知觉与注意` / `知识表征与分类`
  - 机制方向：立即改变目标、立即改变当前事件解释

- `未来导向`
  - 关键词：预期、担忧、计划、预测、准备
  - 主要归属：`推理、问题解决与决策`
  - 机制方向：预览敌人意图、预存效果、延迟爆发、为下一回合保留资源

### 当前决定

- 不使用`风格`作为认知分类维度
- 不使用`灾难化`作为主分类
- 认知分类先按功能来分，而不是按正确与否、积极与否来分
- 时间是认知的重要维度，可以直接作为认知卡设计的一部分
- 认知心理学教材提供的是语义来源，不直接等于游戏中的并列卡牌大类
- 当前优先采用`5 模块骨架`来承载认知卡，再在每个模块下继续长出具体牌型

## 二、CPM 评估序列映射

Scherer 的 Component Process Model (CPM) 将认知评估分为四步、13 个子检查（Stimulus Evaluation Checks）。5 个认知模块各自承担其中不同的子检查。这一映射给出了认知模块之间**自然的激活顺序**，以及认知故障（认知 -1）的精确定位。

### 第一步：Relevance（跟我有关吗？）

| SEC | 问题 | 主模块 | 辅助 | 原因 |
|---|---|---|---|---|
| **Novelty** 新奇性 | 变了吗？突然吗？ | **知觉与注意** | 记忆 | 知觉捕捉变化（<100ms）；记忆核对是否见过 |
| **Intrinsic Pleasantness** 内在愉悦 | 它本身好还是坏？ | **知识表征** | 知觉与注意 | 归类的起点——酸甜苦辣的原始分类，不涉及推理 |
| **Goal Relevance** 目标相关 | 跟我当前目标有关吗？ | **知识表征** | 记忆 | 把刺激匹配到活跃目标层级；记忆提供当前目标是什么 |

> **这一步的角色**：知觉警觉 + 快速归类。还没到推理——只是"有东西变了、是好的/坏的、跟我有关/无关"。

### 第二步：Implications（对我意味着什么？）

| SEC | 问题 | 主模块 | 辅助 | 原因 |
|---|---|---|---|---|
| **Causal Attribution** 因果归因 | 谁导致的？故意的吗？ | **推理** | 知识表征 | 推理构建因果链；知识表征把原因归类（自己/他人/自然，有意/无意） |
| **Outcome Probability** 结果概率 | 接下来会发生什么？ | **推理** | 记忆 | 推演未来状态靠推理；记忆提供基线概率 |
| **Discrepancy from Expectation** 期望偏差 | 跟我想的一样吗？ | **记忆** | 推理 | 记忆存储期望模型；推理评估偏差幅度 |
| **Goal Conductiveness** 目标促进/阻碍 | 帮我还是碍我？ | **推理** | 知识表征 | 推演结果比对目标；知识表征判定"阻碍还是促进" |
| **Urgency** 紧急性 | 需要马上反应吗？ | **知觉与注意** | 推理 | 知觉监控变化速率；推理评估不反应的代价 |

> **这一步的角色**：推理全面接管。五个子检查中四个主靠推理——从"变了"到"对我意味着什么"的整个推演过程在这一步完成。

### 第三步：Coping（我能应对吗？）

| SEC | 问题 | 主模块 | 辅助 | 原因 |
|---|---|---|---|---|
| **Control** 控制 | 我能影响它吗？ | **推理** | — | 纯推演——"我如果做 X，局面会改变吗？" |
| **Power** 能力 | 我有足够资源吗？ | **推理** | 记忆 | 资源盘点靠推理；过去成败经验靠记忆提取 |
| **Adjustment** 适应 | 不能改变的话，我能接受吗？ | **表象与语言** | 推理 | 不是算能不能赢，是在心里彩排"接受之后的生活"。表象系统模拟画面，语言系统给它命名 |

> **这一步的角色**：推理算控制力和资源；但适应（Adjustment）的引擎是表象——脑中浮现"如果我失去这个，生活会变成什么样"。

### 第四步：Normative（这对吗？）

| SEC | 问题 | 主模块 | 辅助 | 原因 |
|---|---|---|---|---|
| **Internal Standards** 内在标准 | 跟我自己的价值观一致吗？ | **知识表征** | 表象与语言 | 行为匹配到内化的道德类别；表象给匹配结果一个内心画面 |
| **External Standards** 外部标准 | 跟社会规范一致吗？ | **知识表征** | 表象与语言 | 行为匹配到文化脚本；表象帮你看见"别人会怎么看我" |

> **这一步的角色**：知识表征匹配标准，表象与语言赋予意义。推理不是主角——价值观匹配不是算出来的，是分类结果。

### 5 模块在 CPM 四步中的角色分布

```
                     Relev.    Implic.   Coping    Norm.
知觉与注意             ████       █         ░         -
记忆                   ██        ███       ██        -
知识表征与分类          ████      ██        -        █████
表象与语言               -        -        ███       ███
推理                    ░       █████     ████       -
```

- **推理**在第二步五个子检查中覆盖四个——它是因果评估的引擎
- **知识表征**是唯一横跨全部四步的模块——从最原始的"好/坏"归类到最复杂的"对/错"标准匹配
- **表象与语言**不参与前两步，在第三步的 Adjustment 和第四步才激活——它处理的是"无法改变"之后的事
- **记忆**是贯穿性支撑——不主控任何一步，但每一步都用到

### 认知模块的激活顺序

CPM 的四步序列给出了 5 模块之间的**自然激活顺序**：

```
知觉与注意 → 知识表征 → 推理 → 表象与语言
   (Step1)     (Step1/4)  (Step2/3)  (Step3/4)
```

**设计含义**：
- 回合内认知卡的打出受此序列约束：不能跳过知觉直接推理（必须先看到，再判断，再推演，最后命名意义）
- 同一回合内越靠后的模块，行动点消耗越高（推理比知觉贵，表象比推理贵）
- 角色病情可以打断或扭曲这个序列（如抑郁症认知迟滞→推理和表象的激活延迟一回合）

### 认知故障（认知 -1）的精确定位

认知 -1 不再是笼统的"所有驱动通向错误"——可以按 CPM 四步精确定位故障点：

| 故障模块 | 故障表现 | 影响的 SEC |
|---|---|---|
| 知觉与注意 (-1) | 漏掉真实威胁，或看到不存在的威胁 | Novelty 误报/漏报 |
| 记忆 (-1) | 期望偏差被放大，基线概率引用错误 | Discrepancy, Outcome Probability 失真 |
| 知识表征 (-1) | 好/坏分类错误，目标匹配失败，标准误判 | Intrinsic Pleasantness, Goal Relevance, Internal/External Standards 全错 |
| 表象与语言 (-1) | 对未来模拟灰暗（抑郁）或虚假（妄想） | Adjustment 失败，Standards 匹配扭曲 |
| 推理 (-1) | 因果链算错，概率估错，控制感和能力感失真 | Attribution, Outcome, Conductiveness, Control, Power 全错 |

### 行为驱动的分步解锁

情绪在 CPM 里不是独立层——它是每一步评估的**副产品**。每个 SEC 到达"初步闭合"时触发对应的情绪信号分量。这意味着行为驱动按 CPM 步骤**逐步解锁**：

```
Step 1 闭合 → 情绪初步激活（效价 + 唤醒）→ 反射可用（如果威胁信号足够强）
Step 2 闭合 → 后果清晰 → 惩罚机制 / 奖励机制可用
Step 3 闭合 → 掌控感明确 → 道德驱动 / 文化习俗可用（知道"该怎么做"了）
Step 4 闭合 → 意义确认 → 价值驱动可用
```

**设计含义**：
- 行为驱动不是每回合全部可用——它们按认知加工的深度逐步解锁
- 没有认知卡就无法推进 CPM 步骤→高阶行为驱动被锁
- 角色病情可以跳过或加速某些步骤（如 PTSD 的创伤闪回→跳跃到 Step 2 的 Discrepancy，绕过正常的知觉→推理序列）

## 三、认知操作的量化：SDT + 双加工 + CHC

旧系统将认知模块的产出压成 +1/0/-1 一个值。但"推理得出的结论是错的"至少有五种不同路径——精度真的差、懒得深想、只看想看的、灾难化倾向、自我欺骗。压成同一个值等于砍掉了认知故障的诊断信息。

两个成熟的心理测量框架可以联合替代标量模型：

### 框架一：信号检测论 (SDT)

SDT 用两个独立维度评估任何认知操作：

| 维度 | 含义 | 独立于 |
|---|---|---|
| **d'** (灵敏度) | 从噪声中区分信号的能力——有多准 | criterion |
| **criterion** (判断偏向) | 判定阈值——多容易说"是" | d' |

两者**独立**。同一个人可以 d' 高但 criterion 极端保守（"看清了一切但不敢下判断"），也可以 d' 很低但 criterion 极端宽松（"什么都看不清却什么都信"）。旧系统把这两种状态都标为"认知 -1"，但心理机制完全不同。

### 框架二：双加工理论 (Dual Process Theory)

Kahneman (2011) 的 System 1 / System 2：

| 维度 | 含义 |
|---|---|
| **加工深度** | 走了快路径（自动、直觉、省力）还是慢路径（受控、分析、费力） |

加工深度独立于精度——直觉可能精准（高手的第一反应），深思可能错误（反刍思维、越想越歪）。

### 认知操作的三维空间

SDT + 双加工 = 三个独立维度：

```
维度 1: d'（精度）        → 有多准
维度 2: criterion（偏向）  → 多容易说"是"，偏向哪个方向
维度 3: 加工深度          → 走了 System 1 还是 System 2
```

### 5 模块 × 3 维度：认知故障的精确诊断

旧 `认知 -1` 在三维框架下拆为多条独立路径：

| 模块 | d' 低 | criterion 偏向 | 加工浅 |
|---|---|---|---|
| **知觉与注意** | 真的分不清信号和噪声 | 注意太宽（全看见·草木皆兵）/太窄（全忽略·视而不见） | 没仔细看，扫一眼就下判断 |
| **记忆** | 提取内容不准确 | 太宽松（虚假记忆·惊弓之鸟）/太严格（什么都想不起） | 没认真回忆，第一个冒出来的就信了 |
| **知识表征** | 归类错误（指鹿为马） | 太宽松（刻板印象）/太严格（无法泛化·疑邻盗斧） | 没仔细分类，凭第一印象贴标签 |
| **表象与语言** | 脑中画面模糊，命名不准 | 框架偏向积极/消极（望梅止渴 vs 杯弓蛇影） | 没仔细措辞，张口就来 |
| **推理** | 逻辑链真的算错了 | 确认偏向（只找支持自己的·纸上谈兵）/灾难化（所有可能都指向最坏） | 没仔细推，凭直觉下结论（守株待兔） |

**同一个"推理 -1"，三维框架下五条不同路径**：

| 路径 | d' | criterion | 深度 | 例子 |
|---|---|---|---|---|
| 真算错了 | 低 | 正常 | 深 | 认真推但能力有限 |
| 不想推 | 正常 | 正常 | 浅 | 懒得想，随便捡了个结论 |
| 只想看想看的 | 正常 | 高确认偏向 | 深 | 努力推，但只搜索支持性证据 |
| 灾难化 | 正常 | 严重悲观偏向 | 深 | 推演正常，但所有可能性指向最坏 |
| 自欺 | 低 | 高乐观偏向 | 浅 | 不想深想，选最舒服的结论 |

### 加工深度与行为驱动的桥梁

加工深度直接映射到行为驱动的控制维度（D）：

```
加工浅(系统1) → D 偏低 → 行为偏被动 → 反射 / 惩罚机制 / 奖励机制 区
加工深(系统2) → D 偏高 → 行为偏主动 → 道德驱动 / 价值驱动 区
```

这不需要额外贴标签——行为驱动的主动性从认知加工的深度中自然导出。

### 新认知向量格式

旧：
```
认知卡: 推理，认知 +1
```

新：
```
认知卡: 推理
  d' (精度):     +0.8  → 逻辑链准确
  criterion (偏向): −0.3  → 偏悲观但未灾难化
  加工深度:      深(System 2)  → 经过了审慎推演
```

### 与 CPM 的对接

CPM 的 13 个 SEC 子检查，每个都落在对应认知模块的三维坐标上。认知故障不再笼统地标"这一步评估出错"——可以精确到"是精度问题、偏向问题还是深度问题"：

| CPM 步骤 | 模块 | d' 控制 | criterion 控制 | 深度控制 |
|---|---|---|---|---|
| Novelty 检测 | 知觉与注意 | 是否真的检测到变化 | 多容易报告"有变化" | 扫一眼还是仔细观察 |
| Outcome Probability | 推理 | 概率估计的校准度 | 乐观/悲观偏向 | 直觉估计还是仔细推算 |
| Internal Standards | 知识表征 | 价值观匹配的准确性 | 对自己多严格 | 本能判断还是深层反思 |

### 第三维度来源：CHC 认知能力模型

SDT 和双加工给了认知操作的两个维度（精度、偏向、深度）。但"这个人擅长什么认知操作"——角色的认知底色——来自另一个独立框架。

Cattell-Horn-Carroll (CHC) 理论是 Carroll (1993) 对 **467 个独立数据集**做因子分析后提取的人类认知能力层级结构——和 PAD 一样是数据涌现的，不是理论构造的：

```
Stratum III:  g（一般智力）
                 │
Stratum II:   10 个广泛能力
   Gf 流体推理   Gc 晶体知识   Gsm 短时记忆
   Gv 视觉加工   Ga 听觉加工   Glr 长时提取
   Gs 加工速度   Gt 反应时     Grw 读写
   Gq 数量推理
                 │
Stratum I:    70+ 个狭窄能力
```

因子结构跨年龄、跨文化、跨测试电池稳定。UK Biobank (N=3,425) 独立验证。

**CHC 和 5 模块是正交关系**——CHC 测量的是"这个人擅长什么"（能力），5 模块描述的是"大脑在做哪类操作"（操作）。同一个操作可以调用多个能力，同一个能力支撑多个操作：

```
              知觉与注意  记忆  知识表征  表象与语言  推理
Gf 流体推理      ○        ○       ○         ○       ●
Gc 晶体知识      ○        ●       ●         ●       ○
Gsm 短时记忆     ○        ●       ○         ○       ○
Glr 长时提取     ○        ●       ○         ○       ○
Gv 视觉加工      ●        ○       ○         ●       ○
Gs 加工速度      ●        ○       ○         ○       ○
```

### 认知的三维框架（完整版）

| 维度 | 框架 | 来源 | 回答的问题 |
|---|---|---|---|
| **操作类型** | 5 模块 | 认知心理学 | 大脑在做什么 |
| **精度 + 偏向** | SDT (d', criterion) | 信号检测论 | 做得多准 |
| **加工深度** | 双加工理论 | Kahneman (2011) | 走了多深 |
| **能力水平** | CHC 3 因子 | 467 数据集因子分析 | 这个人擅长什么 |

前三个维度描述**当前这张认知卡**的属性。第四个维度描述**角色**的认知底色。

旧 `认知 +1/0/-1` 在三框架下的拆解：

```
认知 +1 = 精度高 + 能力匹配 + 深度够 + 偏向适中
认知 -1 = 五种不同原因中的至少一种：
  ① 精度真的低（d' 低）
  ② 偏向极端（criterion 过于保守或过于宽松）
  ③ 加工太浅（System 1 直接跳答案）
  ④ 能力不匹配（CHC 对应因子弱）
  ⑤ 以上组合
```

### 游戏中的使用

**认知卡**记录操作质量和加工深度：
```
认知卡: 推理
  d': +0.8
  criterion: −0.3（偏悲观）
  加工深度: System 2
```

**角色面板**记录能力底色：
```
角色: 苟智空（正常人）
  Gf 流体推理: +0.4
  Gc 晶体知识: +0.2
  Gsm 短时记忆: +0.1
  Glr 长时提取: −0.1
  Gv 视觉加工: +0.3
  Gs 加工速度: +0.0
```

认知卡的最终效果 = 卡面数值 × 角色对应 CHC 因子的能力修正。

## 四、统一数学结构：C⁵ 复平面模型

SDL 框架给出了认知操作的两个独立参数 d'（精度）和 criterion（偏向），它们在数学上天然正交——恰好对应复数的实部和虚部。

### 单个模块：复平面

```
z = x + iy

实部 x = d'（精度）
虚部 y = criterion（判断偏向）

|z| = √(d'² + criterion²)   → 这个认知操作的综合质量（模长）
arg(z) = atan2(criterion, d') → 偏向方向
  - 正虚部：偏向保守（多容易漏掉）
  - 负虚部：偏向宽松（多容易误报）
  - arg(z) = 0：无偏（criterion = 0）
```

SDT 中 d' 和 criterion 被推导为独立参数。复平面直接把它们写成正交分量——不是比喻，是形式化。SDT 的数学基础和复数的代数结构内在对齐。

### C⁵：5 个模块的直和空间

每个模块拥有自己的复平面。5 个模块 = 5 个复数 = **C⁵ 空间中的一个点**：

```
当前认知状态 = (z₁, z₂, z₃, z₄, z₅)

z₁ = 知觉与注意:  d'₁ + i·c₁
z₂ = 记忆:        d'₂ + i·c₂
z₃ = 知识表征:     d'₃ + i·c₃
z₄ = 表象与语言:   d'₄ + i·c₄
z₅ = 推理:        d'₅ + i·c₅
```

**10 个实参数**——四个框架的变量数从 60+ 收敛为一个数量级。

### CPM 四步：C⁵ 中的基底切换

CPM 的每一步激活不同的模块子集，每次激活是一次基底切换——注意力焦点在 C⁵ 空间中移动：

```
Step 1 (Relevance):
  主导基底 = (z₁, 0, z₃, 0, 0)     → 知觉与注意 + 知识表征
  z₁ 的模长决定 Novelty 检测精度
  z₃ 的辐角决定 Intrinsic Pleasantness 的偏向

Step 2 (Implications):
  主导基底 = (0, z₂, z₃, 0, z₅)    → 记忆 + 知识表征 + 推理
  z₅ 的模长决定因果推断和概率估计的质量
  z₂ 的辐角决定期望偏差的方向

Step 3 (Coping):
  主导基底 = (0, 0, 0, z₄, z₅)     → 表象 + 推理
  z₄ 的模长决定 Adjustment 的模拟质量
  z₅ 的实部决定 Control/Power 评估的精度

Step 4 (Normative):
  主导基底 = (0, 0, z₃, z₄, 0)     → 知识表征 + 表象
  z₃ 的辐角决定标准匹配的偏向
  z₄ 的虚部决定自我/社会形象的框架方向
```

基底切换不是模块之间"传值"——是**注意力在 C⁵ 中的旋转**。被激活的模块贡献完整的复数分量，未激活的模块退化到零。

**设计含义**：CPM 序列中模块 activation 的顺序是固定的，但每个模块被激活时产生的复数分量各不相同——这取决于卡牌质量、角色能力和当前情绪状态。

### 加工深度：标量增益

深度不是独立维度——它是作用在整个 z_k 上的标量乘子：

```
z'_k = α · z_k

α ∈ [0, 1]
α = 0    → 纯 System 1（直觉扫过，不加工）
α = 1    → 全 System 2（深度审慎加工）
```

α 的物理含义：

```
模长 |z'_k| = α · |z_k|  → 深度越浅，有效质量越低
辐角 arg(z'_k) = arg(z_k)  → 深度不改变偏向方向，只改变强度
```

α 与行为驱动的接口：

```
α < 0.3  → 反射 / 惩罚机制 / 奖励机制 区（被动行为）
α > 0.7  → 道德驱动 / 价值驱动 区（主动行为）
0.3 ≤ α ≤ 0.7  → 文化习俗区（半自动执行）
```

这解决了原框架中"System 1/2 被当成连续维度"的问题——它从来不是维度，是标量增益。

### CHC 能力：基底权重

角色能力不是独立于模块的变量——它修改每个 z_k 的有效值：

```
CHC 角色向量 = (w_Gf, w_Gc, w_Gsm, w_Glr, w_Gv, w_Gs)

z_推理_有效 = z_推理 × (1 + β·w_Gf)
z_记忆_有效 = z_记忆 × (1 + β·w_Gsm + β·w_Glr)
z_知觉_有效 = z_知觉 × (1 + β·w_Gv + β·w_Gs)
```

CHC 不再需要和 5 模块做映射表——它直接作为增益系数乘在对应模块的复数上。能力高 = 同一个认知卡在这个角色手里产出的 |z_k| 更大，不是改变了 arg(z_k)。

**这解决了 CHC↔5 模块映射无实证的问题**——不需要精确载荷表。β 取一个小值（如 0.2），能力修正就不会主导计算结果。能力是调节器，不是主引擎。

### C⁵ 中认知状态的完整表达

```
一个角色在给定时刻的认知状态：

| 模块       | 复数 z_k              | |z_k| | arg(z_k) |
|------------|------------------------|-------|----------|
| 知觉与注意 |  0.7 − 0.2i           | 0.73  | −16°     |
| 记忆       |  0.5 + 0.1i           | 0.51  | +11°     |
| 知识表征   |  0.6 + 0.0i           | 0.60  | 0°       |
| 表象与语言 |  0.4 − 0.3i           | 0.50  | −37°     |
| 推理       |  0.8 + 0.1i           | 0.81  | +7°      |

加工深度 α = 0.7
CHC 增益 β = 0.2
```

### 与情绪系统（PAD）的接口

两边各有数学空间：

```
认知侧: C⁵ → CPM 步骤激活基底 → |z_k| 触发 SEC 闭合 → arg(z_k) 决定 SEC 偏向
                                                              ↓
情绪侧: PAD 空间       ← PAD 分量更新  ← SEC 闭合信号 × 偏向方向
```

不再是两个独立黑箱各自产出标量拼成态度。两边有明确的结构——C⁵ 的模长和辐角经过 CPM 解释后，驱动 PAD 空间的坐标变化。

### 复平面模型收敛了什么

| 旧问题 | 复平面解法 |
|---|---|
| 四框架拼在一起无接口 | SDT 实部虚部天然正交；深度和 CHC 变成标量乘子——不再需要"接口层" |
| 60+ 参数 | C⁵ = 10 个实参数 × 标量 α × 标量 β |
| 模块间无法统一进单个坐标系 | 不需要统一——每个模块自己的复平面，C⁵ 是直和 |
| criterion 缺乏常模数据 | 辐角是相对值——只需要"偏向哪个方向多少度"，不需要绝对常模 |
| 加工深度被当成连续维度 | α 是标量增益，本来就不是维度 |
| CHC↔模块映射无实证载荷 | β 乘子模式消除了对精确载荷表的需求 |

**最关键的一条**：PAD 能用是因为存在 19,971 词的评分数据库。认知操作的 d' 和 criterion 没有这种数据库。但复平面把问题从"绝对值是多少"变成了**相对关系**——模块之间的相位差、CPM 步骤之间的基底旋转、加工深度对模长的统一缩放——这些可以从理论和 CPM 序列表中推导，不需要等待一个不存在的认知操作评分数据集。
