# 认知演化 — 唯物倾向与唯心倾向

> **⚠️ 文档语言说明（2026-07-14）**：本文写于卡牌版时期，"认知卡"在当前架构中对应技能内封装的认知层参数。两种认知倾向的职业路线设计仍具参考价值，但具体实现方式待技能系统完善后重新设计。

> 认知倾向在战斗结束后如何演化——两种认知倾向（唯物/唯心）提供不同的工具集，没有哪个是"正确"的。在月光观察者效应下，两套都是真的。

## 一、两种认知倾向

这不是两个阵营。是同一枚硬币的两面——两套不同的 "如何看待世界" 的策略。在月光观察者效应下，两套都是真的。

| | 唯物倾向 | 唯心倾向 |
|---|---|---|
| **核心信念** | 世界独立于我的观察而存在 | 我的观察参与构建世界 |
| **认知策略** | 看得更准、分得更清、推得更对 | 重新命名、重新归类、重新叙事 |
| **力量来源** | 准确感知威胁 → 物理应对 | 重塑信念 → 心灵干预 |
| **加成方向** | 物理伤害 + 物理防御 | 心灵伤害 + 心灵防御 |
| **风险** | 看不到信念的力量——在需要 "相信自己" 时无能为力 | 脱离物理现实——幻觉和妄想将自己反噬 |
| **5 模块侧重** | 知觉与注意、推理 | 表象与语言、知识表征 |

**没有哪个是 "正确" 的。** 在一个信念能塑造现实的世界里，唯物和唯心是同等的生存策略。精分患者可能天生偏向唯心——他们更容易相信幻觉。正常人可能偏向唯物——但他们的 "不相信" 本身也是一种信念。

## 二、认知卡的倾向变体

同一个认知模块下，两张倾向不同的卡**不是数值更好或更差**——它们是不同的工具。

### 知觉与注意

```
唯物卡 "明察秋毫"
  效果: 揭示敌人一个隐藏属性。下一张推理卡的 d' +0.2。
  设计逻辑: 你把注意力集中在客观事实上。

唯心卡 "心无旁骛"
  效果: 忽略一个负面情绪卡的 PAD 影响一回合。下一张表象卡的 criterion 向你选择的方向偏移。
  设计逻辑: 你主动过滤掉干扰信念的情绪信号。
```

### 记忆

```
唯物卡 "温故知新"
  效果: 从弃牌堆回收一张本场用过的认知卡。其 d' 获得 +0.1 加成（"上次用过，这次更准"）。
  设计逻辑: 经验是最好的老师——你把上一次的认知操作复现得更精确。

唯心卡 "重构叙事"
  效果: 选择弃牌堆中一张卡，改变其记忆标签（如将"创伤"重标为"教训"）。
       被重标的卡在后续战斗中以新标签出现。
  设计逻辑: 记忆不是录像——每次回忆都是一次重建。在月光下，你有权选择如何记住。
```

### 知识表征与分类

```
唯物卡 "精准归类"
  效果: 揭示敌人的分类标签（威胁/中立/盟友），降低对该敌人的 criterion 不确定性。
  设计逻辑: 通过观察证据将对象归入正确类别。

唯心卡 "重新定义"
  效果: 改变一个对象的标签——将"威胁"改为"误解"，或将"盟友"改为"潜在威胁"。
       一次战斗内只能使用一次。
  设计逻辑: 语言定义现实——你叫它什么，它就变成什么。
```

### 表象与语言

```
唯物卡 "如实描述"
  效果: 移除一个对象的虚假标签或幻象覆盖。恢复其真实属性。
  设计逻辑: 语言应该准确反映客观现实。

唯心卡 "命名之力"
  效果: 给一个对象添加临时标签。"你不再是怪物——你是被困住的人。"
       标签改变对象的战斗行为（敌人可能停止攻击，或改变目标）。
  设计逻辑: 在月光下，命名有创造现实的重量。
```

### 推理、问题解决与决策

```
唯物卡 "逻辑推演"
  效果: 预览敌人下回合最可能的行为（基于其当前态度和战斗 AI）。概率显示为百分比。
  设计逻辑: 客观概率——世界按因果律运作，你的任务是算对它。

唯心卡 "信念干预"
  效果: 展示三个可能的未来，你选择一个"相信"。你的选择增加该未来的实现概率。
  设计逻辑: 观察者效应——你选择相信的未来更可能成真。
```

## 三、倾向积累与认知风格

每打出一张认知卡（唯物或唯心），对应的倾向计数 +1。在战斗结束后的奖励界面，倾向分布影响可选的新认知卡：

```
唯物倾向 > 唯心倾向 → 奖励池中唯物卡权重 ↑
唯心倾向 > 唯物倾向 → 奖励池中唯心卡权重 ↑
```

你可以在几场唯物选择后突然转向唯心——系统不锁你的路，但**转向有代价**：转向后的前三张新卡自带 d' 惩罚——"新视角需要适应"。
