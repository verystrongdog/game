# Game Design Ideas

> **⚠️ 此文件已被 card.md 取代。** card.md 是后期的权威设计稿，对世界观、核心机制和角色能力做了根本性修订。本文件保留仅供考古参考，其中的颜色系统和治疗模拟框架已被废弃（见 design/decisions/）。以 card.md 和 00-05 系列 md 为准。

## 项目

- 暂定名：未定
- 核心主题：情绪、态度、认知与精神状态的相互作用
- 核心目标：把复杂的心理变化抽象成可玩的卡牌与资源系统

## 核心概念

- 卡牌不直接等于`态度`
- 卡牌分为三类：
  - `认知`
  - `情绪`
  - `行为`
- 不同类别的卡牌在结算、排列或组合后，可以形成不同的`态度`
- 敌人和环境会影响玩家的认知、情感和行为
- 敌人可以将自己的态度牌塞给玩家，玩家可以选择接受、转化或抵抗
- 战斗的本质不是单纯削血，而是让敌人或自己进入特定精神状态，直到`情绪崩溃`

## 认知分类

- 认知不等于单纯的“观点”
- 认知更接近：
  - 获取信息
  - 理解信息
  - 处理信息
  - 形成判断
  - 调整判断
- 在游戏中，认知卡不直接代表结论，而是代表`形成看法的过程`

### 核心定义

- 认知卡：改变信息选择、事件理解、记忆调用、时间判断或行动组织方式的卡牌

### 分类方案

- `注意`
  - 核心问题：我注意到了什么，忽略了什么
  - 适合的机制：
    - 抽牌
    - 检索
    - 锁定目标
    - 过滤某类牌
    - 强制关注某个对象

- `理解`
  - 核心问题：我如何理解当前发生的事情
  - 适合的机制：
    - 改变事件含义
    - 改变某张牌的判定
    - 把敌方行为识别为威胁、帮助或干扰
    - 改变某次情绪触发条件

- `记忆`
  - 核心问题：过去的什么内容正在影响现在
  - 适合的机制：
    - 回收弃牌
    - 重复结算上一回合效果
    - 触发闪回
    - 遗忘指定卡牌
    - 保留上一回合的某种颜色或状态

- `时间`
  - 核心问题：我把注意力放在过去、现在还是未来
  - 适合的机制：
    - 提前看到敌方下一步
    - 延后某张牌的结算
    - 提前触发未来效果
    - 把过去使用过的牌重新拉回当前
    - 将当前状态延续到下一回合

- `组织`
  - 核心问题：我如何安排想法与行动顺序
  - 适合的机制：
    - 调整出牌顺序
    - 降低或提高行动点消耗
    - 连携奖励
    - 强制按顺序打出某类牌
    - 储存行动点或延迟行动

### 时间角度的进一步拆分

- `过去导向`
  - 关键词：回忆、闪回、遗憾、经验、创伤、复盘
  - 机制方向：
    - 从弃牌堆取牌
    - 重复上回合效果
    - 让旧情绪再次生效

- `现在导向`
  - 关键词：觉察、聚焦、判断、当下处理
  - 机制方向：
    - 立即改色
    - 立即修正目标
    - 立即改变当前事件解释

- `未来导向`
  - 关键词：预期、担忧、计划、预测、准备
  - 机制方向：
    - 预览敌人意图
    - 预存效果
    - 延迟爆发
    - 为下一回合保留资源

### 当前决定

- 不使用`风格`作为认知分类维度
- 不使用`灾难化`作为主分类
- 认知分类先按功能来分，而不是按正确与否、积极与否来分
- 时间是认知的重要维度，可以直接作为认知卡设计的一部分

## 行动点数

- 使用卡牌需要消耗对应的行动点数
- 行动点数是回合内最基础的资源之一
- 不同角色、患病背景、情绪状态、遗物效果都可以修改卡牌的行动点消耗
- 行动点消耗可以作为“做同一件事有多费力”的抽象表达

### 当前灵感

- 抑郁症患者的所有卡牌行动点消耗 `+1`
- 这种设计可以对应：
  - 行动迟滞
  - 动机下降
  - 启动困难

### 待继续推演

- 每回合的基础行动点数是多少
- 行动点修正是作用于全部卡牌，还是只作用于某一类卡牌
- 是否允许行动点被颜色、情绪、精神状态进一步修正
- 是否存在“超支行动”机制
- 敌人与玩家是否遵守同一套行动点规则

## 精神条

- 精神条拥有三个空位
- 空位被不同颜色染色后，触发对应情绪效果
- 精神条是游戏的核心机制
- 需要继续明确：
  - 颜色叠加发生在什么层级
  - 颜色如何映射为情绪
  - 数值和颜色如何共同决定状态强度

## 颜色系统

### 当前记录的颜色

```text
#FFFFFF  纯白   癫狂
#000000  纯黑   本色 / 空洞 / 冻结候选
#0000FF  纯蓝
#0055AA  深青色
#00AA55  青绿色
#00FF00  纯绿
#5500AA  蓝紫色
#555555  中灰色
#55AA00  黄绿色
#AA0055  紫红色
#AA5500  橙黄色
#FF0000  纯红   欢欣
#550000  深红   积极
#005500  深绿   中性
#000055  深蓝   消极
```

### 当前问题

- 卡牌本身已经有颜色需求，若再叠加复杂颜色，可能导致信息过载
- 如果让整屏变色，表现会太花哨
- 如果只让角色变色，沉浸感可能不足
- 需要决定颜色变化的承载体：
  - 精神条本身
  - 角色外观特效
  - UI 边缘反馈
  - 卡牌结算动画

### 颜色设计方向

- 不直接把`积极 / 消极 / 平和`当最终情绪，而是把它们当底层倾向
- 可以考虑把三原色绑定为更底层的心理过程，而不是结果标签
- 目标是用少量基础颜色生成丰富但可理解的情绪组合

## 情绪与精神状态

### 负面情绪

| 情绪 | 达成条件 | 效果 | 持续时间 |
| --- | --- | --- | --- |
| 恼怒 | 被激怒 | 有概率攻击错误对象，包括自己 | 依据卡牌效果计算 |
| 愧疚 | 被指责 | 失去行动点数 | 依据卡牌效果计算 |
| 畏惧 | 被惊吓、陷入黑暗 | 在回合中最后行动 | 依据卡牌效果计算 |
| 惊厥 | 过度恐惧 | 失去行动能力 | 一回合 |
| 沮丧 | 受到创伤 | 伤害降低，受到伤害增加 | 依据卡牌效果计算 |
| 绝望 | 短时间经历多种负面情绪 | 全属性降低 | 直到经历一次正面情绪 |
| 自卑 | 长时间处于负面状态 | 无法攻击 | 直到经历一次正面情绪 |
| 惘然 | 灰色 | 将手牌洗回抽牌堆并重抽相同数量 | 依据卡牌效果计算 |
| 忧郁 | 蓝色 | 待补充 | 待补充 |

### 正面情绪

| 情绪 | 达成条件 | 效果 | 持续时间 |
| --- | --- | --- | --- |
| 欢欣 | 纯红色 | 行动卡拥有双倍效果 | 一回合 |

- 小时候的照片
- 偏振眼镜
  - 选择性接收态度
- 《认知协调论》
  - 具体效果待补充

## 角色 / 症状灵感

> 这里先记作灵感原型，不直接视为严格医学设定。

- 阿贝贝
  - “阿贝贝”指儿童长期依恋、用以获取安全感的安抚物，例如毛巾、毯子或毛绒玩具
  - 该词源自网络视频
  - 在心理学上可对应“过渡性客体”
  - 不仅婴幼儿会依赖它来缓解分离焦虑，许多成年人也会通过这类物品调节情绪与压力

- 医生
  - 描述：有时候病人与医生的界限并不明显，但是你终究知道的更多，不是吗
  - 机制：在态度结算时可以将行为卡转变为任意颜色

- 正常人
  - 描述：我为什么会在这里？这个世界上真的有正常人吗？

- 躁狂症
  - 描述：易怒
  - 机制：在态度结算时可以将任意态度卡转变为红色

- 抑郁症
  - 描述：悲观
  - 机制：在态度结算时可以将任意态度卡转变为蓝色

- 双向情感障碍
  - 机制：经历负面情绪后，下一次情绪变化一定为正面情绪；连续正面情绪后会陷入负面情绪

- 精神分裂症
  - 机制：在负面情绪和正面情绪下可以召唤另一个自己

- 创伤后应激障碍（PTSD）
  - 机制：进入负面情绪时会出现幻觉，敌人的行为与态度会发生改变

- 自闭症
  - 描述：善于和卡牌交朋友
  - 机制：满足一定条件可以修改卡牌数值，包括敌人的卡牌

- 胆小鬼
  - 描述：容易受到惊吓
  - 机制：陷入恐惧状态会增加行动力，但是过度恐惧会造成惊厥并失去行动能力

- 拖延症
  - 机制：没有使用的行动点数和卡牌可以积攒到下一个回合

- 健忘症
  - 机制：所有精神状态都只持续一回合

## 世界与战斗逻辑

- 玩家与敌人都应拥有两种基础状态：
  - `精神病状态`
  - `非精神病状态`
- 这两种状态应影响：
  - 可用卡牌
  - 态度染色方式
  - 情绪触发条件
  - 目标选择或行为逻辑
- 可以考虑把这两种状态作为战斗中的上位状态机，而不是单纯的 debuff
- 争论常常来自于认知差异，而非事实本身
- 认知不是一成不变的东西
- 他人与环境会影响你的认知、情感和行为
- 亲人之间会共享情感
- 有些人会强迫你做出行为
- 抽象是核心方法：
  - 不还原现实的细节动作
  - 只保留心理影响的结构

## 当前设计问题

- 如何通过精神条的数值与颜色表达不同情绪
- 三种基础态度卡不能稳定同时出现在手上，如何解决
- 是否需要利用他人的态度作为自己的资源
- 敌人与玩家是否公用同一套底层规则
- 敌人与玩家是否应共用同一套牌库
- `精神病状态 / 非精神病状态` 如何切换、是否可逆、由谁判定
- 三种纯色态度卡最终组合出的态度是否一定为正面态度
- 如何定义“击败敌人”
- 如何让抽象足够强，但又不失去现实联想

## 新增灵感

- 精神病患者形成态度的过程很可能是有缺陷的，他们受困于自身的病情，无法做到一些正常人很容易做到的事
- 这也是为什么要把态度拆分为`认知 + 情绪 + 行为`
- 这三者中任意一者不正常，都会导致态度形成出问题
- 游戏的核心玩法是：玩家控制患病角色，尽可能选择正确的态度去面对事情；或者即使选择不对应的态度，但配合病情反而能达到很好的效果
- 这里的病情可以近似看作人物能力
- 幻觉这一症状有很大的发挥空间
- 敌人灵感：一只被陷阱抓住的猴子
- 陷阱是装有饵料、带孔的椰子；空手时可以伸进去，抓住饵料后因为握拳无法把手抽出来
- 重点不是猴子愚蠢，而是“不会松手”
- 现实中的映射：
  - 在股市中被套牢
  - 染上赌博
  - 明知道最后会口腔纤维化还是要嚼槟榔
- 这个猴子不要做得太野性
- 要给它穿上衣服
- 要让它表现出自己知道这样会被抓住，并且强调自己很聪明
- 但最重要的是：它不会松手

## 特殊事件 NPC

### 都灵之马

- 作为特殊事件 NPC 的灵感来源
- 关键词：
  - 虚无
  - 苦难
  - 共情过载
- 无法承受的理解
- 真相导致崩溃
- 更适合做成高风险高价值的`认知事件 NPC`
- 它带给玩家的不是普通奖励，而是`代价极高的理解`
- 它的核心价值可以是：
  - 看见真相
  - 强烈共情
  - 撕开幻觉
  - 意义交换
  - 崩溃式净化
- 基本方向：
  - 玩家会知道更多
  - 但“知道更多”本身就是伤害
- 适合的出现时机：
  - 连续经历多次负面情绪后
  - 精神条出现特定颜色组合时
  - 多次选择共情、忍耐、目睹苦难类态度后
  - 在一次重大失败之后
- 不适合做成普通随机事件
- 更适合在玩家对苦难的“看见”累计到一定程度时出现

因为虚无一直在肢解人类。你去过菜市场看过牛蛙吗？他们拥挤在肮脏的网格里面，随后被人捞起斩下头颅，去除内脏，剥下皮，交给顾客。牛蛙能理解自己的痛苦吗，他们知道自己一生下来就是要被吃掉的吗,一旦理解了，他们就会疯掉.不能，他们只知道焦虑或者一种困惑。他们不理解他们真实的东西，那种痛苦超过了他们的理解范围。人类就是这样子的动物，人类一生下来就不得不面临荒诞的命运，人类对于自身的痛苦也超过了人类能理解的范围,人类要面临着生存的困境是如此的宏大,战争屠戮饥饿疾病瘟疫,除去这个之外，还有个最本质的痛苦，就是无时不在的死亡，死亡意味着彻底的消解，你的生存，你的意志，你的欲望，你一切的爱都无关紧要，在死亡面前，这些东西每时每刻都在毁灭着你，不但毁灭你的肉体，也毁灭你的意义,人类不能理解这种痛苦，只会产生一种焦虑，就像牛蛙不能理解案板上的菜刀为什么会砍下他的头颅一样。于是远古的人类很早就学会了欺骗，发明了哲学、宗教、艺术、心理学，各种各样的意识形态，这些意识形态告诉你，死亡并不可怕，死亡后有天堂，有轮回，一切都是为了欺骗我们这些双足牛蛙们……所有这些都像是试图给那种超出认知范围的剧痛缝一个可以理解的口子，但口子永远太小，痛还是从四面八方渗进来。在20世纪的时候科学和技术进一步瓦解了亚伯拉罕的神话，人们赖以自慰，欺骗自己的甜蜜幻觉也消失了，他们不得不面临血淋淋的真实，每个人都像被杀害前的牛蛙一样焦虑，恐慌，是依然无法贯彻的透彻的理解。人类对于世界的认知终于超过了宗教所构建的认知边界，却无法承受这种真相所带来的精神毁灭。尼采的哲学一直试图在基督道德死掉的废墟上重构一种全新的世界：永恒轮回，超人，权力的意志。然而尼采本人却没能完全承受这个“真相”，如同拉斯柯尔尼科夫一样，他一度自以为拥有超人的意志，却仍旧无法扛住现实的代价；后者最终选择回归基督教道德的怀抱。而尼采则早已摒弃了古典世界与旧秩序的一切，在肉体与精神的双重煎熬中，走向了自己的终结。在梅毒三期的后期肉体的疼痛使得尼采忽然理解了这一切的痛苦来源，此前，他一直声称的超人意志和酒神精神，在病痛和死亡的残忍面前变得如此不堪。这样的故事在哲学家中如此的平常。推崇生命哲学的德勒兹在肺病的疼痛中选择从3楼一跃而下，结束了自己的生命，探讨现代知识是权力所塑造的福柯在面临艾滋的绝症，也和平凡人一样疯了一样的寻求医院的治疗。这很简单，因为哲学家也是人，而只要是人类在生命的最后似乎总是要被某种腐败，衰老，病痛的阴影所俘获，虚无的阴影总会如同洪水一样漫过你的脚踝，然后一步步吞没一切。而对于尼采来说理解这些意味着崩溃，在都灵的广场上农夫抽打的皮鞭隐喻了故事的真相。像马这样坚韧自由而优雅的生物，却被末人毫无意义地挥霍、粗暴而残忍地鞭打，直至陷入精疲力竭，苍白的境地。现实轻松又残酷地吃掉了生命，他坚持权力意志能够胜利的幻觉就迎来了惨烈的破碎。而这样的故事对于尼采来说过于震撼，如同那群牛蛙们终于看清了他们头顶那把滴血的菜刀，这种理解一旦清晰明了，那么就有数不清的无限的，超越你自身的剧烈痛苦出现，这种痛苦已经超过了他们的认知。这就是尼采对着马哭的原因，在某一瞬间，马儿悲惨的嘶鸣声就这么如此自然的回荡在他的耳边，渗进了他的灵魂之中，为他的人生做了预见，他发现自己写的一切文字竟比不上生命对于苦难的一声的叫唤，此后他的余生就只能听见马儿的嘶鸣。他与被殴打的马，和被屠宰的马，被杀的牛蛙，被肢解的鱼，被虚无吞噬意义的人类完全的100%的共情了，这样的共情超越了人类的理解的自身，切切实实的感受到了某种不可忍受的痛苦。这种尖锐的潮湿的衰朽在人类群体中，荡漾在人类群体中，流传像是疾病一样，像是瘟疫一样。在1889年1月3日，尼采在都灵的广场抱着马的脖子流下了眼泪，并陷入持续的崩溃，此后11年，他再未曾写过一字。

## 战斗设定

- 故事背景发生在一家精神病治疗中心
- 这里的院长使用“面具”疗法帮助患者直面自身病症
- 敌人可以来自：
  - 护士
  - 医生
  - 护工
  - 家人
  - 回忆
- 少数拥有幻想症状的病人还有可能将物品视为敌人
- 最终 boss 对应疾病的成因

## 面具设计

- 威尼斯面具比较适配当前想法
- 这种面具足够花哨，而且有很多装饰空间，适合承载共享症状
- 不希望把共享症状主要做成单纯的颜色变化，避免和情绪颜色系统冲突
- 可以采用分层表达：
  - 面具轮廓表示主原型 / 主病症
  - 附加装饰表示共享症状
  - 颜色只做辅助提示，不承担主要区分功能

### 装饰设计方向

- 不同共享症状不一定都使用同一种装饰物
- 可以按照症状类别分配不同装饰家族：
  - 羽毛
  - 裂纹
  - 锁链 / 带子
  - 镜片 / 玻璃片
  - 铃铛 / 金属挂饰
  - 刺 / 角 / 尖饰
  - 蜡封 / 缝线
  - 流苏 / 垂坠物
  - 镜面碎片

### 位置含义

- 额头：认知类症状
- 眼周：感知、怀疑、幻觉、注意偏差
- 口部：表达、压抑、冲动言语
- 脸颊：情绪残留、羞耻、愧疚、社交影响
- 下巴或边缘：行为倾向、行动迟滞、逃避、强迫动作

### 当前倾向

- 一个共享症状更适合用`装饰类型 + 固定位置规则`来表示
- 情绪 / 精神状态继续主要用颜色和光效表达
- 开局选择面具搭配的界面，可以表现为玩家观察镜子中戴着面具的自己

## 待验证的研究方向

- 常见精神障碍的临床表现
- 精神障碍的分类体系
- 症状簇、病程、功能损害模式、发育阶段
- 哪些医学概念适合转成游戏机制，哪些不适合直接使用
