### 两套数据的一致性

| 比较 | 一致 | 不一致 |
|---|---|---|
| V（效价） | 两套数据的排序和间距高度一致 | NRC 极值更极端（BWS 特性） |
| A（唤醒） | 方向一致：恐惧/愤怒高，悲痛低 | **NRC 唤醒值系统性地高于 Warriner**——NRC 的焦虑 A=+0.73，Warriner 仅 A=−0.06。这是 BWS 和 SAM 的方法差异 |
| D（控制） | 方向一致：愤怒/快乐高，恐惧/悲痛低 | NRC 的 D 极值更大 |

**结论**：相对位置和方向两套数据一致。绝对值因方法不同有偏差。游戏中取 NRC VAD 值——BWS 方法在区分度上更优。

## 三、PAD 空间覆盖分析

### 3.1 八分区覆盖

基于 Valdez & Mehrabian (1994) 的 PAD 八分区 + NRC VAD 19,971 词实测分布：

| 八分区 | NRC 词数 | 15 情绪覆盖 | 代表情绪 |
|---|---|---|---|
| +P +A +D | 967 | ✅ | 快乐 |
| +P +A −D | 26 | ✅ 🆕 | 敬畏 |
| +P −A +D | 545 | ✅ 🆕 | 希望 |
| +P −A −D | 399 | ✅ 🆕 | 平静 |
| −P +A +D | 481 | ✅ | 愤怒 |
| −P +A −D | 881 | ✅ 🆕 | 恐惧、焦虑、厌恶、恐怖、绝望 |
| −P −A +D | 4 | ✗ | (轻蔑/冷漠——不补) |
| −P −A −D | 600 | ✅ 🆕 | 悲痛、孤独 |
| 中性/边界 | 16,067 | ✅ | 共情、内疚、爱 |

**7/8 分区覆盖。** −P −A +D（4 词，轻蔑/冷漠/无聊）不作，因为临床场景不需要。

### 3.2 9 情绪 → 15 情绪的改进

| 改进 | 说明 |
|---|---|
| 填补 +P −A 区 | 新增平静、希望——治疗目标象限，之前完全空白 |
| 填补 +P +A −D 区 | 新增敬畏——仅 26 词的稀有区，对应顿悟/超越体验 |
| 细分 −P +A −D 区 | 881 词原来只有 3 个标签，现在拆为恐惧/焦虑/厌恶/恐怖/绝望——各自有独立的 PAD 坐标 |
| 细分 −P −A −D 区 | 600 词原来只有 1 个标签，现在拆为悲痛/孤独——丧失 vs 隔离 |
| 未补 | −P −A +D 区（4 词）——不做 |

## 五、维度定义

| 维度 | 含义 | + 极 | − 极 |
|---|---|---|---|
| V (Valence) 效价 | 主观感受的好坏 | 愉悦、舒适 | 不悦、痛苦 |
| A (Arousal) 唤醒 | 生理/心理激活水平 | 兴奋、紧张 | 平静、困倦 |
| D (Dominance) 控制 | 对情境的掌控感 | 掌控、主动 | 被控、顺从 |

三维度近乎正交（fMRI 验证：Baucom et al., 2012）。

## 六、计算公式

### 6.1 情绪距离

```
dist(E1, E2) = √[(V1−V2)² + (A1−A2)² + (D1−D2)²]
```

### 6.2 多情绪叠加

```
V_current = Σ(V_i × w_i) / Σw_i
A_current = Σ(A_i × w_i) / Σw_i
D_current = Σ(D_i × w_i) / Σw_i
```

### 6.3 情绪过渡矢量

```
transition(E_from → E_to) = (V_to−V_from, A_to−A_from, D_to−D_from)
```

### 6.4 PAD → 行为推力

```
趋近/回避方向 = sign(V)
行为强度       = |A|
主动/被动     = sign(D)
```

## 七、与游戏系统的接口

### 情绪数据格式（技能/NPC AI 参考）

```
卡牌: 恐惧
VAD: V=−0.854, A=+0.680, D=−0.414  (NRC VAD 归一化)
来源: 场景触发 / 认知操作触发
```

### 行为驱动的 PAD 激活条件

| 行为驱动 | PAD 条件 |
|---|---|
| 反射 | A > 0.5 且 D < −0.3 |
| 惩罚机制 | V < 0 |
| 奖励机制 | V > 0 |
| 道德驱动 | D > 0.2 |
| 文化习俗 | −0.2 < D < 0.2 |
| 价值驱动 | D > 0.5 |
