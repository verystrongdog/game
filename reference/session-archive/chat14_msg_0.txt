
而不是：

```text id=\"g9l3mq\"
上午 / 下午 / 夜晚
        │
        └──→ 修改 E_c / E_th / q̂ / m_field
```

### “夜晚更危险”怎么办？

这里也建议**不要在 #103 解决机制本身**。

#103 只裁决：

> **时段本身不能改变月相场动力学参数。**

至于为什么夜晚可能：

- 更危险；
- 更容易进入深层；
- NPC 行为不同；
- 某些事件概率发生变化；

属于**design/events/空间状态层的独立机制**，后续按你说的队列单独 grilling。

这样就不会出现一个非常危险的“万能月光参数”：

> 夜晚 → 月光强 → 场能量强 → 危险性强

然后所有东西最后都被塞进 \(E_{th}\) 或 \(m_{field}\)。
