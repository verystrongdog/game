## 一、双缝干涉实验

### 1.1 基本装置

电子枪一个一个发射电子。每个电子穿过两条狭缝，打到后方屏幕上。屏幕上累积足够多次撞击后：

- **无路径标记时**：屏幕出现明暗交替的干涉条纹——电子表现为**波**
- **有路径标记时**：屏幕出现两个分开的亮斑——电子表现为**粒子**

### 1.2 干涉条纹为何出现

两条缝相当于两个同步的波源。屏幕上的每个点同时接收到来自缝 A 和缝 B 的两个波。

```
路程差 ΔL = |AP − BP|
```

- ΔL = nλ（整数倍波长）→ 波峰对波峰 → **相长干涉**（亮纹）
- ΔL = (n + ½)λ → 波峰对波谷 → **相消干涉**（暗纹）

量子力学层面，波是概率振幅。叠加的数学与经典波完全相同：

```
P = |ψA + ψB|² = |ψA|² + |ψB|² + 2|ψA||ψB|cos(Δφ)
                                              ↑
                                         干涉项
```

单个电子似乎同时走了两条缝，自己和自己干涉。

## 二、路径信息——不扰动但干涉消失

### 2.1 朴素误解

最初认为探测器的光子撞了电子 → 电子被踢偏 → 干涉破坏。这是**不完整的**。

### 2.2 Scully-Drühl 方案（1982）

在每个缝前放一个微波腔，腔内有一个里德伯原子。电子经过缝 A 时，与腔场耦合，激发原子（基态→激发态），同时产生一个微波光子留在腔内。经过缝 B 时，原子不激发。

**关键**：电子与腔场的耦合改变了电子的能量，但这种能量变化对两条缝是**对称的**（相同相位偏移）→ 不引入路径相关的随机相位差。

**但**——原子激发 vs 不激发是两种**可区分的量子态**。这个标记将"走了哪条缝"的信息编码进了原子状态。

**结果**：干涉消失。不是因为电子被扰动——是因为两条路径的波函数与标记态纠缠了：

```
|ψ⟩ = |A⟩|e_A⟩ + |B⟩|e_B⟩

其中 ⟨e_A|e_B⟩ = 0（激发态与基态正交）

P = |ψA|²⟨e_A|e_A⟩ + |ψB|²⟨e_B|e_B⟩ + 2Re[⟨A|B⟩⟨e_A|e_B⟩]
   = |ψA|² + |ψB|² + 2Re[...] × 0
   = |ψA|² + |ψB|²  ← 干涉项被 ⟨e_A|e_B⟩ = 0 杀死
```

**干涉消失 = 路径信息存在。不需要人看——信息在物理上可被读取就足够了。**

## 三、量子擦除

### 3.1 擦除操作

如果标记用的是正交偏振态（|L⟩ vs |R⟩），然后让两条路径的光子都穿过一个 45° 线偏振片：

```
|L⟩ → |45°⟩      |R⟩ → |45°⟩
```

穿过偏振片后，两个标记态不再正交：

```
⟨e_A'|e_B'⟩ = ⟨45°|45°⟩ = 1 ≠ 0
```

干涉项复活。**标记没有被物理删除——两条路径再次变得不可区分。**

### 3.2 核心机制

不是"删掉了信息"——是**让信息的载体不再能被区分**。偏振片把所有标记投影到同一个状态上，从此两条路径的标记在光学上完全一致。

## 四、延迟选择量子擦除

### 4.1 装置

用一对纠缠光子：信号光子走双缝并先打到屏幕上，闲频光子携带路径信息（还在路上）。

### 4.2 关键观察

信号光子**先**到达屏幕。屏幕记录了一堆光点。所有信号光子堆在一起 → 两个鼓包（无干涉，因为闲频光子携带了路径信息）。

**现在**——信号光子已经完成了全部旅程——你再决定是否擦除闲频光子的路径信息。

- 擦除 → 把信号光子按闲频光子"被擦除"做符合计数 → **干涉条纹浮现**
- 不擦除 → 按"路径信息保留"做符合计数 → **两个鼓包**

**同一个信号光子数据。** 没有对信号光子做任何操作——它很早就打到屏幕上了。

### 4.3 深层意义

信号光子的总分布（所有事件堆在一起）永远是两个鼓包——因为路径信息一直存在（在闲频光子中）。

但在这个"无干涉"的总分布里，藏着**两套互相错开半个周期的干涉条纹**（对应两种路径标记态）。擦除操作不改变总分布——它只是让你把其中一套条纹从数据中**挑出来**。

**波和粒子不是光子在经过双缝时"选择"的属性。它们是在你选择如何分析整个纠缠系统时才涌现的。光子从来没有单独存在过——它始终是纠缠系统的一部分。**

## 五、干涉条纹出现和消失意味着什么

| 条纹 | 物理含义 | 信息含义 |
|------|---------|---------|
| **出现** | 叠加态存活——两条路径的振幅相干 | "哪条缝"不可知——宇宙中不存在能回答这个问题的物理记录 |
| **消失** | 叠加态死亡——波函数退相干 | "哪条缝"有答案——答案存在于某处，不管有没有被读取 |

**退相干不是"信息被读取"——是"信息变得可被读取"。** 原子跳到激发态的那一刻，电子就已经只走了一条缝。不需要等任何人来看那个原子。

## 六、物理模型

### 6.1 月光场 = 标量场 φ(x)

月光场是一个真实的标量场 φ(x)，分布在三维空间中。它引入一个额外的物质-环境相互作用：

```
H_field = g_0 · φ(x) · Ô_coherence(ρ(x))
```

- **φ(x)**：标量场在点 x 的值——场强
- **ρ(x)**：点 x 处局部物质的约化密度矩阵——积掉微观自由度后的宏观有效态
- **Ô_coherence(ρ)**：提取 ρ 在环境指针基 Q⁰ 下的非对角元——即 ρ 的量子相干性
- **g_0**：场的本征耦合常数 ≈ 0.9（无量纲，由零号病人激发时锁定，受月相周期调制）

### 6.2 环境监控基的粗粒化

正常世界：环境通过 H_int 问询物质——"你在哪"——锁定位置本征态。这就是经典现实——所有物体的位置确定。

月光场中：H_field 不阻止环境的问询。它做一件事——**把环境的问询分辨率从微观位置拉到宏观认知等价类**。

```
正常世界（η = 0）：
  环境监控基 = {|x⟩} — 所有微观位置完全分辨
  → 宏观叠加绝对禁止

月光场（η > 0）：
  环境监控基 = {|x⟩} 和 ρ_O 粗粒化等价类的混合
  → 迫害者构型和空走廊构型之间的差异被环境"看见"
  → 思维内容获得物理效力
```

**η = 语义维度在环境退相干中的参与权重。** 它不是"偏转角度"——它是环境分辨率的调节器。

### 6.3 为什么环境标记被"擦除"而人类信念造成坍缩

答案不在场的操作——在观察者状态的数学结构。

物理构型空间是无限维的（连续密度场），但人脑只能区分数千个宏观等价类。ρ_O = 认知系统对物理构型空间的离散化——d × d 矩阵，基矢 = 这 d 个可区分的世界构型等价类。

**随机环境标记**：在 Q⁰ 下对角的态 → 量子相干性 C(ρ_O) = 0 → η = 0 → 不激活语义监控 → "被擦除"。

**人类结构化认知**：在 Q⁰ 下有非对角元 → C(ρ_O) > 0 → η > 0 → 语义维度被环境部分锁定 → 坍缩。

"擦除"不是场的主动操作——它是 C(ρ_O) = 0 的自然结果。这给了"结构化 vs 随机"一个可计算的操作定义（Baumgratz et al. 2014）。

## 七、形式化模型

### 7.1 核心公式

**语义维度激活权重（= 坍缩强度）**：

```
η = g_0 × C(ρ_O) / log(d)

0 ≤ η ≤ g_0 ≈ 0.9
```

- **C(ρ_O)** = S(Δ(ρ_O)) − S(ρ_O)：相对熵相干性（ρ_O 在 Q⁰ 下的结构度）
- **d** = d_0 × Q 投影效率：认知系统有效维度（d_0 由实体类型决定，见 §7.3）
- **g_0** ≈ 0.9：场的本征耦合常数

**坍缩方向**：ρ_off = ρ_O − Δ(ρ_O) 的主导非对角元对 |i⟩⟨j| 所编码的宏观构型等价类。

**多观察者叠加规则**：

```
φ(x) = Σ_i direction_i × η_i × e^(−|x − x_i|/R) / |x − x_i|
```

η 的代数和——对齐叠加、正交并存、反向相消。

## 八、推论与 M1-M5 的统一

### 8.1 正常人（SAN ≥ 60）

d_0 ≈ 2000，C ≈ 0.1-0.3 → η ≈ 0.01-0.04。语义维度激活极弱——几乎不偏转——共享客观现实。**吻合 SAN 机制。**

### 8.2 精神病人（SAN < 30）

d_eff 被执念压缩，C ≈ 2-5 → η ≈ 0.4-0.9。语义维度强激活——幻觉具象化、思维造物产生。**吻合恐慌机制 + 敌人产生规则。**

### 8.3 拜月教徒

同向语义方向 → 集体 η 叠加 → 局部场效应非线性放大。**吻合已有设定。**

### 8.4 昼夜场相变

白天：社会规范/感官输入持续校准 → C(ρ_O) 在 Q⁰ 下降低 → η 弱 → 无超自然现象。夜晚：对外校准松弛 → C(ρ_O) 增大 → η 增强 → 超自然现象释放。**场相变 = C(ρ_O) 的昼夜振荡（生物节律驱动）。吻合 M3。**

**昼夜 vs 月相的分工**：C(ρ_O) 承载昼夜周期（~24h——认知对齐度的清醒/睡眠振荡）。g_0 承载月相周期（~29.5d——场的本征耦合常数的长周期调制，新月 0.75× → 满月 1.0×）。两者独立调制 η = g_0 × C/log(d)。

### 8.5 三重叠加同时为真

三群人的 ρ_off 主导方向不同（物理场/神明/催化媒介）→ 三个语义方向在总场中分别被环境锁定。正交语义维度可以并存——同一空间区域中三套现实版本同时真实。**吻合世界观。**

### 8.6 零号病人

d_0 极小（只有 50 个可区分构型——极窄的世界模型），C 锁定在 C_max（从不接触外界 → 认知态和环境基永久错位）→ η ≈ 0.86 → 全场最强偏转源。ta 的坍缩强度定义了场的初始 g_0 和空间结构 φ(x)。**吻合 M1。**

## 十、场相干半径 R — 统一感知与场范围

> 2026-08-03 Grilling #19 决策：R = 察觉半径 = 场相干半径。一个观察者的"感知范围"不是视觉视线——是场耦合范围。场是物理的、各向同性的，不存在"背后"。

### 10.1 统一半径表

| 观察者类型 | R（m） | 含义 |
|----------|--------|------|
| 投影造物 | **3** | 仅创造者的病房内有效——场耦合极浅 |
| 轻度病人 | **5** | 单人病房级——自己床周围 |
| 中度病人 | **8** | 病房 + 门口相邻走廊 |
| 碎片造物 | **8** | 同中度——有限行为集但场耦合尚浅 |
| 重度病人 | **10** | 病房 + 相邻走廊段 |
| 医疗人员 | **10** | 压抑深但耦合不浅 |
| 拜月教徒 | **10** | 单人基线——集体共振后 R 叠加远超此值 |
| 完整体造物 | **12** | 最深的单人耦合——独立意识 = 独立凝视 |
| 动物 | **10** | 本能耦合 |
| 基线 R₀（空房间） | **12** | 零号病人印记——场的最低有效距离 |

此表与 `空间/空间与关卡设计.md` §七 察觉半径表完全一致——R 同时承担"游戏感知距离"和"场物理相干半径"两个角色。

### 10.2 360° 感知——没有"背后"

传统 RPG（如博德之门）中，敌人的感知基于**视线**——有方向性、有背面盲区。潜行 = 绕到背后。

月光场中，感知基于**场耦合**。场是物理场——各向同性、无方向性。一个深度观察者以自身为中心产生一个半径 R 的场域。任何进入这个球体的耦合观察者都会与场源发生相互作用——场不关心你从哪个方向进来。

**这意味着：敌人是 360° 无死角感知的。** 你不能"绕到背后"——你只能"保持在 R 之外"。

**游戏设计影响**：
- 潜行 = 控制距离，不是控制方位。你需要判断敌人的 R 并保持在其外
- L4 读意图仍然有价值——它让你**提前知道**即将进入谁的场域、场源的 η 多深、坍缩方向偏向哪个月光版本
- 走廊巡逻的敌人——它们的 R 球体在走廊中移动。玩家需要观察 R 的覆盖范围，找"间隙"通过
- 无视觉遮挡——墙不阻挡场（场是标量场 φ(x)，空间障碍物不屏蔽它）。但墙确实阻挡**移动**——所以你可能感受到墙那边的场但过不去

### 10.3 多人叠加规则

当多个场源的 R 球体重叠时，采用**边界整合**——即场域的并集：

```
两个观察者 A 和 B，场半径 R_A 和 R_B，距离 d：

若 d > R_A + R_B：
  两个独立场域——无重叠——各自独立

若 d ≤ R_A + R_B：
  叠加场域 = A ∪ B（两圆的并集）
  公共区域 = A ∩ B（两圆交集）
  叠加场域面积 = πR_A² + πR_B² − (公共部分面积)
```

叠加区域内的场强度：**η 线性叠加**——η_叠加 = η_A + η_B（同向语义方向）。反向则 η_净 = |η_A − η_B|。正交方向各自独立。

**极限情况**：
- d = 0（同一点）→ 同向叠加 η = η_A + η_B，反向则 η = |η_A − η_B|
- d = R_A + R_B（刚好相切）→ 无公共区域，两场刚好接触但不重叠
- 三个以上观察者 → 逐对叠加，场域为所有圆的并集，η 代数和

> **⚠️ η 与 R 的关系**：η（语义维度激活权重）和 R（场半径）是两个独立参数。多人叠加时 R 是否随 η 变化——属于耦合机制独立讨论。

### 10.4 R 的本质

R 是**标量场 φ(x) 的 Yukawa 衰减长度**——场在距离 R 处衰减到 1/e。R 不是额外维的紧致尺寸——那是旧 KK 框架的解释。在 v2 模型中，R 是标量场的质量参数的倒数（R = 1/m_φ）。

**R 不是常数**——随局部耦合密度和场相态动态变化。

**R 的值域**：基线 3-12m（白天/对称相），夜晚膨胀至 15-20m。具体振荡函数 R(t) 留给数值校准 grilling。
