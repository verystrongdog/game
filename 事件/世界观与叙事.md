# 世界观与叙事

> **维度: 事件** — 月光/意识外显效应定义触发条件，叙事定义时间轴。

## 世界背景

故事发生在一家存在超自然现象的心理治疗中心。

### 空间扭曲

这个地方的空间结构被扭曲。不管尝试从什么地方离开，都会近似于绕地球一周的方式从治疗中心的另一端返回。治疗中心没有"外面"，或者说"外面"同时也是"里面"。这种封闭性不是物理意义上的围墙，而是一种空间拓扑的异常。

### 宏观意识外显效应

意识外显效应在这里没有被局限在微观世界。角色观察到的现象可能与其它 NPC 看到的不同——同一个房间、同一个人、同一句话，在不同角色的感知中可能呈现完全不同的形态。

换句话说，这里没有"客观现实"的绝对权威。每个人的观察都在参与构建他们所经历的现实。

### 月光与多版本基态

一轮诡异的月亮挂在空中，无论身处何处都能看到月光。

内容以多版本基态存在——同一个对象同时以多种状态在场，不同单子（内容内意识个体）从共享基质中取出自己那一版。这意味着事物在被某单子取出之前，并不处于对该单子的确定状态。

#### 月光本质：三重叠加

月光本身是无定形的自然现象。但意识外显效应不豁免月光自己——不同观察者根据自身的认知和信念，从月光中取出不同的版本：

- **理性观察者** → 取出**物理场**（A）——可量化的自然力。容器注意力的可见痕迹，可以被测量、增强、衰减、屏蔽。
- **虔信者** → 取出**有意志的神明**（B）——会回应祈祷、降下神谕、选择看什么。月亮是活的。
- **普通患者** → 取出**无声的催化媒介**（C）——不强加意志，只是放大已有的观察。

**三者同时为真——不存在"月光到底是什么"的客观答案。** 月光不偏爱任何解释。它静静地接收所有投射，把所有解释都变成真的。这就是月光的恐怖和美丽：它是一面镜子，映出的不是你的脸，是你相信什么。

#### 推论

- 场强度受月相和人类群体性精神事件双重影响（⚠️ v2 参数 g_0/η/φ 已废弃，2026-08-11 #38，新 CGL+AGC 参数待定）
- 不同人看到的月光颜色/质感/强度可能不同——取决于他们取出的月光版本
- 月光没有"正确理解方式"——但有些人无法接受这一点（→ 拜月教）

### 心想事成（及其危险）

意识外显效应的另一个后果是：心想事成在一定程度上是可以被实现的。

这**不是**什么好事。

精神病患者们的怪诞思想在这种特殊环境下被具象化了。因为相较于普通人，精神病患者更愿意无条件地相信自身的幻觉。这些思想——乃至患者本身——就是游戏中的敌人以及 NPC。

一个妄想症患者坚信有人要害他，那么在月光下，那个迫害者就会真的出现。一个重度抑郁者觉得自己一文不值，那么这个信念就会以某种形式在他周围"证明"自己。

### 拜月教

月光本质上是无定形的。但"无定形"对某些人来说不可接受——他们需要月光有意义。当足够多的信念聚集，月光就真的开始回应。拜月教不是迷信——它是**自我实现的预言**。

**教众构成：**
- 将月光视为神明的病人和工作人员
- **虔信者**：彻底皈依——月光是神明，需要被崇拜，不信者=亵渎
- **投机者**：发现"信的人越多，月光的'神性'越强"——利用教派服务于自身目的

**核心权力逻辑：**
> 月光 = 神 → 不信的人 = 在削弱神 → 有义务纠正（或消灭）不信者

这意味着拜月教是天然的反派阵营。不是因为他们邪恶——从他们的视角看，他们是唯一看清真相的人。他们的祭礼、仪式、祷词都在真实地增强局部 η——因为信念在月光下本身就是物理力。

详见 [03-敌人与事件 §六](../实体/敌人与事件.md)。

## 敌人来源

敌人设计已基于脑区链路模型全面重写——见 [03-敌人与事件.md](../实体/敌人与事件.md)。核心来源：

- **精神病人**：500 床精神卫生中心的核心群体——幻觉与妄想在月光下具象化
- **思维造物**：精神内容在月光下具象化为物理实体——从简单投影到完整独立意识体
- **医疗人员**：职业压抑在月光下反噬——不是免疫者，是不稳定的稳定者
- **拜月教徒**：将月光取版本为神明的群体——信念赋予他们真实的力量
- **动物**：医院中的动物（或病人想象中的动物）受月光影响

敌人与玩家共用同一套 50 解剖实体 L0-L5 链路体系——敌我同构。敌人的特殊性来自7参数化性格（4 tone baseline + 3 CSTC bias）和髓鞘化基线。

## 战斗逻辑

### 核心原则

既然敌人是基于意识外显效应产生的，那么也可以被它打败——只要**相信**敌人被打败了就可以。

胜利的方式因此有很多种：
- 相信自己有足够的武力，将敌人的血量削减到 0
- 通过说服敌人来达到目的
- 控制自己的认知，强行认为眼前的东西不存在
- 让敌人情绪崩溃

### 敌我同构

- 没有本质上的"敌人"与"玩家"分种
- 所有角色共用同一套底层体系（50 解剖实体 + L0-L5 链路 + 髓鞘化 + SAN/HP）
- 对立更多来自当前关系、视角、病情影响、回忆和误解，而不是固定阵营
- 玩家使用技能（链路激活），NPC 使用 Affordance Competition 实时 salience 选择行动（见 [NPC AI 行为模型](../规则/技能树系统/NPC%20AI%20行为模型.md)）

## SAN 值与血量

- SAN 值代表精神稳定程度
- 血量代表生理存活状态
- 二者在特定情况下可以相互转化：
  - 低 SAN 值时通过自残回复 SAN 值
  - 通过做一些降低 SAN 值的事情回复血量（比如吃怪物肉）

## 叙事原则

### 抽象是核心方法

不还原现实的细节动作，只保留心理影响的结构。因为卡牌的本质源于现实，它们会按照原有的逻辑自动产生联系。

### 角色状态

角色病情直接体现在角色被动能力上（参见 02-角色与面具.md），不再做全局的"精神病 / 非精神病"状态切换。

### 视角与空间

- 开局选择面具搭配的界面，可以表现为玩家观察镜子中戴着面具的自己
- 随身镜子作为自我观察和技能编排的 UI 界面

## 单局 & 单场流程

> **⚠️ 已废弃（2026-07-28）**：旧版"局"和"轮回"框架已被废除。游戏现在为连续世界——没有离散的局边界，没有轮回。完整设计见 [游戏循环](游戏循环.md)。

## 叙事基调

- 争论常常来自于认知差异，而非事实本身
- 认知不是一成不变的东西
- 他人与环境会影响你的认知、情感和行为
- "如果你很难阻止负面的情绪出现在自己身上，那么你仍然可以选择使用什么样的态度去面对它"
- 这是一个关于在无法逃避的困境中，如何选择态度去面对的故事

## 世界观地基：意识包裹

> **2026-08-12 Grilling #41 采纳**：意识包裹（世界=庞大意识的内容）是上述所有设定的统一地基。CGL+AGC 时空数学框架是内容的内容骨架（容器内一致性约束骨架），不描述容器的现象壳。

### 统一解释

意识包裹将六条已有设定统一为同一组公设的推论：

- **空间扭曲**：世界是意识的内容 → 内容止于内容边界 → 没有"外面"是必然的，不是异常的
- **月光三重叠加**：三种取版本同时为真 → 因为不存在可以裁决它们的客观层（容器不可入，D14）
- **意识外显效应**：被包含者各自得到自己的世界（D14）→ 观察=单子对共享基质取版本
- **心想事成**：信念塑造内容是容器的原生操作——患者只是"调制更弱"，与常人同一机制不同参数（敌我同构的延伸）
- **拜月教自洽性**：神明版本不可被科学家证伪，科学家版本不可被神明证伪——D15 使双方对称
- **都灵之马**：死亡引渡者=容器边界职能的人格化。中立无敌=坚不可摧（D13）的机制实例化

### 硬性约束（D15 不可证实铁律）

意识包裹**只作为设计师的统一地基存在**。游戏内任何文本、机制、结局、UI 都不得以事实语态陈述：

- "世界是意识的內容"
- 容器的身份（是什么、是谁）
- 这是第几层
- 任何暗示"真相比三重叠加更底层"的表述

D15 的正确推论：**一切都不可证实**——这是结构性永久悬念（游戏资产），不是可揭示的谜底。

### 与 CGL+AGC 的关系

意识包裹（本体论层）⊃ CGL+AGC（内容骨架层）。意识包裹回答"为什么"，CGL+AGC 负责"怎么一致地运行"。CGL+AGC 的所有公式、参数、边界声明保留不变——它们描述内容运行的规则，不描述容器的体验（现象壳保持桥接公设）。术语说明（2026-08-21 #38）：CGL+AGC 称「内容骨架」，不再称「结构核」——后者专指 #40 意识义（意识的可数学定义部分）。

### 意识包裹 ≠ 机制

意识包裹不产生任何数值参数、不进入任何公式、不调制任何检定。它是本体论层——只回答"为什么"，不回答"多少"。
