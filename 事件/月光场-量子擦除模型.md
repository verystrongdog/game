## 一、双缝干涉实验

### 1.1 基本装置

电子枪一个一个发射电子。每个电子穿过两条狭缝，打到后方屏幕上。屏幕上累积足够多次撞击后：

- **无路径标记时**：屏幕出现明暗交替的干涉条纹——电子表现为**波**
- **有路径标记时**：屏幕出现两个分开的亮斑——电子表现为**粒子**

### 1.2 干涉条纹为何出现

两条缝相当于两个同步的波源。屏幕上的每个点同时接收到来自缝 A 和缝 B 的两个波。

```
路程差 ΔL = |AP − BP|
```

- ΔL = nλ（整数倍波长）→ 波峰对波峰 → **相长干涉**（亮纹）
- ΔL = (n + ½)λ → 波峰对波谷 → **相消干涉**（暗纹）

量子力学层面，波是概率振幅。叠加的数学与经典波完全相同：

```
P = |ψA + ψB|² = |ψA|² + |ψB|² + 2|ψA||ψB|cos(Δφ)
                                              ↑
                                         干涉项
```

单个电子似乎同时走了两条缝，自己和自己干涉。

## 二、路径信息——不扰动但干涉消失

### 2.1 朴素误解

最初认为探测器的光子撞了电子 → 电子被踢偏 → 干涉破坏。这是**不完整的**。

### 2.2 Scully-Drühl 方案（1982）

在每个缝前放一个微波腔，腔内有一个里德伯原子。电子经过缝 A 时，与腔场耦合，激发原子（基态→激发态），同时产生一个微波光子留在腔内。经过缝 B 时，原子不激发。

**关键**：电子与腔场的耦合改变了电子的能量，但这种能量变化对两条缝是**对称的**（相同相位偏移）→ 不引入路径相关的随机相位差。

**但**——原子激发 vs 不激发是两种**可区分的量子态**。这个标记将"走了哪条缝"的信息编码进了原子状态。

**结果**：干涉消失。不是因为电子被扰动——是因为两条路径的波函数与标记态纠缠了：

```
|ψ⟩ = |A⟩|e_A⟩ + |B⟩|e_B⟩

其中 ⟨e_A|e_B⟩ = 0（激发态与基态正交）

P = |ψA|²⟨e_A|e_A⟩ + |ψB|²⟨e_B|e_B⟩ + 2Re[⟨A|B⟩⟨e_A|e_B⟩]
   = |ψA|² + |ψB|² + 2Re[...] × 0
   = |ψA|² + |ψB|²  ← 干涉项被 ⟨e_A|e_B⟩ = 0 杀死
```

**干涉消失 = 路径信息存在。不需要人看——信息在物理上可被读取就足够了。**

## 三、量子擦除

### 3.1 擦除操作

如果标记用的是正交偏振态（|L⟩ vs |R⟩），然后让两条路径的光子都穿过一个 45° 线偏振片：

```
|L⟩ → |45°⟩      |R⟩ → |45°⟩
```

穿过偏振片后，两个标记态不再正交：

```
⟨e_A'|e_B'⟩ = ⟨45°|45°⟩ = 1 ≠ 0
```

干涉项复活。**标记没有被物理删除——两条路径再次变得不可区分。**

### 3.2 核心机制

不是"删掉了信息"——是**让信息的载体不再能被区分**。偏振片把所有标记投影到同一个状态上，从此两条路径的标记在光学上完全一致。

## 四、延迟选择量子擦除

### 4.1 装置

用一对纠缠光子：信号光子走双缝并先打到屏幕上，闲频光子携带路径信息（还在路上）。

### 4.2 关键观察

信号光子**先**到达屏幕。屏幕记录了一堆光点。所有信号光子堆在一起 → 两个鼓包（无干涉，因为闲频光子携带了路径信息）。

**现在**——信号光子已经完成了全部旅程——你再决定是否擦除闲频光子的路径信息。

- 擦除 → 把信号光子按闲频光子"被擦除"做符合计数 → **干涉条纹浮现**
- 不擦除 → 按"路径信息保留"做符合计数 → **两个鼓包**

**同一个信号光子数据。** 没有对信号光子做任何操作——它很早就打到屏幕上了。

### 4.3 深层意义

信号光子的总分布（所有事件堆在一起）永远是两个鼓包——因为路径信息一直存在（在闲频光子中）。

但在这个"无干涉"的总分布里，藏着**两套互相错开半个周期的干涉条纹**（对应两种路径标记态）。擦除操作不改变总分布——它只是让你把其中一套条纹从数据中**挑出来**。

**波和粒子不是光子在经过双缝时"选择"的属性。它们是在你选择如何分析整个纠缠系统时才涌现的。光子从来没有单独存在过——它始终是纠缠系统的一部分。**

## 五、干涉条纹出现和消失意味着什么

| 条纹 | 物理含义 | 信息含义 |
|------|---------|---------|
| **出现** | 叠加态存活——两条路径的振幅相干 | "哪条缝"不可知——宇宙中不存在能回答这个问题的物理记录 |
| **消失** | 叠加态死亡——波函数退相干 | "哪条缝"有答案——答案存在于某处，不管有没有被读取 |

**退相干不是"信息被读取"——是"信息变得可被读取"。** 原子跳到激发态的那一刻，电子就已经只走了一条缝。不需要等任何人来看那个原子。

## 六、映射：月光场 = 45° 偏振片

### 6.1 核心类比

| 量子擦除实验 | 月光场 |
|------------|--------|
| 缝前原子/偏振标记 | 环境——每个分子的碰撞都在"标记"路径信息（标记态：随机的 |L⟩ 或 |R⟩） |
| 标记产生方式 | 环境中亿万次随机的物理相互作用不可控地编码着"路径信息" |
| **45° 偏振片** | **月光场**——把所有标记投影到同一个状态上 |
| 偏振片之前 | 路径可区分（环境标记五花八门）→ 无宏观叠加 → **经典世界** |
| 偏振片之后 | 环境标记被抹平——不可区分 → 干涉恢复 → **宏观叠加态可以存活** |
| 谁决定装不装偏振片 | 场始终在。擦除是场的**默认状态**——由零号病人的初始场激发 |

### 6.2 为什么人类的凝视不被完全擦除

环境标记是随机的（|L⟩ 或 |R⟩，无规律）→ 全部投影到 |45°⟩ → 完全抹平。

人类的信念是有意态的、有确定方向的——不是随机的，不是 |L⟩ 或 |R⟩ 的等概率混合，而是某个确定的角度 |θ⟩。当 |θ⟩ ≠ 45° 时，投影到 |45°⟩ 上有一个残留分量：

```
|θ⟩ → |45°⟩ 的投影 ≠ 原值
残留 = cos(θ − 45°) × |θ⟩ 的幅度
```

残留分量 = 路径信息 = 坍缩。**不是场"选择"不擦除人类标记——是场做同样的投影操作，但确定性标记（信念）被擦除后仍有残留。**

## 七、形式化模型

### 7.1 符号定义

| 符号 | 含义 | 游戏映射 |
|------|------|---------|
| θ | 信念的"角度"——观察者认知偏离环境基线的程度 | 认知确定度。信得越深，θ 离 45° 越远 |
| 45° | 月光场的擦除方向——场固有的"投影轴" | 场的基线——将一切标记投影到这个方向 |
| |θ − 45°| | 信念与环境基线的"偏离度" | 月光下 SAN 稳定度的反映。θ → 45° = SAN 高（更接近环境基线，更不"标记"世界） |
| cos²(θ − 45°) | 擦除后**残留**的分量 | **坍缩强度**——残留越大，路径信息越多，坍缩越强 |
| sin²(θ − 45°) | 被擦除的分量 | 被场消掉的部分——不造成坍缩 |

### 7.2 坍缩强度公式

```
C(observer) = g × cos²(θ − 45°)

g = 观察者耦合常数（个体在场中的耦合深度） [NEW]
θ = 观察者的信念角度 [NEW]
C = 该观察者造成的局部坍缩强度 [NEW]
```

### 7.3 场总强度

```
Φ(location) = Σ_i C_i × f(r_i)

C_i = 观察者 i 的坍缩强度
r_i = 观察者 i 到场中某点的距离
f(r) = 汤川型空间衰减函数: e^(−r/R) / r
R = 场相干半径（凝视的有效距离） [NEW]
```

**信得越深（|θ − 45°| 越大）→ cos²(θ−45°) 越大 → C 越大 → 局部 Φ 越大。**

## 八、推论与已有设定的统一

### 8.1 正常人（SAN ≥ 60）

信念不执着，θ 接近 45° → 残留小 → C 弱 → 坍缩弱。SAN 高时月光影响轻——**吻合现有 SAN 机制**。

### 8.2 精神病人（SAN < 30）

信念固化，θ 远离 45° → 残留大 → C 强 → 坍缩猛烈。幻觉具象化、思维造物产生——**吻合恐慌机制 + 敌人产生规则**。

### 8.3 拜月教徒

集体信念共振 → 所有人的 θ 趋同 → 残留分量相干叠加 → 局部坍缩强度非线性放大。吻合"拜月教徒增强局部月光强度"的已有设定（`实体/敌人与事件.md` §6.3）。

### 8.4 白天（对称相）

场仍在，但人类清醒的理性认知使 θ 天然更接近 45° → C 弱 → 坍缩极弱 → 白天无超自然现象。**吻合"M3 对称相 ≠ 场关闭"**（`决策树.md` M3）。

场相变（对称相↔破缺相）的物理含义：**场的 45° 投影轴是否发生偏移。** 生物节律驱动这个偏移——清醒时轴稳定在 45°，睡眠/月光下轴发生微小的周期性振荡——这个振荡就是"集体生物节律拍频"（`决策树.md` M4）。

### 8.5 三重叠加同时为真

不是三个客观月光。是三群人的 θ 分布不同 → 场的投影轴对三群人产生了三种不同的残留分量 → 三种坍缩结果——物理场/神明/催化媒介。**吻合世界观"三者同时为真"**（`事件/世界观与叙事.md`）。

### 8.6 零号病人

ta 的"不同观察基线"——ta 从未接触外界，没有受过任何环境标记的训练。ta 的 θ 轴天然不在 45°。ta 的初始场 = 第一个非 45° 的投影。这个投影激发了一个有偏向的场——从此场有了一个"擦除轴"——45° 被锁定了。**吻合 M1**（`决策树.md` M1）。

## 十、场相干半径 R — 统一感知与场范围

> 2026-08-03 Grilling #19 决策：R = 察觉半径 = 场相干半径。一个观察者的"感知范围"不是视觉视线——是场耦合范围。场是物理的、各向同性的，不存在"背后"。

### 10.1 统一半径表

| 观察者类型 | R（m） | 含义 |
|----------|--------|------|
| 投影造物 | **3** | 仅创造者的病房内有效——场耦合极浅 |
| 轻度病人 | **5** | 单人病房级——自己床周围 |
| 中度病人 | **8** | 病房 + 门口相邻走廊 |
| 碎片造物 | **8** | 同中度——有限行为集但场耦合尚浅 |
| 重度病人 | **10** | 病房 + 相邻走廊段 |
| 医疗人员 | **10** | 压抑深但耦合不浅 |
| 拜月教徒 | **10** | 单人基线——集体共振后 R 叠加远超此值 |
| 完整体造物 | **12** | 最深的单人耦合——独立意识 = 独立凝视 |
| 动物 | **10** | 本能耦合 |
| 基线 R₀（空房间） | **12** | 零号病人印记——场的最低有效距离 |

此表与 `空间/空间与关卡设计.md` §七 察觉半径表完全一致——R 同时承担"游戏感知距离"和"场物理相干半径"两个角色。

### 10.2 360° 感知——没有"背后"

传统 RPG（如博德之门）中，敌人的感知基于**视线**——有方向性、有背面盲区。潜行 = 绕到背后。

月光场中，感知基于**场耦合**。场是物理场——各向同性、无方向性。一个深度观察者以自身为中心产生一个半径 R 的场域。任何进入这个球体的耦合观察者都会与场源发生相互作用——场不关心你从哪个方向进来。

**这意味着：敌人是 360° 无死角感知的。** 你不能"绕到背后"——你只能"保持在 R 之外"。

**游戏设计影响**：
- 潜行 = 控制距离，不是控制方位。你需要判断敌人的 R 并保持在其外
- L4 读意图仍然有价值——它让你**提前知道**即将进入谁的场域、场源的 g 多深、坍缩方向偏向哪个月光版本
- 走廊巡逻的敌人——它们的 R 球体在走廊中移动。玩家需要观察 R 的覆盖范围，找"间隙"通过
- 无视觉遮挡——墙不阻挡场（场是五维几何的投影，三维空间中的障碍物不屏蔽它）。但墙确实阻挡**移动**——所以你可能感受到墙那边的场但过不去

### 10.3 多人叠加规则

当多个场源的 R 球体重叠时，采用**边界整合**——即场域的并集：

```
两个观察者 A 和 B，场半径 R_A 和 R_B，距离 d：

若 d > R_A + R_B：
  两个独立场域——无重叠——各自独立

若 d ≤ R_A + R_B：
  叠加场域 = A ∪ B（两圆的并集）
  公共区域 = A ∩ B（两圆交集）
  叠加场域面积 = πR_A² + πR_B² − (公共部分面积)
```

叠加区域内的场强度：g_叠加 = g_A + g_B（线性叠加——用最基础的规则，不引入复杂的干涉项）。

**极限情况**：
- d = 0（同一点）→ 叠加场域 = 大圆（半径为 max(R_A, R_B)），g = g_A + g_B
- d = R_A + R_B（刚好相切）→ 无公共区域，两场刚好接触但不重叠
- 三个以上观察者 → 逐对叠加，场域为所有圆的并集

> **⚠️ R 与耦合的关系**：R（场半径）和 g（耦合强度）是两个独立机制。多人叠加时 R 是否随 g 变化——属于耦合机制的讨论范围，此处仅定义空间几何叠加规则。耦合机制独立讨论。
