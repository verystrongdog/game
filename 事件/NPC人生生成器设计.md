> #87「NPC 人生自主起草功能（矩阵驱动）」的正式正典。AI 用社会演化矩阵自主起草 NPC 前半生（出生 → 进入精神卫生中心、遇"月光"异常为止）——不再阻塞等待用户手写纯文本。核心原则：**生成器不定义"正确人生"，只做结构输出 + 约束诊断**（环境=叙事结构输出，非分类资格；校验=诊断系统，非分类器）。

## 一、定位与边界

**生成器回答**：一个 NPC 的前半生（社会土壤 → 人生经历 → 创伤记忆）如何由社会演化矩阵自主起草。

```
矩阵（宏观社会层）→ 人生叙事线 → 环境序列 + 事件序列 → 创伤记忆 → 转化接口 → 疾病
```

**边界**：
- 本设计不定义创伤记忆的量化转化（[创伤记忆转化接口](规则/技能树系统/创伤记忆转化接口.md) 已定义）
- 本设计不定义记忆存储/检索（[记忆内容层](规则/技能树系统/记忆内容层.md) 已定义）
- 本设计不定义疾病内容（`pathology_edges.json` 已定义）
- 素材库生产批次规划（P1 普通 NPC 生态 → P4 Boss 生命史）见 [剧情系统设计.md](剧情系统设计.md) §4.4

**理论支撑**：凯博文《苦痛和疾病的社会根源》——社会根源 = 社会结构 × 人际网络；家庭支持缺失/关系损伤是常见诱因通道。

> **修订注（2026-09-06，#114/#116 裁定）**：§一 定位中"生成器不定义正确人生、疾病从经历涌现"为生成器本体原则；**患者生产层现按"病种优先的目标实例化"执行**——目标 slot =（病种 d × 六轴缺口 × 自由维约束），起草满足 d 的必要原子证据、排除原子由替代解释支撑，资格回放门后定稿。配额/病房构成 = 批次设计输入（非涌现输出）。本修订适用范围 = 患者生产层；资格核验层（~19 病解锁）保持证据中立，两层隔离铁律见决策记录。涌现原则保留于：自由维靶内多样性工艺、六轴多样性门禁（§4.6）、验证脚本（MVP 类）、未来范式升级预留。轨迹演化模型（#116 原方向）暂停，恢复条件 = 资源到位或出现可信世界表示（[决策记录](../.scratch/grilling-116-disease-gen-evolution/决策记录-平凡实例化.md)）。

## 二、因果源流

```
社会演化矩阵（宏观：政策/经济/教育/医疗 × 时间/地域，见 #89 社会演化矩阵）
    ↓
Soil Sampler（土壤采样）
    ↓
叙事约束（出生年 / 生命周期阶段 / 社会事件等）
    ↓
Event Generator（按已定义叙事约束生成人生叙事线）
    ↓
人生叙事线
    ├────→ 环境序列 ──→ 暴露量 T ──→ 事件生成机会
    └────→ 事件序列 ──→ Trauma Memory Builder ──→ Transformer
```

**叙事驱动**：环境与事件都是人生叙事线的投影（同源不互相定义）——环境不因产生事件而存在，事件不因环境存在而获资格。

## 三、本体原则（三条不变量 + 防黑箱）

### 3.1 三条不变量（锁死）

1. **环境不是分类器结果，而是 Event Generator 生成的人生叙事线的结构输出**——"环境存在"由人生叙事建模为持续性生活场域，不由时长/频率/事件数量阈值决定
2. **环境存在性 ≠ 暴露量 T ≠ 塑造结果**——T ↑ 最多 ⇒ 潜在事件生成机会 ↑；禁止 T ↑ ⇒ 创伤↑/事件严重度↑/疾病概率↑（塑造由个体化机制 β/k/g 决定）
3. **不存在 T_min / 环境资格判定 / is_fixed_environment() 类独立资格机制**——防回归约束：未来提议加回资格判定的答案是"不是"

### 3.2 防黑箱约束

"人生叙事"不是独立的本体实体或判定器，而是 Event Generator 按已定义叙事约束生成的**中间产物**——叙事驱动描述生成关系，不引入"叙事判定器"。

### 3.3 环境本体定义

> 环境 = NPC 人生叙事中被建模为持续性生活场域的结构性经历。存在性不由持续时长、互动频率或事件数量的客观阈值决定；这些量属于环境的暴露属性，而非环境资格条件。

环境内容维度（关系结构内容，保留）：家庭结构 / 亲密关系 / 代际冲突 / 关系损伤 + 家庭外场域。

### 4.2 Q2 — 参数选择规则：宏观确定锚定 + 微观随机采样（✅ 2026-09-01）

```
宏观社会事件（时代烙印）── 确定性锚定
  1977 恢复高考 / 1997 下岗潮 / 2003 非典 / 2008 金融危机……
  由出生年×地域唯一确定 = 社会演化矩阵的直接投影（人人共享时代背景）
        ↓
微观人际事件（个体遭遇）── 随机采样
  同样经历下岗潮：A 家庭冲突加剧 / B 染上酒瘾 / C 振作再就业
  从「事件类型 × 场所」池按概率采样（创伤记忆转化接口 §3.2.1 十类事件为池）
```

满足：①矩阵时代真实性 ②M5 个体多样性 ③确定性偏好（同 seed 同 NPC，复用 #71 DeterministicRng）。

### 4.3 Q3 — 因果链强度（✅ 2026-08-21 + 2026-09-01 世界观裁决）

- 创伤 = 唯一触发路径（无创伤记忆不发病）
- 遗传/先天 = β(t) 阈值调制（个体易感性接口，非致病路径）
- 韧性双机制：累积期抵抗 = k（应对/缓冲），恢复期 = #90 降档
- 详见 [创伤记忆转化接口](规则/技能树系统/创伤记忆转化接口.md) §一

### 4.4 Q4 — 模板化边界（✅ 2026-09-01）

| 层级 | 允许复用 | 约束 |
|------|---------|------|
| **类型学** | 环境类型、事件类型、关系类型 | 作为生成词汇，不代表具体人生 |
| **生成规则/结构模式** | 生命周期映射、事件约束、关系生成规则 | 可复用，但必须产生新的实例 |
| **人生实例** | ❌ 不作为模板复用 | 每个 NPC 独立生成时间线、事件、关系及其组合 |

**正典措辞（锁死）**：类型学与生成规则允许复用；具体人生实例必须独立生成。M5 所禁止的是 NPC 级完整人生模板的复用，而非环境、事件、关系等类型学或生成结构的复用。素材池用于提供实例生成参考，不得作为完整人生模板直接实例化。

**防回归约束**：相同类型、结构或事件在不同 NPC 中重复出现，不构成模板复制（"同构 ≠ 模板复制"）；只有将既有 NPC 的具体人生轨迹作为整体成品复用于另一 NPC，才构成违反 M5 的模板化。禁止用"出现相同事件类型"作为模板化判据。

**素材池定性**：病案素材 → 提供可能的事件/关系/病程形态 → 生成规则 → 结合当前 NPC → 新实例；禁止"素材 → 复制 → NPC"。

### 4.5 Q5 — 审阅流程（✅ 2026-09-01）

**交付形态 = C**：结构化人生骨架（时间线/事件/关系）+ 简版叙事视图。**同一份草稿的两个视图，不是两个独立事实源**——结构化骨架 = 可计算事实载体，叙事 = 人类可读呈现；改任一边 = 改同一事实。

**迭代规则 = 锚点 + 依赖边界传播 + 局部重生成**：用户修改 → 锚点 → 依赖传播（改父母离异 → 家庭环境 → 相关事件 → 创伤记忆 → 疾病派生）→ 局部重生成 → 保留未受影响部分。

**用户修改优先于 AI 生成规则**：用户版本 = 当前事实；AI 不得为"保持矩阵统计合理"把用户改回去。

**定稿入 M2 双轨**：用户定稿文本 → 轨道一（AI 不再改写）；结构化数据 → 轨道二 `.gen.json`。

**M2 澄清**：轨道一「AI 不改写」指**定稿后**不改写；AI 首次生成阶段可以作为作者（起草人生）。

### 4.6 Q6 — 生成质量校验：三层门禁（✅ 2026-09-01，终题）

```
生成批次
   ↓
① 个体合法性（硬性，个体级）：矩阵/出生年/年龄/地域/社会事件窗口硬约束
   违反 → FAIL（约束违反，非审美判断）
   ↓
② 批次多样性（批次级）：检测事件/疾病/时间线长度/事件密度/关系数量的异常集中或模式塌缩
   异常 → WARNING / 重生成 / 人工审阅（不要求服从预设唯一分布）
   ↓
③ 素材形态（软性）：五本病案 = 现实形态参考，非规范分布非生成目标
   偏离 → WARNING / 人工审阅（"与五本书不像"不判 FAIL）
   ↓
交付审阅
```

**关键原则**：
- 质量校验**不是分类器**——是生成后诊断系统（发现约束违反/批次塌缩/形态异常），不重演资格判定问题
- 阈值区分：资格阈值已废弃；**质量门禁阈值允许存在**，但第一版不拍数值——先锁指标/统计口径/失败警告语义，具体阈值待批次可观测后标定

#### 第②层操作化：六轴多样性诊断（2026-09-03 #89-D20/D21 落地，第一批指标锁）

> 第②层"批次多样性"从抽象概念固化为可检查指标。**指标锁、数值不锁**（同 Q6 原则，待批次观测后标定）。六轴定义详见 `.scratch/grilling-89-npc-material/叙事多样化维度定义.md`。

**六轴（批次级统计口径）**：

| 轴 | 指标 | 警告语义（第一版） |
|----|------|-------------------|
| 轴1 入院方式 | 被动危机 / 家属发现 / 强制 / 自愿 / 求说法 的分布 | 单一方式占比异常高 → WARNING |
| 轴2 入院功能状态 | 严重失能 / 慢性恶化 / 功能完好 | 全为"严重失能" → WARNING |
| 轴3 叙事功能 | 受难者 / 发光者 / 否认对抗者 / 扮演利用者 / 对照系 | 全为"受难者" → WARNING |
| 轴4 弧线结构 | 高光→跌落 / 平缓→晚变 / 慢性并行 / 低开高走 / 无高光 | 高光→跌落占比异常 → WARNING |
| 轴5 创伤通道 | 十类事件类型的使用分布 | 经济/丧失占比异常、未用通道 ≥2 类 → WARNING |
| 轴6 亮度光谱 | 黯淡 / 明亮 / 中性 | 全"黯淡" → WARNING |

**防回归约束**：新增患者须命中 ≥1 轴缺口（`叙事多样化维度定义.md` §三 约束清单）；存量患者不强改（已达标），差异靠新增稀释。

**与资格门关系**：六轴多样性是**生成后诊断**（Q6 语义），不参与资格判定（#113 Eligibility ⊥ 生成质量）——两套系统正交。

## 五、A′-Generator 架构

**定位**：生成器流水线的**静态边界设计**（非"插件系统设计"——插件化是未来自然获得的能力，不是当前目标）。

### 5.1 阶段职责隔离（5 阶段，暂不锁接口形状）

| 阶段 | 职责 | 输入 | 输出 |
|------|------|------|------|
| Soil Sampler | 土壤/宏观输入采样 | 社会演化矩阵 | 叙事约束 |
| Event Generator | 人生叙事线生成 | 叙事约束 | 环境序列 + 事件序列 |
| Memory Builder | 创伤记忆构造 | 事件序列 | 创伤记忆（ΔI=k×A → L） |
| Transformer | 转化 | 创伤记忆 | 疾病档位（创伤记忆转化接口 §3.1-§3.4） |
| Artifact Deriver | 产物派生 | 结构化数据 | .gen.json + 简版叙事视图 |

### 5.2 静态 seam 与失败语义

- **静态 seam**：模块间只依赖契约（输入/输出），不依赖内部实现；数据产物（JSON）与功能模块分离；接口形状留到实现批次
- **失败语义三层**（WARNING ≠ FAIL ≠ fail-fast，作用于不同时相）：
  - 开发期 schema 演化：增字段 → WARNING / 删字段 → ERROR（S2+ 既有）
  - 生成任务输入验证：契约不满足 → FAIL
  - 静态模块装配：依赖/版本/契约不满足 → fail-fast（#111 精神移植）
- **fallback 是生成策略，不是模块状态**：input_source ∈ {canonical, fallback}；兜底「慢性冲突/高压」仅限开发/演示模式；正式生成缺失 → FAIL
- **严格排除**：运行时热插拔 / HMR / 通用模块状态机 / registry / wrapper 层
- **铁律**：错误在最近契约边界被识别——不伪装成合法数据向下游传播

### 5.3 与 #111 的关系

#111 = 通用模块化原则（静态契约/seam/装配期验证/fail-fast）→ 引擎与 #87 生成器各自落地；#87 不发明"生成器插件框架"。

| **负荷×声明相关性（MVP 发现 2026-09-03，第 2 归因）** | #87 Q3 + #113 证据域交互 | **新增待决**——MVP 跨 seed 确认 60-69% 患者"病理化(L≥1.0)但五病全 INELIGIBLE/UNDETERMINED"。主因：创伤负荷(L) 与 clinical_history 声明**完全独立采样** → 大量"负荷够但声明无发作史(MISSING/0)"错配。真实世界"负荷高的患者通常有过发作"（否则不病理化），但 #113 让两者正交、MVP 放大错配。**规则候选**：声明概率随 L 提升（负荷高→DEPRESSIVE 等更可能=1），或声明含"负荷→发作史"的临床推理层——需权衡：提升相关性 vs 保持声明独立（#113 Q2-3 选 A 的边界） |
| **资格池结构偏差（MVP 发现 2026-09-03，第 3 归因，跨 #87/#113）** | 生成规则 + 资格系统 | **新增待决**——R=1000：MDD 占全部主病 45.5%（每 100 可判定患者 45 个 MDD）。根因：资格池仅 5 病 + **MDD 候选面最宽**（在 5 类事件候选集出现 5 次 vs 其他病 1-2 次）→ 召回最多→主病最多。**规则候选**：①~19 病解锁扩池（#113 批次）②候选面权重修正（防 MDD 结构性霸榜）③主病选择改 N/F/R sim（MVP 暂用 L_agg 最高，MDD 共同终点天然占优）——三者需联动裁决 |
