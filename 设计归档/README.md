# 设计归档 — grilling 决策记录与工作稿

> 各轮 grilling 的**源记录**：决策记录、任务计划、工作稿、审查报告。它们是 [决策树](../docs/%E5%86%B3%E7%AD%96%E6%A0%91/README.md) 各条目的第一手依据。

> **性质**：归档内容，非活跃正典。**活跃文档不得把本目录当作设计依据**——要引用结论请引用 `规则/` `实体/` 等正典，或引用决策树对应条目。本目录只回答「当时为什么这么定」。
>
> **来源**：2026-09-12 仓库重构 Phase 2 从 `.scratch/` 迁入。迁入范围 = 被任何活跃文档、代码或决策树引用的文件；未被引用的过程残留随 `.scratch/` 一并移出版本控制。

## 一、结构与命名

按原 `.scratch/<slug>/` 的 slug 保留子目录结构：

```
设计归档/grilling/
├── grilling-<NN>-<话题>/        每轮 grilling：决策记录 / task-plan / 草案
│   └── 决策记录.md              该轮结论正本
├── csharp-<子系统>/             引擎实施批次的过程记录（规格正本在 规格/引擎/）
├── review-plan-design/          review-plan 机制的设计与审查
├── review-trace-*.md            逐次审查留痕
├── _根级/                       原 .scratch/ 根目录下的散落文件
└── backup-windows-only-2026-09-12/  Windows 侧独占文件止损备份
```

## 二、内容索引

| 类别 | 子目录 | 说明 |
|------|--------|------|
| 早期设计轮次 | `grilling-24` ~ `grilling-40` | 引擎数据关系、校准、意识讨论等 |
| P 系列实施批次 | `grilling-69` ~ `grilling-90` | 外部刺激 / 引擎路线图 / 情境 / NPC / 素材 / 记忆存储 |
| 后期专题 | `grilling-95` ~ `grilling-126` | estimator 有效性、插件化、疾病生成、Unity 沙盘、玫瑰实验 |
| 疾病资格核验 | `grilling-113` `grilling-116` | 19 病解锁的裁决点与收尾记录 |
| 引擎实施批次 | `csharp-*` | 各子系统的 impl/issues 记录 |
| review 机制 | `review-plan-design` `review-trace-*` `task-check-*` | 审查流程定义与留痕 |

**每轮的关键产物**：`决策记录.md`（结论）、`task-plan.md`（执行计划）、`*审查报告.md` / `*实现说明.md`（过程结论）。

## 三、与决策树的关系

- **决策记录.md** = 该轮 grilling 的原始结论正本，包含完整追问过程与备选方案。
- **[docs/决策树/](../docs/%E5%86%B3%E7%AD%96%E6%A0%91/README.md)** = 跨轮次的**索引与分叉记录**，每条的「详见」指向本目录对应文件。
- 引用格式：`决策树: [Grilling] <话题> §第N题 → 结论`（决策树条目）→ 决策记录（本目录，第一手）。
