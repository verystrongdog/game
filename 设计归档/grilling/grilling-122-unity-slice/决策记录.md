# Grilling #122 — Unity 呈现沙盘：决策记录

> Issue: [#122](https://github.com/verystrongdog/game/issues/122) | 维度: 呈现 + 管线 | 状态: ✅ 决策闭合，实施待本地验证（沙箱激活受阻，改本机验证）

## 背景与沿革

- 用户启动"呈现相关的工作"→ 原定话题「状态面板细部规格」；用户提出**依赖顾虑**：无可控角色可调试前，纸面 UI 规格不可行（"unity界面上能看到的模型，给它现在能够实施的指令它能做出相应动作"）。
- 澄清后确认"角色模型"= **可运行载体**（非受控角色实例语义）→ 载体选择 **Unity 工程骨架 + 脚本**（用户本地 Editor 验证）。
- 过程中发现 Unity 新版 CLI（`unity`，1.0.0-beta.8）可 headless 管理/驱动 Editor（[unity-cli 参考](https://docs.unity.com/en-us/unity-cli/unity-cli-reference)）；本沙箱下载 Unity 6000.0.83f1（≈4.2GB 下载/8GB 安装）成功，但 **Personal 许可激活受阻**：容器无 Secret Service 钥匙串 → unity-cli OAuth 令牌无法持久化（"Token slot missing or corrupt"）→ `license activate --personal` 强制要求已登录会话 → 死锁（无 root 装 gnome-keyring；deb 解包依赖链缺失 libgcr-base）。
- **法律核查**（2026-06-30 ToS §17.2 AI-agent 条款）：本地 Editor+项目文件工作流属官方澄清范围外（不触发）；Personal 资格/命令行激活路径合规性已记录。
- **裁决**：放弃沙箱内 Unity 运行验证 → 用户本机（Windows）已验证 unity-cli 登录成功 → 验证环境 = 用户本机。
