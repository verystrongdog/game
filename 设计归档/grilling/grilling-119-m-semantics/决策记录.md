# Grilling #119 决策记录 — m（髓鞘化）语义层定案

> 用户质疑髓鞘化的物理基础能否支撑技能成长体系，经事实核查（废弃的是 364 链路数据，m 已重锚三体 CC+PP 888 边）+ 逐题 + 红队攻击，收敛为 m 语义层定案。

## 定案摘要

| 决策 | 内容 |
|------|------|
| Q1 | m = 复合成熟度参数（髓鞘=科学锚标签）：整合髓鞘同步效率 ⊕ 突触权重 ⊕ 自动化程度；三写（使用/巩固/突破）三读（强度 W∝m_mean / 效率 sigmoid(m) / 负反馈 f(m)）；不变量 = 公式不拆解 m 成分 |
| Q2 | 0.8→1.0 = 自动化跃迁（受控→自动，双加工/ACT-R）；三型 = 三种自动化路径；叙事 = 催化剂（游戏化压缩） |
| Q3 | 天花板三因子 ⊥ m（sync 乘子不进 ceiling）；速查表术语修正（髓鞘化同步 = m 效率读出，非第 4 天花板因子） |
| P1 | m 内写入 = {使用Δm, 增强+, 突破}；m 外状态 = {标记倍率位, 聚焦倍率}（不属 m 成分） |
| P2 | m（含 1.0）不改变激活条件（情境自动激活/聚焦门控照旧） |
| P3 | 日常理解（增强 ≤0.3）≠ 叙事质变（突破 0.8→1.0，存在性重组织）；突破非均匀适用所有链路 |

## 关键事实（Step 0 核查）

- 废弃 = 364 pairwise 链路（#26）；m 载体 = 三体 CC+PP 888 边（#73 D1）
- 消费：调制层 sigmoid(m) sync 乘子（Pajevic 2023）+ 动力学层 W 权重因子 m_mean / Gurney c_loop（运行时 §九）
- 增长：Δm = base(L) × (1−sigmoid(m,0.45,10)) × g(n) × 标记倍率（核心机制 §1.3）；0.8→1.0 突破来自叙事节点（脑功能层级 §12.1）
- 阶段表即"受控→自动"轴：初学→熟练→专精→精通→完全自动化

## 红队攻击记录

- 攻击 P1 成立：标记位（#73 D4）是 m 外状态，Q1 原表述误并入 m
- 攻击 P2 成立：需显式声明 m 不改激活门控
- 攻击 P3 半成立：增强上限 0.3 vs 突破 0.8-1.0 的通道分界需声明
- 攻击未破：档位表=示例；病理 m=病态自动化；自动化不衰退

## 推迟

- 关键突破触发规则（叙事节点/三型×链路绑定/m 涨幅）→ 下一 grilling
