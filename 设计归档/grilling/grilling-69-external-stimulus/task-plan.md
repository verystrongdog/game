## 一、背景与动机

内部动力学已完整锚定（WC 皮层动力学 69 functional_id、脑干广播 4 tone、CSTC 门控，见 [运行时状态模型](../../../%E8%A7%84%E5%88%99/%E6%8A%80%E8%83%BD%E6%A0%91%E7%B3%BB%E7%BB%9F/%E8%BF%90%E8%A1%8C%E6%97%B6%E7%8A%B6%E6%80%81%E6%A8%A1%E5%9E%8B.md)）。但「外界刺激」此前只有机制骨架（`s = W_sensory × α`），来源覆盖仅 14 个战斗对抗事件（[运行时状态模型 §4.5](../../../%E8%A7%84%E5%88%99/%E6%8A%80%E8%83%BD%E6%A0%91%E7%B3%BB%E7%BB%9F/%E8%BF%90%E8%A1%8C%E6%97%B6%E7%8A%B6%E6%80%81%E6%A8%A1%E5%9E%8B.md)）。非战斗/环境/世界刺激未定义。

**本次目标**：定义「神经系统之外、世界之内」有哪些东西能成为 s(t) 入口，并为非战斗来源补齐 α pattern 机制。不推翻 WC 方程，只在 s 项内部细化 + 增加月光场通道 + 扩展模态。

**边界（本地约定）**：任务目标/承诺的「持续压力」认定为内部认知态，排除出本次 scope（见 §十推迟清单）。

## 二、核心架构

### 2.1 总输入公式（确认版）

WC 皮层动力学总输入在 [运行时状态模型 §4.1](../../../%E8%A7%84%E5%88%99/%E6%8A%80%E8%83%BD%E6%A0%91%E7%B3%BB%E7%BB%9F/%E8%BF%90%E8%A1%8C%E6%97%B6%E7%8A%B6%E6%80%81%E6%A8%A1%E5%9E%8B.md) 基础上扩展：

```
(P1) h_j(t) = Σ_k W_jk·a_k(t) + b_j(t) + s_j(t) + m_field_j(t)
      ↑其             ↑已有          ↑已有     ↑本次新增
```

其中 s_j(t) 拆为两层：

```
(P2) s_j(t) = s_事件_j(t) + s_env_j(t)
```

- `s_事件_j`：战斗/事件一次性脉冲（现有 14 个 α pattern，走 `s = W_sensory × α`，[运行时状态模型 §4.5](../../../%E8%A7%84%E5%88%99/%E6%8A%80%E8%83%BD%E6%A0%91%E7%B3%BB%E7%BB%9F/%E8%BF%90%E8%A1%8C%E6%97%B6%E7%8A%B6%E6%80%81%E6%A8%A1%E5%9E%8B.md)）
- `s_env_j`：**环境基调** [NEW]——当前空间/场景的真实物理存在（房间气味/温度/光线/内容物），经同一 `W_sensory × α` 展开，环境内恒定
- `m_field_j`：**月光场通道** [NEW]——独立的 CGL+AGC 相干场，承载观察者效应/幻觉具象化/空间扭曲，不进感官模态

### 2.2 世界观定性（关键）

**环境基调 与 月光场 是两类独立输入**：

| 通道 | 来源 | 本质 | 进神经方式 |
|------|------|------|-----------|
| **环境基调 s_env** | 局部空间（房间气味/温度/光线） | 真实独立物理存在，非月光产物 | 感官模态 `W_sensory × α_env` |
| **月光场 m_field** | 月亮本身（CGL+AGC 相干场） | 世界级场源，调制环境基调 | 独立第三通道（非感官模态） |

月光场对环境基调做**调制**，不是来源。月球不新增感官模态。

### 2.3 刷新时序（确认版）

- **事件脉冲 s_事件**：在战斗/事件发生节点注入，一次性后归零（现有语义不变）
- **环境基调 s_env**：在「环境空间切换」节点刷新为稳定值，本环境内恒定
- **月光场 m_field**：在「空间切换 + 月相/昼夜推进」节点刷新，反映当前空间月光密度

### 2.4 输入源分类（四来源域）

外界刺激按来源域分层（[新增] 本次 grilling D1）：

| 来源域 | 翻译 | 例 | 进 s(t) 方式 |
|--------|------|----|-------------|
| 战斗对抗 | 敌我回合内动作结果 | 物理攻击命中/被击中/倒下 | 事件脉冲 s_事件（已有 14 α） |
| 环境·世界 | 场景空间物理存在 | 房间气味/温度/光线/内容物 | 环境基调 s_env（新增）|
| 社会·叙事 | NPC 行为/对话/线索 | 对话/委托/观察读出/Boss 命名 | 事件脉冲（复用语言+社会模态）|
| 内感受·生理 | 身体内部生理 | 药效/心跳/SAN恐慌/幻觉 | 见 §四（复用痛觉/躯体；药效=状态机制）|

## 五、α pattern 数据化

### 5.1 动机

`EventProcessor.cs` 当前硬编码 α pattern 为定长数组 `new[] {1,0,1,0,0,0}`（6 元素，见 [EventProcessor.cs](../../../src/YouAreNotTheFish.Core/Engine/EventProcessor.cs) §Emit）。模态扩展 + 后续新增刺激源会把数组改成 8/更多元素，**每次扩展都动引擎核心代码**且易错位。

### 5.2 决策 [NEW]

α pattern 迁移至新数据文件 `data/connectivity/alpha_patterns.json`，配置驱动。此后新增模态/事件/刺激源 = 只改 JSON，不动引擎核心代码。

### 5.3 目标数据契约

```json
{
  "schema": "alpha_patterns",
  "version": 1,
  "modalities": ["visual","auditory","somatosensory","pain","social_cognition","language_cognition","olfactory","thermoreception"],
  "events": {
    "A1": {"trigger": "物理攻击命中", "pattern": [1,0,1,0,0,0,0,0], "m_alpha": 1.0},
    "B4": {"trigger": "被精神攻击", "pattern": [0,0,0,1,1,1,0,0], "m_alpha": "m_delta"},
    "...": "..."
  }
}
```

参数说明：
- `pattern` 长度 = `modalities` 长度 = 8 [NEW]
- 现有战斗事件 pattern 迁移：原 6 位 + 末 2 位补 0（嗅觉/热觉战斗事件默认 0，除非设计明确需要）
- `m_alpha` 沿用现有语义：A 类 = `1.0`，B/C/D 类 = `m_delta`（见 [运行时状态模型 §4.5](../../../%E8%A7%84%E5%88%99/%E6%8A%80%E8%83%BD%E6%A0%91%E7%B3%BB%E7%BB%9F/%E8%BF%90%E8%A1%8C%E6%97%B6%E7%8A%B6%E6%80%81%E6%A8%A1%E5%9E%8B.md)）
