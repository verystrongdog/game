## 核心决策

- **Step 0 边界**：#101 定 R 结构/语义（落点 fid 集合、权重结构、数学约束）；数值（r、α_s）归 #35。「怎么加权」的形式由 #101 定，「权重数值」由 #35 定。不重定义 m_field 接口、不修改 q̂/g 职责、不承担 E_c/E_th 校准。
- **Q1 落点**：S_core = 12 节点 = L1∪L2 ∩ W活跃（L1 4：Amygdala/Hippocampus×2/Parahippocampal；L2 8：ACC×3/Insula/OFC/PCC/Isthmus/TemporalPole）。排除 L0/L3/W排除节点。硬约束：落点 ⊆ W活跃。S_ext 暂不纳入。
- **Q2 结构**：R = Σ_s α_s·v_s^norm；互斥分区 + 语义内归一化 + 独立缩放；扩展性不变量（新增语义不改旧语义分量 ⇒ 不触发重校准）；PLACEHOLDER 对齐 #103（未校准 α_s 禁入正式数值消费）。
- **Q3 通道**：m_field = 独立输入源；三通道输入层加法共存；禁 s_env×m_field 交互项；「放大」降级系统响应层描述。
- **Q4 权重**：主辅两档（主 4 L1 / 辅 8 L2，档内等分）：v_s^norm(j) = r/(4r+8)[主] 或 1/(4r+8)[辅]；r 归 #35；r=1 仅 PLACEHOLDER。
- **Q5 固定**：R_i ≡ R ∀ i；职责正交化（空间→q̂、状态→g、月相→q̂基线、落点→R）；个体差异不走 R。
- **Q6 符号**：R[j] ≥ 0（输入层性质）；当前硬稀疏 12；长期不变量 supp(R) ⊆ W_active；12 非永久上限。
- **Q7 独立**：与情境系统无运行时协调；情境选择不读 m_field；情境扩展走情境系统侧。
