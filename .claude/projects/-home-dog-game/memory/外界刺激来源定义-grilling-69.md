# Grilling #69 — 外界刺激来源定义

> Grilling #69 (issue #69, 2026-08-16) 确立神经系统「外界刺激」的来源分类学。内部动力学完整后暴露的缺口：s(t) 此前仅覆盖战斗对抗事件。本文记录 13 项共识（11 决策 + 2 修正），作为后续实施的 memory。

## 核心架构

```
(P1) h_j(t) = Σ_k W_jk·a_k(t) + b_j(t) + s_j(t) + m_field_j(t)
(P2) s_j(t) = s_事件_j(t) + s_env_j(t)
```

- **s_事件**：战斗/事件一次性脉冲（现有 14 战斗 α pattern，走 W_sensory × α）
- **s_env 环境基调**：持续场形态，当前空间内容呈现（气味/温度/光线），经 W_sensory × α_env，环境内恒定（#101 措辞修正：来源=共享基质经观察者取版本，非月光产生）
- **m_field 月光场**：独立第三通道，承载观察者效应/幻觉/空间扭曲，非感官模态

## 术语（已入库 term_registry 2026-08-16）

- **m_field**：月光场通道——独立第三输入通道，CGL+AGC 相干场的神经落点
- **s_env 环境基调**：持续场形态的 s(t) 分量，空间内容呈现（#101 措辞修正）
- **嗅觉 olfactory / 热觉 thermoreception**：新增感官模态（W_sensory 第 7/8 列）
- **α_env**：环境基调模态强度向量 [0,1]^8
- s(t)/W_sensory 定义已由 6 模态更新为 8 模态

## 重要边界

- **环境基调 ≠ 月光场**：环境基调是空间内容呈现（局部感官，来源=共享基质经观察者取版本），月光场是独立世界级场（调制呈现强度，非内容来源）。曾有术语碰撞——"场"在项目里专指月光场(CGL+AGC)，环境持续场改名「环境基调」避开。（#101 措辞修正）
- **m_field ≠ 废弃月光场 v2(η/g_0)**：是神经输入通道概念，非复活旧标量场公式。新参数集待 Grilling #38/#35。
- **不实施数据/代码改动**：本次仅确立设计决策 + 文档/注册表同步。W_sensory 扩列、EventProcessor 重构属实施任务（见 task-plan T1-T9）。
