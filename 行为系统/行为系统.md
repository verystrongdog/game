# 共情→利他通路 — 加第七种驱动？

> 聚焦待解决问题 #2：共情在行为层没有对应的执行器。

---

## 一、问题的精确表述

共情在情绪模型里被定义为 "传递其他情绪的管道"，PAD 坐标 ≈ (0.15, 0.20, 0.05)，推力接近零。

在当前行为模型里，这意味着：一个角色高度共情到他人的痛苦 → 自己的 PAD 几乎不变 → 行为系统几乎不产生反应。

但现实中，共情是最强的行为驱动力之一。一个母亲看到孩子溺水——她不是 "经过规范性评估后认为应该跳下去"，也不是 "计算了不救的惩罚和救的奖励"。她已经在跳了。

这不是任何一种现有驱动的语义：

| 现有驱动 | 为什么不对 |
|---------|-----------|
| 反射 | 反射是回避（远离威胁源），不是趋近（冲向危险中的他人） |
| 惩罚机制 | "不救的话我会内疚"。因果链太长——行为在先，内疚预期在后。母亲是先跳了，不是先算了一遍内疚成本 |
| 奖励机制 | "救人让我开心"。救人当然可能伴随满足感，但解释不了代价极大的利他——你跳进冰水时不是在想"这会让我开心" |
| 道德驱动 | "我应该救"。接近，但道德评估是慢的——规范性推演需要2-3回合，而母亲已经在第0回合跳了 |
| 文化习俗 | "这种情况下就应该救人"。同样太慢，且太冷——照护行为不是照本宣科 |
| 价值驱动 | "救人高于我自己的安全"。接近，但价值驱动的典型场景是文天祥式的抽象信念坚守，不是对具体脆弱个体的即时反应 |

**共情在行为层需要一个执行器。** 这个执行器的特征是：快速（接近反射速度）、趋近（而非回避）、自动（不经过推论）、指向他人而非自身。

---

## 二、方案 A：加第七种驱动——照护驱动 (Caregiving Drive)

神经基础：催产素-多巴胺通路，区别于奖励机制（多巴胺-伏隔核）、道德驱动（前额叶规范性推理）、反射（杏仁核-PAG）。

ARCH 模型里对应的原型是 **Theromata**——对脆弱对象的保护/安抚冲动。从单细胞生物到哺乳动物都存在：趋近脆弱同类、给予保护。

### 计算定义

```
照护驱动 (Caregiving)

触发源:
  不是自身的 PAD——而是被共情传递过来的**他人 PAD**。
  
  g_care = σ( w_vuln · Vulnerability_signal + w_attach · Attachment_strength - θ_care )
  
  其中:
    Vulnerability_signal = 认知模块(知觉+知识表征)判定的 "对象 X 需要帮助" 的信号强度
    Attachment_strength = 与该对象的情感纽带强度 (0=陌生人, 1=至亲)
    θ_care 的基线受催产素相关参数影响 (个体差异, 可被药物/病情调制)
    
    w_vuln = 2.5, w_attach = 1.5, θ_care = 0.3

PAD 敏感度:  特殊的——读取的是**被共情的他人 PAD**，而非自身 PAD:
  他人 P 越低 (越痛苦) → g_care 越强
  不读取自身的 P, A, D —— 所以你可以自己也在恐惧中 (自身 P<0, A>0, D<0) 但仍然激活照护

认知前置:
  需要: 知觉与注意 (注意到他人) + 知识表征 (归为 "需要帮助的")
  不需要: 推理/规范性评估 (照护在评估之前发生)

行为拉力 s:  s_valence = +1.0 (强烈趋近需要帮助的对象),
              s_intensity = 0.9,
              s_autonomy = +0.7 (主动——"我要去")

惯性与时程:
  上升半衰期: 0.3 回合 —— 接近反射速度 (看到→已经跳了)
  衰减半衰期: 随 Vulnerability_signal 消退 (对方安全后消退)
  
  特殊: 照护行为完成 (对方安全) → g_care 快速衰减 (不需要持续的照护激活)
        照护行为被阻止 (无法接近) → g_care 持续高激活 + Arousal 上升 (挫败)

可被压制条件:
  自身 D < -0.7 (完全失控状态下无力照护他人)
  Attachment_strength ≈ 0 (对陌生人的照护需要道德/价值驱动补充)
  共情疲劳: 连续多次照护激活后, θ_care 暂时 ↑ (burnout)

与其他驱动的互动:
  照护 + 恐惧 (自身) → 冲向危险 ("我怕但我必须去")
  照护 + 价值驱动 → 照护行为被赋予 "这不只是救一个人, 这是救我所信" 的叙事
  照护被惩罚机制压制 → 想帮但不敢 (旁观者效应—— "我会不会反而受伤?")
  照护 + 道德驱动 → 照护被规范性框架合理化 ("我这样做是对的")
```

### 优点

- 干净地解释 "母爱/利他/舍身救人" 的行为——不需要绕路
- 有独立的神经基础，不是其他驱动的附庸
- 为游戏提供了新的行为通道：共情 heavy 的角色有一条独特的行动路径
- PAD 空间优雅：照护读取他人 PAD，自身 PAD 不变——所以恐惧+照护 = 又怕又冲
- 与世界观一致：治疗中心里，"被他人苦难牵引" 是一个核心主题

### 缺点

- 7 种驱动比 6 种复杂。更多参数，更多需要平衡的相互作用
- 需要认知模块支持 "他人 PAD 感知" 的接口（目前认知模块的输出是 C⁵，没有 "他人的情绪状态" 字段）
- 打开的缺口：如果加了照护，ARCH 的另外 9 个原型也要加吗？

## 方案 B：不新增驱动，给现有驱动加 "他人指向模式"

核心思路：认知模块识别到 "他人 X 正在受苦" → 该信号作为 modifier 进入现有驱动的激活函数。

```
认知 → 识别 "他人正在受苦"
  │
  ├→ 惩罚机制: 将他人的预期损失 → 映射为自己的预期损失
  │     "如果他继续受苦 = 我会承受痛苦" → 回避信号 → 但方向翻转
  │     回避 "他人继续受苦" 的状态 → 趋近 "消除他人痛苦" 的行为
  │     问题: 惩罚机制的固有方向是回避——翻转后是否有残留？
  │
  ├→ 道德驱动: 短路规范性评估
  │     "应该帮助" 被自动判定为真 → 无需 2-3 回合规范性推演
  │     Attachment_strength 作为优先级加权
  │     问题: 道德驱动即使在短路后仍然是 "应该"——不是内脏级的"必须"
  │
  └→ 价值驱动: 他人的福祉被纳入价值层级
        Attachment_strength 高 → "此人安危" 自动进入价值排序的顶层
        问题: 这实际上是在价值驱动里硬编码了一个照护子模块
```

### 优点

- 结构更省——不破坏 6 种驱动的框架
- 惩罚机制 → 道德驱动 → 价值驱动 的渐进激活可以解释利他行为的 "升级路径"（从怕内疚到应该做到甘心付出）
- 避免了 "加了照护，下次要不要加探索/支配/归属" 的滑坡

### 缺点

- 三种现有驱动的 "他人指向模式" 需要各自的 modifier 逻辑——实质上分散了照护的复杂度，却没有统一概念
- 仍然无法解释照护行为的**速度**。惩罚/道德/价值机制都有认知前置，但母亲救孩子在神经层面是杏仁核-催产素通路，比任何认知评估都快
- 照护行为的独特现象学——"不是我在选择帮你，是我的身体已经在帮了" ——在 modifier 模型里找不到位置。它既不是惩罚机制的 "我怕"，不是道德驱动的 "我应该"，不是价值驱动的 "我信"
- 游戏层面，modifier 模型让 "有共情的角色" 和 "没共情的角色" 的行为差异只在参数值上——而不是在有/没有一种行为通道。这对角色差异化不利

## 建议：方案 A，但有约束

照护驱动应该加，因为：

1. **它确实是一种独立的驱动逻辑**——不是其他六种的子类或组合
2. **速度不同**——接近反射，快于所有其他 S2 通道驱动
3. **它和其他驱动的关系是竞争/合作的平等关系**——不是 modifier
4. **对游戏的角色差异化至关重要**——共情 heavy 的角色有一条独特的、内脏级的行为通道

约束条件，防止滑坡到 "再加 10 种驱动"：

**驱动添加的判定标准：**
> 一种候选驱动需要满足三个条件才能被加入——
> 1. 它不可能是现有某种驱动的参数化变体（不是 "更强烈的奖励机制"）
> 2. 它有独立的 PAD 敏感度剖面（读取的信号源与现有 6 种不同）
> 3. 它的行为拉力方向/速度/模态与现有 6 种在质上不同（不是程度差异）

照护满足全部三项，ARCH 的其他原型大概率不满足。支配 (Agonix) 可以是奖励机制+道德驱动+价值驱动的组合；探索 (Navigia) 可以是奖励机制+反射的组合。但照护的 "读你而非我的 PAD" + "反射级速度的趋近" 无法被组合出来。

# 情绪→行为 因果链

> 补完行为模型 v2 中情绪到行为的传递机制。回答一个核心问题：PAD 坐标是怎么变成行为输出的？

---

## 一、两条通路

情绪对行为的影响不是单一通道。在神经层面，杏仁核既通过直接投射到导水管周围灰质 (PAG) 触发冻结/逃跑/战斗，也通过前额叶投射影响 deliberative 决策。两条通路并行，速度不同，互相竞争。

对应到模型：

```
通路 A: 情绪 → 直接行为推力  → 行为向量 (快速, 粗糙, 不经过驱动系统)
通路 B: 情绪 → 驱动激活门控  → 行为向量 (慢速, 精细, 经过驱动系统)
```

**两条通路的输出不是 "哪个大选哪个"——它们是同一个行为向量的两个分量，按认知处理进度混合。**

```
B(t) = λ_raw · B_raw(PAD) + λ_drive · B_drive(PAD, cog)

其中:
  λ_raw = exp(-cog_progress)      — 认知处理越深入, 原始推力权重越低
  λ_drive = 1 - exp(-cog_progress) — 认知处理越深入, 驱动权重越高
  cog_progress ∈ [0, 1]           — CPM 评估序列的完成度
```

关键含义：**认知没处理完的时候，你的行为主要是情绪的原始推力。认知处理完之后，驱动系统接管。**

---

## 二、通路 A：直接情绪推力 (B_raw)

这是情绪对行为最古老、最快的通道。不经过认知评估，不经过驱动分类——PAD 空间中的位置直接映射为一个行为向量。

### 推力公式

```
B_raw(PAD) = {
  valence:   P,                          // P>0 趋近, P<0 回避
  intensity: |A|,                        // |A| 越大行为越强
  autonomy:  D                           // D>0 主动, D<0 被动
}
```

这是情绪模型中已有的映射（"P 决定趋近/回避方向，A 决定行为强度，D 决定主动/被动"），直接用作原始行为推力。

### 不同情绪的原始推力

| 情绪 | PAD | B_raw 结果 |
|------|-----|-----------|
| 快乐 | +P +A +D | 趋近 + 高强度 + 主动 → "冲向目标" |
| 爱 | +P +A ~0D | 趋近 + 高强度 + 半被动 → "被牵引着靠近" |
| 愤怒 | −P +A +D | **回避(?) + 高强度 + 主动** → 矛盾：P说回避但D说主动 |
| 恐惧 | −P +A −D | 回避 + 高强度 + 被动 → "被推着逃跑" |
| 焦虑 | −P +A −D | 同恐惧但 A 稍低 |
| 厌恶 | −P +A ~0D | 回避 + 高强度 + 中性 → "推开/远离" |
| 内疚 | −P ~0A −D | 回避 + 低强度 + 被动 → "缩回去" |
| 悲痛 | −P −A −D | 回避 + 低强度 + 被动 → "动不了" |
| 共情 | ~0P ~0A ~0D | 推力接近零——共情本身不给行为方向，它传递的是**被共情情绪的方向** |

### 愤怒的矛盾

愤怒的 B_raw 出现了矛盾：P<0（不愉快）说 "回避"，但 D>0（控制感）说 "主动"。原始推力给出的是 **"又回避又主动"**——这在行为上就是 **"主动逼近威胁源"**（回避信号+主动控制=朝威胁移动以消灭它）。

这个矛盾恰好解释了愤怒为什么是**唯一使人主动靠近威胁源的情绪**：PAD 空间中，只有愤怒同时具备 −P（威胁信号）和 +D（控制信号）。其他所有 −P 情绪都是 −D 或 ~0D。

## 三、通路 B：驱动门控 (B_drive)

这就是 v2 模型的核心——PAD 坐标进入每个驱动的敏感度函数 g_i(PAD)，决定哪些驱动被激活，然后按加权平均产生行为向量。

### B_drive 的语义

B_raw 回答 "情绪推我往哪走"，B_drive 回答 "**在当前情绪状态下，我采用哪种行为逻辑**"。

同一个 PAD 坐标可以激活多个驱动，每个驱动有不同的 "为什么这样做" 的理由：

| PAD 状态 | 激活的驱动 | 各自的 "为什么" |
|----------|-----------|---------------|
| 恐惧 (−P, +A, −D) | 反射 | "身体替我做决定" |
| | 惩罚机制 | "远离这个危险的东西" |
| 愤怒 (−P, +A, +D) | 惩罚机制 | "消除这个威胁" |
| | 奖励机制 | "纠正不公后的正面结果" |
| | 道德驱动 | "这是正义的愤怒" |
| 快乐 (+P, +A, +D) | 奖励机制 | "继续做这件事！" |
| | 道德驱动 | "做对的事让我快乐" |
| 内疚 (−P, ~0A, −D) | 惩罚机制 | "我应该被惩罚" |
| | 道德驱动 | "我必须弥补" |

### 通路 B 输出的不只是一组激活值

B_drive 输出的 vector 和 B_raw 的 vector 在同一个空间中——都是 (valence, intensity, autonomy)。差异在于：

- B_raw 的 valence 直接 = P。如果 P<0，原始推力永远是回避。
- B_drive 中，价值驱动的 s_valence 可以取 ±1.0，**不受 PAD 的 P 约束**。→ 即使 P<0，如果价值驱动激活，"趋近"仍然可以从驱动系统输出。

这就是 **"我害怕但我还是要做"** 的计算路径：B_raw 说回避，但 value drive 的 s_valence=+1 在加权中占了上风。

## 四、两条通路的混合时机

λ_raw 和 λ_drive 的权重不是固定的——它取决于认知处理的进度：

```
cog_progress = CPM 四步中已完成的步数 / 4

t=0 (刺激出现):   cog_progress = 0    → λ_raw = 1.0,  λ_drive = 0.0
                  行为 = B_raw         → "身体先动"

t=1 (关联性完成): cog_progress = 0.25 → λ_raw = 0.78, λ_drive = 0.22
                  反射/文化习俗开始介入，但原始推力仍主导

t=2 (意涵完成):   cog_progress = 0.5  → λ_raw = 0.61, λ_drive = 0.39
                  惩罚/奖励机制开始介入

t=3 (应对完成):   cog_progress = 0.75 → λ_raw = 0.47, λ_drive = 0.53
                  道德驱动可以激活，驱动系统开始主导

t=4 (规范性完成): cog_progress = 1.0  → λ_raw = 0.37, λ_drive = 0.63
                  价值驱动可以激活，行为主要由驱动系统决定
```

**但有一个例外：反射可以短路这个时间线。**

如果 PAD 满足反射的敏感度条件 (A 很高 + D 很低)，反射在 t=0 时刻就产生极大的 α_reflex，且 λ_raw 还没有衰减 → B_raw + 反射同时指向回避 → 行为瞬间确定为 "逃跑"。

这就是为什么在极端恐惧下，后续的认知推进不会改变行为——即使 cog_progress 到了 1.0、道德驱动激活了、知道 "不应该逃"，反射的激活强度仍然在行为混合中占主导。要改变这个需要的是：**降低反射的激活**（如镇定卡、认知重评），或者**激活价值驱动产生更强的反向拉力**。

## 五、情绪→认知→行为的间接通路

情绪不只直接影响行为——它还影响认知，认知再影响行为。这是一条间接通路。

```
情绪 (PAD) → 认知扭曲 → 认知模块输出改变 → 驱动前置条件改变 → 行为改变
```

### 情绪对认知模块的影响

| 情绪 | 认知扭曲 | 对行为系统的下游影响 |
|------|---------|-------------------|
| 恐惧 | 注意窄化（只看到威胁）、知识表征偏误（中性→威胁） | 惩罚机制 φ 更容易满足（因为知识表征报告了更多 "威胁"） |
| 愤怒 | 推理偏误（对方意图被解读为恶意） | 道德驱动 φ 满足（规范性评估 = "对方错了"） |
| 快乐 | 注意拓宽、风险低估 | 奖励机制 φ 更容易满足（推理高估成功概率）、惩罚机制 φ 更难满足（低估威胁） |
| 内疚 | 记忆提取偏误（反复回放错误） | 道德驱动 φ 通过内疚耦合被短路激活 |
| 悲痛 | 推理偏误（未来被评估为无望） | 奖励机制 φ 难以满足（推理判定 "没有希望"）→ 行为趋近消失 |
| 厌恶 | 知识表征偏误（对象被归入 "不可接触"） | 惩罚机制 + 文化习俗共同激活（远离 + 公开排斥） |

### 这条通路的时程

比通路 B 更长——情绪先要扭曲认知，认知再影响行为。在游戏中可能跨越 2~4 回合。但它产生更持久的行为改变：一旦认知被扭曲了，即使情绪消退，行为仍然改变（因为驱动门控条件被认知状态永久改变了，直到认知被重新校正）。

## 七、情绪叠加 (emotion blending) 的行为含义

多张情绪卡在手 → 多情绪在 PAD 空间取加权平均 → 中间坐标。

这在行为上有重要后果：**两种 "负面" 情绪的组合可以产生完全不同的行为。**

```
恐惧 (−P, +A, −D) + 愤怒 (−P, +A, +D)
= PAD ≈ (−0.68, +0.74, −0.05)   ← D 轴互相抵消！
B_raw ≈ 回避 + 高强度 + 半被动
Drives: 反射 + 惩罚 (来自恐惧) + 道德 (来自愤怒)

结果: 僵住了 —— 想逃(恐惧)又想打(愤怒)，D≈0 导致既不能完全逃也不能完全打。
      外在表现为 "对峙" 状态：高度警觉，但行为冻结。
```

```
恐惧 (−P, +A, −D) + 悲痛 (−P, −A, −D)
= PAD ≈ (−0.75, +0.18, −0.60)
B_raw ≈ 回避 + 低烈度 + 被动
Drives: 惩罚 (弱) —— A 被悲痛拉低，反射/惩罚都激活不足

结果: 崩溃性退缩 —— 相比纯恐惧(高强度回避)，
      恐惧+悲痛的人反而**不动了**：A 被拉低，行为强度骤降。
      这解释了为什么丧失之痛会覆盖求生本能。
```

```
愤怒 (−P, +A, +D) + 快乐 (+P, +A, +D)
= PAD ≈ (−0.12, +0.69, +0.58)   ← P 轴接近零！
B_raw ≈ 微偏回避 + 高强度 + 主动
Drives: 奖励 (来自快乐) + 惩罚+道德 (来自愤怒)

结果: 兴奋的战斗欲 —— "我要打，而且打得很爽"。
      P≈0 意味着情绪本身不痛苦也不快乐，纯粹的行为释放。
```

这些情绪混合的行为输出不是靠查表——是靠 PAD 加权平均后的坐标，再进入 g_i 函数统一计算。**两张 "负面" 卡叠加不一定产生更负面的行为。**这恰好是 PAD 空间比 ±1/0 标量优越的地方。

## 八、总结：情绪→行为的完整因果链

```
情绪卡打出
    │
    ├→ PAD 加权平均 → 当前 PAD 坐标 (p, a, d)
    │
    ├────────────────┬──────────────────┐
    │                │                  │
    ▼                ▼                  ▼
通路 A             通路 B              间接通路
(直接推力)         (驱动门控)          (情绪→认知→行为)
    │                │                  │
B_raw = {          各驱动 g_i(PAD)     情绪扭曲认知模块:
  val = P,          计算激活度          注意窄化/拓宽
  int = |A|,        × 文化调制          归类偏误
  aut = D           × 认知前置         记忆提取偏差
}                   门控                推理偏误
    │                │                  │
    │                ▼                  ▼
    │            各驱动激活            认知前置条件
    │            加权平均              被改变
    │            B_drive               │
    │                │                  │
    └────────┬───────┘                  │
             │                          │
             ▼                          ▼
    λ_raw · B_raw  +  λ_drive · B_drive
             │
             ▼
       最终行为向量 B(t)
             │
    ┌────────┼────────┐
    ▼        ▼        ▼
  valence  intensity  autonomy
  [-1,1]    [0,1]     [-1,1]
```

一条通路，三条分叉。情绪不是先 "变成" 某种驱动再输出行为——它同时走了三条路，三条路在行为混合层汇合。

# 控制成本与启动系统

> 2026-07-06。
> 理论基础：Shenhav et al. (2017) EVC + Seligman (1972) 习得性无助 + DSM-5 意志消沉。
> 经验锚定：Zhang et al. (2019) 自控力日内波动 ~61% + 恢复机制的分散实证。
> 整合进行为系统-整合.md 第十三节。

---

## 一、核心模型

意志力不是池。是三个参数的博弈，加随机波动。

```
硬解锁态度可用 ⇔ EVC > θ_initiation

EVC = benefit − C_control − effort_discount + ε

ε ~ Logistic(0, 0.3)    ← 日内随机波动。
                           同样的情境, 随机好一点就过了, 差一点就卡住。
                           玩家体验: "今天不知道怎么了, 就是动不了"。
```

| 参数 | 含义 | 变化速度 |
|------|------|---------|
| **C_control** | 当前控制成本 | 战斗内，每回合随 PAD 衰减波动 |
| **θ_initiation** | 启动阈限 | 跨战斗漂移 (3-5场) |
| **effort_discount** | 努力折扣率 | 跨战斗漂移 |
| **helplessness** | 习得性无助 | 跨战斗漂移 |
| **ε** | 日内随机 | 每回合微扰动 |

---

## 二、C_control — 非线性控制成本

```
C_resistance = 2.0 × σ(|V − V_drive| × |A| × 3.0 − 1.5)

σ(x) = 1 / (1 + e^(−x))

C_control = C_base + C_resistance
```

**C_base (驱动固有难度)**：

| 驱动 | C_base | 说明 |
|------|--------|------|
| 文化 | 0 | 执行外部脚本 |
| 惩罚 (V>0) | 0 | 保护正面状态——不算逆着 |
| 奖励 (V<0) | 1 | 逆着情绪趋近 |
| 道德 (D<−0.3) | 1 | 低控制感中坚守 |
| 照护 (S<0.4) | 1 | 帮陌生人不如帮至亲自然 |
| 价值 | 2 | 覆盖 S1——最费力的控制 |

**已验证的完整 C_control 表 (sigmoid, ε=0)**：

| 情绪 | 反射 | 惩罚 | 奖励 | 道德 | 文化 | 价值 | 照护 |
|------|:----:|:----:|:----:|:----:|:----:|:----:|:----:|
| 快乐 | ✕ | ✕ | 0 | 0 | 1.2 | 0 | 1.4 |
| 爱 | ✕ | ✕ | 0 | 0 | 0.4 | 0 | 1.4 |
| 共情 | ✕ | 0.8 | 0 | 0 | 0.5 | 2.5 | 1.5 |
| 平静 | ✕ | ✕ | 0 | 0 | 0.9 | 2.7 | 1.7 |
| 希望 | ✕ | ✕ | 0 | 0 | 0.7 | 0 | 1.4 |
| 敬畏 | ✕ | 0 | 2.0 | 1.5 | 0.4 | 3.0 | 2.0 |
| 愤怒 | ✕ | 0 | 2.8 | 0 | 1.0 | 0 | 2.8 |
| 恐惧 | 0 | 0 | 2.8 | 2.4 | 1.1 | **3.8** | 2.8 |
| 焦虑 | 0 | 0 | 2.8 | 2.3 | 1.0 | **3.8** | 2.8 |
| 厌恶 | 0 | 0 | 2.7 | 2.2 | 1.0 | **3.7** | 2.7 |
| 恐怖 | ✕ | 0 | 2.8 | 0 | 1.1 | **3.8** | 2.8 |
| 绝望 | 0 | 0 | 2.7 | 2.2 | 0.9 | **3.7** | 2.7 |
| 内疚 | ✕ | 0 | 1.6 | 1.5 | 0.4 | 2.6 | 1.6 |
| 悲痛 | ✕ | 0 | 2.4 | 2.0 | 0.8 | 3.4 | 2.4 |
| 孤独 | ✕ | 0 | 2.4 | 1.9 | 0.7 | 3.4 | 2.4 |

> 最高值：恐惧/焦虑/恐怖+价值 C=3.8——全游戏最昂贵的行为。"赴汤蹈火"不是比喻。
> 最低非零硬解锁：爱+文化 C=0.4——"在爱的状态下遵循社交礼仪"几乎不费劲。

**ε 波动验证 (恐惧+价值, C_base=2, C_resistance≈1.47)**：

```
C_control 范围: 3.1 ~ 4.0 (ε 贡献 ±0.5)
AP 溢价: 3 (稳定)
SAN 磨损: −1.6 ~ −2.5
效果折扣: 40%~53%
```

波动幅度合理——AP 不会因为一次坏 roll 突然翻倍，但效果和 SAN 有可感知的差异。

**C_control → 支付**：

```
AP 溢价   = floor(C_control)
SAN 磨损  = max(0, C_control − 1.5)
效果折扣  = 1 − 0.15 × C_control
```

## 三、持续状态参数

### θ_initiation — 启动阈限

| 状态 | 值 | 玩家感受 |
|------|-----|---------|
| 正常 | 1.0 | 有点好处就动 |
| 轻度抑制 | 1.5 | 需要更大的理由 |
| 中度抑制 | 2.0 | 只有重要的事才值得动 |
| 重度抑制 | 2.5 | 几乎什么都不值得动 |
| 躁狂相 | 0.5 | 不需要理由就冲动 |
| 意志消沉 | 3.0 | 想做但动不了 |

漂移：连续多场不使用硬解锁 → θ 轻度↑。价值覆盖成功 → θ 轻度↓。病情 modifier 主导方向。

### effort_discount — 努力折扣

| 状态 | 值 | 玩家感受 |
|------|-----|---------|
| 正常 | 0.5 | 为未来付出是值得的 |
| 轻度升高 | 1.0 | 未来的吸引力打折了 |
| 中度升高 | 1.5 | 未来看起来很远 |
| 重度升高 | 2.0 | 未来被折到几乎看不见 |
| 冲动相 | 0.2 | 不等未来——现在就做 |

漂移：趋近行为获得奖励 → discount 轻度↓。趋近反复失败 → ↑。抑郁 modifier：失败放大↑↑。

### helplessness — 习得性无助

| 状态 | 值 | 玩家感受 |
|------|-----|---------|
| 正常 | 0 | 相信自己的行动能改变结果 |
| 轻度动摇 | 0.5 | 开始不确定 |
| 中度侵蚀 | 1.0 | "上次试了没用"——benefit 显示为 ??? |
| 重度固化 | 2.0 | "做了也没用"——大部分硬解锁 benefit=??? |
| 完全无助 | 3.0 | "我不动了" |

漂移：覆盖 S1 成功 −0.05/次，覆盖 S1 失败 +0.10/次，自然卡成功（微小胜利）−0.01/次。clamp(0, 3.0)。

## 四、恢复机制

按文献确认的六条通路（排除葡萄糖——注册复制未过）。

### 战斗内

| 触发 | 效果 | 文献 |
|------|------|------|
| **等待** (wait) | θ −0.1, ε 重掷 | 微休息恢复执行功能 |

|------|------|

## 六、已知问题 (游戏流程测试时修复)

1. **sigmoid 参数 (2.0/3.0/1.5) 是估的。** 全表跑出来范围 0~3.8, 看起来合理, 但实际手感需要测试。
2. **ε 波动窗口 ±0.5。** 边缘情况——一次坏 roll 可能让刚好够用的卡灰掉。需要测试"差一点就能用"的频率是否令人沮丧。
3. **恢复速率缺乏校准。** 自然卡 −0.01 helplessness 太慢 (100次才能从1.0归零)。等待 −0.1 θ 如果每回合都做可能鼓励拖延。具体数值等战斗节奏确定后统一调。
4. **helplessness 增长/消退不对称 (−0.05/+0.10)。** 两次成功才能抵消一次失败。连败后的恢复期可能过长。
5. **effort_discount 在状态栏中不如 θ 和 helplessness 直观。** "未来被折到看不见" 不如 "你觉得做事费力" 容易被玩家感知。
6. **Zhang et al. (2019) 和 Stadler et al. 未下载验证。** 日内波动 ~61% 来自搜索结果摘要。

# 照护驱动 — 亲疏远近计算

> 照护驱动的激活依赖于 "跟这个 NPC 有多近"。不是二元的（有关/无关），而是由多个独立因子叠加的连续值。

---

## 照护驱动的激活公式（补完）

```
g_care = σ( w_vuln·V + w_attach·S - θ_care )

其中:
  V = Vulnerability_signal  — 认知模块判定的 "这个对象需要帮助" 的强度 (0~1)
  S = Attachment_strength   — 角色与这个对象的情感纽带强度 (0~1)
```

V 是局面判断（"她受伤了"），S 是关系判断（"她对我很重要"）。两者独立。陌生人的 V=1 但 S=0.1 → g_care 可能不够高。至亲的 V=0.3 但 S=0.9 → 仍然激活。

**S 不是手动填的值——由以下因子叠加计算。**

---

## S 的构成

```
S = clamp( Σ factors, 0, 1 )

各 factor 独立贡献，上限 clamp 避免溢出。
```

### 因子 1：先天纽带 (Innate Bond)

```
取值范围: 0 ~ 0.4

  血亲 (父母/子女/兄弟姐妹):    0.35 ~ 0.40
  恋人/配偶:                    0.30 ~ 0.40
  密友:                        0.20 ~ 0.30
  普通朋友/熟人:                0.10 ~ 0.15
  陌生人:                       0.00 ~ 0.02
  敌对者:                       0.00 (或负值——见 "反向因子")
```

**先天纽带在游戏开始时设定，整局不变。** 它代表 "在进入治疗中心之前就已存在的关系"。

但——在这个游戏里，"进入治疗中心之前" 可能是一个不可靠的概念。角色的记忆是否准确？月光下，你以为是你母亲的人真的是你母亲吗？先天纽带的稳定性是叙事工具——可以在特定剧情节点被挑战（"你以为的姐姐其实是……"）。

---

### 因子 2：并肩经历 (Shared History)

```
取值范围: 0 ~ 0.3

计算方式:
  S_hist = min(0.3, base + Σ event_contribution)

  base = 0

  每场共同战斗:         +0.02 ~ 0.04  (取决于战斗烈度)
  每次救助行为:         +0.05 ~ 0.10  (你救了对方, 或对方救了你)
  每次背叛/伤害:        −0.05 ~ −0.15 (对方伤害了你或你关心的人)
  关键叙事事件:         ±0.05 ~ 0.20  (一次深刻的对话、一个共享的秘密)
  
  衰减: 如果连续 N 场战斗没有互动, S_hist 缓慢衰减 (−0.01/场)
       但不会降到零——"一起经历过的事" 不会被完全遗忘
```

**这个因子是动态的、累积的。** 它让队友关系在战斗中自然加深，让背叛产生机械后果。

关键设计问题：这个因子是**显式**还是**隐式**的？玩家能看到 "羁绊等级" 吗？还是只能从照护行为卡的可用性中反向感知？

---

### 因子 3：脆弱性共鸣 (Vulnerability Resonance)

```
取值范围: 0 ~ 0.2

计算方式:
  S_vuln = 0.2 × 脆弱信号强度 × 共鸣系数

  脆弱信号强度 (0~1):
    年幼/体型小:          +0.3
    受伤/被困:            +0.5
    恐惧/哭泣:            +0.4
    无力自保(由认知判定): +0.6
    主动求助:             +0.3
  
  共鸣系数 (0~1):
    自己也曾处于类似状态:  +0.5 ~ +1.0
    自己从未经历过:        +0.2
    自己曾因此被伤害:      +1.0 (强烈的 "我不让这事再发生")
```

**这个因子是对 "年幼弱小 → 共情增加" 的系统化。** 它不只依赖对象本身的属性——也依赖角色的自身经历。一个曾经被遗弃的角色，看到另一个被遗弃的人，共鸣系数接近 1.0。

---

### 因子 4：互惠债务 (Reciprocity Debt)

```
取值范围: 0 ~ 0.15

计算方式:
  S_recip = 0.15 × (对方为你做的事 / 你为对方做的事 的比值)

  比值接近 1 (互相):     S_recip ≈ 0.07 (中性互惠)
  比值 > 1 (你欠对方):   S_recip → 0.15 (有债)
  比值 < 1 (对方欠你):   S_recip → 0 (不欠债，但也不减分——你不会因为帮了别人而不想再帮)
  
  特殊: 救助生命 → 比值直接跳到+0.15(上限)，且衰减极慢。
```

**这个因子捕捉的是互惠本能——你欠对方的时候更倾向于帮对方。** 但它在 S 中的贡献被有意压低（上限 0.15），因为照护行为不应该被简化为 "还人情"。

---

### 因子 5：相似性 (Similarity)

```
取值范围: 0 ~ 0.1

计算方式:
  S_sim = 0.1 × similarity_score

  similarity_score 由以下维度叠加:
    相同病情:             +0.3
    相似经历(认知判定):   +0.3
    相同阵营/信仰:         +0.2
    相似性格(面具类型):   +0.2
```

这个因子贡献最小（上限 0.1），因为相似性和照护之间的实证关系不如前四个因子强。但它解释了为什么同类患者之间容易产生互助——"你也经历过这个"。

---

### 因子 6：负面纽带（反向因子）

```
取值范围: −0.3 ~ 0

计算方式:
  S_neg = −clamp( hostility_score, 0, 0.3 )

  hostility_score:
    对方主动攻击过你:          +0.10
    对方伤害过你关心的人:      +0.15
    对方被认知归类为 "敌人":   +0.05
    对方曾背叛你 (叙事事件):   +0.20
  
  特殊: S_neg 可以累积到 −0.3，但不能将 S 拉到负值——
       对敌人的 S ≈ 0，不会变成 "反照护"（希望对方受苦）。
       反照护是另一个机制（见下文）。
```

**对敌人的 S 不一定是零。** 一个你并肩作战过的叛徒 → S_hist 高 + S_neg 高 → 可能 S 仍然为正。这产生了 "我还关心他，虽然他背叛了我" 的复杂情感——照护驱动可能仍然激活，尽管惩罚机制同时也在说 "离他远点"。

---

## 完整的 S 计算

```
S = clamp( S_innate + S_hist + S_vuln + S_recip + S_sim + S_neg, 0, 1 )
```

### 一个例子

```
角色 A: 苟智空
对象 B: 陈姐 (队友，共同经历了 5 场战斗，救过智空一次)

S_innate = 0.25  (密友级别——共同在治疗中心求生的伙伴)
S_hist   = 0.18  (5 场战斗 × 0.02 + 1 次救助 × 0.08)
S_vuln   = 0.05  (陈姐当前状态尚可，未受伤，未求救)
S_recip  = 0.10  (陈姐救过智空 → 智空欠陈姐)
S_sim    = 0.05  (相似病情)
S_neg    = 0.00

S = 0.63

如果陈姐现在受伤:
  V = 0.7 (受伤+恐惧)
  g_care = σ(2.5×0.7 + 1.5×0.63 - 0.3) ≈ σ(2.40) ≈ 0.99
  
照护驱动强烈激活。所有照护类行为卡可用且折扣。
```

### 同一个角色对敌人

```
对象 E: 猴子 (成瘾的具象化敌人，曾攻击过智空)

S_innate = 0.00  (不是人，没有先天纽带)
S_hist   = 0.00  (没有并肩经历)
S_vuln   = 0.00  (虽然它在某种意义上是 "被困在成瘾里的人"，但认知模块判定为威胁)
S_recip  = 0.00
S_sim    = 0.05  (智空自己也曾被成瘾困住——相似性产生一丝共鸣)
S_neg    = −0.15 (敌人+攻击过智空)

S = clamp(0.00 + 0.00 + 0.00 + 0.00 + 0.05 − 0.15, 0, 1) = 0.00

照护驱动不激活。除非——
```

## 特殊敌人：篡改 S

用户提到 "不排除一些特殊敌人能够影响这一数据"。这正是照护驱动的病理学入口。

### 篡改类型

**A. 强制拔高 S（"伪装的求助者"）**
```
敌人能力: "无辜的面孔"
  效果: 将 S_vuln 强制设为 0.5 + S_sim 强制设为 0.3
  结果: 即使 S 其他因子为零，敌方仍可能激活照护驱动
  玩家体验: 照护类行为卡对敌人亮起来了——你想帮 "它"
  叙事: 这不是你软弱。是它的能力在扭曲你的共情。
```

**B. 强制抑制 S（"离间者"）**
```
敌人能力: "裂痕"
  效果: 将队友的 S_neg 临时 +0.2
  结果: 原本可以激活照护的队友突然不够了——照护卡灰色
  玩家体验: "我为什么不想帮她了？" 
  叙事: 敌人在你和队友之间制造了裂痕。你需要认知卡来揭穿——"这不是真的"。
```

**C. 镜像 S（"你看到的是你自己"）**
```
敌人能力: "镜中人"
  效果: 敌人的 S = 你自己的 S_sim（相似性系数取最大值 0.1×1.0）
        + 你的创伤记忆被提取
  结果: 敌人看起来像你自己——你无法攻击 "自己"
  叙事: 最危险的敌人不是怪物，是你内心的投射
```

---

## 需要决策的问题

1. **S 是否对玩家可见？** 作为数字（"羁绊值: 0.63"）还是作为质化描述（"你愿意为她冒险"）？还是完全不可见，只通过照护卡的可用性间接感知？

2. **S 的衰减速度？** 并肩经历是否会因为被冷落而消退？如果连续 10 场战斗不带某个队友，回来时她是否还是 "一起经历过生死的伙伴"？

3. **S 的上限是否需要角色差异？** 反社会人格角色的 S 上限是否应该更低（0.3？）？共情能力强的角色是否应该更高？还是直接通过 θ_care 的差异来体现（不降低 S 上限，但提高激活门槛）？

4. **S 的负面极值——是否存在 "反照护"？** 当前设计是 S 下限 clamp 到 0。但临床上存在对脆弱产生攻击/排斥的现象（虐待、残酷）。是否需要 S < 0 的区间——照护驱动的反向激活，使 "伤害" 类行为卡获得加成？

# 行为卡的选择梯度

> 从 v2.1 约束层衍生出的设计原则。行为系统不给玩家唯一最优解——它给一个梯度。

---

## 核心思想

行为系统的约束不是二元的（可用 / 不可用），而是**渐变的**。玩家面对的不是 "什么能做" 的判断题，而是 "付出什么代价做这件事" 的选择题。

三档：

| 档位 | 条件 | 表现 |
|------|------|------|
| **优势卡** | α_i 远高于 θ_play | 行动点消耗降低，效果增强。驱动在推着你走——做这件事顺水推舟。 |
| **劣势卡** | α_i 勉强超过 θ_play | 行动点消耗升高。驱动激活不够——做这件事很费力，但你仍然可以做。 |
| **惩罚卡** | α_i < θ_play 或驱动被压制 | 正常不可用。但在特定条件下可以 "硬打"——消耗额外的行动点和/或 SAN 值，效果仍然打折。你在逆着自己的驱动行事。 |

---

## 每档的设计含义

### 优势卡 — "顺着做"

```
条件: α_i ≥ θ_play + margin (margin = 0.2~0.3 depending on drive)

效果:
  cost_modifier < 1.0 (折扣)
  effectiveness > 1.0 (增益)
  
玩家体验:
  "恐惧让我想逃——逃跑确实是对的，而且逃得很顺畅。"
  "我现在状态正好，这件事做起来毫不费力。"

设计意图:
  奖励玩家 "顺应自己的心理状态"。你不需要总是硬刚——有时候最优策略就是顺着情绪走。
```

### 劣势卡 — "硬着头皮做"

```
条件: θ_play ≤ α_i < θ_play + margin

效果:
  cost_modifier > 1.0 (加价)
  effectiveness ≈ 1.0 (不增不减)

玩家体验:
  "我现在不太想坚持……但我可以咬牙坚持。多付一个行动点。"
  "恐惧让我想逃，但我选择不逃——这很耗力，但还能做到。"

设计意图:
  允许玩家在任何 α_i > θ_play 的情况下选择行为——但设置渐变的代价。
  防止出现 "α_i 刚过阈值 → 行为和 α_i=0.9 一样便宜" 的断崖。
```

### 惩罚卡 — "逆着做"

```
条件: α_i < θ_play（本来不可用）或驱动被 S2 主动压制

效果:
  需要额外支付 "硬打成本"——通常是 1~2 点额外行动点 + 可能的 SAN 值损耗
  effectiveness 被压制因子折扣 (0.4~0.7)

  特殊:
    价值驱动可以 "解锁" 被 S1 压制的反向行为: 
      反射说 "逃"，价值驱动的覆盖信号可以让 "面对"（原本不可用）变为可用。
      但这种硬解锁需要额外成本——"我怕但我上" 不是没有代价的。

玩家体验:
  "我完全不想面对这件事。恐惧已经接管了。但我仍然可以逼自己。代价很大，而且做得很勉强。"
  "理智告诉我应该坚持（道德驱动说 '坚守'），但身体已经在逃了。我可以在逃的同时告诉自己 '这是错的'。"

设计意图:
  在极端心理状态下，玩家可以做出违反直觉的选择——
  但代价很高，而且效果打折。
  这对应现实中的 "意志力行为"——你做得到，但消耗极大，而且质量不高。
```

---

## 与 "态度" 的交互

玩家选择不同档位的行为卡 → 形成的态度在**性质**上不同：

```
同一组 认知+情绪 搭配不同档位的行为卡:

  认知=看清威胁 (+1) + 情绪=恐惧 (−1)
  
  + 行为=逃跑 (优势，Reflex): 态度 = 知难而退
    "我看清了情况，我感到害怕，我顺应了逃跑的冲动。"
    完全一致的态度。稳定。不消耗额外资源。

  + 行为=面对 (惩罚，Value): 态度 = 逆流而上
    "我看清了情况，我感到害怕，但我拒绝逃跑。"
    认知和情绪都在说 "逃"，行为在说 "不"。
    态度内部充满张力。消耗大，但产生的态度对敌人的影响也可能更大——
    因为观察者效应下，张力本身就是力量。
```

**态度的力度可能和它内部的张力成正比。** 一个认知、情绪、行为三者一致的态度（如 (+1,-1,-1) 知难而退）是稳定的、容易维持的。一个内部矛盾的态度（如 (+1,-1,+1) 逆流而上）是昂贵的、不稳定的——但它对敌人的干扰可能更强，因为月光下的 "不相信" 比 "相信" 更有破坏力。

（这只是推想。态度晶体已经搁置，等重新设计态度体系时需要回头验证。）

---

## 这条原则不能丢

行为系统的目标不是 "找出当前状态下最优的行为"——那是 v2 的错误假设。

行为系统的目标是 **"告诉玩家选择每个行为的代价是什么"**。最优行为是玩家根据当前局面和自己愿意付出的代价来决定的，不是系统算出来的。

有时候你选择劣势卡，因为你看到三步之后的局面需要你做现在不想做的事。

有时候你选择惩罚卡，因为你的人物就是这样的——在恐惧中坚持，即使成本很高、效果很差，但 "坚持" 本身就是意义。

约束创造选择。梯度创造权衡。

# 行为模型 v2.1 — 行为约束层

> **纠正 v2 的架构错误。** v2 将行为当成计算结果（替代了玩家选择），这与原始卡片设计矛盾。
> v2.1 将行为系统定位为 **行为卡的约束层**：不替代玩家选择，只决定哪些行为卡可用、成本多少、效果多大。

---

## 〇、先明确各组分的关系

```
三类卡牌的地位:

  认知卡: 玩家牌库的基础组成部分。初始牌库给定，游戏过程中可通过叙事事件、
          治疗行为、镜子房间改变牌库构成。认知卡代表 "你怎么看"。

  情绪卡: 部分在玩家牌库中，部分由敌人/环境强制塞入手牌。
          情绪卡代表 "你现在感受到什么"。
          情绪卡打出后 → 产生 PAD 向量 → 叠加到当前 PAD 状态。

  行为卡: 玩家牌库的组成部分。和认知卡一样可以构筑。
          行为卡代表 "你做什么"。
          但不同于认知卡——行为卡能否打出，取决于当前 PAD 和认知状态。
```

```
回合流程:

  1. 抽牌阶段: 从牌库抽认知/情绪/行为卡。
               环境/敌人可能额外塞情绪卡入手牌。
               当前 PAD 状态 = 上一回合遗留 + 新打出情绪卡的叠加。

  2. 状态计算: 行为系统根据当前 PAD + 认知进度 → 计算各驱动的激活度。
               → 决定手牌中哪些行为卡当前可用。
               → 决定可用行为卡的行动点消耗修正。

  3. 出牌阶段: 玩家选择打出 1 认知 + 1 情绪 + 1 行为（从可用行为卡中选择）。
               三卡组合 → 形成当前回合的态度。

  4. 结算阶段: 态度效果结算。行为系统惯性更新（α_i 漂移）。
               跨遭遇参数漂移在战斗结束后计算。
```

行为系统的工作在 **步骤 2**。它不替代步骤 3 中的玩家选择。

---

## 一、新的核心公式

```
行为约束 = 可用性门控 + 成本调制 + 强制行为 + 效果调制

其中:
  可用性门控:  驱动 i 激活 → 类型 i 的行为卡可以被打出
               驱动 i 未激活 → 类型 i 的行为卡灰色/不可选

  成本调制:    驱动 i 激活度高 → 类型 i 的行为卡消耗更少行动点
               驱动 i 激活度低 → 类型 i 的行为卡消耗更多行动点

  强制行为:    驱动 i 激活度超过强制阈值 → 本回合必须至少打出一张类型 i 的行为卡
               (通常只适用于反射——惊恐状态下，"不逃"不是选项)

  效果调制:    驱动 i 激活度极高 → 类型 i 的行为卡获得效果加成
               驱动 i 被 S2 主动压制 → 类型 i 的行为卡效果打折
```

## 二、六种行为卡类型

每种驱动对应一类行为卡。同类行为卡共享驱动门控条件，但具体效果不同（即同类型下有多张不同的卡）。

| 类型 | 示例卡 | 默认 valence | 典型效果方向 |
|------|--------|-------------|-------------|
| **反射** | 逃跑、僵住、闪避 | −1 | 立即减轻威胁压力，但降低对局面的控制 |
| **惩罚机制** | 回避、妥协、克制 | −1 | 减少后续伤害概率，但放弃当前机会 |
| **奖励机制** | 追求、坚持、试探 | +1 | 增加获取增益的概率，但暴露于风险 |
| **道德驱动** | 坚守、维护、自责 | 0 | 稳定自身状态，影响敌人道德判断 |
| **文化习俗** | 遵从、从众、运用仪式 | 0 | 低消耗的保守行动，按社会脚本执行 |
| **价值驱动** | 牺牲、突破、对抗 | ±1 | 最高影响力但最高代价的行动 |

每张行为卡携带：
- **类型标签**（属于哪种驱动）
- **valence**（+1/0/−1，用于态度形成）
- **行动点基础消耗**
- **卡牌效果**（对自身/敌人/环境的具体影响）
- **最低驱动激活度要求**（α_i 高于多少才能打出）

---

## 三、从驱动激活到卡牌可用性

### 3.1 可用性判定

```
行为卡 X（类型 i）可以被打出 ⇔ α_i(t) ≥ θ_play_i

其中:
  α_i(t) = 驱动 i 当前激活度（含惯性，见第五节）
  θ_play_i = 类型 i 的打出阈值

默认 θ_play:
  反射:      0.15  (最容易打出——身体反应不需要太多激活)
  惩罚机制:  0.20
  奖励机制:  0.25
  文化习俗:  0.15  (社会脚本也容易触发)
  道德驱动:  0.35  (需要更强的规范性确信)
  价值驱动:  0.50  (最高门槛——为信仰行动不是随时都能做的)
```

### 3.2 成本调制

```
行为卡 X（类型 i）的行动点消耗 = base_cost_X · cost_modifier_i

cost_modifier_i = 1 + β_i · (1 - α_i(t))

  α_i(t) 高 → cost_modifier 接近 1.0（基础消耗）
  α_i(t) 低（但高于阈值）→ cost_modifier 增大（做这件事更费力）
  α_i(t) < θ_play → 不可用（不适用调制）

β_i 为成本敏感度:
  反射:      β=0.5  (成本波动小——身体反应不怎么受意志影响)
  惩罚机制:  β=1.0
  奖励机制:  β=1.2  (成本波动大——没动力时追什么都很累)
  道德驱动:  β=0.8
  文化习俗:  β=0.3  (社会脚本执行成本低且稳定)
  价值驱动:  β=1.5  (成本波动最大——信念不足时硬撑极耗能)
```

### 3.3 强制行为（恐慌规则）

```
当 α_reflex(t) > θ_force（强制阈值 ≈ 0.85）时:

  本回合至少必须打出一张 反射 类型的行为卡。
  如果手牌中没有可用的反射行为卡 → "僵住"（基础反射卡）自动加入手牌并强制打出。
  
  这不占用玩家的 "出牌" 选择——恐慌行为是额外的、不受控制的。
  玩家仍然可以在此之上选择自己的行动。
```

这个规则只对反射驱动生效。其他五类驱动不设强制规则——它们是对行为施加拉力，不是剥夺行为控制。

### 3.4 效果调制

```
行为卡 X 的效果 = base_effect_X · (1 + γ_i · (α_i(t) - θ_play_i))

  α_i 越高 → 效果越强（你的行为背后有强烈的驱动力）
  α_i 刚刚超过阈值 → 接近基础效果
  
γ_i 为效果增益系数:
  反射:      γ=0.2  (反射行为的增益有限——你是被迫的，不是全力以赴)
  惩罚机制:  γ=0.5
  奖励机制:  γ=0.6
  道德驱动:  γ=0.7
  文化习俗:  γ=0.2
  价值驱动:  γ=1.0  (价值驱动的行为效果受信念强度影响最大)

特殊情况——驱动被 S2 主动压制:
  如果行为卡 X 对应的驱动被压制（w₂>0.5 且 S2 压制了 S1）
  → 效果 × 压制因子（0.3~0.7）
  → 你内心在抗拒你正在做的这件事。
  
  例子: 你在用 "回避"（惩罚机制），但你的道德驱动在说 "不应该逃"。
        打出的回避卡效果打折——你做得到，但做得不彻底。
```

---

## 四、没有可用行为卡时怎么办

可能存在一种情况：没有任何行为卡的 α_i 超过 θ_play。这发生在极端情绪状态下——通常是深度抑郁（所有 α_i 被压低）或解离状态（PAD 全部接近零）。

此时：
- **等待**（"wait"）作为保底行为，始终可用
- 等待 = valence 0，行动点消耗 = 0，效果 = 跳过本回合的行为出牌
- 打出等待 → 态度仅由认知 + 情绪决定（行为轴 = 0）
- 等待也会产生行为惯性更新（不做选择也是一种选择——μ_i 衰减生效）

## 五、驱动激活计算（保持 v2 的数学，但输出目的不同）

### 5.1 PAD 敏感度

```
g_reflex  = σ(2.0·max(0,A-0.3) + 1.5·max(0,0.5-D) - 0.5)
g_punish  = σ(2.5·min(0,P) + 1.0·max(0,A-0.2) - 0.3)
g_reward  = σ(2.5·max(0,P) + 0.8·max(0,A-0.2) - 0.35)
g_moral   = σ(2.0·max(0,D-0.1) + 1.0·(1-|A|) - 0.4)
g_culture = σ(1.5·(1-|D|) + 2.0·C_score - 0.3)
g_value   = σ(1.5·max(0,D-0.4) + 3.0·Override_signal - 0.7)
```

### 5.2 认知前置门控

```
g_i 有效 = g_i · φ_i(cog)

φ_reflex  = 1.0  (无前置——短路通道)
φ_punish  = 知识表征完成 ? 1.0 : 0.3
φ_reward  = 知识表征 ∧ 推理完成 ? 1.0 : 0.2
φ_moral   = 规范性评估完成 ? 1.0 : 0.1
φ_culture = 知识表征完成 ? 1.0 : 0.4
φ_value   = 五模块全部完成 ? 1.0 : 0.05
```

### 5.3 惯性

```
α_i(t) = α_i(t-1) + λ_i·(g_i·c_i·φ_i - α_i(t-1)) - μ_i·α_i(t-1)
```

各驱动的 τ（时程）参数保持与 v2 一致。

## 六、双系统仲裁在约束层的角色

```
S1 驱动（反射、惩罚、文化）→ 激活快 → 它们对应的行为卡在战斗早期可用
S2 驱动（奖励、道德、价值）→ 激活慢 → 它们对应的行为卡需要认知推进后才解锁

时间线:
  回合 1: 反射 + 文化的行为卡立即可用（如果 PAD 满足条件）
          惩罚的行为卡可能可用（φ_punish 只需知识表征）
  回合 2: 奖励的行为卡可能解锁（φ_reward 需要推理模块）
  回合 3: 道德的行为卡可能解锁（φ_moral 需要规范性评估）
  回合 4+: 价值的行为卡可能解锁（φ_value 需要全部五个模块）

S2 压制 S1 时:
  被压制的 S1 行为卡可能仍然可用（它只是被 "不鼓励"），
  但效果被压制因子折扣（见 3.4）。
```

这创造了一个自然的设计节奏：**早期回合的行为选择受情绪主导（窄），后期回合受认知扩展（宽）。**

## 七、行为卡被塞入的情况

敌人可以像塞情绪卡一样塞行为卡："强迫你做出某些行为"（原始设计）。

当敌人塞入一张行为卡：
- 该卡加入手牌（和普通行为卡一样）
- 但该卡的 α_i 要求被**忽略**——敌人的压力让你可以做出平时不会做的行为
- 打出被塞入的行为卡可能有附加代价（SAN 值降低——"我在做我不想做的事"）

玩家仍然可以选择**不打**被塞入的行为卡——除非它触发了强制规则（敌人塞入的是反射卡 + 你处于高反射状态）。

## 八、病情扭曲的作用位置

病情参数扭曲仍然存在（保持 v2 的畸变矩阵），但扭曲的**后果**变了：

| 病情 | α_i 被如何扭曲 | 对行为卡的影响 |
|------|---------------|--------------|
| 抑郁症 | g_reward ↓↓, g_punish ↑ | 奖励类行为卡难以解锁；惩罚类行为卡容易解锁且成本低 |
| PTSD | θ_reflex ↓, τ_decay_reflex ↑↑ | 反射类行为卡几乎总可用；"不逃"可能需要主动压制 |
| OCD | g_moral ↑↑, 与 g_punish 耦合 | 道德类行为卡总是高亮；但效果可能被惩罚机制的压制折扣 |
| 躁狂 | g_reward ↑↑, θ_value ↓↓, 认知前置被短路 | 奖励和价值行为卡过早解锁；玩家可以做 "还不该做" 的事 |
| 焦虑 | θ_punish ↓↓, 假阳性 ↑ | 惩罚类行为卡在安全情境中也亮着——"快避开" |

## 九、与情绪和认知的接口

### 情绪 → 行为约束

```
当前 PAD (p,a,d) 来自:
  - 上一回合遗留的 PAD
  - 本回合打出的情绪卡的 PAD 向量叠加
  - 环境/事件对 PAD 的直接调制

PAD → 各驱动 g_i(PAD) → α_i(t) → 行为卡可用性/成本/效果
```

### 认知 → 行为约束

```
认知模块完成状态 → φ_i(cog) → 门控 g_i

认知模块的 "结论方向" m → 调制 g_i:
  知识表征判定 "有威胁" → g_punish 增强
  推理判定 "有可行路径" → g_reward 增强
  规范性评估判定 "对方有错" → g_moral 增强
  记忆提取 "上次成功了" → g_value 增强
```

### 行为约束 → 玩家

```
行为系统输出 (每回合):
  {
    available:    [可用的行为卡列表]     ← 玩家手牌中满足 α_i ≥ θ_play 的行为卡
    costs:        {卡名: AP消耗}         ← 每张可用卡的修正后行动点消耗
    mandatory:    null | 卡类型           ← 是否触发强制行为
    effectiveness: {卡名: 效果倍率}      ← 每张卡的效果调制系数
    suppressed:   [被压制的行为卡列表]    ← 可用但效果被折扣的卡
  }
```

玩家在这个约束空间内做选择。

## 十、v2.1 不回答的问题

1. **行为卡的具体设计**：每类下各有多少张卡、每张卡的具体效果、基础行动点——这些是卡牌设计的工作，不在行为系统的范围内。

2. **牌库构筑规则**：认知/情绪/行为卡的配比、手牌上限、抽牌规则——核心机制层面的问题。

3. **态度结算公式**：态度晶体搁置后，认知 + 情绪 + 行为 如何形成最终态度的计算方法——需要等认知和情绪的输出格式确定后回来重新设计。

4. **照护驱动（第 7 驱动）**：如果加了，对应的照护类行为卡（保护、安抚、牺牲）的 θ_play 和特性需要单独定义。

5. **跨遭遇参数漂移**：保持三层模型（后台漂移 + 镜子感知 + 主动干预），具体漂移公式待定。

6. **行为抑制 ι**：未纳入 v2.1。如果加入，ι 可以直接将某个驱动的 α_i 临时压低——使对应行为卡不可用或成本暴增。这比 "S2 压制折扣" 更强力——不是打折，是关掉。

# 行为模型

> 本文档从 `01-核心机制.md` 中提取。包含 6 种行为驱动的分类结构、心理学展开边界、以及 PAD 激活条件。

---


## 行为分类

card.md 中定义了 6 种行为：

| 行为 | 描述 | 向量倾向 |
| --- | --- | --- |
| **反射** | 摆脱危险接触的简单动作 | 中性 |
| **惩罚机制** | 为了避免接受惩罚所采取的措施 | 倾向于 -1 |
| **奖励机制** | 为了主动得到奖励所采取的措施 | 倾向于 +1 |
| **道德驱动** | 为了符合自身价值观所采取的措施 | 中性 |
| **文化习俗** | 处在特定文化中的人会根据相应习俗决定自身行为 | 中性 |
| **价值驱动** | 为了更有价值的事情违背生理反应、拒绝奖励、接受惩罚、抛弃道德和文化 | 可突破向量限制 |

### 行为不是动作，是驱动逻辑

行为不等于动作本身。行为的重点是剥离复杂成因机制之后，回到简单的驱动逻辑上。在特定条件下（如敌方强迫、环境压力），行为可以脱离主观意识单独分析。

同一动作可能来自不同的行为驱动，同一行为驱动也可能表现为完全相反的动作。

### 六种行为的展开边界

**反射**

- **心理学定位**：反射是行为系统中唯一不经过认知-情绪-行为链的通道。它跳过前两步，直接从刺激到反应。核心特征是**自动性**和**无需决策**——它不是"选择不思考"，而是根本就没有经过思考回路。进化上，反射是大脑最底层的保护机制，存在时间远超意识本身。
- **触发条件**：突如其来的感官刺激（巨响、闪光、冲击）、对身体的直接威胁（烫、刺、坠落）、极端恐惧下的冻结反应（"吓得动不了"）
- **在态度体系中的角色**：反射的向量值通常为 0（中性）或 -1（回避）。它与恐惧天然亲和——恐惧触发反射，反射又加剧恐惧，形成自我强化的循环。反射是对其他行为驱动的**短路**——无论你多想靠近、多想坚持，一个足够强的反射刺激可以让你瞬间回避。在月光的观察者效应下，反射还有一个特殊性质：因为它不经过意识加工，所以**反射不会受到"你相信自己是什么样的人"的影响**。它是态度的锚——最接近生理真实的那一层。
- **与其他行为的区分**：反射与惩罚机制的区别在于是否有预期参与——反射没有预期，惩罚机制有。"手被烫缩回来"是反射，"怕被烫而不碰"是惩罚机制。
- **古典参照系**：呆若木鸡（训练到极致反而纹丝不动——抑制了反射）、噤若寒蝉（恐惧使人噤声——身体快过意志）、惊弓之鸟（一次创伤后的永久反射）、草木皆兵（知觉与注意的扭曲触发了一系列错误反射）

**惩罚机制**

- **心理学定位**：惩罚机制是对负面结果的预判驱动的行为修正系统。它不需要惩罚已经发生——只需要**预期**到惩罚可能发生。这种预期能力使人类可以在没有亲身体验过后果的情况下调整行为，但也使人可以被**想象中的惩罚**所控制。核心特征是**被负面预期驱动**，方向通常是回避或退缩（行为 -1），但也可以表现为积极应对以消除威胁（行为 0 或 +1）。
- **触发条件**：过去受到过类似惩罚（经验）、观察到他人受到惩罚（替代学习）、被明确告知会受到惩罚（规则学习）、自己推演出可能的负面后果（推理）。在月光下，还有一个独特的触发源：**怕自己想到的东西成真**——这是侵入性思维在观察者效应下的致命性。
- **行为表现**：回避（远离可能触发惩罚的情境）、妥协（服从惩罚者的要求）、克制（主动抑制可能引发惩罚的行为或念头）、过度准备（反复检查以消除被惩罚的可能性）
- **在态度体系中的角色**：惩罚机制是行为轴上最稳定的 -1 来源。它经常与恐惧、焦虑、内疚三种负面情绪搭配——恐惧告诉你"这个危险"，惩罚机制说"所以离它远点"。它与共情的关系尤其微妙：当你共情到对方的痛苦，而接近对方意味着你会承受这份痛苦，惩罚机制会推开你。这就是为什么共情 + 惩罚机制 = 袖手旁观——不是不关心，是关心的代价太大。
- **与其他行为的区分**：惩罚机制 vs 反射——反射是已经触发了的即时反应，惩罚机制是预防性的、基于预期的。"被烫到缩手"是反射，"知道烫所以不碰"是惩罚机制。惩罚机制 vs 道德驱动——"我不偷因为会被抓"是惩罚机制，"我不偷因为那是错的"是道德驱动。同一个行为（不偷），不同的驱动逻辑。
- **古典参照系**：讳疾忌医（蔡桓公回避诊断——怕确诊后的惩罚性治疗）、惩羹吹齑（被烫过后过度泛化——冷菜也吹）、投鼠忌器（想做但怕连带伤害）、因噎废食（一次惩罚导致过度回避）

**奖励机制**

- **心理学定位**：奖励机制是对正面结果的预判驱动的行为趋近系统。它是多巴胺通路在行为层面的表达——重要的不是获得奖励本身，而是**预期奖励的那一刻**。奖励机制使人主动探索环境、尝试新事物、投入资源追求目标。核心特征是**被正面预期拉动着走**，方向通常是趋近或投入（行为 +1），但在等待奖励时也可以表现为观望（行为 0）。
- **触发条件**：过去获得过类似奖励（经验）、观察到他人获得奖励（替代学习）、被告知有奖励（承诺）、自己推演出可能的正面结果（推理）、好奇心——"想知道答案"本身就是奖励
- **行为表现**：追求（投入资源接近目标）、坚持（面对阻碍不放弃——奖励的预期抵消了过程中的痛苦）、试探（尝试新方法以求更大奖励）、分享（将奖励的信息分享给他人以扩大收益）
- **在态度体系中的角色**：奖励机制是行为轴上最稳定的 +1 来源。它经常与快乐、爱两种正面情绪天然搭配——快乐 + 奖励机制 = 心悦诚服地投入，爱 + 奖励机制 = 心甘情愿地付出。但奖励机制也可以与负面情绪共现：恐惧 + 奖励机制 = 铤而走险，愤怒 + 奖励机制 = 孤注一掷。负面情绪下的奖励机制往往带有冒险色彩——你知道可能是陷阱，但诱人的奖励让你无法拒绝。
- **与其他行为的区分**：奖励机制 vs 价值驱动——"我努力学习为了考高分"是奖励机制（成绩是奖励），"我努力学习为了改变家族命运"是价值驱动（家族命运不是奖励，是高于自身利益的目标）。奖励机制 vs 道德驱动——"我助人为乐"是奖励机制（快乐是奖励），"我助人因为那是我的责任"是道德驱动。
- **古典参照系**：守株待兔（等待重复的奖励——奖励机制固化为行为模式）、趋之若鹜（群体追逐同一个奖励）、奇货可居（长时间持有以换取更大奖励——吕不韦投资异人）、重赏之下必有勇夫（奖励机制压倒恐惧和道德）

**道德驱动**

- **心理学定位**：道德驱动来源于内化的对错标准——它不是对外部惩罚的恐惧（那是惩罚机制），不是对外部奖励的追求（那是奖励机制），而是**"这件事就是应该这样做"的内在确信**。道德驱动是唯一可以在没有任何外部后果的情况下改变行为的驱动力——没人看着你、没有奖励也没有惩罚，你仍然选择做对的事。核心特征是**行为由内部价值标准决定，与外部奖惩系统独立**。
- **触发条件**：行为与内化道德标准的匹配检查（自觉或不自觉）、面对道德冲突（两个价值观互相矛盾时，道德驱动需要选择服从哪一个）、社会期待（但不是因为怕惩罚——而是因为"我应该符合这种期待"）
- **行为表现**：坚守（即使代价巨大也不违背自己的准则）、示范（通过行为影响他人的道德判断）、自责（违背道德后的自我惩罚——与内疚情绪紧密相连）、维护（为受道德谴责的他人辩护或为受道德认可的他人站台）
- **在态度体系中的角色**：道德驱动的向量值通常为 0（中性），但在不同的价值观体系下可以表现为 +1 或 -1。它与内疚天然亲和——内疚是"我做错了"的信号，道德驱动是"我应该做对"的行动。道德驱动 + 内疚 = 将功补过。道德驱动也经常与愤怒共现——当目睹他人违反自己认可的道德标准时，会触发道德愤怒（义愤），驱动行动去纠正。
- **与其他行为的区分**：道德驱动 vs 惩罚机制——"我不偷因为会被抓"是惩罚机制，"我不偷因为那是错的"是道德驱动。同一个不偷的行为，前者怕外部惩罚，后者怕违背自己的标准。道德驱动 vs 文化习俗——文化习俗是**外部脚本**（别人都这样所以我也这样），道德驱动是**内部标准**（即使别人都不这样我还是要这样）。
- **古典参照系**：舍生取义（孟子——生命可弃，义不可弃）、不食周粟（伯夷叔齐——道德驱动胜过饥饿和自我保存）、管宁割席（因价值观不合而断绝友谊——道德驱动割舍社会关系）、不为五斗米折腰（陶渊明——道德驱动拒绝奖励机制）

**文化习俗**

- **心理学定位**：文化习俗是个体从所处文化环境中**借用**的行为模板。与其他五种行为不同的地方在于——它的驱动力不来自个体内部（奖惩的预期、道德的判断、价值的排序），而来自**外部文化脚本**："这种情况下就应该这么做"。个体不需要理解为什么、不需要评估后果、甚至不需要产生与之匹配的情绪——只需要执行。核心特征是**行为由文化环境预先编写，个体不一定是思考者和感受者，只是执行者**。
- **触发条件**：处于特定文化场合（婚礼、葬礼、节日、职场）、他人都在做某件事（从众压力）、被文化规定了"应该怎么做"的模糊情境、跨文化碰撞（两种文化脚本冲突——选择遵从哪个？）
- **行为表现**：遵从（不加思考地执行文化模板）、从众（跟随群体的行为）、抗拒（意识到文化脚本后选择不遵从——但这通常消耗更多心理能量）、运用（有意识地操纵文化符号来达到目的——但此时主驱动不再是文化习俗，而是奖励机制或价值驱动）
- **在态度体系中的角色**：文化习俗的向量值通常为 0（中性）——它不预设方向，只提供模板。但它与其他行为驱动的互动非常有趣：文化习俗可以为道德驱动提供骨架（"我们文化中的道德规范是什么"）、文化习俗可以被奖励机制操纵（"按习俗做有奖赏"）、文化习俗与惩罚机制的关系最紧密——违背习俗的惩罚往往是社会性的（排斥、羞辱）。情绪方面，文化习俗与共情关系特殊——共情可以让你**感受到**文化习俗对他人的意义，从而更自然地执行它们，而不是机械服从。
- **与其他行为的区分**：文化习俗 vs 道德驱动——道德驱动是内化的（你认为这是对的），文化习俗是外借的（你的文化说这是应该的）。文化习俗 vs 惩罚机制——很多文化习俗背后的确有惩罚（违背习俗会被排斥），但执行文化习俗的那一刻，个体通常**没有在想惩罚**——只是照做。区别在于：惩罚机制的行为伴随着"我怕不做的后果"，文化习俗的行为没有这个计算过程。
- **古典参照系**：入乡随俗（文化切换——到了不同的文化环境就随那里的规矩）、繁文缛节（文化习俗过度增生反而成为负担）、约定俗成（荀子——名称、规矩都不是天经地义的，而是约定俗成的）、邯郸学步（文化习俗的同化压力可以使人丧失自我）

**价值驱动**

- **心理学定位**：价值驱动是行为系统里的**王牌**。当一个人为了某个高于其他一切的目标，可以违背生理反应（反射失效）、拒绝奖励（奖励机制失效）、接受惩罚（惩罚机制失效）、抛弃内化的道德（道德驱动失效）、无视文化期待（文化习俗失效）——这就是价值驱动在运作。核心特征是**行为优先级的彻底重新排序**：在所有其他驱动力给出的方向都是"不要做"时，价值驱动说"做"——并且它能赢。它不是"更强烈的奖励机制"——奖励机制追求的是**对自己有利的结果**，价值驱动追求的是**被认定高于自身利益的意义**。
- **触发条件**：遇到一个被认定为"高于自身利益"的目标或意义、其他所有驱动力都指向相反方向而目标仍然被坚持、必须在个人利益与更大价值之间做出选择、生命或身份面临根本性威胁时对意义的坚守
- **行为表现**：牺牲（放弃自身利益——物质、安全、名誉、甚至生命）、坚持（在所有反馈都说"停下来"的时候继续）、突破（做从未有人做过的事因为"这是一件需要被做的事"）、对抗（对抗整个系统、制度或时代——因为价值观说"这是错的"）、探索（明知道有危险还去——"搞懂这里的规则"被置于"安全"之上）
- **在态度体系中的角色**：价值驱动是唯一可以突破向量限制的行为——理论上它可以取 +1、0 或 -1 中的任何值，取决于价值方向。在态度组合中，价值驱动 + 恐惧 = 赴汤蹈火（你怕但你仍然去了），价值驱动 + 爱 = 鞠躬尽瘁（你爱这个目标胜过爱自己），价值驱动 + 悲痛 = 哀兵必胜（丧失之痛转化为不可阻挡的行动力）。价值驱动也经常与道德驱动同时出现，但两者可以分离——"为了一个高于自身道德的目标，放弃自己的道德"就是价值驱动压倒道德驱动的极限情况。
- **与其他行为的区分**：价值驱动 vs 奖励机制——两者都是趋近行为（行为 +1），但奖励机制追求的是**对自己有利的结果**，价值驱动追求的是**被认定高于自身利益的意义**。价值驱动 vs 道德驱动——道德驱动是关于**对错**的，价值驱动是关于**重要性的排序**的。一个行为可以同时是道德驱动和价值驱动（舍生取义——既是道德对错，也是价值排序），但也可以只是其中之一。
- **古典参照系**：鞠躬尽瘁死而后已（诸葛亮——价值驱动耗尽生命）、卧薪尝胆（勾践——十年屈辱换复国，所有其他驱动力都在说停止，价值驱动说继续）、人生自古谁无死留取丹心照汗青（文天祥——死亡与不朽的比较，价值驱动赢了）、我不入地狱谁入地狱（地藏菩萨——价值驱动主动选择承受苦难）

## 一、行为系统的定位

**v2.1 架构：行为系统 = 行为卡的约束层。** 不替代玩家选择，只决定哪些行为卡可用、成本多少、效果多大。(v2 把行为当成计算结果，已废弃。)

```
三类卡牌的地位:
  认知卡: "你怎么看" —— 玩家牌库基础组成部分
  情绪卡: "你感受到什么" —— 打出后产生 PAD 向量
  行为卡: "你做什么" —— 能否打出取决于当前 PAD 和认知状态

回合流程:
  1. 抽牌阶段
  2. 状态计算: PAD + 认知进度 → 驱动激活度 → 行为卡可用性/成本/效果
  3. 出牌阶段: 玩家打 1 认知 + 1 情绪 + 1 行为
  4. 结算阶段: 态度效果 + 行为惯性更新
```

行为系统的工作在步骤 2。输出给玩家的是一个**被约束的选择空间**，不是"最优行为"。

**核心公式：**
```
行为约束 = 可用性门控 + 成本调制 + 强制行为 + 效果调制
```

## 二、六种驱动

六种驱动不是六种动作——是六种**行为逻辑**。同一动作可能来自不同驱动，同一驱动可能表现为完全不同方向的动作。

| 驱动 | 默认 valence | 所属系统 | 核心语义 |
|------|-------------|---------|---------|
| **反射** | −1 | S1 (FFFS) | 身体替你做决定。不经过认知-情绪-行为链，直接从刺激到反应。 |
| **惩罚机制** | −1 | S1 (BIS) | 对负面结果的预判驱动行为修正。不需要惩罚已发生——只需要预期。 |
| **奖励机制** | +1 | S1 (BAS) | 对正面结果的预判驱动行为趋近。多巴胺通路——重要的不是获得奖励，是预期奖励。 |
| **道德驱动** | 0 | S2 | 内化的对错标准。唯一可以在无外部奖惩时改变行为的驱动力。 |
| **文化习俗** | 0 | 外部脚本 | 从文化环境借用的行为模板。个体不一定是思考者/感受者，只是执行者。 |
| **价值驱动** | ±1 | S2 override | 王牌。可以违背生理反应、拒绝奖励、接受惩罚、抛弃道德和文化。 |

**关键区分：**
- 反射 vs 惩罚机制：反射没有预期，惩罚机制有。"被烫缩手"是反射，"怕烫不碰"是惩罚机制。
- 惩罚机制 vs 道德驱动："我不偷因为会被抓" vs "我不偷因为那是错的"。
- 奖励机制 vs 价值驱动："我努力学习为了考高分" vs "我努力学习为了改变家族命运"。
- 道德驱动 vs 文化习俗：道德是内部标准，文化是外部脚本。

## 三、驱动激活计算

### 3.1 PAD 敏感度 (g_i)

```
g_reflex  = σ(2.0·max(0,A-0.3) + 1.5·max(0,0.5-D) - 0.5)
g_punish  = σ(2.5·min(0,P) + 1.0·max(0,A-0.2) - 0.3)
g_reward  = σ(2.5·max(0,P) + 0.8·max(0,A-0.2) - 0.35)
g_moral   = σ(2.0·max(0,D-0.1) + 1.0·(1-|A|) - 0.4)
g_culture = σ(1.5·(1-|D|) + 2.0·C_score - 0.3)
g_value   = σ(1.5·max(0,D-0.4) + 3.0·Override_signal - 0.7)
```

> 注意：上述 sigmoid 公式是实现细节。态度建模使用 PAD-情绪参考表的设计阈值（V≶0, D>−0.3 等）作为自然激活判定，σ 公式用于计算连续的激活强度。

### 3.2 激活条件总览 (设计阈值)

| 驱动 | 自然激活条件 | 硬解锁 | 不可用 |
|------|------------|--------|--------|
| 反射 | A>0.5 ∧ D<−0.3 | — (反射不可意志控制) | 其余全部 |
| 惩罚 | V<0 | V>0 (除共情管道特例外不可硬解锁) | 快乐/爱/平静/希望+惩罚 |
| 奖励 | V>0 | V<0 (可意志力强制趋近) | — |
| 道德 | D>−0.3 | D≤−0.3 (可意志力坚守) | — |
| 文化 | C_score 门控 (无PAD阈值) | 全部 15 情绪可走 | — |
| 价值 | D>0.3 | D≤0.3 (可意志力覆盖) | — |

## 四、行为卡约束层

### 4.1 可用性判定

```
行为卡 X (类型 i) 可以被打出 ⇔ α_i(t) ≥ θ_play_i
```

| 驱动 | θ_play |
|------|--------|
| 反射 | 0.15 |
| 惩罚机制 | 0.20 |
| 奖励机制 | 0.25 |
| 文化习俗 | 0.15 |
| 道德驱动 | 0.35 |
| 价值驱动 | 0.50 |

### 4.2 成本调制

```
cost_modifier_i = 1 + β_i · (1 - α_i(t))
```

| 驱动 | β_i |
|------|-----|
| 反射 | 0.5 |
| 惩罚机制 | 1.0 |
| 奖励机制 | 1.2 |
| 道德驱动 | 0.8 |
| 文化习俗 | 0.3 |
| 价值驱动 | 1.5 |

### 4.3 效果调制

```
行为卡 X 的效果 = base_effect_X · (1 + γ_i · (α_i(t) - θ_play_i))
```

| 驱动 | γ_i |
|------|-----|
| 反射 | 0.2 |
| 惩罚机制 | 0.5 |
| 奖励机制 | 0.6 |
| 道德驱动 | 0.7 |
| 文化习俗 | 0.2 |
| 价值驱动 | 1.0 |

### 4.4 强制行为（恐慌规则）

```
当 α_reflex(t) > θ_force (≈0.85):
  → 本回合必须至少打出一张反射类行为卡
  → 手牌无可用反射卡 → "僵住" 自动加入并强制打出
```

仅反射驱动有此规则。其他五类不设强制。

### 4.5 无可用行为卡时

**等待** (wait) 作为保底行为，始终可用：
- valence = 0, AP = 0, 效果 = 跳过本回合行为出牌
- 态度仅由认知+情绪决定 (行为轴 = 0)
- 等待也产生行为惯性更新 (μ_i 衰减生效)

## 五、情绪→行为因果链

### 5.1 双通路模型

```
通路 A (直接): 情绪 → B_raw → 行为推力 (快速, 粗糙, 不经过驱动系统)
通路 B (加工): 情绪 → 驱动激活门控 → B_drive (慢速, 精细, 经过驱动系统)

B(t) = λ_raw · B_raw(PAD) + λ_drive · B_drive(PAD, cog)
```

### 5.2 B_raw: 直接情绪推力 (Frijda 行动倾向)

```
B_raw = (valence: P, intensity: |A|, autonomy: D)
```

### 5.3 混合权重随 CPM 进度变化

```
λ_raw = exp(−cog_progress)
λ_drive = 1 − exp(−cog_progress)
```

| CPM 进度 | λ_raw | λ_drive | 主导系统 |
|----------|-------|---------|---------|
| 0 (刺激出现) | 1.00 | 0.00 | 身体先动 |
| 0.25 (关联性) | 0.78 | 0.22 | 反射/文化开始介入 |
| 0.50 (意涵) | 0.61 | 0.39 | 惩罚/奖励介入 |
| 0.75 (应对) | 0.47 | 0.53 | 道德驱动开始主导 |
| 1.00 (规范性) | 0.37 | 0.63 | 价值驱动激活 |

### 5.4 间接通路：情绪→认知→行为

情绪扭曲认知模块输出 → 认知前置条件改变 → 行为改变。跨越 2-4 回合，产生更持久的行为改变。

### 5.5 情绪混合

多张情绪卡 → PAD 加权平均 → 中间坐标 → 不同的驱动激活剖面。

```
恐惧(-P,+A,-D) + 愤怒(-P,+A,+D) → D≈0 → 对峙(高度警觉但行为冻结)
恐惧(-P,+A,-D) + 悲痛(-P,-A,-D) → A被拉低 → 崩溃性退缩
愤怒(-P,+A,+D) + 快乐(+P,+A,+D) → P≈0 → 兴奋的战斗欲
```

## 七、行为卡选择梯度

行为系统的约束不是二元的——是渐变的。

| 档位 | 条件 | 表现 |
|------|------|------|
| **优势卡** | α_i 远高于 θ_play | AP降低, 效果增强。驱动在推着你走。 |
| **劣势卡** | α_i 勉强超过 θ_play | AP升高。驱动不够——很费力但还能做。 |
| **惩罚卡** | α_i < θ_play 或驱动被压制 | 正常不可用。可花意志力"硬打"——消耗额外AP/SAN，效果打折。 |

**设计原则：** 同一组 (认知+情绪) 搭配不同档位的行为卡 → 态度性质不同。恐惧+逃跑(优势)=知难而退。恐惧+面对(惩罚档, 价值硬解锁)=逆流而上。态度的力度可能和它内部的张力成正比。

## 八、双系统仲裁

```
S1 驱动 (反射、惩罚、文化) → 激活快 → 早期回合可用
S2 驱动 (奖励、道德、价值) → 激活慢 → 需要认知推进后才解锁

时间线:
  回合 1: 反射 + 文化立即可用
  回合 2: 惩罚可用
  回合 3: 奖励可用

  回合 5: 价值可用
```

S2 压制 S1 时：被压制的 S1 行为卡可能仍可用，但效果被压制因子折扣 (0.3~0.7)。

## 九、照护驱动 (第七驱动)

> 状态：方案已定 (方案A)，具体参数和后续问题待落地。

### 9.1 为什么需要

共情在行为层没有执行器。PAD≈(0.46, −0.30, 0.09)，推力接近零。但现实中，共情是最强的行为驱动力之一。现有六种驱动都无法解释"母亲救孩子"的快速趋近。

照护驱动的特征：**快速（接近反射速度）、趋近（而非回避）、自动（不经过推论）、指向他人而非自身。**

### 9.2 神经基础

催产素-多巴胺通路，区别于：奖励机制（多巴胺-伏隔核）、道德驱动（前额叶规范性推理）、反射（杏仁核-PAG）。

### 9.3 激活公式

```
g_care = σ( w_vuln · Vulnerability_signal + w_attach · Attachment_strength - θ_care )

其中:
  Vulnerability_signal = 认知模块判定的 "对象需要帮助" 的强度 (0~1)
  Attachment_strength = 与对象的情感纽带强度 (0~1)

参数: w_vuln=2.5, w_attach=1.5, θ_care=0.3
```

**关键特性：读取的是被共情传递的他人 PAD，不是自身 PAD。** 自身可以在恐惧中 (P<0, A>0, D<0) 但照护驱动仍然激活。

### 9.4 行为拉力

```
s_valence   = +1.0  (强烈趋近需要帮助的对象)
s_intensity = 0.9
s_autonomy  = +0.7  (主动——"我要去")
```

### 9.5 时程

- 上升半衰期: 0.3 回合 (接近反射速度——看到→已经跳了)
- 衰减: 随 Vulnerability_signal 消退
- 照护完成 → g_care 快速衰减
- 照护被阻止 → g_care 持续高激活 + Arousal 上升 (挫败)

### 9.6 可被压制条件

- 自身 D < −0.7 (完全失控)
- Attachment_strength ≈ 0 (陌生人需要道德/价值补充)
- 共情疲劳: 连续多次照护后 θ_care 暂时 ↑

### 9.7 Attachment_strength (S) 计算

```
S = clamp( Σ 6因子, 0, 1 )
```

| 因子 | 范围 | 说明 |
|------|------|------|
| 先天纽带 | 0~0.4 | 血亲/恋人/密友/陌生人/敌对。初始设定，整局不变（但月光下可能被挑战） |
| 并肩经历 | 0~0.3 | 共同战斗 +0.02~0.04/场, 救助 +0.05~0.10, 背叛 −0.05~−0.15。连续无互动衰减 −0.01/场 |
| 脆弱性共鸣 | 0~0.2 | 对象脆弱信号强度 × 自身经历共鸣系数 |
| 互惠债务 | 0~0.15 | 欠对方的越多越倾向于帮。救过命→直接+0.15，衰减极慢 |
| 相似性 | 0~0.1 | 相同病情/经历/信仰/性格。贡献最小 |
| 负面纽带 | −0.3~0 | 攻击/伤害/背叛/归类为敌。S的下限clamp到0，不对敌人产生反照护 |

### 9.8 特殊敌人能力 (S 篡改)

- **"无辜的面孔"**：强制拔高 S_vuln + S_sim → 对敌人激活照护
- **"裂痕"**：临时 +0.2 队友 S_neg → 照护卡灰色
- **"镜中人"**：敌人的 S = 你的 S_sim → "你看到的是你自己"

### 9.9 与其他驱动的互动

- 照护 + 自身恐惧 → 冲向危险
- 照护 + 价值驱动 → 照护被赋予 "这不只是救一个人" 的叙事
- 照护被惩罚机制压制 → 旁观者效应
- 照护 + 道德驱动 → 照护被规范性框架合理化

## 十、跨遭遇参数漂移

### 10.1 三层混合模型

**核心主张：参数在后台漂移，倾向在镜中显现，改变在手中发生。**

#### 第 1 层：后台自动漂移（玩家不可见）

遭遇结束后根据战斗日志自动调整底层参数。

**漂移规则：**

```
反射敏化/脱敏:
  单场 α_reflex > 0.8 回合数多 → θ_reflex ↓ (敏化)
  连续多场 α_reflex < 0.3 → θ_reflex ↑ (脱敏)
  PTSD → 敏化速率↑↑, 脱敏速率↓↓

惩罚机制泛化/消退:
  激活后认知再评估 "无实际威胁" → θ_punish ↑ (消退)
  激活后 "确有威胁" → θ_punish 保持或↓
  焦虑 → 再评估偏误 (总判"有威胁") → 消退被阻止

奖励机制增益/衰减:
  趋近→成功 → g_reward ↑ (自我效能上升)
  趋近→失败 → g_reward ↓ (习得性无助)
  抑郁 → 失败放大↑↑, 成功衰减↑

价值驱动自我效能:
  覆盖成功 → θ_value ↓ (下次更容易)
  覆盖失败 → θ_value ↑ (道德损伤)
  成功的覆盖在叙事中被 "命名" → 漂移倍增
```

#### 第 2 层：倾向感知（镜子房间，质性呈现）

6 个玩家可感知的倾向维度：

| 倾向 | 底层映射 | 极端表现 |
|------|---------|---------|
| 惊觉度 | θ_reflex, τ_decay_reflex | 高→"一点响动就心跳加速" |
| 回避 | θ_punish, τ_decay_punish | 高→"你发现自己在避开很多东西" |
| 趋近 | θ_reward, g_reward | 低→"什么都不太吸引你" |
| 良心 | guilt_moral_coupling, θ_moral | 高→"一点小错就无法释怀" |
| 意志 | g_value, θ_value, ι baseline | 高→"你能在恐惧中坚持" |
| 固着 | τ_decay (全驱动平均) | 高→"过去的反应模式不易消退" |

**镜子房间呈现：** 镜中影像的行为/姿势/表情传达倾向，不贴数字。高惊觉→肩膀紧绷眼神扫动。低趋近→眼神空洞面无表情。高意志→站得笔直。

#### 第 3 层：主动干预（玩家 agency）

**A. 面具调整：** 不同面具组件对行为参数施加基线偏移。换面具=改变行为倾向"起点"，但不能抵消已累积的第 1 层漂移。

**B. 治疗行为：** 叙事窗口中的主动漂移（暴露疗法、价值确认、命名成功经历）。消耗叙事窗口（有限时机），不是想脱敏就能脱敏。

**C. 卡牌策略自我强化：** 牌库里某类卡占比高→对应参数倾向于同方向漂移。你用什么卡，就变成什么样的人。

## 十一、归因系统

> 跨遭遇参数漂移解决了"感知"，归因解决"理解"。

### 11.1 核心设计：归因即叙事选择

在月光的观察者效应下，"你相信自己变勇敢了"和"你真的变勇敢了"可以是一样的。

```
镜子房间中，变化有三个可能的归因:
  归因 A (创伤叙事): "我越来越容易被吓到，因为我正在崩溃。"
  归因 B (成长叙事): "我越来越警觉，因为我在适应这个环境。"
  归因 C (不叙事): "我不知道为什么。但它确实在发生。"

你选择相信哪一个 → 月光效应让这个解释获得部分现实性。
```

### 11.2 五层归因架构

| 层面 | 时机 | 内容 |
|------|------|------|
| 战斗层 | 战斗中 | 不解释。战斗中没有余裕分析自己。 |
| 战后总结 | 战斗结束 | 简短行为概览（痕迹），不标注因果。 |
| NPC 反馈 | 安全空间 | NPC 提供归因提议。"你注意到没有，每次遇到那种生物你第一反应都是后退。" |
| 镜子房间 | 安全空间 | 镜中影像展示倾向变化 + 记忆闪回。**玩家选择如何叙述。** |
| 治疗会话 | 节点性 (~每章一次) | 治疗师引导准确归因。"我们来回顾一下。你还记得那次面对之后的感受吗？" |

### 11.3 叙事选择的月光效应

选择"成长叙事"→ 覆盖行为获得增益。月光下，相信本身改变了机械现实。这不是面板欺骗——这是 CBT（认知行为治疗）的核心回路的游戏化。

# 跨遭遇参数漂移 — 三层混合模型

> 聚焦待解决问题 #1：行为参数如何在遭遇之间变化。

---

## 一、为什么这个问题值得单独讨论

当前行为模型 v2 的所有计算发生在一次遭遇 / 一场战斗的时间尺度上。驱动激活、双系统仲裁、惯性方程——全是一个回合到下一个回合的事。

但一场战斗结束后呢？角色带着什么进入下一场战斗？

如果一个角色在一场遭遇里：
- 反射被反复触发 6 次（被幻觉实体反复惊吓）
- 惩罚机制一直高激活（持续回避）
- 价值驱动从未激活（没有遇到 "值得覆盖恐惧" 的事）
- 道德驱动激活了一次但行为无效（做了对的事但没改变结果）

遭遇结束后，这个角色的行为系统参数还是原来的吗？

如果参数不变，那每一场战斗都是独立的——遭遇之间没有因果联系。战斗的经验没有被编码到角色的 "行为倾向" 里。

这和这个游戏的叙事前提直接矛盾——在一个治疗中心里，经历应该改变你。

---

## 二、两种极端的审视

### 完全隐式

参数全部在后台。每次遭遇后，根据战斗日志静默更新参数。玩家不知道自己的 θ_reflex 是 0.3 还是 0.7。玩家只能通过行为输出的变化间接感受到——"我怎么最近老是在逃跑？"

**优点：**

- 沉浸感最强。玩家通过体验发现自己的变化，而不是通过读取数字
- 更接近真实心理变化——你通常不是在 "查看自己的焦虑指数"，而是注意到 "最近出门前反复检查门锁"
- 可以制造惊喜和叙事转折——你以为自己好了，但某个情境触发揭示了你的参数并没有变
- 为叙事设计提供了 "揭示" 的空间

**缺点：**

- 玩家可能完全感知不到变化。如果行为输出的差异太微妙，参数漂移等于不存在
- 感觉不公平。"为什么我的角色这次逃跑了？"——玩家不知道参数被改了
- 难以 debug 和平衡
- 丧失了 "治疗" 的主动感——治疗中心里的患者应该主动参与自己的康复，但如果参数是黑箱，玩家没有 agency

---

### 完全显式

每个行为参数以数值展示在角色面板上。遭遇结束后，面板上的数字变动，变成绿色(+改善)或红色(-恶化)。玩家可以看到 "惊觉度: 0.72 → 0.68 (-0.04, 脱敏训练有效)"。玩家可以用资源（治疗点数/镜子房间时间）主动调整参数。

**优点：**

- 完全透明的因果关系。每一次选择的后果可见
- 玩家有 agency——可以制定 "康复策略"
- 参数变化成为明确的游戏目标
- 易于 debug 和平衡

**缺点：**

- 把心理变化变成属性 spreadsheet——可能严重破坏沉浸感
- "我需要把惊觉度刷回 0.5 以下" ——这和一个人真正处理创伤的体验相去甚远
- 参数变化 "被玩家盯着" 时，自然主义叙事变得困难——没法制造 "你以为你好了但你没有" 的时刻
- 参数之间可能有非直觉的互动——给了玩家数字但玩家不理解数字的涌现效果

---

## 三、为什么需要第三个方案

隐式太远——玩家没有 agency，浪费了 "治疗中心" 的叙事前提。

显式太近——把心理变化变成 Excel 表格，浪费了 "体验式叙事" 的可能性。

需要的是一种**玩家知道方向但不知道坐标**的模式。

类比：
- 你不会在 HUD 看到一个数字叫 "恐高症指数: 0.6"
- 但你会在上楼梯时感到心跳加速，画面边缘微微暗化
- 你**感到**了变化。你知道你在变。但你说不出精确的数字。

这就是三层模型想要达到的效果。

---

## 四、三层架构

### 第 1 层：后台漂移（自动，玩家不可见）

遭遇结束后，根据战斗日志自动调整底层参数。

**漂移规则（初步）：**

```
反射敏化/脱敏:
  单场战斗 α_reflex > 0.8 的回合数 > N
    → θ_reflex 小幅 ↓ (敏化——更容易被惊到)
  连续 M 场战斗 α_reflex 从未超过 0.3
    → θ_reflex 小幅 ↑ (脱敏——不那么容易被惊到)

  特殊: PTSD 角色 → 敏化速率 ↑↑, 脱敏速率 ↓↓
        (敏化容易脱敏难——这正是创伤的 "卡住" 特征)

惩罚机制泛化/消退:
  驱动激活后，认知模块事后再评估判定 "实际上没有威胁"
    → θ_punish 小幅 ↑ (消退——"上次白怕了")
  驱动激活后，认知模块事后再评估判定 "确有威胁"
    → θ_punish 保持或小幅 ↓

  特殊: 焦虑角色 → 再评估偏误 (总是判定 "确有威胁")
        → 消退被阻止 (假阳性自我验证)

奖励机制增益/衰减:
  目标导向行为成功 (奖励驱动激活 → 趋近 → 获得正面结果)
    → g_reward 小幅 ↑, θ_reward 小幅 ↓ (自我效能上升)
  目标导向行为失败 (奖励驱动激活 → 趋近 → 没有结果或负面结果)
    → g_reward 小幅 ↓ (习得性无助——"试了也没用")

  特殊: 抑郁角色 → 失败放大权重 ↑↑ (一次失败 = 大幅衰减)
        成功衰减权重 ↑  (一次成功不被承认——"只是运气")

价值驱动自我效能:
  价值驱动成功覆盖 S1 驱动 (覆盖信号 → 行为 → 正面结果)
    → θ_value 小幅 ↓ (下次覆盖更容易——"我做得到")
  价值驱动覆盖失败 (覆盖 → 行为 → 负面结果 或 行为未执行)
    → θ_value 小幅 ↑ (下次覆盖更困难——道德损伤)

  特殊: 成功的覆盖在叙事中被 "命名" 后 → 漂移倍增
        (语言标记巩固了自我效能——"那次我没有逃" 和不说出来是不同的)
```

**关键设计原则：漂移速率因角色病情而异。** 正常人的反射会自然脱敏，PTSD 的反射只敏化不脱敏——相同的遭遇历史产生不同的参数轨迹。这就是 "病情既是缺陷" 的计算定义。

---

### 第 2 层：倾向感知（玩家可见，但不以数字呈现）

底层参数太细碎（10+ 个），不适合直接对玩家展示。需要压缩为少数几个**可感知的行为倾向**，用质性而非量化的方式呈现。

**6 个玩家可感知的倾向维度：**

| 倾向 | 底层映射 | 极端状态的表现 |
|------|---------|--------------|
| **惊觉度** (Startle) | θ_reflex, τ_decay_reflex | 高→ "一点响动就心跳加速"；低→ "没什么能吓到你" |
| **回避** (Avoidance) | θ_punish, τ_decay_punish | 高→ "你发现自己在避开很多东西"；低→ "你不再因为害怕而退缩" |
| **趋近** (Approach) | θ_reward, g_reward | 高→ "你想要更多"；低→ "什么都不太吸引你" |
| **良心** (Conscience) | guilt_moral_coupling, θ_moral | 高→ "一点小错就让你无法释怀"；低→ "对错不再重要" |
| **意志** (Will) | g_value, θ_value, ι baseline | 高→ "你能在恐惧中坚持"；低→ "你很难违抗身体的反应" |
| **固着** (Fixation) | τ_decay (全驱动平均) | 高→ "过去的反应模式不容易消退"；低→ "你能灵活适应" |

**呈现方式——"镜子房间" 作为界面：**

项目文档已经将镜子房间定位为 "开局、构筑、单局收束的重要空间"。这恰好是倾向感知的天然载体。

每次进入镜子房间时，角色面对镜子，镜中映出的不是外貌，而是当前的行为倾向。具体表现：
- **不在镜子上贴数字**。而是通过镜中影像的行为、姿势、表情来传达
- 高惊觉 → 镜中的自己肩膀紧绷，眼神快速扫动
- 低趋近 → 镜中的自己眼神空洞，面无表情
- 高意志 → 镜中的自己站得笔直，一动不动
- 高固着 → 镜中的自己重复同一个姿势，像卡住了

镜子是一种**模糊但可读的界面**。你看得到变化，但你说不出精确数值。变化的方向和幅度是清晰的，足够支撑 "我需要改变什么" 的决策。

这为 "镜子房间是开局、构筑、收束的重要空间" 提供了具体的机械含义：
- **开局**：第一次进入 → 看到自己的初始倾向 → 建立 baseline 认知
- **构筑**：遭遇之间回来 → 看到倾向的变化方向 → 决定下一步策略（继续暴露？休息？换面具？）
- **收束**：重大节点后回来 → 看到累积变化的全貌 → 叙事总结（"你变了" 的具体内容）

---

### 第 3 层：主动干预（玩家有意识的行为）

有了感知（第 2 层），玩家需要能**做些什么**来改变自己不想要的倾向。这是 agency 的入口。

**干预手段：**

**A. 面具调整（角色构筑层面）**

面具已经设计了 "轮廓表示主原型，装饰表示共享症状"。行为倾向可以成为面具构筑的一部分：
- 不同的面具组件对行为参数施加**基线偏移**
- 换面具 = 改变行为倾向的 "起点"
- 但面具不能抵消第 1 层的漂移——它只能提供一个补偿性的基线

例如：
- "猎人的轮廓" → θ_reflex +0.2（降低惊觉度基线）
- "母亲的装饰" → g_value +0.15（提升意志基线）
- 但如果你的底层 θ_reflex 因为反复创伤已经降到 0.1，面具的 +0.2 只是拉到 0.3——你仍然比正常人更容易受惊

**B. 治疗行为（叙事/资源层面）**

某些特定的叙事行为可以主动漂移参数，且漂移量大于被动漂移：
- 在安全环境中**主动暴露**于恐惧刺激 → θ_reflex 显著 ↑（系统性脱敏）
- 完成**价值确认**叙事事件 → θ_value 显著 ↓（"我重新确认了什么比我自己重要"）
- **命名**过去的成功覆盖经历 → 巩固自我效能（语言标记效应——对应世界观中 "命名赋予现实性" 的设定）

这些行为消耗的不是普通行动点，而是**叙事窗口**——有限的、只出现在特定时机的选择。不是 "我想脱敏就能脱敏"——你需要在治疗师引导下、在安全空间里、在自己准备好的时候。

**C. 卡牌/牌库调整（构筑层面）**

玩家的牌库构成会影响第 1 层的漂移方向：
- 牌库里惩罚机制相关的卡牌占比高 → θ_punish 更倾向于 ↓（你的策略本身就是回避导向的，你越用越回避）
- 牌库里价值驱动相关的卡牌占比高 → θ_value 更倾向于 ↓（你总是尝试覆盖，覆盖越来越容易）
- 这不是直接改参数——这是**牌库策略的自我强化效应**。你用什么样的卡，你就变成什么样的人。

## 五、三层之间的信息流

```
遭遇战斗
    │
    ▼
[第 1 层] 后台自动漂移
    │  根据战斗日志 + 角色病情 modifier 调整底层参数
    │  玩家不可见
    │
    ▼
  底层参数变化累积到阈值
    │
    ▼
[第 2 层] 倾向感知更新
    │  镜子房间: 行为倾向的质化呈现更新
    │  游戏世界: NPC 对话反映你的变化 ("你最近好像不太一样了")
    │  行为输出: 驱动激活剖面改变 → 玩家在战斗中感受到差异
    │
    ▼
[第 3 层] 玩家主动干预
    │  面具调整: 补偿性基线偏移
    │  治疗行为: 叙事窗口中的主动漂移
    │  卡牌策略: 牌库构成的自我强化
    │
    ▼
  干预效果 → 反馈到第 1 层的底层参数
    │
    ▼
下一场遭遇 — 带着改变后的行为系统进入
```

## 六、一个完整的例子

```
角色: 苟智空 (暂定)
病情: PTSD (基线: θ_reflex 偏低 = 容易受惊, τ_decay_reflex 偏长 = 惊到后缓不过来)

初始状态 (第 1 层):
  θ_reflex = 0.30  (正常人 0.50)

遭遇 #1: 在走廊遇到具象化的 "猴子" (成瘾的具象化敌人)
  战斗过程:
    第 1 回合: 猴子突然出现 → PAD 恐惧 → 反射高激活 (α=0.91)
    第 2 回合: 仍然在反射主导下逃跑
    第 3 回合: 认知推进, 奖励机制激活 → 决定面对
    第 4 回合: 使用价值卡 "我答应过师父" → 价值覆盖, 击败敌人

  遭遇后第 1 层更新:
    反射过度激活 (2 回合 α>0.8) → θ_reflex: 0.30 → 0.24 (敏化!更敏感了)
    价值覆盖成功 → θ_value: 0.70 → 0.62 (自我效能上升)
    τ_decay_reflex 因为 PTSD 特殊参数 → 不降反升 (更长的恢复期)

遭遇 #2: 安全场景 —— 治疗室对话, 无战斗

遭遇 #3: 再次进入走廊
  B_raw 因 θ_reflex 降低 → 同样的惊吓刺激, 反射激活更快更强
  但 θ_value 也降低了 → 价值覆盖的阈限更低 → "我上次做到了,这次也行"

  玩家体验:
    第 1 回合: "操怎么又跑了!" —— 反射比上次更快触发 (θ_reflex 降低的效果)
    第 2 回合: 但这次只用 1 回合就稳住了 (θ_value 降低的效果 —— "上次覆盖的经验加快了这次的反应")

镜子房间 (第 2 层):
  战斗之间进入镜子房间:
    惊觉度: ↑ (比上次更高了 —— PTSD 的敏化在继续)
    意志:  ↑ (但也更强了 —— 价值驱动的自我效能在累积)
    NPC 评论: "你最近反应更大了，但你也更快地稳住了自己。"

玩家决策 (第 3 层):
  看到惊觉度在恶化 → 决定:
    A. 在下次治疗窗口尝试 "系统脱敏" 叙事事件 (主动提升 θ_reflex)
    B. 或者换一个有 "镇静" 效果的面具装饰 (补偿性基线偏移)
    C. 或者接受 "高惊觉" 作为角色特征, 转而强化意志/价值路线
```

## 七、需要回答的后续问题

1. **漂移量级**：一场战斗的自动漂移幅度多大？如果幅度太小 → 玩家感觉不到变化。太大 → 参数在一两次遭遇后就极端化。需要定义 "累积多少次遭遇后，行为发生可感知的变化"。

2. **漂移天花板和地板**：参数不能无限漂移。θ_reflex 不能降到 0（任何刺激都触发反射）或升到 1（永远不反射）。硬边界是什么？

3. **角色差异**：不同角色的基线参数在哪里读取？是与面具绑定（换面具 = 新基线），还是与角色绑定？还是两者叠加？

4. **死亡/失败的处理**：如果一场战斗失败（角色被敌人击溃），第 1 层的漂移是否仍然发生？还是失败抹去了这次遭遇的学习效果？

5. **多人关系中的漂移**：如果队友的行为影响了角色，队友行为是否也会触发第 1 层漂移？（例如：队友背叛 → 信任损伤 → θ_punish ↓）

---

## 八、建议

三层混合模型的核心主张可以概括为一句话：

> **参数在后台漂移，倾向在镜中显现，改变在手中发生。**

这不是隐式和显式之间的折中——这是三个不同功能的三层。第 1 层保证因果性（遭遇改变你），第 2 层保证可读性（你知道你在变），第 3 层保证 agentivity（你能做些什么）。

建议下一步：定义第 1 层的具体漂移公式（漂移量级、天花板/地板），确定第 2 层镜子房间的呈现语言（视觉隐喻 vs 文字描述），明确第 3 层中 "治疗行为" 的叙事窗口机制。

# 归因问题 — 玩家如何知道 "我为什么变了"？

> 跨遭遇参数漂移的后续追问。三层模型解决了**感知**（第 2 层让你看到变化），但没有解决**归因**（你不知道为什么变了）。

---

## 一、为什么这个游戏绕不开归因

普通 RPG 里这不是个问题。力量 +1 就是 +1，玩家知道是因为升了级 / 穿了装备。因果链是面板级别的，不需要解释。

但这个游戏的因果链涉及：
- 你在战斗中逃跑了 4 次
- 这 4 次里有 3 次事后证明其实没有威胁
- 但你的反射系统不知道 "事后证明"——它只在当下触发了
- 与此同时你的价值驱动激活了一次但失败了
- 这两件事叠加：回避被强化了，覆盖被削弱了

**这不是面板级别的因果。这是心理级别的因果。**

而 "理解自己的心理变化的原因" ——这恰好是这个游戏的主题。一个关于治疗中心的游戏，如果角色不知道为什么自己变成了这样，那治疗在治什么？

---

## 二、五条路

逐一审视各自的前提和代价。

### 路 1：完全透明 — 机械归因

```
战斗结束后弹出日志：
  θ_reflex: 0.30 → 0.24 (-0.06)
    原因: 反射激活 6 回合 (3 回合 α>0.9, 3 回合 α>0.8)
    其中 4 回合的威胁在事后被认知再评估判定为 "不存在"
    但反射不读取再评估结果，仍然敏化
    PTSD modifier: 敏化速率 ×1.5

  θ_value: 0.70 → 0.62 (+0.08)
    原因: 价值驱动覆盖反射成功 (1 次)
    覆盖类型: 恐惧场景中的道德-价值联合覆盖
```

**前提假设：** 玩家需要、想要、且能消化精确的因果数据。心理变化可以被面板化而不损失其心理性。

**代价：**
- 把心理变化变成了 spreadsheet。角色不再是一个正在经历创伤的人，而是一组可以被优化的参数
- "我需要把 θ_reflex 刷回 0.5" ——这和治疗的目标在表面上是同一个方向（降低惊觉），但在体验上完全不是同一件事。一个是 "我理解了我的恐惧并学会面对它"，一个是 "我把一个属性值调回了目标区间"
- 完全透明消灭了自我认识的模糊性——而这个游戏的主题恰好是 "在月光下，你相信什么，什么就更真实"。如果你的参数面板告诉你精确的 θ_reflex = 0.24，这和你 "相信自己已经好了" 之间是什么关系？面板会揭穿自我欺骗，而自我欺骗可能是游戏的重要叙事工具

**何时这条路是对的：** 如果游戏的核心 fantasy 是 "通过资源管理优化自己的心理健康"——像 Darkest Dungeon 那样。但 Darkest Dungeon 的角色不是 "你"——你管理的是雇佣兵。这个游戏的角色是你自己。

---

### 路 2：完全模糊 — 零归因

```
战斗结束后：什么提示都没有。

下次进入镜子房间：
  惊觉度 ↑ (偏高)
  回避 ↑ (偏高)

没有解释。你自己想。
```

**前提假设：** 玩家能从游戏体验中自己推断出因果。不需要系统告诉 "为什么"——你经历了战斗，你应该知道。

**代价：**
- 大多数玩家**不知道**。他们会把镜子里的变化当作随机事件或者剧本强制的走向
- "我不知道我做了什么导致了这个" → 丧失 agency → "这个游戏里的选择真的重要吗？"
- 玩家可能做出错误归因："一定是因为我用了那张卡"——而实际原因可能是完全不同的机制
- 错误归因 + 玩家据此调整策略 → 策略失败 → 更大的挫败感

**何时这条路是对的：** 如果游戏是纯叙事体验，所有变化都是作者意图而非涌现结果。但行为系统是涌现的——变化来自系统计算，不是剧本。涌现结果不解释 = 黑箱 = 玩家无法学习。

---

### 路 3：叙事归因 — 角色的理论

```
战斗结束后：
  角色的内心独白: "自从在走廊里被那个东西追过之后，我好像不太敢一个人走路了。"

这个独白捕捉到了变化的方向（更害怕独处），但：
  - 不写具体数字
  - 因果链是角色的解读，不一定等于实际的机械因果
  - 可能正确，可能片面，可能完全错误
```

**前提假设：** 归因本身是一种叙事行为，可以由角色来完成，不需要由系统直接向玩家广播。

**代价：**
- 实现成本高——需要大量叙事模板覆盖各种因果场景
- 角色的归因可能和玩家的体验不一致——"我没有觉得我怕独处，我只是在那个场景里合理地选择了逃跑"——玩家和角色对同一件事的解读分裂了
- 但如果这个分裂本身就是设计意图呢？——角色说 "我变懦弱了"，玩家知道 "不，那不是懦弱，那是唯一合理的策略"——玩家对角色产生了超越角色自我认知的理解。这是一种高级叙事体验，但不是所有玩家都会这样解读

**何时这条路是对的：** 如果归因被设计成游戏内容而非游戏界面——角色对自己的理解本身就是叙事的一部分。Disco Elysium 用技能之间的对话来做这件事。

---

### 路 4：治疗式归因 — 结构化反思

```
战斗结束后: 无反馈。

回到安全空间后:
  NPC (治疗师/同伴): "你最近好像不太对劲。上次从地下室回来后，你就一直在避开走廊。"
  
  这是一个 "归因提议"——NPC 给出了一个因果假设。

镜子房间:
  不是显示数字，而是显示**记忆片段**——战斗中反射被高度激活的那些时刻的闪回。
  "这些时刻改变了你的身体记忆。"

治疗会话 (周期性叙事事件):
  "我们来谈谈地下室的那次遭遇。你连续逃了四个回合。前三个回合你确实在面对威胁。但第四个回合，威胁已经过去了——你还在逃。你还记得当时在想什么吗？"
  
  这是引导玩家自己做归因，而不是系统替玩家归因。
```

**前提假设：** 归因不是一次性的信息传递，而是一个过程。这个过程本身就构成了 "治疗" 的游戏内容。系统有机械真相，但系统不直接广播——系统引导玩家自己去发现。

**代价：**
- 设计复杂度最高。需要设计 "归因引导" 的叙事机制
- 节奏控制：归因不能太频繁（打断游戏），也不能太少（积累困惑）
- 对不习惯这种 "慢归因" 的玩家可能感到困惑——"到底发生了什么？为什么没人直接告诉我？"

**何时这条路是对的：** 如果归因被当作核心玩法——"理解自己" 就是游戏的主要行动之一，不是战斗结算的附属品。

### 路 5：因果痕迹 — 不解释，但留下线索

```
战斗结束后:
  行为总结 (与普通卡牌游戏的战斗总结类似):
    "本场战斗行为概览:
      回避行为: ████████░░ 8 回合
      趋近行为: ██░░░░░░░░ 2 回合
      覆盖行为: █░░░░░░░░░ 1 回合"
  
  不解释 "这意味着什么"。但展示了原始数据。

下次进入镜子房间:
  惊觉度升高了。
  如果你回顾上次战斗的总结，你可以自己做连接:
    "8 回合回避 → 惊觉度升高。嗯。"

  系统不替你做这个连接。但系统确保**线索和结果在时间上是接近的**。
```

**前提假设：** 玩家不需要被告知因果——只需要被提供足够的**可见的中间状态**，让他们自己做推断。这尊重了 "自我认识" 的过程，同时没有完全隐去机械数据。

**代价：**
- "行为总结" 本身已经是一种面板化——"回避行为 8 回合" 就是一个数字指标
- 不同玩家做推断的能力差异很大——有些人能一眼看出模式，有些人完全不会去想
- 错误归因仍然存在—— "我用了太多惩罚机制卡牌" vs "我用了惩罚机制卡牌但关键是那 4 次无威胁的回避"——玩家可能把原因归结到卡牌选择而不是情境判断

**何时这条路是对的：** 如果目标是 "给有洞察力的玩家一套侦探工具，让他们自己解开自己的心理谜题"。

## 三、核心矛盾不是技术性的

五条路之间的差异，不是 "哪条更精确" 或 "哪条更好实现"。差异在于对以下问题的不同回答：

> **"理解自己的心理" 在这个游戏里是手段还是目的？**

- 如果是**手段**——玩家理解参数因果是为了更好地 build 和战斗 → 路 1（透明面板）或路 5（痕迹线索）
- 如果是**目的**——理解自己的过程本身就是游戏要模拟的东西 → 路 3（叙事归因）或路 4（治疗式归因）

这个游戏的设计目标是什么？

项目文档说：*"玩家控制患病角色，尽可能选择正确的态度去面对事情；或者即使选择不对应的态度，但配合病情反而能达到很好的效果。"*

这段话里，"理解自己" 更像手段——你知道自己有什么病，你据此选择态度。

但同一份文档也说：*"在观察者效应框架下，额外存在一种胜利路径：让敌人 '相信自己被打败了'。"*

"相信" 是认知层的操作——你改变的不是现实，而是对现实的认知。如果同样的逻辑适用于玩家自身——"你相信自己变勇敢了" 和 "你真的变勇敢了" 在月光下可以是一样的——那归因就不再是 "报告真相"，而是 **"选择相信哪个版本的自己"**。

这就彻底变了。

## 四、一个更大胆的方案：归因即叙事选择

如果月光的观察者效应不仅作用于敌人，也作用于玩家自身：

```
在镜子房间里，你看到自己的变化，但变化有三个可能的 "归因":

  归因 A (创伤叙事): "我越来越容易被吓到，因为我正在崩溃。"
  归因 B (成长叙事): "我越来越警觉，因为我在适应这个环境。"
  归因 C (不叙事): "我不知道为什么。但它确实在发生。"

你选择相信哪一个？

如果你选择归因 A → 你的角色接下来的行为被创伤框架染色。
  同样的反射激活，叙事标签是 "我又在逃了" → 可能强化回避倾向
如果你选择归因 B → 同样的反射激活，叙事标签是 "我更敏锐了" → 可能降低回避倾向
如果你选择归因 C → 没有叙事框架 → 继续观察
```

这不是在粉饰现实——这是在**选择你对现实的解释**，而月光的观察者效应让这个解释获得部分现实性。

这个方案的前提是：**游戏敢于让玩家的自我认知和机械现实之间存在张力。** 你相信你变勇敢了，系统参数没有变，但因为月光效应，"相信" 本身给覆盖行为提供了一个增益——所以你实际上通过相信变勇敢而真的变勇敢了一点。

这不是 "面板欺骗玩家"。这是 **"叙事自我" 和 "机械自我" 之间的反馈回路**——认知行为治疗 (CBT) 的核心就是这个回路。"改变你对自己行为模式的叙述" 本身就是一种有效的治疗。

## 五、我的立场

路 4（治疗式归因）作为主体框架，但注入路 3 和上述 "叙事选择" 的元素。

具体来说：

**战斗层面：** 不解释。你在战斗中，你没有余裕分析自己。战斗结束后最多给一个简短的行为总结（路 5 的痕迹），不标注因果。

**安全空间层面：** NPC 提供归因提议（路 4）。"你注意到没有，每次遇到那种生物，你第一反应都是后退。" 这是镜子房间之外的、社交维度的反馈。NPC 的归因可能对可能错——不同的 NPC 给出不同的解读。

**镜子房间（核心）：** 这是你自己的反思空间。没有 NPC 告诉你怎么回事——你自己看。镜中的影像展示你的倾向变化（感知层），同时呈现记忆闪回——那些驱动高度激活的时刻。**你可以选择如何叙述这些变化**——"我在崩溃" vs "我在适应" vs "我需要更多时间理解"。你选择的叙述影响月光效应对你的反馈。

**治疗会话（节点性）：** 不频繁——可能每章一次或者每个重大事件后一次。治疗师帮你连接因果："我们来回顾一下。地下室的遭遇之后，你的惊觉反应变强了。但你在走廊那次主动面对了它。你还记得那次面对之后的感受吗？" 这是引导你做**准确归因**的时刻——不是替你做，而是帮你做。

**为什么是这个组合：**
- 日常体验保留了心理变化的模糊性（你不总知道你为什么变了）
- 社交反馈给了外部视角（别人看到你没看到的东西）
- 镜子房间给了 agency（你选择如何理解自己）
- 治疗会话给了准确性（在叙事节点上，有人帮你把碎片拼起来）

## 六、仍要回答的问题

1. **"叙事选择" 的月光效应该如何定量？** 如果你选择相信自己 "更勇敢了"，覆盖行为获得多大的增益？增益应该足够显著让选择有分量，但不能大到让机械层面完全被叙事覆盖取代。

2. **错误归因的后果如何呈现？** 如果你在镜子里选择了 "我在适应" 但实际参数在恶化——什么时候、以什么方式，现实会撞破你的叙事？一场无法逃避的战斗？一次镜子给出的 "真实反馈"？还是某个 NPC 的直接戳破？

3. **治疗师的 "正确率" 是多少？** 治疗师应该比 NPC 同伴更准确，但不应该全知。治疗师也可能犯错——如果她错了，玩家能发现吗？

4. **归因选择是否应该是不可逆的？** 你今天相信 "我在变勇敢"，过了三场战斗发现不是这么回事——你能改变你的叙事吗？还是旧的叙事会留下痕迹？
