# 心境与情绪 — 两层模型

> 区分**心境（mood）**和**情绪（emotion）**两个时间尺度，解决"手牌缺情绪卡→PAD 断电"的架构问题，同时为情绪选择提供跨战斗的战略后果。
>
> 边界之外不是硬 clamp——是**暴走/宣泄/萎靡**的周期循环。

---

## 一、设计动机

当前链路中 PAD 的唯一生产源是情绪卡。手牌缺情绪卡 → 驱动激活无法计算 → 行为卡全部灰色。这对应初始设计随笔中已经标记的问题：

> "三种态度卡片总会有不能同时出现在手上的可能性" — `卡牌系统.md`

两层模型的回答：**心境是背景辐射，情绪卡是脉冲信号。** 没有情绪卡的回合，心境的 PAD 仍然驱动行为系统；打出情绪卡时，当前 PAD 在心境基础上偏移。情绪卡不是"制造 PAD 的开关"，而是"扰动 PAD 的力"。

---

## 二、心理学依据

心境和情绪在情感科学中是明确区分的基础概念：

| | 心境 (Mood) | 情绪 (Emotion) |
|---|---|---|
| **时程** | 数小时到数天 | 数秒到数分钟 |
| **对象** | 弥漫性，无特定触发事件 | 有明确触发事件 |
| **强度** | 低强度，背景性 | 高强度，占据性 |
| **意识** | 常不被觉察（"我就是觉得低落"） | 被强烈意识到（"我现在很愤怒"） |
| **神经底物** | 5-HT/NE tonic 水平 | 多巴胺/NE phasic 爆发 |
| **功能** | 设定认知和行为的基线偏向 | 对具体事件的即时反应 |
| **游戏中** | 战略层——跨战斗缓慢变化 | 战术层——战斗内快速波动 |

心境障碍（如抑郁症）和情绪反应（如恐惧条件反射）涉及不同的神经回路和药理干预靶点——这个区分有独立的实证基础，不只是一种便于设计的分类。

---

## 三、变量命名

| 变量 | 含义 | 变化速度 |
|---|---|---|
| **PAD_mood** | 心境 PAD——弥漫性情感底色 | 跨战斗（η_mood = 0.15/场） |
| **PAD_curr** | 当前 PAD——此刻的情感状态 | 战斗内（每回合更新） |
| **PAD_card** | 情绪卡的自带 PAD 坐标 | 固定（NRC VAD 数据，15 锚点） |
| **PAD_set** | 角色心境设定点——"你本来的样子" | 固定（由病情决定，叙事节点可修改） |
| **PAD_exp** | 战斗情绪经历——战后稳定化的输入 | 每场战斗一次 |

## 四、心境层

### 4.1 初始心境

角色进入游戏时的 `PAD_mood`。不同角色的初始心境不同——它本身就是"病情"在情感层的表达：

| 角色类型 | PAD_mood 初始值 (V, A, D) | 设定依据 |
|---------|--------------------------|---------|
| 正常人 (苟智空) | (+0.30, −0.30, 0.00) | 在治疗中心里略有不安，但基本稳定 |
| 抑郁症 | (−0.40, −0.30, −0.50) | 低愉悦、低唤醒（精神运动迟滞）、低控制感 |
| 焦虑症 | (−0.30, +0.50, −0.40) | 高警觉、低控制感 |
| PTSD | (−0.20, +0.50, −0.40) | 持续性过度警觉 |
| 躁狂症 | (+0.60, +0.50, +0.55) | 高愉悦、高唤醒、高控制感（夸大） |
| 双相障碍 | 取决于当前相 | 抑郁相 = 抑郁心境，躁狂相 = 躁狂心境 |
| 自闭症 | (0.00, −0.50, −0.10) | 低唤醒（对外部刺激反应弱）、略低控制 |

> 上表为初步参照，具体数值需要在模拟中校准。PAD_set 初始值 = PAD_mood 初始值，PAD_set 在整局游戏中不变，除非关键叙事节点触发修改（如镜子房间的自我认知重构）。

### 4.2 心境在战斗中的角色

**心境在战斗中只读**——它是 PAD_curr 的回归目标和衰减锚点。

```
战斗开始:  PAD_curr = PAD_mood（当前情绪从心境起步）
战斗进行:  PAD_curr 随情绪卡偏移，回合间向 PAD_mood 回弹
战斗结束:  PAD_curr_end → 经过稳定化 → PAD_mood 被部分更新
```

### 4.3 无情绪卡时的行为

即使手牌没有情绪卡，`PAD_curr` 仍然存在（= PAD_mood，或上一回合遗留的 PAD_curr）。驱动激活函数 `g_i(PAD_curr)` 直接可用，行为卡门控正常运作。情绪卡从"必需品"变成"调控工具"。

## 五、当前情绪层

### 5.1 情绪卡偏移公式

打出情绪卡时，PAD_curr 向 PAD_card 方向偏移：

```
ΔPAD = κ_eff × (PAD_card − PAD_curr)

PAD_curr_new = PAD_curr + ΔPAD
             = (1 − κ_eff) × PAD_curr + κ_eff × PAD_card
```

其中 `κ_eff` 是有效偏移系数，综合了基础偏移率和同情绪 ln 累积递减（见 5.2–5.3）。

**为什么用"拉向"而非"设为"：** 情绪卡不是直接替换当前情绪——它是在已有情绪底色上的一次扰动。心境低落时被打了一针"快乐"，不会瞬间变成完全的快乐，只是被拉向快乐方向一部分。

### 5.2 基础偏移系数 κ_base

```
κ_base = 0.30  (默认值)

调制因素:
  SAN 低 → κ_base ↑（精神脆弱时情绪波动更大）
    每低于 maxSAN 的 20%，κ_base +0.05
    例: SAN = 40/100 → κ_base = 0.30 + 0.05×3 = 0.45

  病情 → κ_base 偏移:
    抑郁症: κ_base − 0.05（情感迟钝 / flattening）
    焦虑症: κ_base + 0.10（情绪反应性增强）
    PTSD:   κ_base + 0.10（过度警觉 → 情绪放大）
    躁狂:   κ_base + 0.05（情绪不稳定）

  萎靡期间: κ_base × 0.5（见 §8.3）
```

κ_base = 0.30 的直觉示例——从平静心境打恐惧卡：

```
初始 PAD_curr = PAD_mood = (0.60, −0.76, 0.11)  [平静]
打出恐惧卡 PAD_card = (−0.85, 0.68, −0.41)

V: 0.60 + 0.30×(−0.85−0.60) = 0.60 − 0.435 = +0.165
A: −0.76 + 0.30×(0.68−(−0.76)) = −0.76 + 0.432 = −0.328
D: 0.11 + 0.30×(−0.41−0.11) = 0.11 − 0.156 = −0.046

PAD_curr_new ≈ (+0.17, −0.33, −0.05)
```

不像纯粹的恐惧，但明显向恐惧方向移动。一张卡 ≈ 30% 的"拉近"。

### 5.3 同情绪重复的 ln 边际递减

多次打出同一种情绪卡，每次的边际偏移递减。复用现有累积公式的 ln 结构：

```
κ_eff(n) = κ_base × f_ln(n, k) / f_ln(1, k)

其中:
  f_ln(n, k) = ln(1 + k·n) − ln(1 + k·(n−1))    ← 第 n 次的边际贡献
  k = 0.3 + 0.7 × |A_card|                         ← 唤醒度越高，递减越快
  n = 本场战斗中该情绪卡被使用的次数

归一化因子 f_ln(1, k) = ln(1 + k) 保证 κ_eff(1) = κ_base
```

**递减示例（恐惧卡，k = 0.3 + 0.7×0.68 ≈ 0.78）：**

| 第 n 次 | f_ln | κ_eff / κ_base | 实际 κ_eff (κ_base=0.30) |
|---------|------|----------------|--------------------------|
| 1 | 0.577 | 1.000 | 0.300 |
| 2 | 0.366 | 0.634 | 0.190 |
| 3 | 0.268 | 0.464 | 0.139 |
| 4 | 0.210 | 0.364 | 0.109 |
| 5 | 0.171 | 0.296 | 0.089 |

高唤醒情绪（如恐惧 |A|=0.68）递减更快——连续恐惧刺激的效应迅速饱和，符合神经适应性实证模式（杏仁核对重复威胁刺激的 BOLD 反应在 3-5 次后显著衰减）。

> **设计直觉**：反复打同一张情绪卡的有效性快速下降。玩家被鼓励情绪多样化——但如果真想强化某种情绪，正常路径被 ln 递减限制，**暴走路径**提供了另一个选择（见 §8）。

### 5.4 多情绪混合

不同情绪卡先后打出时，各自独立计数（n 按情绪类型分别计算），但 PAD_curr 是共享的。后打的情绪卡从**当前 PAD_curr**（已被前面情绪卡偏移过的状态）出发再偏移。

```
例子:
  回合 1: 打 恐惧 → PAD_curr 从心境向恐惧偏移 ~30%
  回合 2: 打 愤怒 → PAD_curr 从(近恐惧)状态向愤怒偏移 ~30%
  回合 3: 再打 恐惧 → n_恐惧 = 2, κ_eff 降到 0.190
```

情绪顺序有策略意义——先用低成本的情绪铺路，再用想强化的情绪卡（n 低 → κ_eff 高）主导最终状态。

### 5.5 回合间衰减（向心境回归）

每回合结束时，PAD_curr 向 PAD_mood 方向回弹：

```
PAD_curr(t+1) = PAD_mood + (PAD_curr(t) − PAD_mood) × (1 − δ)

δ = δ_base + δ_A + δ_D
δ_base = 0.20            ← 基础衰减率
δ_A    = 0.15 × |A_curr| ← 高唤醒情绪衰减更快
δ_D    = −0.10 × D_curr  ← 高控制情绪更持久（D 正 → δ 减小）
```

与 `态度系统.md` 中现有衰减公式的参数结构一致，但目标从"归零"改为"归心境"。

**衰减直觉**：
- 平静心境 + 恐惧爆发 → δ ≈ 0.35，2-3 回合后显著回弹
- 恐惧心境 + 恐惧爆发 → 衰减慢（PAD_curr 离 PAD_mood 本来就近）
- 快乐 + 高 D → δ 较小，快乐更持久（控制感降低衰减率）

### 5.6 变量追踪

战斗中需要追踪的状态变量：

```
PAD_mood:    (V, A, D)  — 本场战斗恒定
PAD_curr:    (V, A, D)  — 每回合更新
n_emotion:   {emo_name: count}  — 每种情绪卡的本场使用次数（用于 ln 递减）
emo_active:  emo_name | None  — 最近一张情绪卡的名称（用于 C_control 查表，见 §6）
is_berserk:  bool  — 是否处于暴走回合
is_lethargy: int   — 萎靡剩余回合数（0 = 正常）
```

## 六、C_control 的适配

当前 C_control 表按 `情绪名 × 驱动` 查表。在两层模型下，`PAD_curr` 是混合态——不是任何单一离散情绪的坐标。

**适配方案：使用最近一张情绪卡的名称查 C_control 表。**

```
如果本场战斗至少打过一张情绪卡:
  emo_active = 最近一张情绪卡的名称
否则:
  emo_active = 距离 PAD_mood 最近的情绪锚点（PAD 空间欧氏距离）
```

**理由**：C_control 测量的是"在某种情绪状态下做逆驱动行为的成本"。心境虽然也有 PAD，但缺乏明确的分类归属——平静心境下的低控制感和恐惧情绪下的低控制感，PAD 的 D 值可能相近，但心理体验完全不同。C_control 表需要知道的是"哪个心理状态"。

**共情卡的特殊处理**：共情卡不更新 emo_active——它是情绪管道而非情绪源。

## 七、战后稳定化

### 7.1 战斗经历聚合

```
PAD_exp = PAD_curr_end   (简化方案：最后一回合结束时的 PAD_curr)

备选方案（等模拟验证后决定）:
  PAD_exp = 0.7 × PAD_curr_end + 0.3 × PAD_curr_avg
  （近因加权——最后的状态更重要，但不忽略整场轨迹）
```

简化方案的直觉：经过多回合偏移和衰减后，最后一回合的 PAD_curr 已经是整场战斗情绪轨迹的合理总结。

### 7.2 心境更新公式

```
PAD_mood_new = PAD_mood_old + η_mood × (PAD_exp − PAD_mood_old)

η_mood = 0.15  (心境学习率)
```

**单场战斗后的心境变化示例**（恐惧主导）：

```
初始心境 = (0.30, −0.30, 0.00)  [正常人]
PAD_exp ≈ (−0.70, +0.50, −0.40)  [恐惧主导的战斗]

V: 0.30 + 0.15×(−0.70−0.30) = 0.30 − 0.15 = +0.15
A: −0.30 + 0.15×(0.50−(−0.30)) = −0.30 + 0.12 = −0.18
D: 0.00 + 0.15×(−0.40−0.00) = 0.00 − 0.06 = −0.06

新心境 = (+0.15, −0.18, −0.06)
变化: V ↓15%, A ↑12%, D ↓6%
```

**连续 N 场同类战斗的累积效应**（近似指数收敛）：

```
N=1:   移向战斗情绪 15.0%
N=3:   移向战斗情绪 38.6%
N=5:   移向战斗情绪 55.6%
N=10:  移向战斗情绪 80.3%
```

心境不会在一场战斗后剧烈翻转，但 5-10 场持续的情感倾向会深刻改变心境。

### 7.3 心境边界

心境边界不设硬 clamp。心境在正常情况下不会超出 [−1, +1]（η_mood 太小，单场偏移量不足以冲出），但对心境**被外部力量攻击**（敌人能力、关键叙事事件）时，出界不是被截断——而是触发**心境暴走**（见 §8.5）。

## 八、暴走与宣泄

> 当 PAD 超出 ±1 的正常范围时，不是硬截断——是**情绪冲破了调节系统**，进入短暂的宣泄状态，随后是更长的萎靡期。

### 8.1 触发条件

```
触发: |V_curr| > 1.0 或 |A_curr| > 1.0 或 |D_curr| > 1.0

不触发的情况:
  - 萎靡期间（刚宣泄完，无法再次暴走）
  - 同一场战斗中已有过一次暴走（每场战斗最多一次）
```

最容易触发暴走的场景：
- 短时间内被敌人大规模塞入同类情绪卡
- 玩家连续主动打出同类情绪卡 + 认知卡的放大调制 → 冲破了 ln 递减的阻尼
- SAN 极低时 κ_base 变大 → 情绪偏移幅度变大 → 更容易冲出边界

### 8.2 暴走回合（1 回合）

**暴走是情绪的宣泄——不是压制，是让它彻底爆发出来。**

暴走类型由冲出边界的维度决定：

| 暴走类型 | 触发维度 | 效果 |
|---------|---------|------|
| **恐慌暴走** | V < −1 或 A > +1 | 反射/惩罚行为卡 AP −1、效果 +50%。其他驱动行为卡全部灰色。 |
| **狂怒暴走** | D > +1 | 惩罚/道德/价值行为卡 AP −1、效果 +50%。无法使用照护/文化。敌我不分（目标随机化）。 |
| **躁狂暴走** | V > +1 | 奖励/价值行为卡 AP −1、效果 +50%。每回合额外 +1 AP。出牌目标随机化。 |
| **木僵暴走** | A < −1 | 跳过本回合，无法行动。SAN 恢复 maxSAN 的 15%。 |
| **巅峰体验** | V > +1 且 D > +1 | 所有行为卡 AP = 0、效果 ×2。持续 2 回合。结束后强制触发萎靡 × 2 倍时长。 |

**暴走回合通用规则：**

```
- κ_eff 临时 ×2（敞开了宣泄）
- 与暴走情绪"同方向"的行为卡获得增益
- 与暴走情绪"反方向"的行为卡全部灰色
- 暴走回合结束时强制宣泄回弹（见 8.4）
```

### 8.3 萎靡状态（3 回合）

暴走之后是萎靡——情绪系统过载后的强制冷却。

```
效果:
  ├─ κ_eff × 0.5（情绪迟钝——刚宣泄完，什么感受都变钝了）
  ├─ 所有行为卡 AP +1（精力耗竭）
  └─ 无法触发新的暴走（萎靡期间 PAD_curr 即使超出 ±1 也不暴走）
```

萎靡结束时恢复正常。完整暴走周期 = **1 + 3 = 4 回合**。

### 8.4 宣泄回弹

暴走回合结束时，PAD_curr 被强制向心境方向回弹——宣泄的本质是把积聚的情绪能量一次性释放：

```
PAD_curr_after = PAD_mood + 0.3 × (PAD_curr_before − PAD_mood)

约 70% 的偏移量被"宣泄"掉了。
```

**数值流示例**（恐惧暴走）：

```
初始心境 = (−0.50, +0.30, −0.30)

回合 1-2: 连续被塞两张恐惧卡，PAD_curr 被推向极端
  PAD_curr = (−1.15, +0.72, −0.55) ← V 超出 −1，触发恐惧暴走！

暴走回合:
  手牌中"逃跑""僵住"AP 0, 效果 1.5×
  但"坚持""牺牲""安抚"全部灰色
  κ_eff = 0.60（翻倍）、又打了一张恐惧 → V 冲到 −1.40

暴走结束时宣泄:
  V: −0.50 + 0.3×(−1.40−(−0.50)) = −0.50 − 0.27 = −0.77
  A: +0.30 + 0.3×(0.85−0.30) = +0.30 + 0.17 = +0.47
  D: −0.30 + 0.3×(−0.60−(−0.30)) = −0.30 − 0.09 = −0.39

  PAD_curr 宣泄后 ≈ (−0.77, +0.47, −0.39)

萎靡 3 回合:
  κ_eff = 0.30 × 0.5 = 0.15（打出情绪卡几乎没反应）
  所有行为卡 AP +1
  "冷静下来之后，你觉得筋疲力尽。"
```

注意暴走后的 PAD_curr (−0.77, +0.47, −0.39) 比暴走前的极端值 (−1.40, …) 更接近心境——宣泄确实起作用了。但因为心境本身偏负 (−0.50)，宣泄后仍然在负区间。**宣泄不能根治负面心境，只能解除"过载"状态。**

### 8.5 心境暴走（战略层）

跨战斗层面，如果 PAD_mood 被外部攻击或极端累积推至超出 ±1，触发**心境暴走**——一种持续性的精神状态崩溃：

```
恐惧心境暴走 (V_mood < −1):
  效果: 每一场战斗开始时自动被塞入一张"恐惧"卡
  叙事: "月光下，恐惧已经不只是你的情绪——它附着在你身上，像第二层皮肤。"

愤怒心境暴走 (D_mood > +1 且 V_mood < −0.5):
  效果: 道德驱动和行为抑制削弱（θ_moral −0.2、无法使用照护）
        所有对抗性行为的 C_control 减半——"逆着做"变得容易
  叙事: "你不再问'这样做对吗'。你只知道'我要这样做'。"
```

**恢复**：心境暴走不能通过"休息几场"自然消退。需要关键叙事节点（治疗会话、镜子房间认知重构）来修复。某些角色构筑可以**主动维持心境暴走**换取持续的战斗增益——代价是照护和道德驱动永久灰掉。

### 8.6 暴走的策略意义

```
正常路径: 情绪卡 → κ_eff 递减 → 安全但效果有限
暴走路径: 情绪卡 → κ_eff 递减 → 强行继续 → 冲破边界
           → 暴走 1 回合（获得定向增益 + 行为收窄）
           → 宣泄回弹（PAD_curr 重置）
           → 萎靡 3 回合（代价）
```

**当作风险规避**：大多数情况下你不会想触发暴走——3 回合萎靡的 AP 惩罚很致命。

**当作工具利用**：在某些局面下主动触发暴走反而最优——
- PAD_curr 已严重偏负，大部分行为卡灰了 → 与其在低效状态下挣扎，不如触发暴走 → 宣泄 → 重置 PAD_curr → 萎靡结束后恢复完整行为选择空间
- 暴走回合的同方向增益是真实收益——一个精心计算的暴走可以在正确时机打出决定性一击

这和 SAN↔HP 互转的设计思路同源：**用短期自我伤害换取长期战斗可持续性。**

## 九、完整回合流程

```
1. 回合开始
   PAD_curr = 上一回合遗留（首回合 = PAD_mood）
   检查萎靡计时器: is_lethargy > 0 → 萎靡惩罚生效, is_lethargy -= 1

2. 抽牌阶段
   抽认知/情绪/行为卡。环境/敌人可能塞情绪卡。

3. 状态计算
   以 PAD_curr 为输入:
   ├─ g_i = compute_drive_activations(PAD_curr)
   ├─ φ_i = compute_phi(cog_progress)
   ├─ g_eff_i = g_i × φ_i
   ├─ 行为卡可用性/成本/效果判定
   └─ (无需情绪卡也能完成——PAD_curr 来自心境)

4. 出牌阶段
   如果打了情绪卡:
   ├─ n += 1, 计算 κ_eff(n, k)
   ├─ 萎靡中? → κ_eff × 0.5
   ├─ 暴走中? → κ_eff × 2
   ├─ PAD_curr += κ_eff × (PAD_card − PAD_curr)
   ├─ 检查暴走触发: |V/A/D| > 1.0 且 非萎靡 且 本场未暴走过?
   │   → 触发暴走, is_berserk = true
   └─ 更新 emo_active

   认知卡: 推进 CPM, 执行卡面效果
   行为卡: 计算 B(t), 检查暴走限制

5. 回合结算
   态度效果结算。行为惯性更新。

   如果 is_berserk:
   ├─ 宣泄回弹: PAD_curr = PAD_mood + 0.3×(PAD_curr − PAD_mood)
   ├─ is_berserk = false
   └─ is_lethargy = 3

6. 回合结束（衰减）
   PAD_curr = PAD_mood + (PAD_curr − PAD_mood) × (1 − δ)

7. 战斗结束（稳定化）
   PAD_exp = PAD_curr_end
   PAD_mood += η_mood × (PAD_exp − PAD_mood)
   检查心境暴走: |V_mood/A_mood/D_mood| > 1.0?
   清零 n_emotion, is_lethargy
```

## 十一、设计含义

### 11.1 手牌不齐问题

即使没有情绪卡，PAD_curr 仍然可用（= 心境 PAD），驱动激活和行为门控正常运作。

### 11.2 心境作为战略资源

每场战斗的情绪选择有跨战斗后果。反复使用同类情绪 → 心境向该方向漂移 → 后续战斗起始状态改变 → 可用的行为通道逐渐收窄或拓宽。逆转负面心境需要在多场战斗中主动选择反向情绪卡——光等不够。

### 11.3 暴走作为宣泄

情绪边界不是禁区——是临时出口。暴走让玩家在极端情况下获得爆发力，但以萎靡期为代价。这创造了真实的战术权衡：适可而止还是不惜失控？这个张力恰好是许多精神病理的核心悖论。

### 11.4 心境被攻击

敌人可以直接攻击心境（不限于塞情绪卡）。心境攻击比情绪冲击更危险——改变底色，影响持续多场战斗。

### 11.5 与病情系统的关系

病情在两个参数上体现——PAD_set（设定点）和 κ_base 偏移（情感迟钝/过度反应）。不直接惩罚操作，而是改变情感系统的动态特性。

## 十二、待解决问题

1. **κ_base = 0.30 需要校准。** 偏移 30% 体感如何——一张情绪卡是否"太弱"还是"刚好"？
2. **η_mood = 0.15 需要测试。** 5-10 场心境明显变化——这个速度对游戏流程是否合适？
3. **C_control 的 emo_active 方案**——用最近情绪卡名称查表，在混合情绪（中间态 PAD_curr）下是否会产生不合理的行为成本？可能需要用 PAD_curr 到最近锚点的欧氏距离插值 C_control。
4. **共情卡在两层模型下的行为**——共情的情绪管道角色。它不应更新 emo_active，但被共情传递来的他人情绪应如何影响 PAD_curr？
5. **PAD_set 是否应该完全固定？** 关键叙事节点（如镜子房间）是否应允许修改？
6. **心境变化的 UI 反馈**——心境的缓慢变化可能难以被玩家注意，需要设计明确但不频繁的提示。
7. **暴走类型的自动判定**——当多个维度同时出界时（如 V < −1 且 D > +1），按什么优先级判定暴走类型？
8. **心境暴走的触发概率**——η_mood = 0.15 下单场战斗几乎不可能让心境冲出 ±1。心境暴走在正常游戏中是否仅由外部攻击触发？那它的设计必要性是否有待验证？
