# 任务/目标系统

> 在连续世界（无"局"/无轮回）中，NPC 是任务的唯一入口，Boss 是叙事引力中心。笔记本三层（承诺/线索/自问）记录玩家与世界的互动——从 NPC 委托到环境碎片到内心疑问。
>
> **维度: 事件** — 分拣：任务有触发条件（NPC对话/环境障碍/线索拼合）和时间轴（完成/回报/放弃），属于事件维度。

## 一、核心定位

### 1.1 设计原则

- **NPC 是任务唯一入口**：所有可执行任务（承诺）来自 NPC 对话或环境障碍。不存在"系统派发"的任务。
- **Boss 是叙事引力中心**：每个 Boss 形成一个叙事星群——影响 NPC（→ 委托）和环境（→ 线索），两者指向同一源头。
- **笔记本是记录工具**：纯 UI 层，不是叙事物件。三层记录玩家与世界的所有互动。
- **无追踪提示**：HUD 上不显示当前任务。玩家想不起来就打开笔记本。

### 1.2 与其他系统的关系

| 系统 | 关系 |
|------|------|
| 关卡流程与进度 | 门控任务 = 钥匙链推进的 UI 表达 |
| 可塑性巩固 | 承诺完成 → 巩固窗口（经历驱动成长） |
| 游戏循环 | 时段推进 → NPC 委托刷新 |
| Boss 设计 | Boss = 叙事网络的节点中心 |
| 线索系统 | 纯背景线索拼合 → 自问浮现 |

## 二、笔记本：三层记录

笔记本是打开任务系统的 UI 界面，三层以**标签页**切换：

```
┌─ 笔记本 ──────────────────────┐
│ [承诺] [线索] [自问]          │
│                                │
│  ▢ 帮老王去药房拿劳拉西泮      │
│  ▢ 找到住院楼2F的钥匙          │
│  ✓ 帮小李找回病历              │
│  ~~放弃：帮赵护士值夜班~~       │
│                                │
│  ↩ 回到游戏                    │
└────────────────────────────────┘
```

### 2.1 承诺层

**来源**：NPC 对话中接受委托，或环境障碍（如发现锁住的门）自动写入。

**性质**：
- 有明确完成条件
- 完成后**划掉**（✓），不消失
- 可**放弃**（划掉保留，标记 ~~放弃~~），后果取决于 NPC 类型
- 同一 NPC 可同时给出多个承诺
- 可有前置→后续任务链

**门控承诺**：发现楼梯间锁住 → 自动写入"找到上楼的钥匙"。非 NPC 来源，由环境触发。

**容量**：无上限——NPC 和其委托数量有限，自然收敛。

### 2.2 线索层

**来源**：环境交互（读字条/检查病历/摸涂鸦）、NPC 对话中提到的非委托信息。

**性质**：
- **自动写入**——所有可能有用的非委托信息自动记入
- **不可删除**——写满翻页
- **不需要"完成"标记**——纯背景线索自足，只是世界在对你说话
- **拼合效果**：多余条纯背景线索拼合 → 可能触发新自问浮现，或改变对某 NPC 的理解

**线索流通方向**（单向管道）：

```
环境碎片/NPC对话 → 线索层
                    ├──→ 指向 NPC → 对话触发委托 → 承诺层 → 完成/回报
                    └──→ 纯背景故事（自足，不指向任何任务）
```

### 2.3 自问层

> **⚠️ 独立子话题**：自问层详细设计留待后续独立讨论。以下仅为当前框架。
>
> 🔧 **接口角色已定（2026-09-06 Grilling #121）**：自问层 = [角色发展轴](../实体/角色发展轴.md) 的**玩家侧驱动动作（输入端点 IN-2）+ 呈现面（输出端点 OUT-2）**——"渐悟"的玩家可感通道，消解结果写入角色发展轴的议题记录。端点角色已锁定，UI/触发/消解规则等详细设计仍属延迟项（见 §十一）。

**来源**：线索拼合自动触发，或游戏进程中的关键事件。

**性质**：
- 玩家角色自己产生的疑问——"我为什么在这里？""我真的想出去吗？"
- 无 NPC 给，无完成条件
- 随游戏进程**自然消解或深化**
- 自问的消解 = "回家"驱动力的具体化表达

## 三、任务生命周期

### 3.1 承诺层流程

```
发现 → 接受 → 记录 → 执行 → 完成 → 回报
  │                        │        │
  └── 可婉拒（无后果）      │        └── 需回到 NPC 处对话触发
                             │
                      └── 可放弃（后果取决于 NPC 类型）
```

| 阶段 | 触发 | 说明 |
|------|------|------|
| **发现** | NPC 对话中自然提出请求 | 无感叹号，无 UI 标记 |
| **接受** | 玩家选择接受 | 自动记入承诺层 |
| **记录** | 接受后 | 笔记本显示为 ▢ 条目 |
| **完成** | 环境触发（拿物品/到地点/击败敌人） | 自动勾选 ✓ |
| **回报** | 回到 NPC 处对话 | 触发巩固窗口 + 可能附赠物品/信息 |
| **放弃** | 玩家主动操作 | 划掉保留，NPC 态度取决于 NPC 类型 |

### 3.2 线索层流程

```
环境交互/NPC闲聊 → 自动写入线索层 → 玩家阅读
                                      ├── 纯背景（自足）
                                      └── 拼合触发自问/NPC认知偏移
```

### 3.3 门控流程

```
发现障碍 → 自动写入承诺层 → 玩家找解法 → 完成 → 划掉
```

## 四、任务类型与分类

### 4.1 按来源

| 类型 | 来源 | 功能 | 示例 |
|------|------|------|------|
| **委托** | NPC 个人请求 | 建立关系、获得巩固、填充世界 | "帮我去药房拿 X""找找我的病历" |
| **门控** | 环境障碍 | 推进关卡、解锁新区域 | "找到住院楼 2F 的钥匙"（实际在小头目身上） |
| **叙事碎片** | NPC/环境 | 揭示世界观、拼合线索 | 不在承诺层——自动进入线索层 |

### 4.2 委托的子分类

| 子类型 | 特征 | 时间 |
|--------|------|------|
| **日常委托** | 可再生，NPC 每天可给新的 | 小档 |
| **重要委托** | 与 Boss 网络相关，通常是一次性 | 中档 |
| **主线级承诺** | 推动钥匙链或引发自问质变 | 大档 |

---

## 五、时间约束

| 约束类型 | 适用场景 | 示例 |
|----------|---------|------|
| **无时限** | 大多数委托 | "帮我找到妹妹的病房"——什么时候完成都行 |
| **时段约束** | 只在特定时段可做 | "夜晚值班护士不在时帮我去拿……" |
| **今日内** | 紧急委托（少数） | "我今天必须拿到药"——下一日未完成 → NPC 反应 |

## 六、主线与 Boss 叙事网络

### 6.1 "主线"的定义

**"主线"不在笔记本里单独标注。** 它由两条线交汇构成：

- **结构性主线**（原"脊柱线"，🔧 2026-08-16 grilling #86 改名）：门控承诺 → 钥匙链推进 → Boss 面对。玩家不需要被告诉"这是主线"——钥匙链本身是最强的方向信号。
- **叙事性主线**（原"理解线"，🔧 2026-08-16 grilling #86 改名）：线索拼合 → 自问浮现/消解 → 世界观理解加深。

设计师内部使用"是否推进钥匙链或引发自问质变"来判断一个任务是否为主线级，用于决定叙事权重和巩固效果。玩家看不到这个分类。

### 6.2 Boss 叙事网络

每个 Boss 是叙事节点中心，向外发散：

```
Boss（叙事节点）
  │
  ├──→ 影响 NPC ──→ NPC 困顿/求助 ──→ 承诺层
  │                                      │
  └──→ 影响环境 ──→ 线索碎片    ──→ 线索层
                                         │
                              玩家追溯两者 → 确认方向 → 通向 Boss
```

### 6.3 Boss 节点的三阶段

| 阶段 | 特征 | 玩家感知 |
|------|------|---------|
| **接触前** | 受影响的 NPC 给委托，环境线索隐约指向更大存在 | 可能尚未意识到有 Boss |
| **确认** | 线索+委托交汇，某个 NPC/线索直接命名 Boss | "这里有一个更大的东西" |
| **面对** | 门控解锁，可进入 Boss 空间 | 战前可能有后续委托（增益/信息） |

### 6.4 独立 NPC 弧

并非所有 NPC 委托都挂在 Boss 下面。独立于 Boss 网络的 NPC 故事线：
- 提供稳定的小档巩固来源
- 让世界有呼吸感——不是所有人都围着 Boss 转
- 可能间接提供通向 Boss 网络的信息或道具
- 具体弧线留待内容填充时逐角色设计

## 七、任务发现

- **无感叹号**：不用外部 UI 标记。
- **待机动作区分**：有委托的 NPC 待机动作与无委托的不同——视觉语言替代 UI 标记。
- **对话发现**：只有在与 NPC 对话时才会发现具体委托内容。
- **时段/事件刷新**：休息/时段推进后，NPC 可能产生新委托；对话选项可能随时间或事件变化。
- **回访价值**：已给过承诺的 NPC → 回报时再次对话 → 可能引出新承诺（任务链）。

## 八、笔记本 UI

- **打开方式**：快捷键（待定，建议 `J` 或 `N`）。
- **三层标签页**切换：[承诺] [线索] [自问]。
- **承诺显示状态**：▢ 未完成 / ✓ 已完成 / ~~放弃~~。
- **线索**：纯罗列，无状态标记，写满翻页。
- **自问**：格式待后续子讨论。
- **门控承诺**：格式与 NPC 承诺一致，不特别标记。
- **启动时空笔记本**：三条都是空的。玩家醒来后，第一个线索来自环境探索，第一个承诺来自第一个 NPC 对话。

### 8.1 延迟事项

> **⚠️ 延迟**：笔记本中条目关联的可视化方案——当多条承诺和线索指向同一 Boss 时，如何让玩家感知到关联？与自问层详细设计一起留待后续子讨论。

## 九、可塑性巩固整合

任务系统与可塑性巩固的关系详见 **[核心机制 §八](../%E8%A7%84%E5%88%99/%E6%A0%B8%E5%BF%83%E6%9C%BA%E5%88%B6.md#八可塑性巩固)**。要点：

- 承诺完成 → 触发巩固窗口（非战斗承诺使用纯叙事权重计算事件强度）
- 非战斗承诺的巩固窗口**所有已解锁链路均可选**
- 巩固窗口 = **立即使用**（事件结束当场决定）
- 门控承诺通常伴随战斗 → 使用战斗事件强度公式
