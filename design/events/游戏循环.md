## 一、核心定位：没有"局"

### 1.1 为什么废除"局"

旧框架（卡牌 Roguelike）中，"局"是离散的游戏单元——每局重新抽牌、打完结算、重来。新框架（回合制 RPG + 髓鞘化持续成长）中：

- 髓鞘化只增不减——角色不会"归零重来"
- 空间拓扑封闭——玩家永远出不去
- 叙事基调是"在无法逃避的困境中如何面对"——不存在"通关"

**"局"的概念被废除。** 玩家经历的是一个连续的、没有明确边界的体验。

### 1.2 为什么废除"轮回"

轮回（软轮回/硬轮回）是旧框架的产物——同一空间在不同轮次承载不同内容。在连续世界中：

- 患者固定——每间病房住的是确定的患者
- 空间变化由月光周期驱动——同一空间在满月和新月下呈现不同状态
- 玩家的持久成长意味着"重来"没有意义

**"轮回"概念被废除。** 空间复用由月光强度和昼夜周期自然驱动。

### 1.3 核心玩法循环（🔧 2026-09-16 · [#181](https://github.com/verystrongdog/game/issues/181) 选项 A）

**定位**：本作是**叙事驱动的心理 CRPG**——主循环由对话、调查、认知检定与承诺/线索/自问构成；回合制心理对抗是**并列解决路径之一**。

```
探索（物理医院层 → 扭曲空间 → 患者内心世界）
  → 对话与调查：接下承诺、收集线索（任务目标系统 §二）
  → 认知检定：读现有 m / SAN 的被动检定（剧情系统设计 §3.1）
  → 冲突：可经对话 / 说服 / 投降 / 认知压制 / 规避解决，也可升级为回合战斗
  → 后果写回 Q / R / F / W / K（剧情系统设计 §3.1）
  → 休息：推进一个时段（§2.2）
```

| 项 | 裁定 | 权威 |
|---|---|---|
| 战斗的职责 | **并列解决路径之一**，是**冲突升级后的可选解决器**，不是连续体验的必经环节 | [世界观与叙事](%E4%B8%96%E7%95%8C%E8%A7%82%E4%B8%8E%E5%8F%99%E4%BA%8B.md) §战斗逻辑 |
| 非战斗行为的地位 | 对话、调查、异常暴露与认知检定**同样**进入休息与时段推进 | §2.2 |
| 叙事的后果范围 | 直接改关系 / 世界状态 / 感知版本 / 空间访问 / 自问演化 / 结局映射；**不经对话效果直接改 m/SAN/HP** | [剧情系统设计](%E5%89%A7%E6%83%85%E7%B3%BB%E7%BB%9F%E8%AE%BE%E8%AE%A1.md) §3.1 |
| 既有战斗与动作资产 | **全部保留并继续被消费**，不因定位调整删除或降级 | [#181](https://github.com/verystrongdog/game/issues/181) §预期差分 |

> **这不是新增系统**：上表四项都是把已有正典（对话 DAG、笔记本三层、被动检定、回合结算）**排进同一个循环**并裁定优先级。战斗结算、时间公式、结局触发方式**均不变**。

## 二、时间系统

### 2.1 时段：每天三段

| 时段 | 月光基线 | 特点 |
|------|---------|------|
| **上午** | 弱 | NPC 活动多（查房、工娱疗），适合对话和探索 |
| **下午** | 中 | 部分 NPC 位置改变，某些内容仅在下午可访问 |
| **夜晚** | 强 | 月光最强，危险最高，深层空间更容易滑入 |

时段只提供**软约束**——夜晚出门危险但不是禁止，白天在深处待着也不受限制。时段影响可访问性和风险，不硬性锁死行为。

> **接口契约（Grilling #103 Q3）**：时段「月光基线（上午弱/下午中/夜晚强）」属**观察/呈现层表观**，不是场能量或动力学参数（E_c/E_th/q̂）的时段函数——夜晚更危险、更容易滑入深层等真实机制权重属事件/空间状态层事务（空间维度 grilling 队列项），不由月光场接口层赋予。

### 2.2 时间推进方式：休息驱动

时间不会连续流逝。只有"休息"动作才推进一个时段：

```
玩家自由探索/对话/战斗 → 需要恢复 → 选择休息 → 推进一个时段
```

**设计原理**：战斗损耗（HP/SAN 下降）自然驱动玩家去休息。不需要额外的"你必须睡觉"的压力系统。

> **🔧 2026-09-16（[#181](https://github.com/verystrongdog/game/issues/181) 选项 A）——休息动机不再绑在战斗上**：推进时段的**唯一**动作仍是「休息」（本节的公式与 §3.3 的恢复量都不变），但**逼玩家去休息的原因**不再假定为战斗损耗。对话、调查、异常暴露、认知检定失败、空间爬深同样产生消耗与压力，构成非战斗的休息动机；上句「战斗损耗自然驱动玩家去休息」由此**降为理由之一**（保留原文作为当时的设计理由，不再作为正典的唯一口径）。判定依据：[§1.3 核心玩法循环](#13-核心玩法循环-2026-09-16--181-选项-a) 把战斗裁定为并列路径——若休息只由战斗驱动，非战斗通关路径就没有时间节拍器。

**恢复量不因动机而变**：§3.3 的 SAN 恢复 `+5/回合` 对**任何动机触发的休息**一律适用（非战斗推进**不新增任何数值**，零新阈值）；本节只改「为什么去休息」，不改「休息给什么」。

**游戏日推进（Grilling #103 Q1/Q4）**：夜晚第 3 次休息完成瞬间 = 游戏日边界 = **唯一的月相推进点**——D → D+1，λ(D) = (1−cos(2πD/29.5))/2 更新（D=0 ↔ 新月，开局醒来）。战斗回合、死亡/复活、空间切换、日内时段切换均**不推进 D**；只有休息推进时间。

### 2.3 昼夜复位与昼夜记忆

> ⚠️ **状态：暂时设定（owner 2026-09-18 口述裁定）**。本节是新规则，落盘时**尚无试玩证据**，也未经过其他维度的冲突清扫（见 §2.3.4 待定清单）。

#### 2.3.1 三层定义

| 层 | 内容 |
|---|---|
| **白天 = 现实层** | 一切正常。病人是普通病人、护士是普通护士、门是普通门。没有战斗、没有技能、没有造物、没有扭曲。**白天是纯叙事/探索/对话时段**（原文与权威：`空间与关卡设计` §7.1 昼夜分离——本节不改它，只是给它补上"人为什么会照常"的那一环） |
| **夜晚 = 超自然层** | 月光出现 → 一切激活。**人的意识被投射到周围环境中**（意识外显效应，`世界观与叙事` §宏观意识外显效应）；所有战斗/技能/造物/扭曲空间只在夜间运作 |
| **次日白天 = 复位** | 环境恢复正常，连带**记忆按 §2.3.2 处理**。⇒ 白天的世界可以完全正常，**不需要任何人演戏** |

#### 2.3.2 夜晚记忆的保留规则（本节的实质）

对任一个体 x，`回忆(x, 昨夜) ∈ {保留, 忽略}`：

```
保留  ⟺  x 的疾病程度足够深，
        以至于不会有任何"正常人"相信从他嘴里说出的夜晚景象

忽略  ⟸  其余全部人（含所有"正常人"、轻/中度患者）
         ——不是删除，而是不形成可陈述的记忆：
           他们说不出"昨晚发生了什么"，也不会去说
```

**两条读法必须同时成立**（这是规则的要点）：

1. **保留条件是社会性的，不是临床性的**——判据不是"他病得重"，而是"**没人会信他**"。疾病只是让这句话成立的手段。
2. ⇒ **在这个地方，唯一能作证的证词，按定义必然被判定为不可信。** 想证明夜晚发生过什么，唯一可能的证人恰恰是白天最不被采信的那批人——这与 [D15 不可证实铁律](%E4%B8%96%E7%95%8C%E8%A7%82%E4%B8%8E%E5%8F%99%E4%BA%8B.md) 同向，也是本作主题的一次直接机制化。

**临床代理（[NEW]，提议待确认）**：以病情严重度 **「重度」（CGI-S 6–7 / GAF ≤ 40，`敌人与事件` §2.1）** 作为保留门槛的代理判据。⚠️ 这只是把上面那条社会性判据落成可查询字段的**代理**，是否采用待 owner 确认。

#### 2.3.3 这条规则解释了什么（顺带收益）

- **「医护认为自己没事」不是自欺，是字面事实**（owner 2026-09-18 前一条裁定"医护也会上下班离开医院、仍被异常影响、认为自己没事"）——按本节，普通人**真的不记得**，所以"没事"对他们成立。
- **白天的日常不需要任何掩饰机制**：不需要封锁消息、不需要封口、不需要 "医院控制舆论" —— 记忆自己就复位了。
- **现实病房的既有现实吻合**：精神科病房里，病人的夜间陈述本就不被采信；本节把这一条现实**升格为世界观规则**，而不是当作偏见来批判。

## 三、休息与风险

### 3.1 任意地点可休息

玩家可以在任何位置选择休息。没有"必须回到安全屋"的限制。

### 3.2 位置影响偷袭风险

| 位置 | 偷袭概率 | 说明 |
|------|---------|------|
| 物理医院层走廊/病房 | 低 | 相对稳定 |
| 物理医院层公共空间 | 低-中 | 活动室、食堂等 |
| 扭曲空间（轻度） | 中 | 空间开始不稳定 |
| 扭曲空间（重度） | 高 | 靠近患者意识焦点 |
| 患者内心世界 | 极高 | 最深处 |

基础公式：`偷袭概率 = 位置基础概率 × 休息回合数`（封顶 ×4）。

被偷袭时：敌方先手 1 回合，已恢复的 SAN 不损失。

### 3.3 休息效果

| 效果 | 值 |
|------|-----|
| SAN 恢复 | +5/回合（无 CD） |
| 时间推进 | 1 个时段 |
| 快捷槽重排 | 可（通过随身镜子） |

### 3.4 护士站昼夜变化

| 时段 | 护士站状态 |
|------|-----------|
| **白天** | 真人护士——可对话、补给、任务线索。可能沦陷（被敌人占据），需清场才能使用。 |
| **夜晚** | 护士变成**投影**——中立单位，不会受伤，没有情绪反应，更接近一种自然现象。休息功能依然可用。 |

夜晚可有以护士为原型的小头目（负面情绪在月光下扭曲现实的具象化，非三大思潮 Boss 级别）。

🔧 **2026-09-18 补一条解释**（owner 裁定"§5.2 承认三条边界路径"的连带）：那个小头目是**替她值班的东西攒出的账**——夜里的投影**无情绪反应、不受伤**，`+1` 在她自己身上没有可累加的地方（**代理型**，见 [敌人与事件 §5.2.1](../entities/%E6%95%8C%E4%BA%BA%E4%B8%8E%E4%BA%8B%E4%BB%B6.md)）⇒ 于是账面落在**替她值班的那个东西**身上。⚠️ 杀掉它算不算她的账——**留白**。⇒ [谭丽娟稿](../spec/material/drafts/%E8%B0%AD%E4%B8%BD%E5%A8%9F-%E5%8F%99%E4%BA%8B%E8%A7%86%E5%9B%BE.md) 是这条的第一个人物当事人。

## 四、移动与空间切换

### 4.1 分层移动方式

| 空间层 | 移动方式 | 说明 |
|--------|---------|------|
| L0 物理医院 | 自由移动 | 走廊/病房/活动室之间连续走动 |
| L1 扭曲空间 | 单节点 | 一个战斗场景，非节点链 |
| L2 患者内心世界 | 单场景 | 一个大场景（非多节点串联），小头目在场景内某处 |

物理医院的自由移动建立"这是一栋真实的楼"的地方感。

### 4.2 空间切换：鬼打墙式无缝过渡

空间之间的切换采用**鬼打墙式无缝过渡**——场景变化不应被玩家轻易察觉。物理地图不变，但**门的另一侧在变化**。

```
走廊（正常）→ 进门 → L1 扭曲房间 → 门关上（不可逆）
→ 战斗/探索 → 门/窗再打开：
  ├── L1-only: 扭曲消散，房间恢复正常 → 开门回走廊
  └── L1→L2: 门外是患者精神世界 → 找出口 → 回到同一扇门外的走廊
```

核心规则：
- 进入 L1 后**不可回头**，门关上后只能向前
- L1→L2 出门后**回不来**，门变回普通病房门
- L1-only 房间扭曲消散后**可能复发**（休息／月光场强度变化后）
- **月光场强度**越高 → 扭曲房间越多/越易复发

### 4.3 空间渐变（修订）

L1 扭曲空间和 L2 患者内心世界**不是硬分层的两个关卡类型**，而是同一种现象的不同强度：

```
正常物理空间 → 轻微扭曲 → 严重扭曲 → 患者内心世界
               ← 越靠近患者意识焦点，扭曲越深 →
```

两者都是病人精神状态不稳定导致的意识外显效应暴走。扭曲空间是正常物理空间和患者内心世界之间的过渡带。越靠近患者意识关注的区域，空间扭曲效应越严重，最后直接与患者的内心世界连通。

### 4.3 空间复用：月光周期

没有轮回后，空间复用由月光场驱动：
- 同一间病房在不同场强度下呈现不同状态
- 某些内容仅在月光现实（壳上旋转态，d=0）时可访问
- 月相自然推进（每天休息 3 次 = 一天过去）：λ(D) = (1−cos(2πD/29.5))/2，D = 自开局起已完成的游戏日数（D=0 ↔ 新月），每游戏日边界推进一步；满月连续峰值 D=14.75
- 场基线由 `moonState(D)` 只读查询提供（λ/E_c/E_th/q̂ 基线 + 校准状态），游戏日边界广播 `MOON_PHASE_CHANGED` 刷新通知（Grilling #103 接口契约）
- ⚠️ v2 参数 g_0/η/η_crit 已废弃（2026-08-11 #38），具体机制见 [时空结构数学框架 §十一](../rules/%E6%97%B6%E7%A9%BA%E7%BB%93%E6%9E%84%E6%95%B0%E5%AD%A6%E6%A1%86%E6%9E%B6.md)（月光场实例化 + 接口层协议块）

## 五、死亡与复活

### 5.1 分难度

| 难度 | 复活规则 |
|------|---------|
| **低难度** | 死亡 → 都灵之马出现，无限复活 |
| **中难度** | 复活次数有限 |
| **高难度** | 无法复活，HP=0 = 永久死亡 |

### 5.2 灵魂跟随机制

HP=0 → 玩家以灵魂状态跟随都灵之马：

- 持续 **7 回合**
- 马在医院中随机移动
- 玩家可**主动选择**脱离灵魂状态复活
- 7 回合结束 → 在马的当前位置**强制复活**
- 主动 vs 强制复活无代价差异——差别纯粹是控制权

### 5.3 都灵之马

从"中立无敌 NPC"重新定位为**引渡者/psychopomp**——死亡后出现，引导灵魂，随机移动后释放玩家复活。不是敌人，不是盟友，是医院规则的一部分。

---

## 六、存档

存档 = 暂停并退出。读档 = 继续。**不能"回到过去"。**

死亡必有后果——没有读档重来的路径。中低难度可以随时存档（退出游戏用），高难度无法存档。

---

## 七、日常节奏

### 7.1 典型一天（无强制）

玩家自由决定每天的节奏。时段只提供软约束：

> 上午 → 探索物理医院，跟 NPC 对话，调查线索
> 下午 → 决定深入方向，进入扭曲空间或患者世界
> 夜晚 → 月光最强，在深处继续推进或返回休息

也可以：上午直接深入深处，花一整天战斗，夜晚踉跄回来休息。或者连续几天在深处不回来（只要能活下来）。

### 7.2 时段影响

某些 NPC 只在特定时段出现在特定位置，某些事件只在特定时段触发。但这不是硬性锁死——是"更容易遇到"而非"只有这时才能遇到"。

---

## 八、结局触发

### 8.1 三个结局 = 月光的三重叠加

| 结局 | 月光观 | 含义 |
|------|--------|------|
| A | 月光是物理场 | 可量化、可测量、可破解的自然力 |
| B | 月光是有意志的神明 | 会回应、会选择、是活的 |
| C | 月光是无声的催化媒介 | 不强加意义，只是放大 |

不存在"真结局"——月光三重解释同时为真，结局只是玩家最终的存在状态。

### 8.2 触发方式

结局由**条件自动触发**——髓鞘化模式 + 见证的 Boss 故事 + 探索深度 → 阈值到达 → 结局事件自然发生。

玩家不主动选择结局。结局是"你是谁"在最终时刻的自然映射。

### 8.3 Boss 的功能

三个 Boss 对应三种月光思潮。击败 Boss ≠ 选择结局——Boss 战是**见证一种月光思潮的生命史**：它如何从一个人的信念开始，膨胀成有自我意识的存在，在月光下变得强大，最终被自己的信念吞噬走向疯狂。

Boss 的功能是叙事深度体验和深度理解，不是"关卡终点"。

---

## 九、玩家驱动力

### 9.1 核心驱动：回家

玩家想回家。这是所有人都能立刻理解的驱动力。

### 9.2 张力的处理

"回家"是一个不可及的驱动力。类似《黑暗之魂》的"火已渐熄"——玩家一开始想回家，但随着探索逐渐发现，"家"这个概念本身可能就不存在、已经被摧毁、或只是记忆。

驱动力从一开始的"回家"转化为**"理解为什么回不去了"**。

空间拓扑封闭不是物理牢笼——它是世界观的核心谜题。为什么没有"外面"？答案是否存在，本身就是一个谜。

### 9.3 驱动力的病名：**《无法离开医院》**（🔧 2026-09-20 owner 裁定）

玩家不是先作为一名自愿住院患者要求出院。开场的苟智空刚下夜班、正在回家，却来到医院边界；他沿园区绕行后回到原点，踏上门诊台阶后由夜转昼，被护士称为“0527”，而手环姓名是“苟笙”。

因此“回家”从第一幕就同时是三件事：

- **行动目标**：找到一条能通往医院之外的路；
- **身份案件**：查清为什么院方的身份、床位和编号记录都先于他的“入院”存在；
- **固有疾病**：每次离开尝试都可能换一种方式证明“你仍在院内”。

现实出院程序仍可在后续成为一次具体验证，但不再承担主角入院前提，也不能用“自愿住院”覆盖开场的身份矛盾。

## 十、游戏开始

> 🔧 **2026-09-17 修正（owner 裁定）**：原 §10.1 写「**没有角色选择画面**，没有"选面具"的 meta 步骤。你是谁，醒来时就已注定」。该口径**被取代**——开局有选择。权威在 [疾病特长](../entities/%E7%96%BE%E7%97%85%E7%89%B9%E9%95%BF.md)。
>
> **改动的性质**：不是"加了一个角色选择画面"，而是把成因拆成两条腿——**经历**（无条件给基本属性 + 解锁疾病候选）+ **玩家自己的选择**（要不要让它变成病）。原口径的立场（**你没有选你是谁**）保留在经历层：经历决定你只能在候选里选，**疾病不是货架上的商品**。

### 10.1 初始场景

玩家**在病房中醒来**——但醒来之前先经过 [疾病特长](../entities/%E7%96%BE%E7%97%85%E7%89%B9%E9%95%BF.md) §六 待办 8 所列的五屏开局（结构已定，玩家可见文案待写）：**选经历（10 段，含互斥灰卡）→ 属性结算（五档）→ 疾病候选 → 选疾病 → 在镜子界面整理面具**。

开局**不是**选职业：**经历**决定你能得什么病，**你自己决定要不要**。经历的数量限额 10；属性完全由经历决定，无自由分配点。

随身携带一面镜子——可以用来自我观察（重排快捷槽），**也是开局的最后一步**，也是死亡后都灵之马找到你的锚点。开局不显示玩家人脸：已选疾病先表现为面具上的挂件、花纹或裂隙，玩家可调整挂件位置；该整理暂不改变疾病或装备机制，也没有物理依赖，见 [疾病特长 §4.5](../entities/%E7%96%BE%E7%97%85%E7%89%B9%E9%95%BF.md)。

### 10.2 面具：开局外观与探索装备

面具仍不用于"开局选角色"（本口径**不变**）。14 个角色的机械设计保留并作为**26 病卡的机制来源**。开局镜子只整理**已经选定的疾病外观**；医院探索中找到/获得、可更换并提供机械效果的面具组件属于**装备层**。外观层与装备层是否最终合并尚未裁定。

（面具装备的完整机械设计待后续整理。）

### 10.3 开局状态与 [CP-01](../slices/CP-01-ward-1f/slice.md) 的关系

开局产出的**基本属性（5 项 × 五档）+ 疾病选择**是玩家进入住院楼 1F 时的初始配置。CP-01 切片合同（§一）**不因此变更**——排除项仍是「完整技能树 · 完整 NPC AI · Boss · 月相全系统 · 完整主线与全量 NPC 素材 · 多角色 · 美术精修」；疾病特长属**已有 26 病与 14 角色设计的开局入口**，不是新增系统。⚠️ 呈现面独立实现（Web 界面，owner 2026-09-17 裁定），不走 `design → data → code → unity` 既定路径，故切片四轴表**不新增行**。

## 十一、废弃概念

> **⚠️ 已废弃："局"（discrete runs）** — 来自旧卡牌 Roguelike 框架。在连续世界 + 持久成长新框架下，游戏不再划分为离散的"局"。废弃于 2026-07-28 grilling。

> **⚠️ 已废弃："轮回"（reincarnation/reroll）** — 来自旧卡牌 Roguelike 框架。空间复用现在由月光周期自然驱动，不需要轮回机制。废弃于 2026-07-28 grilling。

> **⚠️ 已废弃：镜子房间** — 从固定安全屋重新定位为随身物品。镜子不再是空间，是 UI 界面。废弃于 2026-07-28 grilling。2026-09-18 新增的开局面具整理发生在该 UI 中，不恢复物理房间。

> **⚠️ 已废弃：面具 = 角色选择** — 面具从开局角色选择改为装备（游戏内获得/更换）。14 角色机械设计保留。废弃于 2026-07-28 grilling。
>
> 🔧 **2026-09-17 注**：「废弃」的是**面具承担角色选择**这件事——不是"开局没有选择"。开局的角色侧选择改由**疾病特长**承担（[疾病特长](../entities/%E7%96%BE%E7%97%85%E7%89%B9%E9%95%BF.md)），且形式不是选职业而是**来源解锁**。面具仍只作装备，本行不变。
