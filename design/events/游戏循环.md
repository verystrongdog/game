## 一、核心定位：没有"局"

### 1.1 为什么废除"局"

旧框架（卡牌 Roguelike）中，"局"是离散的游戏单元——每局重新抽牌、打完结算、重来。新框架（回合制 RPG + 髓鞘化持续成长）中：

- 髓鞘化只增不减——角色不会"归零重来"
- 空间拓扑封闭——玩家永远出不去
- 叙事基调是"在无法逃避的困境中如何面对"——不存在"通关"

**"局"的概念被废除。** 玩家经历的是一个连续的、没有明确边界的体验。

### 1.2 为什么废除"轮回"

轮回（软轮回/硬轮回）是旧框架的产物——同一空间在不同轮次承载不同内容。在连续世界中：

- 患者固定——每间病房住的是确定的患者
- 空间变化由月光周期驱动——同一空间在满月和新月下呈现不同状态
- 玩家的持久成长意味着"重来"没有意义

**"轮回"概念被废除。** 空间复用由月光强度和昼夜周期自然驱动。

## 二、时间系统

### 2.1 时段：每天三段

| 时段 | 月光基线 | 特点 |
|------|---------|------|
| **上午** | 弱 | NPC 活动多（查房、工娱疗），适合对话和探索 |
| **下午** | 中 | 部分 NPC 位置改变，某些内容仅在下午可访问 |
| **夜晚** | 强 | 月光最强，危险最高，深层空间更容易滑入 |

时段只提供**软约束**——夜晚出门危险但不是禁止，白天在深处待着也不受限制。时段影响可访问性和风险，不硬性锁死行为。

> **接口契约（Grilling #103 Q3）**：时段「月光基线（上午弱/下午中/夜晚强）」属**观察/呈现层表观**，不是场能量或动力学参数（E_c/E_th/q̂）的时段函数——夜晚更危险、更容易滑入深层等真实机制权重属事件/空间状态层事务（空间维度 grilling 队列项），不由月光场接口层赋予。

### 2.2 时间推进方式：休息驱动

时间不会连续流逝。只有"休息"动作才推进一个时段：

```
玩家自由探索/对话/战斗 → 需要恢复 → 选择休息 → 推进一个时段
```

**设计原理**：战斗损耗（HP/SAN 下降）自然驱动玩家去休息。不需要额外的"你必须睡觉"的压力系统。

**游戏日推进（Grilling #103 Q1/Q4）**：夜晚第 3 次休息完成瞬间 = 游戏日边界 = **唯一的月相推进点**——D → D+1，λ(D) = (1−cos(2πD/29.5))/2 更新（D=0 ↔ 新月，开局醒来）。战斗回合、死亡/复活、空间切换、日内时段切换均**不推进 D**；只有休息推进时间。

## 三、休息与风险

### 3.1 任意地点可休息

玩家可以在任何位置选择休息。没有"必须回到安全屋"的限制。

### 3.2 位置影响偷袭风险

| 位置 | 偷袭概率 | 说明 |
|------|---------|------|
| 物理医院层走廊/病房 | 低 | 相对稳定 |
| 物理医院层公共空间 | 低-中 | 活动室、食堂等 |
| 扭曲空间（轻度） | 中 | 空间开始不稳定 |
| 扭曲空间（重度） | 高 | 靠近患者意识焦点 |
| 患者内心世界 | 极高 | 最深处 |

基础公式：`偷袭概率 = 位置基础概率 × 休息回合数`（封顶 ×4）。

被偷袭时：敌方先手 1 回合，已恢复的 SAN 不损失。

### 3.3 休息效果

| 效果 | 值 |
|------|-----|
| SAN 恢复 | +5/回合（无 CD） |
| 时间推进 | 1 个时段 |
| 快捷槽重排 | 可（通过随身镜子） |

### 3.4 护士站昼夜变化

| 时段 | 护士站状态 |
|------|-----------|
| **白天** | 真人护士——可对话、补给、任务线索。可能沦陷（被敌人占据），需清场才能使用。 |
| **夜晚** | 护士变成**投影**——中立单位，不会受伤，没有情绪反应，更接近一种自然现象。休息功能依然可用。 |

夜晚可有以护士为原型的小头目（负面情绪在月光下扭曲现实的具象化，非三大思潮 Boss 级别）。

## 四、移动与空间切换

### 4.1 分层移动方式

| 空间层 | 移动方式 | 说明 |
|--------|---------|------|
| L0 物理医院 | 自由移动 | 走廊/病房/活动室之间连续走动 |
| L1 扭曲空间 | 单节点 | 一个战斗场景，非节点链 |
| L2 患者内心世界 | 单场景 | 一个大场景（非多节点串联），小头目在场景内某处 |

物理医院的自由移动建立"这是一栋真实的楼"的地方感。

### 4.2 空间切换：鬼打墙式无缝过渡

空间之间的切换采用**鬼打墙式无缝过渡**——场景变化不应被玩家轻易察觉。物理地图不变，但**门的另一侧在变化**。

```
走廊（正常）→ 进门 → L1 扭曲房间 → 门关上（不可逆）
→ 战斗/探索 → 门/窗再打开：
  ├── L1-only: 扭曲消散，房间恢复正常 → 开门回走廊
  └── L1→L2: 门外是患者精神世界 → 找出口 → 回到同一扇门外的走廊
```

核心规则：
- 进入 L1 后**不可回头**，门关上后只能向前
- L1→L2 出门后**回不来**，门变回普通病房门
- L1-only 房间扭曲消散后**可能复发**（休息/η 变化后）
- 月光场 η 越高 → 扭曲房间越多/越易复发

### 4.3 空间渐变（修订）

L1 扭曲空间和 L2 患者内心世界**不是硬分层的两个关卡类型**，而是同一种现象的不同强度：

```
正常物理空间 → 轻微扭曲 → 严重扭曲 → 患者内心世界
               ← 越靠近患者意识焦点，扭曲越深 →
```

两者都是病人精神状态不稳定导致的意识外显效应暴走。扭曲空间是正常物理空间和患者内心世界之间的过渡带。越靠近患者意识关注的区域，空间扭曲效应越严重，最后直接与患者的内心世界连通。

### 4.3 空间复用：月光周期

没有轮回后，空间复用由月光场驱动：
- 同一间病房在不同场强度下呈现不同状态
- 某些内容仅在月光现实（壳上旋转态，d=0）时可访问
- 月相自然推进（每天休息 3 次 = 一天过去）：λ(D) = (1−cos(2πD/29.5))/2，D = 自开局起已完成的游戏日数（D=0 ↔ 新月），每游戏日边界推进一步；满月连续峰值 D=14.75
- 场基线由 `moonState(D)` 只读查询提供（λ/E_c/E_th/q̂ 基线 + 校准状态），游戏日边界广播 `MOON_PHASE_CHANGED` 刷新通知（Grilling #103 接口契约）
- ⚠️ v2 参数 g_0/η/η_crit 已废弃（2026-08-11 #38），具体机制见 [时空结构数学框架 §十一](../rules/%E6%97%B6%E7%A9%BA%E7%BB%93%E6%9E%84%E6%95%B0%E5%AD%A6%E6%A1%86%E6%9E%B6.md)（月光场实例化 + 接口层协议块）

## 五、死亡与复活

### 5.1 分难度

| 难度 | 复活规则 |
|------|---------|
| **低难度** | 死亡 → 都灵之马出现，无限复活 |
| **中难度** | 复活次数有限 |
| **高难度** | 无法复活，HP=0 = 永久死亡 |

### 5.2 灵魂跟随机制

HP=0 → 玩家以灵魂状态跟随都灵之马：

- 持续 **7 回合**
- 马在医院中随机移动
- 玩家可**主动选择**脱离灵魂状态复活
- 7 回合结束 → 在马的当前位置**强制复活**
- 主动 vs 强制复活无代价差异——差别纯粹是控制权

### 5.3 都灵之马

从"中立无敌 NPC"重新定位为**引渡者/psychopomp**——死亡后出现，引导灵魂，随机移动后释放玩家复活。不是敌人，不是盟友，是医院规则的一部分。

## 六、存档

存档 = 暂停并退出。读档 = 继续。**不能"回到过去"。**

死亡必有后果——没有读档重来的路径。中低难度可以随时存档（退出游戏用），高难度无法存档。

## 七、日常节奏

### 7.1 典型一天（无强制）

玩家自由决定每天的节奏。时段只提供软约束：

> 上午 → 探索物理医院，跟 NPC 对话，调查线索
> 下午 → 决定深入方向，进入扭曲空间或患者世界
> 夜晚 → 月光最强，在深处继续推进或返回休息

也可以：上午直接深入深处，花一整天战斗，夜晚踉跄回来休息。或者连续几天在深处不回来（只要能活下来）。

### 7.2 时段影响

某些 NPC 只在特定时段出现在特定位置，某些事件只在特定时段触发。但这不是硬性锁死——是"更容易遇到"而非"只有这时才能遇到"。

## 八、结局触发

### 8.1 三个结局 = 月光的三重叠加

| 结局 | 月光观 | 含义 |
|------|--------|------|
| A | 月光是物理场 | 可量化、可测量、可破解的自然力 |
| B | 月光是有意志的神明 | 会回应、会选择、是活的 |
| C | 月光是无声的催化媒介 | 不强加意义，只是放大 |

不存在"真结局"——月光三重解释同时为真，结局只是玩家最终的存在状态。

### 8.2 触发方式

结局由**条件自动触发**——髓鞘化模式 + 见证的 Boss 故事 + 探索深度 → 阈值到达 → 结局事件自然发生。

玩家不主动选择结局。结局是"你是谁"在最终时刻的自然映射。

### 8.3 Boss 的功能

三个 Boss 对应三种月光思潮。击败 Boss ≠ 选择结局——Boss 战是**见证一种月光思潮的生命史**：它如何从一个人的信念开始，膨胀成有自我意识的存在，在月光下变得强大，最终被自己的信念吞噬走向疯狂。

Boss 的功能是叙事深度体验和深度理解，不是"关卡终点"。

## 九、玩家驱动力

### 9.1 核心驱动：回家

玩家想回家。这是所有人都能立刻理解的驱动力。

### 9.2 张力的处理

"回家"是一个不可及的驱动力。类似《黑暗之魂》的"火已渐熄"——玩家一开始想回家，但随着探索逐渐发现，"家"这个概念本身可能就不存在、已经被摧毁、或只是记忆。

驱动力从一开始的"回家"转化为**"理解为什么回不去了"**。

空间拓扑封闭不是物理牢笼——它是世界观的核心谜题。为什么没有"外面"？答案是否存在，本身就是一个谜。

## 十、游戏开始

### 10.1 初始场景

玩家**在病房中醒来**。没有角色选择画面，没有"选面具"的 meta 步骤。你是谁，醒来时就已注定。

随身携带一面镜子——可以用来自我观察（重排快捷槽），也是死亡后都灵之马找到你的锚点。

### 10.2 面具：从角色选择到装备

面具不再用于"开局选角色"。14 个角色的机械设计保留，但面具改为**装备**——你在医院中探索时找到/获得，戴上后获得对应的机械效果。面具可以更换。

（面具装备的完整机械设计待后续 grilling。）

## 十一、废弃概念

> **⚠️ 已废弃："局"（discrete runs）** — 来自旧卡牌 Roguelike 框架。在连续世界 + 持久成长新框架下，游戏不再划分为离散的"局"。废弃于 2026-07-28 grilling。

> **⚠️ 已废弃："轮回"（reincarnation/reroll）** — 来自旧卡牌 Roguelike 框架。空间复用现在由月光周期自然驱动，不需要轮回机制。废弃于 2026-07-28 grilling。

> **⚠️ 已废弃：镜子房间** — 从固定安全屋重新定位为随身物品。镜子不再是空间，是 UI 界面。废弃于 2026-07-28 grilling。

> **⚠️ 已废弃：面具 = 角色选择** — 面具从开局角色选择改为装备（游戏内获得/更换）。14 角色机械设计保留。废弃于 2026-07-28 grilling。
