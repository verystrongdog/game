## 一、统一基础：脑区链路模型

### 1.1 六层功能层级

技能不来自心理学分类（认知/情绪/行为），而是从脑区的解剖功能自下而上逐层构筑。L0是原子操作，每往上一层是对下层的整合、调制、抑制或重定向。

```
L5  跨模态皮层     ← 语言、推理、社会认知、多模态整合          ～150-300ms
L4  高级单模态      ← 模式识别、特征提取、分类                  ～80-150ms
L3  初级感觉皮层    ← 原始感官输入（V1/A1/S1/M1）              ～30-80ms
L2  旁边缘整合     ← 内感受、突显检测、价值评估                ～50-120ms
L1  边缘系统       ← 核心情绪、记忆形成、奖罚学习              ～20-80ms
L0  脑干核团       ← 生存反射、唤醒、神经调质广播              ～10-30ms
```

**层级关系规则**：

| 方向 | 含义 | 延迟 | 可控性 | 设计含义 |
|------|------|------|--------|---------|
| 自下而上 (L0→L5) | 信号逐层传递、越来越抽象 | 每层+20-50ms | 越低越不可控 | L0 技能可被强制触发 |
| 自上而下 (L5→L0) | 高层调制低层、抑制/重定向 | 每层+30-80ms | 越高越灵活 | L5 可改变低层的触发条件 |
| 侧向 (同层之间) | 同层脑区互相竞争/协同 | 10-30ms | 中等 | 同层技能有连携潜力 |

详见 **[脑功能层级模型](skill-tree/%E8%84%91%E5%8A%9F%E8%83%BD%E5%B1%82%E7%BA%A7%E6%A8%A1%E5%9E%8B.md)** — 50解剖实体完整列表、各层坐标、文献来源。

### 1.2 链路与技能

**链路**：脑区之间的功能连接。数据来源：Hansen et al. (2024) 脑干-皮层FC + 文献荟萃。
连接模型采用**三体神经架构**（Grilling #26）——三种通信原语替代旧的 pairwise 有向模型：
- **CSTC 环路**（门控决策）— 基底节-丘脑-皮层闭环，每回合放行 M1/Broca 各 1 动作
- **皮层-皮层连接**（信息传递）— 双向互惠（Markov 2013），functional_id 节点间 W 矩阵
- **脑干广播**（全局调制）— 4 核团弥漫投射，设置全局 tone 参数

所有链路始终激活（D5 全局激活模型）。激活水平见 [运行时状态模型](skill-tree/%E8%BF%90%E8%A1%8C%E6%97%B6%E7%8A%B6%E6%80%81%E6%A8%A1%E5%9E%8B.md) §九。
连接数据见 `data/connectivity/tripartite_model.json`。

**技能**：链路上下文（网络集合 × 主导角色）的链路组封装。技能 ≠ 链路——链路是底层神经基础设施，技能是链路上下文的可执行组合。快捷槽 6 个装技能，基础行动（物理攻击/精神攻击/防御）保留为无链路要求的基础层。详见 [技能生成机制](skill-tree/%E6%8A%80%E8%83%BD%E7%94%9F%E6%88%90%E6%9C%BA%E5%88%B6.md)。

> **⚠️ 已修正（2026-07-30 / 2026-08-03）**：旧版本文档将"链路"和"技能"混为一谈（§1.2 原标题"链路 = 技能"）。二者现已明确分开：脑区承载链路，技能 = 链路上下文链路组。37 个 AI 操作技能已废弃（D20，2026-08-03），快捷槽装的是技能，不是链路。详见 [方案-v3-链路数据层重构](../archive/grilling/review-plan-design/%E6%96%B9%E6%A1%88-v3-%E9%93%BE%E8%B7%AF%E6%95%B0%E6%8D%AE%E5%B1%82%E9%87%8D%E6%9E%84.md)。

### 1.3 髓鞘化成长

> 🔧 **语义注记（2026-09-06 Grilling #119 定案）**：m（髓鞘化）= 三体连接的**功能成熟度**——复合抽象参数，髓鞘化仅为科学锚标签。m 内写入 = {使用 Δm、可塑性巩固增强、关键突破}；m 外状态 = {标记倍率位、聚焦倍率}（不属 m 成分）。m 只经强度读出（W ∝ m_mean）与效率读出（sigmoid(m)）影响数值，**不改变激活条件**。0.8→1.0 关键突破 = **自动化跃迁**（受控→自动加工完成，叙事节点为催化剂——见 [脑功能层级 §12.1](skill-tree/%E8%84%91%E5%8A%9F%E8%83%BD%E5%B1%82%E7%BA%A7%E6%A8%A1%E5%9E%8B.md)）。详见 [决策树 #119](../decisions/README.md)。

技能不使用"技能点"购买——**使用即成长**。

| 髓鞘化 m | 阶段（玩家侧正式名） | 机制注记（旧名） |
|----------|---------------------|------------------|
| 0-0.3 | 笨拙 | 初学 |
| 0.3-0.5 | 协调 | 熟练 |
| 0.5-0.7 | 精通 | 专精 |
| 0.7-1.0 | 娴熟 | 精通 |
| 1.0 | **本能** | 完全自动化（= 自动化加工完成，双加工/ACT-R） |

> 🔧 **词表（2026-09-06 Grilling #120）**：阶段正式名 = 笨拙/协调/精通/娴熟/本能（玩家语域）；旧名仅作机制注记。"完全自动化"不再作为阶段显示名。突破规则（0.8→1.0 触发链/就绪门槛/突破资格）见 [关键突破](skill-tree/%E5%85%B3%E9%94%AE%E7%AA%81%E7%A0%B4.md)。

**增长公式**：

```
Δm = base(L) × f(m_current) × g(n_activations) × 标记倍率

其中:
  base(L) — 层级基础增长率:
    L0: 0.03   L1: 0.04   L2: 0.05   L3: 0.05
    L4: 0.06   L5: 0.07

  f(m) = 1 - sigmoid(m, shift=0.45, steep=10)
    — 反sigmoid递减: m越低可塑性越高，m越高增长越慢
    — m=0→0.99, m=0.3→0.82, m=0.5→0.38, m=0.7→0.08

  g(n) — 激活次数亚线性累积:
    g(1)=1.0, g(2)=0.5, g(3)=0.25, g(4+)=0.1
    — 鼓励广度，递减"刷同一招"的收益

  标记倍率: 已标记链路 ×2（来自可塑性巩固 §八）
```

> 注意：这里的 sigmoid 与链路调制天花板的 sigmoid (shift=0.4, steep=8) 参数不同——功能同步窗口 ≠ 可塑性窗口。

### 1.4 敌我同构

NPC 和玩家**共用同一套脑区、链路、髓鞘化、SAN/HP体系**。NPC 的特殊性来自 7 参数化性格（4 tone baseline + 3 CSTC bias），不来自独立系统。

| | 玩家 | 基础 NPC（杂兵） | 高级 NPC（Boss） | 友方 NPC |
|---|---|---|---|---|
| 脑区基础设施 | 完整 50 解剖实体 | 同 | 同 | 同 |

| 聚焦容量 | 起始 4（常驻，无上限，D4） | 同 | 同 | 同 |

| SAN 恢复（脱战） | 跨战斗延续 | 重置到预设值 | 重置到预设值 | 跨战斗延续 |

## 二、玩家交互：基础行动 + 快捷槽 + 链路聚焦（构建层）+ 技能执行（战斗层）

> **⚠️ 2026-08-03 范式修正（Grilling #20）**：旧版"每回合激活点预算 + 手动激活链路"模型废弃。激活点从战斗资源改为**常驻聚焦容量**（D4/D7/D26），链路始终激活（D5），玩家战斗内零资源管理。详见 [方案-v3-链路数据层重构](../archive/grilling/review-plan-design/%E6%96%B9%E6%A1%88-v3-%E9%93%BE%E8%B7%AF%E6%95%B0%E6%8D%AE%E5%B1%82%E9%87%8D%E6%9E%84.md)。

### 2.1 全脑全局激活模型（D5）

**所有链路始终处于激活状态**——不存在"未激活的链路"。

运行时激活水平由三层因果链动力学决定（Grilling #32，详见 [运行时状态模型](skill-tree/%E8%BF%90%E8%A1%8C%E6%97%B6%E7%8A%B6%E6%80%81%E6%A8%A1%E5%9E%8B.md)）：

```
回合 Phase 1 情境更新:
  Layer 2  脑干 tone  ← clip(baseline + δ_eff + (tone−baseline−δ_eff)·e^(−Δ/τ), 0, 1)   [4 调质，解析解]
       ↓ b_j = Σ tone × w(j)
  Layer 1  皮层 a(t)  ← a' = σ(h) + (a − σ(h))·e^(−Δ/τ)                              [69 节点，解析解]
       ↓ c_loop = mean(a(CI))
  Layer 3  CSTC gate  ← 1 − O_GPi                                                    [3 环路]
```

- **节点级而非链路级**：激活变量 `a(t)` 附着在 69 个 functional_id 上（神经群体），不逐链路计算
- **髓鞘化进权重**：m（髓鞘化）决定连接权重 W，间接驱动激活传播，不再作为直接乘数
- **情境通过网络涌现**：不再逐链路查"情境相关性"——s(t) 激活关键节点 → W 传播 → 全脑响应
- **聚焦 = W 倍率**：聚焦改为 W 矩阵的连接权重倍率（×2.0），不再直接乘在公式中

旧公式 `激活水平 = m × rel × focus` 的迁移对照见 [运行时状态模型 §九](skill-tree/%E8%BF%90%E8%A1%8C%E6%97%B6%E7%8A%B6%E6%80%81%E6%A8%A1%E5%9E%8B.md#九mrelfocus-的角色迁移)。

### 2.2 激活点 = 常驻聚焦容量（D4/D7）

**激活点不再是战斗资源，是构建层资源**——髓鞘化驱动的成长指标，无上限：

```
激活点 = 常驻聚焦容量（能同时聚焦多少条链路的数量）
基础: 4（Cowan 2001 工作记忆容量 3-4）
成长: 任意 2 条链路 m ≥ 0.7 → +1，任意 4 条链路 m ≥ 0.7 → +2（原 §8.5 保留）
无上限: 随髓鞘化成长持续增长
```

- **髓鞘化 = 质量**（哪些链路强、多强），**激活点 = 数量**（同时聚焦几条）
- 聚焦在**构建层（非战斗）**配置——战斗中不再分配聚焦
- 战斗中技能激活 = **启用已聚焦链路组**（D26），不消耗激活点

### 2.3 构建层 vs 战斗层

```
构建层（非战斗）:
  玩家操作: 髓鞘化（使用即增长，m0→0.8→1.0）+ 聚焦（激活点配置常驻聚焦集）
  产出: 常驻聚焦链路集 + 技能构建

战斗层（执行）:
  玩家操作: 快捷槽技能（6 个）+ 基础行动
  技能 = 链路上下文（网络集合×主导角色）的链路组
  技能激活 = 启用已聚焦链路组（组内链路 ×2 生效）
  战斗资源: 仅冷却/时机决策——零资源管理
```

### 2.4 快捷槽

- 战斗前从**已解锁的技能**中选择 **6 个**编入快捷槽
- 战斗中点击快捷槽图标触发技能（如有目标指向则选目标）
- 快捷槽在非战斗时通过技能树界面管理
- ⚠️ 快捷槽装的是**技能**，不是链路——这是两个独立系统

### 2.5 回合战斗流程

完整的回合制战斗阶段/时机/响应窗口定义见 **[回合战斗流程](%E5%9B%9E%E5%90%88%E6%88%98%E6%96%97%E6%B5%81%E7%A8%8B.md)**。以下为摘要：

**核心原则**：不设 AP。行动约束来自基底节 CSTC 环路门控——M1 运动环路和 Broca 语言环路各自独立放行，每回合各 1 个动作。

**五阶段结构**：
```
Phase 1: 情境更新 → L0-L2 自动激活
Phase 2: 继承 → 持续链路冷却递减
Phase 3: 速度排序 → 察觉+决断+执行 三成分加权，排出全局顺序
Phase 4: 按序执行 → 快→慢轮流行动，后动者看到前方公开行动
        每个行动窗口：声明 → 响应窗口 → 结算
Phase 5: 回合收束 → 释放已激活链路 + NPC 策略更新 → 下一回合
```

**关键设计决策**：
- 先手盲选，后手可见前方行动（信息不对等 = 战术深度）
- 防御 = 跨行动窗口持续状态（从自己行动时到下次自己行动时）
- 响应窗口在"声明"和"结算"之间——意图与落地有间隙
- 即时伤害当场结算，被击倒者跳过当回合行动窗口
- L4 读意图 = 盲选时可窥探对方意图
- 伏击 = 察觉方获 1 轮自由行动窗口

## 三、NPC AI：Affordance Competition

> 完整设计见 **[NPC AI 行为模型](skill-tree/NPC%20AI%20%E8%A1%8C%E4%B8%BA%E6%A8%A1%E5%9E%8B.md)**。以下为机制摘要。

### 3.1 核心理念

NPC 的行动选择从与玩家共享的神经动力学中自然涌现（Cisek 2007 + GPR 2001），无需离线预烘焙：

```
Salience(skill) = mean(a_j for j ∈ skill.cortical_nodes) × gate_bonus(role) × (1 + tone_bias(role))
NPC 行动 = argmax Salience  (Boss) 或 Softmax Salience/T  (杂兵)
```

### 3.2 性格参数化

NPC 性格由 7 连续参数定义（4 tone baseline + 3 CSTC bias）。6 概念标签（敏化-威胁/敏化-奖励/抑制不足/过度抑制/反刍/社交钝化）保留为设计师简写界面，底层自动映射到 7 参数。

### 3.3 响应速度

| 响应类型 | 时机 | 机制 |
|---------|------|------|
| 反射级（L0-L2） | **同回合** | δ_event 冲击即时改变 tone → tone_bias 偏移 → 同回合重算 salience |
| 策略级（L3-L5） | **下回合** | 下回合 Phase 1 更新 a(t) + gate → 重新计算全技能 salience |

### 3.4 多 NPC 协调

不设显式"团队 AI 层"。协调从现有机制自然涌现：
- **情境共享**：同阵营 NPC 共享事件冲击（δ_event + s(t)）→ 类似 tone 状态 → 类似行为倾向
- **观察读出**：社会认知链路感知同伴 M1/Broca 输出 → 自动行为调整
- **主动协调**：NPC 用语言对同伴发出意图——**公开可听**（玩家可偷听、利用）

## 四、战斗结算

### 4.1 基础行动

基础行动不来自任何解锁——它们是角色的**身体和声音**，开局即存在。所有链路的调制最终汇入两条输出通道：M1（骨骼运动）和 Broca（语言）。

| # | 行动 | 类型 | 动作 | 冷却 | 效果 |
|---|------|------|-----|------|------|
| 1 | **物理攻击** | 物理 | 1 | 0 | HP -4 |
| 2 | **精神攻击** | 精神 | 1 | 0 | SAN -2, HP -1 |
| 3 | **防御** | 防御 | 1 | 1 | 本回合物理伤害 -50% |

**设计原则**：身体不需要大脑许可就能出拳。精神攻击走 Broca 通道（言语/思维），占用该通道 1 回合。

### 4.2 物理攻击

```
脑区: M1 + 壳核 (CSTC 感觉运动环路)
空手伤害: 4 HP
命中率: 85%（基础）+ 武器命中修正 + 链路命中调制
```

- 受 L0 趋向回避: -10% 命中
- 受 L1 失望标记: -5%/层
- 受 L3 执行动作(精准): +20% 命中
- 伤害公式: `(4 + weapon_bonus) × (1 + force_mod + motivation_mod)`，weapon_bonus 0~+6, force cap +50%（下界 0——沮丧不降出力），motivation cap +100%（下界 −1——🔧 2026-08-14 Grilling #24 E-1 裁决：低动机沮丧时物理出力下降，与精神攻击及 flow 层 producer 口径统一）。武器数据见 [design/entities/武器与装备](../entities/%E6%AD%A6%E5%99%A8%E4%B8%8E%E8%A3%85%E5%A4%87.md)
- 暴击（🔧 2026-08-16 Grilling #77 新增，F-3 规则空缺补全）: 命中判定通过后 → `crit_rate = clip(base_crit + k_crit × (a_exec − θ_crit), 0, cap)`，`a_exec = mean(a(Precentral), a_SD1_somatic)`（与速度执行分同源）；暴击伤害 ×1.5（基础 → gate×防御 → ×1.5 → 量化）；emit A3+B3 事件。参数 **base_crit 0.05/θ_crit 0.82/k_crit 1.0/cap 0.30 [NEW] 暂定（2026-09-03 Grilling #35 定案）**——θ_crit/k_crit 由原 0.6/0.5 上调：静息 a_exec=0.80777 实测（csharp-speed 任务issue #5），原 θ_crit=0.6 使静息即 15.4% 暴击（结构性错位）；**低于阈值保留负偏差**（a_exec<θ_crit 时 crit<base_crit，静息约 3.8%，惩罚语义，不加 max）；P4d 实施后按实际 a_exec 分布回归校准。L4 识别弱点 → crit_rate +0.15
- 结算量化（2026-08-13 裁决）：伤害/SAN/HP 全程一位小数——主伤害 round 半进位量化到 0.1，每步结算后立即量化（防 f32 漂移）；基础伤害 4 HP 即 4.0

### 4.3 精神攻击

```
脑区: dlPFC/ACC → 无特定运动输出
基础伤害: 2 SAN + 1 HP
命中: 永远命中（你无法选择不听别人说话、不看别人眼神）
```

精神攻击的本质不是"发出精神波"——是"你的存在、你的凝视、你的意志对他人构成的精神压力"。在月光下，这种压力变得物理上真实（意识外显效应）。

**防御靠认知重评**（前额叶对情绪信号的重新解释），而非闪避：

> **🔧 2026-09-03（Grilling #35 定案）：精神攻击范式迁移至 a(t) 派生轨。** 新公式 = `mean(a of S_mental) × scale_mental − 忍耐`（S_mental = cognitive CSTC 环路 ∩ W活跃 7 fid，见 [运行时状态模型 §8.1](skill-tree/%E8%BF%90%E8%A1%8C%E6%97%B6%E7%8A%B6%E6%80%81%E6%A8%A1%E5%9E%8B.md)；scale_mental ≈ 3 暂定，PENDING_IMPLEMENTATION）。下方旧公式 `2 × (1 + motivation_mod)` **降级为迁移前实现/历史公式**——引擎（`DamageCalculator.CalcMentalDamage` 常量 base 2）在 P 系列接入前继续运行旧轨（受控暂态：规范世界=新轨 / 运行世界=旧轨）。motivation 乘子随迁移删除（动机经 DA_VTA tone → b_j → a(t) 内化，再乘即双算）。

```
精神攻击实际伤害（旧轨，历史实现） = 2 × (1 + motivation_mod)
                   - 敌方忍耐被动减免
```

- 忍耐·主动: 占用 Broca 通道 1 回合 → SAN 减免翻倍（-2 而非 -1），持续 1 回合，CD 2
- 低 SAN 穿透: 敌方 SAN < 30% → 额外 +30%；SAN < 15% → ×2
- 结算量化（2026-08-13 裁决）：精神 SAN 伤害 round 半进位量化到 0.1；HP 成分 = SAN伤害 × 0.5 向下取至 0.1（基础 2 SAN + 1 HP 即 2.0/1.0）

详见 **[基础行动设计](skill-tree/operations/%E5%9F%BA%E7%A1%80%E8%A1%8C%E5%8A%A8%E8%AE%BE%E8%AE%A1.md)**。

### 4.5 胜负条件

| 条件 | 效果 |
|------|------|
| **HP = 0** | 物理压制——被击败，离开战斗，留尸体 |

## 五、SAN 系统

### 5.0 SAN/HP 上限

SAN 上限来自三项加和：实体类型基线 + 稳定链路髓鞘化 + 装备。HP 同理（不含链路项）。面具组件对 SAN 的影响走 link_SAN 路径——组件改变链路 m，间接影响 stabilising 链路的均值。

```
SAN_max = SAN_base(entity_type) + link_SAN + equipment_SAN
HP_max  = HP_base(entity_type)  + equipment_HP

link_SAN = k_stab × mean(m_stabilizing) × SAN_base
  k_stab = 0.3（初值可调）
  stabilizing = {Emotion Regulation, Cognitive Attention Control} 网络，共 20 条链路
```

| 项 | 说明 | 来源 |
|---|------|------|
| **SAN_base / HP_base** | 实体类型查表——角色/敌人/NPC 各自有基线值 | §十 参数速查 + 敌人 Stat Block |
| **link_SAN** | 稳定链路髓鞘化均值 × 系数 × SAN_base。组件间接影响此项（修改链路 m 后自动反映在 mean 中） | 本节 |
| **equipment_SAN / equipment_HP** | 护甲/饰品附加的 SAN/HP 上限。当前全 1/1 占位 | [武器与装备](../entities/%E6%AD%A6%E5%99%A8%E4%B8%8E%E8%A3%85%E5%A4%87.md) 各物品表 |

### 5.1 SAN 分段效果

| SAN (% of SAN_max) | 效果 |
|----------|------|
| SAN ≥ 90% | 高峰——感知精度最高，情境扰动 < 5% |
| SAN ≥ 60% | 稳定——正常运作 |
| SAN 30-59% | 承压——情境偏移，新颖性维度 ±10% |
| SAN < 30% | 恐慌——切换到恐慌行为表，L0-L2 可能额外触发焦虑链路 |
| SAN < 15% | 崩溃边缘——可能随机触发不应激活的链路（幻觉） |
| SAN = 0 | **完全随机行为**——从所有合法链路中完全随机激活，不受情境和性格约束 |

### 5.2 SAN 恢复

**战斗内**：

| 操作 | SAN 恢复 | 成本 | 限制 |
|------|---------|------|------|
| L2 内省 | +5 | 动作 1, CD 4 | 恐慌状态不可用 |
| L5 自省（元认知） | +3 | 动作 1, CD 5 | 可清除负面标签 |
| 忍耐·主动 成功 | +2 | — | — |

**战斗间（休息）**：

| 参数 | 值 |
|------|-----|
| 每休息回合 SAN 恢复 | +5（无 CD） |
| 偷袭概率 | 基础概率 × 休息回合数（封顶 ×4） |
| 偷袭后果 | 敌方获得 1 回合先手，休息被打断（已恢复的 SAN 不损失） |

### 5.3 SAN/HP 互转

- **HP → SAN**（自残——疼痛接地）：
  - 兑换率：前 10 HP → 1:2（1 HP 换 2 SAN），后 5 HP → 1:1（递减）
  - 单次上限：最多花 15 HP（换最多 25 SAN）
  - 单场战斗上限：30 SAN 总恢复
  - 动作成本：占 M1 通道

- **SAN → HP**（如吃怪物肉——月光下信仰赋能的肉体恢复）：
  - 兑换率：前 10 SAN → 2:1（2 SAN 换 1 HP），后 10 SAN → 3:1（递减）
  - 单次上限：最多花 20 SAN（换最多 8 HP）
  - 单场战斗上限：15 HP 总恢复
  - 动作成本：占 M1 通道

- **约束**：兑换率不对称——HP→SAN 效率更高（真金白银的痛苦换稳定），SAN→HP 效率更低（牺牲精神是危险的交易）

## 八、可塑性巩固

> 髓鞘化回答"用得多所以熟练"。可塑性巩固回答"经历得多所以学得快"——前者是局部、自动、使用驱动的；后者是全局、手动、经历驱动的。二者互补构成完整的成长系统。
>
> **2026-07-31 修订**：去掉"点数"中间抽象和等级系统。事件强度动态计算，巩固窗口立即选择，效果由事件实际参与决定。详见 [任务/目标系统 §九](../events/%E4%BB%BB%E5%8A%A1%E7%9B%AE%E6%A0%87%E7%B3%BB%E7%BB%9F.md#九可塑性巩固整合)。

### 8.1 神经基础

**突触标签与捕获（Synaptic Tagging & Capture, Frey & Morris 1997）**：弱刺激在突触上设定短暂的"标签"（蛋白合成不依赖，持续~2-3小时）。重要事件（显著/新异/情绪性）触发**可塑性相关蛋白（PRPs）**合成——BDNF、PKMζ、CREB 等——由蓝斑核-去甲肾上腺素（LC-NE）相位激活释放，在全脑扩散。标签捕获 PRPs → early-LTP 转化为 late-LTP → 暂时变化固化为长期变化。

玩家经历重要事件 → LC-NE 相位激活 → PRP 释放 → 玩家手动选择将 PRPs 引导至特定链路的标签上。

### 8.2 事件强度（动态计算）

事件强度不再用固定档位（小/中/大），而是从事件本身动态计算。

**战斗事件**（三因子）：

```
事件强度 = 挑战度 + 激活广度 + 叙事权重
```

| 因子 | 计算方式 | 范围 |
|------|---------|------|
| **挑战度** | 敌方最强链路 m / 玩家对应链路 m（红骷髅同一逻辑） | 0-1 |
| **激活广度** | 战斗中激活的链路数 / 激活点上限 | 0-1 |
| **叙事权重** | Boss 网络距离基础值 + 设计师可调偏移 | 0-1 |

**非战斗事件**（纯叙事权重）：

```
事件强度 = Boss 网络距离基础值 + 设计师可调偏移
```

> 非战斗承诺的完成过程未激活特定链路，无法用挑战度和激活广度衡量——其"值得巩固"程度由叙事意义决定。

**强度→效果映射**：

| 强度 | 增强 (m+) | 标记可用 |
|------|----------|---------|
| 低 (<1.0) | m + (0.03-0.07) | 否 |
| 中 (1.0-2.0) | m + (0.07-0.12) | 可选（增强/标记二选一） |
| 高 (>2.0) | m + (0.12-0.20) | 是 |

### 8.3 巩固窗口（立即选择）

事件结束后**立即**弹出巩固窗口：

1. 短暂定格（1-2 秒）
2. 脑区面板自动弹出
3. 高亮本次事件中**激活过的链路**（金色边框 = 可选巩固目标）
4. 灰色链路 = 未参与此事件，不可选
5. 选中一条链路 → 选择效果：[标记] 或 [增强]
6. 确认 → 面板关闭 → 回到游戏

**关键约束**：
- **即时决定**：巩固窗口不可跳过、不可延迟——经验在此刻被捕获或永远流失
- **仅参与者可选**：只有本事件中激活过的链路能被巩固
- **非战斗例外**：纯非战斗承诺（探索/对话）的巩固窗口，所有已解锁链路均可选
- **标记唯一**：同一链路不可重复标记——已标记链路显示 ⊗，不可再选
- **增强上限**：m > 0.3 后增强不可用——显示灰色 + 原因（"髓鞘化已超过增强上限"）

### 8.4 两种效果

| 效果 | 神经隐喻 | 机械效果 | 约束 |
|------|---------|---------|------|
| **标记** | 突触标签 — 对未来可塑性更敏感 | 该链路后续 Δm 永久 ×2 | 不可重复 |
| **增强** | 即时捕获 — PRP 立即利用 | m + (强度决定量) | m > 0.3 不可用 |

- 标记 = 理解了原理，以后练它事半功倍
- 增强 = 没练过但理解了，直接推进髓鞘化
- m > 0.3 后只能通过标记和实际使用继续成长——巩固帮你入门，实践帮你精进

### 8.5 激活点增长（髓鞘化驱动）— 常驻聚焦容量

> ⚠️ **2026-08-03 修正（Grilling #20，D4/D7）**：激活点从"每回合战斗资源"改为"常驻聚焦容量"（构建层资源）。**无上限**——随髓鞘化成长持续增长。

激活点不由等级驱动，而由髓鞘化成熟度驱动：

| 条件 | 激活点（聚焦容量） |
|------|--------|
| 起始 | 4 |
| 任意 2 条链路 m ≥ 0.7 | +1 → 5 |
| 任意 4 条链路 m ≥ 0.7 | +1 → 6 |
| 后续成长 | **无上限**（髓鞘化持续增长则容量持续增长） |

聚焦容量用于构建层配置常驻聚焦链路集（§2.2）。战斗中不再消耗激活点。

### 8.6 敌我同构

- 仅玩家有此系统
- NPC 使用静态髓鞘化模板，无巩固窗口
- Boss 虽有"跨战斗延续"髓鞘化，但无额外标记/增强能力

## 十、数值基线

> 2026-07-31 数值校准 grilling — 奠基层参数。详见 [决策树](../decisions/README.md)。

### 10.1 HP/SAN 上限公式

```
SAN_max = SAN_base(entity_type) + link_SAN + equipment_SAN
HP_max  = HP_base(entity_type)  + equipment_HP

link_SAN = k_stab × mean(m_stabilizing) × SAN_base
  k_stab = 0.3（初值可调）
  stabilizing = {Emotion Regulation, Cognitive Attention Control}，共 20 个 functional_id（见 data/connectivity/tripartite_model.json）
```

阈值（≥60% 稳定/<30% 恐慌/=0 随机）为相对值——按 SAN_max 百分比计算。详见 §五。
