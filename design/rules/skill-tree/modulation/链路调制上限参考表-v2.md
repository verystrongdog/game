### 物理伤害双通道公式

```
物理攻击伤害 = base × (1 + force_mod + motivation_mod)

force_mod = min(Σ force链路.ceiling × sync(myelination), 0.50)
  → "你的身体能做到什么程度"
  → 稳定, 可靠, 不受情境影响

motivation_mod = min(Σ motivation链路.ceiling × sync(myelination), 1.00)
  → "你想做到什么程度"
  → 情境敏感: 对恐惧标记敌人+额外动机, 对友方-动机
  → 高 motivation_mod 时: 伤害+但自身SAN消耗+ (用力过猛)
```

## 结算顺序 (Priority Rules)

同一回合内, 低 priority 的链路先结算:

| Priority | 层级 | 典型链路 | 先结算什么 |
|----------|------|---------|----------|
| 1 | L0 脑干 | 应激反应, 警觉, 忍耐 | 闪避判定, 恐慌触发, SAN护盾 |
| 2 | L1 边缘 + L3 感觉 | 恐惧条件化, 期待, 注视 | 情绪调制, 感官信息获取 |
| 3 | L2 旁边缘 | 冲突感知, 内感受, 识人 | 异常检测, 阈值显示 |
| 4 | L4 单模态 | 识别, 读意图, 想象 | 分类标签, 意图预测 |
| 5 | L5 跨模态 | 计划, 命名, 控制, 决策, 叙事重构, 全脑协调, 裁决 | 认知框架, 伤害计算, 全局规则改变 |

> **设计含义**: 身体反应(闪避/恐慌)永远比理性决策(计划/命名)先发生。你想压制恐惧→先用 L5 控制, 但 L0 的恐惧已经在 priority=1 时执行了——你得预判。
