# 素材起草规范 v1.0（NPC 患者叙事视图执行规范）

> #87 A′-Generator 起草的执行规范——管"如何写叙事"（资格声明侧规范管"如何判声明"，本文管"如何起草"，姊妹文档）。把今天 7 稿验证有效的工艺固化为可执行 checklist，任何起草者（含无长上下文的新会话 AI）按此执行可维持质量下限。
>
> 依据：#89-D18 两层模型（A1-A4 功能完成度 / B1-B5 质量校验）+ 批次配额表 + 六轴多样性 + 本批 7 稿实证（周卫国/杨秀兰/苏晴/吴桐/唐念安/许一鸣/贺春兰）。

## 一、起草前必读（防上下文丢失 + 防同质化）

1. **读索引簿**：[患者生态索引](../../spec/material/%E6%82%A3%E8%80%85%E7%94%9F%E6%80%81%E7%B4%A2%E5%BC%95.md)——查目标病种/地域/时代/机制是否与存量或同批冲突（例：周卫国×陈国强同为东北钳工 4050——若先读索引可避开）；
2. **读记账表**：[多样性记账表](../../spec/material/%E5%A4%9A%E6%A0%B7%E6%80%A7%E8%AE%B0%E8%B4%A6%E8%A1%A8.md)——查六轴缺口与地域/时代/性别池，确定本稿命中的差异化点；
3. **读配额表位定义**：目标病种 × 六轴缺口 × 创伤通道（[批次配额表](../../spec/material/%E6%89%B9%E6%AC%A1%E9%85%8D%E9%A2%9D%E8%A1%A8-P1%E8%A1%A5%E5%85%85.md)）；
4. **读目标病资格签名**：转化接口 §3.2.2 签名表——起草时按签名铺设叙事证据（声明型原子要在叙事里有"=1 的依据"和"=0 的替代解释"；表征型如 PTSD 要铺 F/N 记忆）。
5. **（非患者侧）** 起草医护 / 警卫 / 科研 / 后勤 / 家属时，改读 [NPC生态台账](../../spec/material/NPC%E7%94%9F%E6%80%81%E5%8F%B0%E8%B4%A6.md)（名单与驻地）+ [职能侧多样化轴](../../spec/material/%E8%81%8C%E8%83%BD%E4%BE%A7%E5%A4%9A%E6%A0%B7%E5%8C%96%E8%BD%B4.md)（替代本文 §四 的患者六轴）——患者六轴以「入院」为原点，员工没有入院动作；第 1–3 步的患者侧三件（索引簿 / 记账表 / 配额表）对非患者不适用。

## 二、叙事视图结构模板（章节）

1. **开场场景**（具体、感官化、埋核心冲突）——用"现在时"切进一个关键时刻（除夕/厕所/会议室/秤前）；
2. **土壤**（出生地域/时代/家庭——社会演化矩阵对齐，一段交代阶级与时代印记）；
3. **创伤成型**（诱发事件：羞辱/丧失/控制/暴力——必须是事件，不是概述）；
4. **病程展开**（症状如何演化/藏匿/影响生活——写"机制"不写"标签"）；
5. **危机/转折**（入院触发点——六轴轴 1 的叙事化）；
6. **病房**（与存量/同批患者的生态交互——必须先查索引知道病区里"住着谁"）；
7. **收束**（一丝转变或洞见——不治愈，但移动一点点）。

> 存量 6 + 同批 6 位在 B 病区（周/杨/苏/吴/唐/许/贺 7 位新 + 顾/孙/陈/林/高/王 存量视入院时间）——生态联动优先与**同病区**病友编织。

## 三、B1-B5 质量校验清单（每稿必须全达标）

- **B1 台词样本 ×4**：不同场景/不同对象；每句可反推人物（语言指纹）；含 1 句"核心句"（可当宣传语/主题锚）；
- **B2 日常碎片 ×6**：动作性细节；其中至少 1 件是"物件仪式"（秤/剪刀/检查单/笔记本——症状的具象载体）；
- **B3 症状可见化**：表格列出症状簇 × 表现 × 触发——机制可见而非标签堆叠；
- **B4 反直觉点**：1 段说明"这个人最反直觉的地方"——人物不是标签的集合；
- **B5 五感细节 ×5**：至少 2 个"创伤锚定感官"（气味/声音/触觉与创伤事件绑定——如贺春兰的胃酸味、唐念安的刀声）。

## 四、六轴命中与反同质化

1. 每稿在头部声明差异化定位（命中的缺口）；
2. 地域/时代/职业尽量不与存量重复（查记账表）；必要时同城但语境分离（如广州：林小满城中村打工 vs 唐念安白领妈妈）；
3. 每稿必须与**至少 1 位**同病区患者有真实的生态交互（写进病房章节），交互点要机制相关（BN×AN 互督吃饭 > 泛泛聊天）。

## 五、资格合规与回放

1. 起草时铺设目标病签名所需叙事证据（声明原子 =1 要有叙事依据；排除原子要有替代解释）；
2. 起草后在 `.gen.json` 写入结构化事件、记忆与精确的 `资格声明（#87 规范化声明）` 块；不从叙事自然语言猜测声明；
3. 将成对草稿登记到 `design/spec/material/npc-materials-manifest.json`，并按其规范输入 `{events, memories, declarations}` 人工核对（原由 `validate_npc_materials.py` 内部 Adapter 转出 `validate_eligibility.py` 的输入——两件均已随全部门禁于 2026-09-17 删除）；
4. 回放目标病种资格：状态为 `validated` 的草稿，目标病必须回放为 **ELIGIBLE**（⚠️ 原 `python3 code/tools/validate_npc_materials.py` 这条命令已不可跑，回放改人工按本表逐原子判）；
5. 若 INELIGIBLE：修叙事（不修声明凑数——防污染铁律）；若输入缺失则补资料，不得误判为通过；
6. 交叉声明全 0 需在叙事里有支撑（无独立 MDE 等）；
7. 目标病 ELIGIBLE 但其他病也 ELIGIBLE（共病）时，主病由聚合/主病选择分流——在 gen.json 注明。

## 六、产出与落盘

- `drafts/<名>-叙事视图.md`（本章节模板）+ `drafts/<名>.gen.json`（identity/lifespan/relations/traits_origin/story_hooks/trauma_memories/**反应史**/资格声明/symptoms_presentation/transformation）；
- **`反应史`**（2026-09-18 新增，依据 [NPC人生生成器 §4.2](../../events/NPC%E4%BA%BA%E7%94%9F%E7%94%9F%E6%88%90%E5%99%A8%E8%AE%BE%E8%AE%A1.md) 微观层两步化）：条目 = `{处境, 反应, 反应类型, 后果}`——**只记可观察动作，不写道德判词，不得写成受害者有罪**；它是"为什么这个人病了 / 没病"的**内部**那一半（外部那一半是处境采样）；
- **`档位` 与 `临床严重度` 是两个字段，不许混写**（2026-09-18 owner 裁定拆字段，全池 25 份已执行）：
  - **`档位` 只指创伤负荷档**——定义见 [创伤记忆转化接口 §3.3](../skill-tree/%E5%88%9B%E4%BC%A4%E8%AE%B0%E5%BF%86%E8%BD%AC%E5%8C%96%E6%8E%A5%E5%8F%A3.md)，**取值是闭集** `{∅, 轻, 中度, 重}`（键在 `L_agg(d)` 上，`= clamp(g(L_agg) + h(I_max_agg), ∅, 重)`）；**`∅` 时不得带 `阈值`**，其余档必须带同档 `阈值`（`轻 [1.0,2.0)` / `中度 [2.0,3.5)` / `重 [3.5,∞)`）；
  - **`临床严重度`**（`disease_profile` 同层）= 病种 CGI-S 范围（来源 `design/entities/diseases/<病>.md`）+ **本例的临床严重度声明**（住院指征 / 功能形态 / 排除性评估；P2 批那种"由某某声明侧判定"的文字就归这里）。
  - ⚠️ **`L_agg < 1.0` ⇒ `档位 = ∅` 而病依然是真的**：此时病理化由**声明侧资格原子**承担（`SZ_POSITIVE_COURSE_HISTORY` / `ASPD_PATTERN_HISTORY` …），两义不得互推（先例：张守义/段鹏/易川）。`check_npc_materials.py` 的 `bands` 判据按此三项执法（闭集 / ∅ 不带阈值 / 患者稿必带 `临床严重度`）；
- **非患者侧变体**（[素材起草规范 §一 第 5 步](#一起草前必读防上下文丢失--防同质化)）：医护 / 警卫 / 科研 / 后勤 / 家属稿的 `.gen.json` **移除** 资格声明 / transformation / disease_profile / symptoms_presentation，**新增** 履历 / 岗位与年限 / 反应史 / 压抑计数线 / 去留弧线，并以 `key_memories` 替代 `trauma_memories`（健康者置空）。首例 = `drafts/郑晓敏.gen.json` v1.1；此外**未患病者的背景须过** [正常人侧反模子清单](../../spec/material/%E6%AD%A3%E5%B8%B8%E4%BA%BA%E4%BE%A7%E5%8F%8D%E6%A8%A1%E5%AD%90%E6%B8%85%E5%8D%95.md)；
- 每稿完成后**登记 manifest，并更新索引簿 + 记账表**（一行）；
- 头部注明：配额表位/目标病种/差异化定位/资格门状态。
- 落盘后必须运行完整 NPC 素材审计，不得只对单份临时规范输入跑资格门。
