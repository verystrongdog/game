# 资格声明侧规范（#87 A′ 声明形成规则）

> 资格门只消费 #87 已规范化声明（E_d^hist），不解析叙事（转化接口 §3.2.2 :175）。本文定义**声明如何从叙事形成**——"什么素材算成立（=1）"、"什么素材不算（=0 的替代解释）"、三值语义与回放门流程。这是平凡实例化下**防声明污染**的执行防线：起草者按目标病实例化时，声明判定必须过替代解释纪律，不能因"目标要这个病"就让素材自动达标。
>
> 依据：#113 资格层（G1-G4/归位原则/三值语义）+ 批次 1-2 资格签名定案（转化接口 §3.2.2）+ 校验器 `code/tools/validate_eligibility.py`。

## 一、总则

1. **三值语义**：`X_e ∈ {1（叙事有明确临床素材支撑）, 0（有明确替代解释或素材明确否定）, MISSING（该维度无资料/不可判）}`。**MISSING ≠ FALSE**；MISSING → UNDETERMINED。
2. **替代解释纪律（核心防污染）**：#89 陈国强先例——"有低落 ≠ DEPRESSIVE=1：低落被饮酒 + 处境解释 → =0"；顾维扬先例——"创业高光 ≠ HYPOMANIA=1：缺完整发作三样 + 时代红利替代解释 → =0"。推广：**任何 =1 必须无竞争性替代解释；存在替代解释 → =0（不是 MISSING）**。
3. **硬证据优先**（#113 组合规则）：必要原子显式 0 / 排除原子显式 1 → INELIGIBLE，优先于其他原子 MISSING（校验器已实现）。
4. **判定主体**：#87 起草者（人机协同）+ 回放审计；资格门（校验器）只机械检查，不重判临床。
5. **病程/时长/组合判定**（≥X/Y、≥6 月、≥2 年、15 岁前、>1h/天 等）**全部在声明侧完成**——声明值 = 已含时长判定的临床事实，资格门不现场计算（CYCLIC 配方）。
6. **回放门流程**：起草叙事 → 按本表逐原子判定（填 1/0/MISSING + 依据）→ `validate_eligibility.py` 机械回放 → 目标病须 ELIGIBLE 且依据链可审计 → 用户审阅。

## 二、原子判定要点表

> 列：原子 | 声明语义 | =1 的叙事素材（成立要件） | =0 的替代解释（不成立要件） | 反样本/注意

### A. 心境发作史类（首批五基础原子 + 病程型）

| 原子 | 语义 | =1 要件 | =0 替代解释 |
|------|------|---------|------------|
| DEPRESSIVE_EPISODE_HISTORY | 重性抑郁发作存在性 | 叙事含 ≥1 次完整 MDE：≥2 周持续低落/快感缺失 + 功能变化（作息/兴趣/社交），无竞争解释 | 低落被物质/处境/哀伤解释（陈国强）；亚阈值情绪波动 |
| MANIA_HISTORY | 躁狂发作存在性 | 完整躁狂：≥1 周心境高涨/易激惹 + 精力↑ + 功能损害 ∨ 住院 ∨ 精神病性特征（非并列必备） | 创业高光/时代红利可解释的"亢奋期"（顾维扬 HYPOMANIA 教训）；药物/物质所致 |
| HYPOMANIA_HISTORY | 轻躁狂发作存在性 | 完整轻躁狂：≥4 天心境/精力改变 + 相对基线明确改变，无显著功能损害 | 缺"明确异常心境/相对基线改变/完整发作持续性"三样 → =0（顾维扬回放） |
| CYCLIC_MOOD_HISTORY | 反复亚阈值心境波动病程模式 | 叙事显示多年反复两相波动（非发作级）的病程模式声明 | 单相持续低落（→PDD 语义）；时期计数不可代模式 |
| SUBSTANCE_USE_HISTORY | 持续/反复物质使用行为存在性 | 叙事含实际使用行为（种类/频率的临床判定在声明侧），非单次 | 社交饮酒未达"持续使用"；使用由处方/医疗驱动 |

### B. 人格模式类（BPD/ASPD/分裂型——持久模式单原子，组合判定留声明侧）

| 原子 | 语义 | =1 要件 | =0 替代解释 |
|------|------|---------|------------|
| BPD_PATTERN_HISTORY | BPD 式持久人格模式（人际两极化/情绪反应性/冲动自损/身份紊乱/空虚多域） | 叙事显示成年早期起、跨情境的多域持久模式（≥5/9 判定声明侧完成） | 应激性短暂波动（→BPD 反样本）；发作性心境障碍可解释（双相/MDD 优先分流）；物质所致 |
| ASPD_PATTERN_HISTORY | ≥18 岁起漠视/侵犯他人权利行为模式（≥3/7 声明侧判定） | 叙事显示持续反社会行为模式（违法/欺骗/攻击/鲁莽/不负责任/无悔意多域） | 环境性/团伙语境（文化规范）；SUD 犯罪；仅躁狂/精分期间行为（Criterion D） |
| CONDUCT_DISORDER_HISTORY | 15 岁前品行障碍存在性（独立史实原子） | 叙事显示 <15 岁起品行障碍级行为（声明侧判定 15 岁边界） | 青少年限局型反社会（adolescence-limited）；成人后起始 |
| STPD_PATTERN_HISTORY | 分裂型人格模式（认知-知觉扭曲 + 社交缺陷/古怪） | 叙事显示认知/知觉异常模式（牵连/魔幻思维/知觉体验/多疑/古怪言语，≥5/9 声明侧）+ 社交疏离，文化限定内 | 文化/宗教规范信念；应激性短暂偏执（BPD C9）；SZ 前驱（有发作史则归 SZ 轨）；ASD（发育轨） |

### C. 病程模式类（PDD/GAD/拖延 + SSD 时长——慢性模式单原子）

| 原子 | 语义 | =1 要件 | =0 替代解释 |
|------|------|---------|------------|
| PDD_PERSISTENT_DEPRESSION_PATTERN | ≥2 年持续低落病程模式 | 叙事显示 ≥2 年多数日子低落（无 >2 月无症状期）——排除躁狂/轻躁狂/环性史（排除原子硬门） | 发作-缓解型（有 DEPRESSIVE 但无慢性模式 → MDD 轨）；哀伤/PGD 对象性；物质/躯体所致 |
| GAD_WORRY_PATTERN_HISTORY | 慢性多域过度担忧模式（≥6 月） | 叙事显示 ≥6 月多生活域难控担忧 + 躯体伴随 | 担忧仅见于 MDD 发作期（F 条 → MDD 轨）；单一主题健康焦虑（→疾病焦虑语义）；OCD 侵入观念（无中和结构差异见 OCD） |
| PROCRASTINATION_PATTERN_HISTORY | 慢性非情境性任务回避-延迟模式（含损害/痛苦） | 叙事显示跨情境长期任务回避 + 明确功能损害/痛苦（努力折扣机制叙事） | 情境性拖延（截止日前）；ADHD 发育轨（12 岁前跨情境注意结构）；MDD 抑郁相迟滞（→DEPRESSIVE 分流）；倦怠（工作绑定）；完美主义回避（OCPD 语义） |
| SYMPTOM_DURATION_6M | 躯体症状持续 ≥6 月事实 | 叙事显示症状持续 ≥6 月（SSD 用，声明侧完成时长判定） | —（时长否定即 =0） |

### D. 行为史类（进食族 6 域原子 + SZ/焦虑/OCD 模式 + SSD 症状/投入）

| 原子 | 语义 | =1 要件 | =0 替代解释 |
|------|------|---------|------------|
| SOMATIC_SYMPTOM_HISTORY | 持续躯体症状存在性 | 叙事含持续躯体症状（部位/痛苦临床判定声明侧） | 症状可完全由器质解释且无过度投入 → 仍可 =1（DSM-5 允许共病）但须 OVERINVESTMENT 判定 |
| SYMPTOM_PSYCHOLOGICAL_OVERINVESTMENT | 与症状相关的心理过度投入 | 不相称持续想法/持续高焦虑/过度时间精力（SSD 与躯体疾病区分键） | 关注与症状相称（正常慢病患者）；伪装/造作（故意）→ 声明侧排除 |
| BINGE_HISTORY | 失控性暴食发作史（量大+失控感两成分） | 叙事含反复失控暴食（客观量大 + 主观失控感）——频率判定声明侧 | 无失控感的过量进食（大食者/肥胖）；MDD 非典型/双相发作内暴食（→发作史轨）；SRED 无意识进食 |
| COMPENSATORY_BEHAVIOR_HISTORY | 为防增重的补偿行为史（域级：催吐/泻药/禁食/过度运动） | 叙事含为防增重的补偿行为（域级判定，非清除级） | 躯体性呕吐/反刍（无防增重动机）；竞技减重（表现目的）；表演性催吐 |
| LOW_WEIGHT_PATTERN | 显著低体重模式/史 | 相对年龄/性别/发育轨迹的显著低体重（AN 判别键；BMI 数值判定声明侧） | 躯体疾病/甲状腺/消化道/ARFID（无怕胖/体像）；运动员表现型（无怕胖心理结构）；环境性食物不可得 |
| WEIGHT_GAIN_PREVENTION | 怕增重/防增重行为 | 低体重前提下怕胖恐惧 ∨ 持久防增重行为（AN B，二选判定声明侧） | 正常体重关注/健康饮食 |

| SZAFFECTIVE_COURSE_HISTORY | 分裂情感病程（心境+独立精神病性） | 心境发作与精神病性并发 + 心境外独立 ≥2 周 + 心境占多数 + 不间断疾病期（全声明侧） | BD-I 伴精神病性（无心境外独立精神病性结构）；SZ+MDD 共病（心境少数/残留期）；亚阈值心境波动（非发作） |
| OCD_PATTERN_HISTORY | 侵入观念/强迫行为临床模式 | 侵入不想要的观念（含中和冲动）与/或强迫行为 + 耗时/损害（or both 析取；声明侧判定） | GAD 担忧（较自我协调、无中和结构——不靠内容区分，靠侵入性+失谐性+中和）；MDD 反刍（自我一致）；ASPD/BDD/囤积/拔毛（无观念-中和结构）；ASD 仪式（发育轨）；正常侵入想法（无模式无耗时损害） |

### E. 身份结构类（DID）

| 原子 | 语义 | =1 要件 | =0 替代解释 |
|------|------|---------|------------|
| IDENTITY_STATE_HISTORY | ≥2 人格状态/自我感断裂存在性 | 叙事显示身份结构（≥2 人格状态/自我感-自主感断裂）——与 D_seg≥0.85（#90 访问层区隔标记）双成分 | 解离性遗忘（DA，无身份结构 → 无项目槽）；PTSD 解离亚型（无 ≥2 状态）；OSDD 样（身份结构但无区隔 → D_seg 门拦，无主病语义正确）；诈病/表演（行为证据/目击侧纪律）；文化附体（Criterion D 排除） |

### F. 表征签名说明（PTSD——唯一 E_d^mem 资格）

PTSD 不走声明原子，走记忆表征签名（校验器实现）：`∃m: event_type ∈ {威胁/暴力, 性创伤} ∧ F ≥ 0.80 ∧ N ≤ 0.40`（θ [NEW 初值可调]）。F/N 由 #90 记忆层表征字段提供（非 #87 声明）。急性应激（<1 月）病程区分 → 呈现层（延迟项）。

## 三、回放门最小流程（起草后必做）

1. 起草叙事完成 → 起草者按 §二 填全部相关原子（目标病必要原子 + 同候选集交叉原子）→ 每原子附依据（叙事段引用）；
2. 运行 `python3 code/tools/validate_eligibility.py patient.json` → 目标病须 ELIGIBLE；
3. 若 INELIGIBLE：查依据（必要原子 =0 / 排除原子 =1 的具体叙事冲突）→ 修叙事（不修声明凑数——防污染铁律）或改目标 slot；
4. 若 UNDETERMINED：补资料或按 MISSING 语义接受（MISSING ≠ FALSE，不强行判定）；
5. 用户审阅（外审/回放纪律，#89 惯例）。
