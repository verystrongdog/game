# 技能点经济

> 技能点获取、分配、重置的数值模型。目标：单局游戏无法全解锁（必须选择路线），解锁曲线前快后慢（早期有成就感，后期有取舍压力）。

## 一、技能点获取

### 1.1 获取来源

| 来源 | 点数 | 频率 | 说明 |
|------|------|------|------|
| 普通战斗胜利 | +1 | 每场 | 遭遇战/小怪战 |
| Boss 战胜利 | +2~3 | 每章末 | 根据 Boss 难度浮动 |
| 关键叙事节点 | +1~2 | 每章 2-3 次 | 治疗会话、角色抉择、镜子房间重大发现 |
| 支线完成 | +1 | 可选 | 探索/帮助 NPC/发现隐藏内容 |

### 1.2 单局总获取量估算

```
假设:
  - 单局游戏 3 章
  - 每章: 4 场普通战斗 + 1 场 Boss + 2 个叙事节点
  - 额外: 2 个支线

单局总获取:
  3 × (4×1 + 2 + 2×1) + 2
  = 3 × 8 + 2
  = 26 点

浮动范围: 20~35 点（取决于探索度和难度）
```

### 1.3 设计目标

- 总需求：~200 技能点（全部 73 个节点全部解锁所需）
- 总获取：~26 点（单局可获得量）
- **解锁比例：约 13%**——选择哪个 13% 是构筑的核心

## 二、解锁成本

### 2.1 按层级

| 层级 | 每节点成本 | 该层节点数 | 该层总成本 |
|------|----------|----------|----------|
| L1 | 1 | 11 (5+3+3) | 11 |
| L2 | 2 | 14 (5+3+6) | 28 |
| L3 | 3 | 16 (5+4+6) | 48 |
| L4 | 5 | 16 (5+4+6) | 80 |
| L5 | 8 | 4 (5-1+1+?) 实际终极技能另外算 | ~32 |
| 终极 | 10 | 12 | 120 |

> 注：技能树精确节点数待所有 JSON 映射完成后确认。当前为估算。

### 2.2 解锁策略示例

**策略 A：广撒网（多功能基础）**
```
投入: 26 点
解锁: 10 个 L1 (10pt) + 5 个 L2 (10pt) + 2 个 L3 (6pt)
结果: 17 个技能，覆盖面广，但没有高阶技能
适合: 新手玩家 / 探索型玩家
```

**策略 B：专注单一路线（深度专精）**
```
投入: 26 点
解锁: 3 个 L1 (3pt) + 2 个 L2 (4pt) + 1 个 L3 (3pt) + 1 个 L4 (5pt) + 1 个 L5 (8pt)
      + 额外 3pt 散布
结果: ~10 个技能，但有 1 条完整的 L1-L5 路线
适合: 有明确 build 思路的玩家
```

**策略 C：终极技能 rush**
```
投入: 26 点
解锁: 按终极技能的最少前置路径→点亮 1-2 个终极技能
  前置: 认知 ×2 (L4+L5 = 5+8=13) + 情绪 ×1 (L4 = 5) + 行为 ×1 (L4 = 5) = 23
  + 终极技能本身 10pt = 33（略超预算，需要放弃一些旁支或靠叙事节点额外点数）
适合: 追求高光时刻的玩家
```

## 三、解锁曲线模拟

### 3.1 预期解锁进度

| 战斗场数 | 累计点数 | 预期解锁节点数 | 预期最高层级 |
|---------|---------|-------------|------------|
| 0 (开局) | 3 | 3 个 L1 | L1 |
| 3 | 6 | 4 个 L1 + 1 个 L2 | L2 |
| 5 | 8 | 4L1 + 2L2 | L2 |
| 8 | 12 | 4L1 + 3L2 + 1L3 | L3 |
| 12 | 17 | 混合 L1-L3 | L3 |
| 15 (第一章Boss) | 20 | 混合 L1-L4 | L4 |
| 20 | 24 | 混合 L1-L4 + 可能 1 终极 | L4/终极 |
| 25 (终章) | 28 | 最终 build | L5/终极 |

### 3.2 曲线特征

- **前 5 场战斗**：快速解锁期（每场 1 点 = 解锁 1 个 L1）
- **第 5-10 场**：开始面临选择（L2 要 2 点——是深钻还是铺开？）
- **第 10-15 场**：核心 build 成型（L3-L4 开始解锁）
- **第 15 场后**：精细化调整（解锁终极技能或补被动）

## 四、路线选择空间

### 4.1 三种典型 build

**"看清一切"——认知专精**
```
主打: 认知 L5 全解锁 (1+2+3+5+8=19pt)
辅修: 情绪 L1 (平静) + 行为 L1 (反射)
打法: 每回合先开认知技能（揭示/预判/命名），然后用反射基础技输出
```

**"血脉偾张"——情绪爆发**
```
主打: 情绪 L5 (恐怖)
辅修: 认知 L2-L3（归因、甄别）+ 行为 L3（价值）
打法: 累积恐怖 PAD → 硬解锁价值技能 → 终极技"赴汤蹈火"
```

**"顺水推舟"——S1 主导**
```
主打: 行为反射 L1 + 惩罚 L2 + 文化习俗 L3
辅修: 情绪 L1-L2 (恐惧、愤怒) + 少量认知 L1-L2
打法: 顺着情绪走——恐惧时逃、愤怒时打、平静时运用仪式
      低 AP 消耗、低意志力需求——不硬撑的"顺势而为"流派
```

### 4.2 路线互斥性

关键设计：**不是所有路线都兼容。** 选了认知专精就很难同时选情绪 L5。选择了恐怖路线就锁死了部分冷静路线的选项（恐怖学习中会用到的绝望前置与希望/爱/共情的 PAD 位置相距甚远）。

## 五、重置机制

### 5.1 重置条件

- 在技能树界面中可随时重置
- 成本：消耗当前 SAN 的 50%
- 限制：同一次安全场景中只能重置 1 次

### 5.2 重置行为

- 所有已解锁节点变回未解锁
- 已消耗的技能点**全额返还**
- 快捷槽配置清空（需要重新编排）
- 树的视觉回到初始状态

### 5.3 设计意图

- 允许玩家实验不同 build
- 代价足够高（50% SAN）让重置是"决策"而非"随便改"
- 低 SAN 时重置代价反而小（50% of 10 = 5），高 SAN 时重置代价大（50% of 50 = 25）——鼓励在安全空间尝试而非在高压下乱改

## 六、参数速查

| 参数 | 值 | 说明 |
|------|-----|------|
| 普通战斗点数 | 1 | 每场 |
| Boss 战点数 | 2-3 | 每章末 |
| 叙事节点点数 | 1-2 | 每章 2-3 次 |
| 单局总获取 | ~26 | 20-35 浮动 |
| L1 成本 | 1 pt | 11 个节点 |
| L2 成本 | 2 pt | 14 个节点 |
| L3 成本 | 3 pt | 16 个节点 |
| L4 成本 | 5 pt | 16 个节点 |
| L5 成本 | 8 pt | 4 个节点（不含终极） |
| 终极技能成本 | 10 pt | 12 个节点 |
| 全部解锁需求 | ~200 pt | 73 个节点 |
| 解锁比例 | ~13% | 单局可解锁 / 总需求 |
| 重置成本 | SAN 的 50% | 全额返还点数 |
