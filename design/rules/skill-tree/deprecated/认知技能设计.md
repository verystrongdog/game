## 二、L1 知觉与注意

> CPM Step 1 (Relevance) 的核心模块。认知的"入口层"——角色先看到、注意到什么。

### 洞见（被动）

```
认知层:
  module: 知觉与注意
  d_prime: +0.2（基线偏移，不影响主动技能）
  criterion: 0
  processing_depth: 0.3（System 1）
  cpm_step: 1

被动效果: 永久提升知觉精度 d'_知觉 +0.2
解锁成本: 1 技能点
```

### 察微（被动）

```
被动效果: criterion_知觉 -0.2（更宽松——更容易报告"有变化"）
解锁成本: 1 技能点
```

### 纵观（主动）

```
认知层:
  module: 知觉与注意
  d_prime: +0.5
  criterion: +0.3（偏保守——降低假阳性）
  processing_depth: 0.5

主动效果: 揭示敌方 1 个隐藏属性。冷却 2 回合。AP: 0。
解锁成本: 1 技能点
```

### 警觉（被动）

```
被动效果: 进入战斗时自动获得 1 层"警觉"标记。
  警觉标记: 下一次"纵观"技能效果翻倍，消耗标记。
解锁成本: 1 技能点
```

### 凝神（主动）

```
主动效果: 强制锁定一个敌方目标。对该目标的后续认知效果 +30%。
  持续 2 回合。冷却 3 回合。AP: 0。
解锁成本: 1 技能点
```

## 三、L2 记忆

> CPM Step 2 (Implications) 的支撑模块。记忆不是主引擎，但每一步都需要记忆提供基线数据。

### 拾遗（主动）

```
主动效果: 减少随机一个冷却中的技能冷却 1 回合。
  冷却 2 回合。AP: 0。
解锁成本: 2 技能点
前置: 知觉与注意 L1（任意 1 个节点）
```

### 追忆（主动）

```
主动效果: 复制上一回合自身或敌方打出的一个技能效果（×0.7）。
  冷却 3 回合。AP: 1。
解锁成本: 2 技能点
```

### 闪回（被动）

```
被动效果: 角色 SAN < 40% 时，随机触发一次"恐惧"情绪偏移（PAD 偏移量 ×0.5）。
  每场战斗最多触发 2 次。不可控制。
解锁成本: 2 技能点
```

### 铭刻（被动）

```
被动效果: 战斗中首次成功使用某个主动技能时，该技能本场战斗后续使用效果 +10%。
解锁成本: 2 技能点
```

### 释怀（主动）

```
主动效果: 移除自身 1 个负面认知标签（"威胁""罪责""污染"等）。
  冷却 4 回合。AP: 0。
解锁成本: 2 技能点
```

## 四、L3 知识表征与分类

> CPM Step 1 & 4 的双重角色——最初归类"这是什么"，最后判定"这对不对"。

### 甄别（主动）

```
主动效果: 改变一个目标的一个标签（将"威胁"改为"中立"，或将"友方"改为"可疑"）。
  冷却 3 回合。AP: 0。
解锁成本: 3 技能点
前置: 记忆 L2（任意 1 个节点）
```

### 归因（主动）

```
主动效果: 揭示敌方当前行为的驱动归属（显示"该技能属于 XX 驱动"）。
  并标记该驱动——后续对该驱动行为的反制效果 +25%。冷却 3 回合。AP: 0。
解锁成本: 3 技能点
```

### 类比（被动）

```
被动效果: 角色遇到已有标签的同类敌人时，认知效果自动 +15%。
  （"你见过这种东西。你知道它是什么。"）
解锁成本: 3 技能点
```

### 定性（主动）

```
主动效果: 为敌方施加一个"定性"标记（如"施暴者""受困者""骗子""守护者"）。
  该标记影响敌方的 AI 策略倾向。持续 3 回合。冷却 4 回合。AP: 0。
解锁成本: 3 技能点
```

### 正名（主动）

```
主动效果: 移除自身或友方 1 个负面标签 + 替换为 1 个正面标签。
  "你不叫怪物。你叫幸存者。"
  冷却 5 回合。AP: 0。
解锁成本: 3 技能点
```

## 五、L4 表象与语言

> CPM Step 3 (Adjustment) 和 Step 4 (Normative) 的核心模块。命名赋予现实性——月光下尤为关键。

### 转述（主动）

```
主动效果: 重新描述当前战斗情境——改变敌方的心理框架。
  敌方下一个技能的 PAD 偏移方向被反转（V 符号翻转）。
  冷却 6 回合。AP: 0。
解锁成本: 5 技能点
前置: 知识表征 L3（任意 1 个节点）
```

### 白描（主动）

```
主动效果: 清除战场上所有幻象/伪装/假象效果。
  "月亮底下，没有东西能永远伪装。"
  冷却 5 回合。AP: 0。
解锁成本: 5 技能点
```

### 构想（被动）

```
被动效果: 每回合开始时，角色可以选择本回合的行为"看起来像"另一个驱动。
  （例：实际是"恐惧+逃跑(反射)"，但对外表现为"冷静撤退(文化)"。）
  不改变实际态度结算——只改变敌方对你的判定。
解锁成本: 5 技能点
```

### 隐喻（被动）

```
被动效果: 角色打出的技能附带"隐喻"标签时，对敌人的 PAD 偏移额外 +15%。
  "这不只是一拳——这是你欠我的。"
解锁成本: 5 技能点
```

### 命名（主动）

```
主动效果: 为一个未命名的现象/敌人/状态命名。命名后：
  - 该实体获得一个永久标签
  - 角色对该实体的所有效果 +30%
  - 该实体在观察者效应下变得更"稳定"（不再享受量子叠加的保护）
  每场战斗最多 1 次。冷却: 无需冷却但限一次。AP: 2。
解锁成本: 5 技能点
```

## 六、L5 推理与决策

> CPM Step 2 & 3 的核心模块。因果推断、概率估计、控制感评估。

### 预判（主动）

```
主动效果: 预览敌方下一个回合将要使用的技能。
  "我已经看到了。你准备好的那招。"
  冷却 4 回合。AP: 0。
解锁成本: 8 技能点
前置: 表象与语言 L4（任意 1 个节点）
```

### 筹算（被动）

```
被动效果: 所有技能的 AP 消耗 -1（最小为 1）。
  仅对 AP ≥ 2 的技能生效。
解锁成本: 8 技能点
```

### 推演（主动）

```
主动效果: 模拟本回合的两种不同行动→选择更优路径。
  实际效果: 本回合可以使用 2 个非行为型主动技能（而不是 1 个）。
  冷却 6 回合。AP: 1。
解锁成本: 8 技能点
```

### 权衡（主动）

```
主动效果: 牺牲本回合的行为输出→下一回合所有效果 ×1.5。
  "有时候不做，比做更困难。"
  冷却 5 回合。AP: 0。
解锁成本: 8 技能点
```

### 决意（被动）

```
被动效果: 角色 HP < 30% 时，所有主动技能的冷却 -1 回合。
  "人在绝境中想得最快。"
解锁成本: 8 技能点
```
