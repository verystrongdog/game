## 一、架构概览

技能 = 逻辑引擎 + 交互外壳。

```
┌──────────────────────────────────────┐
│         3D 技能树界面 (独立)          │
│  认知分支 / 情绪分支 / 行为分支       │
│  玩家在此解锁、浏览、编排技能          │
└──────────────┬───────────────────────┘
               │ 点亮技能 → 可带入战斗
               ▼
┌──────────────────────────────────────┐
│        战斗中的技能选择               │
│                                      │
│  玩家: 快捷槽选 1 技能                 │
│  NPC:  AI 从自身已解锁技能池中选 1 技能  │
│                                      │
│  每个技能内部封装:                     │
│    认知层 (d', criterion, 模块归属)     │
│    情绪层 (PAD 偏移)                   │
│    行为层 (驱动归属, valence, AP)       │
└──────────────┬───────────────────────┘
               │
               ▼
┌──────────────────────────────────────┐
│     态度结算引擎 (共享，不变)           │
│                                      │
│  PAD → 驱动激活 (sigmoid)             │
│  CPM 4 步评估序列                     │
│  7 步态度结算链路                      │
│  硬解锁 / EVC / 意志力                │
│  态度碰撞                             │
│  SAN / HP 更新                        │
└──────────────────────────────────────┘
```

**核心原则：**
- 态度结算引擎 = 技能的计算核心，玩家和 NPC 共用，与卡牌版一致。
- 卡牌层彻底移除。技能内部封装认知/情绪/行为参数，引擎照常运转。
- "认知+情绪+行为=态度"链路完整保留——玩家不再手动组合三张卡，而是激活一个内部封装了三层的技能。

## 二、技能树拓扑结构 — 大脑形态

### 2.1 整体形态：玻璃大脑

技能树呈现为一个半透明的"玻璃大脑"，悬浮在虚空中。**态度模型的 3D 空间 (valence × intensity × autonomy) 是技能树的底层坐标系**——每个技能节点放在其对应脑区的解剖位置，三个轴直接映射到大脑解剖轴：

| 态度轴 | 大脑轴 | 解剖含义 |
|--------|--------|---------|
| X = Valence (效价) | 左右 | 左半球 = 回避/负面，右半球 = 趋近/正面 |
| Y = Intensity (强度) | 上下 | 底部 = 脑干/基础反射，顶部 = 皮层/复杂加工 |
| Z = Autonomy (自主性) | 前后 | 后部 = 被动/感官，前部 = 主动控制/执行功能 |

```
                     前额叶极 (终极技能)
                    ┌─────────────────┐
                   /  dlPFC  vmPFC     \
                  /   推理   价值/道德   \
                 /                      \
      认知      /    Broca  Wernicke     \     行为
    (皮层后→前) |     语言   知识表征      |   (脑干→前额叶)
                |                        |
      枕叶/顶叶  |     岛叶    ACC        |    NAcc/VTA
      知觉/注意  |     复合情绪           |    奖励/惩罚
                |                        |
                 \    杏仁核  海马体     /
                  \   核心情绪  记忆    /
                   \                  /
                    \   脑干 (PAG)   /
                     \   反射驱动  /
                      └──────────┘
                      小脑 (后下方)
```

- 大脑主体 = 两个半椭球体（左右半球），中间纵裂间隙
- 底部 = 脑干锥体（反射驱动所在），后下方 = 小脑椭球
- 越靠近前额叶顶部（前上方）→ 技能层级越高、越贵
- **颜色仅用于 UI 区分分支**：认知蓝紫、情绪暖橙、行为青蓝、终极金色
- **节点不是挂在树上的果实，而是脑内的发光点——解锁 = 点亮脑区**

### 2.2 认知分支：后→前皮层梯度（5 模块）

认知 5 模块沿大脑皮层后→前轴排列，对应信息加工从感觉到推理的层级。越往前（前额叶）→ 层级越高：

```
认知分支 (后→前)
  后部 (Z<0)                         前部 (Z>0)
  ═══════════════════════════════════════════════
  L1 知觉与注意    L2 记忆      L3 知识表征   L4 表象与语言   L5 推理与决策
  枕叶/顶叶       颞叶/海马    TPJ/颞下回    Wernicke/Broca  前额叶
  洞见/察微/纵观   拾遗/追忆    甄别/归因     转述/白描       预判/筹算
  警觉/凝神       闪回/铭刻    类比/定性     构想/隐喻       推演/权衡
                  释怀         正名          命名            决意
```

25 个节点，从 25 张认知卡映射。CPM 的"先看到→再判断→再推演→最后命名"在脑区后→前梯度上物理化。

### 2.3 情绪分支：深→浅边缘系统梯度（15 节点）

情绪沿脑深部→皮层表面排列。**Z 轴 = 情绪层级，X 轴 = PAD Valence，Y 轴 = PAD Intensity。A 轴（唤醒度）编码为节点发光强度**（A 高 = 亮，A 低 = 暗）。

```
情绪分支 (深→浅, 脑干→皮层)
  Y=0.88 (L5):              恐怖 (杏仁核-mPFC耦合)
  Y=0.70 (L4):  绝望  内疚  敬畏  孤独  (OFC/mPFC/颞极)
  Y=0.50 (L3):  共情   爱   焦虑  厌恶  (前脑岛/ACC)
  Y=0.28 (L2):  希望  愤怒  悲痛       (NAcc/BNST/腹侧纹状体)
  Y=0.10 (L1):  快乐  恐惧  平静       (杏仁核/下丘脑/PAG)
                  ↑                  ↑
             P+ (X>0, 趋近)    P- (X<0, 回避)
```

15 个节点全部是**被动型**——学会后永久扩展角色的可用 PAD 状态范围。详细设计见 [大脑形态技能树-设计](./大脑形态技能树-设计.md)。

### 2.4 行为分支：底→顶动作系统梯度（7 驱动）

行为沿脑干→前额叶的"控制梯度"排列。底部 = S1 快速反射（无需认知），顶部 = S2 高阶控制（需要全部认知模块）。

```
行为分支 (底→顶, 脑干→前额叶)
  Y=0.90 (L4 S2王牌): 价值驱动 — 牺牲/对抗/突破   (ACC+额顶控制网络)
  Y=0.85 (L4):        照护     — 安抚/保护/舍身   (前脑岛+ACC+VTA)
  Y=0.60 (L3 S2慢速): 道德驱动 — 自责/维护/坚守   (vmPFC+TPJ)
  Y=0.55 (L3):        文化习俗 — 遵从/从众/运用仪式 (mPFC+后扣带)
  Y=0.35 (L2 S1中速): 奖励机制 — 试探/追求/坚持   (NAcc+VTA)
  Y=0.30 (L2):        惩罚机制 — 回避/妥协/克制   (基底节+杏仁核)
  Y=0.08 (L1 S1快速): 反射     — 逃跑/僵住/闪避   (PAG+脑干)
```

21 个节点，从 21 张行为卡映射。底部（反射）不需要认知前置，顶部（价值/照护）需要认知 L5 解锁后才能使用。

### 2.5 跨分支前置关系

高级行为技能需要对应认知层级的节点已解锁：

| 行为层级 | 需要的认知前置 |
|---------|-------------|
| L1 反射 | 无（不需要认知前置）|
| L2 惩罚/奖励 | 认知 L2 记忆至少 1 个节点已解锁 |
| L3 道德/文化习俗 | 认知 L3 知识表征至少 1 个节点已解锁 |
| L4 价值/照护 | 认知 L5 推理至少 1 个节点已解锁 |

## 三、技能内部封装

### 3.1 三层封装模型

每个技能内部封装三个参数层：

```
技能 {
  id: "against_the_current"
  name: "逆流而上"
  display: {
    description: "心灵震慑 8 +意志力+1"
    flavor: "你看清了，你感受到了恐惧，你没有逃。"
    ap: 3
    cooldown: 5
  }
  
  // === 认知层 ===
  cognition: {
    module: "推理与决策"        // 5 模块之一
    d_prime: 0.8               // SDT 精度
    criterion: -0.3            // SDT 判断偏向
    processing_depth: 0.9      // System 2 深度 (0~1)
    cpm_step: 4                // 在 CPM 哪一步激活
    effect: "揭示威胁 + 框架压制"  // 认知层的具体效果
  }
  
  // === 情绪层 ===
  emotion: {
    pad_anchor: "fear"         // 15 个 NRC VAD 锚点之一
    pad_offset: { V: -0.85, A: 0.68, D: -0.41 }  // PAD 偏移量
    intensity: 0.9             // 情绪冲击强度 (0~1)
  }
  
  // === 行为层 ===
  behavior: {
    drive: "价值"               // 7 驱动之一
    valence: 1                  // 行为方向 (-1/0/+1)
    base_ap: 3                  // 基础 AP 消耗
    base_effect: 8              // 基础效果值 (心灵震慑)
    hard_unlock: true           // 是否需要硬解锁
    c_control: 3.8              // 控制成本 (查表)
  }
}
```

### 3.2 技能激活流程

```
玩家点击技能 "逆流而上"
  ↓
① 认知层: 设定本回合认知框架
   d'=0.8, criterion=-0.3 → z_推理 = 0.8 - 0.3i
  ↓
② 情绪层: 推送 PAD 偏移
   V=-0.85, A=0.68, D=-0.41 → 叠加到当前 PAD 状态
  ↓
③ 行为层: 计算驱动激活
   g_value = σ(1.5·max(0,D-0.4) + 3.0·Override_signal - 0.7)
  ↓
④ 硬解锁判定 (C_control=3.8)
   EVC = benefit - C_control - effort_discount + ε
   通过 → 消耗 3 AP + SAN 磨损
  ↓
⑤ B(t) = λ_raw·B_raw + λ_drive·B_drive
  ↓
⑥ 态度碰撞 → 心灵震慑 8 + 意志力+1
```

### 3.3 技能的数据来源

所有技能参数从现有 JSON 数据文件映射：

| 参数来源 | JSON 文件 | 字段 |
|---------|----------|------|
| 认知层 d'/criterion/模块 | `data/cognition_cards.json` | cards[].cognitive_quality, cards[].module |
| 情绪层 PAD 偏移 | `data/emotion_cards.json` | cards[].pad, cards[].play_effect.pad_offset |
| 行为层 驱动/valence/AP | `data/behavior_cards.json` | cards[].drive, cards[].valence, cards[].base_ap |
| C_control 查表 | `data/drives.json` + `态度系统/态度系统.md` | 情绪×驱动控制成本表 |
| 态度效果 | `data/attitudes.json` | attitudes[].game_effect |

## 四、技能分类

### 4.1 三类技能

| 类型 | 占比 | 说明 | 认知/情绪/行为分支分布 |
|------|------|------|---------------------|
| **主动技能** | ~70% | 每回合可选激活，消耗 AP，有冷却 | 主要是行为分支（21 个），少量认知分支主动技 |
| **被动技能** | ~25% | 学会后始终生效，修改角色基线参数 | 主要是认知分支和情绪分支（~30 个） |
| **终极技能** | ~5% | 需要跨分支前置，大效果长冷却 | 树顶交汇处（~12 个，详见 [终极技能设计](./终极技能设计.md)） |

### 4.2 被动技能的效果类型

| 效果 | 来源分支 | 示例 |
|------|---------|------|
| 修改认知基线 d' | 认知 | 洞见: d'_知觉 +0.2 |
| 修改认知 criterion | 认知 | 正名: criterion_表象 -0.3（更宽松） |
| 扩展 PAD 可用范围 | 情绪 | 学会恐惧: 可在技能中使用恐惧的 PAD 偏移 |
| 修改 PAD 衰减率 | 情绪 | 平静: δ_PAD × 0.8 |
| 降低驱动 θ_play | 行为 | 坚守: θ_道德 -0.1 |
| 回复资源 | 行为 | 克制: 每回合意志力 +0.5 |

### 4.3 终极技能

终极技能需要同时满足认知+情绪+行为三个分支的高层前置（见 [终极技能设计](./终极技能设计.md)）。它们是旧系统中"特殊态度"的映射——如"逆流而上"（恐惧+价值硬解锁）。

## 五、资源系统

与旧系统完全一致，数值参数不变：

| 资源 | 运作方式 |
|------|---------|
| **AP** | 每回合回复至上限（默认 6）。主动技能消耗不同 AP。认知型/情绪型被动技能不消耗 AP。 |
| **SAN** | 硬解锁技能消耗 SAN。态度碰撞消耗 SAN。低 SAN 时所有技能冷却 +1 回合，效果 ×0.8。 |
| **意志力** | 技能被压制时（敌人 debuff）消耗意志力强行激活。部分技能被动回复意志力（克制/坚守）。 |
| **HP** | 归零战败。 |

参数速查：

| 参数 | 符号 | 默认值 | 位置 |
|------|------|--------|------|
| 每回合 AP 上限 | AP_max | 6 | §五 |
| 硬解锁 SAN 磨损 | — | max(0, C_control − 1.5) | 态度系统/态度系统.md §⑤ |
| 意志力基础池 | — | 3 | 行为系统/行为系统.md §十三 |

## 六、快捷槽与构筑

### 6.1 快捷槽

- **6 个快捷槽**——在技能树界面中从已解锁的技能中拖拽编排
- 战斗中只能使用快捷槽中的技能
- 战斗间隙可打开技能树界面更换配置
- 快捷槽编排 = 战前策略选择，取代卡牌版的抽牌随机性

### 6.2 构筑限制

- 6 个槽中至少需要包含：至少 1 个认知型技能 + 至少 1 个行为型技能
- 情绪型技能不强制——玩家可以选择不带情绪技能（等价于旧系统的"执行"组合），但行为技能成本会偏高
- 无上限限制类型配比（可全带行为技能，但缺少认知框架的效果加成）

## 七、技能点经济

| 机制 | 数值 |
|------|------|
| 获取方式 | 战斗胜利、叙事事件、角色剧情节点 |
| 每场普通战斗 | 1 点 |
| Boss 战 | 2-3 点 |
| 解锁成本 | L1=1pt, L2=2pt, L3=3pt, L4=5pt, L5=8pt |
| 同子枝前置 | 需解锁至少 1 个 L(n-1) 节点才能解锁 Ln |
| 跨分支前置 | 高级行为技能需要对应认知层级已解锁（见 §2.5） |
| 重置 | 技能树界面中可重置（消耗当前 SAN 的 50%） |
| 总获取量 vs 总需求 | ~40 点可获取 vs ~200 点总需求——必须选择路线 |

## 八、3D 可视化设计原则

详见 [3D可视化设计规范](../../../%E5%91%88%E7%8E%B0/3D%E5%8F%AF%E8%A7%86%E5%8C%96/3D%E5%8F%AF%E8%A7%86%E5%8C%96%E8%AE%BE%E8%AE%A1%E8%A7%84%E8%8C%83.md)。核心原则：

1. **空间关系 = 设计关系**：物理距离近的节点在概念上也近
2. **未解锁可见但灰色**：全景可见，知道"有什么可学的"
3. **颜色仅用于 UI 区分分支**：不使用颜色表示态度/情绪语义
4. **可旋转、可缩放**：拖动旋转视角，滚轮缩放
5. **冷却可视化**：冷却中的节点半透明 + 沙漏粒子

节点状态速查：

| 状态 | 视觉 |
|------|------|
| 未解锁 | 灰色半透明，轮廓可见 |
| 可解锁（有足够点数）| 闪烁微光 + 轻微脉动 |
| 已解锁 | 发光，颜色饱满，缓慢脉动 |
| 冷却中 | 半透明覆盖层 + 旋转沙漏粒子 |
| 终极技能 | 大尺寸，多棱面晶体，粒子环绕 |

## 九、与战斗系统的对接

### 9.1 回合流程

```
旧 (卡牌版):
  抽牌 6 张 → 审查手牌 13 张 → 选认知卡 → 选情绪卡 → 选行为卡 → 组合检测 → 确认 → 结算

新 (技能版):
  检查快捷槽 6 个 → 点击 1 个技能 → 结算
```

技能内部自动完成认知+情绪+行为的组合，玩家不需要理解组合规则。

### 9.2 敌我交互：Debuff 替代塞牌

| 旧机制（塞卡牌）| 新机制（Debuff）|
|---------------|---------------|
| 敌人塞情绪卡"恐惧" | "恐惧污染"——恐惧相关技能增强，其他情绪被动被压制 |
| 敌人塞认知卡"这是威胁" | "认知框架扭曲"——玩家 d' 临时降低，criterion 偏向威胁 |
| 敌人塞行为卡"逃跑" | "行为强制"——反射技能被强制高亮，其他技能 AP +1 |

特定技能（正名、白描、坚守等）可消除 debuff。

### 9.3 冷却系统

| 技能层级 | 冷却 | 设计意图 |
|---------|------|---------|
| L1 基础技能 | 0-1 回合 | 可频繁使用 |
| L2-L3 进阶技能 | 2-3 回合 | 有节奏使用 |
| L4 高阶技能 | 4-5 回合 | 关键时刻使用 |
| 终极技能 | 8-12 回合 | 一场战斗 1-2 次 |

### 9.4 NPC 也使用技能

NPC 和玩家共用同一棵技能树和同一套技能系统：

- NPC 的已解锁技能由设计师预设（体现角色性格/病情/战术风格）
- NPC 的快捷槽编排 = AI 策略（激进型/保守型）
- NPC 回合：检查快捷槽 → AI 选 1 技能 → 走态度结算引擎 → 态度碰撞
- NPC 也会硬解锁（消耗意志力激活与当前 PAD 冲突的技能）
- 玩家技能通过修改 NPC 的 PAD/SAN/驱动激活度来干预

详见 [01-核心机制.md](../../核心机制.md) §敌我共用规则。
