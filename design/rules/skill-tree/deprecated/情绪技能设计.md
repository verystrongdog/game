## 二、PAD 空间中的节点排列

15 个情绪节点在 3D 树上的物理位置对应其 PAD 三维坐标的拓扑投影：

- **P+ 方向（上方）**：快乐、爱、希望、共情、平静
- **P- 方向（下方）**：恐惧、愤怒、焦虑、厌恶、绝望、内疚、悲痛、孤独、恐怖
- **D+ 方向（右侧）**：快乐、希望、愤怒、爱
- **D- 方向（左侧）**：恐惧、焦虑、内疚、绝望、悲痛、孤独
- **A+ 区（前方）**：恐惧、愤怒、焦虑、厌恶、恐怖、敬畏
- **A- 区（后方）**：平静、悲痛、孤独、共情

拓扑规则：
1. 相邻情绪在 PAD 空间中距离近 → 树上节点近
2. 两情绪 PAD 距离公式：`dist = sqrt((V1-V2)² + (A1-A2)² + (D1-D2)²)`
3. 解锁某情绪的前置 = PAD 空间中距离最近的 1-2 个已解锁情绪

## 三、核心情绪 (L1)

> 三种最基础的情绪，覆盖 PAD 空间的三个关键区域。

### 快乐

```
情绪层:
  pad_anchor: "joy"
  pad_offset: { V: +0.96, A: +0.65, D: +0.59 }
  intensity: 0.8

被动效果: 
  - 角色可以使用"快乐"作为技能的情绪层（PAD 偏移朝快乐方向）
  - 快乐状态下，惩罚驱动的 θ_play +0.1（更难触发回避）
解锁成本: 1 技能点
```

### 恐惧

```
情绪层:
  pad_anchor: "fear"
  pad_offset: { V: -0.85, A: +0.68, D: -0.41 }
  intensity: 0.9

被动效果:
  - 角色可以使用"恐惧"作为技能的情绪层
  - 恐惧状态下，反射驱动的 θ_play -0.05（更容易触发逃跑）
解锁成本: 1 技能点
```

### 平静

```
情绪层:
  pad_anchor: "calm"
  pad_offset: { V: +0.60, A: -0.76, D: +0.11 }
  intensity: 0.3

被动效果:
  - 角色可以使用"平静"作为技能的情绪层
  - PAD 衰减率 × 0.8（情绪消退更慢——平静使人稳定）
解锁成本: 1 技能点
```

## 四、桥梁情绪 (L2)

> 从 L1 核心情绪沿 PAD 轴移动一步到达的情绪。

### 希望

```
情绪层:
  pad_anchor: "hope"
  pad_offset: { V: +0.85, A: -0.37, D: +0.48 }
  intensity: 0.5

被动效果: 角色可以使用"希望"作为技能的情绪层。
  P+ 区（愉悦）情绪的效果 ×1.1。
解锁成本: 2 技能点
前置: 快乐 L1（PAD 距离最近: |V:0.11|, |A:1.02|, |D:0.11| → 希望更安静、更被动一点）
```

### 愤怒

```
情绪层:
  pad_anchor: "anger"
  pad_offset: { V: -0.67, A: +0.73, D: +0.31 }
  intensity: 0.9

被动效果: 角色可以使用"愤怒"作为技能的情绪层。
  愤怒是唯一主动靠近威胁源的情绪（P-但D+）。愤怒+行为技能的硬解锁成本 C_control 降为 0（见 C_control 表）。
解锁成本: 2 技能点
前置: 恐惧 L1（从恐惧沿 D 轴翻转为正：D: -0.41 → +0.31）
```

### 悲痛

```
情绪层:
  pad_anchor: "grief"
  pad_offset: { V: -0.90, A: -0.42, D: -0.67 }
  intensity: 0.4

被动效果: 角色可以使用"悲痛"作为技能的情绪层。
  悲痛状态下，奖励驱动的 θ_play +0.15（更难被奖励吸引）。
  但照护驱动在悲痛中仍然可以激活（读他人 PAD，不读自身 PAD）。
解锁成本: 2 技能点
前置: 恐惧 L1 或 平静 L1
```

## 五、复合情绪 (L3)

> 需要多方向基础情绪的组合才能理解的情绪。

### 共情

```
情绪层:
  pad_anchor: "empathy"
  pad_offset: { V: +0.46, A: -0.30, D: +0.09 }
  intensity: 0.3

被动效果: 角色可以使用"共情"作为技能的情绪层。
  共情是"情绪的管道"——当角色掌握了共情后：
  - 可以读取敌方的当前 PAD 状态（战斗中显示一个简化的情绪指示器）
  - 照护驱动的 Attachment_strength 基线 +0.1
解锁成本: 3 技能点
前置: 任意 2 个 L2 情绪
```

### 爱

```
情绪层:
  pad_anchor: "love"
  pad_offset: { V: +1.00, A: +0.04, D: +0.35 }
  intensity: 0.6

被动效果: 角色可以使用"爱"作为技能的情绪层。
  爱是唯一可以让人主动选择不利选项的正向情绪。
  爱状态下，价值驱动的 θ_play -0.1（为所爱之人坚守更容易）。
解锁成本: 3 技能点
前置: 快乐 L1 + 希望 L2
```

### 焦虑

```
情绪层:
  pad_anchor: "anxiety"
  pad_offset: { V: -0.71, A: +0.73, D: -0.32 }
  intensity: 0.8

被动效果: 角色可以使用"焦虑"作为技能的情绪层。
  焦虑状态下，惩罚驱动的 θ_play -0.05（更容易触发回避）。
  注意：焦虑与恐惧 PAD 距离很近（|V:0.14|, |A:0.05|, |D:0.09|）——
  两个节点在树上物理相邻。焦虑是"未来的恐惧"。
解锁成本: 3 技能点
前置: 恐惧 L1 + 任意 1 个 L2
```

### 厌恶

```
情绪层:
  pad_anchor: "disgust"
  pad_offset: { V: -0.90, A: +0.55, D: -0.37 }
  intensity: 0.7

被动效果: 角色可以使用"厌恶"作为技能的情绪层。
  厌恶+行为技能的"排斥"效果（推开/移除敌方 buff）效果 ×1.2。
解锁成本: 3 技能点
前置: 恐惧 L1 + 愤怒 L2
```

## 六、精细情绪 (L4)

> 最复杂、最多层混合的情绪。

### 绝望

```
情绪层:
  pad_anchor: "despair"
  pad_offset: { V: -0.77, A: +0.59, D: -0.51 }
  intensity: 0.8

被动效果: 角色可以使用"绝望"作为技能的情绪层。
  绝望状态下，价值硬解锁的 C_control = 3.7（"背水一战"的代价）。
  但绝望+价值的技能效果随已损 HP 比例增长。
解锁成本: 5 技能点
前置: 恐惧 L1 + 悲痛 L2 + 焦虑 L3
```

### 内疚

```
情绪层:
  pad_anchor: "guilt"
  pad_offset: { V: -0.58, A: +0.13, D: -0.59 }
  intensity: 0.5

被动效果: 角色可以使用"内疚"作为技能的情绪层。
  内疚自动短路激活道德驱动——内疚+道德的技能 C_control 降至 1.5。
  "我做错了——我必须弥补。"（这是行为系统 §九 的"内疚耦合"机制）
解锁成本: 5 技能点
前置: 悲痛 L2 + 任意 1 个 L3
```

### 敬畏

```
情绪层:
  pad_anchor: "awe"
  pad_offset: { V: -0.06, A: +0.48, D: -0.40 }
  intensity: 0.6

被动效果: 角色可以使用"敬畏"作为技能的情绪层。
  P≈0, A>0, D<0——"在你面前，我渺小但清醒"。
  敬畏+文化的技能效果 ×1.5（仪式效果翻倍）。
解锁成本: 5 技能点
前置: 恐惧 L1 + 平静 L1 + 任意 1 个 L3
```

### 孤独

```
情绪层:
  pad_anchor: "loneliness"
  pad_offset: { V: -0.50, A: -0.55, D: -0.52 }
  intensity: 0.4

被动效果: 角色可以使用"孤独"作为技能的情绪层。
  孤独是所有 A<0 的情绪中最"重"的——A 被压低到 -0.55。
  孤独+价值的技能 C_control 约 3.4（"独行"——自己相信自己）。
解锁成本: 5 技能点
前置: 悲痛 L2 + 平静 L1 + 任意 1 个 L3
```

## 七、超越情绪 (L5)

### 恐怖

```
情绪层:
  pad_anchor: "terror"
  pad_offset: { V: -0.77, A: +0.70, D: -0.12 }
  intensity: 1.0

被动效果: 角色可以使用"恐怖"作为技能的情绪层。
  恐怖是世界观的核心情绪——在月光下，"怕到极致"本身会改变现实。
  恐怖状态下:
  - 反射驱动的 α 激活 ×1.2（更容易触发恐慌强制）
  - 但恐怖+价值 C_control = 3.8（全游戏最贵的硬解锁）
  - 恐怖+照护 = "我怕但我必须去"（冲向危险以保护他人）
解锁成本: 8 技能点
前置: 恐惧 L1 + 焦虑 L3 + 绝望 L4
```
