# 终极技能设计

> 终极技能 = 旧系统中"特殊态度"的映射。需要同时满足认知+情绪+行为三个分支的高层前置。大效果，长冷却（8-12 回合），一场战斗 1-2 次。数据源：[attitudes.json](../../../../data/attitudes.json)。

## 二、详细设计

### 逆流而上

```
技能内部封装:
  认知层: 推理与决策, d'=+0.8, criterion=-0.3, 深度=0.9
  情绪层: 恐惧 PAD 偏移 (V=-0.85, A=+0.68, D=-0.41)
  行为层: 价值驱动, valence=+1, base_ap=3, C_control=3.8

显示:
  AP: 3  CD: 10回合
  心灵震慑 8  +1意志力
  "你看清了，你感受到了恐惧，你没有逃。"

前置需求:
  认知: 决意 (推理 L5)
  情绪: 恐惧 (至少情绪 L4 层级)
  行为: 牺牲 (价值 L3)

硬解锁: 是 (C_control = 3.8，全游戏最贵)
```

### 奋起

```
显示:
  AP: 2  CD: 6回合
  心灵震慑 6 + 驱散敌方防御
  "愤怒给了你力量——不是摧毁，是纠正。"

前置需求:
  认知: 归因 (知识表征 L3)
  情绪: 愤怒 (至少情绪 L3)
  行为: 对抗 (价值 L3)

硬解锁: 否 (C_control = 0，愤怒+价值免费)
```

### 献身

```
显示:
  AP: 3  CD: 10回合
  心灵震慑 5 + 保护 1 名队友 + 自身 HP -10%
  "为所爱之人赴死——这不是代价，是选择。"

前置需求:
  认知: 隐喻 (表象与语言 L4)
  情绪: 爱 (至少情绪 L4)
  行为: 牺牲 (价值 L3)

硬解锁: 否 (C_control = 0，爱+价值自然流动)
```

### 背水

```
显示:
  AP: 4  CD: 12回合
  心灵震慑 × (1 + 已损HP比例) + 无视防御
  "你已经失去了那么多。还有什么好怕的？"

前置需求:
  认知: 决意 (推理 L5)
  情绪: 绝望 (情绪 L5)
  行为: 突破 (价值 L4)

硬解锁: 是 (C_control = 3.7)
特殊: 伤害 = base_effect × (1 + (maxHP - currentHP) / maxHP × 2)
```

### 净除

```
显示:
  AP: 3  CD: 5回合
  心灵震慑 5 + 移除所有幻象/假象效果
  "这是幻觉。恶心是真的——但幻觉不是。"

前置需求:
  认知: 白描 (表象与语言 L3)
  情绪: 厌恶 (至少情绪 L3)
  行为: 对抗 (价值 L3)

硬解锁: 是
特殊: 月光下清除观察者效应产物
```

### 抚慰

```
显示:
  AP: 2  CD: 3回合
  目标 A-0.3 + 回复 SAN 2
  "你不必一个人扛。你的痛——我也能感觉到一点。"

前置需求:
  认知: 类比 (知识表征 L3)
  情绪: 共情 (至少情绪 L4)
  行为: 安抚 (照护 L4)

硬解锁: 否 (低 C_control，最强的回复类终极技能)
```

### 虔敬

```
显示:
  AP: 2  CD: 5回合
  仪式效果翻倍 + 回复 SAN 2
  "仰望——不是因为渺小，是因为看见了更大的东西。"

前置需求:
  认知: 隐喻 (表象与语言 L3)
  情绪: 敬畏 (至少情绪 L4)
  行为: 运用仪式 (文化习俗 L3)

硬解锁: 否
特殊: 敬畏情绪下仪式效果翻倍。在月光下，「虔敬」将敬畏的文化重量转化为现实力量。
```

### 赴汤蹈火（最高阶）

```
显示:
  AP: 5  CD: 12回合
  绝对保护 1 名目标 1 回合 (免疫所有伤害 + 不受任何负面效果影响)
  自身受到伤害 ×1.5 (持续 3 回合)
  "我不入地狱，谁入地狱。"

前置需求:
  认知: 命名 (表象与语言 L5)
  情绪: 恐怖 (情绪 L5)
  行为: 舍身 (照护 L4)

硬解锁: 是
特殊: 全游戏最强的保护技能。使用后的脆弱期（3 回合受伤+50%）需要团队配合。
```

## 三、设计原则

1. **终极技能 = 旧特殊态度的映射**：每个终极技能对应一个在旧卡牌系统中已有详细参数的特殊态度条目（C_control、效果类型、叙事名）
2. **跨分支前置**：需要同时点亮认知+情绪+行为三个分支的高层节点才能解锁——物理上位于树顶三枝交汇处
3. **长冷却**：一场战斗最多使用 1-2 次——不是常规输出手段，是逆转局面的关键时刻
4. **叙事权重**：每个终极技能都有 flavor 文字——它们在叙事上代表了角色的核心人格选择
