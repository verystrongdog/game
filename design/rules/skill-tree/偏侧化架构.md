# 偏侧化架构 — 三体模型左右偏侧（lateralization）

> 三体神经模型（51 节点，L+R 合并）的左右偏侧表达规范。Grilling #92 定案：偏侧以**节点级连续系数**承载，**不进战斗结算**，作为可见但非机制的游戏要素（技能命名/展示/叙事锚点），并为疾病侧偏侧偏离（SZ 等）提供数据落点。修复 #26 重构时静默丢弃的偏侧能力（#20 D10 决策，决策树 :1414）。

## 一、决策来源与定位

- **Grilling #92**（2026-08-20，GitHub [#92](https://github.com/verystrongdog/game/issues/92)）：三体模型左右偏侧化缺失——健康脑偏侧不可表达。本 issue 从 #88（病因-疾病-神经转化接口）Q0.1 拆出，定**偏侧架构**；#88 定**疾病→映射内容**。
- **定位**：维度 规则 + 管线。架构层（本文件）：字段形态、语义、落点、校验。内容层（#88）：每条 pathology edge 的具体取值。
- **历史锚点**：
  - #20 D10（决策树 :1414）：「链路粒度 = 解剖粒度（DK 左右边独立），偏侧异常值得作为游戏机制」——本架构是此决策的恢复与落地。
  - #26（决策树 :1845-1847）D7 图节点模型（dk_name 为节点，L+R 合并）+ D8 mirror_of——本架构在 51 节点图**不动**的前提下补偏侧维度。
  - #26 重构静默丢弃左右独立（`脑功能层级模型.md` §二十 grep `左右/偏侧/半球/镜像` 零命中）——无决策记录讨论此取舍，本架构补此缺失记录。

## 二、核心原则（四条）

1. **偏侧不进结算**：`lateralization` 与 `laterality_delta` 仅承载展示/命名/叙事锚点语义，不进入任何战斗结算公式（伤害/buff/debuff/m 偏移）。此为 Q1 定案，后续任何"偏侧进入结算"的提议须先反转本决策。
2. **合并节点不动**：51 节点图、1049 条连接（776 皮层-皮层 + 47 CSTC + 114 脑干 + 112 特权通路）零改动。偏侧以字段承载，不拆节点（C″ 全拆 68 节点已否决：成本与 |d|<0.1 的文献收益不成比例）。
3. **单一真源 + 派生**：存储层唯一（连续系数），显示层派生（标签）。不引入方向枚举 + 幅度双字段（α 形态已否决，信息冗余）。
4. **数据保真**：健康基线（节点字段）与疾病侧偏离（Δ 字段）分离存储，combined 为派生值不落盘（Q8）。

## 三、字段规格：lateralization（健康基线）

### 3.1 语义

- 字段名：`lateralization`，类型 float，定义域 `[−1, +1]`。
- 符号：负 = 左偏（left_dominant），正 = 右偏（right_dominant），0 = 完全双侧（bilateral）。
- 幅度：`|lateralization|` = 偏侧强度。
- **范围声明**：仅用于显示层标签派生（§六）、技能命名/展示、叙事锚点。**不进结算**。

### 3.2 落点

- 权威源：`data/connectivity/tripartite_model.json` → `graph_nodes.<node>.lateralization`（dk_name/图节点级，一节点一系数）。
- 同步：`data/brain_regions.json` → 带 `dk_name` 的 functional_id 条目（同 dk_name 多 functional_id 取同一值；无 dk_name 的脑干核团主变体 = 0）。
- 不适用：镜像实体（LC_R/SNc_R）不写此字段（见 §五）；正交声明（见 §七）。

### 3.3 健康基线初值

初始默认全 0（双侧）。已知偏侧方向有文献支持的节点，建议初值如下 **[NEW 初值待文献复核]**（方向来自 Kong 2018 / Karolis 2019，幅度为设计初值，换算规则待内容批次定案）：

| 节点 | 方向 | 建议初值 | 文献依据 |
|------|------|---------|---------|
| parsopercularis（Broca 区后部） | 左 | −0.7 | Kong 2018：额下回岛盖部表面积左偏最强 |
| transversetemporal（Heschl 回） | 左 | −0.7 | Kong 2018：颞横回左偏最强 |
| superiortemporal（颞上回/颞平面） | 左 | −0.6 | Kong 2018：颞上回左偏；尸检 55-67% 左颞平面更大 |
| middletemporal（颞中回，语言网络核心） | 左 | −0.6 | Schijven 2023：MTG 为左半球语言网络核心区 |
| parahippocampal（海马旁回） | 左 | −0.3 | Kong 2018：男性海马旁回更左偏 |
| insula（前脑岛，情绪轴） | 右 | +0.2 | Karolis 2019：情绪功能轴 → 右 |

其余节点默认 0（双侧）。数值换算（文献效应量 → [−1,+1] 系数）与全量基线表 → 内容批次（#88 或单独任务）。

## 四、字段规格：laterality_delta（疾病侧偏离）

### 4.1 语义

- 字段名：`laterality_delta`（Δ），类型 float，定义域 `[−1, +1]`，默认 0。
- 语义：疾病导致的偏侧偏离量，叠加在健康基线之上。文献"左/右"经符号映射（左 → 负、右 → 正），效应量经换算映射为幅度。
- **不进结算**：同 §二.1。

### 4.2 落点

- 随 `pathology_edges.json` 的病理边存储（每条边端点级 Δ 信息）。该文件尚未创建（规划产物，#84 任务计划 + 决策树 :2817），schema 由本文件定义。
- 受 `design/entities/角色与面具.md` §8.8.2 铁律约束：**每个病理边（含 Δ）必须有文献依据 + 只能从已定义疾病推导**。
- 不写入疾病目录 frontmatter（避免与 #88「疾病文件扩展」议题纠缠；偏侧偏离是病理边属性而非疾病属性）。

### 4.3 叠加规则

- 存储：`baseline`（节点字段）+ 逐条 Δ（病理边），**combined 不落盘**（派生值）。
- 派生：`combined = baseline + ΣΔ`（多疾病线性求和）。
- 钳制：显示层标签派生前 `clamp(combined, −1, +1)`；超界截断仅影响标签，不回流数据。

### 4.4 已知内容锚点（SZ，Schijven 2023 / Okada 2016）

| 节点 | 文献发现 | Δ 方向 |
|------|---------|--------|
| rostralanteriorcingulate（rACC） | 厚度偏侧方向反转（对照左偏 → SZ 右偏），d=−0.083 | 正（右偏） |
| middletemporal（MTG） | 右偏增大（左 MTG 变薄 ↔ 幻听），d=−0.074 | 负（左偏增强） |
| Pallidum（苍白球） | 体积左偏（对照无此偏侧），d=0.081 | 负（左偏） |

具体取值（Δ 数值）→ #88 内容填充，本文件不给定值。

## 五、镜像实体处置

### 5.1 现状（已核验，2026-08-20）

- `data/brain_regions.json`：`LocusCoeruleusRight` / `SubstantiaNigraParsCompactaRight` = `hemisphere: "R"` + `function_profile: {mirror_of: <主变体>}`，10 字段缺失。
- `tripartite_model.json`：两个镜像为图节点，0 出边、0 次作端点——纯显示实体。
- 其他双侧结构（STN/上丘/VTA/PAG/丘脑/纹状体/杏仁核/海马）**均无**镜像——现有 2 个是偶然处置，非模式。

### 5.2 处置（M1 + 前向规则）

1. **存量展开**：`LocusCoeruleusRight` / `SubstantiaNigraParsCompactaRight` 复制主变体完整 10 字段 function_profile，`mirror_of` 保留为溯源注释字段。
2. **前向规则**：新镜像实体默认**显示层**（无剖面展开，仅坐标 + hemisphere + mirror_of）；**机制引用镜像 = 校验报错**。
3. **偏侧字段不适用镜像**：主变体（LC/SNc）双侧 = 0；镜像无 lateralization 字段。

## 六、显示层派生规则

### 6.1 标签派生

显示层（脑区面板/随身镜子/技能命名/3D 节点标注）将连续系数派生成标签：

```
|combined| ≥ t  →  标签 = 方向词（负 → "左偏" / 正 → "右偏"）
|combined| < t  →  标签 = "双侧"
```

- **t = 0.5** **[NEW 初值可调]**，显示层专用、零结算影响。
- 依据：Karolis 2019 偏侧系数标度（0=双侧 ±1=单侧）；健康偏侧"显著但非单侧"——t 过滤弱偏侧区，仅明显偏侧出标签。

### 6.2 可见性（Q2b-A）

- **仅玩家自角色可见**：玩家自己的脑区面板/随身镜子显示偏侧标签。
- **敌方/面具的偏侧偏离不进任何面板 UI**（黑箱原则，决策树 :51 + #88 Q0.4）——敌方偏侧异常通过叙事与战斗表现传达（幻听台词、特效、技能名）。
- 数据层如实入库（Q2b「入库」）：敌方/面具偏离写入病理边 Δ，仅呈现层受黑箱约束。

## 七、与 3D 坐标的关系（正交声明）

- `mni_xyz` 语义 = **该解剖区域的代表位置**（合并节点 L+R 合并，坐标取源数据一侧——无对错）。偏侧系数独立表达左右偏向，**两者正交**：
  - 坐标不因偏侧系数改变。
  - 偏侧系数不因坐标来源改变。
- 已知事实：32 皮层节点坐标左右混杂（parsopercularis x=+48.5 右、superiortemporal x=−52.6 左；InferiorParietalAngular obj_file = `lh.*.obj` 而 mni x=+38.4 右）——**非数据错误**，是合并语义的正常结果，本次不修正。
- 3D 中偏侧的可见表达（标签/标注/高亮）→ 呈现维度批次（P6 或单独 issue），本架构不产 3D 规格。

## 九、数据落点与校验

### 9.1 落点清单

| 数据 | 字段 | 位置 |
|------|------|------|
| 健康基线 | `lateralization` | `tripartite_model.json` graph_nodes（权威）+ `brain_regions.json` 对应 functional_id 条目（同步） |
| 疾病侧偏离 | `laterality_delta` | `pathology_edges.json` 病理边（待 #88 创建） |
| 镜像 | mirror_of + 展开剖面 | `brain_regions.json` |

### 9.2 校验

- T8 升级：镜像一致性（展开剖面 = 主变体逐字段相等）+ 机制引用镜像 = 报错（前向规则）。
- 定义域校验：`lateralization ∈ [−1,+1]`、`laterality_delta ∈ [−1,+1]`。
- 注册表 `numerical_locations` 复查：偏侧相关术语（偏侧/laterality_delta/镜像实体/LC_R/SNc_R）入库后，本文件同步维护其数值位置。
