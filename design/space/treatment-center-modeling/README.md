# 医院场地建模项目

## 项目定位

这是一个独立的 Blender 场地建模项目。

目标是基于本地参考图集中的`500床方案一（25-29）`，构建一套适用于游戏场地生产的精神专科医院场景。

该项目的重点不是做完整建筑表现，也不是做施工级还原，而是：

- 保证整体体量和空间关系可信
- 让场景适合关卡、镜头和玩法使用
- 用模块化和实例化降低重复劳动

## 当前核心原则

- 先标准模块，后整层铺开
- 先灰模，后细化
- 先玩法动线，后装饰填充
- 能实例化就不要手工重复建
- 一层不作为全楼标准模板
- 二层和三层是标准层模块的主要来源

## 开工顺序

1. 整理参考图到 `references/`
2. 在 `blend/` 中建立主工程文件
3. 先做总平面灰模
4. 先做主楼标准层模块
5. 用标准模块拼装二层和三层
6. 再回做一层特殊空间
7. 最后补右侧附属楼、左侧体块、屋面、门窗和道具

## 项目注意事项

### 不要过早高精度

在标准病房、走廊、交通核没有定型前，不要急着做细节、UV 和高密度家具摆放。

### 不要让目录失控

参考、工程、导出和文档必须分开放。

一旦混在一起，后续转移项目时很容易丢依赖、丢版本、丢上下文。

### 不要破坏模块母版

如果某个实例需要特殊修改，优先复制成独立对象，不要直接在母版模块上做临时改动。

### 不要默认所有房间都值得完整建

先区分：

- 可游玩区域
- 可进入但低细节区域
- 仅外观区域

## 接手者第一检查项

任何人接手项目后，先检查这 5 项：

1. 参考图和 Blender 朝向是否一致
2. 单位是否为`1 Blender Unit = 1 米`
3. 标准病房和标准走廊模块是否已经建立
4. 二层和三层是否真的复用同一套模块
5. 当前哪些区域是高优先级可达区域

## 结论

这个项目真正的风险不在于“医院太大”，而在于“重复内容太多，稍微组织不好就会大面积返工”。

因此，目录结构、模块规则和文档交接不是附属工作，而是项目本身的一部分。
