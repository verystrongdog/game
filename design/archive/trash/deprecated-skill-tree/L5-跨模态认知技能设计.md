# L5 跨模态皮层 — 认知与语言

> L4 告诉你"这是蛇"。L5 告诉你"这条蛇有毒吗？我应该怎么办？上次是谁被蛇咬了？"——多模态整合、语言化、推理。L5 是主动认知操作的富集层，激活点和认知槽消耗的主要来源。
>
> **设计原则**: L5 操作设定"认知框架"——改变接下来几回合的规则。L5 是玩家操作密度最高的层级。各操作消耗 1-2 激活点。

## 一、L5 操作总览

29 个 L5 脑区，按功能模块合并为 **6 个主动操作**：

| # | 操作 | 脑区 | 激活点 | 核心效果 |
|---|------|------|--------|---------|
| 1 | **计划** | dlPFC + 额极 + 额上回 + 额中回尾部 | 1 | 预设未来 2-3 回合的行动序列 |
| 2 | **命名** | Broca + Wernicke + 弓状束 + 颞上回 | 2 | 给事物赋予语言标签→固化为现实 |
| 3 | **换位** | TPJ + 缘上回 + mPFC | 1 | 以他人视角看世界 |
| 4 | **决策** | vmPFC + OFC | 1 | 最终价值判断、确认选择 |
| 5 | **控制** | dlPFC + 额顶网络 + ACC | 2 | 主动压制/重定向 L0-L1 自动反应 |
| 6 | **自省** | mPFC + 额上回(内侧) | 1 | 思考自己的思考→元认知 |

**合并说明:**
- dlPFC/额极/额上回/额中回尾部(前额叶执行系统) → 合并为"计划"+"控制"
- Broca/Wernicke/弓状束/颞上回(语言系统) → 合并为"命名"
- TPJ/缘上回(社会认知) → 合并为"换位"
- vmPFC/OFC(价值系统) → 合并为"决策"
- mPFC + 额上回内侧(自我参照) → 合并为"自省"

**不产生独立技能的结构:**
- 前脑岛/ACC/后扣带/颞极 → 已在 L2 中定义为技能（功能上属于旁边缘）
- 白质通路（mPFC-杏仁核, vmPFC-TPJ, 岛叶-ACC, 岛叶-ACC-VTA, 岛叶-PFC-杏仁核, 岛叶-vmPFC, 前额叶-海马）→ 作为技能间的连接通路
- DMN+OFC, 前额叶极 → 留给 L6

## 二、操作设计

### 操作 1: 计划 (Plan)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: dlPFC + 额极(BA10) + 额上回 + 额中回尾部
MNI:  dlPFC (-38, 32, 34)         → 游戏 (-0.44, 0.44, 0.33)
      额极 (-8, 60, 4)             → 游戏 (-0.12, 0.13, 0.43)
      额上回 (-18, 38, 42)         → 游戏 (-0.20, 1.02, 0.26)
      额中回尾部 (-34, 14, 48)      → 游戏 (-0.38, 1.08, 0.09)
类型: 主动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

预设未来 2 回合的行动序列：
- 选择 2 个快捷槽中的技能，指定"本回合用 A，下回合用 B"
- 如果按照计划执行：
  - 第 1 步正常执行
  - 第 2 步按计划执行时：AP -1，且该步的认知槽占用 -1（"不需要再想了，已经想好了"）
- 如果中途被迫改变计划（恐慌强制/敌方打断/友方危急）：
  - 获得 1 层失望标记（"计划被打乱了"）
  - 但认知槽释放（不再占槽）

**限制:**
- 计划只能在"安全"状态下制定（SAN ≥ 50%）
- 不能在恐慌/BNST激活状态下制定新计划（"太焦虑了，没法思考未来"）
- 可以有 1 个活跃计划（新计划替换旧计划）

**激活点储存 (髓鞘化 ≥ m0.5 解锁):**
- 每回合可将 **1 个未使用的激活点** 存到下回合
- 储存的点**只能用于执行计划预设的操作**，不可用于计划外操作
- 储存上限: 1 点（dlPFC 工作记忆的固有限制——保持一个特定意向在线，不是空白支票）
- 对标设计: 杀戮尖塔的 Ice Cream 遗物——能量储存不是默认功能，是特定条件解锁的奖励
- "我预判了你的预判"——dlPFC 在脑中保持多步计划在线，跨回合维持行动意向

**对 L0-L1 的调制:**
- 计划激活时，熟练的连续使用计数不会被"按计划执行"重置
- 计划中的第 2 步如果触发了应激反应 → 计划自动取消 + 不获得失望（"身体优先，这不是你的错"）

**AP 消耗:** 1（制定计划本身需要思考）
**认知槽占用:** 1（计划保持在线需要持续占用工作记忆）
**冷却:** 无（可随时制定新计划；但每回合只能制定 1 次）

**设计依据:**
dlPFC: 工作记忆和计划——保持多步目标在线。额极(BA10): 前瞻记忆和认知分支
(coordinating multiple tasks)——"我会在完成 A 之后做 B"。额上回: 高级认知和
自我意识。额中回尾部: dlPFC 的运动端——将计划转化为行动序列。

### 操作 2: 命名 (Name)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: Broca + Wernicke + 弓状束 + 颞上回
MNI:  Broca (-48, 14, 18)         → 游戏 (-0.63, 0.53, 0.15)
      Wernicke (-56, -42, 8)       → 游戏 (-0.75, 0.35, -0.11)
      弓状束 (-40, -10, 24)         → 游戏 (-0.44, 0.82, -0.07)
      颞上回 (-54, -32, 8)         → 游戏 (-0.60, 0.64, -0.22)
类型: 主动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

为战场上的一个实体命名——赋予它一个语言标签：
- **命名敌方**: 该敌方获得一个永久标签（玩家自定义/或从预设中选择）
  - 标签效果：角色对该敌方的所有效果 +20%
  - 该敌方在观察者效应下变得"更稳定"——隐藏属性被锁定（不再变化）
  - "你叫什么不重要。我管你叫'胆小鬼'——现在你是了。"
- **命名友方**: 清除友方 1 个负面标签 + 替换为正面标签
  - "你不叫怪物。你叫幸存者。"
- **命名自己**: 清除自身 1 个负面标签 + SAN 恢复 3
  - 每场战斗最多 1 次

**月光效应:**
- 命名是观察者效应的核心触发方式——在月光下，命名一个东西**真的会让它变成那样**
- 月光下命名敌方：效果 +30%（而非 +20%），且敌方 AI 策略被标签影响
- 月光下命名自己：标签效果持续整场战斗，不受 SAN 波动影响

**对 L4 的调制:**
- 命名敌方后，L4 识别对该敌方的 AP 消耗固定为 0——"已经知道他是谁了，不需要再辨认"

**AP 消耗:** 2
**认知槽占用:** 2（语言产出 + 理解需要大量执行控制）
**冷却:** 每场战斗 1 次（命名是沉重的行为——你不能随便重新命名）

**设计依据:**
Broca区: 语言产出和句法构建。Wernicke区: 语言理解和语义提取。弓状束: 连接
Broca和Wernicke的白质通路——"理解→表达"的桥梁。颞上回: 听觉联合皮层，
包含 Wernicke 区的后部。命名是语言系统最核心的功能——给事物赋予语言标签
不仅是描述，在月光下是**创造**。

### 操作 3: 换位 (Perspective-Take)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: TPJ + 缘上回 + mPFC
MNI:  TPJ (-52, -50, 28)         → 游戏 (-0.69, 0.82, -0.23)
      缘上回 (-52, -44, 32)       → 游戏 (-0.58, 0.91, -0.30)
      mPFC (-4, 48, 10)           → 游戏 (-0.14, 0.77, 0.21)
类型: 主动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

以敌方视角看当前战斗：
- 揭示：敌方眼中的"最大威胁"是谁（不一定是你的角色）
- 揭示：敌方的 AI 策略倾向（偏进攻/偏防御/偏支援/偏逃跑）
- 揭示：敌方的"恐惧"——它最怕什么效果类型

**衍生效用:**
- 如果揭示敌方害怕某效果 → 快捷槽中有该类技能则高亮 + 该技能效果 +25%
- 如果揭示敌方不认为你是威胁 → 本回合你的攻击有概率不被防御
- 如果 L2 识人已解锁 → 换位额外揭示敌方的"动机"（为什么在这里/为什么战斗）

**代价:**
- 过度换位——连续使用换位（对同一敌方 2 次/战斗内）→ 有概率"迷失"
  - 迷失：SAN -3，自身认知槽上限 -1（持续到战斗结束）
  - "你太沉浸在他人的视角里了。你忘了自己是谁。"

**AP 消耗:** 1
**认知槽占用:** 1
**冷却:** 3 回合

**设计依据:**
TPJ: 心理理论(Theory of Mind)的核心——理解他人有不同于自己的信念、欲望和意图。
缘上回: 语音工作记忆和模仿——"在脑中复述他人的话"。mPFC: 社会认知和自我参照——
区分"自己的视角"和"他人的视角"。三者构成从"看到他人行为"到"理解他人心理"的完整通路。

### 操作 4: 决策 (Decide)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: vmPFC + OFC (价值系统)
MNI:  vmPFC (-4, 42, -14)       → 游戏 (-0.13, 0.13, 0.18)
      OFC (-22, 34, -16)         → 游戏 (-0.35, 0.12, 0.20)
类型: 主动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

当快捷槽中有 ≥2 个可用技能时，使用"决策"来**锁定选择**：
- 锁定后：本回合所选技能的效果 +20%
- 锁定后：本回合不能更改选择（"下了决心就不要回头"）
- 锁定的技能占用认知槽 -1（"决定了——不需要再权衡"）

**对 L2 的调制:**
- 决策 + L2 价值直觉：如果锁定的技能恰好是价值直觉高亮的技能 → 额外加成 +10%
  - "OFC 的直觉和 vmPFC 的确认一致——你知道这是对的"

**代价:**
- 如果锁定的技能被敌方闪避/抵抗 → 获得 1 层失望标记（比普通失望更快）
- "你确信它是对的——然后它失败了。失望更重。"

**与计划的关系:**
- 决策可以和"计划"叠加——计划中的第 2 步如果使用决策锁定 → 双重加成
- "想好了。决定了。执行。"

**AP 消耗:** 0
**认知槽占用:** 决策本身占 1 槽；锁定技能的槽成本 -1（最少减到 0）。
  例: 锁定L5命名(原2槽)→命名只需1槽 + 决策占1槽 = 总2槽（原需2槽，不变）
  例: 锁定L3注视(原1槽)→注视只需0槽 + 决策占1槽 = 总1槽（原需1槽，不变）
  例: 锁定L0应激主动(原1槽)→0槽 + 1槽 = 总1槽（不变）
  决策不减少总槽消耗——它只是把"权衡要不要做"的隐形成本消除了。
  真正的好处是+20%效果和锁定后的不可更改（避免了临时犹豫）。
**冷却:** 3 回合

**设计依据:**
vmPFC: 价值整合和决策信心。vmPFC 将来自 OFC(价值比较)、杏仁核(情绪权重)、
海马(过去经验)的信息整合为"最终选择"。vmPFC→纹状体的投射启动选择的行动。
vmPFC 损伤→决策瘫痪(无法做出选择)或冲动决策(不经过整合就选择)。

### 操作 5: 控制 (Control)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: dlPFC + 额顶网络 + ACC背侧
MNI:  dlPFC (-38, 32, 34)         → 游戏 (-0.44, 0.44, 0.33)
      额顶网络 (-34, 42, 36)       → 游戏 (-0.38, 0.95, 0.28)
      ACC背侧 (-6, 16, 32)         → 游戏 (-0.08, 0.59, 0.15)
类型: 主动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

主动压制一个 L0 或 L1 的自动反应——"我知道身体想干嘛，但我不做"：
- **压制应激反应**: 本回合 HP 低于触发阈值时 → 不自动闪避。闪避换成下一次攻击效果 +25%
  - "我不逃。我反击。"
- **压制趋向回避**: 本回合不按情境回避——可以手动选择趋近
  - "我知道它很可怕。我选择靠近。"
- **压制 BNST 焦虑**: 如果 BNST 已激活 → 暂停 2 回合
  - "焦虑停了。现在我可以思考。"
- **打断习惯化**: 重置熟练的连续使用计数（"不要自动驾驶"）

**代价:**
- 每次控制操作占用 2 个认知槽（是普通 L5 操作的 2 倍——压制身体需要大量心力）
- 连续控制（2 回合内再次控制）→ 认知槽占用 +1（累计 3 槽）

**AP 消耗:** 0（控制本身不消耗 AP——它改变的是其他技能的运作方式）
**认知槽占用:** 2（压制自动反应）
**冷却:** 无（可在 AP 允许范围内任意使用，但认知槽是约束）

**设计依据:**
dlPFC: 认知控制的核心——抑制不合适的优势反应。额顶网络: 灵活的任务切换和抑制控制。
ACC背侧: 冲突检测后→触发dlPFC的认知控制级联。Botvinick2001→Kerns2004→
ACC检测到冲突(自动反应 vs 意图)→dlPFC激活→压制自动反应。"控制"本质上
就是 ACC→dlPFC→行为抑制这条通路。

### 操作 6: 自省 (Metacognition)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: mPFC + 额上回(内侧)
MNI:  mPFC (-4, 48, 10)          → 游戏 (-0.14, 0.77, 0.21)
      额上回 (-18, 38, 42)        → 游戏 (-0.20, 1.02, 0.26)
类型: 主动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

思考自己的思考——元认知评估：
- 检视当前自身状态：
  - 当前主动的认知槽占用明细
  - 当前活跃的 L1-L2 学习标记（恐惧/期待/失望 各几层）
  - 当前恐慌风险等级
  - SAN 预期变化趋势

- 基于检视结果，可以选择：
  - **修正**：清除 1 个 L1 学习标记（选恐惧/期待/失望之一 → 清除 1 层）
  - **重新评估**：降低恐慌触发阈值 5%（SAN 阈值提高——"没那么危险"）

  "不是'我在想什么'——是'我为什么这样想'。"

**限制:**
- 修正/重新评估每场战斗各限 1 次
- 修正是 L5 dlPFC→杏仁核自上而下通路（"理性告诉我不需要这么怕"）

**AP 消耗:** 1
**认知槽占用:** 1（元认知本身需要认知资源）
**冷却:** 5 回合

**设计依据:**
mPFC: 自我参照加工——思考关于自己的信息。mPFC→杏仁核的自上而下通路参与
情绪调节（"重新评估"——reappraisal——是认知行为疗法的核心机制）。
额上回内侧: 元认知和自我意识。自省体现了 dlPFC/mPFC 之间的协作——
dlPFC 提供当前状态数据，mPFC 提供"这对'我'意味着什么"的解读。

## 三、L5 调制矩阵

### L5 → L4-L0

| L5 技能 | → 调制目标 | 调制方式 |
|---------|----------|---------|
| 计划 | L0 熟练 | 计划执行不打断连续计数 |
| 计划 | L0 应激反应 | 计划中应激触发→不获得失望 |
| 命名 | L4 识别 | 命名后识别 AP→0 |
| 命名 | L1 恐惧条件化 | 命名后恐惧标记获取 +50%（"有名字的东西更好怕/更好打"） |
| 换位 | L2 识人 | 换位触发识人的社会角色 + 动机揭示 |
| 换位 | L0 趋向 | 换位后可主动选择趋向方向（不耗认知槽） |
| 决策 | L2 价值直觉 | 决策+直觉一致→额外+10% |
| 决策 | L1 期待 | 锁定的技能命中→期待标记获取 +1 |
| 控制 | L0 全部 | 压制任何 L0 自动反应 |
| 控制 | L1 BNST | 暂停 BNST 焦虑 2 回合 |
