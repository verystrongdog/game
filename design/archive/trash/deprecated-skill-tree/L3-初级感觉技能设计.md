# L3 初级感觉皮层 — 外部世界的信息入口

> L0-L2 主要处理**内部状态**（我安全吗？我饿吗？）。L3 开始处理**外部世界**的原始数据——光、声、触、运动。L3 是信息获取层，操作以主动为主（感知在游戏中是主动选择——"我要看什么？"）。**L3 是玩家开始手动分配激活点（每操作 1 点）的第一层。**
>
> **设计原则**: L3 操作提供关于外部世界的精确信息。它们向 L0 警觉和 L2 内感受提供更高质量的输入。L3 本身不做判断——那是 L4-L5 的事。

## 一、L3 操作总览

7 个 L3 脑区合并为 **4 个操作**，3 主动 + 1 被动：

| # | 操作 | 脑区 | 性质 | 激活点 | 核心效果 |
|---|------|------|------|--------|---------|
| 1 | **注视** | V1 + 枕顶联合 + 楔叶 | 主动 | 1 | 花 AP 聚焦观察，揭示敌方详情 |
| 2 | **聆听** | A1 | 主动 | 1 | 检测隐蔽敌人/即将到来的攻击 |
| 3 | **身体感知** | S1 + 旁中央小叶 | 被动始终 | 0（自动） | 精确感知自身受伤位置和身体状态 |
| 4 | **执行动作** | M1 | 主动 | 1 | 下一个行为技能精准度提升 |

**合并说明:**
- 枕顶联合 + 楔叶（次级视觉/空间注意）→ 并入"注视"——同属视觉通路
- 旁中央小叶（下肢运动/感觉）→ 并入"身体感知"——同属体感系统
- M1 是运动输出的最终皮层端——它本身不产生"动作类型"，但提升所有主动动作的精度

## 二、操作设计

### 操作 1: 注视 (Observe)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: V1 + 枕顶联合 + 楔叶
MNI:  V1 (7.9, -74.0, 1.6)       → 游戏 (-0.14, 0.56, -0.54)
      枕顶联合 (31.0, -75.7, -5.6)  → 游戏 (-0.43, 0.47, -0.59)
      楔叶 (-8, -80, 28)           → 游戏 (-0.09, 0.86, -0.54)
类型: 主动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

选择一个敌方目标，本回合聚焦观察。揭示以下信息：
- 敌方的 1 个隐藏属性（抗性/弱点/技能冷却状态）
- 敌方的当前状态标签（如果有"隐藏"标签→有概率揭示）
- 如果 L4 纺锤体回已解锁 → 额外揭示敌方的"身份类型"

**对 L0 的调制:**
- 注视目标期间（本回合），对该目标的 警觉 标记立即 +1
- 如果目标被持续注视 ≥ 2 回合（连续使用注视）→ 警觉标记额外 +1
- "V1 的精确视觉输入让上丘的威胁检测更准确"

**AP 消耗:** 1
**认知槽占用:** 1（主动聚焦需要注意力的执行控制）
**冷却:** 0（可以连续使用，但每次连续使用 AP+1——"眼睛累了"）

**设计依据:**
V1: 初级视觉皮层，边缘检测和方向选择性。枕顶联合: 背侧视觉通路("where"通路)，
空间注意和多目标追踪。楔叶: 次级视觉，运动检测和空间视觉。三者构成完整的
"看→定位→追踪"视觉管线。

### 操作 2: 聆听 (Listen)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: A1 (Heschl 回, 初级听觉皮层)
MNI:  (-42, -24, 10) → 游戏 (-0.47, 0.66, -0.16)
类型: 主动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

主动聆听周围环境：
- 检测是否有隐蔽/隐形敌方在场（不揭示具体位置，只报告"有/无"）
- 如果敌方下回合准备使用大型技能 → 有概率提前 1 回合获得"声音预警"
- 预警效果：该技能的名称被部分揭示（"??之??"），本回合可提前准备防御

**对 L0 的调制:**
- 聆听触发的声音预警 → 警觉自动获得 1 层标记（针对发出声音的敌方）
- 如果该敌方之前被注视过 → 预警信息更精确（技能全名揭示）

**AP 消耗:** 0（听觉是被动接收，主动聆听只消耗注意力不消耗AP）
**认知槽占用:** 1（过滤噪音、识别有意义的声音需要执行控制）
**冷却:** 2 回合

**设计依据:**
A1 (Heschl 回): 初级听觉皮层，频率分析和声音定位。听觉系统与视觉不同——
声音不需要"朝向"即可接收（360度感知），但信噪比低（需要过滤环境噪音）。
"聆听"反映的是主动听觉注意——不是听到声音（那永远是自动的），而是
"在噪音中找出有意义的声音信号"。

### 操作 3: 身体感知 (Body Awareness)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: S1 + 旁中央小叶
MNI:  S1 (-42, -26, 54)       → 游戏 (-0.47, 1.15, -0.18)
      旁中央小叶 (-8, -30, 60)   → 游戏 (-0.09, 1.22, -0.20)
类型: 被动(始终生效)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

解锁后获得以下精确感知：
- HP 和 SAN 显示从柱状条变为精确数字
- 身体哪个部位受伤 → 显示受伤位置（头/躯干/四肢）和该部位的 debuff 详情
- 感知自身的 debuff 持续时间（"这个眩晕还会持续 2 回合"）
- 预感即将受到的伤害类型（物理/精神/混合），在敌方技能释放前 1 回合

  "解锁前，你只知道'我受伤了'。
   解锁后，你知道'左臂被精神冲击击中，残余刺痛还会持续 2 回合'。"

**与 L2 内感受的关系:**
- L2 内感受: 告诉你**阈值**在哪里（"恐慌快要触发了"）
- L3 身体感知: 告诉你**当前精确状态**是什么（"SAN=34, HP=42, 左臂受伤"）
- 两者互补——一个管"什么时候到极限"，一个管"现在是什么状态"

**对 L0 的调制:**
- 身体感知让应激反应的预测更精确——受到即将到来的伤害预告后，
  可以主动激活应激反应（提前闪避），而不用等到 HP 掉到阈值以下

**AP 消耗:** 0（被动）
**认知槽占用:** 0
**冷却:** N/A

**设计依据:**
S1: 初级体感皮层，身体表面的触觉/痛觉/温度/本体感觉的地形图(penfield homunculus)。
旁中央小叶: 下肢的运动和感觉代表区。S1 的精确身体地图使人能够定位"哪里受伤了"而
不只是"我受伤了"。本体感觉(proprioception)——不需要看就知道自己的肢体在什么位置——
是 S1 的核心功能。

### 操作 4: 执行动作 (Execute)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: M1 (初级运动皮层, BA4)
MNI:  (-37, -22, 58) → 游戏 (-0.41, 1.19, -0.15)
类型: 主动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

为下一个主动行为技能（L4+伤害/防御类技能）提供精确的运动执行：
- 下一个技能命中率 +20%
- 如果下一个技能是连续使用（触发熟练）→ 该技能的冷却额外 -1
- 如果连续使用执行动作 → 第二次 AP 消耗 -1（M1 自身的熟练化）
- **基础伤害**: 执行动作本身附带精神冲击 2（M1→皮质脊髓束→运动输出的最低限度伤害）
  - 这不是"攻击"——这是"你的存在本身对他人的精神压力"

  "想到和做到之间有一个 M1。解锁 M1 让你跨越了这段距离。"

**代价:**
- M1 本身不产生伤害或防御——它只是"准备"。花 AP 和槽位来确保下一个动作命中
- 如果下一个技能被敌方闪避 → 获得 1 层失望标记（"动作完美但没打中"）

**AP 消耗:** 1
**认知槽占用:** 1（精确运动执行需要注意力）
**冷却:** 1 回合

**设计依据:**
M1: 初级运动皮层，运动输出的最终皮层端。皮质脊髓束从 M1 第5层锥体细胞(Betz cells)
发出，直接投射至脊髓运动神经元。M1 编码的是运动的**精确参数**（方向、力度、速度），
而不是运动的目标（那是前运动皮层和基底节的事）。"执行动作"反映的是 M1 的精确性——
前面的策略和计划已经做好，M1 确保执行到位。

## 三、L3 调制矩阵

### L3 → L0

| L3 技能 | → L0 技能 | 调制方式 |
|---------|----------|---------|
| 注视 | 警觉 | 聚焦目标→警觉+1(立即); 连续注视→额外+1 |
| 聆听 | 警觉 | 声音预警→警觉+1(针对声源) |
| 身体感知 | 应激反应 | 伤前预告→可提前主动激活应激 |
| 执行动作 | 熟练 | 配合连续使用→冷却额外-1 |

### L3 → L2

| L3 技能 | → L2 技能 | 调制方式 |
|---------|----------|---------|
| 身体感知 | 内感受 | S1精确数据→内感受精度↑(阈值预测更准确) |
| 注视+聆听 | 冲突感知 | 视听联合揭示→冲突检测更敏感 |

### L3 与 L4 的前瞻连接

| L3 技能 | → L4 技能(待设计) | 关系 |
|---------|-----------------|------|
| 注视 | 识别(颞下回) | V1输入→颞下回进行物体识别 |
| 注视 | 识面(纺锤体回) | V1输入→纺锤体回进行面孔识别 |
| 聆听 | 理解(Wernicke) | A1输入→Wernicke进行语言理解 |
| 身体感知 | 整合触觉(顶叶) | S1输入→顶叶进行体感整合 |
| 执行动作 | 策略(尾状核/L5) | M1执行→L5评估执行结果 |
