# L0 脑干基底操作 — 生存反射层

> 脑干核团提供的 6 个基底操作。**开局即存在，不需要解锁**——它们是你拥有脑干就有的生存程序。不可拆解、最低延迟、不消耗激活点（情境自动激活）。所有更高层级的链路都是对这些基底操作的整合、调制、抑制或重定向。
>
> **设计原则**: L0 = 身体替你做的决定。玩家不能选择不做——只能花认知槽来压制或重定向。L0 操作不消耗激活点（自动激活），消耗认知槽的压制动作属于 L5 控制操作的范畴。
>
> **资源模型**: 意志力(WP)已废弃，替换为认知负荷（详见 [脑功能层级模型 §十三](../../%E8%A7%84%E5%88%99/%E6%8A%80%E8%83%BD%E6%A0%91%E7%B3%BB%E7%BB%9F/%E8%84%91%E5%8A%9F%E8%83%BD%E5%B1%82%E7%BA%A7%E6%A8%A1%E5%9E%8B.md#十三资源与效果体系)）。压制 L0 反射占用 1 个认知槽，槽位上限 = 3 + SAN/30。

## 一、L0 基底操作总览

16 个 L0 脑区中，**6 个核团**产生基底操作，其余为通路或基础设施：

| # | 操作名 | 脑区 | 性质 | 激活点 | 一句话 |
|---|--------|------|------|--------|--------|
| 1 | **应激反应** | PAG | 被动(条件触发) | 0（自动） | 威胁→自动闪避/逃离 |
| 2 | **警觉** | 上丘 | 被动(始终生效) | 0（自动） | 自动检测威胁方向 |
| 3 | **忍耐** | 中缝背核 | 被动+主动 | 0（自动） | 过滤不重要刺激, 抑制冲动 |
| 4 | **激活** | 蓝斑 | 主动 | 0（自动） | 占用认知槽, 全局唤醒提升 |
| 5 | **趋向** | VTA | 被动(始终生效) | 0（自动） | 定义基础行为方向 |
| 6 | **熟练** | 小脑皮层 | 被动(始终生效) | 0（自动） | 重复使用→AP降低 |

**不产生独立操作的结构：**

| 结构 | 原因 |
|------|------|
| 中缝正中核 | 功能并入"忍耐"——两个中缝核都是5-HT系统 |
| 黑质致密部(L/R) | 运动启动是所有主动操作的基础，不独立为操作 |
| 脑桥网状核 | 呼吸/心跳/自主神经——太基础，不参与战斗 |
| 蓝斑_R, 黑质致密部_R | 双侧对称结构，与左侧合并 |
| VTA-NAcc | L0→L1 多巴胺通路，作为"趋向"与 L1"期待"的连接 |
| 杏仁核-PAG | L1→L0 恐惧-防御链路，作为 L1 恐惧条件化的解剖基础 |
| 反射环路×3 | 通路，不是独立操作。作为"应激反应"的三种表现 |

## 二、基底操作设计

### 操作 1: 应激反应 (Stress Response)

```
脑区: PAG (中脑导水管周围灰质)
MNI:  (0, -30, -8) → 游戏 (0.00, 0.46, -0.20)
类型: 被动(条件自动触发)
```

**触发条件:**
- HP < 40% 时自动触发（"身体感到了危险"）
- 或 敌方释放"威胁"标签技能时自动触发
- 或 玩家主动激活（占用 1 个认知槽，持续 1 回合）→ 可自由选择时机

**被动触发效果:**
- 本回合闪避 1 次攻击
- AP 消耗 0（身体替你做了）
- 不占用认知槽

**主动激活效果:**
- 同被动效果 + 本回合移动力 +1
- AP 消耗 1
- 占用 1 个认知槽（压制身体的自然防御节律、提前启动需要执行控制介入）

**冷却:** 0 回合（被动触发无冷却）
**主动激活冷却:** 2 回合

**连续应激衰减:**
- 每次被动触发后，下次触发阈值 -5%（HP<35%, 30%...）
- "身体不能在极限状态下连续应激——每次应激后需要更高的危险信号才能再次触发"
- 战斗结束后重置

**设计依据:**
PAG 是防御行为的 master integrator。dlPAG→主动逃逸(Glu)，vlPAG→冻结(GABA)。Hansen2024: PAG属GREEN社区。Paxinos2004: 损毁PAG后刺激杏仁核/下丘脑不再产生防御反应——PAG是防御的最终输出端。

**高层调制接口:**
- L1 杏仁核→降低触发阈值（恐惧条件化让应激更容易触发）
- L2 前脑岛→内感受精度影响应激的方向选择(逃 vs 冻)
- L5 dlPFC→可以花认知槽主动压制应激（"我知道危险，但我不逃"）——占用 2 个槽

### 操作 2: 警觉 (Alert)

```
脑区: 上丘 (Superior Colliculus)
MNI:  (0, -32, -4) → 游戏 (0.00, 0.51, -0.22)
类型: 被动(始终生效)
```

**触发条件:**
- 始终生效——战斗开始时自动获得 1 层"警觉"标记
- 敌方隐藏属性/技能/意图被揭示时，额外获得 1 层

**效果:**
- 每层警觉标记:
  - 威胁检测距离 +1（更早看到敌方动作）
  - 对"突袭/埋伏"类敌方技能的闪避率 +10%
- 最多叠加 3 层
- 标记在战斗结束后清除

**AP 消耗:** 0（被动）
**认知槽占用:** 0（自动操作，不需要执行控制）
**冷却:** N/A（被动技能）

**设计依据:**
上丘接收视网膜直接输入(Glu)，是视觉-运动接口。投射至PAG启动逃逸——mSC→DPAG(Glu)触发无条件逃逸。Hansen2024: 上丘属GREEN社区。在感觉不安全时，感觉处理从上丘→PAG轴旁路绕过皮层。

**高层调制接口:**
- L3 V1→提供更精确的视觉信息，增加警觉标记获取速度
- L4 颞上沟→自动检测生物运动(意图感知)，触发警觉
- L5 dlPFC→主动扫描: 花 AP+1 个认知槽获取额外警觉标记

### 操作 3: 忍耐 (Endure)

```
脑区: 中缝背核 (Dorsal Raphe Nucleus)
MNI:  (0, -32, -14) → 游戏 (0.00, 0.39, -0.22)
类型: 被动 + 主动
```

**被动效果:**
- SAN 伤害减免: 每次受到 SAN 伤害时，减免 1 点（最低受到 1 点）
- "中缝核的 5-HT 系统过滤掉不重要的威胁信号"
- 认知槽占用: 0（自动运作）

**主动效果:**
- **精神防御**: 本回合 SAN 伤害被动减免从 -1 翻倍为 **-2**（最低仍受到 1 点）
- **压制恐慌强制**: 本回合恐慌触发阈值提高
- AP 消耗: 0
- 认知槽占用: 1（主动调动 5-HT 系统过滤威胁信号需要执行控制参与）
- 冷却: 2 回合

**设计意图:**
忍耐是精神攻击的唯一主动防御手段。精神攻击永远命中——但忍耐让你可以主动抵挡它。博弈不在"命不命中"，在时机：攻击方要猜对方这回合会不会激活忍耐（激活了=精神攻击浪费），防御方要判断对方是否在叠动机准备精神爆发（需要提前开忍耐保 SAN）。

**设计依据:**
中缝背核是脑内 5-HT 的主要源头。功能: 感觉门控、冲动抑制、攻击调节。Hansen2024: 中缝背核属PINK社区，是连接扣带皮层的关键 hub。PAG→中缝大核→脊髓的下行疼痛抑制通路——身体自带的镇痛系统。5-HT 耗竭 → 过度反应和攻击性。

**高层调制接口:**
- L1 缰核→失望信号抑制中缝核（"忍耐"被惩罚预期削弱）
- L2 ACC→冲突监测可触发忍耐的主动效果
- L2 满足→触发后忍耐主动的认知槽成本归零
- L4 正名→给痛苦一个名字，忍耐效果翻倍

### 操作 4: 激活 (Mobilize)

```
脑区: 蓝斑 (Locus Coeruleus)
MNI:  (-8, -34, -22) → 游戏 (-0.09, 0.31, -0.23)
类型: 主动
```

**触发:**
- 玩家主动使用

**效果:**
- 本回合:
  - 全局 AP 上限 +2（从 6→8）
  - 所有感知类技能（L3-L4）效果 +25%
  - 所有反射类技能冷却 -1
- 下回合（疲劳）:
  - AP 上限 -1（从 6→5，持续 1 回合）
  - 占用 1 个认知槽（蓝斑的 NE 耗竭后需要执行控制来补偿注意力）
  - "NE 的阶段性释放——phasic burst 之后必然进入 tonic low"

**AP 消耗:** 0
**认知槽占用:** 使用时不占槽（NE 是自动广播）; 疲劳回合占用 1 个槽
**冷却:** 3 回合

**设计依据:**
蓝斑是脑内 NE 的唯一源头。功能: 全局唤醒、警觉性、注意力切换。Hansen2024: 蓝斑属PINK社区，全脑最强 hub——NE投射到整个神经轴。LC phasic activation→增强感觉皮层信噪比。疲劳反映了 phasic burst 后的 refractory period。

**高层调制接口:**
- L1 BNST→持续焦虑让 LC 长期高 tonic，激活的疲劳惩罚加重（占用 2 个槽）
- L2 前脑岛→内感受精度影响激活效果（身体状态好→NE 利用效率高，疲劳槽不减）
- L5 dlPFC→可以有选择地激活（只提升特定感知，减少全面消耗，疲劳不占槽）

### 操作 5: 趋向 (Incline)

```
脑区: VTA (Ventral Tegmental Area)
MNI:  (0, -16, -12) → 游戏 (0.00, 0.42, -0.11)
类型: 被动(始终生效)
```

**效果:**
- 每回合开始时，角色获得一个"趋向"标记:
  - 趋近 (+1): 本回合主动技能的 offensive 效果 +10%
  - 回避 (-1): 本回合主动技能的 defensive 效果 +10%
  - 中立 (0):  无加成

**趋向方向由以下因素决定（优先级从高到低）:**
1. 上回合是否受到伤害 → 回避
2. 上回合是否成功命中 → 趋近
3. 上回合友方是否受伤 → 回避（如果 L1 共情已解锁）
4. 默认 → 中立

"VTA 不是纯粹的'奖励中心'——它编码的是动机突显，正负两面。你的身体在每一刻都有一种'想靠近'或'想远离'的倾向。"

**AP 消耗:** 0（被动）
**认知槽占用:** 0（自动运作）
**冷却:** N/A

**主动干预:**
- L5 vmPFC 解锁后，可以花 1 个认知槽主动设定本回合趋向方向（无视情境）
- "你可以选择你想靠近什么、远离什么——但这需要认知控制"

**设计依据:**
VTA 是脑内 DA 的主要源头之一。功能: 动机突显(正/负)。Hansen2024: VTA属GREEN+BLUE社区。VTA不编码"快乐"——它编码"这个刺激值得我行动"。厌恶刺激也激活VTA(通过投射至mPFC和BNST)。

**高层调制接口:**
- L1 NAcc→奖励预期增强趋近方向的加成
- L1 缰核→惩罚预期增强回避方向的加成
- L5 vmPFC→主动设定趋向方向（占用 1 个认知槽）

### 操作 6: 熟练 (Proficiency)

```
脑区: 小脑皮层 (Cerebellar Cortex)
MNI:  (-32, -58, -28) → 游戏 (-0.36, 0.24, -0.39)
类型: 被动(始终生效)
```

**效果:**
- 连续使用同一主动技能时:
  - 第 2 次连续使用: AP 消耗 -1
  - 第 3 次连续使用: AP 消耗 -1（再减1） + 冷却 -1
  - 第 4 次及以后: 维持第 3 次减免（不再累加）

- 切换技能 → 重置连续计数。
- "小脑的内部模型——你做得越多，它越替你接管。不需要前额叶参与了，身体自己知道怎么做。"

**AP 消耗:** 0（被动）
**认知槽占用:** 0（自动运作——甚至"释放"认知槽：熟练的技能不再需要执行控制参与）
**冷却:** N/A

**熟练释放认知槽:**
- 当某个技能连续使用达到第 3 次时，使用该技能不再占用认知槽（如果原来占用的话）
- "习惯化的本质——从需要 dlPFC 参与的策略性选择，退化为小脑+壳核的自动执行"

**设计依据:**
小脑功能: 预测、时序、内部模型、动作自动化。CSTC环路: 从联合环路(dmStr)→感觉运动环路(dlStr)的转移是小脑和基底节协同完成的——Baladron2020的捷径连接概念。Magrou2024: 小鼠棘密度无梯度(习惯化浅)，灵长类有陡峭梯度。

**高层调制接口:**
- L1 壳核→CSTC感觉运动环路，与熟练协同加速习惯化（第2次就触发AP减免）
- L5 dlPFC→可以花 1 个认知槽"打断"连续使用计数（重置为1）——"不要让身体替你做所有决定"

## 三、恐慌强制规则

```
恐慌强制触发条件: SAN < 30% 或 HP < 25%
  ↓
裁决优先级:
  1. 应激反应（最高优先——身体会先保护自己）
  2. 忍耐（中缝核试图抑制过度反应）
  3. 激活（如果认知槽有空余，蓝斑自动触发激活以应对危机）
  ↓
玩家选择:
  忍耐主动效果可用 且 认知槽有空余 → 可压制恐慌 1 回合
  忍耐冷却中 → 无法压制，必须从恐慌选项中选择
  忍耐可用但认知槽已满 → 无法压制（没有足够的心力）
  不选 → 必须从恐慌强制的选项中选 1 个执行

注意: 压制恐慌 = 忍耐的主动效果。冷却中不可用，与槽位状态无关。
      槽位只是额外条件——两者都要满足才能压制。
```

| 恐慌阶段 | SAN 阈值 | 强制效果 | 认知槽需求 |
|---------|---------|---------|----------|
| 轻度不安 | SAN < 50% | 趋向自动变为"回避"（不可主动设为趋近） | 0 |
| 恐慌边缘 | SAN < 30% | 必须使用 应激反应 或 忍耐(主动) 之一 | 压制需 1 槽 |
| 彻底崩溃 | SAN < 15% | 应激反应 自动触发（不占槽位），**不可压制** | 压制无效 |

## 五、L0 参与的链路（与更高层级的连接）

L0 基底操作参与的核心链路——哪些 L1 调制建立在这些 L0 操作之上：

| L0 操作 | → L1 链路 | 调制方式 |
|---------|------------|---------|
| 应激反应 | 杏仁核(恐惧条件化) | 降低触发阈值——更容易应激 |
| 应激反应 | BNST(持续警觉) | 延长应激状态持续时间 |
| 警觉 | 海马(回忆) | 见过的东西→更快触发警觉 |
| 忍耐 | 缰核(失望) | 惩罚预期削弱忍耐效果 |
| 忍耐 | 隔区(满足) | 奖励后忍耐的主动效果不占认知槽 |
| 激活 | BNST(焦虑) | 焦虑让激活疲劳加重（占 2 槽） |
| 激活 | 下丘脑(稳态) | 身体状态好→激活效果 +20% |
| 趋向 | NAcc(期待) | 奖励预期强化趋近的加成 |
| 趋向 | 缰核(失望) | 惩罚预期强化回避的加成 |
| 熟练 | 壳核(习惯) | CSTC 环路加速连续使用的 AP 减免 |
| 熟练 | 尾状核(策略) | 切换策略时保留 1 层连续计数 |
