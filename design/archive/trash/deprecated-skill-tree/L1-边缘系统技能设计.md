# L1 边缘系统调制 — 情绪着色与经验记录

> L0 的反射是盲目的——不区分"是什么威胁"、"上次遇到同样的结果是什么"。L1 提供**情绪着色**和**经验记录**。L1 的核心功能是**调制 L0 基底操作的触发条件和效果强度**。L1 调制不消耗激活点——由情境自动激活（回忆除外），体现为链路的髓鞘化程度变化。
>
> **设计原则**: L1 调制不替代 L0——它们改变 L0 如何、何时、以多大强度被触发。链路的反复使用 → 髓鞘化 → 调制增强。

## 一、L1 调制总览

21 个 L1 脑区中，合并近似结构后产生 **8 种链路调制**（7 被动 + 1 主动）：

| # | 调制 | 脑区 | 性质 | 激活点 | → 调制的 L0 操作 |
|---|------|------|------|--------|-----------------|
| 1 | **恐惧条件化** | 杏仁核 + BNST | 被动学习 | 0（自动） | 应激反应: 降低触发阈值 |
| 2 | **回忆** | 海马 CA1 + 杏仁核-海马 | 主动 | 1 | 警觉: 熟悉威胁→更快触发 |
| 3 | **辨别** | 海马 CA3 | 被动 | 0（自动） | 警觉: 减少误报 |
| 4 | **识景** | 内嗅皮层 + 海马旁回 | 被动 | 0（自动） | 应激反应: 场景调整触发条件 |
| 5 | **期待** | NAcc + 腹侧纹状体 | 被动学习 | 0（自动） | 趋向: 强化趋近加成 |
| 6 | **失望** | 缰核 | 被动学习 | 0（自动） | 趋向: 强化回避; 忍耐: 削弱效果 |
| 7 | **满足** | 隔区 | 被动条件 | 0（自动） | 忍耐: 满足时压制的槽位成本归零 |
| 8 | **习惯化** | 壳核 + 苍白球 | 被动始终 | 0（自动） | 熟练: 加速 AP 减免 |

**不产生独立调制的 L1 结构：**

| 结构 | 原因 |
|------|------|
| 尾状核 | 并入 L5 策略选择（联合环路的目标导向端） |
| 丘脑 / 丘脑枕 | 感觉中继基础设施，不产生独立调制 |
| 纹状体基质 | CSTC 基质，作为链路连接通路 |
| 基底节间接通路 | 动作抑制通路，并入"习惯化" |
| 下丘脑 | 稳态调节太基础，作为全局被动（非战斗调制） |
| 全脑整合 | 归类到 L6（富俱乐部），不属于 L1 |
| NAcc壳/核, 伏隔核/NAcc, 腹侧纹状体 | 合并为"期待"——同属 NAcc/腹侧纹状体复合体 |

## 二、调制设计

### 调制 1: 恐惧条件化 (Fear Conditioning)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: 杏仁核 + BNST
MNI:  杏仁核 (-22, -4, -18) → 游戏 (-0.37, 0.16, -0.07)
      BNST   (-6, 2, 0)     → 游戏 (-0.07, 0.55, 0.01)
类型: 被动(学习型)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**学习机制:**
- 战斗中每次受到同类型伤害 → 该伤害类型获得 1 层"恐惧标记"
- 恐惧标记持续整场战斗
- 每层标记 = 对含该伤害类型的敌方技能，应激反应的触发阈值 +3%（从 HP<40% → HP<43% → HP<46% → HP<49%）
- 最多 3 层

**效果:**
- 被标记的伤害类型触发时，应激反应自动闪避率 +10%/层
- "杏仁核学会了——这种痛下次要更快躲开"

**BNST 扩展（持续性焦虑）:**
- 恐惧标记 ≥ 3 层时（即已叠满），BNST 激活
- 激活时：忍耐的被动 SAN 减免从 -1 变为 -0（"焦虑让5-HT系统超载，感官门控失效"）
- 激活时：激活技能的疲劳惩罚加重（下回合占 2 个槽而非 1 个）
- BNST 激活持续到战斗结束或用 L5 技能压制

**AP 消耗:** 0（被动学习，自动运作）
**认知槽占用:** 0
**冷却:** N/A

**设计依据:**
杏仁核: 恐惧条件化的核心——LeDoux (2000) 的双通路模型：快速通路(丘脑→杏仁核，~12ms) 和慢速通路(丘脑→皮层→杏仁核，~30-40ms)。BNST: 持续性焦虑(phasic fear=杏仁核, sustained anxiety=BNST)。Davis et al. (2010): BNST 被 CRH(促肾上腺皮质激素释放激素)激活，产生"弥漫性不安"而非"明确的恐惧"。

### 调制 2: 回忆 (Recall)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: 海马 CA1 + 杏仁核-海马
MNI:  海马 CA1 (-26, -18, -18) → 游戏 (-0.37, 0.26, -0.19)
类型: 主动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**
- 从部分线索恢复完整的战斗记忆
- 主动使用：
  - 如果敌方在场且之前遇到过 → 揭示敌方 1 个隐藏属性（抗性/弱点/技能冷却）
  - 如果之前在同一场景战斗过 → 揭示场景中的 1 个可交互元素
  - 如果之前见过敌方某个技能 → 本回合对该技能的闪避率 +20%

**AP 消耗:** 1
**认知槽占用:** 1（主动回忆需要执行控制参与）
**冷却:** 3 回合

**对 L0 的调制:**
- 解锁后永久：见过一次的东西再次出现 → 警觉自动获得 1 层标记
- "海马的 pattern completion——部分线索触发完整记忆"

**设计依据:**
海马 CA1: 模式完成(pattern completion)——从部分输入恢复完整记忆表征。CA1 接受 CA3 的 Schaffer collateral 输入和內嗅皮层的直接 perforant path 输入。杏仁核-海马: 情绪记忆的巩固节点——情绪事件优先被海马编码。

### 调制 3: 辨别 (Discriminate)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: 海马 CA3
MNI:  (-28, -22, -16) → 游戏 (-0.37, 0.26, -0.19)
类型: 被动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**
- 被动减少误报——"这次和上次不一样"
- 当敌方使用与之前相似的（但不完全相同的）"威胁"标签技能时：
  - 不会被恐惧条件化错误触发（避免"一朝被蛇咬，十年怕井绳"）
  - 应激反应的"敌方释放威胁标签"触发条件不会因相似但不同的威胁标签而误触发
  - "那个敌人在虚张声势——和上次真正伤害我的东西不一样"
- 具体表现为：同伤害类型但不同来源的威胁 → 恐惧标记获取速度 -50%（需要更多证据才学会恐惧）

**对 L0 的调制:**
- 叠加在恐惧条件化上——"学会了恐惧，但也学会了什么时候不该恐惧"
- 警觉的假阳性率 -30%（"那个影子不是敌人"）

**AP 消耗:** 0（被动）
**认知槽占用:** 0
**冷却:** N/A

**设计依据:**
海马 CA3: 模式分离(pattern separation)——将相似但不相同的经验编码为不同的记忆表征。CA3 的 recurrent collateral 网络通过 DG(齿状回)的稀疏编码实现模式分离。没有 CA3，人会把所有相似的经验都混在一起。

### 调制 4: 识景 (Recognize Scene)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: 内嗅皮层 + 海马旁回
MNI:  内嗅皮层 (-24, -10, -30) → 游戏 (-0.37, 0.00, -0.07)
      海马旁回 (-28, -36, -18) → 游戏 (-0.31, 0.35, -0.24)
类型: 被动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**
- 进入战斗场景时自动识别场景类型
- 场景类型决定该场景中哪些 L0 反应的触发阈值默认偏高/偏低：
  - 治疗室/安全场景 → 应激反应的触发阈值 +15%（更不容易恐慌）
  - 威胁场景/镜子房间 → 应激反应的触发阈值 -10%（更容易恐慌）
  - 陌生场景 → 警觉自动获得 1 层标记（"新地方，保持警惕"）

**AP 消耗:** 0（被动）
**认知槽占用:** 0
**冷却:** N/A

**设计依据:**
海马旁回: 场景识别(PPA = Parahippocampal Place Area)，专门处理空间布局和场景类别。内嗅皮层: 空间导航的网格细胞(grid cells)所在地——Nobel Prize 2014 (Moser & Moser)。两者共同提供"我在什么地方、这个场景意味着什么"的信息。

### 调制 5: 期待 (Anticipate)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: NAcc + 腹侧纹状体 (伏隔核/NAcc 复合体)
MNI:  (-10, 10, -8) → 游戏 (-0.14, 0.28, 0.05)
类型: 被动(学习型)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**学习机制:**
- 战斗中成功命中敌方 → 对该类型的敌方获得 1 层"期待标记"
- 每层期待标记 = 趋向 的"趋近"方向加成 +5%（从 +10% → +15% → +20%）
- 最多 2 层
- "NAcc 学会了——打中它是有回报的，下次更想靠近"

**额外效果:**
- 期待标记 ≥ 2 层时，L3-L4 的主动感知技能 AP -1
- "期待让注意力聚焦——你的大脑已经把资源预分配到可能获得奖励的方向上"

**AP 消耗:** 0（被动学习）
**认知槽占用:** 0
**冷却:** N/A

**设计依据:**
NAcc: 奖赏预期和动机出力。Schultz et al. (1997) 的多巴胺奖励预测误差——多巴胺不是编码"快乐"，而是编码"比预期好"(正RPE)或"比预期差"(负RPE)。期待标记体现的是正 RPE 累积。腹侧纹状体: 激励突显(incentive salience)——Berridge & Robinson (1998)的"想要(wanting)"vs"喜欢(liking)"区分。

### 调制 6: 失望 (Disappointment)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: 缰核 (Habenula)
MNI:  (-4, -24, 2) → 游戏 (-0.04, 0.57, -0.16)
类型: 被动(学习型)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**学习机制:**
- 战斗中主动技能未命中 / 被闪避 / 被抵抗 → 获得 1 层"失望标记"
- 每层失望标记：
  - 趋向 的"回避"方向加成 +5%（从 +10% → +15% → +20%...）
  - 忍耐 的被动 SAN 减免效果 -1/层（"惩罚预期削弱了5-HT系统"）
- 最多 3 层
- 在 ≤ 1 层时（失望不太多），可以花 1 个认知槽压制失望的趋向偏移

**特殊交互:**
- 失望 3 层 + HP < 25% → 习得性无助风险
  - 忍耐的主动效果（压制恐慌）冷却 +2
  - 需要 L2 冲突感知 或 L5 换位 来解除
- "缰核是反奖赏中心——当世界持续辜负期待，它告诉大脑'别试了'"

**AP 消耗:** 0（被动学习）
**认知槽占用:** 0（自动运作）; 压制失望趋向偏移需 1 槽
**冷却:** N/A

**设计依据:**
缰核: 惩罚预期和失望信号。Matsumoto & Hikosaka (2007): 灵长类缰核神经元在被期待但未获得的奖赏时强烈放电——"负奖赏预测误差"的核心。缰核通过抑制 VTA DA 释放→降低动机。Hikosaka (2010): 外侧缰核→GABA→VTA的通路是"反奖赏"通路。缰核过度激活=抑郁的动物模型。

### 调制 7: 满足 (Satisfaction)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: 隔区 (Septal Region)
MNI:  (0, 4, -2) → 游戏 (0.00, 0.53, 0.03)
类型: 被动(条件触发)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**触发条件:**
- 本回合成功完成以下之一：
  - 击杀敌方
  - 成功保护友方
  - 揭示敌方全部隐藏属性
  - 压制恐慌强制

**效果:**
- 触发后，下回合：
  - 忍耐的主动效果（压制恐慌）不再占用认知槽
  - 忍耐的被动 SAN 减免 +1（额外减免，从 -1 变为 -2）
  - "满足感释放了5-HT——你不需要再绷那么紧了"

**持续时间:** 1 回合（满足是短暂的）

**AP 消耗:** 0（被动）
**认知槽占用:** 0

**设计依据:**
隔区: 快感、社交奖励、攻击抑制。Olds & Milner (1954) 的经典自我电刺激实验——大鼠宁愿放弃食物去按压刺激隔区的杠杆。隔区→下丘脑→脑干的通路抑制防御反应。隔区在哺乳动物中高度保守——社交满足和奖励终止信号的核心。

### 调制 8: 习惯化 (Habituation)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: 壳核 + 苍白球 (CSTC 感觉运动环路)
MNI:  壳核 (-26, 0, 4)   → 游戏 (-0.29, 0.59, 0.00)
      苍白球 (-20, -4, -4) → 游戏 (-0.22, 0.51, -0.03)
类型: 被动(始终生效)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**
- 加速 L0"熟练"技能的 AP 减免速度：
  - 没有习惯化时：第2次连续使用 AP-1, 第3次 AP-1+CD-1
  - 有习惯化时：**第1次重复**（即第2次使用）就触发 AP-1，第2次重复就触发 AP-1+CD-1
- "CSTC 环路建立了捷径——从策略到习惯只需要一次重复"

**代价:**
- 习惯化生效时，主动打破连续使用计数的认知槽成本从 1 变为 2
- "习惯越深，越难用意志打破"

**AP 消耗:** 0（被动）
**认知槽占用:** 0（甚至释放槽——习惯化的技能不占认知槽）

**设计依据:**
Baladron et al. (2020): CSTC环路的"捷径连接"——从联合环路(dmStr/尾状核)→感觉运动环路(dlStr/壳核)的螺旋连接使行为从目标导向退化为自动执行。Cruz et al. (2023): 苍白球是基底节的最终输出核，通过抑制丘脑来门控运动。习惯化的神经基础=皮层→dlStr→苍白球外部→丘脑下核→苍白球内部的间接通路。

## 四、被动效果汇总

| 技能 | 触发 | 效果 | 认知槽占用 |
|------|------|------|----------|
| 恐惧条件化 | 受同类伤害 | 应激触发阈值 +5%/层 (max 4层) | 0 |
| BNST 激活 | 恐惧标记 ≥3 | 忍耐 SAN减免失效; 激活疲劳加重 | 0 |
| 回忆 | 主动使用 | 揭示隐藏属性 / 对该技能闪避+20% | 1（主动时） |
| 回忆(被动) | 见过的东西再现 | 警觉自动 +1标记 | 0 |
| 辨别 | 始终 | 假阳性 -30%, 误触发防护 | 0 |
| 识景 | 进入场景 | 场景类型→调整应激阈值或警觉 | 0 |
| 期待 | 成功命中 | 趋近加成 +5%/层 (max 3层) | 0 |
| 失望 | 技能被挡 | 回避加成 +5%/层; 忍耐削弱; 3层+低HP→习得性无助 | 0（压制需1槽） |
| 满足 | 成功完成关键行动 | 下回合忍耐压制槽位→0; SAN减免+1 | 0 |
| 习惯化 | 始终 | 熟练AP减免加速1步; 打破习惯槽位成本→2 | 0 |

## 五、L1 与 L2 的接口

| L1 技能 | → L2 调制者 | 调制方式 |
|---------|------------|---------|
| 恐惧条件化 | ACC(冲突感知) | 冲突→恐惧标记获取暂停（"等一下，这可能不是威胁"） |
| 恐惧条件化 | 前脑岛(内感受) | 内感受精度↑→分辨"恐惧"vs"兴奋"（心跳快≠危险） |
| 回忆 | ACC背侧(努力评估) | 回忆的认知槽成本随努力评估波动 |
| 期待 | OFC(价值比较) | 多目标时，价值比较决定哪个方向强化更多 |
| 失望 | ACC(冲突感知) | 3层失望时的习得性无助可由冲突感知触发自救 |
| 失望 | 后扣带(内省) | 内省可主动清除失望标记 |
| 满足 | 颞极(识人) | 社交场景中的满足效果扩展到友方 |
| 习惯化 | ACC(冲突感知) | 习惯化的技能在冲突中被自动中断→重置计数 |
