## 一、盘点方法与基准

- **基准**：正典文档 + data/ JSON 为正确基准（用户裁定 A+B）；正典内部冲突按决策树最新裁决（#25/#26/#32/#33 的 2026-08-13 🔧 修正行）
- **判定值**：✅一致 / ⚠️偏差（存在但不影响正确性）/ ❌冲突（与正典不符）
- **偏差类型**：`[NEW]占位` / `过时公式` / `待校准` / `结构不匹配` / `文档过时` / `legacy残留`
- **引用即读取铁律**：每条判定有 Read 证据（`源文件.cs:行号` + `正典/数据 行号或段引用`）
