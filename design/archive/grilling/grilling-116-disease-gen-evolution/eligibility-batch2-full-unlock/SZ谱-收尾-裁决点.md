## 裁决结果（6 项照准）

1. **通道修正（全族）**：偏执/未分化 SZ：B → **A 临床史主导**（幻觉/妄想非记忆形态 C4 + 威胁事件门与 PTSD 共享致高 F 混淆 C5）；分裂型：B → **A 模式声明**（语义锚取 DSM 人格障碍模式，非 ICD-11 6A22——分裂型永不满足 SZ A）；分裂情感：C 混合确认（成分声明化）
2. **三单宽原子（BPD 配方：复合条件判定留 #87 声明侧）**：`SZ_POSITIVE_COURSE_HISTORY`（偏执/未分化共享）/ `STPD_PATTERN_HISTORY`（分裂型）/ `SZAFFECTIVE_COURSE_HISTORY`（分裂情感）
3. **亚型不做资格级区分**（DSM-5 删亚型精神）：偏执/未分化共享签名；差异由事件召回（威胁/慢性 vs 社会伤害/公开羞辱）+ 主病选择表征 sim 承载（design/presentation/聚合层）
4. **无硬排除原子**：物质/躯体所致（SZ E）+ BD-I/MDD 伴精神病性分流 = 声明侧纪律（复用 MANIA/DEPRESSIVE 交叉）
5. **表征域（F）仅起草侧/主题级证据**（创伤主题渗入幻觉内容），不进资格门
6. **Varese 勘误执行**：转化接口 §3.2.1 两处 + 决策树 :3182——OR 2.87 → 总体 **2.78**（95% CI 2.34-3.31；2.87 为性虐待亚组 CI 上界，性虐待 OR=2.38）✅ 已改

## 反样本自检（通过）

短暂精神病性（<1月）/分裂样（1-6月）→ 病程留声明侧；物质所致 → 声明侧 E；BD-I/MDD 伴精神病性 → 无独立阳性病程声明 → BD 轨道（MANIA/DEPRESSIVE 分流）；PTSD 再体验 → F 门不用于 SZ，无混淆；分裂型应激短暂体验 → 非活动期（模式声明排除）；PPD/分裂样/社恐/ASD → 无认知-知觉簇或发育性（模式声明/发育轨拦截）；文化/哀伤/睡眠知觉现象 → 声明侧文化限定。

## 判定结构（定稿形式）

```
Eligibility(偏执/未分化 SZ) = 召回门（事件类型 ∈ 亚型召回集）∧ SZ_POSITIVE_COURSE_HISTORY = 1

Eligibility(分裂情感)       = 召回门（忽视/遗弃）∧ SZAFFECTIVE_COURSE_HISTORY = 1

```
