## 裁决结果（6 项照准）

1. **通道确认**：A 临床史主导（三病无 DSM 记忆形态标准；E_d^mem 仅对照）
2. **六共享域原子（#87 存在性声明，条内判定留声明侧）**：BINGE_HISTORY / COMPENSATORY_BEHAVIOR_HISTORY（域级非清除级——无清除 BN 合法）/ LOW_WEIGHT_PATTERN / WEIGHT_GAIN_PREVENTION / BODY_IMAGE_DISTURBANCE / BED_DISTRESS_PATTERN
3. **每病 AND 组合**：
   - AN = LOW_WEIGHT_PATTERN ∧ WEIGHT_GAIN_PREVENTION ∧ BODY_IMAGE_DISTURBANCE
   - BN = BINGE_HISTORY ∧ COMPENSATORY_BEHAVIOR_HISTORY ∧ BODY_IMAGE_DISTURBANCE（频率留声明侧）
   - BED = BINGE_HISTORY ∧ BED_DISTRESS_PATTERN（"无规律补偿" = 声明侧排除语义，不设硬排除原子）
4. **无硬排除原子**：AN-BP 低体重分流 / MDD·双相发作内暴食分流 = 声明侧纪律（发作史原子交叉）；躯体他因/ARFID/运动员表现型由怕胖/体像域拦截
5. **召回门**：事件类型 ∈ 各病 C(e) 集（AN: 性创伤/控制剥夺；BN/BED: 性创伤/社会伤害/公开羞辱）
6. **MISSING → UNDETERMINED；任一必要域 =0 → INELIGIBLE**

## 反样本自检（通过）

ARFID/躯体低体重/运动员表现型（无怕胖/体像 → AN 拦）；MDD 非典型/双相暴食（无失控感 + 发作结构 → 发作史原子分流）；AN-BP（含 LOW_WEIGHT → AN 轨道）；大食者/肥胖（无失控感 → BINGE 拦）；SRED（无意识 → 声明侧拦）；NES（研究候选，日间失控暴食判别）。
