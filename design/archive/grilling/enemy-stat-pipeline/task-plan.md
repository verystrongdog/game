## 一、概览

### 输入

- 19 种疾病文件（`design/entities/diseases/*.md`）— 每个包含功能域 m 偏移表 + 默认标签 + 行为覆盖 + 非线性跳变 + 组件掉落池 + CGI-S 域扩展表
- 6 性格标签（`data/connectivity/personality_tag_links.json`）— 每个标签 → 15 核心链路 + 连带偏移 ±0.15
- 5 类敌人来源 × 3 级 CGI-S × 19 种疾病（`design/entities/敌人与事件.md` §4.1）— HP/SAN 数值范围
- 空间遭遇数据（`design/space/空间与关卡设计.md` §七）— 楼层密度 + 来源构成
- 364 链路 + 13 功能域（`data/connectivity/link_registry.json`）

### 输出

- 每份人设 → 一个完整 Stat Block（身份/脑区配置/数值基线/情境响应/特殊规则五层结构，定义于 `design/entities/敌人与事件.md` §4.2）
- 杂兵：纯模板生成。精英：模板 + MSE/风险评估字段微调
- 最终数据格式：JSON（`data/enemies/stat_blocks/*.json`），供预烘焙管线消费

### 管线阶段

```
阶段 1: 人设编写（人类/AI 内容生产）
   → 阶段 2: 人设 → 数值映射（AI + 脚本 build_enemy_stats.py）
   → 阶段 3: 预烘焙管线查表（bake_npc_behavior.py）
   → 阶段 4: 校验（validate_enemy_stats.py）
```

### 敌人来源与人设模板对应

| 敌人来源 | 人设格式 | 叙事来源字段 |
|---------|---------|------------|
| 精神病人 | 完整 13 节病历（§二.A） | `病人` |
| 思维造物 | 精简卡片（§二.B） | `思维造物` |
| 医疗人员 | 精简卡片（§二.C） | `医疗人员` |
| 拜月教徒 | 双面模板（§二.D） | `拜月教徒` |
| 动物 | 延期独立设计 | `动物` |

## 二、敌人人设模板

### A. 精神病人 — 完整病历格式

基于标准精神科入院评估（Psychiatric Intake Evaluation）13 节格式，按游戏需求精简调整：

```yaml
# ===== 敌人病历模板 =====

基本信息:
  姓名化名: <首字母缩写-编号，如 MG-054>
  年龄/性别: <如 54/F>
  原职业: <入院前最后职业>
  居住情况: <独居/与家人/无固定住所/集体居住>
  转诊来源: <社区精神卫生队/综合医院急诊/警察/自行/其他>

主诉: "<患者原话引用>"

现病史:
  <症状发展时间线——从触发事件到入院当日。>
  <格式：入院前 N 天——事件描述。按时间倒序。>

既往精神病史:
  诊断: <有/无，列出具体诊断与年份>
  住院: <次数，最近日期>
  自杀企图: <有/无，方法简述>

物质使用史:
  酒精: <频率，量，最后使用>
  烟草: <频率，量>
  其他: <大麻/阿片类/兴奋剂/苯二氮䓬类等，逐一标明>

躯体病史:
  <可能影响精神状况的躯体疾病。慢性病/脑外伤/癫痫/甲状腺等。>

社会与发展史:
  教育: <最高学历或相当经历>
  职业轨迹: <关键职业节点，含失业期>
  关系: <婚姻/伴侣/子女/主要社会关系>
  创伤史: <躯体/性/情感虐待，忽视，事故，暴力目击，战争>
  法律史: <有/无，简述>

精神状态检查:
  外表: <衣着/卫生/与年龄相符程度>
  行为:
    自由描述: <精神运动活动/眼神接触/对环境的反应/异常动作>
    战斗标签: <多选：惊跳反应 / 精神运动迟缓 / 精神运动激越 / 刻板动作 / 无异常>
  言语:
    自由描述: <语速/音量/连贯性/特殊性>
    战斗标签: <多选：言语压迫 / 缄默 / 无异常>
  心境（自述）: "<患者对自身情绪状态的描述>"
  情感（观察）:
    自由描述: <范围/稳定性/与心境和思维内容的一致性>
    战斗标签: <多选：情感平淡 / 情感不稳定 / 无异常>
  思维过程:
    自由描述: <线性/离题/松弛/阻滞/语词杂拌>
    战斗标签: <多选：思维阻滞 / 离题 / 无异常>
  思维内容:
    自由描述: <妄想/强迫/恐惧/先占观念。具体内容如有需引用>
    战斗标签: <多选：妄想 / 强迫思维 / 无异常>
  感知:
    自由描述: <幻觉类型/内容/频率。现实解体/人格解体>
    战斗标签: <多选：幻觉·有 / 无异常>
  认知:
    自由描述: <定向力/注意力/记忆力/抽象思维>
    战斗标签: <多选：定向力受损 / 注意力分散 / 记忆力受损 / 无异常>
  自知力: <对自身精神疾病的认识程度。较好 / 部分 / 有限 / 缺乏>

风险评估:
  自杀: <否认/被动意念/主动意念/有计划/有企图>
  伤人: <否认/意念/威胁/行为>

诊断印象:
  轴I: <DSM-5 诊断 + ICD-10 编码>
  严重度: <CGI-S N（3-7）>

战斗标签: <1-2 个，6 选：敏化-威胁/敏化-奖励/抑制不足/过度抑制/反刍/社交钝化>
```

**DID 病人扩展**：标准 13 节后追加以下 Alter 系统段：

```yaml
# ===== DID 病人 — 标准13节之后追加 =====

Alter系统:
  Alter数量: <2 / 3 / 4 — CGI-S: 中=2, 重=3-4>
  默认Alter: <Alter名称 — 入院时前台人格>

  Alter列表:
    - Alter名称: "<自称名>"
      系统角色: <Host / Protector / Persecutor / Child / 
                 Caretaker / Gatekeeper / Memory Holder / 
                 Introject / Fragment>
      自称年龄: <可能与身体年龄不同>
      自称性别: <可能与身体性别不同>
      形成原因: <1-2句——临床描述，非故事化>
      主触发: <1个情境/刺激>
      次触发: <1-2个，可选>

      功能域配置:                      ← 独立 m 偏移表
        同疾病文件格式。Host Alter 可标注"见疾病文件"
        其他 Alter 列出 3-10 条与此 Alter 相关的链路

      标签: <1-2个>
      行动偏好: {物理攻击: N, 精神攻击: N, 防御: N, 趋近: N, 回避: N}
      恐慌行为: {僵住: N%, 回避: N%, 防御: N%, 攻击: N%, 随机反射: N%}

系统层:
  切换过渡回合: 1（固定）
  切换SAN波动: -5（固定）

  记忆共享:
    - Alter对: [Alter1名, Alter2名]
      方向: <完全 / 部分 / 单向 — 单向需标注方向: A→B>

  共意识:
    - Alter对: [Alter1名, Alter2名]    ← 可同时感知外部世界的 Alter 对
```

**编写原则**：
- **客观描述**，不添加"坚强""不幸"等主观评价
- **主诉**必须引用患者原话，即使逻辑混乱
- **现病史**按时间倒序，每行以"入院前 N 天——"开头
- **精神状态检查**：自由描述保持临床报告风格，战斗标签为结构化枚举（脚本直接读取，不解析自由文本）
- 所有时间、剂量、次数使用精确数字（如有），否则标注"不详"

### B. 思维造物 — 精简卡片

```yaml
[思维造物卡片]

来源病人: <病人化名-编号>
造物等级: <投影 / 碎片 / 完整体>
核心意象: <2-3 句——这个造物是病人什么精神内容的投射>
  例: "病人对弟弟照护失败的恐惧具象化——一个始终背对观者的
       模糊人形，不断重复弯腰搀扶然后手中之人滑落的动作。"
行为模式: <2-3 句——战斗中的行为特征>
```

**造物 m 偏移继承规则**：

| 造物等级 | m 偏移 | 标签 | 行为表 |
|---------|--------|------|--------|
| **投影** | 直接拷贝来源病人的 m 偏移——仅激活核心域（表 B 核心域），关联域和边缘域 m=0 | 继承病人全部标签 | 单一固定模式——只执行一种行为序列循环 |
| **碎片** | 拷贝来源病人的 m 偏移（全量，含关联域） | 从病人标签中抽取 1 个（最突出的），独立骰连带偏移 | 父类模板（按来源病人父类）——有自保本能 |
| **完整体** | 完全独立——独立标签（1-2个）+ 独立 m 偏移（标签偏移+疾病配置重新生成，不拷贝病人数值） | 1-2 个独立标签，可不同于病人 | 独立行为表（同病人精英规则） |

逻辑：投影=疾病影子（完全跟病人走）；碎片=疾病的一个侧面（部分独立）；完整体=独立个体（不拷贝）。

## 三、病历 → Stat Block 映射规则

Stat Block 五层结构定义见 `design/entities/敌人与事件.md` §4.2。以下逐层定义人设字段到 stat 字段的映射。

### 3.1 身份层

| 人设字段 | Stat 字段 | 映射规则 |
|---------|----------|---------|
| 人设类型（A/B/C/D） | 叙事来源 | 病人/思维造物/医疗人员/拜月教徒 — 由人设模板决定 |
| 诊断印象.轴I（病人） / 原身份（教徒） | 具体原型 | 诊断名 + 亚型标记（如 `GAD·照护者型`） |
| 诊断印象.严重度 | 病情等级 | CGI-S 3-4 → 轻度, 5 → 中度, 6-7 → 重度 |

### 3.2 脑区配置层

#### 3.2.1 m 偏移公式

```
最终 m = 0.0 + Δm_disease(直接查功能域配置表) + Δm_tag(标签偏移)
```

**Δm_disease — 查疾病文件 `功能域配置` 表**：

| 规则 | 说明 |
|------|------|
| 查表方式 | 直接取对应严重度列（轻/中/重）的 m 偏移值。**不乘 CGI-S 倍率**——表中的值已是最终值 |
| 域门控 | 查表 A 之前，先用表 B（`CGI-S 域扩展`）过滤——只激活核心域和关联域中列出的链路。边缘域的链路在对应严重度下 m 偏移强制为 0 |
| m倍率列 | 降级为设计参考注释——记录功能域配置值是怎么推导出来的，不参与运行时计算 |

**疾病文件两张表的分工**：

| | 表 A（功能域配置） | 表 B（CGI-S 域扩展） |
|---|---|---|
| 提供 | 每条链路的 m 偏移终值 | 域激活门控（核心/关联/边缘）+ 域数 |
| 消费方 | m 偏移查表 | 决定哪些链路受疾病影响、哪些归零 |

**Δm_tag — 查 `personality_tag_links.json`**：

| 规则 | 说明 |
|------|------|
| 查表方式 | 6 标签 × 15 核心链路 × 连带偏移 ±0.15 |
| 多标签叠加 | 取绝对值最大者，不累加（复用 `NPC AI 行为模型.md` §4.2） |

#### 3.2.2 m 天花板（拮抗对链约束）

```
拮抗对链 m 总和 ≤ 1.4（全局约束）
超限处理: 截断低侧——保留高优先级链路的 m 值，削低优先级链路的 m 值至满足 ≤ 1.4
优先级规则（从高到低）:
  1. 疾病偏移 > 标签偏移
  2. 绝对值大的 > 绝对值小的
  3. 正偏移 > 负偏移
截断后记录 WARNING 日志（"链路 X 被天花板截断：原值 m=N → 截断至 m=N"）
```

**拮抗对数据源**：定义于 `data/connectivity/antagonist_pairs.json`（自动生成 + 手工补充），分四层：

| 层级 | 拮抗关系 | 自动/手工 | 文献 |
|------|---------|:---:|------|
| 网络级 | DMN+OFC↔dlPFC — DMN↔FPN 反相关 | 自动（同对链路双方向互指） | Fox & Raichle (2005) *PNAS* |
| 通路级 | 直接通路(壳核→GPi) ↔ 间接通路(壳核→GPe) — Go/NoGo | 自动（D1/D2 受体分离，Gerfen 2023） | Kravitz et al.; *eLife* 2020 |
| 核团级 | VTA→NAcc ↔ CeA→PAG（奖赏↔防御）/ LC→杏仁核 ↔ DRN→杏仁核（交感↔副交感）/ BLA→NAcc ↔ BLA→CeA | 手工补充 | Yau et al. (2024) *J Neurosci*; Loonen & Ivanova (2016) |
| 行为角色级 | attack↔defend, approach↔flee（从link_behavior_roles.json自动推导） | 自动 | — |

自动生成层覆盖 ~60-70%，手工补充 ~15-25 对。`build_enemy_stats.py` 在截断前合并两个来源去重。

#### 3.2.3 行为表组装

```
行为表 = 父类默认模板（§四）→ 疾病行为覆盖（病灶级微调）→ 病历特殊字段覆盖（个人级微调）
```

| 敌人层级 | 行为表来源 |
|---------|----------|
| **杂兵** | 父类默认模板 + 疾病行为覆盖。不使用病历级微调 |
| **精英** | 父类模板 + 疾病覆盖 + 基于 MSE 战斗标签的病历级微调（§3.4.1 + §3.5） |

#### 3.2.4 恐慌行为表

SAN < 30 时激活。5 项恐慌原语定义见 §五。

来源优先级：

| 来源 | 优先级 | 内容 |
|------|:---:|------|
| 父类恐慌默认模板（§四） | 基 | 5 项恐慌原语百分比 |
| 疾病文件 `非线性跳变` 表 | 覆盖 | 条件→行为覆盖 |
| 风险评估.自杀 | 覆盖 | 僵住 +5%/+10%/+15%/+20%（被动/主动/有计划/有企图）。归一化同行动偏好（§3.3.3） |
| 风险评估.伤人 | 覆盖 | 物理攻击 +10%/+15%/+20%（意念/威胁/行为）。归一化同上 |

### 3.3 数值基线层

#### 3.3.1 HP/SAN 精确值

| 来源 | HP 范围 | SAN 范围 |
|------|---------|---------|
| 轻度病人 | 20-30 | 50-70 |
| 中度病人 | 40-60 | 40-65 |
| 重度病人 | 80-120 | 30-55 |
| 轻度投影造物 | 10-16 | 无独立 SAN |
| 中度碎片造物 | 25-40 | 25-40 |
| 重度完整体造物 | 60-90 | 45-70 |
| 医疗人员 | 25-40 | 70-90 |

**HP 精确值公式**：

```
HP = floor(范围下限 + (范围上限 - 范围下限) × offset_factor)

offset_factor 默认 = 0.5（范围中位）
偏移因子（叠加，从 0.5 往下减）:
  躯体病史中有慢性消耗性疾病      → offset_factor - 0.1
  躯体病史中有脑外伤/癫痫         → offset_factor - 0.1
  物质使用史中酒精重度使用        → offset_factor - 0.1

offset_factor 下限约束: ≥ 0（不破范围下限）
```

**SAN 精确值规则**：

```
SAN = 范围上限 - 偏移总量（从上限往下减）

偏移量:
  既往自杀企图 ≥ 2 次             → -5
  社会史·创伤史 有                → -3

SAN 不低于范围下限
```

#### 3.3.2 槽位预算

```
槽位 = 4 + floor(SAN/30)   （与玩家同公式，见 核心机制.md §2.1）
杂兵: 静态——锁定为入场 SAN 值，不随战斗内 SAN 波动重算
```

> **决策**: 杂兵槽位锁定入场值（非战斗内动态重算）。避免杂兵 SAN 波动→槽位变化→行为复杂度不可控。

#### 3.3.3 行动偏好权重

从父类默认模板（§四）查表获得基线权重（5 项：物理攻击/精神攻击/防御/趋近/回避，总和 = 1.0）。

**病历字段调整因子**（精英和教徒可叠加）：

| 病历特征 | 偏好调整 |
|---------|---------|
| 风险评估.伤人 = 意念 | P(物理攻击) ×1.5 |
| 风险评估.伤人 = 威胁 | P(物理攻击) ×1.5 |
| 风险评估.伤人 = 行为 | P(物理攻击) ×1.5 |
| 物质使用史.兴奋剂 | P(物理攻击) ×1.3 |
| 物质使用史.酒精重度 | P(物理攻击) ×0.7 |
| 自知力 = 较好 | P(防御) ×1.3 |

**归一化规则**：先乘所有适用因子，再全体除以新总和，回到 1.0。多因子累积乘法后归一化（不逐条归一化）。

#### 3.3.4 髓鞘化基线

```
杂兵: 静态模板。使用 m 偏移公式计算后不再变化。
精英: 动态模板。m 偏移公式给出初始值。
  跨战斗成长: 同玩家 Δm 公式，但仅应用战斗内增长，无巩固窗口。
  持久性: 同次休息周期内（同一晚）保留战斗内增长。
          跨休息周期（新一晚全局刷新）重置为初始值。
  跨战斗记忆: 指行为模式记忆（记住玩家的常用策略），非 m 值记忆。
```

## 五、恐慌行为→游戏动作映射

恐慌表中的行为标签统一映射为 5 项**恐慌原语**，父类特有行为在原语基础上叠加链路级效果。

| 恐慌原语 | 可执行动作 | 映射到的行为角色 |
|---------|-----------|---------------|
| **僵住** | 跳过本回合行动窗口 | 无激活（pass） |
| **回避** | 移动远离最近敌方至最大移动距离 | `flee` |
| **防御** | M1 通道选防御 | `defend` |
| **攻击** | 对目标执行一次物理/精神攻击（类型由疾病核心域决定） | `attack_physical` / `attack_mental` |
| **随机反射** | 从 L0-L1 已激活链路中随机触发一条 | `perceive` / `support` / `disrupt` |

### 父类特有覆盖

| 父类 | 特有行为 | 叠加到原语 | 额外效果 |
|------|---------|-----------|---------|
| 焦虑唤醒 | 假阳性威胁检测 | 防御 | 额外激活一条防御域链路 |
| 认知控制 | 仪式行为 | 僵住 | 僵住同时执行固定链路序列 |
| 认知控制 | 冲动行为 | 攻击 | 目标随机（非最近） |
| 社会认知 | 随机目标切换 | 攻击 | 目标随机 |
| 解离性 | Alter 切换 | 僵住 | 切换到另一个非当前 Alter（见 §六） |
| 进食障碍 | 躯体化 | 僵住 | HP 额外 -2/回合 |

### "攻击"原语子类型（按父类硬编码）

| 父类 | 子类型 | 理由 |
|------|:---:|------|
| 奖赏系统障碍 | 精神攻击 | 缺乏行动动力，躯体攻击倾向低 |
| 焦虑唤醒障碍 | 物理攻击 | 惊恐中的自卫——躯体反应 |
| 认知控制障碍 | 随机（各 50%） | 冲动不可预测 |
| 社会认知障碍 | 物理攻击 | 偏执/反社会——躯体攻击倾向高 |
| 解离性障碍 | 精神攻击 | 躯体自我非自身——对身体的归属感弱 |
| 进食障碍 | 精神攻击 | 躯体脆弱，苛责以语言形式表达 |

### 随机采样规则

恐慌表中"随机"（含"随机反射""混乱行为"）均采用**均匀随机**——恐慌状态认知功能瓦解，高 m 链路和低 m 链路被随机点燃的概率相等。

## 六、DID Alter 完整系统

> **决策**: 方案 C——每个 Alter 为独立完整配置。DID 敌人 = 身体层（共享）+ N 个 Alter（独立）+ 系统层配置。

  自称名: <可能与法定名不同>

### 系统层配置

**切换规则**：

| 切换类型 | 触发条件 | 行为 |
|---------|---------|------|

**切换过渡**：1 回合解离性僵住（行动窗口跳过），SAN -5，不可被响应窗口打断。过渡完成后新 Alter 接管。

**切换持久性**：同一场战斗中已出现过的 Alter 再次切换回来时，保留之前战斗内的 m 增长（同精英跨战斗记忆规则）。

**记忆共享矩阵 (N×N)**：
```
共享程度:
  完全 — 双向共享。Alter A 和 B 互相知道对方的所有记忆
  部分 — 知道对方存在但不共享情景记忆
  单向 — A 知道 B 的行为，B 不知道 A 的存在
  无   — 完全遗忘屏障。切换后前 3 回合内激活的链路不可复用
         （疾病规则：记忆域 |m|>0.3 → 海马旁回区隔化）
```

**共意识**：定义哪些 Alter 对可以同时意识到外部世界（一个前台操作，另一个后台观察）。如 `Host ⟷ Protector` 共意识——Host 能感知 Protector "想出来"但 Protector 不接管。

### 与疾病文件的关系

- 疾病文件的 `功能域配置` → Host Alter 的 m偏移
- 其他 Alter 的 m偏移 → 在病历中独立定义
- 疾病文件的行为覆盖/非线性跳变 → 应用于当前前台 Alter，切换后重新评估条件

## 七、生产流程

### 7.1 阶段 1: 模板化批量生成人设

**病人病历 = 疾病差异化 + 年龄/性别/职业多样化**

| 参数 | 多样化规则 |
|------|-----------|
| 年龄 | 疾病流行病学高发年龄 ± 5 岁内均匀采样 |
| 性别 | 疾病流行病学性别比加权随机 |
| 职业 | 从职业池中随机（职业池按教育水平分层） |
| 触发事件 | 从该疾病的常见触发事件池中随机（文献定义 + 临床共识） |
| 转诊来源 | 社区 40% / 综合医院 30% / 警察 20% / 自行 10% |

### 7.2 阶段 2: 人设 → Stat Block 脚本化

编写 `code/tools/build_enemy_stats.py`：

```
输入: data/enemies/clinical_records/*.yaml
输出: data/enemies/stat_blocks/*.json

步骤与类型签名:
  Step 1: parse_yaml(file) → ClinicalRecord
  Step 2: lookup_disease(dx_name) → DiseaseConfig
  Step 3: lookup_tags(tag_list) → TagOffset
  Step 4: compute_m_offset(DiseaseConfig, CGI-S, TagOffset) → Dict<LinkID, float>
          先域门控（表B过滤），再查表A（不乘倍率），再加 TagOffset，
          再天花板截断（拮抗对链 ≤ 1.4）
  Step 5: lookup_parent_template(parent_class) → BehaviorTemplate
  Step 6: apply_override(BehaviorTemplate, ClinicalRecord, is_elite) → BehaviorTemplate
  Step 7: compute_hp_san(CGI-S, source, ClinicalRecord) → {hp: int, san: int}
          HP = floor(lower + (upper-lower) × offset_factor), offset默认0.5
          SAN = upper - san_penalties
  Step 8: compute_drop_pool(DiseaseConfig, source, tier) → DropPool
  Step 9: assemble_stat_block(all_above) → StatBlock
  （DID 敌人额外步骤: assemble_alter_system → 嵌入多个 Alter 配置）
```

### 7.3 阶段 3: 与预烘焙管线集成

`bake_npc_behavior.py`（规格已定，待实现）消费 stat block JSON → 生成 27 情境 × 3 SAN 段行为概率分布。

### 7.4 阶段 4: 校验

编写 `code/tools/validate_enemy_stats.py`：

```
  1. 每份 stat block 中的所有链路 ID 必须在 link_registry.json 中存在
  2. m 值范围检查：-1.0 ≤ m ≤ 1.0
  3. 标签数量检查：1-2 个
  4. 掉落池链路 ID 必须在 link_registry.json 中存在
  5. HP/SAN 值在对应来源×等级的范围内
  6. 每个疾病至少 N 个敌人实例（覆盖率检查）
  7. 恐慌行为表 % 总和 = 100（允差 ±1）
  8. 行动偏好权重总和 = 1.0（经归一化后，允差 ±0.01）
  9. DID 敌人：所有 Alter 的链路 ID 必须存在 + 记忆共享矩阵维度 = Alter 数
```
