### 架构决策 (2026-09-01) — A′-Generator 静态模块契约架构（第八份外部评审 t_6a96531054b4819184b5711a86091831）

**触发**：用户提出——issue 文档落后问题启发引擎插件化（#111），生成器是否考虑同样问题（一个环节出错不应影响整体）。外部评审裁决：**加，且现在加**；但定位为「生成器流水线的静态边界设计」而非「插件系统设计」——插件化是未来自然获得的能力，不是当前目标。

**决策（A′ 采纳）**：

1. **阶段职责隔离**（5 阶段，暂不锁接口形状——避免"用未验证实现结构规定架构"）：
   - Soil Sampler（土壤/宏观输入采样：社会演化矩阵 + 固定生活环境层）
   - Event Generator（事件生成：事件类型 × 场所）
   - Memory Builder（创伤记忆构造：ΔI = k×A → L）
   - Transformer（转化：创伤记忆 → 疾病档位，§3.1-§3.4）
   - Artifact Deriver（.gen.json 派生/产物输出）

2. **静态 seam**：模块间只依赖契约（输入/输出），不依赖内部实现；数据产物（JSON）与功能模块分离；具体接口形状留到实现批次。

3. **失败语义三层**（WARNING ≠ FAIL ≠ fail-fast，作用于不同时相）：
   - 开发期 schema 演化：增字段 → WARNING（兼容扩展）/ 删字段 → ERROR（护栏）——S2+ 既有
   - 生成任务输入验证：契约满足 → 继续 / 不满足 → FAIL
   - 静态模块装配：依赖/版本/契约不满足 → fail-fast（#111 精神移植）

4. **fallback 是生成策略，不是模块状态**：input_source ∈ {canonical, fallback} 标注；兜底「慢性冲突/高压」仅限开发/演示模式；正式生成输入缺失/非法 → FAIL。不引入 Ready/Degraded/Unavailable 状态。

5. **严格排除**：运行时热插拔 / HMR / 通用模块状态机 / registry / wrapper 层（不为模块化制造额外层）。

6. **铁律：错误在最近契约边界被识别**——模块失败时在契约边界报错，不伪装成合法数据向下游传播（"一个环节坏了全链断"的真正解法 = 让错误在边界显形，而非让错误消失）。

**与 #111 的关系**：#111 = 通用模块化原则（静态契约/seam/装配期验证/fail-fast）→ 引擎与 #87 生成器各自落地；#87 不发明"生成器插件框架"。

### 本体纠偏 (2026-09-01) — 环境资格判定概念族废弃（第九/十/十一份外部评审 t_6a9655da977c819197547ec8a9106481 / t_6a9656d9ee088191a86b78c36fd5543e / t_6a9657da1d7881919c42285b153a1915）

**触发**：用户质疑"真的有不变的固定生活环境判定阈值么"——"固定"是个体经验相对属性（同一学校 A 待 5 年被塑造终生 / B 转学 3 个月毫无痕迹），客观阈值与已裁定的"创伤主观性"（客观输入 vs 个体反应）自相矛盾。评审确认并加严：**取消"固定生活环境资格阈值"整套概念**（T_min / 环境资格 / is_fixed_environment() 均不存在）。

**定版链条（A′-Generator 架构内）**：

```
社会演化矩阵
    ↓
Soil Sampler（土壤采样）
    ↓
叙事约束（出生年 / 生命周期阶段 / 社会事件等）
    ↓

    ↓

    └────→ 事件序列 ──→ Trauma Memory Builder ──→ Transformer
```

**三条不变量（锁死）**：
1. **环境不是分类器结果，而是 Event Generator 生成的人生叙事线的结构输出**——"环境存在"由人生叙事建模为持续性生活场域，不由时长/频率/事件数量阈值决定
2. **环境存在性 ≠ 暴露量 T ≠ 塑造结果**——T ↑ 最多 ⇒ 潜在事件生成机会 ↑；禁止 T ↑ ⇒ 创伤↑/事件严重度↑/疾病概率↑（塑造由个体化机制 β/k/g 决定）
3. **不存在 T_min / 环境资格判定 / is_fixed_environment() 类独立资格机制**——防回归约束：未来提议加回资格判定的答案是"不是"

**防黑箱约束**："人生叙事"不是独立的本体实体或判定器，而是 Event Generator 按已定义叙事约束生成的**中间产物**——叙事驱动描述生成关系，不引入"叙事判定器"。

**Q1 方向更新**：原"固定生活环境层（场所维度）"表述废弃 → 环境 = 人生叙事中建模为持续性生活场域的结构性经历；环境内容维度（家庭结构/亲密关系/代际冲突/关系损伤 + 家庭外场域）保留为环境的关系结构内容。

```
宏观社会事件（时代烙印）── 确定性锚定
  1977 恢复高考 / 1997 下岗潮 / 2003 非典 / 2008 金融危机……
  由出生年×地域唯一确定 = 社会演化矩阵的直接投影（人人共享时代背景）
        ↓
微观人际事件（个体遭遇）── 随机采样
  同样经历下岗潮：A 家庭冲突加剧 / B 染上酒瘾 / C 振作再就业
  从「事件类型 × 场所」池按概率采样（§3.2.1 十类事件为池）
```

**落点**（A′-Generator 架构内）：Event Generator——叙事约束 = 宏观确定性锚定输入（矩阵投影），事件生成 = 微观随机采样（事件类型×场所池）。

**满足**：①矩阵时代真实性（NPC 与时代锚定关系不丢，出生年锚定有意义）②M5 个体多样性（同背景不同人生）③确定性偏好（同 seed 同 NPC，复用 #71 DeterministicRng 注入层——生成器内容管线可复现）。

**待细化**（后续）：宏观事件的阶段粒度（十年一档 vs 具体年份）、微观采样的概率分布（事件类型权重）、随机与创伤模型的衔接（采样事件 → ΔI=k×A 的烈度分配）。

### Q4 决策 (2026-09-01) — 模板化边界（第十二份外部评审 t_6a965a7184288191a5c8c77170b2f0b3 采纳）

**问题**：M5「不构建生态位模板」vs 生成器批量产出的复用需求。

**决策（三层锁定）**：

| 层级 | 允许复用 | 约束 |
|------|---------|------|
| **类型学** | 环境类型、事件类型、关系类型 | 作为生成词汇，不代表具体人生 |
| **生成规则/结构模式** | 生命周期映射、事件约束、关系生成规则 | 可复用，但必须产生新的实例 |
| **人生实例** | ❌ 不作为模板复用 | 每个 NPC 独立生成时间线、事件、关系及其组合 |

**正典措辞（锁死）**：
> 模板化边界：类型学与生成规则允许复用；具体人生实例必须独立生成。M5 所禁止的是 NPC 级完整人生模板的复用，而非环境、事件、关系等类型学或生成结构的复用。素材池用于提供实例生成参考，不得作为完整人生模板直接实例化。

**防回归约束**：
> 相同类型、结构或事件在不同 NPC 中重复出现，不构成模板复制（"同构 ≠ 模板复制"——三个 NPC 都经历家庭→学校→职场合法）；只有将既有 NPC 的具体人生轨迹作为整体成品复用于另一 NPC，才构成违反 M5 的模板化。禁止用"出现相同事件类型"作为模板化判据（否则滑向"每个 NPC 连父母离异都不能重复"的强制制造差异极端）。

**#89 素材池定性**：病案素材 → 提供可能的事件/关系/病程形态 → 生成规则 → 结合当前 NPC → 新实例；禁止"素材#3 → 复制 → NPC"。与 Q2 宏观确定+微观生成一致。

### Q5 决策 (2026-09-01) — 审阅流程（第十三份外部评审 t_6a965c055a1c8191a1ed0b8eed05b8fd 采纳）

**问题**：#87 是 M1/M2 的反方向——AI 起草人生 → 用户审阅（旧 M1 是用户写文本 → AI 派生）。交付形态与迭代规则？

**决策（C + 同一事实源）**：

- **交付形态 = C**：结构化人生骨架（时间线/事件/关系）+ 简版叙事视图。**二者是同一份草稿的两个视图，不是两个独立事实源**——结构化骨架 = 可计算的事实载体，叙事 = 人类可读呈现；改任一边 = 改同一事实（防骨架/叙事不一致双真相源）
- **迭代规则 = 锚点 + 依赖边界传播 + 局部重生成**：用户修改 → 确定锚点 → 依赖传播（改父母离异 → 家庭环境 → 相关事件 → 创伤记忆 → 疾病派生）→ 局部重生成/重计算 → 保留未受影响部分（不重生成"15 岁喜欢的运动"等无关内容）
- **用户修改优先于 AI 生成规则**：用户版本 = 当前事实；AI 仅重算受影响派生结果，不得为"保持矩阵统计合理"把用户改回去
- **定稿入 M2 双轨**：用户定稿文本 → 轨道一（AI 不再改写）；结构化数据 → 轨道二 .gen.json（机器处理）

**M2 澄清（AI 起草阶段作者身份）**：轨道一「AI 不改写」指**定稿后**不改写；AI 首次生成阶段可以作为作者（起草人生）——与 M1 方向反转的衔接。

### Q6 决策 (2026-09-01) — 生成质量校验（第十四份外部评审 t_6a965cf2bb648191aee270bf32317d2f 采纳，终题）

**问题**：如何避免千篇一律（对照 5 本已入库病案书多样性）？可执行校验指标。

**决策（三层门禁）**：

```
生成批次
   ↓
① 个体合法性（硬性，个体级）：矩阵/出生年/年龄/地域/社会事件窗口硬约束
   违反 → FAIL（约束违反，非审美判断）
   ↓
② 批次多样性（批次级）：检测事件/疾病/时间线长度/事件密度/关系数量的异常集中或模式塌缩
   异常 → WARNING / 重生成 / 人工审阅（不要求服从预设唯一分布——A=17% 式规定=偷偷定义"正确人生"）
   ↓
③ 素材形态（软性）：#89 五本病案 = 现实形态参考，非规范分布非生成目标
   偏离 → WARNING / 人工审阅（"与五本书不像"不判 FAIL——否则素材从"样本"变"现实的定义"）
   ↓
交付审阅
```

**关键原则**：
- **质量校验不是分类器**：不决定"这个 NPC 是不是合格人生"，而是生成后**诊断系统**（发现约束违反/批次塌缩/形态异常）——不重演 Q1 资格判定问题
- **阈值区分**：资格阈值（T≥1年→是环境）已废弃；**质量门禁阈值允许存在**（重复率>X→批次异常），但**第一版不拍数值**——先锁指标/统计口径/失败警告语义，具体阈值待批次规模和实际输出分布可观测后标定（防"从 1 年换成重复率 20%"的阈值幻觉）

**Q1-Q6 原则链（#87 六问闭合）**：
```
Q1 环境不是分类资格，而是叙事结构
Q2 宏观确定锚定，微观随机生成
Q3 因果关系分层，不把相关性写成决定论
Q4 类型学复用，人生实例不模板化
Q5 AI 起草、用户定稿，修改按依赖局部传播
Q6 结果做约束/多样性/现实性校验，而不定义"正确人生"
```

**#87 剩余细化项（六问闭合后遗留，不阻塞设计）**：Q1 环境内容维度（关系结构）细化 / Q3 生成器侧落地细节 / 宏观事件阶段粒度 / 微观采样概率分布 / 事件→ΔI 烈度分配 / Q6 统计阈值标定（待批次可观测）。
