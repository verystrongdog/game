# Grilling #120 决策记录 — 关键突破触发规则

> m 0.8→1.0（娴熟末段→本能）的触发规则定案。沿革：#119 语义 → Q1 方向裁定（身心发展）→ 拆 #121 角色发展轴 → 回炉定案。

## 定案摘要

| 决策 | 内容 |
|------|------|
| Q-A | 沉淀对象 = 技能（链路上下文组），非单链路；共享边跨技能受益（两次修正沿革：链路→技能） |
| Q-B | 就绪 = 组内全部边 m≥0.8（瓶颈口径）；配套契约：技能使用激活组内全部边（P1c 输入） |

| Q-D | 里程碑→突破资格（暂存、累积不过期）→ 休息执行，不浪费（与巩固窗口即时性解耦） |
| 词表 | 阶段正式名 = 笨拙/协调/精通/娴熟/本能（用户亲定）；旧名降级机制注记 |

## 关键问答沿革（术语语域问题）

- 用户："自动化太像工程术语，不像玩家对自身技能释放熟练度的描述" → 双层命名（机制术语保留 + 玩家侧词表）→ 用户亲定词表笨拙/协调/精通/娴熟/本能
- 用户："链路指什么，跟技能什么关系" → 沉淀对象修正为技能
- 用户："木桶效应存在么" → 数值层求和无木桶 / 行为层自动化=全链流畅木桶成立 → B1 全边门槛 + 可达性配套
- 用户："为什么三种自动化路径会锁死技能域" → 伪绑定裁定：型=突破方式、技能=突破对象，正交

## 术语语域原则（本轮沉淀的方法论）

机制术语（学术/工程腔，如"自动化加工/完全自动化"）与玩家侧呈现词（角色自然语域）分层——玩家可见文本必须是"角色对自身技能释放"的自然描述。先例：脊柱线→结构性主线；本规则建议后续所有机制命名复用。
