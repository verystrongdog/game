## 正文

## 发现场景

讨论 SpeedCalculator 参数数据可达性时，发现基底节 CSTC 链路全部为 0。进一步审计发现根本问题是：**#25 解剖基座重构后，`build_link_legitimacy_matrix.py` 与新的 `brain_regions.json` 数据格式完全脱节。**

## 🔴 致命问题

### 1. 字段名断裂：`bfb_region` → `dk_name`

脚本 `load_brain_regions()` 读取 `r.get("bfb_region")` 构建 `dk_to_regions` 映射。但 #25 后的 `brain_regions.json` 将字段改名为 `dk_name`。**70/70 脑区均无 `bfb_region` 字段 → `dk_to_regions` 完全为空。**

```python
# 脚本 L99: 读取不存在的字段
bfb = r.get("bfb_region")   # ← 70/70 返回 None
if bfb and category == "cortical":
    dk_to_regions[bfb].append((name, level))
```

**影响**：ENIGMA 1114 条连接（698 皮层↔皮层 + 416 皮下→皮层）+ Hansen 44 条脑干投射 → 全部在 `get_region_level()` 返回 `None` → `no_level_mapping` → 丢弃。

### 2. 364 条链接是前朝产物

当前 `link_legitimacy_matrix.json` 的 364 条链路引用 **53 个不存在的脑区名**：
`ACC`, `ACC吻侧`, `ACC背侧`, `Broca区`, `DMN+OFC`, `M1`, `OFC`, `PAG`, `S1`, `TPJ`, `VTA`, `Wernicke区`, `dlPFC`, `mPFC`, `vmPFC`, `上丘`, `丘脑`, `中缝正中核`, `中缝背核`, `伏隔核/NAcc`, `全脑整合`, `前脑岛`, `前额叶极·DMN`, `前额叶极·FPN`, `前额叶极·SN`, `海马旁回`, `海马体 CA1`, `海马体 CA3`, `丘脑枕`, `壳核`, `尾状核`, `小脑皮层`, `岛叶-ACC`, `岛叶-ACC-VTA`, `岛叶-PFC-杏仁核`, `岛叶-vmPFC`, `左额下回`, `弓状束`, `扣带后部`, `杏仁核`, `楔前叶`, `楔叶`, `苍白球`...

这些是旧 89 功能脑区的 zh_name/functional_id，与当前 70 fid 的命名体系不兼容。

**结论**：当前链路矩阵与 `brain_regions.json` 是**两个完全独立、互不兼容的数据集**。脚本从 #25 之后从未成功运行过。

## 🟡 阻塞问题

### 3. Kroell 功能网络混用 ENIGMA 皮下标签

16 处网络定义使用了 `putamen`/`caudate`/`pallidum`/`accumbens`/`amygdala`/`hippocampus`——这些是 ENIGMA 皮下标签，不是 DK 皮层标签。在 `valid_dk` 集合中不存在 → 协同激活判定对皮层下区域永远返回 `False`。

### 4. 白质纤维束模糊匹配表

`_fuzzy_match_dk()` 的 11 个匹配目标不在 `valid_dk` 中：`thalamus`, `amygdala`, `hippocampus`, `putamen`, `caudate`, `pallidum`, `accumbens`, `cerebellum`, `brainstem`, `parstriangularis`, `parsorbitalis`。白质结构验证对皮层下区域失效。

## 🟢 边界问题

### 5. brainstem_cortical_fc.json 引用已删除靶区

- PAG→hypothalamus（下丘脑已于 #25 删除）
- 中缝背核→septum（隔区已于 #25 删除）
- 中缝正中核→septum（同上）

### 6. ENIGMA_SUBCORTICAL_MAP 包含已删除条目

`缰核`/`下丘脑`/`BNST`/`隔区`（4 个 #25 删除的皮层下结构）仍在映射表中，但无对应脑区。

## ✅ 无问题

- `subcortical_links.json` — 11 条手动链路引用全部合法
- 70/70 脑区均有 `level` 字段
- 60/70 脑区有 `dk_name`（10 个 brainstem 核团无 DK 标签，符合预期）

## 修复路径

### Phase 1: 数据对齐（先修字段，让脚本能跑）

1. `bfb_region` → `dk_name`：脚本字段名与数据对齐
2. `dk_to_regions` 构建逻辑重写：cortical 走 DK 标签，subcortical 走 ENIGMA 皮下标签，brainstem 走核团名
3. 删除 ENIGMA_SUBCORTICAL_MAP 中已废弃条目（缰核/下丘脑/BNST/隔区）
4. brainstem_cortical_fc.json 删除 septum/hypothalamus 靶区引用

### Phase 2: 皮下-皮层通道修复

5. L_/R_ 前缀剥离修复：ENIGMA 皮下标签保留原始格式查询 `subcortical_to_enigma`
6. Kroell 网络 + 白质纤维束匹配表：支持 ENIGMA 皮下标签作为合法标识符
7. 脚本重跑 → 得到正确的皮层↔皮层 + 皮下→皮层链路基数
