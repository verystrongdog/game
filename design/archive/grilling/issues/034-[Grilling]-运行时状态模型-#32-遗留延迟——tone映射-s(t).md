## Grilling 进展 — 事件空间数学定义 (2026-08-09)

### D1 — 事件数学定义

```
事件 e = (δ, s)，绑定到具体角色实例

δ ∈ R⁴    tone 脉冲向量 —— 实时注入
s ∈ R⁶⁹   皮层感官输入 —— 打包到下一 Phase 1 注入

同角色同回合多事件: δ = Σ δ_i, s = Σ s_i（加法叠加）
```

trigger 不纳入 e 的分量——它是 δ 和 s 的非零条件，由战斗结算层定义。事件系统的任务：**有哪些 (δ, s) 向量，各自对应什么结算产物**。

### D2 — s 的模态分解

s 不直接指定 69 维分量。事件携带感官模态强度向量 α ∈ [0, 1]⁶，通过解剖映射矩阵展开：

```
s = W_sensory × α
W_sensory ∈ {0, 1}^{69×6}  （待构建）
```

### D3 — 感官模态集 M = 6

| 模态 | 锚定 | 拆分依据 |
|------|------|---------|
| 视觉 | 看到攻击/倒下 | 与听觉节点域不同 |
| 听觉 | 听到声音/倒地 | 与视觉节点域不同 |
| 躯体感觉 | 被击中体感/防御本体感觉 | 与痛觉可分——防御成功有体感无痛 |
| 痛觉 | 被击中痛感/内感受/SAN恐慌体感 | Eisenberger(2003)——社会痛共享物理痛底物 |
| 社会认知 | 读意图/精神攻击社会压力/队友倒下 | 独立节点域（STS/mPFC/颞极） |
| 语言认知 | 精神攻击语言内容/命名 | 与社会的拆分——Broca ≠ STS，未来可能纯语言事件 |

拆分标准：**存在至少一种事件需要激活其一而不激活其二 → 拆**。

### D4 — δ 的二进制 pattern

文献有定性方向（DA-5HT 拮抗，NE 显著性响应），无跨系统定量幅值比。走二进制：

```
δ pattern ∈ {−1, 0, +1}⁴
```

通道差异由 τ 参数提供（NE τ=0.5 快涨快衰，5HT τ=1.5 慢涨慢衰）——相同脉冲打到不同 τ → 不同时间轮廓，不需要在 δ 层加比例。

**影响已记录**：二进制下 A1(命中) 和 A3(暴击) δ pattern 相同，区分靠 magnitude(event_data)；B4(被精神攻击) 和 B1(被物理击中) δ pattern 相同 (+1,0,0,−1)，区分靠 s(t)。

## Grilling 进展 — D9/D10 (2026-08-09)

### D9 — C1 触发机制

C1（SAN < 30% × SAN_max）是 SAN 扣减的**副作用事件**——在伤害结算的同一代码路径中检测：

```
if old_SAN/SAN_max ≥ 0.30 and new_SAN/SAN_max < 0.30:
    emit(C1, target, m=1.0)
```

不从外部监控器轮询。阈值用百分比（玩家 SAN_max=80 → 24，NPC SAN_max=50 → 15）。

### D10 — magnitude 公式

`m ∈ [0, 1]`。行动者用 RPE（实际/预期），承受者用归一化冲击。

| 事件 | m 公式 | 属性来源 |
|------|--------|---------|
| A1/A3 命中/暴击 | `actual_damage / expected_damage` | 攻击者伤害公式 |
| A2 被格挡/闪避 | `actual_damage / expected_damage`（≈ 0） | 攻击者 |
| A4 精神攻击执行 | `actual / expected` | 攻击者精神 damage |
| A5 防御成功 | `damage_blocked / incoming_damage` | 承受者 |
| B1/B3 被击中/暴击 | `|ΔHP| / HP_max` | 承受者 |
| B2 闪避/格挡 | `damage_blocked / incoming_damage` | 承受者 |
| B4 被精神攻击 | `|ΔSAN| / SAN_max` | 承受者 |
| C1/D1/D2 | 1.0 | 阈值/死亡 = 固定最大 |

行动者和承受者用不同分母——A 的 expected 是 A 自身武器属性算出的预期伤害，B 的分母是 B 的 HP_max。
