## 话题

从 #87（NPC 人生自主起草功能）拆出的独立议题（#87-D10，2026-08-19 用户决策）。**记忆物理储存 = 运行时基础设施**（管线维度），服务对象远超创伤记忆：

**现状核查结论（2026-08-19，引用即读取已执行）**：

- 现有设计只有记忆**功能层**（脑区定位：海马 CA1 回忆/CA3 辨别/海马旁回识景/后扣带内省/峡部扣带回溯/颞极识人，[脑功能层级模型.md §四-五](../../规则/技能树系统/脑功能层级模型.md)），**无记忆内容层**（无「一条记忆」的数据结构/存储位置/写入管线/检索接口）
- 91 运行时状态变量全是动力学变量（[运行时状态模型.md §三](../../规则/技能树系统/运行时状态模型.md)），无记忆实体；m 是链路强度非内容
- **先例**：敌人跨战斗记忆（[敌人与事件.md §4.6](../../实体/敌人与事件.md)：链路偏好/行动模式/SAN 习惯/上次结果，带衰减 完整→50%→遗忘→清零）——唯一内容层记忆
- **需求方**：创伤记忆（#87/#88）、NPC 跨战斗记忆、DID 记忆区隔化（[解离性身份障碍.md](../../实体/疾病目录/解离性身份障碍.md)）、健忘症搁置角色（[角色与面具.md §6](../../实体/角色与面具.md)，搁置原因 = 「需建立海马记忆链路直接修改框架」）、玩家叙事记忆

1. **数据结构**：记忆内容实体的 schema——字段（内容/时间锚/来源/关联人物/强度/访问状态）？与创伤记忆载体 `{烈度 I, 表征 N/F/R, 事件快照, 总负荷 L}` 的关系

## #90-D2 再巩固适用范围确认（2026-08-20）

提取 = 写操作（再巩固）应用于**全部记忆类型**（结构统一，无类型特判；所有记录同一状态机），**改写幅度按烈度分级**（A+ 方案）：

- 测试效应 `P_acc += δ_test` 全类型适用（只读收益）
- 与 #87-D8 兼容（访问层遗忘）

## #90-D3 容量机制确认（2026-08-20）

容量 = 纯游戏参数（方案 B），**去神经化**：

- `cost_j = α/a_j`，`Σ_j cost_j ≤ Cap_max`（α = 单位成本、Cap_max = 记忆库总容量，均 [NEW]）
- `a_j = |T_j|/D`（index 稀疏度，内容层自有量）
- **黑箱语义**：内容层不调用海马内部结构——不建 CA3 回返网络、不引 DG 数据；引擎侧对海马维持正典现状（limbic 输入节点 + θ_mem MTL 激活均值）

## #90-D4 存储位置分层确认（2026-08-20）

**构建层持久 + 战斗层快照**：

## #90-D5 写入管线确认（2026-08-20）

**四来源**：
- ① 事件记录（source=event，战斗事件实时 E 编码）
- ② 生成功能产出（source=generated，#87 NPC 人生起草预生成）
- ③ 剧情脚本（source=script，#86 对话树/叙事节点）
- ④ 系统观察（source=observation，NPC 旁观 D1/D2）

**可塑性巩固不是记忆创建来源**（m 层机制，三层分离）：
- 创建 = 事件自动写入；玩家选择 = 巩固窗口只调 TryConsolidate（#73 D4），不触碰 MemoryRecord；记录强化 = 内容层机制（再巩固改写/测试效应/睡眠回放）
- 事件强度（m 档位）与烈度 A（ΔI）共享事件输入但公式独立

**双通道写入**：预生成（②③）直写构建层记忆库；战斗事件（①④）经战斗层 id 快照，战斗结束/休息批量并入构建层。`source` 枚举 = {event, generated, script, observation}

## #90-D6 检索接口 s 构成确认（2026-08-20）

`s_j = w₁·(P·T_j)/N + w₂·(c_R·c_E,j)`，w₁+w₂=1（内容 + 情境加权）：

- **触发源分离**：外部知觉线索（视觉/听觉/人物在场）→ 内容项 (P·T_j)；内部情绪/生理状态 → 情境项 (c_R·c_E)（#87-D7 双触发源天然分离）
- 情境向量 c_t = 时间 + 地点 + 情绪 + 在场人物（[NEW]）
- w₁/w₂ 待校准 [NEW]
- 检索消费方分家：内容层 P_trigger 供创伤/情境触发；引擎层 P_success（θ_mem）供记忆类技能（P1c D5 预留），无需额外对接层
- 文献：TCM（Howard & Kahana 2002）+ Minerva（Hintzman 1988）

- 已否决：档位+幂律共存（两套衰减逻辑）

## #90-D8 schema type 字段定案（2026-08-20）

`type ∈ {behavioral, narrative, generic}`——**trauma 不作为 type**：

- 创伤 = **烈度属性**（I_mem 高 + 表征形态），不是载荷类型；generic/behavioral + 高烈度 = 创伤记忆
- 判定（结构可核验）：behavioral ⟺ 四件套完整；narrative ⟺ Conway 三层完整；generic ⟺ payload = ∅（显式空载荷，非补集）
- 判定主体 = 写入管线（内容层）；生成端只提供输入不标注类型
- 已消除：type 与剂量-反应累积冲突（trauma 移出）、判定主体错层、generic 补集漂移、A_trauma 越界（移交 #88）
