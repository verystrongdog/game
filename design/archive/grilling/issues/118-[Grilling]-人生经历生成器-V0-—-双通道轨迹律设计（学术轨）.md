## 话题

在 [#117](https://github.com/verystrongdog/game/issues/117) 评审结论基础上（D1-D6：结构层采纳、q_t 价值层撤回、决策论重述 + 代理量落地），设计「人生经历生成器」V0：一个从有限起始条件演化出**随机**人生经历轨迹的系统。学术轨——不入游戏正典、不入 #116 决策流（#93/#97/#117 先例）。

**目标形式化**：`G: S₀ → P(τ)`，`τ = (S₀, E₁, S₁, …, E_T, S_T)`；需求 R1（非退化）：固定 `S₀` 下 `|supp P(τ|S₀)| ≥ 2`。

**已锁定（本会话 2026-09-06）**：
- 保留资产 = #117 结构层骨架（R/G 双更新、K_R 随机核、三随机源分解、状态压缩、操作集）+ 概念区分词典；q_t 族不进运行时
- **对象层 = 双通道轨迹律**：被动通道 `E_t ~ P_W(E | S_t, R_t, G_t)`（事件发生在人身上）⊕ 主动通道 `A_t ~ π(S_t, R_t, G_t; 驱力)`（人选择，世界回应）；状态依赖切换规则 v0 候选：`决策点 ⟺ 重大外部事件后 ∨ 驱力状态越阈值`（依据：真实人生两模式交错，选择集中在拐点——用户经历反例证伪 A/B 二元分叉）
- **记忆双层**：被动段记录（δ/RPE 打结果标签）→ 决策点消费（检索既往结果 → 影响 A_t → 世界回应 → 新标签）；分歧主要在决策点累积
- 组件 v0 清单 + 随机源分配（ξ^W 世界 / ξ^A 行为 / ξ^R 记忆操作；编码随机源 = 0）+ 门禁语义（非退化 + 差异不坍缩，数值待标定——指标锁、数值不锁）

**本 issue 范围** = V0 规格逐项裁决（对象/符号/时间结构/组件 v0 形式/随机源/门禁），产出规格文档；模拟实现批次另开 issue（#94 sim 批次先例）。
