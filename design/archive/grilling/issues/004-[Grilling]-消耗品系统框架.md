## Grilling 结论

### 决策汇总

| 决策 | 结论 |
|------|------|
| 消耗品存在 | ✅ 有（17种精神科药物） |
| 核心模型 | 药物 = 链路调制器（抑制↓/增强↑/钳制↕），HP/SAN/速度是涌现结果 |
| 调制强度 | 三级：弱(±0.1-0.2)/中(±0.2-0.4)/强(±0.4-0.6) |
| 风险系统 | 依赖/戒断(苯二氮䓬+兴奋剂) / 耐药(抗精神病D₂类) / 过量(锂盐+TCA) |
| 获取手段 | 三种并存：拾取/掉落/NPC交换 |
| 稀有度 | 四级：常见/不常见/稀有/极稀有 |
| 携带 | 总量上限 6→9→12（叙事扩容×2），同种 2片/槽 |
| UI | 独立物品栏，不吃技能槽 |
| 敌我同构 | 仅特定敌人类型可用（医疗人员/拜月教徒/精神病人） |
| 禁止组合 | 致死×2(苯二氮䓬+酒精/SSRI+MDMA) + 危险×2(氯胺酮+酒精/锂盐+布洛芬) |
| 13功能域 | 全部覆盖 |
