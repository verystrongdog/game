# 疾病特长（开局）

> 开局交付给玩家选择的**特长** = 疾病。**两条腿决定你成为谁**：**你经历过什么**（无条件给你基本属性，并解锁疾病候选）+ **你自己的选择**（要不要让它变成病）。
>
> 不是"选职业"，不靠点数购买——经历决定候选，**你只能在候选里选**。
>
> **维度: 实体 + 事件** — 分拣：疾病作为特长（实体）+ 开局选择流程与解锁规则（事件）。

## 一、定位

### 1.1 三句话

| # | 结论 |
|:-:|---|
| 1 | **疾病是特长**，26 个，玩家从中选。它给"开哪道门 / 关哪道门 / 代价"，**不给数值加成**（唯一例外 = 特定情境下临时 +1，§2.3） |
| 2 | **不由点数购买。** 经历解锁候选，玩家只能在候选里选——疾病不是货架上的商品 |
| 3 | **经历给两样东西**：基本属性（无条件）+ 疾病候选（要选）。**经历决定你有什么，疾病决定你变成什么** |

### 1.2 为什么成因是两条腿

同一段经历，有人病了、有人没病（[NPC 人生生成器 §4.2 Q2](../events/NPC%E4%BA%BA%E7%94%9F%E7%94%9F%E6%88%90%E5%99%A8%E8%AE%BE%E8%AE%A1.md)：「同样经历下岗潮：A 家庭冲突加剧 / B 染上酒瘾 / C 振作再就业」）。

canon 把 A/B/C 的差别归给 **β/k/g**（易感性 / 应对 / 不成熟度）——那是**系统替你掷的**。玩家侧空出来的那个位置是**选择**，本文件补的就是它：

```
经历 ─┬─→ 基本属性（无条件给）        ← 你练出了什么
      └─→ 疾病候选（玩家选）          ← 它有没有长成病
```

**所以"得病"不是纯粹发生在玩家身上的事，有一部分是玩家选的。** 这也让本作那句主题有了机制落点——**你无法选择出现什么，只能选择怎么面对。**

## 二、基本属性

### 2.1 五项

| 属性 | 是什么 | 在场景里干什么 |
|---|---|---|
| **体格** | 体力 · 负重 · 近身 | 推开堵住的门 · 搬 · 扛 |
| **巧手** | 精细 · 操作 · 条理 | 开锁 · 翻找 · 搜刮 · 检验 · 计量 |
| **观察** | 看 · 读人 · 警觉 | 发现线索 · 读意图 · 不被偷袭 |
| **沟通** | 说话 · 说服 · 表演 | 对话选项 · 掩饰 · 谈条件 · 关系 |
| **意志** | 情绪 · 承受 · 撑住 | 抗精神压力 · 忍耐 · 关系抗损 |

> **「心」已删除**（2026-09-17）：它原设计的全部功能都能由其他属性承担——关系值/安慰/说服 → **沟通**；共情/读人 → **观察**；抗精神攻击/撑住 → **意志**。canon 的**忍耐**（精神伤害减免，被动 −1 / 主动 −2，[核心机制 §5.2](../rules/%E6%A0%B8%E5%BF%83%E6%9C%BA%E5%88%B6.md)）即意志的机制面。

### 2.2 五档

**复用 [核心机制 §1.3](../rules/%E6%A0%B8%E5%BF%83%E6%9C%BA%E5%88%B6.md) 的玩家语域正式名**（Grilling #120 定案），不新造词：

| 档 | 名称 | 点数 |
|:-:|---|:-:|
| 0 | **笨拙** | 0–2 |
| 1 | **协调** | 3–4 |
| 2 | **精通** | 5–6 |
| 3 | **娴熟** | 7–9 |
| 4 | **本能** | 10 |

```
起始：全部「笨拙」（你没干过的事，你就是笨拙）
档位 = 该属性从经历拿到的点数所落入的区间
无自由分配点 —— 属性完全由经历决定
封顶 = 10（本能）—— 超出作废
```

> 🔧 **2026-09-18 owner 反馈修正**：原 0–4 一点一档使“4 点 = 本能”，粒度过粗；经历净值改为每段 +2 后，属性上限进一步定为 10。离散区间按 [核心机制 §1.3](../rules/%E6%A0%B8%E5%BF%83%E6%9C%BA%E5%88%B6.md) 的 m 阶段对齐：**只有 10 点（m=1.0）叫本能**，7–9 点仍是娴熟。

> **背后是 m，会成长**：五档对应髓鞘化的阶段名，而 m 随使用增长（[核心机制 §1.3](../rules/%E6%A0%B8%E5%BF%83%E6%9C%BA%E5%88%B6.md)），涨到 1.0 触发**关键突破**。这是本作比极乐迪斯科多的一条——**开局给你的能力不是定死的数字。**

### 2.2.1 五项属性的程度描述

下表是属性页对玩家作出的**能力承诺**：描述“通常能做什么、能做到什么程度”，不等于固定检定难度、必定成功或新增内容门。具体场景仍由交互对象与情境决定。

| 属性 | 笨拙（0–2） | 协调（3–4） | 精通（5–6） | 娴熟（7–9） | 本能（10） |
|---|---|---|---|---|---|
| **体格** | 能完成日常搬拿；持续负重、猛推或近身对抗很快失去姿势。 | 能稳定搬运普通箱物，推开轻型阻碍，并短时架住一个人。 | 会借力移动病床、柜体等重物，能在负重中维持动作。 | 能在狭窄或紧急环境里处理沉重阻碍，并保护他人不被拖垮。 | 几乎不用准备就能判断发力点，让接近身体极限的动作仍然准确。 |
| **巧手** | 会使用常见工具；精细操作需要放慢，步骤一多就容易漏。 | 能按顺序完成日常拆装、搜检和计量，给足时间可处理简单锁扣。 | 能稳定拆解、修复和检验复杂物件，并从操作痕迹判断问题。 | 能在昏暗、受压或时间有限时保持精细动作，少走试错。 | 手先于语言理解结构，凭阻力、声音和触感就能完成复杂操作。 |
| **观察** | 看得到显眼异常；容易漏掉边缘线索、细微表情和前后矛盾。 | 主动查看时能找到常见线索，并辨认明显的不自然之处。 | 能把空间痕迹、说话方式和行为变化连成可靠判断。 | 能同时追踪多人和环境变化，往往在事情发生前察觉征兆。 | 几乎立即分开信号与噪声；一个停顿、错位或缺失就足以指出方向。 |
| **沟通** | 能说清字面需求；很难根据对方反应换说法，也不擅长掩饰。 | 能完成日常询问、解释和协商，并看出对方是否愿意继续。 | 能调整措辞与身份姿态，试探、掩饰或谈条件而不轻易露底。 | 能在紧张或多人场面中引导谈话，同时守住目的与关系。 | 对节奏、沉默和措辞的判断近乎直觉，能抓住极短的开口窗口。 |
| **意志** | 能承受短暂不适；持续压力、恐惧或关系冲击容易打断行动。 | 能在可预期的压力下做完眼前的事，受挫后需要时间恢复。 | 能在长期消耗中守住目标，情绪起伏时仍保留行动余地。 | 能带着疼痛、恐惧或关系损伤继续选择，而不让它们立刻接管。 | 压力出现时仍能直接行动；痛苦不会消失，但无需先说服自己撑住。 |

属性页每张属性卡的顺序固定为：**顶部插画留白 → 属性名与当前程度 → 0–10 点条 → 当前程度的能力描述 → 经历来源**。插画区当前保持空白，不以临时图标填充；以后补图不得挤压或替代能力描述。

### 2.3 临时加成（疾病侧的唯一数值手段）

部分疾病在**特定情境**下临时给 **+1**（重档 +2，⚠️ 待定）。

| 项 | 规则 |
|---|---|
| 值 | **+1**；重档 +2 ⚠️ 待定（§六 待办 4） |
| 触发 | 进入**这个病成立的那个情境**时 |
| 持续 | 该情境持续的整个场景；离开即失效 |
| 封顶 | 受五档封顶约束——本能之后再 + 仍是本能 |

**最关键的一条**：**加成与"关的门"由同一个触发条件产生。**

> 你之所以在那件事上更准，是因为**你只能那样理解它**。

偏执型 SZ 让你观察 +1，条件是你正在找"谁在针对你"的证据——**加成不是白给的，它是那把锁的另一面。**

## 三、人生经历

### 3.1 规则

| 项 | 值 |
|---|---|
| **池子** | 48 段（8 个玩家可读主题；后台仍映射 8 个疾病父类） |
| **限额** | 选 **10 段** |
| **同类上限** | 同一类最多 2 段 |
| **单段净值** | 原始属性变化合计固定为 **+2**；常规写作 `+2` 或 `+1/+1`，允许用 `+3/-1` 表达一项专长伴随另一项损耗 |
| **属性封顶** | 每项 10（本能） |
| **互斥** | 三组七对（§3.3）——互斥的段**灰掉不可选** |
| **提前预览** | 未选满也能进入属性、候选与疾病页；持续显示“尚有 N 段未使用”，镜子页只能预览，选满后才可确认 |

属性先汇总全部已选经历，再统一限制到 **0–10**。因此 `-1` 是已准入的真实数值代价，但不会把最终属性压到 0 以下；统一结算也保证经历的选择顺序不影响结果。`+3/-1` 只用于经历本身能同时说明“练得特别强”与“另一项确实受损”的条目，不为制造负面而滥用。

### 3.1.1 经历卡的“负担”文案（原型提案，未准入）

> ⚠️ **状态边界**：上面的属性变化（包括 `+3/-1` 中的 `-1`）已直接结算；“留下什么负担”仍是 2026-09-18 Web 原型提出的**内容方向**，不是当前游戏已经承接的机制。`StoryEngine`、`data/story/` 与 1F 对话/调查内容尚未实现，故负担当前不写状态、不关内容门，也不额外产生数值减益。

原型中的经历卡暂时回答三件事：

| 字段 | 玩家看到什么 | 是否直接结算 |
|---|---|---|
| **发生过什么** | 2–3 句具体情境，不只是一行标签 | 否 |
| **属性如何变化** | `+2`、`+1/+1` 或 `+3/-1`；原始净值恒为 +2 | 是 |
| **它留下什么负担** | 一条与该经历同源的局限、习惯或内容风险，并明确标为“提案 · 未接入游戏” | **否；待未来逐条准入** |

如果未来准入，经历负担与疾病的“关门/代价”也不是同一层：**经历负担说明你为什么会犹豫选这段人生**；疾病代价说明选定疾病后游戏内容如何改变。任何负担接入对话、调查或空间门之前，必须先逐条写出正式内容落点；在此之前 Web 只显示提案，不能据此宣称角色创建机制已经闭合。

#### 1 · 长期危险与警觉 → 焦虑唤醒障碍

> 不是胆小。是警报器确实一直在响，响得太久，现在没有威胁它也响。

#### 2 · 童年关系与家庭 → 人格障碍

> **「在你长成之前，没有人当你是个人。」**
> 不是性格不好。是当时那套活法管用，后来一直没换——因为没人告诉过你可以换。

| 人生经历 | 属性 | 疾病 |
|---|---|---|
| 从小寄养，换过几次家 | 沟通+2 | BPD · ASPD · DID |
| 父母长期不在（外出打工/离异/早逝） | 巧手+2 | BPD · ASPD · MDD |
| 家里有人酗酒、赌、动手 | 观察+3 · 沟通−1 | BPD · ASPD · PTSD |
| 很早就自己养活自己 | 巧手+1 · 体格+1 | ASPD |
| 被当成工具用（干活/照顾弟妹/替大人传话） | 巧手+2 | BPD · 分裂型 |
| 在学校长期被排斥、被欺负 | 观察+1 · 沟通+1 | 分裂型 · BPD · 社交焦虑障碍 |
| 亲近的人反复离开 | 沟通+2 | BPD |
| 长期扮演一个"懂事"的角色 | 沟通+1 · 意志+1 | 分裂型 · DID |

#### 3 · 身体评价与饮食控制 → 进食障碍

> **「身体是唯一被谈论、也唯一能管的地方。」**
> 别人越过你、评判你、替你决定。剩下能自己说了算的，只有吃和不吃。

| 人生经历 | 属性 | 疾病 |
|---|---|---|

#### 4 · 工作压力与失去控制 → 认知控制障碍

> **「你只能用控制来应付。」**
> 事情不在你手上，所以你抓住你能抓住的：一个数字、一个顺序、一个"等我准备好"。抓不住的时候，你连开始都做不到。

| 人生经历 | 属性 | 疾病 |
|---|---|---|

| 长期被安排，没有决定权 | 沟通+3 · 意志−1 | 拖延症 · AN |
| 家里规矩极多，错一点就罚 | 巧手+1 · 观察+1 | OCD · 分裂型 |
| 长期缺钱，每一笔都要算 | 巧手+1 · 观察+1 | 拖延症 · SUD · MDD |
| 反复失业、反复换工作 | 沟通+1 · 体格+1 | 拖延症 · MDD · SUD |

#### 5 · 身份变化与被迫适应 → 解离性障碍

> **「你把自己分开了，才能继续。」**
> 不是忘记。是当时必须有一部分不在场，后来那部分就一直不在场。

| 人生经历 | 属性 | 疾病 |
|---|---|---|
| 长期反复搬家、转学、换地方（随迁/躲债） | 沟通+3 · 意志−1 | DID · BPD |
| 从小在两套完全不同的环境里来回（父母两家/城乡两头） | 沟通+1 · 观察+1 | DID · 分裂型 |
| 长期扮演一个不是自己的角色 | 沟通+1 · 意志+1 | DID · 分裂型 · ASPD |
| 被要求"把这件事忘掉" | 意志+1 · 巧手+1 | DID · PTSD |

#### 6 · 疾病、照护与身体劳损 → 躯体症状

> **「身体先出的事。」**
> 检查做了，报告是好的。报告不能说服你。

| 人生经历 | 属性 | 疾病 |
|---|---|---|
| **重体力劳动（工地/搬运/矿上/种地）** | **体格+2** | SSD · 慢性疼痛 |
| 自己得过重病、做过大手术 | 观察+3 · 体格−1 | SSD · 惊恐障碍 · MDD |
| 长期慢性疼痛 | 观察+1 · 意志+1 | SSD · MDD |
| 受过工伤 | 体格+1 · 观察+1 | SSD · PTSD |
| 长期在粉尘、噪音、化学环境干活 | 体格+1 · 巧手+1 | SSD |
| 长期照护卧床的人（喂饭/翻身/处理排泄） | 巧手+1 · 意志+1 | SSD · GAD · BED |

#### 7 · 贫困、失败与失去 → 奖赏系统障碍（期待落空组）

> **「你要的东西一直没来，或者来了又走了。」**
> 不是不努力。是努力和结果之间的那根线断了，断得足够久。

| 人生经历 | 属性 | 疾病 |
|---|---|---|
| 长期穷过 | 巧手+1 · 观察+1 | MDD · SUD · 环性 |
| 做生意亏过、欠过债 | 沟通+3 · 意志−1 | MDD · SUD |
| 长期做看不到头的重复劳动（流水线/计件） | 巧手+1 · 体格+1 | MDD · PDD |
| 得到过又失去（挣到过又没了/被裁员） | 沟通+2 | BD-I · BD-II · MDD |
| 反复失败过 | 巧手+2 | MDD · PDD |
| **长期的、没有出口的消耗** | **意志+2** | PDD · 环性 · MDD |

#### 8 · 排斥、监视与敌意 → 奖赏系统障碍（被针对组）

> **「你一直被当成有问题的那一个。」**
> 别人对你的恶意是持续的、具体的、有名字的。久了以后，你开始在没人针对你的时候也看得出来。

| 人生经历 | 属性 | 疾病 |
|---|---|---|
| 长期在单位/厂里被人整、被排挤 | 观察+3 · 沟通−1 | 偏执型 SZ · 未分化型 SZ · 分裂情感 · 分裂型 |
| 在集体宿舍、封闭单位里待过（长期没有退路） | 观察+1 · 意志+1 | 偏执型 SZ · 未分化型 SZ |
| 从小被当成"有问题"的那个孩子 | 观察+2 | 未分化型 SZ · 分裂情感 · 分裂型 |
| 长期被监视、被查、被举报过 | 观察+1 · 意志+1 | 偏执型 SZ · 分裂情感 |
| 家族或小圈子里长期有派系斗争 | 沟通+1 · 观察+1 | 偏执型 SZ · 分裂情感 · 分裂型 |

#### 无经历（发育轨 · 独立一屏）

| 疾病 | 说明 |
|---|---|
| **ASD** · **ADHD** | [转化接口 §3.2.1](../rules/skill-tree/%E5%88%9B%E4%BC%A4%E8%AE%B0%E5%BF%86%E8%BD%AC%E5%8C%96%E6%8E%A5%E5%8F%A3.md) 已裁定二者属**发育性**（遗传度 ~74% / 同 ASD），不参与创伤转化。**它们不由经历产生**——开局面上独立成"生来的"一屏 |

### 3.3 互斥（三组七对）

判据不是"不可能共存"，是**"你不能同时站在两个位置上"**。互斥的段在开局界面上**灰掉**。

先例：[角色与面具 §8.9.2](../entities/%E8%A7%92%E8%89%B2%E4%B8%8E%E9%9D%A2%E5%85%B7.md) **拮抗互斥**。

| 组 | 互斥对 | 为什么 |
|---|---|---|
| **A 身份**<br>（你在那段处境里的位置） | 长期扮演"懂事"的孩子 ⟷ 从小被当成"有问题"的那个孩子 | 一个是被要求消失，一个是被指认出来 |
| | 很早就自己养活自己 ⟷ 长期被安排，没有决定权 | 一个是你自己扛，一个是别人替你定 |
| | 一个人在陌生城市，没有熟人 ⟷ 集体宿舍、封闭单位待过 | 一个是没有同类，一个是没有退路 |
| **B 行当**<br>（同一段时间只能靠一样吃饭） | 要称重的活（舞蹈/体操/模特） ⟷ 重体力劳动（工地/搬运/矿上/种地） | 身体被要求是"轻"还是"重" |
| | 核对类工作（会计/校对/质检） ⟷ 看不到头的重复劳动（流水线/计件） | 一个要求你盯住，一个要求你别想 |
| | 流动/远离的活（长途/海上/井下） ⟷ 固定的岗（门卫/看场子） | 一个是一直在走，一个是一直在站 |
| **C 家庭气质**<br>（你长大的家不能同时是两种） | 家里有人酗酒、赌、动手（失控） ⟷ 家里规矩极多，错一点就罚（过度控制） | 家里不能同时是没人管和管到死 |

### 3.4 属性分布（48 段统计）

| 属性 | 点数 | 判读 |
|---|:---:|---|
| **观察** | 37 | **本作主属性**——精神卫生中心里最值钱的能力是"看得出别人怎么了" |
| **沟通** | 22 | 第二；已计入三条沟通 −1 |
| **巧手** | 18 | |
| **体格** | 11 | 已计入重病经历的体格 −1 |
| **意志** | 8 | 最少；已计入四条意志 −1，且**每一点都贵**——见下 |

以上是 48 段经历的**原始向量总和**，合计 96（48 × 2），尚未按玩家实际选择或单项 0–10 边界截断。

**意志的判定规则（唯一带规则的一项）**：意志**不是**"你受过苦"，是——

> **你持续对抗一件不会结束的事，而且没有退出。**

| 给意志 | 不给意志 |
|---|---|
| 长期疼痛（不会好） | 夜班三班倒（换个工作就结束） |
| 家里有病人，你随时待命（不会结束） | 危险环境干活（每天下班就结束） |
| 封闭单位待过（出院前没有退路） | 反复失业（每段都会结束） |
| 被跟踪、被威胁（不会结束） | 学校被排斥（毕业就结束） |
| 长期的、没有出口的消耗 | 寄养、父母不在（这是遭遇，练的是别的） |
| 长期扮演不是自己的角色 | |
| 被要求"把这件事忘掉" | |
| 长期被监视、被查 | |

**其余四项是你练出来的本事（做得多就会），意志是你没走开。** 这个区分正对本作那句主题——**「你无法选择出现什么，只能选择怎么面对」，意志就是"怎么面对"。**

### 3.5 需 owner 拍的一条

**经历是"限额选的"还是"给定的"？** 当前按**限额选的**（10 段）写。另一条路是"你的人生已经定了，你只能决定面对哪些"——那条更贴主题，但玩家能动性更小。

|:-:|---|---|---|---|---|---|
| 1 | PTSD | 闯入 | 危险可能重现 → **观察+1** | 走廊里你先看见：明雷进视野前就亮起（遭遇） | 慌起来时自问页不响应（调查） | 闪回：L5 全锁 + 目标锁死 |

| 7 | 未分化型精神分裂症 | 闯入 | **无**——没有固定形状就是它的定义 | 没人能给你画一张像：试探/套话对你无效（对话） | 你抓不住细节：小字/批注读不全，线索只记一半（调查） | 行为被替换 |
| 8 | 解离性身份障碍 | 接管 | 切换之后 → **沟通+1** | 有些事别的 alter 做得到：同一个 NPC 会看见完全不同的对话（对话） | 你不记得自己拿过什么：线索页出现没印象的条目（调查） | 你不选谁上来；人称切换 |
| 9 | 重度抑郁症 | 信念 | 有人试图鼓励你 → **意志+1** | NPC 在硬撑时你看得出来（对话） | 你起不来：每个游戏日上午动不了（空间） | **正向的东西传不进来**；拒绝执行你选的行动 |
| 10 | 持续性抑郁障碍 | 信念 | 长期消耗中 → **意志+1** | 你不需要好转也能继续：连续多时段不休息也不掉状态（空间） | 鼓舞/回忆美好类话对你无效（对话） | 没有「平常的一天」 |
| 11 | 广泛性焦虑障碍 | 信念 | 说不清哪里不对 → **观察+1** | 你不等证据：「这里不对」的氛围线索提前拿到（调查） | 你休息不好：护士站恢复打折，多花一倍时间（空间） | 担忧泛化：识破一个敌人的信息自动套到**所有**未知上，包括套错 |
| 12 | 强迫症 | 信念 | 需要核对/检查 → **巧手+1** | 不对的地方一定会发现：被动过的东西 100% 进线索页（调查） | 你必须回头：每 3 个房间重走第 1 个（空间） | 侵入性怀疑：下回合必须做同类型行动 |
| 13 | 反社会型人格障碍 | 信念 | 你要操纵一个人 → **沟通+1** | 你想让谁做什么他就做什么：操纵/施压是正常选项（对话） | 没有人为你挡：遭遇里不会有人加入你（遭遇） | **共感/归属不可用**；目标自动锁定 |
| 14 | 物质使用障碍 | 信念 | 渴求中 → **意志+1** | 你有办法让自己立刻好受：一次行动换即时恢复（遭遇） | 你的动线被钉住：每 2 个时段必须回同一个房间（空间） | 戒断：行动净 −1、SAN 持续掉 |
| 15 | 神经性厌食症 | 信念 | 涉及数字/计量 → **巧手+1** | 数字不会骗你：领药单、食堂账、剂量一眼看穿（调查） | 别人递过来的东西你接不了（对话） | HP 上限持续下降，身体在消耗自己 |
| 16 | 拖延症 | 信念 | 你已经开始做一件事之后 → **巧手+1** | 你攒得下来：线索页「暂时没用」的条目不会忘（调查） | 每个时段先浪费一次：新时段第一次对话只能闲聊（对话） | 启动难：第一个新操作要占语言通道 |
| 17 | 双相障碍I型 | 摆荡 | 躁狂相 → **沟通+1** ／ 抑郁相 → **意志+1** | 躁狂相你能连着打：遭遇里行动次数 +1（遭遇） | 躁狂相你停不下来：**选不了「休息」**，时段不推进（空间） | 摆荡本身：抑郁相正向输入减半 |
| 18 | 双相障碍II型 | 摆荡 | 轻躁狂期 → **巧手+1** ／ 抑郁相 → **意志+1** | 轻躁狂期你突然会做事：要动手的调查一次成功（调查） | 你好的时候比坏的时候短：每 3 个时段有 2 个抑郁相（空间） | 抑郁期更长 |
| 19 | 持续性心境障碍（环性） | 摆荡 | 相位切换前 → **观察+1** | 你比谁都懂周期：排班表、用药时间表自动看懂（调查） | 你没有「正常的一天」：连续两时段做同一件事不成立（空间） | 长期增益类效果减半 |
| 20 | 边缘型人格障碍 | 摆荡 | 关系刚变动 → **沟通+1** | 关系一变你就知道：NPC 关系值变动即时显示（对话） | 你会自己伤害自己：HP→SAN 兑换不受控触发（遭遇） | 关系双倍结算：涨得快，崩得也快 |
| 21 | 社交焦虑障碍 | 摆荡 | 有人在场 → **观察+1** | 你不会被偷袭：休息时的偷袭判定先亮（遭遇） | 有人的时候你说不出话：两个以上 NPC 时「开口」全不出现（对话） | 事后反刍；被注意时行动成本上升 |
| 22 | 分裂情感性障碍 | 摆荡 | **无**——两条线同时在场，没有单一情境 | 同一件事你有两套说法：换个说法再问不会起疑（对话） | 你自己写的东西会变：亲手记的线索会被改写（调查） | 升档快降档慢；身份陈述不稳定 |
| 23 | 神经性贪食症 | 摆荡 | 摄入/补给 → **体格+1** | 你能一次吃下两份：补给道具一次用两份（遭遇） | 你要背着人：补给只能在没有 NPC 的房间做（空间） | 补偿行为：延迟扣减，且更痛 |
| 24 | 暴食障碍 | 摆荡 | 需要扛/推/负重 → **体格+1** | 你扛得住：堵住的门、要推开的东西对你无效（空间） | 你越来越不想解释：每累积一次羞耻，「解释/辩解」少一个（对话） | **痛苦不清零**：暴食后 SAN 不恢复 |
| 25 | ASD | 闯入 | 有明确规则 → **巧手+1** | 规则类的东西不需要想：排班表、门禁、用药周期免检定（调查） | 暗示对你不是难，是**不存在**：看眼色/寒暄/客套根本不出现（对话） | 环境剧变触发过载；选项只显示一半 |
| 26 | ADHD | 闯入 | 同一件事连做 ≥3 次后 → **观察+1** | 一件有意思的事你能钻进去：同房间连查 3 次后线索全出（调查） | 你会在不该走神的时候走神：时段末有概率自动移动到走廊（空间） | 漂移：释放一个随机高链路、自动激活一个随机低链路 |

**两张不给临时加成（设计，不是遗漏）**：**未分化型 SZ**（"没有一种症状能代表你，全都有"）与**分裂情感**（"两条线同时在，谁都不能替谁解释"）——它们的定义就是**没有单一的成立情境**。给它们任何一条加成，都要先给它们一个形状，那就推翻了它们是什么。

### 4.2 四种表现形态

> 分组依据 = [转化接口 §3.2.3](../rules/skill-tree/%E5%88%9B%E4%BC%A4%E8%AE%B0%E5%BF%86%E8%BD%AC%E5%8C%96%E6%8E%A5%E5%8F%A3.md) 的**记忆表征偏好表**（N 叙事化 / F 碎片化 / D_seg 区隔化），不新增分类维度。
>
> **这是对"不同的疾病对患者的影响是不同的，不只是内心声音这种形式"的回答。**

| 形态 | 表征条件 | 它是什么 | 文体 | 覆盖疾病 |
|---|---|---|---|---|
| **闯入式** | F ≥ 0.70 | 它不等你叫它 | 短句、断句，**打断**玩家当前动作/对话。不用引号，不写"它说"——写成**发生** | PTSD · 惊恐 · 特定恐惧 · 躯体症状 · 偏执型 SZ · 分裂型 · 未分化 SZ · ASD · ADHD |
| **信念式** | N ≥ 0.65 | 它从不打断你，它是你思考的底色 | 完整句、笃定的断言，**可直接作为对话选项**——玩家点它，等于让病替自己回答 | MDD · PDD · GAD · OCD · ASPD · SUD · AN · 拖延 |
| **接管式** | D_seg ≥ 0.85 | 不是你听见什么，是**你不在** | 人称/名字改变，**别人格以第一人称说话** | DID |
| **摆荡式** | N、F 皆居中 | 它按周期来 | 相位播报；**同一句话在两个相位意思相反**（唯一修辞） | BD-I · BD-II · 环性 · BPD · 社交焦虑 · 分裂情感 · BN · BED |

### 4.3 每病风味与样本

> 样本按形态换文体。**闯入式写成事件、信念式写成可点的选项、接管式写成别人的第一人称、摆荡式写成同一句的两面。**

| 疾病 | 风味（一句话） | 它怎么出现 |
|---|---|---|
| PTSD | 那件事结束了。它没有。 | 〔打断〕走廊尽头有脚步声。不是这次这个。／〔结算〕你不是在想那件事。你在那件事里。 |
| 惊恐障碍 | 心脏先跑。你后知后觉地跟上。 | 〔打断〕手先麻了。然后是胸口。你知道接下来是什么。／〔结算〕这次不是。这次也像。 |
| 特定恐惧症 | 身体比你想得早知道什么是危险的。它只是分不清"危险"和"不熟悉"。 | 〔打断〕别碰那个。／〔结算〕你退了两步。你甚至没看清是什么。 |

### 4.5 镜子中的面具整理（低优先级）

疾病结算之后，开局最后一步进入**随身镜子的界面**整理自己的面具。本作当前不设计玩家人脸；面具承担角色的可见面部形象，但**不承担职业、角色或疾病的再次选择**。

| 层 | 规则 |
|---|---|
| **输入** | 已在上一屏选定的疾病；镜子步骤不能新增、删除或换病 |
| **疾病外观** | 每种疾病可映射为面具上的**挂件、花纹或裂隙**；逐病造型与组合规则待后续美术设计 |
| **玩家可改** | 调整挂件在面具表面的摆放位置；花纹、裂隙的编辑范围暂未裁定 |
| **不产生的效果** | 移动外观不改变基本属性、疾病机制、内容门或面具装备效果 |
| **技术边界** | 暂无刚体、碰撞、布料、骨骼挂点等物理依赖；当前只记录交互意图，不立即实现编辑器 |
| **优先级** | 低；先保留 Web 的镜子总结页，待面具视觉方案与疾病映射收敛后再制作 |

这里沿用“随身镜子 = UI 界面”的现行定义，不恢复已废弃的固定安全屋“镜子房间”。它也与 [角色与面具 §8.1](%E8%A7%92%E8%89%B2%E4%B8%8E%E9%9D%A2%E5%85%B7.md) 的游戏内装备层分开：**开局面具先表达已经结算的疾病外观；探索中取得的组件与装备效果仍是另一套待整理的机制。** 两者是否最终合并，留待面具系统重审时决定。

### 4.6 固有疾病：《无法离开医院》（🔧 2026-09-20 owner 命名）

> **背景**：owner 2026-09-18 裁定玩家有一个使其能感受医院超自然现象的固有疾病；2026-09-20 进一步确定其名与核心症状为**《无法离开医院》**。它不是对现实诊断的替换称呼，而是本作独有的叙事性疾病。

#### 4.6.1 定位：一个**结构槽位**，不是第 27 个病

| 项 | 规则 |
|---|---|
| **不可选** | 不进经历解锁链（§三），不出现在疾病候选屏（§4.1 的选择流程） |
| **不占额度** | 与"选几张疾病"（§六 待办 3）无关——它恒常在场 |
| **不给属性** | 与全部 26 病一致：不给数值加成（唯一例外仍是 §2.3 的临时 +1） |
| **不可关闭** | 其他疾病是玩家在开局中做的选择；这一样在选择之前已经发生 |
| **恒常开** | 开局五屏走完之后，它一直在 |

#### 4.6.2 可观察症状与玩法接口

```
① 边界失效   —— 玩家无法完成"从医院到外面"的连续过渡；
                绕行会回到大门，穿过出口也可能再次成为院内的人
② 身份黏着   —— 玩家自称"苟智空"，医院却以手环、床位和编号将他识别为"苟笙 / 0527"
③ 夜晚保留   —— 玩家保留夜晚记忆，并能在白天辨识未复位的物证
④ 证言失效   —— 他对"我刚从外面来"和"夜里发生过什么"的陈述，
                会被现有身份记录反向解释为症状
```

> “身份黏着”是开场能观察到的矛盾，不等于文档已裁定哪个姓名是真、手环从何而来，也不等于《无法离开医院》是所有异常的唯一原因。这些仍受 [世界观与叙事](../events/%E4%B8%96%E7%95%8C%E8%A7%82%E4%B8%8E%E5%8F%99%E4%BA%8B.md) 的不可证实边界约束。

> ⚠️ **昼夜边界不变**：白天仍然没有超自然现象可看。《无法离开医院》给玩家的昼夜接口仍是**记忆 + 对残留的辨识力**，不是“白天也能看见怪物”。

#### 4.6.3 不复用现实诊断

旧稿曾提议把第 6 号“分裂型人格障碍”提为玩家固有疾病。**2026-09-20 裁定后该提议作废**：《无法离开医院》与 §4.1 的 26 种可选疾病并列，不占用、替换或暗示其中任何现实诊断。玩家可以在此之外选择零种或多种可选疾病。

#### 4.6.4 开局呈现（与 §4.5 镜子挂钩）

它不占用面具上的疾病挂件位。开局的身体证据是**蓝色患者手环**：上面写着“苟笙 / 0527 / B 栋 147 室 4 床”，与玩家对自己的记忆不一致。手环是入院矛盾的物证，不是可编辑的外观配件。

## 五、效果三层

> **核心约束**：[空间与关卡设计 §7.1](../space/%E7%A9%BA%E9%97%B4%E4%B8%8E%E5%85%B3%E5%8D%A1%E8%AE%BE%E8%AE%A1.md) ——**白天 = 现实层**（无战斗、无技能、无造物、无扭曲）；**夜晚 = 超自然层**。白天是纯叙事/探索/对话时段。
>
> ⇒ **疾病的效果不能全堆在战斗上，否则疾病在整个白天什么都不做。**

| 层 | 疾病在这里做什么 | 什么时候起作用 |
|---|---|---|
| **属性层** | 特定情境下临时 **+1**（§2.3）——**改用法，不改点数** | 一切时候 |
| **内容层** | **开一道门 / 关一道门**（对话 · 调查 · 空间 · 遭遇） | **白天也在起作用——这是主战场** |
| **战斗层** | ~~遭遇里的具体数值~~ | **暂停**（owner 2026-09-17 裁定暂不考虑） |

### 5.1 内容门（四类）

| 门类 | 管什么 | 游戏内表现 | 权威 |
|---|---|---|---|
| **对话门** | NPC 对话选项的**出现 / 说得出口 / 有效** | 有些选项你**看不见**——不是失败，是**不存在** | [剧情系统设计 §3.4](../events/%E5%89%A7%E6%83%85%E7%B3%BB%E7%BB%9F%E8%AE%BE%E8%AE%A1.md) |
| **调查门** | 环境交互能不能**捡起线索**，以及线索能不能**用** | 读字条 / 查病历 / 摸涂鸦 → 笔记本线索页；有些读不全、有些拼不起来 | [任务目标系统 §2.2](../events/%E4%BB%BB%E5%8A%A1%E7%9B%AE%E6%A0%87%E7%B3%BB%E7%BB%9F.md) |
| **空间门** | 能不能**进 / 待得住** | 护士站（白天真人 / 夜晚投影）· 走廊 · 病房 · 扭曲病房（门关上不可逆）· 楼梯间 | [空间与关卡设计 §3.6/§6.3/§6.6](../space/%E7%A9%BA%E9%97%B4%E4%B8%8E%E5%85%B3%E5%8D%A1%E8%AE%BE%E8%AE%A1.md) |

> **内省 = 自问页**：笔记本第三层（[任务目标系统 §2.3](../events/%E4%BB%BB%E5%8A%A1%E7%9B%AE%E6%A0%87%E7%B3%BB%E7%BB%9F.md)）是"内省"在内容层的落点——[核心机制 §5.2](../rules/%E6%A0%B8%E5%BF%83%E6%9C%BA%E5%88%B6.md) 的"内省"与 [角色发展轴](%E8%A7%92%E8%89%B2%E5%8F%91%E5%B1%95%E8%BD%B4.md) 的 IN-2（玩家主动向自己提问）是同一件事的两个面。**"不能用内省"在场景里的意思就是"自问页不响应"**，不是一条数值。

### 5.2 权衡从哪里来

**疾病的价值不在数值上，在内容可达性上**——它决定你能**见到谁、进哪间房、捡起哪条线索、说得出哪句话**。

| 权衡 | 玩家的问题 | 机制 |
|---|---|---|
| **开与关** | 我想要哪种人？ | 每张开一道门、关一道门 |
| **代价** | 我愿意带着什么走？ | 每张卡常驻的内容层代价（§4.1 末列） |
| **加成与锁** | 我在这件事上更准，代价是什么？ | 临时加成与"关的门"**同源**（§2.3） |

**权衡发生在游戏内，不在创建界面。**

> 创建界面**只给门的方向，不给数量**。玩家真正做权衡的时刻是**进楼层之后**：他站在一间关着的房门前，或者看着一个不出现在选项里的说法，才知道自己拿了什么、丢了什么。

**⇒ 内容生产约束**：关掉的门**必须可见**。玩家要走到一间进不去的房、看到一个不出现的选项、读到一条读不全的线索，才知道自己丢了什么。**沉默的代价不算代价。**
