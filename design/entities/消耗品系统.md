# 消耗品系统

> 精神科药物作为消耗品，通过链路调制影响战斗资源（HP/SAN/速度/状态）。药物不直接加减数值，而是对特定链路/上下文链路组施加调制（D28，2026-08-03 13 功能域废弃），HP/SAN/速度变化是链路调制的涌现结果。

## 一、元规则

| 规则 | 内容 |
|------|------|
| **动作成本** | 战斗中消耗品使用 = 1 个动作（替代该回合的物理攻击/精神攻击/防御/技能） |
| **持续时间** | 调制效果持续整场战斗（不追踪回合数） |
| **非战斗使用** | 部分药物（SSRI、尼古丁等）可在战斗外使用，效果在下一场战斗/休息时生效 |
| **生效方式** | 药物不直接加减 HP/SAN/速度，而是**对指定链路（链路级）或上下文链路组（上下文级，特殊药）施加调制**，HP/SAN/速度变化是下游涌现（D28） |
| **每回合限制** | 每回合最多使用 1 种药物 |
| **同种叠放** | 同种药物最多 2 片/槽 |

## 二、调制模型

### 2.1 调制类型

| 类型 | 符号 | 含义 | 涌现下游 |
|------|------|------|----------|
| **抑制** | ↓ | 降低目标链路传导效率（有效 m 值暂时衰减） | 目标链路功能减弱 |
| **增强** | ↑ | 提升目标链路传导效率（有效 m 值暂时放大） | 目标链路功能增强 |
| **钳制** | ↕ | 目标链路域不能超出预设阈值范围 | 该域功能被锁定在稳定区间 |

### 2.2 调制强度

| 强度 | 有效 m 值偏移 | 适用场景 |
|------|-------------|----------|
| **弱** | ±0.1-0.2 | 辅助/辅助调制（尼古丁、布洛芬、SSRI） |
| **中** | ±0.2-0.4 | 主要治疗效果（地西泮、奥氮平、哌甲酯） |
| **强** | ±0.4-0.6 | 紧急/极端干预（氯氮平、劳拉西泮注射、氟哌啶醇） |

### 2.3 与面具组件调制的关系

| 规则 | 内容 |
|------|------|
| **叠加上限** | 同一条链路的药物调制 + 组件调制 → 总调制偏移 ≤ 该链路的拮抗天花板（m 总和 ≤ 1.4） |
| **冲突** | 药物抑制 + 组件增强同一条链路 → 取绝对值最大者（不叠加，不抵消） |

## 三、药物目录（17种）

### 3.1 苯二氮䓬类（防御域/唤醒域 ↓）

#### 地西泮

- **现实机制**: GABA-A 正变构 → Cl⁻ 内流↑ → 全脑抑制↑。口服 15-30min 起效，半衰期 20-100h
- **链路调制**: 防御域 ↓(中) / 唤醒域 ↓(中)
- **涌现效果**: SAN 承受力 ↑（威胁被压制）、速度 ↓
- **依赖风险**: 参见 §四

#### 劳拉西泮（注射）

- **现实机制**: 同地西泮，IM 注射 10-20min 达峰。无活性代谢物
- **链路调制**: 防御域 ↓↓(强) / 运动域 ↓↓(强)
- **涌现效果**: 当回合 SAN 不受威胁 + **跳过下回合**
- **依赖风险**: 与地西泮共享交叉依赖

---

### 3.2 抗精神病药（奖赏域/认知控制域）

#### 氟哌啶醇

- **现实机制**: 强 D₂ 受体阻断 → 镇压幻觉/妄想。EPS（类帕金森/静坐不能/肌张力障碍）
- **链路调制**: 奖赏域(D₂) ↓(强) / 行动门控域 ↓(中)
- **涌现效果**: 清除幻觉/妄想等精神异常 + 概率动作失败（僵硬）
- **注意**: 只阻断 D₂ → 不对抗 5-HT₂A → 阴性症状可能加重

#### 奥氮平/喹硫平

- **现实机制**: 弱 D₂ + 强 5-HT₂A 阻断 + H₁ 阻断。代谢综合征（体重↑↑/血糖↑）
- **链路调制**: 奖赏域(D₂) ↓(弱) / 认知控制域 ↑(中) / 唤醒域 ↓(中)
- **涌现效果**: 每回合 SAN 持续小幅恢复 + 全程速度 ↓

#### 氯氮平

- **现实机制**: 快解离弱 D₂ 结合 + 5-HT₂A + M₁ + H₁。唯一获批难治性精神分裂症。粒细胞缺乏 ~1% → 强制血检
- **链路调制**: 奖赏域 ↓(快解离) / 认知控制域 ↑(中) / 整合域 ↕(中)
- **涌现效果**: SAN 大幅恢复 + 清除所有精神异常。运动链路几乎不受影响
- **特殊代价**: "血液警戒标记"——后续同类抗精神病药效果减半（耐药）

---

### 3.3 兴奋剂（认知控制域 ↑）

#### 哌甲酯

- **现实机制**: DAT 阻断 → 纹状体 + PFC DA↑。儿童ADHD一线（Cortese 2018）
- **链路调制**: 认知控制域 ↑(中) / 奖赏域 ↑(弱)
- **涌现效果**: 下 N 回合速度+X% + 链路命中率+Y%
- **代价**: 结束后 SAN -Z（DA crash）+ 长期使用 → 奖赏域可能生成临时病理链路
- **成瘾风险**: 参见 §四

---

### 3.4 胆碱能拮抗剂（记忆域 ↓）

#### 东莨菪碱

- **现实机制**: 非选择性 mAChR M₁-M₅ 阻断。识别记忆 SDM -1.84 (Miravalles 2025 meta)。透皮贴剂 0.5mg/72h。麻醉前用药
- **链路调制**: 记忆域 ↓↓(强)
- **涌现效果**: 敌方最近 N 回合行动信息暂时无法访问（记忆编码中断）
- **副作用**: 高剂量 → 幻觉

---

### 3.5 NMDA 拮抗剂（自我域 ↓、感觉域 ↓）

#### 氯胺酮/艾氯胺酮

- **现实机制**: NMDA 拮抗 → GABA 中间神经元↓ → 谷氨酸↑ → AMPA → mTOR → BDNF。艾氯胺酮(Spravato®) FDA 2019 批准，24h 抗抑郁起效。解离是副作用
- **链路调制**: 自我域 ↓(中) / 感觉域 ↓(中)
- **涌现效果**: "离开自己"——自我-他人边界模糊 → SAN 暂时不受社交威胁影响。感觉信号过滤增强
- **副作用**: 解离（短暂）、血压↑（需监测）

---

### 3.6 5-HT₂A 激动剂（感觉域 ↑↑、识别域 ↑↑）

#### LSD/赛洛西宾

- **现实机制**: 5-HT₂A 激动 → 网络间 FC↑、网络内 FC↓。LSD > 赛洛西宾 视觉重构 (Shinozuka 2024)。赛洛西宾 Phase 2b TRD: 1周显著有效 (OR=7.60)
- **链路调制**: 感觉域 ↑↑(强) / 识别域 ↑↑(强) / 内感受域 ↓(中)
- **涌现效果**: **感知范围扩大**——可能"看到"隐藏敌人 + 识别模式检测阈值降低 = 假阳性识别（可能看到不存在的）
- **特殊**: 拜月教仪式药物

---

### 3.7 血清素-催产素复合作用（内感受域 ↑、自我社会域 ↑、语言社会域 ↑）

#### MDMA

- **现实机制**: SERT 反向转运（不是阻断——把 5-HT 从突触前泵出来）+ DA + NE 释放 + **催产素系统**激活。PTSD 缓解率 ~80% (Phase II/III)。**FDA 2024/08 拒绝批准**
- **链路调制**: 内感受域 ↑(中) / 自我社会域 ↑(中) / 语言社会域 ↑(中)
- **涌现效果**: 体感增强 + 社交亲和+信任↑ + 语言社交流畅性↑。对社交类精神攻击有抗性
- **代价**: 社交防御↓ → 对欺骗/操纵的防御↓。高体温/低钠血症风险
- **叙事**: 非法——地下治疗网络或特殊NPC提供

---

### 3.8 情绪稳定剂（防御域+奖赏域 ↕）

#### 碳酸锂

- **现实机制**: GSK-3 抑制 → 谷氨酸正常化 + 5-HT 增强。金标准抗躁狂+防复发。降自杀风险 (Cipriani 2013 BMJ: OR 0.13)。治疗窗极窄 (1.5-2×)
- **链路调制**: 防御域 ↕(中) / 奖赏域 ↕(中)
- **涌现效果**: **SAN 地板保护**——SAN 不会降到 X 以下。双向钳制 = SAN 也不会冲太高
- **过量风险**: 多服 1 颗 → 全链路过抑 → SAN 暴跌 + 运动链路失灵（震颤/共济失调）

---

### 3.9 SSRI（全 5-HT 能链路渐进重塑）

#### 氟西汀/舍曲林

- **现实机制**: SERT 阻断 → 突触 5-HT↑。血小板 5-HT 降低 70-90% 已验证靶点 (Anderson 2023)。起效 2-6 周
- **链路调制**: 全 5-HT 能链路 持续调制(弱)（非急性——2-6 周神经可塑性过程）
- **涌现效果**: **非战斗消耗品**——下次休息 SAN 恢复量 +X%
- **代价**: 延迟起效（战内无用）；撤药综合征 → SAN 暂时下降

---

### 3.10 TCA（疼痛域 ↓、唤醒域 ↓↓）

#### 阿米替林

- **现实机制**: SERT+NET 阻断 + H₁/M₁/α₁ 拮抗。21 种抗抑郁药中疗效最高 (OR 2.13, Cipriani 2018)。最强镇静 + 心脏毒性
- **链路调制**: 疼痛域 ↓(中) / 唤醒域 ↓↓(强)
- **涌现效果**: HP +N + 速度 ↓（H₁ 阻断 → 与镇静强度成正比）
- **过量风险**: Na⁺通道阻断(高剂量) + 心脏毒性 → 概率 HP↓（致命性心律失常）

---

### 3.11 NSAID（外周疼痛 ↓）

#### 布洛芬

- **现实机制**: COX-1/COX-2 抑制 → 前列腺素↓ → 外周抗炎镇痛。不直接作用于 CNS 链路
- **链路调制**: 外周疼痛传导 ↓(弱)（非中枢调制）
- **涌现效果**: HP +少量（纯镇痛/抗炎）
- **特点**: 不占链路调制配额、不产生依赖、不过量致死、天花板低
- **限制**: 对精神源性的 HP 损失无效

---

### 3.12 β阻断剂（防御域躯体输出端 ↓）

#### 普萘洛尔

- **现实机制**: 非选择性 β 受体阻断 → 阻断 NE/肾上腺素的外周+中枢 β 效应。阻断焦虑的躯体端（手抖/心悸），不治焦虑本身
- **链路调制**: 防御域躯体输出端 ↓(中)（不抑制杏仁核本身）
- **涌现效果**: **免疫恐惧/恐慌状态** N 回合
- **代价**: 不直接恢复 SAN（恐惧的认知评估仍在）。心脏输出↓ → 物理行动速度微降

---

### 3.13 烟碱类（唤醒域 ↑(弱)）

#### 尼古丁

- **现实机制**: nAChR 激动 → 短暂注意/唤醒提升。精神病院病人间最流通的"货币"（吸烟率 40-80%）
- **链路调制**: 唤醒域 ↑(弱)
- **涌现效果**: SAN +微量 + **社交货币**（可与 NPC 交换信息/物品）。非战斗实用
- **依赖**: 轻度——戒断 = 唤醒域暂时抑制（易怒/注意缺陷）

---

### 3.14 综合抑制剂（防御域 ↓/唤醒域 ↓/认知控制域 ↓/奖赏域 ↑(弱)）

#### 酒精

- **现实机制**: GABA-A 正变构（同苯二氮䓬位点但不同结合口袋）+ NMDA 拮抗 + 伏隔核 DA 释放。剂量依赖：低=去抑制，高=运动损害+镇静，非常高=致死性呼吸抑制
- **链路调制**: 防御域 ↓(中) / 唤醒域 ↓(弱) / 认知控制域 ↓(中) / 奖赏域 ↑(弱)
- **涌现效果**: SAN 承受力微升 + 速度↓ + 命中率↓ + 社交解除抑制
- **剂量**: 低剂量=微效，高剂量=强效+更强副作用
- **特殊风险**: **与苯二氮䓬组合 = 致死**（GABA-A 双正变构协同）→ 参见 §九

## 四、风险模型

### 4.1 依赖与戒断（苯二氮䓬类/兴奋剂类）

| 阶段 | 规则 |
|------|------|
| **计数器** | 每种致依赖药物维护一个"累计使用次数"计数器 |
| **依赖阈值** | 累计使用 ≥ N 次 → 产生生理依赖 |
| **戒断触发** | 依赖后连续 K 场战斗未使用该类药物 → 触发戒断 |
| **戒断效果** | 被抑制的链路域**反弹式过度激活**（有效 m 值额外 +0.3-0.5，符号反转），持续 1-2 场战斗 |
| | 防御域反弹 → SAN 承受力下降 / 恐慌阈值降低 |

**致依赖药物**: 地西泮、劳拉西泮（共享交叉依赖——合并计算计数器）、哌甲酯

### 4.2 耐药（抗精神病药类）

| 阶段 | 规则 |
|------|------|
| **计数器** | 同类药物共享使用计数器 |
| **耐药阈值** | 累计使用 ≥ M 次 → 同类药效衰减 |
| **衰减规则** | 后续使用同类药物 → 调制强度 -1 级（强→中→弱→无效） |
| **交叉耐药** | 氟哌啶醇/奥氮平/喹硫平/氯氮平共享耐药计数器（均为 D₂ 靶点） |

### 4.3 过量（窄治疗窗药物）

| 阶段 | 规则 |
|------|------|
| **触发条件** | 单场战斗内使用 ≥ 2 次同种窄治疗窗药物 |
| **过量效果** | 目标链路域过度抑制/增强 → 调制量级翻倍 → 附加负面状态 |
| | 碳酸锂过量：SAN 暴跌 + 运动链路失灵 |
| | 阿米替林过量：唤醒域过抑 + Na⁺通道阻断 → 速度↓↓ + 概率回合跳过 + 概率 HP↓ |

**窄治疗窗药物**: 碳酸锂、阿米替林

### 4.4 安全类

以下药物不触发依赖/耐药/过量机制：布洛芬、尼古丁、普萘洛尔

## 五、获取与稀有度

### 5.1 获取手段（三种并存）

| 手段 | 说明 |
|------|------|
| **拾取** | 搜查病房床头柜/护士站/药房/拜月教藏匿处等关键设施 |
| **掉落** | 战斗后从特定敌人类型获取：医疗人员（强制药）、拜月教徒（仪式药）、精神病人（随机常见/不常见药） |
| **NPC 交换** | 与友好/敌对 NPC 交换——烟（尼古丁）是最流通的社交货币 |

### 5.2 稀有度分级

| 稀有度 | 获取难度 | 药物 |
|--------|----------|------|
| **常见** | 护士站/病房床头柜 | 布洛芬、尼古丁 |
| **不常见** | 护士站(限量)/特定敌人掉落 | 地西泮、氟西汀/舍曲林(SSRI)、普萘洛尔、酒精 |
| **稀有** | 药房/精英敌人掉落/Boss | 奥氮平/喹硫平、哌甲酯、阿米替林、碳酸锂、东莨菪碱、艾氯胺酮(Spravato) |
| **极稀有** | 药房禁区/Boss/叙事节点/拜月教 | 氯氮平、劳拉西泮注射、氟哌啶醇、氯胺酮(IV)、LSD/赛洛西宾、MDMA |

## 六、携带与使用

### 6.1 携带上限

| 阶段 | 容量 | 触发 |
|------|------|------|
| **初始** | 6 片 | 游戏开始 |
| **扩容 1** | +3 → 9 片 | 叙事节点触发（被动——如"获得护士信任"→得到大药瓶） |
| **扩容 2** | +3 → 12 片 | 叙事节点触发（主动——玩家探索拜月教藏匿处/偷窃药房钥匙→获得更大容器） |

### 6.2 物品栏

- **独立于技能槽**：不占用 6 个快捷技能槽位
- **显示全部携带的药片**：初始一排 6 槽，扩容后 9 → 12 槽
- **同种叠放**：同种药物最多 2 片/槽
- **战斗中随时取用**：选中药片 → 确认使用 → 消耗 1 个动作

### 6.3 补充

- 消耗品用尽后**不会自动补充**
- 获取途径：拾取/掉落/NPC 交换——用一片少一片
- 消耗品是稀缺资源，需要权衡何时使用

### 6.4 非战斗使用

SSRI（休息增益）、尼古丁（社交货币）、尼古丁（微量 SAN）等非即时类药物，在战斗外通过以下界面触发：
- 休息前准备界面——选择是否使用 SSRI 增强本段休息的 SAN 恢复
- NPC 交互界面——选择是否消耗尼古丁进行交换
- 探索界面——选择是否即时使用（如微量 SAN 恢复）

## 七、敌我同构

### 7.1 敌人使用消耗品规则

仅特定敌人类型携带和使用消耗品：

| 敌人类型 | 可用药物 | 说明 |
|----------|----------|------|
| **医疗人员**（压抑-反噬） | 劳拉西泮注射、氟哌啶醇、东莨菪碱 | 标准"强制治疗"武装——注射镇静+抗精神病+记忆抹除 |
| **拜月教徒** | LSD/赛洛西宾、MDMA、尼古丁 | 仪式致幻剂+地下流通货币 |
| **精神病人**（轻/中/重） | 随机持有 1 种常见/不常见药 | 病人间流通、偷藏药片——打败后作为掉落来源之一 |
| **思维造物**（投影/碎片/完整体） | 不携带/不使用 | 非人类实体，不摄入物质 |

### 7.2 敌人使用行为

- 医疗人员在"压抑-反噬"触发后可能对玩家使用强制注射
- 拜月教徒在仪式中可能自行使用 LSD（增强自身感觉域/识别域）
- 精神病人可能在生命值低时使用携带的药物

## 八、药物-技能交互

| 规则 | 内容 |
|------|------|
| **叠加上限** | 同一条链路的药物调制 + 面具组件调制 → 总偏移 ≤ 拮抗天花板（m 总和 ≤ 1.4） |
| **同域叠加衰减** | 两种药物调制同一链路域 → 后者的调制强度 -1 级，且受拮抗天花板限制 |
| **冲突** | 药物抑制 + 组件增强同一条链路 → 取绝对值最大者（不叠加，不抵消） |
| **药理不冲突** | SSRI + 哌甲酯、碳酸锂 + 普萘洛尔等不同链路域的药物可正常组合（不违反每回合 1 种规则的前提下） |

## 九、禁止组合

### 致死组合

| 组合 | 机制 | 结果 |
|------|------|------|
| **苯二氮䓬 + 酒精** | GABA-A 双正变构（同受体不同位点 → **协同放大**）→ 脑干呼吸中枢过度抑制 | 战斗不能 + HP 清零 |
| **SSRI + MDMA** | SERT 被 SSRI 阻断 + SERT 被 MDMA 反向转运 → **5-HT 大量释放但无法清除** → 5-羟色胺综合征 | SAN 清零 + 持续伤害 |

### 危险组合（非致死）

| 组合 | 机制 | 结果 |
|------|------|------|
| **氯胺酮 + 酒精** | NMDA 双重拮抗 + GABA-A PAM → 过度麻醉 | 跳过 2 回合（深度解离）+ 概率 SAN↓ |
| **碳酸锂 + 布洛芬** | NSAID 降低肾脏锂清除率 → 血锂浓度升高 | 锂盐过量触发（等同于多服 1 颗锂盐） |

玩家试图使用禁止组合时 → **警告提示**（如"你感到一阵剧烈的眩晕，意识到这两种药不能一起吃"）。致死组合直接阻止使用；危险组合允许玩家强行使用但触发负面效果。
