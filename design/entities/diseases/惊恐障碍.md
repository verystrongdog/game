## 默认标签

敏化-威胁 + 抑制不足（与 PTSD 标签组合相同——差异全在边层：PTSD = 跨层短路 + 闪回记忆 + LC→dlPFC 结构受损 + 左偏 Δ；惊恐 = 跨层短路 + 内感受误报环 + 发作自限机制 + Δ=0）。

## 行为覆盖

| 条件 | 约束 |
|------|------|
| 内感受边群（e05/e06/e07）m_max ≥ 0.2 | 内感受误报累积——每回合 10% 概率产生一次误报（心悸/气促→威胁）；误报计数 ≥ 2 → 触发发作检查（见非线性跳变） |
| 发作间期（e11 解耦生效） | 预期焦虑——每 5 回合一次"预期发作"检查（5% 概率误触发低强度警觉，不进入发作） |
| 突发刺激（e08 快速通路） | 突发刺激在场 → 发作检查概率 +10%/回合（情境触发端） |

## 思路链

- **发作核心**：e01（Amygdala→PAG 跨层短路 +0.2/+0.4/+0.6）——Klein 1993 窒息误报警（dPAG）+ Brandão dPAG 电刺激诱发惊恐样反应（L1→L0 突发劫持）
- **内感受误报反馈环**：e05/e06（Amygdala↔insula 双向过度耦合）——心悸→"我要死了"→更恐慌；e07（Thalamus→insula 躯体感觉中继放大）为误报信号源
- **NE 风暴**：e03（LC→Amygdala）+ e04（LC→insula）——发作 NE 瞬时 +0.3（δ_event）+ 发作间期高警觉
- **快速通路**：e08（SC→Amygdala）——突发刺激→发作检查概率 +10%（发作诱因感知端）
- **预期焦虑**：e11（vmPFC→Amygdala 解耦沉默）——"担心再次发作"（发作间期调控不足）
- **行动门控**：e09（Amygdala→Accumbens limbic GO）+ e12（precentral→Putamen somatic GO）——逃避/逃跑躯体行动超驱动（bias_somatic +0.15 惊恐独有）
- **发作自限性**：3 回合后回落 vs PTSD 持续锁定——核心机制分界；无记忆域边（发作不固化为闪回记忆）
- **7 参数**：NE +0.2 / 5HT −0.2 / bias_somatic +0.15 / bias_limbic +0.15（与 PTSD 同签名——机制区分在边层）
