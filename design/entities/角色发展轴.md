# 角色发展轴

> 「角色发展轴」= **"角色设定"演化载体的引用-组装式设计**（Grilling #121 定案，2026-09-06）。被控角色有初始设定、行为遵循之；经历（选择/受伤/人际伤害等，剧情未写）改变设定；"看起来会思考"由**内容层记录演化 + 只读接口**呈现。本系统**无新存储层、无新核心机制、无新增数值参数**——组装既有系统（记忆内容层 #90 / m 突破通道 #119 / 可塑性巩固 §八 / 笔记本自问层 / 议题槽），交付物 = glue 契约与输入/输出接口端点。
>
> **维度: 实体 + 事件** — 分拣：角色模板 → 实例的演化载体（实体）+ 进程推进与触发接口（事件）。

## 一、起源与边界

### 1.1 立项来源

- [#120](https://github.com/verystrongdog/game/issues/120) Q1 裁定（2026-09-06 边界收缩评论）：突破触发应跟**角色本身的身心发展进程**相关，而非（仅）主线事件；查证确认项目现无"角色身心发展"载体 → 拆出本 topic 专立载体。
- #119 P3：突破（m 0.8→1.0）= **存在性重组织**（自我模型/世界观级事件），日常理解 ≠ 叙事质变——突破需要"自我模型"层面的触发源。

### 1.2 定位声明

| 做 | 不做 |
|----|------|
| 定义"角色设定"的组成（S1-S6）与演化规则类型 | 不设计 m 任何公式（触发判定/阈值/涨幅/频率 → #120；数值平衡 → #35 轨）|
| 定义载体 = 对既有系统的引用与组装（glue 契约）| 不新建存储层、不新建核心机制（D-5）|
| 定义输入/输出接口端点（IN/OUT）| 不写 #90 铁律、不改 m 系统（D-6）|
| 定义核心议题语义与数量规则 | 不生产逐角色议题内容（内容批次）|

## 二、角色设定分解（S1-S6）

"角色设定"由六成分构成；**结构可增删（配置化，D-3a）**——设计期改动走受控登记（先例：term_registry / #90 schema 演化）。

| 成分 | 含义 | 现有载体 | 运行期立场 |
|------|------|---------|-----------|
| S1 静态内核 | 出身/背景/初始疾病/初始标签基线 | 角色模板（[角色与面具.md](%E8%A7%92%E8%89%B2%E4%B8%8E%E9%9D%A2%E5%85%B7.md) §一–§五 + 疾病目录）| 不变 |
| S2 经历事实 | 发生过什么（含创伤）| [记忆内容层](../rules/skill-tree/%E8%AE%B0%E5%BF%86%E5%86%85%E5%AE%B9%E5%B1%82.md)（#90）| 变（输入源）|
| S3 自我叙事内容 | "我是谁"的当前版本（连贯故事）| #90 type=narrative（Conway 3 层）| **变（只增不减，追加式）** |
| S4 信念/自我断言 | 对自我/世界的断言 × 程度 | #90 schema（载荷待扩展）| **变（修正 = 追加修正记录，不删原条目）** |
| S5 行为倾向 | 6 标签 7 参数（tone+CSTC）| 静态起点（[角色与面具.md](%E8%A7%92%E8%89%B2%E4%B8%8E%E9%9D%A2%E5%85%B7.md) §一）| 暂不变（改动代价待单独评估）|
| S6 既有数值状态 | SAN / m / 意志力 / HP | 已有完整体系 | 不属于本载体（另行接口）|

运行期规则：

- **S3 只增不减**（D-3b）：旧理解保留为历史层，不删除；唯一例外 = 未设计的特殊经历机制（如可遗忘记忆类——作用于 S2 记忆事实，先例 DID 解离性遗忘 / #90 幂律遗忘，不作用于 S3）。
- **S4 修正以追加实现**：旧断言保留 + 修正记录，演化痕迹可呈现。
- 成分槽（S1–S6 层）不在运行期增删。

## 三、物理载体架构：引用与组装

### 3.1 内容层 / 权重层分层（既有正典，本系统不破坏）

项目已有两层分离（[记忆内容层](../rules/skill-tree/%E8%AE%B0%E5%BF%86%E5%86%85%E5%AE%B9%E5%B1%82.md) §1.3 + [运行时状态模型](../rules/skill-tree/%E8%BF%90%E8%A1%8C%E6%97%B6%E7%8A%B6%E6%80%81%E6%A8%A1%E5%9E%8B.md) §九）：

| 层 | 载体 | 可寻址 | 写 m 吗 |
|----|------|-------|--------|
| 内容层 | MemoryRecord 记录（index + 元数据 + 载荷 + 八状态生命周期）| 可寻址（按 id）| **不写**（铁律）|
| 权重层 | m ∈ [0,1] 每条三体连接/病理边一个（构建层慢变量，战斗中只读）| 不可寻址 | m 只认三写入通道 |

**撞名警示**：#90 状态机"C 巩固"（记录内部稳定化，不写 m）≠ 核心机制 §八"可塑性巩固窗口"（m 增强通道）——两套平行系统，同一事件喂两条管道，管道互不经过对方（#90 §六 三层分离：创建=自动 / 窗口=TryConsolidate / 强化=内容层机制）。

### 3.2 本系统的组装（D-5）

```
事件（自问消解 / 关键经历 / Boss 思潮……）
   ├─→ 内容层管道：#90 记录创建/RC 改写（S2/S3/S4 演化）——纯内容
   └─→ 里程碑检测（派生视图聚合）── 达成 ──→ 广播里程碑事件（OUT-1）
```

- **轴 = 派生视图**：议题相关记录家族的聚合状态（自问消解计数 / 记录成熟态 / 改写次数），**无独立存储**。
- 内容层记录的角色 ≤ **事件触发器**（里程碑检测），与 #86 剧情条件语法查 m（c_0005 技能检定门）同构。
- **RESET 澄清**：#90 §4.1 的 RESET（Boss 战击败清零）是**敌方侧**语义（敌人跨战斗记忆清零），不适用于玩家议题记录。Boss 思潮对议题记录的触及 = **改写（B1）**：思潮交锋 → 议题记录走 RC 式改写（旧版本保留 + 追加新版本），不清零。

### 3.3 不变量（D-6）

1. m 只认三写入通道：使用 Δm（[核心机制](../rules/%E6%A0%B8%E5%BF%83%E6%9C%BA%E5%88%B6.md) §1.3）/ 巩固窗口增强+（§八）/ 突破（#119）。
2. 内容层记录的角色 ≤ 事件触发器（不构成 m 写入通道）。
3. #90 铁律原文不动（记忆不写 m、遗忘不作用于 m）；"状态机直写 m"方案正式否决（无需修订铁律）。

## 四、核心议题

### 4.1 定义（D-4）

> **核心议题** = 角色模板 S1 派生的一条**自我参照的存在性张力**：形式为"我是什么 / 我与 X 的关系"型开放问题（X ∈ {创伤、情绪、他人、自我、世界}），无事实性答案；张力由角色无法摆脱的处境构成（疾病 + 回不去的世界），不可消解，只能被"重新安放"（接纳-共存形态），不能被解决或治愈。

- **来源映射规则**（非逐条内容生产）：S1（引言/背景）× 疾病语义（疾病目录中自我参照损伤方向，如 DID did_e03"'我是谁'问题无法回答"）× 世界观约束（回不去 / 无真结局）。
- **作用**：S3/S4 演化的对象 = 角色与议题的关系状态；关系状态的推进由内容批次逐角色定义（本条目不生产内容）。

### 4.2 数量规则（Q-a 定案）

**每可扮演角色模板恰 1 条核心议题（主轴）**。内容复杂度吸收进里程碑结构（§六），不设多轨并行。

### 4.3 终点语义（Q-b 定案）

- **议题有末端**：由内容批次定义该议题的"重新安放"形态（末端里程碑）。
- **无全局完成态**：无"轴满/通关"——角色仍带病、仍回不去，与"无真结局/回不去"世界观调和。
- **不消费结局**：轴终态不作为结局判定输入（OUT-3 摘除，结局触发公式单独裁定）。

## 六、里程碑（输出端点 OUT-1）

**范围纪律（D-7）**：本系统**不设计 m 公式**。就绪门槛（m ≥ 0.8）、三型 × 链路类型绑定、涨幅、频率 → #120 在 #121 闭合后定案；数值平衡 → #35 轨。

本系统只定义：

- **规则类型（Q-c）**：里程碑 = 议题相关记录家族的**聚合状态事件**——达成条件（自问消解 ×N / 关键叙事记录达 STABLE / Boss 思潮改写……的组合）由**内容批次逐角色定义**；本条目不写死阈值公式。
- **事件形状**：里程碑事件 = 事件广播 `(id, 达成时刻, 源 ∈ {自问消解, 关键经历, Boss 思潮改写})`；τ 型/绑定/就绪判定全部由 #120 消费端定义。

> ✅ **#120 消费端定案（2026-09-06）**：里程碑 → 激活突破资格（暂存不即时）→ 休息时段从就绪技能执行 → 组内全部边 m→1.0。就绪 = 技能组内全部边 m≥0.8；沉淀对象 = 技能（链路上下文组）。完整规则见 [关键突破](../rules/skill-tree/%E5%85%B3%E9%94%AE%E7%AA%81%E7%A0%B4.md)。

## 七、研究依据注记（明悟双形态）

设计依据（跨四研究线：顿悟问题解决 / Aha! 体验 / 量子改变 / 叙事身份），**仅注记，不引入机制术语**：

- 顿悟类行为共性：前置积累 → 僵局/定势打破 → 酝酿 → 外源催化剂 → **重构而非新事实** → 事后验证整合（Wallas 1926 五阶段；Ohlsson 僵局理论；原型启发研究——ACC 相关，罗俊龙等）。
- **渐变-突变连续谱**：明悟存在"水到渠成"（渐显）与"顿悟"（突变）两类形态（量子改变研究：洞察型 vs 神秘型，Miller & C'de Baca 2001）——对应本系统：**渐悟 = 内容层记录演化（#90 RC 改写），顿悟 = 里程碑 → 突破跃迁（#120）**。
- 世界观同构：月光"取版本" = 同一处境换框架的重构语义——议题"重新安放"形态与其一致。
