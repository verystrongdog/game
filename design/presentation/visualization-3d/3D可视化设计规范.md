## 一、总体定位

3D 技能树是一个**独立的 UI 界面**——不是镜子房间的附属物，不绑定任何特定场景。在战斗间隙通过菜单或快捷键打开。

**设计目标：**
- 一个半透明的"玻璃大脑"，悬浮在虚空中，由两个半球椭球体 + 小脑 + 脑干组成
- ⚠️ **已废弃（2026-09-13）**：~~态度模型的 3D 空间 (valence × intensity × autonomy) 是技能树的底层坐标系~~ — 坐标已迁 **MNI 解剖坐标**，不做态度空间中转（[脑功能层级模型](../../rules/skill-tree/%E8%84%91%E5%8A%9F%E8%83%BD%E5%B1%82%E7%BA%A7%E6%A8%A1%E5%9E%8B.md) §14.1）。态度空间此后只保留为**设计语义解释**，不是坐标来源
- ⚠️ **已废弃（2026-09-13）**：~~认知/情绪/行为三大分支嵌入同一大脑的不同梯度~~ — 技能分类现为**主导网络 × 主导角色**（[技能生成机制](../../rules/skill-tree/%E6%8A%80%E8%83%BD%E7%94%9F%E6%88%90%E6%9C%BA%E5%88%B6.md) §一）
- 节点是脑内的发光点——解锁 = 点亮脑区（fMRI 式热力光晕）
- 未解锁节点可见但暗灰色（全景可见）
- 颜色仅用于 UI 区分分支（不使用颜色表示态度/情绪语义）

## 二、空间结构 — 大脑形态

### 2.1 整体布局

> ⚠️ **本节整节已废弃（2026-09-13）**：坐标轴映射与椭球体几何参数均不再适用。
> - 坐标：MNI → 游戏空间的公式见 [脑功能层级模型](../../rules/skill-tree/%E8%84%91%E5%8A%9F%E8%83%BD%E5%B1%82%E7%BA%A7%E6%A8%A1%E5%9E%8B.md) §14.1
> - 几何：椭球体近似已由**真实脑曲面 mesh** 取代（DK 皮层 + 皮层下 OBJ，见 [Unity接入设计](Unity%E6%8E%A5%E5%85%A5%E8%AE%BE%E8%AE%A1.md) §3.1）
> - 材料层参数（半透明玻璃/线框叠加）仍可作视觉参考

技能树呈现为一个半透明的"玻璃大脑"。~~坐标轴映射自态度模型：~~

| 态度轴 | 符号 | 范围 | 大脑轴 | 解剖含义 |
|--------|------|------|--------|---------|
| Valence (效价) | X | [-1.1, +1.1] | 左右 | 左半球=回避/负面，右半球=趋近/正面 |
| Intensity (强度) | Y | [0, 1.1] | 上下 | 底部=脑干/反射，顶部=皮层/复杂加工 |
| Autonomy (自主性) | Z | [-0.8, +0.9] | 前后 | 后部=被动/感官，前部=主动/执行控制 |

**大脑几何体参数：**

| 组件 | 几何体 | 参数 (rx, ry, rz) | 位置 (X, Y, Z) |
|------|--------|-------------------|---------------|
| 左半球 | SphereGeometry(1,48,36) scaled | 0.55, 0.90, 0.70 | -0.55, 0.55, 0 |
| 右半球 | SphereGeometry(1,48,36) scaled | 0.55, 0.90, 0.70 | +0.55, 0.55, 0 |
| 小脑 | SphereGeometry(1,24,18) scaled | 0.35, 0.20, 0.30 | 0, 0.15, -0.55 |
| 脑干 | CylinderGeometry(rTop,rBot,h,16) | rTop=0.08, rBot=0.12, h=0.20 | 0, 0.02, -0.15 |

**纵裂间隙**：左右半球间距 0.08 单位。用 Torus 环 (r=0.05) 表示分隔线。

**材质规范：**
- 主体：半透明玻璃 (opacity=0.12-0.15, depthWrite=false, DoubleSide)
- 线框叠加：wireframe (opacity=0.04-0.06, color=#335577, depthWrite=false)
- 脑干：与主体同材质，不透明稍高 (opacity=0.20)

### 2.2 认知分支 — 皮层后→前梯度 (25 节点)

> ⚠️ **已废弃（2026-09-13）**：分支配色与"分支梯度"分类源自旧技能树结构，已被主导网络 × 主导角色取代。保留作视觉参考。

```
坐标 (Y=深度/层级, Z=前后):
  Y≈0.95, Z≈+0.50 — L5 推理与决策 — 前额叶 (dlPFC/vmPFC/额极)
  Y≈0.82, Z≈+0.15 — L4 表象与语言 — Wernicke/Broca区/角回
  Y≈0.65, Z≈-0.10 — L3 知识表征     — TPJ/颞下回/楔前叶
  Y≈0.45, Z≈-0.35 — L2 记忆         — 颞叶/海马体/内嗅皮层
  Y≈0.25, Z≈-0.60 — L1 知觉与注意   — 枕叶/顶叶 (V1-V5/顶内沟)
```

每层 5 个节点在 X∈[-0.3, +0.3] 范围内均匀分布。节点形状 = 二十面体 (IcosahedronGeometry(0.04,1))。

### 2.3 情绪分支 — 边缘系统深→浅梯度 (15 节点)

> ⚠️ **已废弃（2026-09-13）**：同上——情绪分类不再是技能分组维度（见 §3.2 D19 染色）。

情绪节点直接使用 B_raw = (V, |A|, D) 坐标，同时受层级 (tier) 约束的 Y 偏移：

```
情绪 B_raw 坐标 (来自 NRC VAD 数据):
  Y≈0.88 — L5 恐怖     (V=-0.77, |A|=0.70, D=-0.12)
  Y≈0.70 — L4 绝望/内疚/敬畏/孤独
  Y≈0.50 — L3 共情/爱/焦虑/厌恶
  Y≈0.28 — L2 希望/愤怒/悲痛
  Y≈0.10 — L1 快乐/恐惧/平静
```

A 轴（唤醒度）编码为节点发光强度，不参与位置映射：高 A = 亮白光 (emissiveIntensity ~0.9)，低 A = 暗柔光 (~0.2)。节点形状 = 光滑球体 (SphereGeometry(0.045,20,20))。

### 2.4 行为分支 — 动作系统底→顶梯度 (21 节点)

> ⚠️ **已废弃（2026-09-13）**：同上。

行为节点放在对应驱动在态度空间中的质心位置：

```
驱动质心 (V, I, D):
  Y≈0.90, Z≈+0.55 — 价值驱动 (+0.58, 0.78, +0.58) — ACC+额顶网络
  Y≈0.85, Z≈+0.35 — 照护     (+0.41, 0.71, +0.28) — 岛叶+ACC+VTA
  Y≈0.60, Z≈+0.25 — 道德驱动 (+0.16, 0.46, +0.39) — vmPFC+TPJ
  Y≈0.55, Z≈-0.05 — 文化习俗 (-0.09, 0.36, -0.07) — mPFC+后扣带
  Y≈0.35, Z≈ 0.00 — 奖励机制 (+0.61, 0.54, +0.17) — NAcc+VTA
  Y≈0.30, Z≈-0.30 — 惩罚机制 (-0.65, 0.54, -0.38) — 基底节+杏仁核
  Y≈0.08, Z≈-0.55 — 反射     (-0.85, 0.71, -0.52) — PAG+脑干
```

每个驱动的 3 个节点在质心周围小幅偏移 (间距≈0.06)。节点形状 = 立方体/棱柱 (BoxGeometry(0.07,0.05,0.07))。

### 2.5 终极技能 — 前额叶极 (13 节点)

> ⚠️ **已废弃（2026-09-13）**：13 个"终极技能"的节点分类已不在正典中（正典技能来自 71 个链路上下文，见 [Unity接入设计](Unity%E6%8E%A5%E5%85%A5%E8%AE%BE%E8%AE%A1.md) §二）。

13 个终极技能放在对应态度组合的 behavior_output 坐标 (从 attitudes.json 读取)，均位于前额叶极区域 (Y≈0.95, Z≈+0.55)。节点形状 = 十二面体 (DodecahedronGeometry(0.06,1))。

### 2.6 连线规则 — 白质纤维束

- **已解锁连线**：TubeGeometry 管道 (radius=0.004)，颜色 = 分支标识色，沿 Bezier 曲线
- **未解锁连线**：LineDashedMaterial 虚线 (opacity=0.18, dashSize=0.12)
- **曲线弯曲**：中点沿垂直方向偏移 0.12（模仿 DTI tractography 的弧线形态）
- **跨分支连线**：弯曲更大 (offset=0.15)，表示长程纤维束
- **终极技能连线**：三条弧线从认知/情绪/行为三方向汇聚到终极节点

## 三、节点视觉语言

### 3.1 基本形态

> ⚠️ **2026-09-13**：形状/大小现按**层级 L0–L5**（[脑功能层级模型](../../rules/skill-tree/%E8%84%91%E5%8A%9F%E8%83%BD%E5%B1%82%E7%BA%A7%E6%A8%A1%E5%9E%8B.md) §16.1）；下面这套"按分支定形状"已废弃，保留作视觉参考。

- 所有节点 = 发光晶体球体（基本半径 0.03）
- 认知分支节点 = 多面体形状（呼应复平面 C⁵ 的几何感）
- 情绪分支节点 = 光滑球体（PAD 空间的连续感）
- 行为分支节点 = 棱柱体（驱动方向感）
- 终极技能节点 = 大型多棱面晶体（半径 0.06，粒子环绕）

### 3.2 颜色方案（链路上下文染色，D19/D29）

> ⚠️ **2026-08-03 更新（Grilling #20，D19）**：旧"认知/情绪/行为分支"配色废弃（源自旧技能树结构）。链路按**上下文染色**——颜色距离 = 上下文距离（D17/D23）。

```
色相层 = primary_network（14 Kroell 网络 → 14 色相带，环绕色环均分）
明度/饱和度层 = primary_role（8 行为角色 → 同色相内明度偏移）
多网络链路 = 主色 + 次色渐变（视觉跨色相 = 桥接）
Hansen 脑干链路（41 条）= 独立中性色系（灰蓝，按 GREEN/PINK/YELLOW 社区微调明度，D29）
抽象节点（is_design_node）= 灰色 + 虚线（区别于解剖实体）
左右链路 = 同色相 + 侧向标识（L 实线 / R 虚线，或亮度微差）
组件链路（面具激活/抑制）= 不同颜色/材质（§8.10.2 保留）
病理链路 = 不同颜色（§8.8.2 保留）
```

**重要：颜色仅用于 UI 区分链路上下文。** 不使用颜色表示态度/情绪语义（已废弃的颜色系统不可恢复）。

### 3.3 状态视觉

| 状态 | 视觉效果 |
|------|---------|
| **未解锁** | 灰色半透明（α=0.3），轮廓可见，无发光 |
| **可解锁**（有足够点数）| 闪烁微光（频率 1Hz），轻微脉动（scale 1.0→1.1），外环发光 |
| **已解锁** | 颜色饱满（α=0.9），发光，缓慢脉动（频率 0.3Hz） |
| **选中** | 高亮光环（外圈 2× 半径），节点放大（scale 1.3） |
| **冷却中** | 半透明覆盖层（α=0.5 灰色蒙版），旋转沙漏粒子 |
| **强制激活**（恐慌） | 快速闪烁（频率 3Hz），红边脉冲 |

### 3.4 信息面板

点击节点时弹出信息面板（半透明，悬浮在节点旁）：

```
┌─────────────────────┐
│ 决意  [推理 L5]      │  ← 技能名 + 层级
│ ⚡被动               │  ← 主动/被动 图标
│                     │
│ HP < 30% 时          │
│ 所有主动技能冷却 -1   │  ← 效果描述
│                     │
│ 前置: 表象与语言 L4   │  ← 前置条件
│ 解锁: 8 技能点       │  ← 成本
│                     │
│ [解锁] (可解锁时高亮)  │
└─────────────────────┘
```

## 四、交互方式

### 4.1 视角控制

| 输入 | 操作 |
|------|------|
| 鼠标拖动 / 触屏滑动 | 绕树旋转视角（以当前注视点为中心） |
| 滚轮 / 双指缩放 | 缩放（范围：0.3× → 3×） |
| 右键拖动 / 双指平移 | 平移视角 |
| 点击空白处 | 取消选中 |
| F 键 / 双击空白 | 重置视角（回到默认俯瞰角度） |

### 4.2 节点交互

| 操作 | 效果 |
|------|------|
| 悬停 | 节点微微放大（scale 1.1），显示简化提示（技能名 + AP/冷却） |
| 点击 | 选中节点，弹出完整信息面板 |
| 双击（已解锁） | 将技能加入/移出快捷槽 |
| 点击 [解锁] 按钮 | 消费技能点，播放解锁动画 |
| 右键 | 取消选中 |

### 4.3 快捷槽编排

在技能树界面的底部或侧边栏显示 6 个快捷槽：
- 拖拽已解锁节点到槽位 = 装备技能
- 拖出槽位 = 卸下
- 战斗中使用的技能来自快捷槽

### 4.4 搜索和导航

- **搜索栏**：输入技能名快速定位（镜头自动飞向该节点）
- **分支折叠**：点击主干可折叠/展开整根子枝
- **层级高亮**：悬停在快捷槽上时高亮该技能在树上的位置
- **前置高亮**：选中未解锁节点时，高亮所有未满足的前置节点（红色虚线连接）

## 五、成长可视化

### 5.1 解锁动画

```
时间线 (1.0 秒):
  0.0s  点击 [解锁]
  0.0-0.3s  节点从灰色过渡到目标颜色（色相旋转 + 饱和度上升）
  0.1-0.5s  光脉冲从节点沿子枝传播到主干（速度: 0.5单位/秒）
  0.2-0.6s  节点发光强度从 0 上升到 100%
  0.5-1.0s  节点脉动稳定到默认频率
```

### 5.2 子枝点亮

当一根子枝的全部节点被解锁时：
- 该子枝的连线变亮（从暗灰到分支标识色）
- 子枝顶端出现小型结晶（视觉奖励标记）

### 5.3 终极技能解锁

```
时间线 (2.0 秒):
  0.0s   点击解锁终极技能
  0.0-0.5s  三根主干的顶部延伸线亮起
  0.3-1.0s  三条光流从认知/情绪/行为三枝沿主干向上流动
  0.5-1.2s  三道光在顶部交汇——交汇点的晶体生成
  1.0-2.0s  共振光波从晶体向外扩散（覆盖整棵树）
  1.5s     镜头自动推近交汇点
```

### 5.4 树的全景成长

树的整体外观随解锁进度变化：
- **0-20% 解锁**：一棵暗色的骨架，只有少量光点
- **20-50% 解锁**：主干变亮，多条子枝发光
- **50-80% 解锁**：大部分树体发光，多种颜色交织
- **80-100% 解锁**：全树通体发光，三枝交汇处璀璨

## 六、技术约束

### 6.1 性能

- 节点总数：**由数据推导**，不写死——正典口径是 71 个链路上下文 / 50 解剖实体（见 [Unity接入设计](Unity%E6%8E%A5%E5%85%A5%E8%AE%BE%E8%AE%A1.md) §二）。⚠️ 原文"73 个（25+15+21+12）"是旧模型口径，已废弃
- 所有节点使用 Instanced Rendering（共享材质球）——**这条是硬要求**：实测 v2 世代 `.blend` 把材质逐对象复制成 238 个，是反面教材（[脑模型资产登记](%E8%84%91%E6%A8%A1%E5%9E%8B%E8%B5%84%E4%BA%A7%E7%99%BB%E8%AE%B0.md) §三）
- 发光效果使用 Bloom Post-Processing（不用每节点独立光照）
- 粒子效果仅在冷却中和终极技能节点启用

```

    node_cognition.fbx      ← 认知节点（多面体）
    node_emotion.fbx        ← 情绪节点（球体）
    node_behavior.fbx       ← 行为节点（棱柱）
    node_ultimate.fbx       ← 终极节点（大晶体）
    branch_trunk.fbx        ← 主干
    branch_sub.fbx          ← 子枝
  Materials/
    mat_cognition.mat
    mat_emotion.mat
    mat_behavior.mat
    mat_locked.mat          ← 未解锁材质
    mat_cooldown.mat        ← 冷却中材质
  Prefabs/
    SkillTree.prefab
    SkillNode.prefab
  Scripts/
    SkillTreeController.cs
    SkillNode.cs
    SkillTreeCamera.cs
    SkillSlotBar.cs
  Data/
    SkillTreeData.cs        ← 技能树拓扑数据（从 JSON 导入）
```

### 6.3 数据驱动

技能树的拓扑结构（节点位置、连线关系、前置条件）应从数据文件（JSON/ScriptableObject）加载，不硬编码。这样设计迭代时只需修改数据文件，无需改动场景。
