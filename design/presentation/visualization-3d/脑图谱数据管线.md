## 一、设计动机

旧方案：技能 3D 坐标由 PAD 心理学公式推导 → 将真实脑 mesh 旋转缩放去"套"节点位置。

问题：
- 技能位置是 PAD 概念空间的投影，不是真实脑区位置
- 脑 mesh (BigBrain) 与节点坐标系之间的关系是人为变换
- 无法在 Blender 中做精确的脑区-节点对应

新方案：
```
脑图谱 (Harvard-Oxford/AAL3/DK) → 脑区 MNI 质心坐标
→ 归一化到游戏世界空间
→ 技能放置在真实解剖位置上
→ 脑 mesh (brain-for-blender) 直接在 Blender 中原生使用
```

**态度空间的三轴映射保留为设计语义层**——解释为什么某类技能在某脑区，但坐标数据来源于脑图谱。

### `code/tools/brain_atlas_to_blender.py`

脑区坐标数据生成器。

```
用法:
  python code/tools/brain_atlas_to_blender.py              # 生成 brain_regions.json (文献坐标)
  python code/tools/brain_atlas_to_blender.py --obj-dir DIR # 从 OBJ mesh 质心更新坐标
```

输入: 内嵌的 REGION_MAP 字典（**57 脑区——历史口径**，当前 brain_regions.json 是 69 个

## 五、坐标转换公式

### MNI → 游戏世界空间

```
MNI152 空间 (mm, RAS+):
  X = 右(+)/左(-)
  Y = 前(+)/后(-)
  Z = 上(+)/下(-)
  范围: X∈[-90,90], Y∈[-126,90], Z∈[-72,108]

游戏世界空间:
  X = 右(+)/左(-)  ⚠️ 旧注"原PAD Valence轴"已废弃——轴对应关系保留，PAD 不再是坐标来源
  Y = 上(+)/下(-)  ⚠️ 同上（旧注：原PAD Intensity轴）
  Z = 前(+)/后(-)  ⚠️ 同上（旧注：原PAD Autonomy轴）
  范围: X∈[-1.1,+1.1], Y∈[0,1.25], Z∈[-0.8,+0.9]
  （Y 上界 1.1 → 1.25：M1/S1/旁中央小叶位于大脑顶部 MNI Z≈60，来源：脑功能层级模型 §14.1）

转换:
  game_X = (mni_X / 90) × 1.0
  game_Y = (mni_Z / 90) × 1.0 + 0.55
  game_Z = (mni_Y / 126) × 0.85
```

解释:
- MNI X→游戏X: 左右直接对应，除以90归一化
- MNI Z→游戏Y: 上下对应（MNI的上下=游戏的上下），+0.55使底部≥0
- MNI Y→游戏Z: 前后对应（MNI的前后=游戏的前后），除以126(≈max)、乘0.85放缩

### 视角对齐

标准神经影像使用 RAS (Right-Anterior-Superior) 坐标系:
- 上方 = 头顶方向
- 前方 = 面部方向
- 与 3D 引擎的 Y-up / Z-forward 惯例不完全一致

上述转换公式处理了轴交换和归一化。如果你使用不同的 3D 引擎坐标惯例，需相应调整。
