# 全院主线逻辑原型：0527 没有入院那一天

> 用“苟智空记得自己从院外到来，整座医院却记得他一直是 0527”建立贯穿全院的具体案件。本文件是候选逻辑原型；固有疾病《无法离开医院》及入院事实骨架已由 owner 确定，老巴失踪等后续仍是候选。

## 一、为什么需要这条案件

现有正典已经给出“想回家 → 理解为什么回不去”的世界观主线，也给出“门控承诺 → 钥匙链 → 三个 Boss”的空间结构。苟智空的入院矛盾可以把两者连起来：他不只是想找出口，还需要查清为什么一套先于自己到来的记录正在证明“他本来就在这里”。NPC 因此能成为同一案件中的当事人、证人或关系后果，而不是各自站在原地讲主题。

本原型把五个已有事实接在一起：

- 苟智空下夜班回家时来到医院边界，绕行后回到大门，被护士当作从病房逃出的 0527；
- 他记得自己是“苟智空”，手环却写着“苟笙 / 0527 / B 栋 147 室 4 床”；
- 玩家的固有疾病是《无法离开医院》，见[疾病特长](../entities/%E7%96%BE%E7%97%85%E7%89%B9%E9%95%BF.md) §4.6；
- 老巴是“回家”驱动力的第一道人形接口，也是全院唯一记录病人和家属进出的人，见[老巴叙事视图](../spec/material/drafts/%E8%80%81%E5%B7%B4-%E5%8F%99%E4%BA%8B%E8%A7%86%E5%9B%BE.md) §一、§十四；
- 老巴最终失踪、登记簿中断，但发生时点尚未定案，见同稿 §十三。

## 二、表层案件

开场不是“在病房醒来后想出院”，而是一次被院方命名的入院：苟智空记得自己刚从公司下夜班；护士说终于找到了从病房跑出的 0527；他身上的手环为院方说法提供了物证。

玩家最初要查的不是宇宙真相，而是一个可以落到每个科室和 NPC 身上的具体案件：

1. 谁为 0527 办理了入院；
2. 为什么病房、手环和工作人员都在证明他已经住了一段时间；
3. “苟智空”与“苟笙”之间究竟少了哪一天；
4. 为什么每条可能的离院路径最终都会把他重新归类为院内的人。

表层主线因此不再只是“收集钥匙回家”，而是：

```text
证明自己刚从院外到来
→ 发现每类记录都只能证明 0527 早已在院
→ 尝试绕行、门禁、合法手续等不同离院路径
→ 每次失败都留下一种新的“仍在院内”证据
→ 沿身份记录、进出登记和被划掉的旧页进入三栋建筑的历史
→ 分别接触研究、信仰与抵抗留下的解释
→ 回到第一次踏上的门诊台阶，带着无法证实的答案再次离开
```

老巴的登记簿在这里是一种可能反驳或加深院方记录的证据，不再预设“最后一行必然是玩家”。老巴后续失踪仍可作为主线升级，但需要在 0527 案已经立住之后再发生。

## 三、两条暗线

### 3.1 主角暗线：谁有资格证明“我出去过”

主角暗线就是他随身携带的固有疾病《无法离开医院》。它不靠角色对镜头宣布病名，而是通过一组持续发生的冲突被玩家认出：

- 他记得下班回家，手环却证明他属于 B 栋病房；
- 他记得自己叫苟智空，院方每一个可查字段都叫他苟笙或 0527；
- 他走了很久以为正在离开，抬头时却再次看到医院大门；
- 普通人相信白天连续正常，玩家记得夜晚曾经改变；
- 他越试图用院方记录证明自己，越会让那套记录证明“0527 又在否认自己生病”。

角色创建不要改写这个共同起点。不同经历与可选疾病决定苟智空如何观察、描述和处理《无法离开医院》；它们不把主角换成一个没有固定入院事实的空白容器。

### 3.2 医院暗线：被擦掉的不是异常，是人的进出

老巴第三本登记簿在二〇〇〇年前后已有数页被人用尺子整齐划掉；他得到的回答只有“上面收走了”。这说明医院的遗忘史不只存在于传说，也存在于最普通的行政痕迹中。

全院历史不应由一份“真相报告”解释，而应由三套互不兼容、各自拥有物证的处理史组成：

| 路径 | 它如何解释登记异常 | 它保存了什么 | 它看不见什么 |
|---|---|---|---|
| 研究 | 把重复返回、记录缺口和空间异常视为可测现象 | 实验记录、旧档案、被收走的登记页 | 被研究的人怎样生活 |
| 信仰 | 把留下与消失视为月光的回应 | 仪式、口述名单、无人认领的物件 | 信念如何制造自己期待的回应 |
| 抵抗 | 把异常视为需要封锁、巡逻和承受的威胁 | 值班表、封锁线、伤亡与撤退记录 | 防线本身如何扩大恐惧 |

三条路径分别通向 Boss A、Boss B、Boss C，但任何一条都不能证明老巴的最终命运。这保持[世界观与叙事](../events/%E4%B8%96%E8%A7%8C%E4%B8%8E%E5%8F%99%E4%BA%8B.md)的不可证实边界，也让三种月光解释成为案件中的立场，而不是结局前才出现的百科知识。

## 四、全院推进

### 4.1 序章：月初的圆月

苟智空下夜班后发现农历月初却升着圆月。再抬头时，公司被一座招牌残缺的精神卫生中心取代，道路对面没有城市，只有吞没声音的黑暗。他绕园区一周回到原处，最后选择走向医院。

他踏上门诊台阶时，夜晚突然变成白天。护士和保安喊着“找到了”赶来，将他识别为从病房逃出的 0527。他在挣扎中看见蓝色手环上的另一套姓名、编号、床位。**《无法离开医院》在此以行动和物证首次出现，不显示病名解释框。**

### 4.2 第一幕：没有发生的入院

玩家在白天查找 0527 的入院日、送诊人、原始评估和首次分床记录。每一个局部字段都能对上，但找不到那个人真正进门的时刻。[开局剧情逻辑原型](%E5%BC%80%E5%B1%80%E5%89%A7%E6%83%85%E9%80%BB%E8%BE%91%E5%8E%9F%E5%9E%8B.md) 的“没有发生的夜班”改为入院后的第一个昼夜验证：两份夜间记录教会玩家，物证会留下，当事人却未必能在白天陈述它。

这一幕结束于玩家第一次有准备的离院尝试。无论该次采用绕行、门禁还是手续，结果都不应只是“隐形墙挡住了”，而应新增一件与玩家记忆冲突的院内证据。老巴从此成为进出记录的人形接口；他何时失踪另行裁定。

### 4.3 第二幕：登记簿里的人

登记簿不只是老巴失踪案的证物，也是全院人物与“外面”的关系总账。谁真的来过、谁只在门外等、谁从没出现、谁拿着合法单据再次回到走廊，都能与 NPC 自己的说法互相校验。

NPC 与案件的关系分为三类，不要求人人提供关键线索：

- **当事人**：其进出、探视或返回本身就在登记簿中；
- **证人**：看见过老巴、玩家或某件物证，但只能陈述自己的局部经验；
- **关系后果**：不掌握案件信息，却影响玩家以后如何询问、相信或公开另一人的证词。

吴桐、周卫国、唐念安不应被强迫变成三个线索贩卖者。他们首先属于“关系后果”：吴桐使玩家面对“合法同意是否等于拥有决定权”，周卫国使玩家面对“仪器和记录是否有权否定真实疼痛”，唐念安使玩家面对“脑中出现的内容是否等于做过的事”。这些关系随后改变玩家处理登记簿、证词和自身记忆时可采用的措辞与行动。

### 4.4 第三幕：三种处理史

空间钥匙链不再只是升级路线。每进入一栋建筑的深层，玩家都接触医院处理同一类异常的一段历史：

- 门诊楼顶层：Boss A 的研究路径；
- 住院楼天台：Boss B 与拜月教的信仰路径；
- 供应中心：Boss C 的封锁与抵抗路径。

每条路径都必须回答案件的一个实际问题，并制造一个新的矛盾；不能只提供月光设定。例如，研究路径可以证明登记缺口反复出现，却无法证明缺口中的人去了哪里。

### 4.5 终幕：再次经过大门

终幕回到门诊台阶与传达室，而不是停在最后一个 Boss 房间。玩家已经拥有足够多的物证理解三类“为什么回不去”，却仍不能证明苟智空与 0527 何者是原本的自己，也不能把一种月光解释宣布为真相。若老巴失踪的候选被接受，此处再叠加“唯一的进出记录者也无法作证”。

结局仍由既有的髓鞘化模式、见证过的 Boss 故事和探索深度自动映射。案件提供结局发生的具体现场：玩家再次经过那道门时，自己已经成为怎样的人。它不增加“选择 A/B/C 结局”的菜单。

## 五、人物内容的准入问题

新增或扩写 NPC 场景前，先回答以下问题：

1. 此人是案件当事人、证人，还是关系后果；
2. 此人的日常目标是什么，它与玩家调查发生了什么摩擦；
3. 此人掌握的是可观察事实、个人解释，还是转述；
4. 如果删掉此人，案件会失去证据、失去一种行动方式，还是只少一段人物介绍；
5. 此人的背景是否改变了当下行动，而不是只被对话复述。

“只少一段人物介绍”不等于人物必须删除，但说明该内容不应伪装成主线节点。

## 六、待 owner 裁定

本原型只有以下新增事实需要裁定；未裁定前不得扩散到人物正典或运行时数据：

1. 苟智空与手环上的“苟笙”是同一人的身份断层，还是两个人被记录系统缝在一起；
2. 老巴是否失踪，以及失踪应发生在第几次离院验证之后；
3. 老巴的登记簿中是否存在 0527 的首次“进”，还是只有后续返回记录；
4. 二〇〇〇年前后被划掉的旧页是否与 Boss A 的研究史直接相关，还是只保持空间异常关联；
5. 三条路径是否分别提供一种互不相容的 0527 身份解释，但都不取得唯一真相。
