## 你的任务

把开局改成 **在一张病历单上、一问一答地填写过往病史**：

1. **界面是一张病历单**（纸），不是五个屏、不是卡片网格、不是左右分栏的对话界面。
2. **一问一答**：医生问一句 → 患者从闭集里答一句 → **答案当场写成纸上的字** → 自动进下一问。
3. **经历不按时间三问切格**：时间三问只写进病历（主诉与现病史），**不再用来锁池子**；病史条目按"与疾病的关联 + 已答内容"筛，且**任何已答前缀下都选得到别的组合**。

产出可直接落地的契约：**问诊骨架 + 病历单栏目写入表 + 池子口径与放宽规则 + 界面结构 + 校验判据 + 测试**。

**不是**产出玩法哲学，**不是**写文献综述，**不是**保留旧五屏的任何排版。

## 三、问诊骨架（本阶段的核心交付之一）

**七问**，全部用现成词表，不新增任何内容层；答案是**闭集**：

| # | 医生问（玩家可见） | 答案闭集 | 写进病历的哪一栏 |
|:--:|---|---|---|
| 1 | 这件事是从什么时候开始的 | `vocab.onset`（童年 · 少年 · 成年） | 主诉·起病时间；现病史·发病情况 |
| 2 | 从那以后是一直这样，还是断断续续 | `vocab.duration_pattern`（单次 · 持续不断 · 反复发生） | 主诉·持续时间；现病史·病程形式 |
| 3 | 一次能持续多久 | `vocab.duration_span`（瞬时 · 短期 · 长期） | 现病史·主要症状特点 |
| 4 | 那段时间，发生了什么（多选 1–3） | `vocab.event`（8 值） | 现病史·诱因与前驱事件 |
| 5 | 这些事发生在哪儿 | `vocab.context`（5 值） | 个人史·社会环境 |
| 6 | 当时身边有谁（可空 = 一个人） | `vocab.relation`（6 值 + 空值） | 个人史·人际 |
| 7 | 那时候你能决定多少 | `vocab.agency`（4 值） | 现病史·功能与一般情况 |

**不由玩家答的**：`role_care` / `role_power` / `role_belong`（由第 5–6 问答出的记录定，院方笔迹）、`consequence`（输出槽，屏 5 才结算）。

**要求**：
- 每一问的文案、答案标签、写入栏目**全部收口在数据里**（新块 `interview`），代码不许硬编码。
- 七问的问法要**像临床问诊**（现病史五要素：发病情况 / 主要症状特点 / 伴随症状 / 诊疗经过 / 一般情况——见检索记录 §5.1），不是问卷口吻。
- 答案一旦落下，**不得由玩家直接改写**；改答案只能"回到第 N 问重答"，且重答要按规则清掉受影响的已认条目（沿用 `reconcileExperiences` 的思路）。

## 四、池子口径（本阶段的核心交付之二）

**问题**：旧口径是"三答锁一格 ⇒ 池子 = 该格 12 段"，owner 判定锁死不对。

**新口径（按此实现）**：

1. 候选 = **全库 288 段**按"与已答内容的匹配度"排序后的结果：匹配的答案维度越多越靠前（第 4–7 问是维度，第 1–3 问**只写病历、不参与匹配**——它们不再是切池子的键）。
2. 每次向玩家展示 **≤12 条**；玩家逐条「以上属实」，认满 **10 段**（`quota` 不动）。
3. **永不锁死**：任何已答前缀下，池子都必须 ≥10 条且跨 ≥4 个 `context`；匹配不足时**逐级放宽**（先去掉匹配度最低的那一维，再放宽到"匹配 ≥1 维"，最后兜底全部记录），放宽每一步都要在数据里有名字、在校验里可核。
4. 必须给出**可算判据**：跑一遍全部已答前缀（第 4–7 问的组合），报告 ① 分支总数 ② 有多少分支需要放宽 ③ 放宽后最坏池子规模 ④ 最坏情况下的 `context` 跨度。这些数字要写进交付与文档。

5. **疾病侧连带**：`cell_rule`（格病并集 2–4）退役 → `pool_rule`（**最终池子**的病并集 2–4，语义不同：格 ≠ 池）。重算并写出新不等式（`|候选| ≤ min(2×10, u_pool)`），说明本局至少多少张病结构性不可达。**不许把 `cell_rule` 留着当第二份权威。**

## 五、界面结构（本阶段的核心交付之三）

**一屏一张纸**：

```
┌─ 入院记录 ─────────────────────── 住院号 0527 ─┐
│ 一般情况  姓名 自述 __ ｜ 院方 __  性别 __  … │
│ 主诉      「__」                              │
│ 现病史    发病情况 __ · 病程形式 __ · …        │
│            · 第 1 条 <正在填 / 已填>          │
│ 既往史    __                                  │
│ 个人史    __                                  │
│ 家族史    __                                  │
│ 专科情况  （院方写，后置）                     │
│ 初步诊断  （待查：可能性较大的诊断）           │
│ 患者意见  逐条认 / 不认                        │
│ 落款      经治医师签名 · 病史陈述者签名        │
└───────────────────────────────────────────────┘
         医生：<当前问题 + 闭集答案按钮>
```

- 纸占主视觉；**正在填的栏目高亮**，已填栏目显示文字；空着的栏目保留栏位与空白态（`blank`）。
- 问诊条**贴纸**（上方或下方固定），显示当前问题与闭集按钮；答完写入并自动进入下一问。
- **不许**出现：五屏步条 · 卡片网格（`cc-experience-grid`）· 右侧统计栏（`cc-live-summary`）· 分页式栏目向导。
- 十段确认、诊断候选、患者意见、签字**都在同一张纸上发生**，不再翻屏。
