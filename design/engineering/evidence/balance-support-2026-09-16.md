⚠️ 这是 [#165 证据 §七 #4](xbot-contact-phase-2026-09-15.md) 登记的那条**未裁项**（实测同帧两口径给出相反答案、最大层差 41 mm）在本件的回答。

|---|---|---|---|---|---|
| **骨点层**（M2 取点口径） | **0 / 72** | 0 / 0 / **72** | — | 可比帧 **0** | ⛔ **全域退化**：静止/下蹲时只有**趾骨原点**在容差内（`Foot.head` 实测 **+87.29 mm**、`ToeBase.head` ≈ +0.01 mm），两脚**共两点且共线**（仅 x 不同）⇒ **域无面积** |

**建议（依据读数）**：以**蒙皮层**做接地/支撑判据层。三条依据：

1. **骨点层在本仓的取点口径下根本不存在"多边形"**——M2 的两个骨点里能着地的只有趾骨原点，两个趾骨点连线**没有面积**；`支撑多边形` 这个量在骨点层**无法定义**（不是"数值偏了"，是**量本身不成立**）；
2. **蒙皮层就是 owner 看得见的那一层**——口径 §十 的能播类三项表早已把"判据量骨段 / owner 看蒙皮"这条层差登记为已知偏差（同族：#169 的"骨点在肉里 ⇒ 掌面判据假红 −4.21 mm"）；
3. **它同时解释了 41 mm 那条**：骨点层与蒙皮层**不是同一层几何的两个精度档**，而是**两个不同的点集**（前者连脚跟都没有）⇒ 只要判"站得住"，就只能在**看得见的足底**上判。

⚠️ **若要保留骨点层**（例如为了与 M2 接地判据同源）：取点集必须**扩到足骨尾 / 足底最低骨段**，且脚跟要有一个来源（`Toe_End` / `HeadTop_End` 那 13 根**标记骨不许进任何部位**，§15.4）⇒ 属**另开一件**，本件不做、不静默放宽。

## 六、② 件动作 `CrouchPushedBack`：帧表 · 自由度表 · 解空间 · 三项判据

**帧表**（30 fps）：中立 **1** → **下蹲到位 13** → 待推 → **24** 起被推 → **被推到位 33** → **失衡极值 34** → **后撤脚落地 45** → 起身 **57** → 末帧 **72**。

| 段 | 帧 | 下蹲量 | 被推后移 | 后撤步进度 | 产物读数（髋世界 z / 骨盆残差 / 腿残差） |
|---|---|---|---|---|---|
| 下蹲 | 1–13 | 0 → **0.160 m** | 0 | 0 | 帧 13：**0.882749 m** / 0.00 mm / 0.00 mm |
| 待推 | 13–24 | 0.160 m | 0 | 0 | 同上（保持） |
| **被推** | 24–33 | 0.160 m | 0 → **0.140 m** | 0（**双脚不动**） | 帧 33：0.882749 / 0.00 / 0.00 |
| **后撤步** | 33–45 | 0.160 m | 0.140 → 0 | 0 → 1（摆动占前 70%） | 帧 45：后撤 **0.260 m** / 0.00 / 0.00 |
| 起身 | 45–57 | 0.160 → 0.080 m | 0 | 1 | 帧 57：**0.962749 m** / 0.00 / 0.00 |
| 站定 | 57–72 | 0.080 m | 0 | 1 | 同上 |

**「失衡极值帧」是推导量，不是选定值**（同 `door_pass_open_deg()` 的地位）：摆动脚**首次离地**的那一帧 ⇒
`f = ceil(33 + (45−33)×0.7/π × asin(2.8 mm / 50 mm)) = ceil(33.1498) = 34`。
物理含义：**域从双脚缩到单脚的那一刻**（域当场变小），而重心还停在被推位移上 ⇒ 余量全局极小落在这一帧——
**这条是期望，由"时序"判据当场核**（声明 34 == 产物 34 ✅）。
