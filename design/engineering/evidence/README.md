## 必填字段

| 字段 | 说明 |
|---|---|
| base SHA / head SHA | 起止 commit |
| 工具版本 | dotnet / python / Unity 等实际版本 |
| 命令与退出码 | 逐条列出实际执行的命令 |
| 问题差分 | `new_finding = after − mapped(before) − expected_delta`，要求为空 |
| 测试报告定位 | 指向 artifact 或可复现命令 |
| 回滚演练结论 | `git revert` 是否恢复上一状态 |
| 工作树干净 | 检查后无非预期变化 |

判据见 [WORKFLOW.md §五/§六](../../../WORKFLOW.md)。
