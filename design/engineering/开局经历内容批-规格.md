# 开局「人生经历」内容批 · 撰写规格

> **这一份管内容，不管机制。** 机制口径在 [经历结构](../entities/经历结构.md)（§十 锚点是入口）；这里是"给一个格子里添经历"时必须满足的全部条件。
> 数据权威仍是 [`data/opening.json`](../../data/opening.json)——本文件**不复述词表**，动笔前先读它的 `vocab` 块。
> 2026-09-20 首版：288 段（24 格 × 12 段）由 12 个撰写单元并行产出后合并，落盘即通过 `validate` / `validateAnchors` / `validateDiseases` 三套检查。

---

## 一、格子从哪来

三个锚点 facet 都是**单值** ⇒ 组合**划分**整个池子，每条记录恰好落在一个格子里：

```
格 = (onset, duration_span, duration_pattern)     3 × 3 × 3 = 27 个组合
合法格 = 24     （fc_02「瞬时 × 持续不断」判掉 3 个）
```

| 每格要求 | 值 | 来源 |
|---|:-:|---|
| 条数 | **≥10（硬）· 12（推荐）** | 池子下限 = `quota.total`；12 段才有 66 个满额选择，10 段可能只有 1 个 |
| 跨地方数 | **≥4** | `ceil(quota.total / per_value_max)` |
| 每处条数 | **≤3** | `quota.per_value_max`（超出就选不满十段） |
| 格病并集 `u_c` | **2–4** | `data/diseases.json` 的 `cell_rule`：≤4 让候选只剩 3–4 张；≥2 保证屏 4 不至于只剩一张病 |
| 每条指向的病 | **1–2 个，且只能取自本格的 4 张** | 候选筛选力的前提（每条 ≤2） |
| 本格 4 张病 | 每张至少被指向 **2 次** | 否则那张病在本格里是死的 |

## 二、记录 schema（一个不多、一个不少）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | `^exp_\d{4}$`，**内容批按格分配号段**（第 k 格取 `exp_{101+20k}` 起的连续号），永不复用 |
| `title` | string | 卡面标题，**≤8 字**，纯叙事，不解释 |
| `summary` | string | 卡面正文，**≤48 字**，具体、可视、不抒情 |
| `context` | 单值 | 本格规格给定 |
| `relation` | 多值 0–6 | 空数组 `[]` = 一个人 |
| `role_care` / `role_power` / `role_belong` | 单值 | 见 §三.2 |
| `event` | 多值 1–3 | 发生了什么 |
| `duration_span` / `duration_pattern` / `onset` | 单值 | **本格规格给定，不许改** |
| `agency` | 单值 | 你能决定多少 |
| `consequence` | 多值 1–6 | **必须含 `ability`** |
| `effects` | object | `{ "attributes": { <属性id>: 整数 } }`，见 §三.3 |
| `diseases` | string[] 1–2 | 只能取本格那 4 个 id |

**禁止任何其它键**（`category` `theme` `parent` `kind` `class` `tags` `note` `weight` `severity` `intensity` …）：校验器把未知键当错误，这是"语义不许走私"的兜底。

## 三、硬规则（错一条整条作废）

### 3.1 文本 lint

1. **不许出现阿拉伯数字**（`0-9`、`０-９`）。中文数字（三、两、半）可以。
2. **不许出现这三个 facet 的取值标签**（它们的意思必须写在字段里，不许藏在文案里）：
   - `onset`：童年 · 少年 · 成年
   - `duration_span`：瞬时 · 短期 · 长期
   - `duration_pattern`：单次 · 持续不断 · 反复发生
3. 另外禁止：**从小 · 一直 · 每次 · 总是**
4. `title` ≤ 8 字；`summary` ≤ 48 字。

❌ 反例：`从小被忽视`（踩「从小」）· `长期上夜班`（踩「长期」）· `反复发生的搬家`（踩「反复发生」）· `三年里换了五个地方`（阿拉伯数字）
✅ 正例：`夜班排到天亮` · `换过很多地方` · `碗筷空着一副`

### 3.2 与 `relation` 的耦合

`relation` 为 `[]` 时，`role_care` / `role_power` / `role_belong` **必须都是 `none`**。
反之：`role_care` 取 `care_receiver`/`care_giver`、`role_power` 取 `managed`/`manager`、`role_belong` 取 `insider`/`outsider` 时，`relation` **不能为空**。
（`role_power = executor` 允许无人：你只是执行，不指挥谁。）

### 3.3 `effects`

- 属性 id 只有 5 个：`physique` `finesse` `observation` `communication` `will`。
- **项数 1–2**，每项**非零整数**，绝对值 ≤3。
- **代数和正好 = +2**。合法形态：`{a:+2}` · `{a:+1,b:+1}` · `{a:+3,b:-1}`。
- 语义：这一段真的练出了什么，代价写在负项里。不要为了凑数乱配。

### 3.4 非法组合

- 学校 × 伴侣（`context=school` 且 `relation` 含 `partner`）
- 瞬时 × 持续不断（已有格子定义排除，内容里不许出现）

## 四、同一格内 12 条的多样性

| 项 | 下限 |
|---|---|
| `agency` 四值（`active` `partial` `coerced` `powerless`） | 每个 ≥2 次 |
| `event` 八值（`gain` `loss` `conflict` `threat` `failure` `success` `exposure` `change`） | 每个 ≥1 次 |
| `consequence` 除 `ability` 外五值（`relation` `resource` `belief` `behavior` `emotion`） | 每个 ≥2 次 |
| `relation` / 三个 role | 散开，不要 12 条全 `[]` + `none` |

**12 条不能是同一件事换形容词**：职业、地点、人际位置、时代细节都要有区别。

## 五、文风

- **具体、可视、有物件**：碗筷、走廊、签字、凌晨的路、走廊椅子上的作业本。不要写情绪总结（"我很痛苦"），写发生了什么。
- 第二人称或无人称，冷静，不解释意义，不预告结局。一段经历**不是一次事件总结，是一块生活的切片**。
- 不要写疾病名、医学词汇或诊断词——病是**结果**，不是经历的标签；不要出现开局之后的世界内专有名词。

基准是 `data/opening.json` 里的既有记录（`exp_0007` 巷口的第二个人 · `exp_0005` 换药的手）。

## 六、交稿前自检

1. 每条 `id` / `context` / `onset` / `duration_span` / `duration_pattern` 与本格规格一致。
2. 全文件搜不出阿拉伯数字，也搜不出 §三.1 的禁用词。
3. 每条 `effects` 代数和 = +2、项数 1–2、非零、绝对值 ≤3；`consequence` 都含 `ability`。
4. `relation` 为空的三条 role 都是 `none`；反之亦然。
5. `diseases` 只来自本格那 4 个 id，每条 1–2 个，4 张病各被指向 ≥2 次。
6. §四 的多样性与 §一 的条数/地方数都达标。
7. 没有 `school` + `partner`；无未知字段；JSON 合法。

**机械核法**（内容批合并后一次性跑）：

```bash
# 结构自洽 + 锚点逐格体检（零错误才允许合并）
cd web && bun -e "import db from '../data/opening.json'; import ddb from '../data/diseases.json';
import { validate, validateAnchors } from './src/character-creation/opening.js';
import { validateDiseases } from './src/character-creation/diseases.js';
console.log(validate(db).errors.length, validateAnchors(db, ddb).errors.length, validateDiseases(db, ddb).errors.length)"
```

## 七、边界（违反即作废）

- 只写开局经历记录。**不碰战斗内容**（明雷 / 暗雷 / 遭遇门 / HP / SAN 一个字都不提）。
- **不得**引入 C# 引擎或神经模拟系统概念：脑区 · 连接组 · 主导网络 × 主导角色 · W 矩阵 · 意识结构 · 情境原语 · 认知评价 · α 模式 · 环境基调 · β/k/g。
