# 项目总览

> 游戏设计六维框架入口。设计状态和 grilling 路由表见 **[设计框架-六维状态](framework/six-dimensions.md)**。

## 项目

- 正式名：《子非鱼》（英文暂定：You Are Not the Fish）——「面具」降级为游戏内部子功能（面具系统），不再是项目总名
- 核心主题：精神状态在月光下的物理化——脑区链路驱动的回合制战术 RPG
- 核心目标：把神经科学抽象成可玩的 3D 技能树与资源系统
- **⚠️ 卡牌体系已废弃**（2026-07-11）→ 迁移至脑区链路技能树

## 一句话概述

玩家在一家受意识外显效应扭曲的精神卫生中心中，佩戴威尼斯面具，在月光下面对被具象化的幻觉与妄想。通过聚焦 3D 大脑中的神经链路进行战斗（2026-08-03 #20 范式修正）——链路始终激活，聚焦=构建层配置。NPC 共用同一套脑区基础设施，区别来自7参数化（4 tone baseline + 3 CSTC bias）和病情。

## 设计框架：六维分类

游戏 = 规则 × 实体 × 空间 × 事件 → 通过呈现交付，由管线生产。

| 维度 | 回答的问题 | 完成度 | 详情 |
|------|-----------|--------|------|
| **规则** | 能发生什么？怎么发生？ | ~90% | [设计框架-六维状态 §规则](framework/six-dimensions.md#规则) |
| **实体** | 谁是参与者？他们有什么？ | ~70% | [设计框架-六维状态 §实体](framework/six-dimensions.md#实体) |
| **空间** | 他们在哪里？怎么连接？ | ~52% | [设计框架-六维状态 §空间](framework/six-dimensions.md#空间) |
| **事件** | 在什么时候触发？以什么顺序？ | ~69% | [设计框架-六维状态 §事件](framework/six-dimensions.md#事件) |
| **呈现** | 玩家怎么感知和操作？ | ~25% | [设计框架-六维状态 §呈现](framework/six-dimensions.md#呈现) |
| **管线** | 怎么造出来、怎么验证？ | ~86% | [设计框架-六维状态 §管线](framework/six-dimensions.md#管线) |

**分拣标准**（拿到任何设计决策时问自己）：
- 删除所有角色和地点后，逻辑仍成立？→ **规则**
- 定义了"一类东西"的模板？→ **实体**
- 持久存在的容器？→ **空间**
- 有触发条件和时间轴？→ **事件**
- 换一种呈现方式，机制不变？→ **呈现**
- 影响开发效率而非游戏体验？→ **管线**

## 本轮设计共识（2026-07-26 ~ 28 grilling 结论，共 4 轮 69 项决策）

- **交互方式**：3D 技能树——链路上下文技能。战斗中启用已聚焦链路组（D26），L0-L2 由情境调制（rel）自动增强
- **技能与链路分离**：脑区承载链路（三体神经模型：CSTC环路+皮层-皮层+脑干广播，神经基础设施），技能=链路上下文链路组（37个AI操作已废弃，2026-08-03 #20）。快捷槽装的是技能不是链路
- **敌我同构**：NPC 和玩家共用同一套脑区链路体系——区别来自 7 参数化性格（4 tone baseline + 3 CSTC bias）和髓鞘化基线。行动选择从共享的 WC+CSTC+tone 动力学中涌现（Affordance Competition）
- **NPC AI = Affordance Competition 实时 salience**：从与玩家共享的 WC 动力学 + CSTC 门控 + 脑干 tone 调制中涌现（Cisek 2007 + GPR 2001）。6 概念标签保留为设计师简写界面，底层映射到 7 连续参数（4 tone baseline + 3 CSTC bias）
- **成长 = 髓鞘化**：使用即增长，不使用不衰退。Δm = base(L) × 反sigmoid(m) × 激活次数递减。无经验值/等级/技能点
- **6 概念标签（设计师简写，底层 = 4 tone baseline + 3 CSTC bias）**：敏化-威胁 / 敏化-奖励 / 抑制不足 / 过度抑制 / 反刍 / 社交钝化
- **聚焦容量**：起始 4（常驻，构建层，无上限），髓鞘化驱动增长。战斗中不消耗。
- **⚠️ 槽位系统已废弃**（2026-07-30）→ 改用激活点模型
- **SAN 系统**：≥60稳定，<30恐慌，=0随机行为
- **三因子调制**：兴奋性（Momi 2025）× 传导速度（Hansen 2024）× 神经调质增益
- **伤害双通道**：force（运动输出，稳定）+ motivation（动机驱动，情境敏感）
- **精神攻击永远命中**：防御 = 认知重评，走 Broca 通道
- **世界观**：月光三重叠加（物理场/神明/催化媒介三者同时为真，多版本基态）
- **敌人分类**：叙事来源（病人/思维造物/医疗人员/拜月教徒/动物）× CGI-S 病情（轻/中/重）矩阵
- **游戏循环（2026-07-28）**：
  - 废除"局"和"轮回"——连续世界，髓鞘化持久成长
  - 时间：每天三段（上午/下午/夜晚），休息驱动推进
  - 死亡：分难度（低=无限/中=有限/高=无复活），灵魂跟随都灵之马 7 回合
  - 存档：暂停退出/继续，不能回到过去
  - 三结局对应月光三重解释，条件自动触发
  - Boss = 见证月光思潮生命史，非结局选择器
  - 核心驱动力："回家"（不可及）
  - 空间 L1/L2 是同一现象的渐变而非硬分层
  - 面具从角色选择改为装备
  - **面具组件化 v1**（2026-07-29）— 组件容器/HiTOP分类/5槽位/掉落/组件互动
  - **面具系统 v2**（2026-07-29）— ⚠️ 13功能域已废弃(2026-08-03 #20)→链路上下文分类/组件=链路激活(+)抑制(−)/病理链路/同角色加成/操作规则/技能树集成/疾病重叠无效
  - 镜子从固定空间改为随身物品
  - 物理医院自由移动，深层空间节点式移动
- **关卡流程与进度（2026-07-30）**：
  - 空间切换 = 鬼打墙式无缝过渡，物理地图不变但门的另一侧在变化
  - L1 扭曲房间 = 单节点战斗场景，门关上不可逆。L2 = 大场景，非节点链
  - L1-only 房间扭曲消散后可复发；L1→L2 出门后回不来
  - 三层楼钥匙链独立：住院楼(1F全开放→4F天台/拜月教B)，门诊楼(入口在住院2F→顶层/A Boss)，供应中心(入口在门诊3F→中央/C Boss)
  - 三Boss = 三个月光思潮(B=神明/A=物理场/C=催化媒介-生存本能)，暂定打完结束
  - 进度 = 玩家自身变化(红骷髅消失/髓鞘化/镜子/新区域解锁)，无外部世界状态变化
  - 护士站：白天真人(可沦陷)，夜晚投影(无害自然现象，休息仍可用)
  - 一层需要多次/多天推完，三栋楼可自由选择推进顺序
- **任务/目标系统（2026-07-31）**：
  - 笔记本三层：承诺（NPC委托+门控自动写入）/ 线索（环境自动写入，不可删除，纯背景自足）/ 自问（独立子话题延迟）
  - 任务生命周期：发现→接受→记录→执行→完成→回报（回NPC处对话触发），允许放弃
  - Boss = 叙事引力中心：影响NPC（→承诺）和环境（→线索），两者单向管道指向同一源头
  - 任务发现：无感叹号，NPC待机动作区分，对话发现具体内容
  - 可塑性巩固修订：去掉点数/等级，改为巩固窗口（立即选择标记/增强）+ 动态事件强度（战斗三因子/非战斗叙事权重）
  - 激活点增长回到髓鞘化驱动（2条m≥0.7→5点，4条m≥0.7→6点）
	- **数值校准（2026-07-31）**：
	  - 玩家 HP 基线 50 (±10)，SAN 基线 80 (±10)
	  - 战斗长度目标：杂兵 4-6 / 精英 8-10 / Boss 16-20 回合
	  - Δm = base(L) × (1-sigmoid(m,0.45,10)) × g(n) — 反 sigmoid 递减
	  - 玩家起始髓鞘化：L0-L3 0.05-0.30，L4-L5 0.00-0.05
	  - HP↔SAN 互转：不对称兑换率
- **奖励/掉落系统（2026-07-31）**：
  - 组件+消耗品独立骰子掉落，Boss保证至少1件组件
  - 掉落率按敌人种类×层级二维表，稀有度逐层提升
  - 所有获得物品都通过世界交互——尸体搜刮/NPC容器/设施抽屉统一小列表UI
  - 无通用货币，以物易物+组件交换；组件分解=纯删除无收益
  - 日夜循环全局刷新，无防刷机制
  - 武器掉落/Boss背景资料预留接口等待独立系统完成
- **空间遭遇规则（2026-07-31）**：
  - 白天无战斗（纯叙事/探索/对话），所有遭遇 = 夜间规则
  - 明雷为主（走廊/病房/活动室/户外），暗雷仅造物泄漏/扭曲房间入口/休息偷袭
  - 走廊：半随机游荡 + 归属点，由敌人类型决定主动/被动接敌
  - 组间增援：察觉半径内整组加入，察觉半径由敌人类型定义（3-12格），L4识别域解锁显示
  - 遭遇密度按楼层梯度（1F 3-5 → 4F 8-12），每晚刷新一次
  - 户外独立遭遇表（月光直射 = 造物比例×2 / 等级+1 / 动物出现 / 拜月教徒小型仪式）
  - 护士站辐射：正常=周边密度降低，沦陷=密度上升吸引造物
  - L1 扭曲房间：关键预设 + 其余四参数半生成（病情主题×楼层×月光×L1→L2标记）
  - L2 患者内心世界：全预设，每个敌人有叙事关联，无杂兵概念
  - 楼梯间无常规遭遇（鬼打墙独立事件系统处理）
- **NPC AI = Affordance Competition 实时 salience**：行动选择从 WC+CSTC+tone 状态中涌现（Cisek 2007 + GPR 2001），运行时成本接近零，无需离线烘焙。性格由 4 tone baseline + 3 CSTC bias 参数化，6 概念标签为设计师简写界面。旧预烘焙管线（`design/pipeline/预烘焙管线脚本设计.md`）已废弃（2026-08-09）
- **回合战斗流程（2026-07-28）**：
  - 不设 AP——基底节 CSTC 环路门控，M1/Broca 双通道独立放行各 1 动作
  - 速度排序 = 察觉+决断+执行 三成分等权加权，动态重算
  - 5 阶段：情境更新 → 继承 → 速度排序 → 按序执行 → 回合收束
  - 行动窗口：声明 → 响应窗口 → 结算，后动者看到前方公开行动
  - 防御 = 跨行动窗口持续状态（M1 被占用，Broca 仍可用）
  - 即时伤害当场结算，被击倒在行动窗口前则跳过
  - 伏击 = 察觉方 1 轮自由行动窗口
- **态度引擎已废弃**（2026-07-26）：旧态度/情绪/行为/认知系统保留为参考数据源
- **卡牌体系已废弃**（2026-07-11）：旧卡牌参数保留为技能设计参考数据源
