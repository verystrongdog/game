# 职能侧多样化轴（非患者 NPC 生产约束）

> **定位**：与 [患者六轴](叙事多样化维度定义.md) **同构并列**的第二套生产约束——管**医护 / 科研 / 警卫 / 后勤行政 / 家属**等非患者 NPC 的防同质化。**只约束素材生产**：不进游戏、不进数值、不参与疾病资格判定。
>
> **状态**：提案稿 v0（2026-09-18 owner 接受推荐 → 落盘）。生效范围 = 非患者侧素材生产；本轮**尚未**在生产中消费（见 §六）。
>
> **依据**：[患者六轴定义](叙事多样化维度定义.md) §一–§四 · [NPC生态台账](NPC生态台账.md) · [敌人与事件](../../entities/敌人与事件.md) §5.1–5.3 · [游戏循环](../../events/游戏循环.md) §3.4 · [空间与关卡设计](../../space/空间与关卡设计.md) §3.4/§6.3

---

## 一、为什么不能照抄患者六轴

三条理由，逐条指源：

1. **轴 1、轴 2 以「入院」为坐标原点**（患者六轴 §二：轴 1「入院方式」、轴 2「入院时的功能状态」）——医生、护士、护工、保洁、警卫、后勤**没有"入院"这个动作**。硬套就要为 NPC 虚构一个不存在的入院事件。
2. **轴 5「创伤通道」与 24 病分类的资格签名绑定**——员工侧不跑疾病资格（[疾病资格层 Eligibility(d)](../../rules/skill-tree/创伤记忆转化接口.md) §3.2.2），跑的是 [敌人与事件](../../entities/敌人与事件.md) §5.2 的**压抑计数 → 反噬**。
3. **患者六轴没有「去留」这一格**——而员工是**唯一能走出医院的人**（owner 2026-09-18 裁定：医生护士上下班离开医院，不耽误他们被异常影响、认为自己没事 ⇒ 家属的存在不成问题）。「辞职 / 调岗 / 装作没事继续上班 / 投向拜月教」是他们独有的选择面，患者没有。

> **同构关系**：动机 → 状态 → 功能 → 弧线 → 通道 → 亮度。两套轴可并排阅读，而不是两套互不相干的规矩。

| 取值 | 落点 | 与机制的接口 |

> 依据：`敌人与事件` §5.2 逐字「每次触发强烈情绪 → 计数 +1」⇒ **年限就是计数器的叙事载体**（数值本身仍由 §5.2 的机制定义，本轴只负责让计数在人物上有来历）。
>
> **🔧 2026-09-18 边界情形（老巴稿提出）**：「老兵 ⇒ 计数接近临界 ⇒ 反噬」有**第二种老兵**——**熄灭型**：触发机制要求"强烈情绪"，而熄灭者**已不再产生强烈情绪** ⇒ **计数冻结而非累积** ⇒ 不会反噬（代价是：他也不会离开）。首例 = 老巴（34 年，门卫，计数因砸窗事件最后一次跳动后停止）。✅ **owner 2026-09-18 已裁：认可** ⇒ 与仪式型、代理型一并登记为 [敌人与事件 §5.2.1](../../entities/%E6%95%8C%E4%BA%BA%E4%B8%8E%E4%BA%8B%E4%BB%B6.md) 的三条边界路径。

### 轴 4：去留弧线（员工独有）

| 结构 | 说明 | 与机制的接口 |
|------|------|-------------|
| 疲惫累积 → 反噬 | 压抑计数满（§5.2） | 当天可能当场产生**一个完整体造物**（⚠️ 落进 1F 遭遇集需 owner 裁）——**在位载体：郝大力**（唯一） |
| 麻木持稳 | 不反噬也不离开 | 稳定基线（多数人）；**郑晓敏当前倾向** |
| 信仰转向 | 投向拜月教 | 阵营声望 + 二值状态字段——**在位载体：卢桂香**（唯一） |
| 辞职 / 调岗 | 离开医院 | **钥匙与权限唯一可变量**——人走了，钥匙换人管；**在位载体：郁宁**（唯一，已申请过一次没走成） |
| 殉职 / 失踪 | 从名单上消失 | 护士站「沦陷」或「废弃」的叙事来源（`空间与关卡设计` §3.7）；✅ **定案载体：老巴**（2026-09-18 owner 裁定——会改 1F 门控与痕迹面，见[台账 §七⑫](NPC%E7%94%9F%E6%80%81%E5%8F%B0%E8%B4%A6.md)） |
| **留在原地（走不了）** | **不会申请调岗、不会反噬、不会投向任何东西、也不会离开** | 新格（2026-09-18 立；原称"第五路径"）：**在位载体：谭丽娟**（唯一）。代价 = 她永远在同一个位置看同一件事重复发生——与「麻木持稳」的差别：郑晓敏是**倾向**（可动未动），她是**无路可动**（动念都没有） |

> 🔧 **2026-09-18 现状（六稿落地后 · owner 裁定后）**：**六格各有唯一在位载体**——反噬=郝大力 · 麻木持稳=郑晓敏（倾向）· 信仰转向=卢桂香 · 辞职调岗=郁宁 · 殉职/失踪=老巴（候选转**定案**）· 留在原地=谭丽娟（**新立**）。
> 📌 **格数口径（一次说清，防后续引用漂移）**：本表**记得是六格**。"四格已满/第五格"是**裁定过程**里的计数（当时**殉职·失踪**还只是候选、未定案）——定案后按表内实际格数计为**六格**，故"留在原地"是**新立的第六格**。⇒ §三 约束清单第 3 条对**新员工**仍然有效（新人不得再占这六格）。

### 轴 5：底线通道（与患者轴 5 同构，通道不同）

| 通道 | 说明 | 落点 |
|------|------|------|
| **职业性道德损伤** | 职业要求他做的事伤到了他（**执行约束** / 见死不救 / 替医院隐瞒） | **郝大力（约束执行者，主载体）**、何秀云、桑学文 |
| 被病人伤害 | 攻击 / 威胁 / 长期消耗 | 邢跃、裴明远 |
| 医疗事故 | 一次不可挽回的错 | 韦承宇（住院医值夜班） |
| 制度同谋 | 明知而参与（研究 / 名单 / 病历改写） | 褚北、傅思远、姚承志、骆怀安 |

> 与患者侧的关键差别：患者的创伤来自**别人对他做了什么**；员工的创伤来自**他的职业要求他做的事**。

## 三、约束清单（生产新员工时至少满足一条）

1. 岗位动机 ≠ 混口饭（或混口饭的理由必须具体到一个人/一件事）
2. 或叙事功能覆盖一个尚未使用的格子（当前缺：~~告密者~~✅ 褚北 · ~~熄灭者~~✅ 老巴/简国栋）
3. 或去留弧线 ≠ 麻木持稳（当前**六格全占**：反噬 ✅郝大力 · 信仰转向 ✅卢桂香 · 辞职/调岗 ✅郁宁 · 殉职/失踪 ✅老巴（定案）· 留在原地 ✅谭丽娟（新立）⇒ 新员工只能落回「麻木持稳」，或另立新格）
4. 或底线通道使用未用类型（当前缺：**医疗事故**、**被病人伤害**）
5. 或亮度光谱 ≠ 职业性温暖（当前缺：**冷光**、**熄灭**）

**防回归**：同一员工命中 ≥2 条为优；已落名单不强改，差异靠新增补充（同患者六轴 §三）。

## 四、与机制的对齐（三条硬线，不得违反）

| 线 | 内容 | 权威 |
|---|---|---|
| ① 反噬不是精神疾病发作 | 反噬 = 人格的暂时翻转（过度抑制 → 抑制不足），叙事上必须区别于病人恐慌 | `敌人与事件` §5.3 |
| ② 拜月教 = 状态字段，不是职能类别 | owner 2026-09-18 裁定：信徒由院中 NPC 加入产生，**不另设一类 NPC** | owner 裁定 + `世界观与叙事` §拜月教（虔信者/投机者两型） |
| ③ 上下班离开医院 ≠ 免疫 | 员工可离院，但仍被异常影响，且**认为自己没事** | owner 2026-09-18 裁定（与 `世界观与叙事` §空间扭曲 的现存冲突见 [台账 §七](NPC生态台账.md)） |

## 五、记账方式

- **命中格记录**：[NPC生态台账](NPC生态台账.md) 每位员工一列「轴命中」——名单自带防同质化证据，不需事后人肉复核。
- **进 manifest（沿用既有约定）**：`npc-materials-manifest.json` 已容纳非患者素材——形态 = `patient_pool: false` + `status: "non-patient"` + `target_disease: null`（既有先例：郑晓敏）。**非患者不进患者池核对区**（`患者生态索引` 的 `npc-patient-pool`），其素材状态以 manifest 为准、名单与驻地以 [NPC生态台账](NPC%E7%94%9F%E6%80%81%E5%8F%B0%E8%B4%A6.md) 为准。
- **不新建记账表**：非患者名单量级（≈40）不需要患者侧那种独立记账表；轴命中直接写在台账里。
