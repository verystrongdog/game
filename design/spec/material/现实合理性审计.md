# 现实合理性审计（NPC 素材 · 制度与流程层）

> **定位**：审的是**现实制度与流程是否成立**——用工形式 / 排班工时 / 权限钥匙 / 合规流程 / 法规硬线 / 时间跨度。**不审文学、不审机制、不审正典一致性**（那三项分别归 `素材起草规范` §三、六维正典、`危险点表`）。
>
> **触发**：owner 2026-09-18 追问——「一直排夜班？这合理么」。查出谭丽娟稿 v1.0 的"九年一直上夜班"**制度上不成立**（护士三班轮转）。⇒ 按同一条线回头扫员工侧六稿。
>
> **状态**：审计稿 v1（2026-09-18）。**owner 已接受建议 ⇒ R1–R16 已全部应用**（R6 于审计时已修；其余于同日按建议落入六稿 + `任务目标系统` §2.1 示例 + `游戏循环` §九；台账 §3.0 新增「用工形式」表）。**患者侧 17 稿由另一组审计补充（见 §七）**。
>
> **置信度说明**：`高` = 有法条/公开制度依据或行业通识；`中` = 通识推断，个体医院有差异；`低` = 我的推测，需你核。⚠️ 我不是临床或医院管理者，**凡是标 `中/低` 的，请你按你了解的实际情况覆盖我**。

## 一、审的六条轴

| 轴 | 问什么 |
|---|---|
| ① 用工形式 | 编制 / 合同制 / 劳务派遣 / **外包**（这一条决定他能不能被称为"医院职工"、有没有工龄、谁能调动他） |
| ② 排班与工时 | 三班轮转还是固定班；夜班后休息；法定禁排夜班情形 |

| ⑤ 法规硬线 | 《精神卫生法》《女职工劳动保护特别规定》等直接约束行为的条款 |

## 三、跨稿共性（三条，比单项更重要）

1. **编制 / 合同 / 外包的世代断层**（R1 R2 R4 R14）：六稿里五个人都在 1981–2007 年间入院工作，**没有一份写清了用工形式**。而 1990s→2015 正是这段制度变化最大的二十年。⇒ 建议在 [NPC生态台账](NPC%E7%94%9F%E6%80%81%E5%8F%B0%E8%B4%A6.md) §三 每张名单表**增设一列「用工形式」**（正式工 / 合同制 / 派遣 / 外包）。
2. **"一个人的岗位"是叙事需要，不是制度事实**（R7 R10）：谭丽娟的孤独、郁宁的窗口，都是为了让一个人独占一个位置。**制度上它们都不成立**（夜班≥2 人、病区药房对护士）。⇒ 修法不是加人，是**把孤独的定义从"身边没人"改成"身边的人不算数"**——这对本作主题更准。
3. **法规层藏着一个主线段**（R13）：既有设定里"出不去"一直被当作物理事实，而**《精神卫生法》把"能出去"写成了权利**。两者一叠，主题从"被困"升级为"**你的权利在纸面上成立，在现实里失效**"。

### 8.1.1 机械核对：出生年 + 年份 = 年龄（**我已执行**，2026-09-18）

> 跑法：遍历 `drafts/*.gen.json`（25 份，含 6 份非患者），比对 `identity.birth_year + 年份` 与 `identity.入院年龄` / `lifespan[].age`。

### 8.8 「社会性滞留」——住院时长不由临床严重度决定（🔧 2026-09-18 owner 裁定立为合法形态）

> **现象**：精神科病区里存在一类住院——**病情本身不需要继续住院，而出院去向没落实** ⇒ 每月出院评估口径一致（"病情不需要继续住院；出院去向未落实"），人在院内留下来。现实中它常被叫作"压床"，成因是**床位与去向两头**：一边是院外无照护条件（独居、无职业、家属在外地、社区接收渠道不通），一边是医院不能把没有去处的病人直接放到街上。

| # | 项 | 内容 |
|:--:|---|---|
| **R17** | **住院时长的合法解释** | 允许"住院时长由**社会性因素**而非临床严重度决定"。**置信度：中**（通识推断 + 病区管理常识，非文献锚；医院个体差异大——⚠️ 若你了解的实际运作不同，请覆盖本条） |

**写这条时必须写清三件事**（缺一条就退回"人推着进医院"那种含糊写法；参见 §8.5 系统性第 3 条）：

1. **评估口径**——每月/每评估周期记什么（"病情不需要继续住院"）；
2. **出院去向未落实**——具体是哪一头不通（无照护条件 / 无职业 / 家属在外省 / 社区渠道未接上），**不许写"医生不让走"**；
3. **谁在决定**——自愿住院者**随时可以要求出院**（法律上出口一直开着）⇒ 滞留是**他没走**，不是医院不放。⚠️ 这一条把它与"非法拘禁"彻底分开，也正是它最有戏的地方：**门开着，人不出**。

**首例载体 = `易川`（拖延症）**：临床 CGI-S 3（轻症上界）、住院累计 12 个月；三条住院指征"一条也不重"（睡眠-觉醒节律紊乱 / 反刍性自责伴体重下降 / 院外无照护条件），并且明写"**不是**严重精神障碍路径、不涉自伤他伤、不涉非自愿住院"。
他的滞留**不进机制文档**：`游戏循环`/`空间` 的出院权与门控只服务玩家主线，患者侧的长期住院不需要新机制。
