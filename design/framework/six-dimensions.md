## 六维定义与分拣标准

游戏 = 规则 × 实体 × 空间 × 事件 → 通过呈现交付给玩家，由管线生产出来。

| 维度 | 回答的问题 | 分拣标准（问自己） |
|------|-----------|-------------------|
| **规则** | 能发生什么？怎么发生？ | 删除所有角色和地点后，这个逻辑仍然成立吗？成立 → 规则 |
| **实体** | 谁是参与者？他们有什么？ | 这是模板还是实例？定义了"一类东西" → 实体 |
| **空间** | 他们在哪里？怎么连接？ | 这是持久存在的容器，还是随时间触发的发生？持久 → 空间 |
| **事件** | 在什么时候触发？以什么顺序？ | 有触发条件和时间轴吗？有 → 事件 |
| **呈现** | 玩家怎么感知和操作？ | 换一种呈现方式，游戏机制还一样吗？一样 → 呈现 |
| **管线** | 怎么造出来、怎么验证？ | 这影响的是开发效率还是游戏体验？开发效率 → 管线 |
