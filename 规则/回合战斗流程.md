# 回合战斗流程

> 统一的回合制战斗阶段/时机/响应窗口定义。基于基底节 CSTC 环路门控的速度排序模型——M1 运动环路（身体动作）和 Broca 语言环路（言语输出）独立门控，每回合各一个动作。链路的调制效果不因时序变化而失效。
>
> **维度: 规则** — 删除所有角色和地点后，回合阶段/排序/通道/响应规则仍然成立。

## 一、核心概念：基底节门控模型

### 1.1 不要 AP

不引入独立的"行动点数"（AP）。行动次数的约束来自神经解剖事实——基底节（basal ganglia）的 CSTC 环路是动作的门控开关。每次"放行"一个离散动作需要直接通路（Go）和间接通路（No-Go）竞争解决。这是生物学上的 Psychological Refractory Period（心理不应期）瓶颈。

你每回合能做的事不由 AP 定义——由**基底节每次门控窗口内的并行环路数**定义。

### 1.2 CSTC 并行环路

基底节有五条平行的 CSTC 环路（Alexander et al., 1986），其中两条直接对应战斗中的行动输出：

| 环路 | 基底节入口 | 丘脑出口 | 最终靶区 | 对应行动类型 |
|------|-----------|---------|---------|------------|
| **运动环路** | 壳核 | VA/VL | M1/SMA | 物理攻击、防御、身体动作 |
| **前额叶/联想环路** | 尾状核头 | MD | dlPFC | 精神攻击、言语行为（经 Broca） |

两条环路可以**同时放行**——不同入口、不同出口、不同靶区。你可以一边出拳一边骂人。

### 1.3 通道制

每回合（每次基底节门控窗口）：

- **M1 通道**（运动环路）：1 个身体动作 —— 物理攻击 / 防御 / 其他身体动作
- **Broca 通道**（前额叶/联想环路）：1 个言语动作 —— 精神攻击 / 言语行为

两个通道同时可用、分别独立门控。这不是 AP，是神经解剖约束。

## 二、M1 与 Broca 双通道

### 2.1 基础约束

| 通道 | 每回合上限 | 互斥对象 | 基底节环路 |
|------|----------|---------|-----------|
| M1 | 1 个动作 | 物理攻击 ↔ 防御（共享 M1 输出通路） | 运动环路（壳核→VA/VL→M1） |
| Broca | 1 个动作 | 无（当前仅精神攻击，后续可扩展） | 前额叶环路（尾状核头→MD→dlPFC→Broca） |

**移动是独立配额**，不占 M1 或 Broca 通道——基底节门控的是离散动作选择（攻击/防御），移动走小脑-基底节-运动皮层的并行回路。详见 §10.2。

### 2.2 目标选择

- M1 一次一个目标，Broca 一次一个目标
- 可以指不同目标（打 A 的同时骂 B）
- **多目标/AOE** 不是基础行动——需通过特定链路激活赋予（见 §10.6）

### 2.3 窗口内顺序

在同一个行动窗口内，M1 和 Broca 的动作**先后顺序由玩家自行决定**：

- 先 M1 后 Broca：击倒后的垃圾话更具攻击性
- 先 Broca 后 M1：战吼铺垫士气，身体再跟上

调解效果可以指定"仅在某个通道先于另一个时生效"的条件。

## 三、速度排序

### 3.1 三成分模型

谁先动不由单一数值决定，而是三个神经加工成分的综合：

```
速度 = 察觉分 × w₁ + 决断分 × w₂ + 执行分 × w₃
```

| 成分 | 脑区 | 决定什么 | 权重（默认） |
|------|------|---------|------------|
| **察觉** (perception) | L3 V1/A1 → L2 前脑岛/ACC 突显网络 | 多快注意到"局势变了" | 等权 |
| **决断** (decision) | 基底节 CSTC Go/No-Go 竞争解决时间 | 多快选定一个动作 | 等权 |
| **执行** (execution) | M1+壳核 （运动环路） 髓鞘化 | 动作从计划到落地多快 | 等权 |

**默认等权**（各 1/3）。权重只在以下情况偏移：

| 偏移来源 | 效果 |
|----------|------|
| 上回合激活的 L3/L4 感知节点 a(t) 偏高 | 察觉权重↑ |
| 上回合激活的 M1+壳核节点 a(t) 偏高 | 执行权重↑ |
| 情境突显/威胁 | 察觉权重↑ |
| L0 趋向（回避）激活 | 执行权重↑（逃跑反应链更短） |
| 精神攻击型参与者 | 察觉权重↑（需要读对方） |

权重不需要精确到小数点——速度只需要一个**序数结果**（A 比 B 快）。真正让排序动态变化的是 a(t) 的回合间传播和 CSTC gate 竞争。

### 3.2 首次回合排序

第一回合没有上回合激活的节点可参考，使用**静息值**（战斗初始状态 = 静息不动点——遭遇前静息 trace，运行时状态模型 §7.3；a(0) = 0.10 仅 WC 模拟冷启动种子，非战斗初值）：

| 成分 | 首回合来源 |
|------|------------|
| 察觉 | a(Pericalcarine)/a(TransverseTemporal)/a(Insula)/a(AnteriorCingulateCortex) 静息均值 |
| 决断 | c_loop 静息均值（三个 CSTC 环路） |
| 执行 | a(Precentral) 与 a_SD1 静息均值（Putamen 代理 = a_SD1_somatic） |

静息值定义（🔧 2026-08-13 step 7 裁决 Q1=A）：察觉 = 4 节点静息均值、决断 = c_loop 静息均值、执行 = a(Precentral) 与 a_SD1 静息均值。原求和形态已按 csharp-engine plan §十二-8 写回修正为均值形态（🔧 2026-08-13，分量归一化）。逐节点静息值见运行时状态模型 §7.3.1（M1 实测，active ∈ [0.535, 0.771]）。全员同一组静息值 → 首回合全平局 → 按 §3.4 掷硬币破平。

### 3.3 后续回合重算

每回合边界时重算所有参与者的速度：

- 察觉分 = 上回合末 4 节点 a(t) 均值（逐节点低于「未显著激活」阈值时该节点回落至其静息不动点——实测 ∈ [0.535, 0.771]，运行时状态模型 §7.3.1；原「回到静息基线 0.10」作废：0.10 仅初始化值。阈值 0.15 [NEW] 引擎 CalibrationConfig 占位，待校准）
- 决断分 = 上回合末 mean(c_loop)(t)
- 执行分 = 上回合末 mean(a(Precentral)(t), a_SD1(t))（Putamen 代理 = a_SD1_somatic）+ M1 是否被持续占用惩罚

重算后排出新的全局顺序。

### 3.4 同速破平

同速时掷硬币（模拟随机）。每回合重新破平。

### 3.5 等待

参与者可以在自己的行动窗口内选择**等待**——将行动窗口推到本回合最后。不占额外资源（不需要链路调制），代价是无法回到原位置。一旦选择等待，本回合剩下的排序中你就是最后一个。

## 四、回合阶段结构

```
Phase 1: 情境更新（回合开始）
  ├─ 上回合结算结果 → 更新所有参与者的情境原型
  ├─ 双方 L0-L2 自动激活（免费，不占槽）
  └─ 对所有参与者同时生效

Phase 2: 继承
  ├─ 上回合未释放的持续链路继续占槽
  └─ 冷却递减（在自己的行动窗口开始时）

Phase 3: 速度重算
  ├─ 首次回合：三分量取静息值（§3.2 表）
  ├─ 后续回合：上回合激活的链路调整成分权重
  ├─ 掷硬币破平
  └─ 排出全局顺序（快→慢）

Phase 4: 按序执行
  ├─ 按 Phase 3 排序轮流进入行动窗口
  ├─ 每个参与者的行动窗口：声明 → 响应窗口 → 结算
  ├─ 后动者看到前面所有人的公开行动
  └─ 即时伤害在结算时当场生效

Phase 5: 回合收束（最后一名参与者行动窗口结束后）
  ├─ 延迟伤害/状态统一结算
  ├─ 非持续链路解除聚焦
  ├─ NPC L3-L5 策略层更新
  ├─ 检查战斗结束条件
  └─ → Phase 1 下一回合
```

## 五、行动窗口

### 5.1 内部结构

每个参与者在自己的行动窗口内执行：

```
1. 冷却递减（自己窗口开始时）
2. 声明
   ├─ 选择 M1 动作类型
   ├─ 选择 Broca 动作类型
   ├─ 决定 M1 和 Broca 的先后顺序
   └─ 选择激活 L3-L5 链路（在聚焦容量内）
3. 响应窗口 — 其他参与者可以插入反应
4. 结算 — M1 + Broca 动作按照声明顺序落地，链路调制效果一同生效
5. 即时伤害当场结算（HP/SAN 变化立即生效）
```

### 5.2 玩家操作流

1. 轮到玩家 → 游戏暂停
2. 查看前面的行动历史（时间线展示）
3. 决策：选 M1、选 Broca、排顺序、激活链路（可以来回调整）
4. 点"确认" → 全部一起进入声明阶段 → 响应窗口 → 结算
5. 游戏继续到下一个参与者

### 5.3 即时伤害与延迟伤害

- **即时伤害**：行动窗口内结算时当场生效。排在后面的人看到前方已发生的结果（包括击倒）。
- **延迟伤害**：（后续设计预留）在 Phase 5 回合收束时统一结算。

## 六、响应窗口

### 6.1 时机

响应窗口插在"声明"和"结算"之间——意图和落地之间有间隙。你的 dlPFC 有一个窗口去重新解释即将发生的攻击。

### 6.2 可用的响应类型

| 响应 | 触发条件 | 成本 | 效果 |
|------|---------|------|------|
| L0 趋向（回避）自动触发 | 被物理攻击瞄准时 | 免费，自动 | 被动逃避——你在躲 |
| L4 读意图 | 读意图链路已激活 + 目标在行动 | 已在占槽 | 在敌方声明后、结算前调整自己的防御/行动 |
| 忍耐·主动 | 被精神攻击命中（声明后） | 占用 Broca 通道，CD 2 | SAN 减免翻倍（-2 而非 -1） |
| L5 叙事重构 B（条件触发） | 友方被伤害时 | 链路已激活 | 攻击+25%（下个行动窗口生效） |

### 6.3 边界

- 响应**不取消**对方行动——对方已经声明了，结算必然发生
- 响应是"在对方行动落地时你做的即时调整"
- 不是"打断"——不会取消对方的行动，只是调整你自己如何承受

## 七、防御

### 7.1 防御窗口

防御现在是一个**持续状态**，从你的行动窗口（选择防御）起，到**下回合你再次行动时**止。覆盖你两次行动窗口之间的所有敌方行动窗口。

### 7.2 M1 占用

防御期间，M1 通道完全被占用——走 CSTC 间接通路抑制运动输出。不能在此期间做第二个 M1 动作（物理攻击）。必须等到防御到期（下次轮到你行动），才能重新选择 M1 动作。

### 7.3 连续防御与续期

- 防御到期后，你可以在新的行动窗口内**重新选择防御**——续期到再下一轮
- 不需要链路调制即可续期（每次都是一个新的 M1 选择）
- 连续防御下，你的 M1 通道始终被占用，但 Broca 仍然可用

### 7.4 防御期间 Broca

**可用**。M1 和 Broca 走独立 CSTC 环路——你可以在防御姿态下同时精神攻击/言语。你在每个行动窗口都有独立的 M1 和 Broca 选择。但注意：声明防御意味着你这轮选择了"防御"作为 M1 动作——你仍然可以选择精神攻击作为 Broca 动作。

### 7.5 L5 控制对防御的调制（暂定翻译）

原有设计中的"L5 控制延长防御 1 回合"在持续状态模型下不再需要。暂定翻译：L5 控制 = **防御期间可临时借用 M1 一次**——用前额叶执行控制强行覆盖基底节的间接通路抑制，在防御窗口内短暂发起一次物理攻击，然后防御恢复。占 2 槽，高代价。

> ⚠️ 本条为暂定翻译，待后续重新审视。

## 八、战斗开始与结束

### 8.1 战斗开始

| 情况 | 第一回合处理 |
|------|------------|
| **常态**（双方感知对方） | 正常进入速度排序，使用静息 m 计算基线速度。无额外先手。 |
| **伏击**（一方未察觉对方） | 察觉方获得 **1 轮自由行动窗口**——只有察觉方参与排序，对方完全不在队列中（察觉分归零）。自由轮结束后正常进入回合循环。隐藏敌人规则见 §10.14。 |
| **被突袭**（休息中被偷袭） | 敌方获得 1 轮自由行动窗口。然后正常回合开始。 |

### 8.2 战斗结束

战斗的终止条件不是一刀切的规则——是**剩余参与者的决策结果**：

| 条件 | 效果 |
|------|------|
| **HP = 0** | 物理压制——被击败，退出战斗队列。即时生效。 |
| **SAN = 0** | 进入完全随机行为——仍保留在战斗队列中（见 §十二）。 |
| **全员 HP=0/SAN=0** | 一方全灭——战斗结束。 |
| **逃跑** | 用 M1 通道宣布逃跑。该参与者退出战斗队列。 |
| **投降**（有理性残余的敌方） | 用 Broca 通道宣布投降。敌方（医疗人员/拜月教徒）查表决定接受或拒绝。对战精神病患者和思维造物无效。详细流程归入叙事/对话系统。 |
| **全部剩余敌方逃跑/投降** | 战斗结束。 |
| **叙事事件中断** | 后续设计——特定条件触发强制结束。 |

### 8.3 逃跑规则

- 在自己的行动窗口内，用 M1 通道宣布逃跑
- 逃跑成功 → 该参与者退出战斗
- 逃跑失败（如敌方有 L5 控制压制你的回避）→ 留在战斗、浪费了该轮 M1 动作
- 惩罚：逃跑成功 → SAN 部分恢复（摆脱压迫），但该次战斗无髓鞘化增长（未完成）

## 九、冷却与状态持续时间

### 9.1 冷却追踪时机

冷却在你**自己行动窗口的开始时**递减。不是回合边界统一减。

- 这意味着冷却总是跨过一个完整的"两次行动窗口之间"的周期
- 防御 CD=1：你必须经历一轮没有防御的窗口（暴露一次），下次才能再防御

### 9.2 状态持续时间

| 表述 | 对应时长 | 追踪时机 |
|------|---------|---------|
| "持续 N 回合" | 从当前行动窗口起，经历 N 次你的行动窗口 | 自己的行动窗口开始时递减 |
| "持续到敌方倒地" | 事件触发释放，不受时序限制 | 实时检查 |
| "本回合"（旧表述） | 翻译为 "从当前行动窗口到下回合你的行动窗口" | — |

## 十、战斗空间与多参与者

> 战斗采用**战棋式网格坐标模型**（对标神界原罪/博德之门），网格是定位和移动的抽象层，实际空间为 3D 连续空间。控制区、视线、掩体等规则基于物理空间而非网格边界。

### 10.1 网格坐标系统

| 参数 | 值 | 推导来源 |
|------|-----|---------|
| 格大小 | 1m × 1m | 走廊 3m 宽 → 3 格；病房 6.9m → 7×7 格 |
| 网格类型 | 方格 | 与矩形建筑结构对齐 |
| 对角线距离 | 1.5 格（√2 ≈ 1.4 ≈ 1.5） | 对角移动消耗 1.5 倍移动力 |

### 10.2 移动经济

移动是**独立配额**——不占 M1 通道。基底节 CSTC 运动环路门控的是离散动作选择（攻击/防御），移动走小脑-基底节-运动皮层的并行回路，不是同一个门控瓶颈。

| 参数 | 值 | 推导 |
|------|-----|------|
| 基准移动力 | **12 格** | 6 秒回合 × 2m/s 战斗快走 |
| 速度偏移 | ±30%（8-16 格） | 察觉快/执行快的人移动力更高 |
| 通道关系 | 独立于 M1/Broca | 可以先走位再攻击，也可以攻击后走位 |

### 10.3 穿越与占据

| 场景 | 规则 |
|------|------|
| 同一格 | 不可站两人（1m² 容不下两人） |
| 穿过友方格 | 可穿过，不额外消耗移动力 |
| 穿过敌方格 | **不可穿过**——控制区球体物理阻挡 |
| 穿过 SAN=0 角色 | 可穿过（无意图阻挡） |
| 穿过倒地/死亡角色 | 可穿过，不消耗额外移动力 |

### 10.4 控制区与借机攻击

控制区是以角色上半身为中心的**物理球体**（非格子边界），在不规则空间中也能正常工作。

| 参数 | 值 |
|------|-----|
| 默认半径 | **1.5m**（≈ 1.5 格） |
| 覆盖范围 | 所有相邻格（角格中心 1.4m < 1.5m） |
| 扩展 | 长兵器链路激活 → +0.5m |

**借机攻击**：角色从敌人控制区球体内移出时触发。

| 借机方式 | 占用 | 说明 |
|---------|------|------|
| M1 借机 | 消耗本回合 M1 通道（如果还没用） | 物理反击 |
| Broca 借机 | 消耗本回合 Broca 通道（如果还没用） | 精神反击 |
| 通道已用 | 不可借机 | 先动了手就反应不过来了 |

### 10.5 射程

| 类型 | 范围 | 典型 M1 动作 | 典型 Broca 动作 |
|------|------|-------------|----------------|
| 近战 | 相邻格（控制区内） | 拳打/物理接触 | — |
| 短程 | 2-3 格 | 短兵器/投掷物 | 近距离言语 |
| 中程 | 4-8 格 | 长兵器/小型投射 | 正常对话/喊话 |
| 远程 | 9-20 格 | 枪械/弓弩（若有） | — |
| 视线内 | 不限（需视线） | — | 精神攻击（默认） |

### 10.6 多目标攻击 / AOE

**基础行动保持单目标**。AOE（范围攻击）不是基础能力，而是**特定链路激活后赋予的**：

| 链路类别 | 可能赋予的 AOE |
|----------|---------------|
| M1+壳核链路（执行） | 横扫（近战锥形 3 格） |
| L4 通路链路 | 多目标瞄准（物理攻击选 2 目标） |
| Broca+前额叶链路 | 精神冲击波（中程圆形 AOE） |
| L5 整合链路 | 大范围影响（远程大面积） |

AOE 需要更多聚焦——有冷却、或基础伤害递减。具体数值由各链路设计定义。

友军火力规则见 §10.12。

### 10.7 围攻与夹击

| 围攻程度 | 效果 |
|---------|------|
| 2 个敌人在控制区内 | 被围者防御效果 **-25%**（M1 通道被两侧牵扯） |
| 3+ 个敌人在控制区内 | 被围者防御效果 **-50%**，察觉分 **-2**（速度排序劣势） |
| 完全相反方向（≥135°）夹击 | 额外 **+20%** M1 物理命中 |

围攻递减防御迫使玩家用走位和 AOE 避免被包围。利用夹击站位（绕背）是有效的进攻策略。

### 10.8 高度与垂直性

一层层高 3.6m，高度差影响战斗：

| 要素 | 规则 |
|------|------|
| 高度差 | 每 1m 高度差 → 高处对低处 +1 察觉分，M1 近战命中 +5%。远程不受影响 |
| 跳跃 | 1m 垂直 = 1 格移动力消耗 |
| 攀爬 | 2 格移动力/(垂直)m。超过角色身高（~1.8m）的纯垂直面不可攀爬（需楼梯/斜坡/链路辅助） |
| 坠落 | 每 1m 坠落 ≥ 2m → 1 点物理伤害。≥ 5m → 倒地（下回合移动力减半） |
| 掩体 | 半掩体（栏杆/病床/墙角）：M1 远程命中 -20%。全掩体：不可瞄准（除非绕开或破坏） |

高度用**整米数**输入（0, 1, 2, 3...），是关卡设计数据，战斗系统不画 Z 轴网格。

### 10.9 视线与阻挡

| 阻挡类型 | 效果 |
|---------|------|
| **全高阻挡**（墙壁、关闭的门、楼层天花板） | 完全阻断视线，不可瞄准。Broca 精神攻击也受阻（需感知目标） |
| **半高阻挡**（病床、栏杆、矮柜、台子） | 半掩体：M1 远程命中 -20%。Broca 不受影响 |
| **生物阻挡**（友方/敌方站在瞄准线上） | 不阻断视线，M1 远程射击穿透时 -10% 命中/每个挡路角色。Broca 不受影响 |

特殊链路可穿透/减弱阻挡（如 L3 感知链路可察觉墙后气息，L5 整合可无视半掩体）。

### 10.10 部署（战斗开始位置）

| 情况 | 规则 |
|------|------|
| **常态遭遇**（双方互相察觉） | 敌方由遭遇设计者预设站位。玩家小队站在进入空间时的实际位置，可在战斗触发前（警戒状态）微调——移动力减半的自由走位 |
| **伏击**（一方未察觉） | 察觉方获得 1 轮自由行动窗口（§8.1），可自由走位不消耗移动力 |
| **被偷袭** | 被袭击方站在原位，袭击方已预先就位 |

### 10.11 战场边界

**软边界**——没有空气墙。角色跑出遭遇设定的合理范围后自动视为**逃跑成功**（M1 通道，§8.3 惩罚适用）。NPC AI 查表决定是否追击（敏化-威胁标签会追，过度抑制不会）。

### 10.12 友军火力

AOE 范围内不分敌我。友伤程度按**难度**分级：

| 难度 | 友伤规则 |
|------|---------|
| **低** | 关闭——队友免疫 AOE |
| **中** | 开启——队友承受 50% 伤害 |
| **高** | 开启——队友承受 100% 伤害（无减免） |

有链路可赋予"精确 AOE"（不伤队友），作为进阶能力。

### 10.13 环境交互

**M1 杂项动作**——不造成直接伤害，但改变战场状态：

| 环境动作 | 效果 |
|---------|------|
| 关门/开门 | 改变视线和移动通道（门框格变为半高阻挡或开放） |
| 推倒家具 | 该方向 2 格内制造半掩体，经过时移动力双倍消耗 |
| 推挤（对角色） | 目标需在控制区内，推 1 格方向。不造成直接伤害。推下高台/楼梯时适用坠落伤害（§10.8） |
| 破坏物件 | 攻击环境（打碎玻璃/木门/薄墙），破坏后半掩体消失 |

不设计"点燃/元素反应"等复杂系统——精神科语境不需要。

### 10.14 隐藏敌人

未暴露的敌人**不在排序列表中出现**。暴露后（进入任何角色的视线）插入排序末尾（同 §10.16 援军规则）。

L3/L4 感知链路可以察觉墙后隐藏者的存在——排序列表中显示模糊图标但不显示具体位置，直到视线暴露。

### 10.15 遭遇规模

- **无硬上限**。空间和回合长度均非约束因素。
- 遭遇的敌方配置**固定预设**——不随小队人数缩放。玩家带 2 人 vs 3 人，自己承担选择后果。
- 场强度缩放公式仍适用（⚠️ v2 η_player × η_environment 已废弃，2026-08-11 #38，CGL+AGC 新缩放公式待定。详见 [时空结构数学框架](../规则/时空结构数学框架.md)）。

### 10.16 同种与不同种敌人排序

| 类型 | 排序规则 |
|------|---------|
| **同种敌人**（相同配置） | 共享一个速度值，在同一行动窗口内依次（左到右、前到后）执行 |
| **不同种敌人**（杂兵 vs 精英 vs Boss） | 各自独立计算速度，独立行动窗口 |
| **与玩家穿插** | 不同种敌人自然穿插在玩家小队行动窗口之间 |

### 10.17 敌方目标协调

同种敌人在其共享行动窗口内有简单目标分配——优先分散攻击不同目标（避免全部集火同一人），除非有特定标签覆盖。不同种敌人之间独立查表决策。

### 10.18 倒地角色（尸体）

HP=0 角色退出战斗队列后：
- 身体保留在场地上（视觉不消失）
- 可穿过，不消耗额外移动力，可在同一格站立
- 不产生控制区球体（无法借机攻击）
- 尸体后续可能被特定链路利用（预留）

### 10.19 援军/增援

新参与者在其出现的时机插入当前排序列表的**末尾**。后续回合正常参与速度排序。本规则同时覆盖：
- 战斗中新增援敌
- 隐藏敌人暴露（§10.14）
- 临时 NPC 盟友加入

## 十一、NPC 行为

### 11.1 NPC 行动窗口

NPC 的回合行动从 Affordance Competition 实时计算——无需离线预烘焙。在其行动窗口内：

1. 读取当前 WC+CSTC+tone 状态 → 计算各技能 salience（详见 [NPC AI 行为模型](技能树系统/NPC%20AI%20行为模型.md) §三）
2. argmax（Boss）或 Softmax（杂兵）→ 选定技能
3. 声明 → 响应窗口 → 结算

### 11.2 反射级与策略级响应

在新的时序模型中：

| 响应层 | 脑区层级 | 何时更新 | 机制 |
|--------|---------|---------|------|
| **反射级** | L0-L2 | 当场（轮到 NPC 行动窗口时） | 查表时输入已包含截止此刻的所有公开事件 |
| **策略级** | L3-L5 | NPC 的下一个行动窗口 | Affordance Competition salience 反映 当前 tone + CSTC gate + 皮层 a(t) |

### 11.3 策略级更新时机

NPC L3-L5 策略层在 Phase 5（回合收束）时更新——即最后一名参与者行动结束后。下回合 NPC 行动时查的是更新后的表。

### 11.4 NPC 目标选择

NPC 目标选择从 Affordance Competition 的 salience 计算中自然导出。每个候选目标的 salience = 相关皮层节点 a(t) 均值 × gate × tone_bias(role)（详见 [NPC AI 行为模型](技能树系统/NPC%20AI%20行为模型.md) §三）。NPC 选择目标 = argmax 目标 salience。L3/L4 感知技能可揭露更多目标信息（最脆弱目标、读自己意图的目标等）。

## 十二、特殊状态

### 12.1 SAN=0 完全随机行为

- 仍保留在排序列表中，仍占据行动窗口
- M1 和 Broca 动作从合法链路中**完全随机选择**——不受情境和性格约束
- 可能攻击任何人——包括同伴——也可能做无用动作
- SAN=0 不是"不行动"——是"不可预测地行动"

### 12.2 友方受伤的条件触发

L5 叙事重构 B 等"友方受伤→增强"的条件触发：在友方受伤的**瞬间立即激活**（如果链路已聚焦），不等自己行动窗口。这是被动响应——你的脑区链路在监听局势变化。

## 十三、调制链路在新时序下的翻译

本文件定义了新的时序模型（速度排序、持续状态、响应窗口），但**链路调制效果本身不因此失效**。以下是术语翻译表：

| 旧表述 | 新含义 |
|--------|--------|
| "本回合" | 从当前行动窗口到下回合你的行动窗口 |
| "下回合" | 你的下一个行动窗口 |
| "冷却 X 回合" | 必须经历 X 次自己的行动窗口才能再用 |
| "持续 N 回合" | 从激活起，经历 N 次自己的行动窗口 |
| "防御期间" | 从选择防御的行动窗口到下次自己行动窗口之间 |

每条链路的调制效果（加伤、加命中、减伤等）在声明→结算时按照原始公式计算。条件触发（"友方受伤→"、"敌方 SAN<30%→" 等）实时检查——不一定非要在自己的行动窗口。

如有具体链路的翻译存在歧义，以本文件的术语表为准。
