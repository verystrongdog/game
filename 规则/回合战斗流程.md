# 回合战斗流程

> 统一的回合制战斗阶段/时机/响应窗口定义。基于基底节 CSTC 环路门控的速度排序模型——M1 运动环路（身体动作）和 Broca 语言环路（言语输出）独立门控，每回合各一个动作。链路的调制效果不因时序变化而失效。
>
> **维度: 规则** — 删除所有角色和地点后，回合阶段/排序/通道/响应规则仍然成立。

## 一、核心概念：基底节门控模型

### 1.1 不要 AP

不引入独立的"行动点数"（AP）。行动次数的约束来自神经解剖事实——基底节（basal ganglia）的 CSTC 环路是动作的门控开关。每次"放行"一个离散动作需要直接通路（Go）和间接通路（No-Go）竞争解决。这是生物学上的 Psychological Refractory Period（心理不应期）瓶颈。

你每回合能做的事不由 AP 定义——由**基底节每次门控窗口内的并行环路数**定义。

### 1.2 CSTC 并行环路

基底节有五条平行的 CSTC 环路（Alexander et al., 1986），其中两条直接对应战斗中的行动输出：

| 环路 | 基底节入口 | 丘脑出口 | 最终靶区 | 对应行动类型 |
|------|-----------|---------|---------|------------|
| **运动环路** | 壳核 | VA/VL | M1/SMA | 物理攻击、防御、身体动作 |
| **前额叶/联想环路** | 尾状核头 | MD | dlPFC | 精神攻击、言语行为（经 Broca） |

两条环路可以**同时放行**——不同入口、不同出口、不同靶区。你可以一边出拳一边骂人。

### 1.3 通道制

每回合（每次基底节门控窗口）：

- **M1 通道**（运动环路）：1 个身体动作 —— 物理攻击 / 防御 / 其他身体动作
- **Broca 通道**（前额叶/联想环路）：1 个言语动作 —— 精神攻击 / 言语行为

两个通道同时可用、分别独立门控。这不是 AP，是神经解剖约束。

## 二、M1 与 Broca 双通道

### 2.1 基础约束

| 通道 | 每回合上限 | 互斥对象 | 基底节环路 |
|------|----------|---------|-----------|
| M1 | 1 个动作 | 物理攻击 ↔ 防御（共享 M1 输出通路） | 运动环路（壳核→VA/VL→M1） |
| Broca | 1 个动作 | 无（当前仅精神攻击，后续可扩展） | 前额叶环路（尾状核头→MD→dlPFC→Broca） |

### 2.2 目标选择

- M1 一次一个目标
- Broca 一次一个目标
- 可以指不同目标（打 A 的同时骂 B）

### 2.3 窗口内顺序

在同一个行动窗口内，M1 和 Broca 的动作**先后顺序由玩家自行决定**：

- 先 M1 后 Broca：击倒后的垃圾话更具攻击性
- 先 Broca 后 M1：战吼铺垫士气，身体再跟上

调解效果可以指定"仅在某个通道先于另一个时生效"的条件。

## 三、速度排序

### 3.1 三成分模型

谁先动不由单一数值决定，而是三个神经加工成分的综合：

```
速度 = 察觉分 × w₁ + 决断分 × w₂ + 执行分 × w₃
```

| 成分 | 脑区 | 决定什么 | 权重（默认） |
|------|------|---------|------------|
| **察觉** (perception) | L3 V1/A1 → L2 前脑岛/ACC 突显网络 | 多快注意到"局势变了" | 等权 |
| **决断** (decision) | 基底节 CSTC Go/No-Go 竞争解决时间 | 多快选定一个动作 | 等权 |
| **执行** (execution) | M1+壳核 （运动环路） 髓鞘化 | 动作从计划到落地多快 | 等权 |

**默认等权**（各 1/3）。权重只在以下情况偏移：

| 偏移来源 | 效果 |
|----------|------|
| 上回合激活的 L3/L4 感知链路 | 察觉权重↑ |
| 上回合激活的 M1+壳核链路 | 执行权重↑ |
| 情境突显/威胁 | 察觉权重↑ |
| L0 趋向（回避）激活 | 执行权重↑（逃跑反应链更短） |
| 精神攻击型参与者 | 察觉权重↑（需要读对方） |

权重不需要精确到小数点——速度只需要一个**序数结果**（A 比 B 快）。真正让排序动态变化的是链路激活带来的偏移。

### 3.2 首次回合排序

第一回合没有上回合激活的链路可参考，使用**静息髓鞘化基线**：

| 成分 | 静息基线来自 |
|------|------------|
| 察觉 | L3 V1/A1 + L2 前脑岛/ACC 静息 m |
| 决断 | 基底节 CSTC 运动环路 静息 m |
| 执行 | M1+壳核 静息 m |

### 3.3 后续回合重算

每回合边界时重算所有参与者的速度：

- 察觉分 = 上回合激活的感知链路 m 值（未激活则回到静息基线）
- 决断分 = 上回合激活的基底节环路 m 值
- 执行分 = 上回合激活的 M1+壳核 m 值 + 上回合 M1 是否被持续占用（被占用则偏低）

重算后排出新的全局顺序。

### 3.4 同速破平

同速时掷硬币（模拟随机）。每回合重新破平。

### 3.5 等待

参与者可以在自己的行动窗口内选择**等待**——将行动窗口推到本回合最后。不占额外资源（不需要链路调制），代价是无法回到原位置。一旦选择等待，本回合剩下的排序中你就是最后一个。

## 四、回合阶段结构

```
Phase 1: 情境更新（回合开始）
  ├─ 上回合结算结果 → 更新所有参与者的情境原型
  ├─ 双方 L0-L2 自动激活（免费，不占槽）
  └─ 对所有参与者同时生效

Phase 2: 继承
  ├─ 上回合未释放的持续链路继续占槽
  └─ 冷却递减（在自己的行动窗口开始时）

Phase 3: 速度重算
  ├─ 首次回合：静息 m 基线
  ├─ 后续回合：上回合激活的链路调整成分权重
  ├─ 掷硬币破平
  └─ 排出全局顺序（快→慢）

Phase 4: 按序执行
  ├─ 按 Phase 3 排序轮流进入行动窗口
  ├─ 每个参与者的行动窗口：声明 → 响应窗口 → 结算
  ├─ 后动者看到前面所有人的公开行动
  └─ 即时伤害在结算时当场生效

Phase 5: 回合收束（最后一名参与者行动窗口结束后）
  ├─ 延迟伤害/状态统一结算
  ├─ 非持续链路释放槽位
  ├─ NPC L3-L6 策略层更新
  ├─ 检查战斗结束条件
  └─ → Phase 1 下一回合
```

## 五、行动窗口

### 5.1 内部结构

每个参与者在自己的行动窗口内执行：

```
1. 冷却递减（自己窗口开始时）
2. 声明
   ├─ 选择 M1 动作类型
   ├─ 选择 Broca 动作类型
   ├─ 决定 M1 和 Broca 的先后顺序
   └─ 选择激活 L3-L6 链路（在槽位预算内）
3. 响应窗口 — 其他参与者可以插入反应
4. 结算 — M1 + Broca 动作按照声明顺序落地，链路调制效果一同生效
5. 即时伤害当场结算（HP/SAN 变化立即生效）
```

### 5.2 玩家操作流

1. 轮到玩家 → 游戏暂停
2. 查看前面的行动历史（时间线展示）
3. 决策：选 M1、选 Broca、排顺序、激活链路（可以来回调整）
4. 点"确认" → 全部一起进入声明阶段 → 响应窗口 → 结算
5. 游戏继续到下一个参与者

### 5.3 即时伤害与延迟伤害

- **即时伤害**：行动窗口内结算时当场生效。排在后面的人看到前方已发生的结果（包括击倒）。
- **延迟伤害**：（后续设计预留）在 Phase 5 回合收束时统一结算。

## 六、响应窗口

### 6.1 时机

响应窗口插在"声明"和"结算"之间——意图和落地之间有间隙。你的 dlPFC 有一个窗口去重新解释即将发生的攻击。

### 6.2 可用的响应类型

| 响应 | 触发条件 | 成本 | 效果 |
|------|---------|------|------|
| L0 趋向（回避）自动触发 | 被物理攻击瞄准时 | 免费，自动 | 被动逃避——你在躲 |
| L4 读意图 | 读意图链路已激活 + 目标在行动 | 已在占槽 | 在敌方声明后、结算前调整自己的防御/行动 |
| 忍耐·主动 | 被精神攻击命中（声明后） | 占 1 槽，CD 2 | SAN 减免翻倍（-2 而非 -1） |
| L6 叙事重构 B（条件触发） | 友方被伤害时 | 链路已激活 | 攻击+25%（下个行动窗口生效） |

### 6.3 边界

- 响应**不取消**对方行动——对方已经声明了，结算必然发生
- 响应是"在对方行动落地时你做的即时调整"
- 不是"打断"——不会取消对方的行动，只是调整你自己如何承受

## 七、防御

### 7.1 防御窗口

防御现在是一个**持续状态**，从你的行动窗口（选择防御）起，到**下回合你再次行动时**止。覆盖你两次行动窗口之间的所有敌方行动窗口。

### 7.2 M1 占用

防御期间，M1 通道完全被占用——走 CSTC 间接通路抑制运动输出。不能在此期间做第二个 M1 动作（物理攻击）。必须等到防御到期（下次轮到你行动），才能重新选择 M1 动作。

### 7.3 连续防御与续期

- 防御到期后，你可以在新的行动窗口内**重新选择防御**——续期到再下一轮
- 不需要链路调制即可续期（每次都是一个新的 M1 选择）
- 连续防御下，你的 M1 通道始终被占用，但 Broca 仍然可用

### 7.4 防御期间 Broca

**可用**。M1 和 Broca 走独立 CSTC 环路——你可以在防御姿态下同时精神攻击/言语。你在每个行动窗口都有独立的 M1 和 Broca 选择。但注意：声明防御意味着你这轮选择了"防御"作为 M1 动作——你仍然可以选择精神攻击作为 Broca 动作。

### 7.5 L5 控制对防御的调制（暂定翻译）

原有设计中的"L5 控制延长防御 1 回合"在持续状态模型下不再需要。暂定翻译：L5 控制 = **防御期间可临时借用 M1 一次**——用前额叶执行控制强行覆盖基底节的间接通路抑制，在防御窗口内短暂发起一次物理攻击，然后防御恢复。占 2 槽，高代价。

> ⚠️ 本条为暂定翻译，待后续重新审视。

## 八、战斗开始与结束

### 8.1 战斗开始

| 情况 | 第一回合处理 |
|------|------------|
| **常态**（双方感知对方） | 正常进入速度排序，使用静息 m 计算基线速度。无额外先手。 |
| **伏击**（一方未察觉对方） | 察觉方获得 **1 轮自由行动窗口**——只有察觉方参与排序，对方完全不在队列中（察觉分归零）。自由轮结束后正常进入回合循环。 |
| **被突袭**（休息中被偷袭） | 敌方获得 1 轮自由行动窗口。然后正常回合开始。 |

### 8.2 战斗结束

战斗的终止条件不是一刀切的规则——是**剩余参与者的决策结果**：

| 条件 | 效果 |
|------|------|
| **HP = 0** | 物理压制——被击败，退出战斗队列。即时生效。 |
| **SAN = 0** | 进入完全随机行为——仍保留在战斗队列中（见 §十二）。 |
| **全员 HP=0/SAN=0** | 一方全灭——战斗结束。 |
| **逃跑** | 用 M1 通道宣布逃跑。该参与者退出战斗队列。 |
| **投降**（有理性残余的敌方） | 用 Broca 通道宣布投降。敌方（医疗人员/拜月教徒）查表决定接受或拒绝。对战精神病患者和思维造物无效。详细流程归入叙事/对话系统。 |
| **全部剩余敌方逃跑/投降** | 战斗结束。 |
| **叙事事件中断** | 后续设计——特定条件触发强制结束。 |

### 8.3 逃跑规则

- 在自己的行动窗口内，用 M1 通道宣布逃跑
- 逃跑成功 → 该参与者退出战斗
- 逃跑失败（如敌方有 L5 控制压制你的回避）→ 留在战斗、浪费了该轮 M1 动作
- 惩罚：逃跑成功 → SAN 部分恢复（摆脱压迫），但该次战斗无髓鞘化增长（未完成）

## 九、冷却与状态持续时间

### 9.1 冷却追踪时机

冷却在你**自己行动窗口的开始时**递减。不是回合边界统一减。

- 这意味着冷却总是跨过一个完整的"两次行动窗口之间"的周期
- 防御 CD=1：你必须经历一轮没有防御的窗口（暴露一次），下次才能再防御

### 9.2 状态持续时间

| 表述 | 对应时长 | 追踪时机 |
|------|---------|---------|
| "持续 N 回合" | 从当前行动窗口起，经历 N 次你的行动窗口 | 自己的行动窗口开始时递减 |
| "持续到敌方倒地" | 事件触发释放，不受时序限制 | 实时检查 |
| "本回合"（旧表述） | 翻译为 "从当前行动窗口到下回合你的行动窗口" | — |

### 9.3 槽位占用的持续时间

- **瞬时链路**：占槽从激活时起，到参与者的**下个行动窗口开始时**释放。始终占用，直到下次轮到你是否续用。
- **持续链路**：到触发条件满足时才释放（敌方倒地 / 2 轮 / 主动撤销）。

## 十、多目标与多参与者

### 10.1 规模上限

不设硬上限。同时在场参与者数量由遭遇设计决定。超过 5 个参与者的排序列表较长，由遭遇设计者自行权衡。

### 10.2 多目标选择

- M1 一次一个目标，Broca 一次一个目标，可分别指不同目标
- NPC 目标选择见 §11.4

### 10.3 援军/增援

新参与者在其出现的时机插入当前排序列表的**末尾**。之后的回合正常参与速度排序。

## 十一、NPC 行为

### 11.1 NPC 行动窗口

NPC 不通过在线搜索选择链路——已有预烘焙行为表离线编好。在其行动窗口内：

1. 查表（当前即时情境 + SAN 分段 + 已发生的历史事件）→ 行为概率分布
2. 骰子 → 获得链路配置（含 M1 选择、Broca 选择、先后顺序）
3. 声明 → 响应窗口 → 结算

### 11.2 反射级与策略级响应

在新的时序模型中：

| 响应层 | 脑区层级 | 何时更新 | 机制 |
|--------|---------|---------|------|
| **反射级** | L0-L2 | 当场（轮到 NPC 行动窗口时） | 查表时输入已包含截止此刻的所有公开事件 |
| **策略级** | L3-L6 | NPC 的下一个行动窗口 | 预烘焙查表反映 性格标签 × 更新后的情境 |

### 11.3 策略级更新时机

NPC L3-L6 策略层在 Phase 5（回合收束）时更新——即最后一名参与者行动结束后。下回合 NPC 行动时查的是更新后的表。

### 11.4 NPC 目标选择

在预烘焙行为表中嵌入目标选择逻辑（离线采样 1000 次）：

| 标签 | 倾向 |
|------|------|
| 默认 | 最近距离（物理就近，无认知成本） |
| 敏化-威胁 | 优先最近攻击过自己的目标 |
| 敏化-奖励 | 优先最脆弱的目标（低 HP/SAN） |
| 抑制不足 | 优先最容易打到的目标 |
| 过度抑制 | 不主动选择目标（只防御/沉默） |
| 反刍 | 持续攻击同一目标（不换） |
| 社交钝化 | 随机选择 |

当 NPC 激活了 L3/L4 感知链路时，可察觉更多信息（最脆弱目标、读自己意图的目标等）。

## 十二、特殊状态

### 12.1 SAN=0 完全随机行为

- 仍保留在排序列表中，仍占据行动窗口
- M1 和 Broca 动作从合法链路中**完全随机选择**——不受情境和性格约束
- 可能攻击任何人——包括同伴——也可能做无用动作
- SAN=0 不是"不行动"——是"不可预测地行动"

### 12.2 友方受伤的条件触发

L6 叙事重构 B 等"友方受伤→增强"的条件触发：在友方受伤的**瞬间立即激活**（如果链路已占槽），不等自己行动窗口。这是被动响应——你的脑区链路在监听局势变化。

## 十三、调制链路在新时序下的翻译

本文件定义了新的时序模型（速度排序、持续状态、响应窗口），但**链路调制效果本身不因此失效**。以下是术语翻译表：

| 旧表述 | 新含义 |
|--------|--------|
| "本回合" | 从当前行动窗口到下回合你的行动窗口 |
| "下回合" | 你的下一个行动窗口 |
| "冷却 X 回合" | 必须经历 X 次自己的行动窗口才能再用 |
| "持续 N 回合" | 从激活起，经历 N 次自己的行动窗口 |
| "防御期间" | 从选择防御的行动窗口到下次自己行动窗口之间 |

每条链路的调制效果（加伤、加命中、减伤等）在声明→结算时按照原始公式计算。条件触发（"友方受伤→"、"敌方 SAN<30→" 等）实时检查——不一定非要在自己的行动窗口。

如有具体链路的翻译存在歧义，以本文件的术语表为准。
