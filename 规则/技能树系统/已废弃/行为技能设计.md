## 二、L1 反射

> S1 最快通道。不需要认知前置（φ=1.0）。恐慌强制规则适用。

### 逃跑

```
行为层:
  drive: 反射
  valence: -1
  base_ap: 1
  base_effect: 闪避（本回合躲避 1 次攻击）
  theta_play: 0.15
  beta: 0.5
  gamma: 0.2

主动效果: 闪避 1 次攻击。冷却 0 回合（可每回合使用）。
  在恐惧状态下 AP = 0（优势卡——身体替你决定了）。
解锁成本: 1 技能点
```

### 僵住

```
行为层:
  drive: 反射
  valence: 0
  base_ap: 0
  base_effect: 跳过本回合行动，但获得 1 层"硬化"（下次受伤 -50%）
  theta_play: 0.15
  
主动效果: 强制等待 + 减伤。冷却 1 回合。
  恐慌强制触发时自动打出（不占快捷槽）。
解锁成本: 1 技能点
```

### 闪避

```
行为层:
  drive: 反射
  valence: -1
  base_ap: 1
  base_effect: 闪避 + 小位移（调整站位）
  theta_play: 0.15

主动效果: 闪避 1 次攻击 + 与敌方拉开距离。冷却 1 回合。
解锁成本: 1 技能点
```

## 三、L2 惩罚机制

> S1 中速。需要知识表征完成（φ=0.3→1.0）。防御向。

### 回避

```
行为层:
  drive: 惩罚
  valence: -1
  base_ap: 2
  base_effect: 减少后续 2 回合受到伤害 30%
  theta_play: 0.20
  beta: 1.0
  gamma: 0.5

主动效果: 获得 2 层"回避"buff（每层减伤 15%）。冷却 3 回合。
解锁成本: 2 技能点
前置: 反射 L1（任意 1 个节点）+ 认知 L2 记忆（任意 1 个节点）
```

### 妥协

```
行为层:
  drive: 惩罚
  valence: 0
  base_ap: 2
  base_effect: 放弃本回合行为输出→敌方下回合攻击力 -30%
  theta_play: 0.20

主动效果: 降低敌方下回合伤害 30%。冷却 4 回合。
解锁成本: 2 技能点
前置: 同上
```

### 克制

```
行为层:
  drive: 惩罚
  valence: 0
  base_ap: 1
  base_effect: 本回合不做行为输出→意志力 +1
  theta_play: 0.20

主动效果: 跳过行为输出，回复 1 意志力。冷却 2 回合。
  这是旧系统"执行（认知+行为）"组合的效果来源之一。
解锁成本: 2 技能点
前置: 同上
```

## 六、L3 文化习俗

> 外部脚本。需要知识表征完成（φ=0.4→1.0）。低耗稳定。

### 遵从

```
行为层:
  drive: 文化习俗
  valence: 0
  base_ap: 1
  base_effect: 按照当前战斗的"文化情境"执行默认行为（效果取决于战斗环境设定）
  theta_play: 0.15
  beta: 0.3
  gamma: 0.2

主动效果: 根据战斗环境执行一个情境行为。
  在治疗中心走廊 = 轻步慢行（闪避 + 降低敌方注意）
  在病房 = 关门/拉帘（创造隔离区）
  在镜子房间 = 照镜子（回复 SAN 1）
  冷却 1 回合。
解锁成本: 3 技能点
前置: 任意 1 个 L2 行为 + 认知 L3 知识表征（任意 1 个节点）
```

### 从众

```
行为层:
  drive: 文化习俗
  valence: 0
  base_ap: 1
  base_effect: 模仿友方上一回合打出的技能效果（×0.6）
  theta_play: 0.15

主动效果: 复制上一回合友方的技能效果（60% 强度）。
  "别人怎么做，我就怎么做。"
  冷却 2 回合。
解锁成本: 3 技能点
前置: 同上
```

### 运用仪式

```
行为层:
  drive: 文化习俗
  valence: 0
  base_ap: 2
  base_effect: 执行一个"仪式"→ 回复 SAN 2 + 降低自身 PAD 唤醒度 0.3
  theta_play: 0.15

主动效果: 执行安抚仪式。SAN +2，自身 A 值 -0.3（冷静下来）。
  敬畏情绪下效果翻倍（仪式 + 敬畏 = "虔敬"）。
  冷却 4 回合。
解锁成本: 3 技能点
前置: 同上
```

## 七、L4 价值驱动

> S2 王牌。需要全部 5 模块完成（φ=0.05→1.0）。高 AP 高效果，硬解锁核心。

### 牺牲

```
行为层:
  drive: 价值
  valence: +1
  base_ap: 3
  base_effect: 心灵震慑 6 + 自身 HP -10%
  theta_play: 0.50
  beta: 1.5
  gamma: 1.0

主动效果: 心灵震慑 6，自身 HP -10%（当前 HP，不是最大 HP）。
  恐惧+牺牲 C_control = 3.8（全游戏最贵，硬解锁需要强烈意志）。
  愤怒+牺牲 C_control = 0（愤怒时价值驱动免费——"奋起"）。
  冷却 5 回合。
解锁成本: 5 技能点
前置: 道德 L3 或 文化习俗 L3（任意 1 个节点）+ 认知 L5 推理（任意 1 个节点）
```

### 对抗

```
行为层:
  drive: 价值
  valence: ±1（取决于情境——对抗可以用于保护也可以用于攻击）
  base_ap: 3
  base_effect: 心灵震慑 5 + 驱散敌方 1 个 buff
  theta_play: 0.50

主动效果: 心灵震慑 5 + 移除敌方 1 个增益效果。
  冷却 4 回合。
解锁成本: 5 技能点
前置: 同上
```

### 突破

```
行为层:
  drive: 价值
  valence: +1
  base_ap: 4
  base_effect: 心灵震慑 7 + 无视敌方防御 + 自身 SAN -2
  theta_play: 0.50

主动效果: 心灵震慑 7，无视防御。自身 SAN -2。
  "不是为了赢——是为了证明可以。"
  冷却 6 回合。
解锁成本: 5 技能点
前置: 同上
```

## 八、L4 照护驱动

## 九、恐慌强制规则

当 g_reflex > 0.85 时触发恐慌强制——来自旧系统的规则保留：

- 本回合**必须**使用一个反射驱动技能
- 快捷槽中没有反射技能可用 → "僵住"自动激活（不占槽位）
- 玩家可花 3 意志力压制此强制（将 g_reflex 临时压至 0.8）
- 恐慌强制只对反射驱动生效

## 十、参数速查

| 参数 | 符号 | 作用 |
|------|------|------|
| drive | — | 归属的驱动 (7 种之一) |
| valence | — | 行为方向 (-1/0/+1)，影响态度结算 |
| base_ap | — | 基础 AP 消耗 |
| base_effect | — | 基础效果值 |
| theta_play | θ_play | 技能可用性阈值 |
| beta | β | AP 成本敏度（cost_modifier = 1 + β·(1-α)） |
| gamma | γ | 效果增益系数（effect = base × (1 + γ·(α-θ))） |
| c_control | C | 硬解锁控制成本（查表：情绪 × 驱动） |

完整 C_control 表见 [态度系统/态度系统.md](../../../%E5%8F%82%E8%80%83/%E5%BA%9F%E5%BC%83/%E6%80%81%E5%BA%A6%E7%B3%BB%E7%BB%9F/%E6%80%81%E5%BA%A6%E7%B3%BB%E7%BB%9F.md) §⑤。
