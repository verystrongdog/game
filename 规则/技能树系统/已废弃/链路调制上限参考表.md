# 链路调制上限参考表

> 每条链路的最大调制效果（modulation ceiling）由 ENIGMA 结构连接强度、Hansen 2024 脑干-皮层 FC、白质纤维束解剖数据推导而来。
> 
> **公式**: `调制上限 = SC_norm × 层级权重 × 方向因子`
> 
> **实际调制** = `调制上限 × 髓鞘化程度` (髓鞘化 ∈ [0, 1])

## 参数速查

| 参数 | 值 | 说明 |
|------|-----|------|
| ENIGMA SC p95 | 10.48 | 结构连接 95 百分位 (归一化分母) |
| 层级权重 | L0=0.50, L1=0.60, ..., L6=1.10 | 高层链路的调制天花板更高 |
| 方向因子 | 上行1.0, 下行0.7, 广播1.0, 全局1.0 | 下行调制更"费力" |
| 髓鞘化缩放 | 0.0(无) → 1.0(满) | 线性缩放调制上限 |

## 效果类型汇总

将 ceiling 值映射到游戏中的百分比加成:

| 效果类别 | 关联链路 | 叠加方式 | 最大累计 |
|---------|---------|---------|---------|
| damage_physical (物理伤害加成) | 期待, 价值直觉, 命名, 决策 | 加性 | 100% (raw: 179%) |
| damage_mental (精神伤害加成) | 激活, 期待, 命名, 决策 | 加性 | 100% (raw: 148%) |
| defense_physical (物理防御加成) | 身体感知, 想象, 决策 | 加性 | 100% (raw: 154%) |
| hit_rate (命中率加成) | 执行动作, 读意图 | 加性 | 100% (raw: 114%) |
| dodge (闪避率加成) | 应激反应_被动, 应激反应_被动, 警觉, 回忆, 读意图 | 加性 | 100% (raw: 282%) |
| san_recovery (SAN 恢复) | 满足, 内省 | 加性 | 57% (raw: 57%) |
| threshold_mod (触发阈值偏移) | 恐惧条件化, 辨别, 识景, 自省 | 加性 | 100% (raw: 191%) |
| ap_reduction (AP 消耗减免) | 熟练, 期待, 习惯化, 比喻 | 加性 | 100% (raw: 187%) |

> **叠加规则**: 同效果类型内的链路调制**加性叠加**，上限 100%。
> **髓鞘化缩放**: 每条链路的实际调制 = ceiling × 髓鞘化程度。髓鞘化 0.3 = 30% 效果, 0.6 = 60%, 1.0 = 满效果。
