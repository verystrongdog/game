# 基础行动 — 物理与精神攻击

> **维度: 规则** — 基础行动是战斗结算的底层公式，删除所有角色后仍成立。
>
> 基础行动不来自任何解锁——它们是角色的**身体和声音**，开局即存在。所有链路的调制最终汇入两条输出通道：**M1（骨骼运动）**输出身体动作，**Broca（语言）**输出有意识说出的话。物理攻击走 CSTC 感觉运动环路（M1+壳核），精神攻击需要初级执行控制参与（L5 dlPFC/ACC 的最简形式，走 Broca 通道）。链路的髓鞘化增强、调制或暂时压制这些基础行动。
>
> **设计原则**: 身体不需要大脑许可就能出拳。精神攻击占用 Broca 通道。

## 二、行动设计

### 行动 1: 物理攻击

```
脑区: M1 + 壳核 (CSTC 感觉运动环路)
类型: 物理伤害 — 开局可用
```

**效果:** 对单个敌方造成 4 物理伤害。

**命中判定:**
- 基础命中率 85%
- 受 L0 趋向 回避状态影响: -10%
- 受 L1 失望标记影响: -5%/层
- 受 L3 执行动作(精准模式)影响: +20%

**暴击判定（2026-08-16 Grilling #77 新增——F-3 规则空缺补全）:**
- 命中判定通过后 → 暴击判定（a(t) 执行强度驱动，与速度执行分同源——"越出力越易暴击"）:
  ```
  crit_rate = clip(base_crit + k_crit × (a_exec − θ_crit), 0, cap)
  a_exec = mean(a(Precentral), a_SD1_somatic)
  ```
- 暴击效果: 伤害 ×1.5（结算顺序: 基础伤害 → gate × 防御 → ×1.5 → 一位小数量化）
- 暴击事件: 判定通过 → emit A3（暴击者）+ B3（被暴击者），见 [运行时状态模型 §5.5](../../技能树系统/运行时状态模型.md)
- 参数: base_crit 0.05 / θ_crit 0.6 / k_crit 0.5 / cap 0.30（全 [NEW] 待 #35 校准）
- 受 L4 识别「揭示物理弱点」提升: 对弱点目标 crit_rate +0.15（见 §三）

**消耗:** 动作 1 (M1 通道), 冷却 0

**武器加成（2026-08-05 grilling #21）:**
- 武器在战斗外装备（主手/副手/饰品三槽）。物理武器改变 M1 通道的伤害/命中/特殊效果；精神武器（月光场凝结物）占 M1 通道，需链路 m 阈值
- 伤害公式: `(4 + weapon_bonus) × (1 + force_mod + motivation_mod)`
- 命中公式: `85% + weapon_hit_mod + 链路命中调制`
- 完整数据表见 [实体/武器与装备](../../../实体/武器与装备.md)

### 行动 2: 精神攻击

```
脑区: dlPFC/ACC → 无特定运动输出（精神攻击没有"运动通路"）
类型: 精神伤害 — 开局可用
```

**效果:** 对单个敌方造成 2 精神伤害 → 敌方 SAN -2, HP -1。

**精神攻击的本质:**
- 不是"发出精神波"——是"你的存在、你的凝视、你的意志对他人构成的精神压力"
- 在月光下，这种压力变得物理上真实（意识外显效应）
- 精神攻击无视物理防御（闪避/格挡无效——对方的言语/凝视必然进入感知）

**命中:** 精神攻击**永远命中**——你无法选择不听别人的话、不看别人的眼神。但你是否被它动摇，取决于你当下的认知状态。

**防御:**
- 精神防御不是闪避——是前额叶对情绪信号的**认知重评**（reappraisal）
- 公式:
  ```
  精神攻击实际伤害 = base × (1 + motivation_mod)
                     - 敌方忍耐被动减免
  ```
- **忍耐·主动**: 占用 Broca 通道 1 回合 → SAN 减免翻倍（-2 而非 -1），持续 1 回合。冷却 2 回合。
- **低 SAN 穿透**: 敌方 SAN < 30% 时 → 精神攻击额外 +30% 效果；< 15% → ×2（防线已崩溃 / 崩溃边缘——与 §四 速查表、核心机制 §4.3 一致）

**消耗:** 动作 1 (Broca 通道), 冷却 0

---

### 行动 3: 防御

```
脑区: M1 + 苍白球 (CSTC 间接通路 → 运动抑制)
类型: 防御 — 开局可用
```

**效果:**
- 本回合受到的所有物理伤害 -50%
- 本回合不能使用物理攻击（防御和进攻共用 M1 输出通路）
- 本回合可以同时使用精神攻击或感知类技能
- 不能减少精神伤害

**消耗:** 动作 1 (M1 通道), 冷却 1 回合

**冷却设计意图:**
- 不能连续防御——身体需要切换回进攻状态
- 1 回合冷却意味着：防御→暴露→防御→暴露 的节奏

## 三、链路调制如何增强基础行动

| 层级 | 操作 | 对物理攻击 | 对精神攻击 | 对防御 |
|------|------|----------|----------|--------|
| L0 | 趋向(趋近) | 伤害 +10% | — | — |
| L0 | 趋向(回避) | 命中 -10% | — | 减伤 +10% (总 -60%) |
| L0 | 熟练 | 连续物理攻击第3次 AP-1 | — | — |
| L0 | 激活(蓝斑) | — | 精神伤害 +1 | — |
| L1 | 期待(每层) | 伤害 +1/层 | 精神伤害 +1/层 | — |
| L1 | 失望(每层) | 命中 -5%/层 | 命中 -5%/层 | — |
| L1 | 习惯化 | 物理攻击 AP 减免加速 | 精神攻击 AP 减免加速 | — |
| L2 | 价值直觉 | 高亮"该攻击还是该防御" | — | — |
| L3 | 执行动作(精准) | 命中 +20% | — | — |
| L3 | 身体感知 | 揭示弱点→伤害 +2 | — | 减伤 +10% |
| L4 | 读意图 | 读到攻击→可提前防御 | — | 防御当回合无冷却 |
| L4 | 识别 | 揭示物理弱点→对目标暴击率+15% | 揭示精神弱点→对该目标精神攻击 SAN 伤害×1.5（确定性） | — |

## 四、参数速查

| 参数 | 值 | 说明 |
|------|-----|------|
| 物理攻击 动作 | 1 (M1 通道) | |
| 物理攻击 基础伤害 | 4 | 空手 |
| 物理攻击 伤害公式 | `4 × (1 + force_mod + motivation_mod)` | force cap +50%, motivation cap +100% |
| 物理攻击 基础命中 | 85% | 受执行动作/读意图/失望调制 |
| 精神攻击 动作 | 1 (Broca 通道) | |
| 精神攻击 SAN伤害 | 2 | |
| 精神攻击 HP伤害 | SAN伤害的 1/2（向下取至 0.1） | 2026-08-13 一位小数结算 |
| 精神攻击 命中 | 永远命中 | 无命中率判定 |
| 精神攻击 伤害公式 | `2 × (1 + motivation_mod) - 敌方忍耐` | |
| 敌方低SAN穿透 | SAN<30→+30%, SAN<15→×2 | 精神防线崩溃加速 |
| 防御 动作 | 1 (M1 通道) | |
| 防御 减伤 | -50% | 仅物理伤害 |
| 防御 冷却 | 1 回合 | |
| 忍耐·主动 SAN减免 | -2（翻倍） | 冷却 2 回合, 占用 Broca 通道 1 回合 |
| 忍耐·被动 SAN减免 | -1（被动永久） | 最低受到 1 点伤害 |

> **注（2026-08-13 裁决，csharp-damage Q3=D）**：伤害/SAN/HP 结算值全程一位小数——主伤害 round 半进位量化到 0.1（`MathF.Round(x,1)`），HP 成分向下取至 0.1（原「向下取整」在一位小数结算下的粒度对应）。表内整数展示值（SAN -2、HP -1、基础伤害 4）为基线（motivation=0、无穿透）特例，即 2.0/1.0/4.0。
