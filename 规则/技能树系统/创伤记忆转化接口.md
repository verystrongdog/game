## 一、定位与边界

**转化接口回答**：创伤记忆的连续量（L 总负荷、I_max 单次烈度）如何映射为疾病的离散档位（轻/中/重）与病理边 m 偏移。

```
创伤事件 e_i（连续）          ← #87 生成功能产出
  ↓ ΔI = k × A
创伤记忆 R（连续：I_mem, L）   ← #90 存储（I_mem ∈ [0,1] 是强度非档位）
  ↓ f(L, I_max)              ← 本文档定义（转化函数）
疾病档位 s ∈ {∅,轻,中,重}（离散）← 疾病层才有档位
  ↓ 实例化 + B′ 过滤
m = m_offset[s]（病理边模板值）
```

**边界**：
- 创伤记忆**没有档位**——I_mem 是连续强度、L 是连续负荷；"轻中重"只存在于疾病层
- 本接口不定义疾病内容（26 病 + 348 病理边已完成，`pathology_edges.json`）
- 本接口不定义记忆存储/检索（#90 已定义）

**致病立场（Q1a-2，C 定案 + 2026-09-01 世界观裁决修正）**：创伤 = 累积到阈值。无创伤 + 无器质 + 非发育 → 健康（正常人模板 m 基线 0.3-0.5）。未达单次阈值的重复挫折经剂量-反应累积（L = ΣΔI×g）突破阈值 → 创伤记忆。

**世界观裁决（2026-09-01，#87 恢复讨论 + 外部评审核查 t_6a960da7e254819198438cb6185052d7）**：

- **创伤 = 唯一触发路径**：没有创伤记忆就不发病。**创伤来源 = 各类固定生活环境（家庭/学校/职场/部队/社区等）**——事件类型层环境无关（§3.2.1 十类事件：校园霸凌=社会伤害、职场羞辱=公开羞辱/控制剥夺、长期压力=慢性冲突/高压 等），家庭环境**不是**唯一来源。家族聚集现象的**解释层立场**（模型假说非事实等式）：跨代环境传递（凯博文：社会根源 = 社会结构 × 人际网络）为候选解释。
- **β = 个体易感性接口，β(t) 最小化版**（2026-09-01 两轮修正）：**β_i(t) = F(β₀,i, D_i(t))——基线易感性 β₀ × 发育阶段调制**，慢变量；**既往经历和当前环境不直接修改 β**（经历可塑变化走 g/k/L，β 不与它们争夺解释权——模型职责分离，非经验事实断言）。β₀ = 个体基线易感性，来源开放 ∈ {遗传、早期发育、其他稳定个体差异}，不预先裁决权重；β(t) = 基线经发育阶段调制后的当前易感性。家族聚集的遗传/环境归因**不在 β 定义层裁决**（三层分离：经验层 = 家族聚集是观察到的现象 / 解释层 = 本项目立场「跨代环境传递为候选解释」，模型假说非事实等式 / 参数层 = β 接口）。依据：Tienari 芬兰收养研究（基因×环境交互——健康家庭显著降低高遗传风险儿童患病率，Br J Psychiatry 2004;184:216-22，支持"环境可调节易感性表达"）。原「遗传 = 阈值调制」命名废弃（偷渡 β≡遗传 因果判断）。**防自激反馈环**：β(t) 时变 ≠ 每次受创伤后 β 自动改变——事件即时负荷进 L，不反向改 β。
- **g = 环境塑造**：不成熟度由童年环境决定（依恋质量/教养方式/早年经历），非天赋。模型闭合：环境（g 塑造 + 创伤事件）× 个体（β 易感性）——无"无来源"自由度。
- **D9 立场 B「遗传素质」成分废弃**：素质-应激兜底不再需要——无创伤 = 健康严格成立。

**四变量职责表（2026-09-01 定案，第七份外部评审 t_6a9621ee23488191aa80e71f91ac5a5e）**——每个变量单一职责、单一时间尺度，防止概念堆积：

| 变量 | 回答的问题 | 被事件直接改变？ |
|------|-----------|----------------|
| β(t) | 当前发育阶段对刺激的基底易感性 | 否（慢变量，β₀×D(t)） |
| g(t) | 心智/发展状态使事件负荷被放大多少 | 可受发展/状态影响 |
| k | 事件进入负荷系统时有多少被应对/缓冲 | 可受学习与应对能力影响 |
| L(t) | 已累积的病理负荷 | 是，事件直接累积 |

### 3.1 Step 1：病理化判定（双阈值）

```
病理化 ⟺ (I_max ≥ A_trauma_I(i)) ∨ (L ≥ A_trauma_L(i))
  A_trauma_I(i) = 0.7 × β(i)；A_trauma_L(i) = 1.0 × β(i)   （2026-09-01 个体化：β(t) = β₀ × D(t) 慢变量，事件不改 β）
  单次毁灭性事件（I_max 高）或 长期累积（L 高），任一达标即病理化
  否则 → s = ∅（非病理化：创伤记忆作为叙事/记忆存在，不致病）
```

### 3.2 Step 2：疾病选择（M:N 候选集模型，2026-08-21 修正）

**临床事实（已核验）**：1 创伤 → 多疾病（单次灾难 → PTSD+MDD+SUD 共病）与 N 创伤 → 1 疾病（多创伤累积 → 单一抑郁）均存在。转化关系为 **M:N 多对多**。

```
记忆层：Rᵢ → C(Rᵢ)（候选疾病集，1→N）
        事件类型 → 候选集（如 性创伤 → {PTSD, DID, BPD}，临床常见共路径）
        N/F/R 表征 → 选主病（碎片化 F → PTSD/解离、叙事化 N → 抑郁谱、现在感 R → 焦虑谱）
        其余候选 = 卫星病（聚合达标才成型）
  ↓ 资格门（§3.2.2，2026-09-03 #113 新增）
疾病候选逐病检查 Eligibility(d) ∈ {ELIGIBLE, INELIGIBLE, UNDETERMINED}
        仅 ELIGIBLE 进入后续聚合；INELIGIBLE 直接出局（不进主病选择/聚合/档位）
  ↓ 聚合（仅在 ELIGIBLE 候选上）
疾病层：D_j 负荷 = Σ {L(Rᵢ) : D_j ∈ C(Rᵢ)} + I_max 加成
        D_j 档位 = f(聚合负荷)（沿用 §3.3 双维模型，输入变为聚合量）
  ↓
共病：多个 D_j 各自聚合达标 → 同时存在（N→1 + 1→N + N→N 全覆盖）
```

- 映射范围 = **全 25 经历型**（26 − ASD 发育性；#87-D3"18 种"为扩种前数字，Q0.2 扩种后更新）
- 事件类型枚举 = **开放集合**（同烈度 6 特征惯例，#87-D6），存独立数据文件；**增 = 默认未映射态（WARNING）+ 兜底"慢性冲突/高压"**，**删 = ERROR 护栏**（#86 S2+ 演化策略同款）。**兜底来源标注（2026-09-01 第八份评审）**：fallback 是生成策略非模块状态——input_source ∈ {canonical, fallback}；兜底「慢性冲突/高压」仅限开发/演示模式（input_source = fallback），正式生成输入缺失/非法 → FAIL
- 候选集映射表 C(e) = **[NEW] 待逐事件类型填充**（8 初始类型，见下节）

### 3.2.1 事件类型 → 候选疾病集（✅ 定案 2026-08-21，24 经历型全覆盖）

> **分类调整（2026-08-21 转化接口讨论）**：ADHD 移出经历型 → 发育性（遗传度 ~74%，Faraone & Larsson 2019，与 ASD 同性质，不参与创伤转化，走 W_npc 直调）。经历型 = 26 − ASD − ADHD = **24 种**。
>
> **立场 B（2026-09-01 修正：创伤 = 唯一触发路径）**：创伤记忆 → 疾病是**总路径**——没有创伤记忆就不发病。创伤来源不限于家庭（§3.2.1 十类事件环境无关：学校/职场/部队/社区等均为合法发生场所）。原"应激触发型"（双相/SZ 谱等）的"无创伤来源"语义废除：高遗传度病的患者仍有创伤来源——家族聚集者常可追溯到家庭环境（出生在患者家庭本身 = 目睹发病/照料者不稳定/被忽视 = 忽视/遗弃事件类型），但**不排除其他固定生活环境来源**。原「素质-应激兜底（遗传素质 × 慢性应激，低概率自发）」**废弃**——个体差异以 β 个体易感性接口形式进入（§3.1），非独立致病路径（2026-09-01 世界观裁决 + 修正，依据 Tienari 2004 环境可调节易感性表达）。
>
> **卫星病机制**：主病（N/F/R 选择）正常成型；卫星病需**独立聚合阈值 ≥ 1.5**（防 MDD 泛滥，临床"多创伤→更重抑郁"由聚合自然表达）。

| 事件类型 | 候选集 C(e)（主病 + 卫星） | 临床锚 |
|---------|--------------------------|--------|
| 威胁/暴力 | {PTSD 主, 惊恐, 特定恐惧, **偏执型 SZ 卫**} | 急性威胁 RDoC；SZ 创伤路径 Varese 2012（总体 OR 2.78, 95% CI 2.34-3.31；🔧 2026-09-06 勘误：原引 2.87 为性虐待亚组 CI 上界，性虐待 OR=2.38） |
| 丧失/哀悼 | {MDD 主, PDD, BD-I, BD-II, 环性} | 丧失 RDoC；双相谱全覆盖（轻躁狂代偿） |
| 性创伤 | {PTSD 主, DID, BPD, BN 卫, AN 卫, BED 卫} | 高烈度跨域；进食障碍后遗症（暴食谱 BN/BED 共享） |
| 社会伤害（霸凌/排斥/羞辱） | {BPD 主, 社交焦虑, 分裂型, BN 卫, BED 卫, **未分化 SZ 卫**} | 社会过程 RDoC；SZ 创伤路径 |
| 忽视/遗弃 | {BPD 主, MDD, ASPD, **分裂情感 卫**} | 依恋损伤；早期剥夺→情感钝化 |
| 生理/疾病（重病/手术/疼痛） | {躯体症状 主, 惊恐, MDD} | 内感受 RDoC |
| 经济/剥夺 | {SUD 主, MDD, 拖延, **环性 卫**} | 慢性应激 |
| 慢性冲突/高压 | {GAD 主, MDD, OCD, SUD, **偏执型 SZ 卫**} | 慢性应激 + 未映射兜底 |
| （新增）控制剥夺/完美主义压迫 | {AN 主, OCD} | 控制主题（AN 主——进食控制；OCD 共享——对称/秩序/incompleteness，Summerfeldt 2004；🔧 2026-09-06 注记修正：原"进食障碍特异"未含 OCD 候选） |
| （新增）公开羞辱/失败 | {社交焦虑 主, BN, BED, 未分化 SZ} | 评价创伤；暴食谱共享 |

**覆盖验证**：24 经历型全部 ≥1 事件类型可达；MDD 作为共同终点（5 事件类型）是临床事实（Kendler 2011 应激-抑郁模型），由卫星阈值 ≥1.5 管控。

> **环境语义注记（2026-09-01 本体纠偏）**：事件类型层**环境无关**保持不变；事件生成源 = Event Generator 人生叙事线输出的环境序列（暴露量 T 只调事件生成机会）。环境存在性不由时长/频率/事件数量阈值决定（无 T_min/资格判定），塑造结果由个体化机制 β/k/g 决定——本表的事件类型与候选集映射不承担环境资格职责。

### 3.2.2 资格层 Eligibility(d)（✅ 定案 2026-09-03 Grilling #113：创伤负荷 ≠ 疾病资格）

> **定位**：修复 `L_agg(d) ⇏ Eligibility(d)` 结构缺陷。三个反例（#89 顾维扬草稿外部评审 t6a96e985/t6a96ecd6）：丧失聚合 → BD-II（L_agg=1.085，无轻躁狂史）、事件负荷 → 环性（1.575，无周期性）、经济剥夺 → SUD 幽灵候选（0.84，无物质使用史）。资格层 = 候选召回之后、主病选择之前的**硬门**——疾病候选必须先过资格关才进入竞争与聚合。这是变量语义修复，非参数校准。

**链位置**（不可交换）：

```
C(Rᵢ) 召回（§3.2.1）
   ↓ [资格门]
Eligibility(d) ∈ {ELIGIBLE, INELIGIBLE, UNDETERMINED}
   ↓ 仅 ELIGIBLE 进入
主病选择（§3.2.3，在过滤后的候选集上）→ 聚合 L_agg（§3.3）→ Severity
```

- **Eligibility(d) ⊥ L_agg(d)**：Eligibility 判"有没有资格成为 d"（临床史/表征事实），L_agg 判"已经是 d 时负荷多大"（严重度）。两者不互读、不互相修改——否则资格门退化成另一个 severity score。
- **ELIGIBLE ≠ 已诊断**：ELIGIBLE 只表示"必要资格条件满足且排除条件未触发"（准入），不保证档位成立；充分性由 L_agg 档位补足。**Eligibility = 必要条件的机械检查，Severity = 充分性的量化**，两者永不合流（防资格门变成完整诊断器）。

**证据域**：`E_d = E_d^mem ∪ E_d^hist`

| 子域 | 内容 | 来源 |
|------|------|------|
| E_d^mem（记忆内） | 表征域派生证据（如 DID→D_seg、PTSD→F） | 记忆记录（#90 生命周期） |
| E_d^hist（记忆外） | 临床史/行为史证据原子（躁狂史/物质使用史/…） | **#87 A′-Generator 规范化声明字段**（转化接口不解析叙事） |

**全局不变量 G1-G4**（所有资格原子通用）：
- **G1 原子语义 ≠ 原子成立依据**：Eligibility 只消费 #87 已规范化声明；DSM/ICD 是生成侧形成声明的依据，不继续向资格门展开。
- **G2 DSM/ICD = 资格语义锚**（独立证据层），≠ Eligibility 输入清单。病因关联文献不得单独证明资格必要性（`创伤X与d有统计关联 ≠ d必然具有临床事实P ≠ P是d的必要资格条件`）。
- **G3 暂不拆分 ≠ 无需拆分**：工程范围决定不构成医学结论（如 SUD 物质类别拆分）。
- **G4 逻辑地位 ≠ 临床存在性**："X 在 d 中是必要正向"描述 `d⟹X`，不等于"只有 d 才可能出现 X"。

**证据原子三值域**：`X_e ∈ {1（有规范化证据支持）, 0（明确否定）, MISSING（无足够资料判定）}`；**MISSING ≠ FALSE**。`input_source ∈ {canonical, fallback}`（§3.2.1 兜底先例）只负责缺失输入的工程处置（正式→FAIL，演示→fallback），**不得把 MISSING 改造成医学 TRUE/FALSE**（fallback ≠ 医学证据）。

**资格状态三值**：`EligibilityStatus ∈ {ELIGIBLE, INELIGIBLE, UNDETERMINED}`；**UNDETERMINED ≠ INELIGIBLE**（输入不足以执行判定，非第三种资格）。

**组合规则**（N 必要正向 P_i + M 排除条件 N_j，三值语义）：

| 条件状态 | 结果 |
|---------|------|
| ∃P_i = 0 | **INELIGIBLE**（明确反证一票否决） |
| ∃N_j = 1 | **INELIGIBLE**（排除触发一票否决） |
| ∃P_i = MISSING | **UNDETERMINED** |
| ∃N_j = MISSING | **UNDETERMINED** |
| ∀P_i = 1 ∧ ∀N_j = 0 | **ELIGIBLE** |

> 性质：任何明确反证都关闭候选；任何无法确认的必要事实都不能放行候选——同时避免误杀（缺失=假）与空转（缺失=忽略）。

**归位原则**（逐病核验协议五步：①DSM/ICD 标准定位 ②检验 `d⟹X`（X 是否必要，方向不可交换）③检验 `X⟹d`（是否充分）④原子间组合关系 ⑤原子级归位表 + 文献锚）。必要/排除形式定义：
- `P_i 是 d 的必要条件 ⟺ d ⟹ P_i`（疾病级权威依据）
- `N_j 是 d 的排除条件 ⟺ N_j ⟹ ¬d`

### 3.3 Step 3：档位映射（双维模型，聚合输入）

> **前置条件（2026-09-03 #113）**：仅对 `Eligibility(d) = ELIGIBLE` 的候选计算 L_agg 与档位；`Eligibility = 0`（INELIGIBLE）的候选不参与聚合，`UNDETERMINED` 的候选由 input_source 处置（§3.2.2）。`L_agg` 不得充当任何资格证据原子（§3.2.2 禁止项）。

```
D_j 档位 = clamp( g(L_agg) + h(I_max_agg), ∅, 重 )
  L_agg = Σ {L(Rᵢ) : D_j ∈ C(Rᵢ)}      （指向该病的全部记忆聚合负荷）
  I_max_agg = max {I_max(Rᵢ) : D_j ∈ C(Rᵢ)}  （指向该病的最高单次烈度）
  g(L_agg)：L_agg < 1.0 → ∅；1.0 ≤ L_agg < 2.0 → 轻；2.0 ≤ L_agg < 3.5 → 中；L_agg ≥ 3.5 → 重
  h(I_max_agg)：I_max_agg ≥ 0.9 → +1 档（单次毁灭直跳重档）
  B′ 过滤：档位落在该病可用档内（DID 无轻档→实际 m 第一档 0.0 占位）
```

### 3.4 Step 4：实例化

```
档位切换时 m 跳变（演变 = 档位状态切换，非 m 连续变化；保持 :1042 m 固定值决策）
```

## 五、演变：档位状态机

```
s(t) ∈ {∅, 轻, 中, 重}
  升档：L 增长跨阈值（新创伤事件 ΔI 累积）→ s 升
        I_max 更新（更强事件）→ 急性 +1
  降档：治疗/干预 → #90 ΔI_int < 0（再巩固改写负向）→ L 下降 → s 降
        （P_acc 衰减不降档——铁律：遗忘不作用于 m，创伤记忆不随时间衰减）
        **恢复 ≠ 遗忘（2026-09-01 明确）**：ΔL_recovery 仅由 #90 治疗性改写 ΔI_int < 0 提供（恢复期机制）；P_acc 衰减不是恢复——遗忘不降档
  特殊：#90 RESET（DID 区隔/Boss 击败清零）→ s = ∅ 或换病
```

档位迁移由 `L(t)`/`I_max(t)` 实时驱动（#90 生命周期更新这些量），转化函数 f 不变。
