## 一、定位与边界

**转化接口回答**：创伤记忆的连续量（L 总负荷、I_max 单次烈度）如何映射为疾病的离散档位（轻/中/重）与病理边 m 偏移。

```
创伤事件 e_i（连续）          ← #87 生成功能产出
  ↓ ΔI = k × A
创伤记忆 R（连续：I_mem, L）   ← #90 存储（I_mem ∈ [0,1] 是强度非档位）
  ↓ f(L, I_max)              ← 本文档定义（转化函数）
疾病档位 s ∈ {∅,轻,中,重}（离散）← 疾病层才有档位
  ↓ 实例化 + B′ 过滤
m = m_offset[s]（病理边模板值）
```

**边界**：
- 创伤记忆**没有档位**——I_mem 是连续强度、L 是连续负荷；"轻中重"只存在于疾病层
- 本接口不定义疾病内容（26 病 + 348 病理边已完成，`pathology_edges.json`）
- 本接口不定义记忆存储/检索（#90 已定义）

**致病立场（Q1a-2，C 定案）**：创伤 = 累积到阈值。无创伤 + 无器质 + 非发育 → 健康（正常人模板 m 基线 0.3-0.5）。未达单次阈值的重复挫折经剂量-反应累积（L = ΣΔI×g）突破阈值 → 创伤记忆。不引入素质/遗传维度。

## 二、输入：创伤记忆载体

| 符号 | 定义 | 值域 | 来源 |
|------|------|------|------|
| A | 事件烈度 | ∈ [0,1]（6 特征：侵入性/现在感/碎片化/生动性/生理反应/牢固度，开放集合） | #87-D6 |
| k | 强度系数 | > 0（基准 1.0，人物脆弱性调制 [NEW] 后置） | #88 输入约定 |
| g | **不成熟度** | ∈ [0,1]（成熟者 g→0，不成熟者 g→1） | #88 定案（g = 不成熟度，公式零改动） |
| ΔI | 单次事件强度增量 | = k × A | #90 §3.1 |
| L | 总负荷 | ≥ 0 无上界，= Σ ΔI_i × g（剂量-反应，Kolassa 2010） | #90 §3.2 |
| I_mem | 记录强度 | ∈ [0,1]（单条记忆载荷字段） | #87-D6 |
| I_max | 历史最高单次 ΔI | ∈ [0,1]（记忆存储层） | #88 新增（急性维度） |
| N/F/R | 表征形态 | 叙事化/碎片化/现在感 | #87-D6 |

## 三、转化链三步

### 3.1 Step 1：病理化判定（双阈值）

```
病理化 ⟺ (I_max ≥ A_trauma_I) ∨ (L ≥ A_trauma_L)
  单次毁灭性事件（I_max 高）或 长期累积（L 高），任一达标即病理化
  否则 → s = ∅（非病理化：创伤记忆作为叙事/记忆存在，不致病）
```

### 3.2 Step 2：疾病选择

- **事件类型**（事件快照：丧失/威胁/社会伤害…）→ 选父类
- **表征形态 N/F/R** → 选子类（叙事化→抑郁谱、碎片化→PTSD/解离、现在感→焦虑谱）
- 映射范围 = **全 18 经历型**（与 #87-D3"经历型 = 创伤记忆共性范围"一致；MDD/SZ 等补文献锚）
- 事件类型枚举 + 父类/子类映射表 = **[NEW] 待逐病填充**（本 issue 定义结构，内容批次填表）

### 3.3 Step 3：档位映射（双维模型）

```
s = clamp( g(L) + h(I_max), ∅, 重 )
  g(L) = 基础档：L < 1.0 → ∅；1.0 ≤ L < 2.0 → 轻；2.0 ≤ L < 3.5 → 中；L ≥ 3.5 → 重
  h(I_max) = 急性加成：I_max ≥ 0.9 → +1 档（单次毁灭直跳重档）
  B′ 过滤：档位落在该病可用档内（DID 无轻档→实际 m 第一档 0.0 占位）
```

### 3.4 Step 4：实例化

```
m = 疾病模板 m_offset[s]    （pathology_edges.json 每边三档值，s 索引）
档位切换时 m 跳变（演变 = 档位状态切换，非 m 连续变化；保持 :1042 m 固定值决策）
```

## 五、演变：档位状态机

```
s(t) ∈ {∅, 轻, 中, 重}
  升档：L 增长跨阈值（新创伤事件 ΔI 累积）→ s 升
        I_max 更新（更强事件）→ 急性 +1
  降档：治疗/干预 → #90 ΔI_int < 0（再巩固改写负向）→ L 下降 → s 降
        （P_acc 衰减不降档——铁律：遗忘不作用于 m，创伤记忆不随时间衰减）
  特殊：#90 RESET（DID 区隔/Boss 击败清零）→ s = ∅ 或换病
```

档位迁移由 `L(t)`/`I_max(t)` 实时驱动（#90 生命周期更新这些量），转化函数 f 不变。
