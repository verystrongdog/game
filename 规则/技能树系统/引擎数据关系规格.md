## 二、核心数据流图

> 三层因果链（运行时状态模型 §一）：**脑干 tone → 皮层 a(t) → CSTC gate**。每层只依赖前一层。ASCII 图 = 引擎实际调用链（TurnManager 五阶段管线，`Flow/TurnManager.cs`）。

```
┌────────────────────────────── 数据文件（5 JSON，source of truth）──────────────────────────────┐
│ brain_regions.json(69 fid)  tripartite_model.json(51节点+1049边)  W_sensory.json(69×6)           │
│ situation_primitives.json(27)  signal_types.json(4×18词表)                                       │
└───────────────┬─────────────────────────────────────────────────────────────────────────────────┘
                │ GameDataLoader.LoadAll(dataDir) → GameData（5 record 聚合）
                ▼
        ┌─── GameData（只读上下文成员）───────────────────────────────────────────────────────────┐
        │  WMatrixBuilder.Build(GameData) → WMatrix(W[69,69]行归一化, τ[69]四档, RowFids[69]=RegionIds)│
        │    消费: tripartite.corticocortical∪privileged_pathways(排除清单后735) → w=edr×m_mean×focus │
        │          brain_regions.function_profile.timescale → τ（fast0.01/med0.05/slow0.15, mirror继承）│
        │          CalibrationConfig.MDefault=0.3（demo m_mean）；行=接收者=W_sensory.RegionIds 序      │
        └──────────────────────────────────────────────────────────────────────────────────────────┘
                                    │
        ┌───────────────────────────▼─────────────────────────────────────────────────────────────┐
        │ Phase 1 情境更新（每回合，TurnManager 步骤 1-5）                                          │
        │                                                                                          │
        │  ① tone' = ToneUpdater.Step(tone, δ=Σevents, cal)          ← δ_event 实时注入（Phase 4） │
        │    解析解: clip(baseline+δ_eff+(tone−baseline−δ_eff)·e^(−Δ/τ), 0, 1)；δ_eff=δ×0.3       │
        │  ② b_j  = CorticalBias.Compute(tone, GameData) → float[69]  ← brainstem.role 权重        │
        │    b_j = Σ_tone×w(j)；w: active=1.0/modulating=0.5（114 投射）；clip[0,2]                 │
        │  ③ a'   = WcDynamics.Step(a, b, s_pending, WMatrix) → WcState(69)                        │
        │    解析解: a'=σ(h)+(a−σ(h))·e^(−Δ/τ)，h=W·a+b+s；同步更新；排除节点 h=b+s                 │
        │  ④ c_loop = CstcGating 内 mean(a[ci])（3 环路 × CI fid 集）                              │
        │    DA_loop 按环路混合（limbic 0.8VTA+0.2SNc / cog 0.4+0.6 / som 0.2+0.8）                │
        │  ⑤ GurneyState' = CstcGating.Step(a, tone, prev) → gate = 1−O_GPi（3 环路）              │
        └───────────────────────────┬─────────────────────────────────────────────────────────────┘
                                    │ a(t) + gate + tone
        ┌───────────────────────────▼─────────────────────────────────────────────────────────────┐
        │ Phase 3 速度重算（SpeedScoreCalculator + TurnOrderBuilder）                               │
        │  察觉 = mean(a[4察觉节点]，逐节点<0.15回落静息值)                                          │
        │  决断 = mean(c_loop, 3环路)；执行 = mean(a[Precentral], a_SD1_somatic) + M1惩罚(−0.1)    │
        │  speed = 1/3×察觉 + 1/3×决断 + 1/3×执行 → 排序 + 同速掷硬币                              │
        └───────────────────────────┬─────────────────────────────────────────────────────────────┘
                                    │ order
        ┌───────────────────────────▼─────────────────────────────────────────────────────────────┐
        │ Phase 4 按序执行（ActionResolver + DamageCalculator + EventProcessor）                   │
        │  物理: (base+weapon)×(1+clamp(force,0,0.5)+clamp(motivation,−1,1))×gate×防御；命中<0.75 │
        │  精神: round1(max(1.0, round1(base×(1+mot)−忍耐))×gate×穿透)；HP=floor1(san×0.5)        │
        │  → CombatEvent（Physical/Mental/Status/Heal/LinkGrowth 5 类）                            │
        │  → EventProcessor: δ=pattern×m（实时注入 tone）+ s=W_sensory×α（打包下一 Phase 1）       │
        └──────────────────────────────────────────────────────────────────────────────────────────┘
```

**数据流三阶段**（对应你的原始目标三要素）：

| 阶段 | 解剖数据（Data） | 物理背景（Types+Engine） | 战斗逻辑（Engine+Flow） |
|------|-----------------|--------------------------|------------------------|
| 静态 → 动态 | JSON → record → WMatrix/τ | WC 方程（W·a+b+s）→ a(t) | a(t) → 速度排序（察觉/决断/执行） |
| 全局调制 | brainstem 114 投射 → role 权重 | tone → b_j → WC 输入 | tone_bias → motivation_mod → 伤害 |
| 门控 → 结算 | function_profile cstc_role/cstc_loop → CI 集 | c_loop → Gurney → gate | gate_bonus → 技能/行动效果 × |

## 五、关键依赖链

> 模块间显式依赖（构造/调用关系，非正典引用）。依赖方向 = 数据流方向。

```
Console → Flow → Engine → Types → Data
  │          │        │
  │          │        └─ WMatrixBuilder → Data（GameData）
  │          └─ CombatState（Entity）持有 Types 状态 + SPending
  │
  TurnManager 构造依赖（TurnManager.cs:42-55）：
    ActionResolver(data, cal) → DamageCalculator(cal) → Types(CalibrationConfig)
    EventProcessor(wsensory, cal) → Types(WsensoryMatrix, CalibrationConfig)
    SpeedScoreCalculator(data, cal) → Types(CalibrationConfig)
    CstcGating(data) → Types(CstcLoop/CstcRole) + Data(function_profile)
    WMatrixBuilder.Build(data) → Types(WMatrix)
```

**确定性契约**（plan §二）：L2 全部 static 纯函数；RNG 仅经 `IRng`（CombatContext 注入）——`DeterministicRng`（splitmix64，同种子同序列）；GameData 以参数传入；无 static 可变状态。同种子同输入 → 逐位同输出（SmokeTests AC-8 实证）。
