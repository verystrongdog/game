# 皮层动力学 — 通用层

> 定义三体神经模型中皮层-皮层通信原语的运行时动力学。每个 functional_id 节点运行 Wilson-Cowan (1972) 神经群体方程，构成战斗系统的"计算引擎"——感知、记忆、认知控制的信息处理层。CSTC 门控和脑干广播分别在后续文档中定义，按因果链顺序：皮层动力学 → 脑干调制 → CSTC 门控。
>
> **维度: 规则** — 运行时状态模型 #32 的第一个子层。

## 一、设计原则

1. **节点动力学，非链路动力学**：激活变量 `a(t)` 附着在 69 个 functional_id 上（神经群体），不是 364 条链路上。这符合 Wilson & Cowan (1972) 的建模对象——群体发放率。
2. **通用方程，差异化参数**：所有 69 个节点共享同一个 WC 方程形式，差异仅来自 τ（timescale）和 W（连接权重）。
3. **髓鞘化进入权重，不进入激活**：m（髓鞘化）决定连接权重 W，间接影响激活传播效率，而非直接乘出激活值。
4. **情境通过网络涌现，不通过查表**：外部输入 s(t) 激活关键节点 → 网络通过 W 传播激活 → 相关区域自动响应。不再逐链路查"情境相关性"。
5. **数据锚定**：所有参数从已有数据文件派生，不引入新数据文件。

## 二、从链路级到节点级

### 2.1 旧模型（已废弃）

```
激活水平(link_i) = m_i × rel_i × focus_i
```

- 变量层级：每链路一个值（364 个）
- 时间特性：瞬时（无动力学，三个乘数瞬间给出激活值）
- 网络效应：无（链路之间独立计算，不互相影响）
- 数据字段：m/rel/focus 均不存储在链路数据中，运行时从三个独立来源取值

### 2.2 新模型

```
τ_j · da_j/dt = −a_j + σ( Σ_k W_jk · a_k  +  b_j(t) + s_j(t) )
```

- 变量层级：每 functional_id 一个值（69 个）
- 时间特性：一阶动力学，激活需要时间建立和衰减
- 网络效应：激活通过 W 在节点间传播，产生级联和稳态模式
- 数据锚定：τ 来自 function_profile.timescale，W 来自皮层-皮层连接的 EDR 概率 × m

### 2.3 为什么迁移

| 维度 | 旧模型（链路级乘法） | 新模型（节点级 WC） |
|------|-------------------|-------------------|
| 时间惯性 | 无——激活瞬间跳变 | τ 控制建立/衰减速度 |
| 网络传播 | 无——链路独立计算 | W 矩阵驱动节点间传播 |
| 饱和 | 无——线性乘法 | sigmoid 非线性 |
| 文献支撑 | 无——游戏设计发明 | Wilson & Cowan (1972), Breakspear (2017) |
| 与三体模型对齐 | 否——364 链路已废弃（#26） | 是——776 CC 连接直接用作 W |

## 三、通用变量 a(t)

### 3.1 定义

```
a_j(t) ∈ [0, 1]  — functional_id j 在时刻 t 的神经群体激活比例
```

| 值 | 含义 |
|----|------|
| 0 | 群体完全沉默 |
| 0.05–0.15 | tonic 基线（静息状态自发活动） |
| 0.5 | 中等激活——参与当前处理 |
| 1.0 | 饱和发放——最大信息输出 |

### 3.2 变量数量

69 个 functional_id × 1 个 a 值 = **69 个状态变量**。

11 个无 dk_name 的 functional_id（脑干核团/皮层下结构）同样参与 WC 动力学——它们接收皮层-皮层输入的方式不同（通过脑干广播/特权通路），但通用方程形式相同。

### 3.3 存储与更新

- **存储**：`state.a[functional_id]` — 浮点数，每 functional_id 一个
- **更新频率**：每回合 Phase 1（情境更新）时步进。不是实时连续积分——用离散时间步长 Δt
- **步长**：Δ = 1 回合（~1-2 秒游戏时间）。在离散形式下：

```
a(t+Δ) = a(t) + (Δ/τ) · [ −a(t) + σ(input(t)) ]
```

- fast 节点（τ≈0.01s）：Δ/τ ≈ 100 → 几乎瞬间收敛到稳态
- slow 节点（τ≈0.15s）：Δ/τ ≈ 8–15 → 跨回合平滑过渡

### 3.4 初始化

战斗开始时，所有 a_j 初始化为 tonic 基线值：

```
a_j(0) = 0.10  （默认静息基线）
```

受角色 7 参数化性格偏移的节点可以有非默认初始值（后续在脑干调制层定义）。

## 四、Wilson-Cowan 动力学

### 4.1 通用方程（简化形式）

对每个 functional_id j：

```
τ_j · da_j/dt = −a_j + σ( h_j(t) )
```

其中：

| 符号 | 含义 | 来源 |
|------|------|------|
| τ_j | 时间常数（秒） | function_profile.timescale → 查表映射 |
| a_j | 群体激活比例 [0,1] | 状态变量 |
| h_j(t) | 总输入 = Σ_k W_jk·a_k + b_j(t) + s_j(t) | 见 §五、§六 |
| σ(x) | sigmoid 响应函数 | Wilson & Cowan (1972) |

### 4.2 Sigmoid 响应函数

```
σ(x) = 1 / (1 + exp(−v · (x − θ)))
```

| 参数 | 符号 | 默认值 | 含义 |
|------|------|--------|------|
| 增益/陡度 | v | 1.0 | 越高 → 越接近阶跃函数 |
| 阈值 | θ | 0.5 | 半激活点——输入达到 θ 时输出 0.5 |

**与 WC 原文的关系**：WC 原文使用 `S(x) = 1/(1+exp(−v·(x−θ))) − 1/(1+exp(v·θ))`，减去偏移量使 S(0)=0。我们的简化版去掉偏移——允许 0 输入时输出非零（σ(0) ≈ 0.006），等价于 tonic 基线由 `a(0)` 显式设定而非由 sigmoid 零点隐式设定。这在数值上更直观。

### 4.3 离散更新形式

回合制战斗不需要连续积分。每回合 Phase 1 执行一步更新：

```
IF Δ/τ_j ≥ 50:  a_j ← σ(h_j)           — fast 节点直接跳到稳态（解析解）
ELSE:           a_j ← clip( a_j + (Δ/τ_j) · (−a_j + σ(h_j)),  0, 1 )
```

其中 Δ = 回合时长（默认 1.0 秒），h_j 为上回合末计算的总输入。`clip(x, 0, 1)` = max(0, min(1, x))。

**为什么 fast 节点用解析解**：τ_fast=0.01, Δ/τ=100。Euler 步 `a + 100·(−a + σ(h))` 对 σ(h)=0.99, a=0.1 → 0.1+100·0.89=89.1，溢出 [0,1] 三个数量级。解析解 a←σ(h) 等价于连续方程在 t→∞ 的稳态，既准确又稳定。

**medium 节点（τ=0.05, Δ/τ=20）**：Euler + clamp 安全。Δ/τ=20, σ(h)=0.99, a=0.1 → 0.1+20·0.89=17.9 → clip→1.0。虽然也触 clamp，但方向正确——medium 节点在高输入时一回合也能接近稳态。

**slow 节点（τ=0.15, Δ/τ≈7）**：Euler + clamp 安全，跨回合平滑过渡，保留历史。

### 4.4 τ 映射表

| timescale（function_profile） | τ（秒） | Δ/τ（Δ=1s） | 典型节点 |
|------|------|------|------|
| fast | 0.01 | 100 | L0-L2 脑干/边缘系统（Amygdala, PAG, LC） |
| medium | 0.05 | 20 | L3-L4 感觉/单模态皮层（V1, A1, 纹外皮层） |
| slow | 0.15 | ~7 | L5 跨模态皮层（dlPFC, mPFC, Broca） |
| 未知 | 0.05（默认） | 20 | 2 个未标注的 functional_id |

τ 值锚定来源：WC 原文 μ=10ms（单群体膜时间常数）。我们使用有效的"群体时间常数"——比单神经元膜时间常数更长，反映群体级建立时间。Song et al. (2024) 的 timescale 分类（fast/medium/slow）提供层级梯度方向。

## 五、连接权重矩阵 W

### 5.1 矩阵形状

皮层-皮层连接存在于 **40 个 dk_name** 之间（776 条双向边）。但动力学在 **69 个 functional_id** 上运行。需要 dk_name → functional_id 的映射。

**有效节点分界**：CSTC 环路节点（cstc_role ∈ {pallidal_output, thalamic_relay, striatal_gate} 或 cstc_loop=global 的 STN）**不参与皮层-皮层 W 矩阵**。它们在运行时由 CSTC Gurney 层独占驱动——同一段解剖连接不在两套数学框架中重复建模。W 矩阵活跃节点 = **48 个 functional_id**：44 个皮层节点 + Amygdala + Hippocampus×2 + Cerebellum-Cortex（category=subcortical 但参与 CC——操作性分界以 [运行时状态模型 §4.2](运行时状态模型.md) 排除清单为准：CSTC 6 dk + 脑干，共 16 dk / 21 fids。2026-08-13 修正，原「仅 category=cortical」措辞有误）。

**排除清单**：Pallidum, Thalamus-Proper, Putamen, Caudate, Accumbens-area, SubthalamicNucleus

**策略**：同一 dk_name 下的多个 functional_id 共享相同的输入权重模式。

```
W[fid_A][fid_B] = w( dk(fid_A), dk(fid_B) )
```

其中 `dk(fid)` 是 functional_id 对应的 dk_name。若 fid 的 dk_name 在排除清单中或为 None（脑干核团），其皮层-皮层输入权重为 0——这些节点通过 CSTC Gurney 或脑干广播驱动（后续文档定义），不参与皮层-皮层 W 矩阵。被排除节点的 a(t) 也不作为 W·a 的输入（列=0且行=0）。

### 5.2 权重计算

对每对皮层 dk_name (A, B)：

```
w(A, B) = edr_probability(A→B) × m_mean(A→B) × focus_multiplier(A→B)
```

| 因子 | 含义 | 取值范围 | 来源 |
|------|------|---------|------|
| edr_probability | 解剖连接概率 | [0.10, 0.85] | `tripartite_model.json` corticocortical.edr_probability |
| m_mean | 该连接涉及链路的平均髓鞘化 | [0, 1] | 从 link_registry 推导——连接 A→B 对应的链路集合的 m 均值 |
| focus_multiplier | 聚焦倍率 | 1.0 或 2.0 | 玩家构建层聚焦配置——若该连接对应的链路组被聚焦则 ×2 |

**连接不存在时**：若 dk_name A 和 B 之间没有皮层-皮层连接（不在 776 条中），`w(A,B) = 0`。

**自连接**：`w(A, A) = 0`——节点不自兴奋（自兴奋由 sigmoid 和网络回路间接产生）。

### 5.3 m_mean 的推导

**m 值的运行时来源**：每条链路一个 `m ∈ [0, 1]`，存储于 `combat_state.link_states[link_id].m`（角色构建状态，由髓鞘化增长公式 `核心机制.md` §2.3 驱动，使用即增长，不衰退）。构建层慢变量——战斗中 m 不变（仅战后可塑性巩固更新），但不同战斗之间 m 可以不同。

一条皮层-皮层连接 A→B 对应旧链路注册表中的 0 条或多条链路。映射方式：

1. 旧链路 `link_registry.json` 中 `source_dk_name=A AND target_dk_name=B` 的链路
2. 若存在多条 → `m_mean = mean(combat_state.link_states[link_id].m for link_id in links_A→B)`
3. 若不存在（即此连接来自 tripartite 构建脚本的 EDR 筛选，不在旧 364 链路中）→ `m_mean = 0.3`（默认未髓鞘化基线）
4. 若 A 或 B 在 link_registry 中无对应（CC 独有的 5 个节点：isthmuscingulate, bankssts, cuneus, transversetemporal, lingual；Pallidum 原在此清单，2026-08-13 移除——CSTC 排除节点与 link_registry 对应关系无关）→ `m_mean = 0.3`（默认基线）

> **✅ 已解决（运行时状态模型 §4.2）**：Pallidum 及其他 CSTC 专有节点（Thalamus-Proper, Putamen, Caudate, Accumbens-area, SubthalamicNucleus）已从 CC 的 W 矩阵中排除。皮层-皮层 W 包含 **35 个 dk_name**（51 节点 − 16 排除，48 fids——含 Amygdala/Hippocampus/Cerebellum-Cortex 三个 subcortical dk；2026-08-13 修正，原「~34（皮层节点）」有误），排除规则见 [运行时状态模型 §4.2](运行时状态模型.md#42-排除-cstc-专有节点)。demo 阶段 m_mean ≡ m_default = 0.3（无 LinkState——csharp-wmatrix spec B4）。

### 5.4 权重归一化

每行 W 做 softmax 或简单归一化（除以行和），确保每个节点的总输入在合理范围内：

```
W_normalized[j][k] = W[j][k] / (Σ_i W[j][i] + ε)
```

ε = 0.01 防止除零。

### 5.5 特权通路

`privileged_pathways.json`（112 条）中的连接绕过 `|Δlevel| ≤ 1` 约束但仍走 EDR。它们**同样进入 W 矩阵**，与其他皮层-皮层连接无异。它们的特殊性在于解剖上跨层（如 EC→HC Δ=3），在运行时动力学中没有特殊处理——权重由同样的公式计算。

## 六、外部输入 s(t)

> 事件空间定义由 Grilling #34 确立（2026-08-09）。s(t) 通过 W_sensory 69×6 矩阵从感官模态 α 展开，完整规格见 [运行时状态模型 §4.5](运行时状态模型.md#45-外部输入-st)。本节保留接口概念的叙述性说明。

### 6.1 定义

```
s = W_sensory × α
W_sensory ∈ {0, 1}^{69×6}  — 感官模态→皮层节点解剖映射矩阵
α ∈ [0, 1]⁶                — 事件感官模态强度向量
```

外部输入代表"从神经系统外部来的"信号——感官输入、战斗事件、任务目标。与皮层-皮层输入（W·a）和脑干调制（b）分开。

数据文件：`data/connectivity/W_sensory.json`（已构建，2026-08-09）。

### 6.2 感官模态 M = 6

| 模态 | 锚定 | 拆分依据 |
|------|------|---------|
| 视觉 | 看到攻击/倒下 | 与听觉不同节点域 |
| 听觉 | 听到声音/倒地 | 与视觉不同节点域 |
| 躯体感觉 | 被击中体感/防御本体感觉 | 与痛觉可分——防御成功有体感无痛 |
| 痛觉 | 被击中痛感/内感受/SAN恐慌 | Eisenberger (2003)——社会痛共享物理痛底物 |
| 社会认知 | 读意图/精神攻击社会压力/队友倒下 | 独立节点域（STS/mPFC/颞极） |
| 语言认知 | 精神攻击语言内容/命名 | Broca ≠ STS——未来可能纯语言事件 |

拆分标准：**存在至少一种事件需要激活其一而不激活其二 → 拆。**

### 6.3 事件→s(t) 映射流程

1. 战斗事件携带感官模态强度向量 α（14 事件类型 × 6 模态 pattern，见运行时状态模型 §4.5 α pattern 表）
2. `s = W_sensory × α` 将模态激活展开为 69 维皮层节点驱动
3. s(t) 打包到下一回合 Phase 1 注入 WC 方程（皮层加工延迟 200ms+，打包延迟合理）

### 6.4 与旧接口的差异

旧接口（本文档创建时的占位设计）：
```
s_j(t) = Σ_event  event.impact_strength × event.node_affinity(j)  ← 已废弃
```

新接口（Grilling #34 闭合）：
```
s = W_sensory × α  ← 当前正典
```

旧接口需要手工维护 69×N 的 event→node_affinity 映射表。新接口将"事件→节点"映射拆为两步——事件→模态（α pattern，14×6 小表）+ 模态→节点（W_sensory，69×6 解剖固定矩阵）——消除了手工维护负担。

### 6.5 默认值

无事件回合：`α = 0` → `s_j(t) = 0`（所有节点）。系统由内部动力学（W·a）和脑干调制（b）驱动。

## 七、m/rel/focus 的角色迁移

### 7.1 对照表

| 旧角色 | 旧公式 | 新角色 | 新位置 |
|--------|--------|--------|--------|
| m（髓鞘化） | 直接乘出激活 | 连接权重因子 | W 矩阵 — m_mean(A→B) |
| rel（情境调制） | 逐链路查表乘数 | 外部输入 + 网络传播 | s_j(t) + W·a 动力学 |
| focus（聚焦） | 直接乘出激活（×2） | 连接权重倍率 | W 矩阵 — focus_multiplier |

### 7.2 m 不变的部分

m 的增长公式不变（`核心机制.md` §2.3 Δm = base(L) × f(m) × g(n) × 标记倍率）。m 仍然是构建层慢变量——使用即增长，不衰退。变的是 m 的**消费方式**：不再直接乘出激活值，而是决定连接权重。

### 7.3 rel 不变的部分

"情境"的概念不变——战斗中的情境原型（威胁/社交/探索等）仍然存在。变的是 rel 的**消费方式**：不再逐链路查一个相关性分数，而是通过外部输入 s(t) 激活关键节点，让网络传播替换查表。

### 7.4 需要更新的已有文件

| 文件 | 位置 | 当前内容 | 变更 |
|------|------|---------|------|
| `规则/核心机制.md` | §2.1、§52 | `激活水平 = m × rel × focus` | 替换为 WC 公式 + 本 §七对照表 |
| `规则/技能树系统/技能生成机制.md` | §一、§五 | `skill_effect = Σ m_i × focus_i × rel(i, situation)` | 效果计算公式改为从 a(t) 派生（不再用 m×focus×rel） |
| `data/term_registry.json` | terms.链路 | definition 含旧公式 | 更新 definition，标注 formula_change |

## 八、战斗输出映射

皮层动力学层的 a(t) 值需要转换为战斗系统可用的数值。

### 8.1 直接输出

| 输出 | 节点 | 映射 |
|------|------|------|
| 察觉分（速度排序 §三） | V1, A1, 前脑岛, ACC | `perception_score = mean(a of L3 sensory nodes) × w_perception` |
| 决断分（速度排序） | 基底节 CSTC 环路 | 由 CSTC 层输出，皮层提供 salience c |
| 执行分（速度排序） | M1, 壳核, 前运动皮层 | `execution_score = a(Precentral) × w_execution` |
| 精神攻击基础伤害 | dlPFC, Broca, ACC, STS | `mental_damage_base = mean(a of cognitive nodes) × scale` |
| 记忆检索成功率 | 海马 CA1/CA3, 旁海马, 内嗅皮层 | `memory_success = sigmoid(mean(a of MTL nodes) − θ_mem)` |

### 8.2 间接输出（经 CSTC）

| 输出 | 皮层提供 | CSTC 提供 |
|------|---------|----------|
| 技能 gate_bonus | cortical_input 节点的 a(t) → salience c | Gurney 竞争 → O_GPi → gate |
| 行动是否被抑制 | 皮层计划强度 | GPi 门控输出 |
