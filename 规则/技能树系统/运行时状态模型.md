# 运行时状态模型

> 三体神经模型（Grilling #26）的运行时动力学——从静态解剖到动态模拟的桥梁。按因果链顺序定义三层：皮层动力学（信息处理引擎）→ 脑干广播（全局色调调制）→ CSTC 门控（动作放行决策）。69 个 functional_id 节点 + 4 个脑干 tone + 3 个 CSTC 环路 gate 构成完整的回合制战斗神经状态。
>
> **维度: 规则** — Grilling #32 运行时状态模型。

## 一、设计原则

1. **节点动力学，非链路动力学**：激活变量 `a(t)` 附着在 functional_id 上（神经群体），不是链路上。链路级 `m × rel × focus` 公式已废弃。
2. **因果链顺序**：脑干 tone → 皮层 a(t) → CSTC gate。每层只依赖前一层，不跨层。
3. **通用方程，差异化参数**：同层共享数学形式，差异来自 τ、W、权重等参数。
4. **数据锚定**：所有参数从已有 JSON 数据文件派生。不引入新数据文件。
5. **髓鞘化进权重，不进激活**：m 决定连接权重 W，间接驱动激活传播。
6. **回合制离散更新**：每回合 Phase 1（情境更新）步进一步，Δt = 1.0s。

## 二、架构总览

```
回合 Phase 1: 情境更新
│
├─→ Layer 2: 脑干广播（先更新——它调制皮层）
│   NE/DA_VTA/DA_SNc/5HT tone ← 上回合事件 δ_event + 衰减回 baseline
│   │
│   └─→ b_j = Σ tone × w(j)   （加法注入皮层）
│
├─→ Layer 1: 皮层动力学
│   69 个 functional_id 的 a(t) ← WC: τ·da/dt = −a + σ(W·a + b + s)
│   │
│   └─→ a(t) 输出三个用途:
│       ① 战斗输出（感知/记忆/认知/精神攻击）
│       ② CSTC salience c（环路内 CI 均值）
│       ③ 反馈到自身（W·a 下回合输入）
│
└─→ Layer 3: CSTC 门控
    3 环路 × Gurney 5 群体 → O_GPi → gate
    │
    └─→ gate_bonus 进入技能效果计算（Phase 4 行动窗口）
```

## 四、Layer 1：皮层动力学（WC 通用层）

> 详细规格见 [皮层动力学-通用层](皮层动力学-通用层.md)。本节列出核心公式和与 Layer 2/3 的接口。

### 4.1 通用方程

对每个 functional_id j（category=cortical 且不在 CSTC 排除清单中）：

```
τ_j · da_j/dt = −a_j + σ( h_j(t) )
h_j(t) = Σ_k W_jk · a_k(t)  +  b_j(t)  +  s_j(t)
           ↑                      ↑          ↑
      皮层-皮层输入          脑干调制    外部/感官输入
```

**离散更新**（每回合 Phase 1）：

```
IF Δ/τ_j ≥ 50:  a_j ← σ(h_j)                                  — fast 节点解析解
ELSE:           a_j ← clip( a_j + (Δ/τ_j)·(−a_j + σ(h_j)),  0, 1 )
```

### 4.2 有效节点分界

CSTC 环路节点不参与皮层-皮层 W 矩阵——它们由 Layer 3 Gurney 独占驱动。排除清单：Pallidum, Thalamus-Proper, Putamen, Caudate, Accumbens-area, SubthalamicNucleus。脑干核团（dk_name=None）同样排除（行=0 且列=0）。

### 4.3 连接权重 W

```
w(A, B) = edr_probability(A→B) × m_mean(A→B) × focus_multiplier(A→B)
```

- `edr_probability`：`tripartite_model.json` corticocortical 连接，∈ [0.10, 0.85]
- `m_mean`：`combat_state.link_states[link_id].m` 中 (A→B) 对应链路的均值
- `focus_multiplier`：1.0 或 2.0（玩家聚焦）
- 行归一化：`W_norm[j][k] = W[j][k] / (Σ_i W[j][i] + 0.01)`

### 4.4 τ 映射

| timescale | τ（秒） | Δ/τ |
|-----------|--------|-----|
| fast | 0.01 | 100 |
| medium | 0.05 | 20 |
| slow | 0.15 | ~7 |
| 未知 | 0.05（默认） | 20 |

### 4.5 外部输入 s(t)

接口已定义，数据源（event→node_affinity 映射表）待后续文档创建。当前 `s_j(t) = 0`。

## 五、Layer 2：脑干广播调制

### 5.1 解剖基座

四个脑干核团，全部位于 L0（`脑功能层级模型.md` §三）：

| Tone | 解剖源 | 神经递质 | 投射类型 | 目标数 | 原子操作 |
|------|--------|---------|---------|--------|---------|
| NE_tone | 蓝斑 (LocusCoeruleus) | 去甲肾上腺素 | diffuse_broadcast | 32 皮层目标 | 激活——提升全局唤醒 |
| DA_VTA_tone | 腹侧被盖区 (VTA) | 多巴胺 | targeted_broadcast | 11 目标（NAcc+PFC+杏仁核+纹状体） | 趋近——动机突显 |
| DA_SNc_tone | 黑质致密部 (SNc) | 多巴胺 | targeted_broadcast | 3 目标（壳核+尾状核+NAcc） | 执行——运动启动 |
| 5HT_tone | 中缝背核 + 中缝正中核 | 血清素 | diffuse_broadcast | 34 皮层目标（100% 重叠） | 忍耐+等待——冲动控制 |

数据来源：`tripartite_model.json` brainstem (114 条)，`brain_regions.json` L0 实体，Hansen et al. (2024) Table 1。

### 5.2 动力学

```
τ_tone · d(tone)/dt = −(tone − baseline) + δ_event

离散: tone ← tone + (Δ/τ_tone)·( −(tone − baseline) + δ_event )
      tone ← clip(tone, 0, 1)
```

无 sigmoid——tone 是调质浓度，不需要发放率饱和。

### 5.3 τ_tone 映射

| Tone | τ_tone（秒） | Δ/τ | 理由 |
|------|------------|-----|------|
| NE_tone | 0.5 | 2.0 | 唤醒变化快——秒级 |
| DA_VTA_tone | 0.3 | 3.3 | RPE 信号 phasic~100ms，主观感觉有惯性 |
| DA_SNc_tone | 0.8 | 1.3 | 运动状态惯性大 |
| 5HT_tone | 1.5 | 0.7 | 情绪最慢——跨回合变化 |

### 5.4 baseline（静息水平）

角色性格标签决定。战斗开始时 tone 从 baseline 启动。标签→基线映射表后续定义。

| Tone | 默认 baseline | 说明 |
|------|-------------|------|
| NE_tone | 0.3 | 正常警觉 |
| DA_VTA_tone | 0.4 | 中等动机 |
| DA_SNc_tone | 0.5 | 运动顺畅 |
| 5HT_tone | 0.5 | 正常冲动控制 |

### 5.5 δ_event（事件冲击）

战斗事件驱动的瞬时冲击——正或负。每回合汇总 δ_event，然后衰减回 baseline。

| 事件 | NE | DA_VTA | DA_SNc | 5HT |
|------|-----|--------|--------|-----|
| 技能命中敌人 | — | +0.3 | — | — |
| 技能被格挡/MISS | — | −0.2 | — | — |
| 被敌人击中 | +0.4 | — | — | −0.1 |
| 队友倒下 | +0.3 | −0.3 | — | −0.2 |
| 成功防御/忍耐 | — | — | — | +0.15 |
| SAN 跌破恐慌阈值 | +0.3 | — | — | −0.3 |
| 击败敌人 | — | +0.4 | +0.1 | +0.1 |

完整映射表后续定义。

**同回合多事件汇总**：加法叠加——脑干核团是积分器，天然汇总所有输入。`δ = Σ events`。叠加后由 τ_tone 衰减和 clip [0,1] 提供饱和保护。这符合 TD 学习框架中同一时间步内 r(t) = Σ r_i 的做法（Schultz et al. 1997）。

### 5.6 注入皮层：b_j(t)

```
b_j(t) = NE_tone × w_NE(j) + DA_VTA_tone × w_VTA(j) + DA_SNc_tone × w_SNc(j) + 5HT_tone × w_5HT(j)
```

**投射权重 w**（两档，从 `tripartite_model.json` brainstem.role 字段取）：

| role | w | 含义 | 数量 |
|------|---|------|------|
| `"active"` | 1.0 | 靶向调制——功能显著的调制 | 15/114 |
| `"modulating"` | 0.5 | 弥漫广播——基线调制 | 99/114 |
| 不在目标集中 | 0 | 不接收该 tone | — |

### 5.7 未参与广播的 L0 节点

PAG、上丘、脑桥网状核、小脑皮层——不广播 b_j，但从皮层接收输入（特权通路 + s(t)），a(t) 由 WC 方程正常驱动。它们的 a(t) 不作为 CSTC salience 源（不是 cortical_input）。

## 六、Layer 3：CSTC 门控（粗粒度）

### 6.1 粗粒度 3 通道

每环路一个 Gurney 通道。通道与现有数据 1:1 映射，不需要拆分纹状体。

| 环路 | cortical_input 节点 | striatal_gate | 游戏含义 |
|------|---------------------|---------------|---------|
| somatic | precentral, paracentral, superiorfrontal | Putamen | 物理技能门控 |
| cognitive | parsopercularis, rostralmiddlefrontal, frontalpole, caudalmiddlefrontal, caudalanteriorcingulate | Caudate | 认知/语言技能门控 |
| limbic | Amygdala, Hippocampus, insula, rostralanteriorcingulate, medialorbitofrontal, lateralorbitofrontal, caudalanteriorcingulate, superiorfrontal | Accumbens-area | 情绪/本能技能门控 |

> **caudalanteriorcingulate 和 superiorfrontal 跨两个环路**——它们的 a(t) 同时贡献给 cognitive 和 limbic（caudalanteriorcingulate）或 limbic 和 somatic（superiorfrontal）的 salience c。这是解剖事实——ACC 参与认知控制（dorsal）和情绪评估（rostral），SFG 参与运动计划和默认网络。

### 6.2 Salience c

```
c_loop = mean( a(ci)  for ci ∈ loop.cortical_inputs )
```

每个环路一个标量 c ∈ [0, 1]，从该环路所有 cortical_input 节点的 a(t) 取均值。

### 6.3 Gurney 模型（每环路独立运行）

参照 Gurney-Prescott-Redgrave (2001)，每环路 5 个群体：

| 群体 | 角色 | 输入 |
|------|------|------|
| SD1 | GO / 直接通路 D1 | u = c_loop × W_SEL × (1 + DA_loop) |
| SD2 | NO-GO / 间接通路 D2 | u = c_loop × W_CONT × (1 − DA_loop) |
| STN | STOP / 超直接通路 | u = c_loop × W_STN + O(GPe) × W_GPe_STN |
| GPe | 间接通路中间站 | u = ΣO(STN)·W_STN_GPe + O(SD2)·W_CONT_GPe + O(SD1)·W_SEL_GPe |
| GPi | 输出门 | u = ΣO(STN)·W_STN_GPi + O(GPe)·W_GPe_GPi + O(SD1)·W_SEL_GPi |

**DA 调制**（按环路差异化混合——VTA 管动机投射到 NAcc/limbic，SNc 管运动投射到 Putamen/somatic）：

```
DA_limbic    = 0.8 × DA_VTA_tone + 0.2 × DA_SNc_tone   ← 动机主导
DA_cognitive = 0.4 × DA_VTA_tone + 0.6 × DA_SNc_tone   ← 认知执行居中
DA_somatic   = 0.2 × DA_VTA_tone + 0.8 × DA_SNc_tone   ← 运动执行主导
```

每个环路的 DA_loop 替代原来的等权平均，进入该环路 Gurney 的 D1/D2 ramp 调制。DA 升高 → D1 增强（GO↑），D2 抑制（NO-GO↓）。

**连接权重**（来自 Gurney 2001 + Humphries 2003）：

| 权重 | 值 | 含义 |
|------|-----|------|
| W_SEL | 1.0 | 皮层→SD1 |
| W_CONT | 1.0 | 皮层→SD2 |
| W_STN | 1.0 | 皮层→STN |
| W_SEL_GPi | −1.0 | SD1→GPi（GO） |
| W_CONT_GPe | −1.0 | SD2→GPe |
| W_STN_GPi | 0.9 | STN→GPi（STOP） |
| W_STN_GPe | 0.9 | STN→GPe |
| W_GPe_STN | −1.0 | GPe→STN |
| W_GPe_GPi | −0.3 | GPe→GPi |

**动力学**（每群体一阶衰减，同 WC 骨架）：

```
τ_gurney · da/dt = −a + u      (τ_gurney = 0.04s, k = 25)
a(t+Δ) = (a(t) − u) × exp(−k·Δ) + u       (解析解)
```

τ=0.04s, Δ=1.0s, Δ/τ=25 → Gurney 群体在单回合内几乎收敛到稳态。用解析解而非 Euler（Δ/τ 大但 k 也大，exp(−25)≈0，a→u）。

**分段线性 ramp 输出**：

```
O(a) = 0                        if a < e
     = m × (a − e)              if e ≤ a ≤ 1/m + e
     = 1                        if a > 1/m + e
```

其中 e = 0.2（阈值），m = 1.0（斜率）。

**DA 调制 ramp 斜率**（Humphries 2003，每环路用各自的 DA_loop）：

```
m_SD1 = 1.0 + DA_loop        ← DA 升高 → GO 增强
m_SD2 = 1.0 − DA_loop        ← DA 升高 → NO-GO 减弱
```

### 6.4 Gate 输出

```
gate_loop = 1 − O_GPi_loop
```

O_GPi 高（tonic 抑制强）→ gate 低（动作被钳制）。O_GPi 低（去抑制）→ gate 高（动作放行）。

gate ∈ [0, 1]——连续值，不是二元开/关。

### 6.5 技能映射

CSTC 门控作用于**动作输出型**角色——即需要通过基底节放行的行为。输入型角色（perceive）和元认知型角色（support）绕过门控。

| 技能 role | CSTC 映射 | 门控规则 |
|-----------|----------|---------|
| attack_physical | somatic | `gate_bonus = gate_somatic` |
| attack_mental | cognitive | `gate_bonus = gate_cognitive` |
| defend | limbic | `gate_bonus = gate_limbic` |
| perceive | bypass | `gate_bonus = 1.0` |
| approach | limbic | `gate_bonus = gate_limbic` |
| flee | limbic | `gate_bonus = gate_limbic` |
| disrupt | limbic | `gate_bonus = gate_limbic`；无 CI 链路 fallback 1.0 |
| support | bypass | `gate_bonus = 1.0` |

**设计理由**：

- **perceive bypass**：感知是输入通道——57% 的感知链路不经过任何 CSTC CI。知觉质量仍受 NE_tone 调制（警觉/注意），但不经过动作门控。
- **support bypass**：元认知操作（共情安抚、认知策略、记忆检索辅助）不走基底节动作通道。7% 的 support 链路无 CI（DMN 节点），bypass 同时解决了映射不可判定问题。
- **defend → limbic**：数据校验——防御链路 CI 分布 limbic 9 vs somatic 2。防御是威胁检测→恐惧响应（Amygdala→PAG），走 limbic 环路。
- **attack_mental → cognitive**：语言攻击的 CI 分布 limbic 37 + cognitive 32，但 gate 只用 cognitive。limbic 对语言的影响不通过 CSTC 门控——它走皮层-皮层 W 矩阵（Amygdala/insula → Broca 的 W 权重），自然地通过 WC 动力学提升语言节点 a(t)——这个通路已经在 base damage 计算中被捕捉了。gate 只管语言通道开关。
- **disrupt fallback**：75% CI 匹配 limbic。38% 无 CI 链路（镜子神经元系统 fusiform→颞上回）fallback gate=1.0——共情干扰不经过动作门控。
- **caudalanteriorcingulate 和 superiorfrontal 跨环路**：它们的 a(t) 同时贡献给两个环路的 c_loop（§6.1），产生自然的认知-情绪-运动耦合。这是解剖事实，非设计缺陷。

**gate_bonus 结算**（在 Phase 4 行动窗口时）：

```
gate_bonus(skill) = gate_somatic                                    if role = attack_physical
                  = gate_cognitive                                   if role = attack_mental
                  = gate_limbic                                     if role ∈ {defend, approach, flee, disrupt}
                  = 1.0                                             if role ∈ {perceive, support} (bypass)
                  = 1.0                                             if role = disrupt ∧ skill has no CI (fallback)
```

技能基础效果 × gate_bonus。gate=1 → 满额；gate=0 → 被完全门控抑制。不阻止玩家使用——只影响效果。

## 七、三层集成：因果链数据流

### 7.1 每回合执行顺序

```
Phase 1: 情境更新
├─ 1. Layer 2 更新: tone ← tone + (Δ/τ_tone)·(−(tone−baseline) + δ_event)
│    δ = Σ events（同回合事件加法叠加，§5.5）
│
├─ 2. Layer 2→1 注入: 计算 b_j = Σ tone × w(j)（69 维向量）
│
├─ 3. Layer 1 更新: a_j ← WC_step(a_j, h_j = W·a + b + s)
│    W·a 使用上一回合末的 a 值（同步更新避免顺序偏倚）
│
├─ 4. Layer 1→3 传递: c_loop = mean(a(ci) for ci in loop)
│    DA_limbic/cognitive/somatic 按环路混合权重计算（§6.3）
│
└─ 5. Layer 3 更新: Gurney 群体 → O_GPi → gate_loop
     Gurney 用解析解（τ=0.04, Δ=1s → 稳态）

Phase 2-3: 继承 + 速度重算
  a(t) 贡献察觉分/决断分/执行分

Phase 4: 玩家行动窗口
  技能结算: gate_bonus(skill) = gate_loop × 技能基础效果
```

### 7.2 层间接口

```
Layer 2 → Layer 1:  b_j ∈ [0, 2]   (max=2.0 — 全脑最高为 Accumbens-area 接收 DA_VTA+DA_SNc 均为 active=1.0×2=2.0)
                    → clip 到 [0, 2] 防止过度驱动

Layer 1 → Layer 3:  c_loop ∈ [0, 1] (cortical_input a(t) 均值)
                    DA_limbic/cognitive/somatic ∈ [0, 1] (VTA/SNc 按环路混合权重)

Layer 3 → 战斗:    gate_loop ∈ [0, 1]
```

### 7.3 初始化

战斗开始时：
- `a_j(0) = 0.10`（所有皮层节点，tonic 静息基线）
- `tone = baseline`（从性格标签读取，默认 NE=0.3, DA_VTA=0.4, DA_SNc=0.5, 5HT=0.5）
- `Gurney 群体 a = 0`（从静息开始，首回合快速收敛到稳态）

## 八、战斗输出映射

### 8.1 从 a(t) 直接输出

| 输出 | 计算 | 消费者 |
|------|------|--------|
| 察觉分 | `mean(a of L3 sensory nodes) × w_perception` | `回合战斗流程.md` §三 速度排序 |
| 决断分 | 由 CSTC 层输出（GPi 竞争解决时间代理） | 同上 |
| 执行分 | `a(Precentral) × w_execution` | 同上 |
| 精神攻击基础伤害 | `mean(a of cognitive nodes) × scale_mental` | 伤害公式 |
| 记忆检索成功率 | `σ( mean(a of MTL nodes) − θ_mem )` | 技能系统记忆类技能 |

> **⚠️ 权重待赋值**：w_perception, w_execution, scale_mental, θ_mem 的具体数值在后续数值校准中定义。

### 8.2 从 gate 输出

| 输出 | 计算 | 消费者 |
|------|------|--------|
| 物理技能 gate_bonus | `gate_somatic` | 技能效果结算 |
| 认知/语言技能 gate_bonus | `gate_cognitive` | 技能效果结算 |
| 情绪/防御/本能技能 gate_bonus | `gate_limbic` | 技能效果结算（approach/flee/defend/disrupt） |
| 感知/辅助技能 gate_bonus | `1.0`（bypass） | 技能效果结算（perceive/support） |

### 8.3 从 tone 输出（间接）

Tone 不直接进入战斗数值——它们通过 b_j 影响 a(t)，再通过 a(t) 和 gate 间接影响。例外：

| 输出 | 计算 | 消费者 |
|------|------|--------|
| 全局唤醒（UI 显示） | `NE_tone` | HUD 警觉指示器 |
| 冲动度（UI 显示） | `1 − 5HT_tone` | HUD 冲动/耐心指示器 |

## 九、m/rel/focus 的角色迁移

| 旧角色 | 旧公式 | 新角色 | 新位置 |
|--------|--------|--------|--------|
| m（髓鞘化） | 直接乘出 `activation` | 连接权重因子 | L1 W 矩阵 — m_mean(A→B)；L3 Gurney — c_loop 隐含 m 加权 |
| rel（情境调制） | 逐链路查表乘数 | 外部输入 + 网络传播 | L1 s_j(t) + W·a 动力学 |
| focus（聚焦） | 直接乘 ×2 | W 权重倍率 | L1 W 矩阵 — focus_multiplier |

m 的增长公式不变（`核心机制.md` §2.3）。m 仍是构建层慢变量。变的是消费方式。
