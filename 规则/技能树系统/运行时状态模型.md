## 一、设计原则

1. **节点动力学，非链路动力学**：激活变量 `a(t)` 附着在 functional_id 上（神经群体），不是链路上。链路级 `m × rel × focus` 公式已废弃。
2. **因果链顺序**：脑干 tone → 皮层 a(t) → CSTC gate。每层只依赖前一层，不跨层。
3. **通用方程，差异化参数**：同层共享数学形式，差异来自 τ、W、权重等参数。
4. **数据锚定**：所有参数从已有 JSON 数据文件派生。不引入新数据文件。
5. **髓鞘化进权重，不进激活**：m 决定连接权重 W，间接驱动激活传播。
6. **回合制离散更新**：每回合 Phase 1（情境更新）步进一步，Δt = 1.0s。

## 二、架构总览

```
回合 Phase 1: 情境更新
│
├─→ Layer 2: 脑干广播（先更新——它调制皮层）
│   NE/DA_VTA/DA_SNc/5HT tone ← 上回合事件 δ_event + 衰减回 baseline
│   │
│   └─→ b_j = Σ tone × w(j)   （加法注入皮层）
│
├─→ Layer 1: 皮层动力学
│   69 个 functional_id 的 a(t) ← WC: τ·da/dt = −a + σ(W·a + b + s)
│   │
│   └─→ a(t) 输出三个用途:
│       ① 战斗输出（感知/记忆/认知/精神攻击）
│       ② CSTC salience c（环路内 CI 均值）
│       ③ 反馈到自身（W·a 下回合输入）
│
└─→ Layer 3: CSTC 门控
    3 环路 × Gurney 5 群体 → O_GPi → gate
    │
    └─→ gate_bonus 进入技能效果计算（Phase 4 行动窗口）
```

## 四、Layer 1：皮层动力学（WC 通用层）

> 详细规格见 [皮层动力学-通用层](皮层动力学-通用层.md)。本节列出核心公式和与 Layer 2/3 的接口。

### 4.1 通用方程

对每个 functional_id j（W 活跃节点 = 48 fids：44 皮层 + Amygdala + Hippocampus×2 + Cerebellum-Cortex；排除节点（CSTC 6 dk + 脑干，16 dk / 21 fids）W 行=列=0、方程退化为 h_j = b_j + s_j。2026-08-13 修正，原措辞「category=cortical 且不在 CSTC 排除清单中」漏掉 3 个 subcortical 参与 dk）：

```
τ_j · da_j/dt = −a_j + σ( h_j(t) )
h_j(t) = Σ_k W_jk · a_k(t)  +  b_j(t)  +  s_j(t)
           ↑                      ↑          ↑
      皮层-皮层输入          脑干调制    外部/感官输入
```

**离散更新**（每回合 Phase 1）——解析解（2026-08-13 由 Euler+clip 修订，csharp-engine 实现实证）：

```
a_j' = σ(h_j) + (a_j − σ(h_j)) · e^(−Δ/τ_j)                  — 统一解析指数解，无 Δ/τ 分支
```

h_j 在回合内视为常数，上式是连续方程在 [t, t+Δ] 上的精确积分。fast 节点（Δ/τ=100）e^(−100)≈0 → 即原分支的特例 a_j ← σ(h_j)；slow 节点（Δ/τ≈6.7）e^(−6.67)=1.27e-3 → 单回合收敛 ≥99.87%，每回合近乎 `a_j ← σ(W·a+b+s)`（固定点迭代，无历史记忆——原「slow 跨回合平滑过渡」叙述作废，见 [皮层动力学-通用层 §4.3](皮层动力学-通用层.md)）。解析解自动保证 a_j' ∈ (0,1)（a 与 σ 的凸组合），无需 clip——原 Euler 方案需要 clip 的原因随公式替换消除。

### 4.2 有效节点分界

CSTC 环路节点不参与皮层-皮层 W 矩阵——它们由 Layer 3 Gurney 独占驱动。排除清单：Pallidum, Thalamus-Proper, Putamen, Caudate, Accumbens-area, SubthalamicNucleus。脑干核团（dk_name=None）同样排除（行=0 且列=0）。

### 4.3 连接权重 W

```
w(A, B) = edr_probability(A→B) × m_mean(A→B) × focus_multiplier(A→B)
```

- `edr_probability`：`tripartite_model.json` corticocortical 连接，∈ [0.10, 0.85]
- `m_mean`：`combat_state.link_states[link_id].m` 中 (A→B) 对应链路的均值
- `focus_multiplier`：1.0 或 2.0（玩家聚焦）
- **放置**：`w(A, B)` 为 A→B 权重，写入矩阵时 `W[fid_B][fid_A] = w(A, B)`——行=接收者 B、列=发送者 A，与 §4.1 `h_j = Σ_k W_jk·a_k` 一致（2026-08-13 补，同步 [皮层动力学-通用层 §5.1](皮层动力学-通用层.md) 索引序修正）
- 行归一化：`W_norm[j][k] = W[j][k] / (Σ_i W[j][i] + 0.01)`

| slow | 0.15 | ~7 |

### 4.5 外部输入 s(t)

> 定义由 Grilling #34 确立（2026-08-09）。

s(t) 不直接指定 69 维分量。事件携带感官模态强度向量 α ∈ [0, 1]⁶，通过解剖映射矩阵展开：

```
s = W_sensory × α
W_sensory ∈ {0, 1}^{69×6}  → `data/connectivity/W_sensory.json`（已构建，2026-08-09）
```

> **三通道结构（Grilling #69/#75）**：s_total = s_事件 + s_env + m_field。事件脉冲 s_事件（一次性，下一 Phase 1 注入）与持续场 s_env（环境内恒定，空间切换刷新）经 W_sensory 展开；**m_field（月光场通道）不经过 W_sensory**（非感官模态），独立注入——见下。

> **m_field 接口（Grilling #38/#101）**：`m_field_vec⁽ⁱ⁾(t) = q̂_{x_i(t)}(t) · g(SAN_i, state_i) · R`——q̂ = 月光场理论投影输出（[时空结构数学框架 §十一](../../规则/时空结构数学框架.md)），g = 机制层调制（待校准），R = 神经节点落点向量（**Grilling #101 闭合，2026-09-02**：全局固定结构，12 落点 = L1∪L2 ∩ W活跃，主辅两档参数化，非负/稀疏/扩展性不变量，详见 [时空结构数学框架 §11.5](../../规则/时空结构数学框架.md)）。引擎侧 MFieldStrength 占位（#75）由此获得数值来源链；节点级落点已填充。更新时序 = 空间切换 + 月相/昼夜节点（#69 D7）。

**s_j 值域**：单模态节点 s_j ∈ [0, 1]（α 恒 ≤ 1——A 类固定 m_α=1.0，B/C/D 类 m 均 ≤ 1.0 由公式保证）。双模态节点（12 个，如 BanksSTS=auditory+soc、Postcentral=soma+pain）在全强度双模态事件中 s_j 可达 2.0。WC sigmoid σ 提供自然饱和——双模态节点收到的是更强的感官驱动，而非"溢出"。

**非皮层节点**：25 个 subcortical/brainstem functional_id（14 subcortical + 11 brainstem）W_sensory 行全零。其中 21 个排除 fid（CSTC 6 dk 的 10 个 + 脑干 11 个）不参与 WC 皮层动力学（§4.2 排除规则，W 行=列=0）；其余 4 个 subcortical fid（Amygdala + Hippocampus×2 + Cerebellum-Cortex）**参与** W（§4.2 排除清单未含它们），W_sensory=0 → 其感官信息经皮层-皮层连接间接接收已处理的结果。Amygdala（虽在 Grilling #34 社会认知节点列表中出现，但 category=subcortical → W_sensory=0——其痛觉/社会加工通过 insula→dACC→Amygdala 连接间接获得）。2026-08-13 修正，原「它们不参与 WC 皮层动力学」对 4 个 subcortical 参与 fid 不成立。

### 5.2 动力学

```
τ_tone · d(tone)/dt = −(tone − baseline) + δ_event

离散（解析解，2026-08-13 由 Euler+clip 修订——csharp-engine 实现实证）:
tone' = clip( baseline + δ_eff + (tone − baseline − δ_eff) · e^(−Δ/τ_tone), 0, 1 )
δ_eff = δ × δ_scale ，δ_scale = 0.3 [NEW]（引擎 CalibrationConfig.DeltaScale——
        全局 δ 缩放因子，§5.5「数值校准延迟」预告的两条路线之一；0.3 为占位值，整体校准时复核）
```

> **A6 δ = sign(tone_bias[skill.role])**：sign 取的是**权重表的固定符号**（NPC AI 行为模型 §3.3），不是动态 (tone−baseline) 的符号。权重=0 的 tone 不受技能使用影响（sign(0)=0 → 该 tone 无脉冲）。例如 attack_physical 权重 (0, +0.3, +0.5, −0.3) → sign = (0, +1, +1, −1)，无论当前 tone 状态如何，使用攻击技能总是 DA↑ 5HT↓。A6 α = 0（技能走 WC 内部通路，外部 s(t) 不需要）。

|---|---------|-----|--------|--------|-----|
| D1 | 队友被击倒 | +1 | −1 | 0 | −1 |
| D2 | 敌人被击倒 | 0 | +1 | 0 | +1 |

#### magnitude 表

`δ = pattern_δ × m`，`m ∈ [0, ∞)`。溢出由下游 `clip(tone, 0, 1)` 处理。m < 0.01 时跳过 emit（避免浮点噪声产生零向量事件）。

#### 注入时序

| 时机 | 内容 | 理由 |
|------|------|------|
| 实时（事件发生瞬间） | δ_event → tone | 脑干快通路（τ=0.3-1.5s），应即时应答 |
| Phase 1（下回合开始） | s(t) 打包注入 → WC | 皮层慢加工（200ms+），打包延迟合理 |

**同回合多事件汇总**：加法叠加——脑干核团是积分器。`δ = Σ events`。叠加后由 τ_tone 衰减和 clip [0,1] 提供饱和保护。符合 TD 框架 r(t) = Σ r_i（Schultz et al. 1997）。

> ✅ **2026-09-03（Grilling #35 定案）一回合事件数量不变量**：**不设独立 N_max 上限**。上界由行动经济自然约束（每角色 ≤ 2 自身行动 + 敌方数 + 倒下数 + 1 阈值跨越），tone clip [0,1] + m<0.01 跳过 emit + WC σ 饱和为三层保护。δ 事件不触发 δ 事件（无链式递归）。引擎 EventProcessor 加装配期防御断言：单角色单回合事件数 > 64 → 抛异常（防未来引入链式/生成事件机制时静默退化；64 为防御阈值非设计语义）。

## 六、Layer 3：CSTC 门控（粗粒度）

### 6.1 粗粒度 3 通道

每环路一个 Gurney 通道。通道与现有数据 1:1 映射，不需要拆分纹状体。

| 环路 | cortical_input 节点 | striatal_gate | 游戏含义 |
|------|---------------------|---------------|---------|
| somatic | precentral, paracentral, superiorfrontal | Putamen | 物理技能门控 |
| cognitive | parsopercularis, rostralmiddlefrontal, frontalpole, caudalmiddlefrontal, caudalanteriorcingulate | Caudate | 认知/语言技能门控 |
| limbic | Amygdala, Hippocampus, insula, rostralanteriorcingulate, medialorbitofrontal, lateralorbitofrontal, caudalanteriorcingulate, superiorfrontal | Accumbens-area | 情绪/本能技能门控 |

> **caudalanteriorcingulate 和 superiorfrontal 跨两个环路**——它们的 a(t) 同时贡献给 cognitive 和 limbic（caudalanteriorcingulate）或 limbic 和 somatic（superiorfrontal）的 salience c。这是解剖事实——ACC 参与认知控制（dorsal）和情绪评估（rostral），SFG 参与运动计划和默认网络。**fid 级实现**（2026-08-13 step 6 裁决）：跨环路由同 dk 的不同 fid 分属两环实现——caudalanteriorcingulate = AnteriorCingulateCortex(limbic) + AnteriorCingulateCortexDorsal(cognitive) + FrontalPoleSN(limbic)；superiorfrontal = SuperiorFrontal(somatic) + SuperiorFrontalMPFC(limbic)。每个 fid 只贡献一个环路，无单点双消费。

### 6.2 Salience c

```
c_loop = mean( a(ci)  for ci ∈ loop.cortical_inputs )
```

每个环路一个标量 c ∈ [0, 1]，从该环路所有 cortical_input 节点的 a(t) 取均值。

**粒度（2026-08-13 step 6 裁决）**：ci 按 **functional_id（fid）** 取——function_profile 中 `cstc_role == cortical_input` 且 `cstc_loop == <loop>` 的 fid 各以自身 a_j 直接入均值（§6.1 表的 dk 名是解剖叙述，运行时无 dk 级聚合层）。多 fid 的 dk 节点按其 fid 数加权（如 rostralmiddlefrontal 3 个 CI fid 计 3 份）。

### 6.3 Gurney 模型（每环路独立运行）

参照 Gurney-Prescott-Redgrave (2001)，每环路 5 个群体：

| 群体 | 角色 | 输入 |
|------|------|------|
| SD1 | GO / 直接通路 D1 | u = c_loop × W_SEL × (1 + DA_loop) |
| SD2 | NO-GO / 间接通路 D2 | u = c_loop × W_CONT × (1 − DA_loop) |
| STN | STOP / 超直接通路 | u = c_loop × W_STN + O(GPe) × W_GPe_STN |
| GPe | 间接通路中间站 | u = ΣO(STN)·W_STN_GPe + O(SD2)·W_CONT_GPe + O(SD1)·W_SEL_GPe |
| GPi | 输出门 | u = ΣO(STN)·W_STN_GPi + O(GPe)·W_GPe_GPi + O(SD1)·W_SEL_GPi |

**DA 调制**（按环路差异化混合——VTA 管动机投射到 NAcc/limbic，SNc 管运动投射到 Putamen/somatic）：

```
DA_limbic    = 0.8 × DA_VTA_tone + 0.2 × DA_SNc_tone   ← 动机主导
DA_cognitive = 0.4 × DA_VTA_tone + 0.6 × DA_SNc_tone   ← 认知执行居中
DA_somatic   = 0.2 × DA_VTA_tone + 0.8 × DA_SNc_tone   ← 运动执行主导
```

每个环路的 DA_loop 替代原来的等权平均，进入该环路 Gurney 的 D1/D2 ramp 调制。DA 升高 → D1 增强（GO↑），D2 抑制（NO-GO↓）。

**连接权重**（来自 Gurney 2001 + Humphries 2003）：

| 权重 | 值 | 含义 |
|------|-----|------|
| W_SEL | 1.0 | 皮层→SD1 |
| W_CONT | 1.0 | 皮层→SD2 |
| W_STN | 1.0 | 皮层→STN |
| W_SEL_GPi | −1.0 | SD1→GPi（GO） |
| W_SEL_GPe | 0.0 | SD1→GPe（无连接——ModelDB 83560 默认；Gurney 2004 'g' 选项 −0.25） |
| W_CONT_GPe | −1.0 | SD2→GPe |
| W_STN_GPi | 0.9 | STN→GPi（STOP） |
| W_STN_GPe | 0.9 | STN→GPe |
| W_GPe_STN | −1.0 | GPe→STN |
| W_GPe_GPi | −0.3 | GPe→GPi |

**动力学**（每群体一阶衰减，同 WC 骨架）：

```
τ_gurney · da/dt = −a + u      (τ_gurney = 0.04s, k = 25)
a(t+Δ) = (a(t) − u) × exp(−k·Δ) + u       (解析解)
```

τ=0.04s, Δ=1.0s, Δ/τ=25 → Gurney 群体在单回合内几乎收敛到稳态。用解析解而非 Euler（Δ/τ 大但 k 也大，exp(−25)≈0，a→u）。

**a 不做 clamp**（2026-08-13 step 6 裁决）——负阈值机制要求 a 可为负（STN/GPe/GPi 的 u 可低至 −1.3）。值域按解析界文档化（§三 91 变量表）。

**分段线性 ramp 输出**：

```
O(a) = 0                        if a < e
     = m × (a − e)              if e ≤ a ≤ 1/m + e
     = 1                        if a > 1/m + e
```

**per-population 阈值**（2026-08-13 step 6 裁决，对齐 ModelDB 83560 GPR_engine.m 原始参数——原设计单一 e=0.2 实测导致 gate 恒 1 惰性，见决策树 #33 🔧 修正）：

| 群体 | e | 含义 |
|------|-----|------|
| SD1 | 0.2 | GO 激活阈值 |
| SD2 | 0.2 | NO-GO 激活阈值 |
| STN | −0.25 | 超直接通路低阈（快速响应） |
| GPe | −0.2 | 间接通路中间站 tonic 输出 |
| GPi | −0.2 | **tonic 抑制**——静息 a_GPi=0 时 O_GPi=0.2 → gate=0.8 |

m = 1.0（SD1/SD2 由 DA 调制，见下）。负阈值群体在 a=0 即产生 tonic 输出——这是 §6.4 门控抑制的来源。

**DA 调制 ramp 斜率**（Humphries 2003，每环路用各自的 DA_loop）：

```
m_SD1 = 1.0 + DA_loop        ← DA 升高 → GO 增强
m_SD2 = 1.0 − DA_loop        ← DA 升高 → NO-GO 减弱
```

### 6.4 Gate 输出

```
gate_loop = 1 − O_GPi_loop
```

O_GPi 高（tonic 抑制强）→ gate 低（动作被钳制）。O_GPi 低（去抑制）→ gate 高（动作放行）。

gate ∈ [0, 1]——连续值，不是二元开/关。

### 6.5 技能映射

CSTC 门控作用于**动作输出型**角色——即需要通过基底节放行的行为。输入型角色（perceive）和元认知型角色（support）绕过门控。

| 技能 role | CSTC 映射 | 门控规则 |
|-----------|----------|---------|
| attack_physical | somatic | `gate_bonus = gate_somatic` |
| attack_mental | cognitive | `gate_bonus = gate_cognitive` |
| defend | limbic | `gate_bonus = gate_limbic` |
| perceive | bypass | `gate_bonus = 1.0` |
| approach | limbic | `gate_bonus = gate_limbic` |
| flee | limbic | `gate_bonus = gate_limbic` |
| disrupt | limbic | `gate_bonus = gate_limbic`；无 CI 链路 fallback 1.0 |
| support | bypass | `gate_bonus = 1.0` |

**设计理由**：

- **perceive bypass**：感知是输入通道——57% 的感知链路不经过任何 CSTC CI。知觉质量仍受 NE_tone 调制（警觉/注意），但不经过动作门控。
- **support bypass**：元认知操作（共情安抚、认知策略、记忆检索辅助）不走基底节动作通道。7% 的 support 链路无 CI（DMN 节点），bypass 同时解决了映射不可判定问题。
- **defend → limbic**：数据校验——防御链路 CI 分布 limbic 9 vs somatic 2。防御是威胁检测→恐惧响应（Amygdala→PAG），走 limbic 环路。
- **attack_mental → cognitive**：语言攻击的 CI 分布 limbic 37 + cognitive 32，但 gate 只用 cognitive。limbic 对语言的影响不通过 CSTC 门控——它走皮层-皮层 W 矩阵（Amygdala/insula → Broca 的 W 权重），自然地通过 WC 动力学提升语言节点 a(t)——这个通路已经在 base damage 计算中被捕捉了。gate 只管语言通道开关。
- **disrupt fallback**：75% CI 匹配 limbic。38% 无 CI 链路（镜子神经元系统 fusiform→颞上回）fallback gate=1.0——共情干扰不经过动作门控。
- **caudalanteriorcingulate 和 superiorfrontal 跨环路**：它们的 a(t) 同时贡献给两个环路的 c_loop（§6.1），产生自然的认知-情绪-运动耦合。这是解剖事实，非设计缺陷。

**gate_bonus 结算**（在 Phase 4 行动窗口时）：

```
gate_bonus(skill) = gate_somatic                                    if role = attack_physical
                  = gate_cognitive                                   if role = attack_mental
                  = gate_limbic                                     if role ∈ {defend, approach, flee, disrupt}
                  = 1.0                                             if role ∈ {perceive, support} (bypass)
                  = 1.0                                             if role = disrupt ∧ skill has no CI (fallback)
```

技能基础效果 × gate_bonus。gate=1 → 满额；gate=0 → 被完全门控抑制。不阻止玩家使用——只影响效果。

### 8.3 从 tone 输出（间接）

Tone 不直接进入战斗数值——它们通过 b_j 影响 a(t)，再通过 a(t) 和 gate 间接影响。例外：

| 输出 | 计算 | 消费者 |

### 8.4 NPC 行动选择（Affordance Competition）

> 详见 [NPC AI 行为模型.md](./NPC%20AI%20行为模型.md) §三。

NPC 的回合行动 = affordance competition 的获胜者。从已存在的 WC+CSTC+tone 状态实时计算，无需离线预烘焙：

```
Salience(skill) = mean(a_j) × gate_bonus(role) × (1 + tone_bias(role))
NPC 行动 = argmax Salience  (Boss) 或 Softmax Salience/T (杂兵)
```

**文献锚点**：Cisek (2007) affordance competition — 多个动作在皮层并行指定，BG 提供偏置，胜者即行动。GPR (2001) — 去抑制选择。tone_bias 权重方向来自 Aston-Jones (2005, NE), Schultz (1997, DA), Daw (2002, 5HT)。
