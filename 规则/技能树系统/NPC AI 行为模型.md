## 一、设计原则

1. **敌我同构**：NPC 和玩家共用同一套脑区、链路、髓鞘化、槽位、SAN/HP 体系。NPC 的特殊性来自参数偏移，不来自独立系统。
2. **预烘焙优先**：NPC 的行为选择离线计算（性格模板 × 情境 × SAN 分段），运行时只做查表和骰子。不设在线搜索或最优决策。
3. **性格 = 链路偏移**：不引入 Big Five 等外部人格框架。NPC 的性格由 6 个链路群标签的髓鞘化偏移定义。
4. **疾病 = 连续谱**：精神疾病从正常人模板的链路偏离导出（RDoC/p-factor/HiTOP 框架背书方向），没有"正常 vs 异常"的清晰边界。
5. **不设独立 AI 层**：NPC 的行动选择、目标选择、协调行为都从链路结算自然涌现，没有外加的"战术 AI"或"行为树"。

## 二、感知与信息

### 2.1 感知边界

| 类型 | 可感知 | 不可感知 |
|------|--------|---------|
| **基础 NPC** | 玩家的外在行为输出（M1 身体动作 + Broca 语言输出） | 玩家内部链路配置、当前激活节点、SAN 精确值 |
| **高级 NPC**（有 L3/L4 感知链路） | 同上 + 部分揭露玩家链路/激活/SAN | 揭露程度取决于其感知链路的髓鞘化程度（连续谱） |
| **友方 NPC** | 与基础 NPC 相同 | 同基础 NPC |

### 2.2 感知通道

同构于玩家，NPC 有两个自然感知通道：

| 通道 | 神经基础 | 游戏表现 |
|------|---------|---------|
| **观察读出** | 社会认知链路（颞极/mPFC/STS）——感知 M1/Broca 输出 | NPC 看到同伴/玩家在做什么，自动调整 |
| **听觉/语言** | 颞横回→颞上回→Broca 解码 | NPC 听到的语音（包括玩家和同伴的战术沟通） |

### 2.3 信息不对称

- **玩家大脑对 NPC 不可见**：玩家内部链路配置、激活节点、SAN 精确值——NPC 默认看不到
- **NPC 大脑对玩家不可见**：见 §七（3D 大脑 UI），仅在玩家用 L3/L4 感知技能时部分揭露
- **例外**：高级 NPC 有 L3/L4 感知链路时可以部分"读心"——和玩家端感知技能同构

## 三、行为决策：预烘焙模型

### 3.1 核心理念

NPC 不和玩家一样做在线链路选择。NPC 的行为决策分两层：

| 层面 | 执行 | 时机 |
|------|------|------|
| **离线预烘焙** | Softmax 采样：P(i) ∝ exp(β×m_i×rel_i)，β 受 SAN+标签驱动 → 行为概率分布表 | 设计师创建 NPC 时，只跑一次 |
| **在线查表** | 当前回合情境 + NPC SAN 分段 → 查表 → 骰子 → 获得链路配置 | 每回合开始，一次 |

### 3.2 预烘焙管线

> **📝 2026-07-31 更新**：采样算法从 Monte Carlo 1000 次加权采样改为 **Softmax (Boltzmann 分布)**，β 参数受 SAN + 标签双重驱动。情境匹配改为**模型 A 分层门控**。详见 [预烘焙管线脚本设计](../../../管线/预烘焙管线脚本设计.md)。

```
设计师设定性格标签（6 选 1-3）
  → 标签 → 链路髓鞘化偏移 + 连带偏移（共享脑区自动计算） → 完整髓鞘化分布
  → 对 27 情境原型 × 3+ SAN 分段，计算每条链路的 Softmax 概率:
    P(link_i) ∝ exp(β × m_i × rel_i)
    其中 β = clamp(β_base(SAN) + Σ β_tag_mod, 0.1, 5.0)
        rel 按模型 A 分层门控 (L0=2.0, L1=1.5, L2=1.3, L3+×ε)
  → 不放回多选 (Luce's choice axiom)，激活点预算 + 槽位梯度约束
  → 聚合为配置级概率分布表（≥1% 截断）
  → 运行时查表
```

### 3.3 在线查表流程

```
每回合开始:
  1. 情境系统确定当前回合的主导情境原型
  2. 读取 NPC 当前 SAN 分段
  3. 查预烘焙表: (情境, SAN分段) → 概率分布
  4. 从分布中采样 → 获得本回合激活的链路配置
  5. 链路配置 → 调制基础行动 → M1/Broca 输出结算
```

### 3.4 响应速度

| 响应类型 | 时机 | 机制 |
|---------|------|------|
| **反射级（L0-L2）** | **同回合** | 情境标签即时更新 → 重新查表（仅 L0-L2 自动激活部分） |
| **策略级（L3-L6）** | **下回合** | 下回合情境更新 → 重新查表（全链路配置） |

神经科学理由：L0-L2 是快速路径（脑干→边缘系统，~10ms），L5-L6 需数百 ms 到数秒——反射立即调整，策略需要"想一下"。

### 3.5 查表频率

每回合一次。情境可能因玩家行为、NPC 自身状态变化、η 变化而跨回合切换，NPC 行为随之切换。

## 四、性格模板与偏离

### 4.1 六个链路群标签

从 L1-L2（边缘/旁边缘）的核心功能导出，覆盖大多数精神病理的回路基础：

| # | 标签 | 链路群 | 游戏表现 |
|---|------|--------|---------|
| 1 | **敏化-威胁** | 杏仁核+前脑岛→PAG/脑干 | 过度警觉，容易恐惧逃离 |
| 2 | **敏化-奖励** | VTA→NAcc/壳核 | 冲动趋近，成瘾倾向 |
| 3 | **抑制不足** | dlPFC→杏仁核/纹状体抑制链路弱 | 自控差，无法压制冲动 |
| 4 | **过度抑制** | dlPFC 控制链路全部过高 | 抑制一切——不说话、不动、情感淡漠 |
| 5 | **反刍** | 默认网络（后扣带+vmPFC）髓鞘化过高 | 关不掉的内在世界 |
| 6 | **社交钝化** | 颞极/mPFC/STS 社会认知链路髓鞘化过低 | 不理解社交线索，不回应 |

### 4.2 标签的偏离参数

| 参数 | 值 | 理由 |
|------|-----|------|
| 每个标签覆盖链路数 | 3-8 条 | 足够产生行为差异，不糊成一片 |
| 主偏移量（正向偏离） | +0.3 ~ +0.5 | 从"有时选"变为"经常选" |
| 主偏移量（负向偏离） | -0.3 ~ -0.5 | 从"有时选"变为"几乎不选" |
| 连带偏移 | ±0.1 ~ ±0.2 | 链路非孤立——敏化杏仁核会轻微影响相关评估链路 |
| 多标签叠加规则 | 取最大值（不累加） | 避免叠加推至 m=1.0 |

### 4.3 偏离粒度

三种粒度，设计师按需选用：

| 粒度 | 操作 | 适用场景 |
|------|------|---------|
| **链路群标签** | 选标签 → 批量偏移 | 默认方式——快速生成 NPC |
| **单条链路** | 在标签基础上覆盖特定链路的髓鞘化值 | 精细打磨 Boss |
| **拮抗对** | 设定拮抗链路的比值（如趋近/逃离 = 1:0.3） | 核心角色性格刻画 |

## 五、正常人模板与精神疾病

### 5.1 正常人模板

所有 NPC 从一个**分层基线**出发：

| 链路类型 | 正常髓鞘化范围 | 说明 |
|---------|--------------|------|
| 大多数日常链路 | m = 0.3-0.5 | 日常使用但不专精 |
| 个性差异链路 | ±0.2 | 有人偏焦虑、有人偏乐观——正常范围内的个体差异 |
| 极端浮现技能链路 | m ≈ 0 | 正常人不会动不动"赴汤蹈火" |

### 5.2 精神疾病 = 偏离

> RDoC（NIMH 研究框架）：精神疾病是脑回路的极端偏离，不是离散类别。
> p-factor 模型（Caspi et al.）：正常-亚临床-临床是连续谱。
> HiTOP：没有"正常 vs 异常"的清晰边界。

在游戏中，施加偏离标签即可模拟精神病理：

| 病理 | 标签组合 | 链路偏离 |
|------|---------|---------|
| PTSD | 敏化-威胁 + 抑制不足 | 杏仁核→PAG ↑, vmPFC→杏仁核抑制 ↓ |
| 抑郁（快感缺失） | 过度抑制 + 敏化-奖励(负) | VTA→NAcc ↓, dlPFC 控制 ↑ |
| 抑郁（反刍） | 反刍 + 过度抑制 | 默认网络 ↑, 运动输出 ↓ |
| 强迫症 | 敏化-威胁 + 抑制不足 | 纹状体-丘脑-皮层环路 ↑ |
| 躁狂 | 敏化-奖励 + 抑制不足 | VTA→NAcc ↑, dlPFC 抑制 ↓ |
| 精神分裂（阴性） | 社交钝化 + 过度抑制 | Broca 社交链路 ↓ |

### 5.3 链路模型不覆盖的边界

| 边界 | 覆盖层 |
|------|--------|
| 幻觉的具体内容（听到什么声音、看到什么） | 叙事/世界观层——链路决定"容易产生幻觉"，内容来自角色背景 |
| 妄想的具体信念 | 叙事/世界观层——链路决定"偏执解释倾向"，信念内容来自背景 |
| 发育性障碍（ASD） | 结构连接差异，非髓鞘化差异——需单独处理 |
| 纯粹神经递质异常 | 神经调质增益层（[链路调制上限参考表-v2](./调制参数/链路调制上限参考表-v2.md)），非髓鞘化层 |

## 六、NPC 类型

### 6.1 三类 NPC

| | 基础 NPC（杂兵） | 高级 NPC（感知型/Boss） | 友方 NPC |
|---|---|---|---|
| **感知能力** | 外在行为 | 外在行为 + L3/L4 揭露玩家内部 | 同基础 |
| **成长** | 无——静态模板 | 有——持久髓鞘化跨战斗延续 | 有 |
| **SAN 恢复（战斗内）** | 无 | 无 | 有（对称于玩家） |
| **SAN 恢复（脱战）** | 重置到预设值 | 重置到预设值 | 跨战斗延续 |
| **跨战斗记忆** | 无 | 有（见 §十一） | 有 |
| **持久髓鞘化** | 无——战斗间完全重置 | 有——使用即成长 | 有 |

### 6.2 基础 NPC（杂兵）

- 静态模板。每场战斗 SAN 和链路配置都重置到预设值。
- 所有同模板杂兵共用同一份预烘焙行为表。
- 被击败：HP=0 → 离开战斗 + 留尸体。

### 6.3 高级 NPC（Boss / 重要剧情角色）

- 持久髓鞘化跨战斗延续。和玩家同构：使用最频繁的链路获得髓鞘化潜能。
- 每次遭遇以满 SAN 开始（脱战恢复）。
- Boss 阶段切换 = 多套性格标签配置，HP/SAN 阈值触发切换。每套配置独立预烘焙。
- 被击败：HP=0 → 离开战斗 + 留尸体。特殊击败条件（击晕/控制等）以后再添加。

### 6.4 友方 NPC

- SAN 跨战斗延续，可被玩家治疗/SAN 恢复拉回。
- SAN=0 → 完全随机行为（见 §九）。
- HP=0 → 离开战斗。

## 七、行动生成

### 7.1 从链路配置到行动

NPC 没有独立的"行动选择模块"。查表获得的链路配置走和玩家**完全相同的结算管道**：

```
激活的链路配置
  → 链路调制基础行动（力道/精度/犹豫/附带效果）
  → 终端输出: M1（身体动作）或 Broca（语言）
```

见 [基础行动设计](./操作层/基础行动设计.md) 和 [L0-L6 各层技能设计](./操作层/) 中的结算规则。

### 7.2 目标选择

目标选择也走链路，不做单独的"选目标 AI"模块：

| 链路 | 目标偏向 |
|------|---------|
| 杏仁核→PAG 恐惧逃离 | 远离**当前威胁源**（情境威胁权重最大者） |
| VTA→NAcc 趋近 | 趋向**当前最高奖励值的目标**（最近/最弱/最高价值） |
| dlPFC→杏仁核 压制+评估 | 选择**有威胁但可压制的目标**（威胁/应对能力评估） |
| 社会认知链路（颞极/mPFC） | 优先**社交最显著的目标**（谁在说话/做表情/身份最高） |

多个链路同时激活 → 目标偏向加权和解。NPC 可能出现目标冲突（同时想逃离 A 又趋向 B），冲突解决取决于最强链路的髓鞘化程度。

### 7.3 NPC 位移

NPC 的移动方式待空间/关卡设计搭建后再定义。玩家位移 = 鼠标点击，NPC 位移 TBD。

## 八、多 NPC 协调

### 8.1 不设显式"团队 AI 层"

协调从现有机制自然涌现：

| 机制 | 效果 |
|------|------|
| **情境共享** | 同阵营 NPC 在同一情境下 → 倾向类似行为方向（髓鞘化模式不同产生有意义的分化） |
| **观察读出** | 社会认知链路感知同伴 M1/Broca 输出 → 自动行为调整 |
| **主动协调（Broca→Broca）** | NPC 用语言对同伴发出意图——**公开可听**（玩家可以偷听、利用、或被假命令欺骗） |

### 8.2 协调是连续谱

| 类型 | 表现 |
|------|------|
| 两个"敏化-威胁" | 同时恐惧逃离——0 协同，各自往不同方向跑 |
| 两个"社交强化型"（社交链路髓鞘化高） | 一个攻击时另一个自动补位/助攻——**1+1>2** |
| 社交强化 + 社交钝化 | 一方试图协调，另一方完全不理解——**1+1<2** |

### 8.3 同模板 NPC 分化

同一模板的多个 NPC 通过**5% 随机抖动（预烘焙表概率分布）+ 目标选择差异**自然产生行为分化。不需要额外"个体变异"参数。

## 九、SAN 与击败

### 9.1 NPC SAN 系统

NPC SAN 和玩家同构，但在恢复机制上有差异（见 §六）。

| SAN 区间 | 效果 |
|----------|------|
| SAN ≥ 60 | 槽位加成：+2（基础 4 + 2 = 6） |
| SAN 30-59 | 槽位：基础 4 + 1 = 5 |
| SAN < 30 | 恐慌——切换到"恐慌配置"预烘焙表，槽位不加成 |
| SAN = 0 | **完全随机行为**——从所有合法链路中完全随机激活，思维断裂、行为紊乱、不可预测但不等于无害 |

### 9.2 SAN=0 的随机行为

参考精神分裂症中的思维形式障碍（formal thought disorder）和紊乱行为（disorganized behavior）。NPC 不再受情境或性格模板约束，行为完全不可预测——可能意外触发危险链路组合，也可能完全瘫痪。

### 9.3 击败

- **击败条件**（默认）：HP = 0（物理压制）
- **击败结果**：留尸体
- **Boss 例外**：SAN=0 先进入随机行为阶段，HP=0 才真正击败
- 击晕/控制等其他击败条件以后添加

### 9.4 战斗开始时 SAN

| NPC 类型 | 初始 SAN |
|----------|---------|
| 杂兵 | 设计师预设值（满 SAN）——每场重置 |
| 重要 NPC | 满 SAN——每次遭遇重置（脱战迅速恢复） |
| 友方 NPC | 跨战斗延续 |

## 十、浮现式特殊技能

### 10.1 同条件，不同到达难度

NPC 和玩家使用**同一套浮现技能前置条件**（敌我同构）。见 [脑功能层级模型 §四.2](./脑功能层级模型.md)。

- NPC 因畸形髓鞘化可天然满足某些浮现技能的条件（如 PTSD 型 NPC 自动获得"恐惧专精"）
- 玩家达到同等配置需要艰苦的成长路径
- 重要 NPC 的浮现技能列表随髓鞘化成长而变化

### 10.2 设计含义

- 设计师在创建 NPC 时，脚本自动检测哪些浮现技能的前置条件被满足，生成该 NPC 的浮现技能列表
- 玩家用 L3/L4 感知技能揭露 NPC 时，可能发现它拥有某个浮现技能——披露了它的性格配置

## 十一、记忆与跨战斗持久化

### 11.1 记忆什么

| NPC 类型 | 跨战斗记忆 |
|---------|-----------|
| **杂兵** | 无——每次都像第一次见面 |
| **重要 NPC** | 上次战斗中的玩家**外在行为输出**（用了什么行动、说了什么话） |
| **重要 NPC** | 上次战斗中被玩家成功压制的链路 → 下次见面时对应防御链路的髓鞘化 +0.1 |

### 11.2 不能记忆什么

- 玩家的内部链路配置（NPC 看不到，不能记忆）
- 玩家的 SAN 精确值（只能感知是否 < 30 的恐慌外在表现）

### 11.3 重要 NPC 成长的玩家后果

- 重复使用同一策略 → NPC 越来越有抗性（防御链路髓鞘化增加）
- 玩家换套路 → NPC 需要重新适应
- NPC 髓鞘化成长方向和玩家同构——使用即增长

## 十二、设计师工作流

### 12.1 必需步骤（4 步）

| 步骤 | 操作 | 复杂度 |
|------|------|--------|
| 1 | **选性格标签**：从 6 个中选 1-3 个（或组合以产生复杂性格） | 低 |
| 2 | **设 SAN 基线**：默认 50，可调 | 低 |
| 3 | **选角色类别**：基础 NPC / 高级 NPC（有感知链路）/ 友方 NPC | 低 |
| 4 | **勾选浮现技能**：如有满足前置条件的浮现技能，勾选启用 | 中 |

### 12.2 脚本自动完成

- 标签 → 髓鞘化偏移 → 完整髓鞘化分布
- 髓鞘化分布 + SAN 基线 + 角色类别 → 预烘焙 27 情境 × 3+ SAN 分段行为表
- 满足条件的浮现技能列表

### 12.3 可选手动覆盖

- 逐链路调整髓鞘化（精细打磨 Boss）
- 特定情境下的强制行为（"SAN<30 一定逃跑，不随机"）
- 添加病理标签（强迫症/躁狂/PTSD 等——特定链路的冲突激活）

## 十三、性能考量

| 层面 | 方案 | 运行时成本 |
|------|------|-----------|
| 行为选择 | 预烘焙表查表 | 一次查表 + 一次骰子——几乎零 |
| 槽位约束 | 编码在烘焙结果中 | 零 |
| 链路→行动结算 | 和玩家端相同管道 | 和 1 个玩家同成本 |
| 杂兵数量 | 所有同模板杂兵共用一份预烘焙表 | O(1) 查表 × N 个独立骰子 |
| 多 NPC 协调 | 自然涌现（无外加层） | 零 |
| 预烘焙离线时间 | 每模板 × 27 × 3 Softmax 计算 | ≤ 秒级（纯 Python） |
