## 一、设计原则

1. **敌我同构**：NPC 和玩家共用同一套三体神经模型（CSTC 环路 + 皮层-皮层 + 脑干广播）、69 functional_id 节点 WC 动力学、SAN/HP 体系。NPC 的特殊性来自参数偏移，不来自独立系统。
2. **Affordance Competition 行动选择**：NPC 的行动选择从 WC 动力学 + CSTC 门控 + 脑干 tone 调制中自然涌现，无需离线预烘焙或独立决策公式。选择机制锚定 Cisek (2007) affordance competition 框架 + GPR (2001) 去抑制选择模型。
3. **性格 = tone baseline + CSTC 偏置**：NPC 的性格由 4 个脑干 tone 的静息基线 + 3 个 CSTC 环路偏置参数化。保留 6 个概念标签作为设计师界面，底层映射到 tone/CSTC 参数。不引入 Big Five 等外部人格框架。
4. **疾病 = 连续谱**：精神疾病从正常人参数的极端偏离导出（RDoC/p-factor/HiTOP 框架背书方向），没有"正常 vs 异常"的清晰边界。
5. **选择即动力学**：NPC 不设独立的 AI 决策层。行动 salience 从与玩家共享的 WC+CSTC+tone 状态中实时计算，affordance competition 的获胜者即 NPC 的回合行动。

## 二、感知与信息

### 2.1 感知边界

| 类型 | 可感知 | 不可感知 |
|------|--------|---------|
| **基础 NPC** | 玩家的外在行为输出（M1 身体动作 + Broca 语言输出） | 玩家内部链路配置、当前激活节点、SAN 精确值 |
| **高级 NPC**（有 L3/L4 感知链路） | 同上 + 部分揭露玩家链路/激活/SAN | 揭露程度取决于其感知链路的髓鞘化程度（连续谱） |
| **友方 NPC** | 与基础 NPC 相同 | 同基础 NPC |

### 2.2 感知通道

同构于玩家，NPC 有两个自然感知通道：

| 通道 | 神经基础 | 游戏表现 |
|------|---------|---------|
| **观察读出** | 社会认知链路（颞极/mPFC/STS）——感知 M1/Broca 输出 | NPC 看到同伴/玩家在做什么，自动调整 |
| **听觉/语言** | 颞横回→颞上回→Broca 解码 | NPC 听到的语音（包括玩家和同伴的战术沟通） |

### 2.3 信息不对称

- **玩家大脑对 NPC 不可见**：玩家内部链路配置、激活节点、SAN 精确值——NPC 默认看不到
- **NPC 大脑对玩家不可见**：见 §七（3D 大脑 UI），仅在玩家用 L3/L4 感知技能时部分揭露
- **例外**：高级 NPC 有 L3/L4 感知链路时可以部分"读心"——和玩家端感知技能同构

## 三、行为决策：Affordance Competition 模型

> **⚠️ 旧预烘焙模型已废弃（2026-08-09）**：离线 Softmax `P(i) ∝ exp(β × m_i × rel_i)` 公式基于旧 pairwise 364 链路模型。旧预烘焙管线（`管线/预烘焙管线脚本设计.md`）架构已过时，使用的 `link_NNN` ID 和 `rel` 字段在三体模型中不存在。

### 3.1 核心理念

NPC 不单独运行一套"决策引擎"。行动选择从与玩家共享的神经动力学中**自然涌现**——Cisek (2007) 的 affordance competition 框架：多个潜在动作在皮层中**并行指定**，通过相互抑制**竞争**，基底节 + 脑干调质提供**偏置**，胜出者即行动。

| Cisek 框架 | 我们的实现 |
|-----------|-----------|
| 额顶皮层并行指定多个动作 | 69 functional_id 节点 WC 动力学——多节点同时活跃 |
| 皮层内相互抑制竞争 | WC 方程 W·a 项 + 归一化——隐式竞争（解剖 W 矩阵非显式抑制结构） |
| BG 偏置皮质竞争 | Layer 3 CSTC 3 环路 gate_bonus——体/认知/边缘域偏置 |
| 神经调质全局调制 | Layer 2 脑干广播 4 tone——NE/DA_VTA/DA_SNc/5HT |

**关键文献锚点：**

| 主张 | 文献 |
|------|------|
| 行动指定与选择并行，非串行（感知→决策→行动） | Cisek (2007) Phil Trans R Soc B; Cisek & Kalaska (2010) Ann Rev Neurosci |
| BG 偏置皮质竞争，非独立选择器 | Cisek (2007) §3 — "the competition is biased by input from the basal ganglia and prefrontal regions" |
| BG 通过去抑制实现选择（GO/NO-GO/STOP） | Gurney, Prescott & Redgrave (2001) Biol Cybern — 已在运行时状态模型 Layer 3 实现 |
| NE 调节 exploit/explore，phasic=专注/tonic=扫描 | Aston-Jones & Cohen (2005) Ann Rev Neurosci |
| DA 编码奖赏预测误差，驱动趋近 | Schultz, Dayan & Montague (1997) Science |
| 5HT 抑制冲动，与 DA 拮抗 | Daw, Kakade & Dayan (2002) Neural Networks |

### 3.2 从动力学到行动选择

NPC 的每回合行动选择 = **读取 affordance competition 的获胜者**。不需要离线预烘焙——salience 从当前回合的 WC+CSTC+tone 状态实时计算。

```
每回合 Phase 1 后 (tone + a(t) + gate 已更新):

对每个可用技能 i:
  Salience_i = mean(a_j(t)  for j ∈ skill_i.cortical_nodes)   ← 皮层并行指定 (Cisek 2007)
             × gate_bonus(skill_i.role)                        ← BG 域偏置 (Cisek 2007; GPR 2001)
             × (1 + tone_bias(skill_i.role))                   ← 神经调质全局偏置 (Aston-Jones 2005; Schultz 1997)

NPC 行动 = argmax_i Salience_i                          (确定性)
       或 ~ Softmax_i P(i) ∝ exp(Salience_i / T)       (概率性, T = 采样温度)
```

**每项的文献锚点：**

| 项 | 计算 | 文献来源 | 在我们模型中 |
|----|------|---------|-----------|
| `mean(a_j)` | 技能支持皮层节点的平均激活 | Cisek (2007): "multiple potential actions are specified in parallel within the fronto-parietal cortex" | 运行时状态模型 §四 Layer 1 WC 动力学, 69 节点 a(t) |
| `gate_bonus(role)` | 技能角色对应的 CSTC 环路 gate | GPR (2001): 去抑制选择; Cisek (2007): "BG biases cortical competition" | 运行时状态模型 §六 Layer 3 CSTC 门控, 3 环路 gate |
| `tone_bias(role)` | 脑干调质对行为域的偏置 | Aston-Jones (2005): NE→explore/exploit; Schultz (1997): DA→approach; Daw (2002): 5HT→inhibition | 运行时状态模型 §五 Layer 2 脑干广播, 4 tone |

### 3.3 tone_bias 计算

tone 对行为域的偏置基于各神经调质在行为控制中的已知角色：

```
tone_bias(role) = Σ_t w_t(role) × (tone_t − baseline_t)
```

其中 `(tone_t − baseline_t)` 是当前 tone 偏离其静息基线的量——tone 处于基线时 tone_bias=0，选择由 WC+CSTC 主导。

| 行为角色 | NE 权重 | DA_VTA 权重 | DA_SNc 权重 | 5HT 权重 | 文献依据 |
|---------|---------|------------|------------|---------|---------|
| perceive | +0.5 | 0 | 0 | 0 | NE→警觉/注意增强 (Aston-Jones 2005) |
| attack_physical | 0 | +0.3 | +0.5 | −0.3 | DA_VTA→动机趋近 (Schultz 1997); DA_SNc→运动启动; 5HT↓→冲动释放 (Daw 2002) |
| attack_mental | 0 | +0.4 | 0 | −0.3 | DA_VTA→认知动机; 5HT↓→社交去抑制 |
| defend | +0.4 | −0.2 | 0 | +0.4 | NE→威胁警觉; 5HT→行为抑制/忍耐; DA↓→回避 |
| approach | 0 | +0.5 | +0.2 | −0.3 | DA_VTA→奖赏趋近 (Schultz 1997); 5HT↓→冲动 |
| flee | +0.5 | −0.3 | 0 | −0.2 | NE→高唤醒恐惧; DA↓→回避; 5HT↓→恐慌逃离 |
| disrupt | 0 | +0.2 | 0 | −0.3 | 弱 DA 趋近（社会干扰）+ 5HT↓去抑制 |
| support | 0 | 0 | 0 | +0.3 | 5HT→亲社会行为/耐心 (Daw 2002; Crockett et al. 2009) |

> **设计层**：权重符号方向来自文献（NE→警觉/防御, DA→趋近/行动, 5HT→抑制/忍耐），具体数值 (±0.2~±0.5) 为设计校准层——后续数值校准中调整。

### 3.4 Softmax 选择

**确定性** (`argmax`)：Boss/重要 NPC 使用——行为一致，可预测，玩家可学习对抗。

**概率性** (`Softmax`)：基础 NPC/杂兵使用——行为有变化，不完全可预测。

```
P(i) ∝ exp( Salience_i / T )

T = T_base + T_SAN
  T_base = 0.15（默认——允许适度探索但不完全随机）
  T_SAN:
    SAN% ≥ 60% → +0（最确定——理性选择）
    SAN% 30-59% → +0.10（中等噪声）
    SAN% < 30% → +0.30（高噪声——恐慌）
    SAN = 0 → T = ∞ → 均匀随机（思维断裂——完全不可预测）
```

**设计理由**：SAN 下降 → 温度升高 → 行为更随机——这是精神病理学中"认知紊乱随应激增加"的直接游戏化。SAN=0 时温度→∞对应旧模型 §9.2 的"完全随机行为"。

### 3.5 响应速度

| 响应类型 | 时机 | 机制 |
|---------|------|------|
| **反射级** | **同回合** | tone 事件的 δ_event 冲击即时改变 tone → tone_bias 即时偏移 → 同回合重算 salience |
| **策略级** | **下回合** | 完整 WC 动力学步进（τ=0.01-0.15s, Δ=1s）→ a(t+1) 变化 → salience 变化 |

神经科学理由（同旧模型）：L0-L2 脑干/边缘系统 ~10ms 快速路径——反射即时调整。皮层 WC 节点 τ 慢——策略需要"想一下"。

### 3.6 与玩家路径的对比

| | 玩家 | NPC |
|---|------|-----|
| Phase 1 情境更新 | 同：tone + WC + CSTC 全部更新 | 同 |
| a(t), gate, tone 计算 | 同——共享动力学 | 同——共享动力学 |
| Phase 4 行动选择 | **手动**：玩家从 3D 技能树 + 快捷槽选技能 | **自动**：affordance competition salience → argmax/Softmax |
| 技能效果结算 | 同——`skill_effect × gate_bonus(role)` | 同 |
| 可塑性巩固 | 玩家手动标记 + 经历驱动 | NPC 使用即成长（同构） |

**NPC 不需要额外模拟——它和玩家跑同一套动力学。区别只在 Phase 4：玩家手动选技能，系统替 NPC 自动选。**

### 3.7 性能考量

| 层面 | 成本 |
|------|------|
| WC 动力学 | 与玩家共享——69 节点 × 1 回合 = 已支付 |
| CSTC gating | 与玩家共享——3 环路 Gurney = 已支付 |
| Salience 计算 | 每 NPC × 每技能 × O(技能节点数)，≤ 毫秒级 |
| Softmax | 每 NPC 一次归一化，≤ 微秒级 |
| **总额外成本** | **接近零**——salience 计算从已存在的 a(t)/gate/tone 派生 |

对比旧预烘焙模型：离线烘焙 27 情境 × 3+ SAN 分段 → 运行时 O(1) 查表。新模型运行时成本同样接近零（几次浮点乘加），**但不需要离线烘焙**——消除了旧管线维护负担。

## 四、NPC 参数化

> **⚠️ 旧 6 标签链路群模型已废弃（2026-08-09）**：旧模型的"性格标签→链路群 m 偏移"使用 `link_NNN` ID（pairwise 旧模型），在三体模型中不存在。旧 `personality_tag_links.json` 全部 `auto_generated: true`，基于已废弃的旧链路 ID。详见 [personality_tag_links.json](../../data/connectivity/personality_tag_links.json)。

### 4.1 参数空间

NPC 性格由 7 个连续参数定义——全部从三体模型的动力学中自然导出：

| # | 参数 | 类型 | 值域 | 动力学角色 |
|---|------|------|------|-----------|
| 1 | NE_baseline | float | [0, 1] | 蓝斑去甲肾上腺素静息水平——基线警觉度 |
| 2 | DA_VTA_baseline | float | [0, 1] | VTA 多巴胺静息水平——基线动机/奖赏敏感度 |
| 3 | DA_SNc_baseline | float | [0, 1] | 黑质多巴胺静息水平——基线运动启动倾向 |
| 4 | 5HT_baseline | float | [0, 1] | 中缝核血清素静息水平——基线冲动控制 |
| 5 | bias_somatic | float | [-0.3, +0.3] | CSTC 躯体环路 gate 偏置——物理行动倾向 |
| 6 | bias_cognitive | float | [-0.3, +0.3] | CSTC 认知环路 gate 偏置——语言/认知行动倾向 |
| 7 | bias_limbic | float | [-0.3, +0.3] | CSTC 边缘环路 gate 偏置——情绪/本能行动倾向 |

> **bias 生效方式**：`gate_loop_effective = gate_loop + bias_loop`（clamp [0, 1]），在 §3.2 salience 计算中替代原始 gate_bonus。bias 是 NPC 的 CSTC 结构性偏移——不随时间变化（不像 gate 随 Gurney 动力学每回合波动）。

**正常人默认值**（运行时状态模型 §5.4 + §7.3）：

| 参数 | 默认 | 说明 |
|------|------|------|
| NE_baseline | 0.3 | 正常警觉 |
| DA_VTA_baseline | 0.4 | 中等动机 |
| DA_SNc_baseline | 0.5 | 运动顺畅 |
| 5HT_baseline | 0.5 | 正常冲动控制 |
| bias_somatic | 0 | 无躯体偏置 |
| bias_cognitive | 0 | 无认知偏置 |
| bias_limbic | 0 | 无边缘偏置 |

### 4.2 6 标签设计师界面

设计师仍可使用 6 个概念标签——底层自动映射到 7 参数。标签是**设计简写**，不是独立系统。

| # | 标签 | 游戏表现 | → tone 效果 | → CSTC 偏置 | 文献依据 |
|---|------|---------|------------|-------------|---------|
| 1 | **敏化-威胁** | 过度警觉，容易恐惧逃离 | NE_baseline +0.2, 5HT_baseline −0.2 | bias_limbic +0.15 | Shin & Liberzon (2010): PTSD 杏仁核过度反应 + NE 高唤醒 |
| 2 | **敏化-奖励** | 冲动趋近，成瘾倾向 | DA_VTA_baseline +0.2, 5HT_baseline −0.2 | bias_limbic +0.15 | Robinson & Berridge (1993): incentive sensitization — DA 对奖赏线索过度敏化 |
| 3 | **抑制不足** | 自控差，无法压制冲动 | 5HT_baseline −0.2 | bias_somatic +0.15 | Soubrié (1986): 5HT 行为抑制假说 — 低 5HT → 去抑制 |
| 4 | **过度抑制** | 不说话、不动、情感淡漠 | 5HT_baseline +0.2 | bias_somatic −0.15 | Crockett et al. (2009): 5HT 增强惩罚诱导的行为抑制 |
| 5 | **反刍** | 关不掉的内在世界 | NE_baseline −0.1（内转——降低外部警觉） | bias_cognitive +0.15 | Hamilton et al. (2015): 抑郁症 DMN 过度连接——内在思维主导 |
| 6 | **社交钝化** | 不理解社交线索，不回应 | —（无显著 tone 偏移） | bias_cognitive −0.15 | Green et al. (2015): 精神分裂症社会认知缺损——社会脑网络低激活 |

> **设计层**：标签→参数的具体偏移量 (±0.1~±0.2) 为设计校准层——符号方向有文献支撑，幅值在后续数值校准中调整。多标签叠加取最大值（同旧模型规则），clamp 到参数值域内。

**标签选择建议**（同旧模型）：设计师选 1-3 个标签。超过 3 个 → 参数几乎退回默认（多标签最大值叠加互相抵消）。

### 4.3 偏离粒度

三种粒度（保留旧模型的三级结构）：

| 粒度 | 操作 | 适用场景 |
|------|------|---------|
| **概念标签** | 选标签 → 自动映射到 7 参数 | 默认方式——快速生成 NPC |
| **参数直调** | 在标签基础上手动覆盖 7 参数的具体值 | Boss / 重要剧情角色精细打磨 |
| **节点 m 直调** | 覆盖特定 functional_id 节点对应皮层连接的 m 值 | 极端独特的浮现技能配置 |

**第 3 级（节点 m 直调）的实现**：NPC 拥有独立的 `W_npc` 矩阵（从 tripartite_model.json CC 连接派生，m 不同 → W 不同）。player/NPC 共享同一套动力学方程，但各自的 W 矩阵不同——这就是敌我同构下的个体差异。默认 NPC 使用 `m_default = 0.3`（运行时状态模型 §4.3），标签只改变 tone baseline + CSTC bias。节点 m 直调是最高粒度的覆盖。

## 五、正常人模板与精神疾病

### 5.1 正常人模板

所有 NPC 从一个**分层基线**出发：

| 链路类型 | 正常髓鞘化范围 | 说明 |
|---------|--------------|------|
| 大多数日常链路 | m = 0.3-0.5 | 日常使用但不专精 |
| 个性差异链路 | ±0.2 | 有人偏焦虑、有人偏乐观——正常范围内的个体差异 |
| 极端浮现技能链路 | m ≈ 0 | 正常人不会动不动"赴汤蹈火" |

### 5.2 精神疾病 = 偏离

> RDoC（NIMH 研究框架）：精神疾病是脑回路的极端偏离，不是离散类别。
> p-factor 模型（Caspi et al.）：正常-亚临床-临床是连续谱。
> HiTOP：没有"正常 vs 异常"的清晰边界。

在游戏中，施加偏离标签即可模拟精神病理：

| 病理 | 标签组合 | 链路偏离 |
|------|---------|---------|
| PTSD | 敏化-威胁 + 抑制不足 | 杏仁核→PAG ↑, vmPFC→杏仁核抑制 ↓ |
| 抑郁（快感缺失） | 过度抑制 + 敏化-奖励(负) | VTA→NAcc ↓, dlPFC 控制 ↑ |
| 抑郁（反刍） | 反刍 + 过度抑制 | 默认网络 ↑, 运动输出 ↓ |
| 强迫症 | 敏化-威胁 + 抑制不足 | 纹状体-丘脑-皮层环路 ↑ |
| 躁狂 | 敏化-奖励 + 抑制不足 | VTA→NAcc ↑, dlPFC 抑制 ↓ |
| 精神分裂（阴性） | 社交钝化 + 过度抑制 | Broca 社交链路 ↓ |

### 5.3 链路模型不覆盖的边界

| 边界 | 覆盖层 |
|------|--------|
| 幻觉的具体内容（听到什么声音、看到什么） | 叙事/世界观层——链路决定"容易产生幻觉"，内容来自角色背景 |
| 妄想的具体信念 | 叙事/世界观层——链路决定"偏执解释倾向"，信念内容来自背景 |
| 发育性障碍（ASD） | 结构连接差异，非髓鞘化差异——需单独处理 |
| 纯粹神经递质异常 | 神经调质增益层（[链路调制上限参考表-v2](./调制参数/链路调制上限参考表-v2.md)），非髓鞘化层 |

## 六、NPC 类型

### 6.1 三类 NPC

| | 基础 NPC（杂兵） | 高级 NPC（感知型/Boss） | 友方 NPC |
|---|---|---|---|
| **感知能力** | 外在行为 | 外在行为 + L3/L4 揭露玩家内部 | 同基础 |
| **成长** | 无——静态模板 | 有——持久髓鞘化跨战斗延续 | 有 |
| **SAN 恢复（战斗内）** | 无 | 无 | 有（对称于玩家） |
| **SAN 恢复（脱战）** | 重置到预设值 | 重置到预设值 | 跨战斗延续 |
| **跨战斗记忆** | 无 | 有（见 §十一） | 有 |
| **持久髓鞘化** | 无——战斗间完全重置 | 有——使用即成长 | 有 |

### 6.2 基础 NPC（杂兵）

- 静态模板。每场战斗开始时 tone 和 a(t) 重置到预设基线。
- 所有同模板杂兵共用同一组 7 参数化性格（4 tone baseline + 3 CSTC bias）。
- 被击败：HP=0 → 离开战斗 + 留尸体。

### 6.3 高级 NPC（Boss / 重要剧情角色）

- 持久髓鞘化跨战斗延续。和玩家同构：使用最频繁的链路获得髓鞘化潜能。
- 每次遭遇以满 SAN 开始（脱战恢复）。
- Boss 阶段切换 = 多套 7 参数化性格配置（tone baseline + CSTC bias），HP/SAN 阈值触发切换。
- 被击败：HP=0 → 离开战斗 + 留尸体。特殊击败条件（击晕/控制等）以后再添加。

### 6.4 友方 NPC

- SAN 跨战斗延续，可被玩家治疗/SAN 恢复拉回。
- SAN=0 → 完全随机行为（见 §九）。
- HP=0 → 离开战斗。

## 七、行动生成

### 7.1 从 Salience 到行动

NPC 没有独立的"行动选择模块"。§三 affordance competition 选出技能后，走和玩家**完全相同的结算管道**：

```
Salience winner → 技能
  → WC 动力学 a(t) 调制基础行动（力道/精度/犹豫/附带效果）
  → gate_bonus × 技能基础效果 → 最终伤害/buff/debuff
  → 终端输出: M1（身体动作）或 Broca（语言）
```

见 [基础行动设计](./操作层/基础行动设计.md) 和 [各层技能设计](./操作层/) 中的结算规则。

> **⚠️ 旧模型残余清除**：§7.1 原文"激活的链路配置 → 链路调制基础行动"基于旧 pairwise 链路模型。行动生成现在走 WC 节点 a(t) + gate_bonus → 技能效果结算（运行时状态模型 §八）。

### 7.2 目标选择

目标选择同样从动力学涌现——不做单独的"选目标 AI"模块。每个候选目标的**目标 salience** 从 NPC 当前 WC 节点激活中计算：

| 机制 | 对应节点/环路 | 目标偏向 |
|------|-------------|---------|
| 恐惧/威胁评估 | 杏仁核 + 前脑岛 a(t) → limbic gate | 远离**威胁 salience 最高者**（最近/最强/最威胁） |
| 奖赏趋近 | NAcc + VTA 相关 a(t) → limbic gate | 趋向**奖赏 salience 最高者**（最弱/最近/最高掉落） |
| 认知压制 | dlPFC + ACC 相关 a(t) → cognitive gate | 选择**有威胁但可压制者**（威胁/应对能力比） |
| 社交突显 | 颞极/mPFC/STS 相关 a(t) → cognitive gate（感知 bypass） | 优先**社交最显著者**（谁在说话/做表情/身份最高） |

**目标 salience 竞争**：每个候选目标的 salience = 上述节点群的 a(t) 均值 × 该目标对应的 gate × tone_bias。**NPC 选择目标 = argmax 目标 salience**。多偏向同时激活 → 加权和解——NPC 可能出现目标冲突（同时想逃离 A 又趋向 B），冲突解决取决于最强节点群。

### 7.3 NPC 位移

NPC 的移动方式待空间/关卡设计搭建后再定义。玩家位移 = 鼠标点击，NPC 位移 TBD。

## 八、多 NPC 协调

### 8.1 不设显式"团队 AI 层"

协调从现有机制自然涌现：

| 机制 | 效果 |
|------|------|
| **情境共享** | 同阵营 NPC 在同一情境下 → 倾向类似行为方向（髓鞘化模式不同产生有意义的分化） |
| **观察读出** | 社会认知链路感知同伴 M1/Broca 输出 → 自动行为调整 |
| **主动协调（Broca→Broca）** | NPC 用语言对同伴发出意图——**公开可听**（玩家可以偷听、利用、或被假命令欺骗） |

### 8.2 协调是连续谱

| 类型 | 表现 |
|------|------|
| 两个"敏化-威胁" | 同时恐惧逃离——0 协同，各自往不同方向跑 |
| 两个"社交强化型"（社交链路髓鞘化高） | 一个攻击时另一个自动补位/助攻——**1+1>2** |
| 社交强化 + 社交钝化 | 一方试图协调，另一方完全不理解——**1+1<2** |

### 8.3 同模板 NPC 分化

同一模板的多个 NPC 通过**5% 随机抖动（salience 概率分布）+ 目标选择差异**自然产生行为分化。不需要额外"个体变异"参数。

## 九、SAN 与击败

### 9.1 NPC SAN 系统

NPC SAN 和玩家同构，但在恢复机制上有差异（见 §六）。

| SAN 区间 | 效果 |
|----------|------|
| SAN% ≥ 60% | 聚焦容量 +2（基础 4 + 2 = 6） |
| SAN% 30-59% | 聚焦容量 +1（基础 4 + 1 = 5） |
| SAN% < 30% | 恐慌——切换到"恐慌配置"参数组（tone NE↑, 5HT↓），聚焦容量不加成 |
| SAN = 0 | **完全随机行为**——从所有合法链路中完全随机激活，思维断裂、行为紊乱、不可预测但不等于无害 |

### 9.2 SAN=0 的随机行为

参考精神分裂症中的思维形式障碍（formal thought disorder）和紊乱行为（disorganized behavior）。NPC 不再受情境或性格模板约束，行为完全不可预测——可能意外触发危险链路组合，也可能完全瘫痪。

### 9.3 击败

- **击败条件**（默认）：HP = 0（物理压制）
- **击败结果**：留尸体
- **Boss 例外**：SAN=0 先进入随机行为阶段，HP=0 才真正击败
- 击晕/控制等其他击败条件以后添加

### 9.4 战斗开始时 SAN

| NPC 类型 | 初始 SAN |
|----------|---------|
| 杂兵 | 设计师预设值（满 SAN）——每场重置 |
| 重要 NPC | 满 SAN——每次遭遇重置（脱战迅速恢复） |
| 友方 NPC | 跨战斗延续 |

## 十、浮现式特殊技能

### 10.1 同条件，不同到达难度

NPC 和玩家使用**同一套浮现技能前置条件**（敌我同构）。见 [脑功能层级模型 §四.2](./脑功能层级模型.md)。

- NPC 因畸形髓鞘化可天然满足某些浮现技能的条件（如 PTSD 型 NPC 自动获得"恐惧专精"）
- 玩家达到同等配置需要艰苦的成长路径
- 重要 NPC 的浮现技能列表随髓鞘化成长而变化

### 10.2 设计含义

- 设计师在创建 NPC 时，脚本自动检测哪些浮现技能的前置条件被满足，生成该 NPC 的浮现技能列表
- 玩家用 L3/L4 感知技能揭露 NPC 时，可能发现它拥有某个浮现技能——披露了它的性格配置

## 十一、记忆与跨战斗持久化

### 11.1 记忆什么

| NPC 类型 | 跨战斗记忆 |
|---------|-----------|
| **杂兵** | 无——每次都像第一次见面 |
| **重要 NPC** | 上次战斗中的玩家**外在行为输出**（用了什么行动、说了什么话） |
| **重要 NPC** | 上次战斗中被玩家成功压制的链路 → 下次见面时对应防御链路的髓鞘化 +0.1 |

### 11.2 不能记忆什么

- 玩家的内部链路配置（NPC 看不到，不能记忆）
- 玩家的 SAN 精确值（只能感知是否 < 30% 的恐慌外在表现）

### 11.3 重要 NPC 成长的玩家后果

- 重复使用同一策略 → NPC 越来越有抗性（防御链路髓鞘化增加）
- 玩家换套路 → NPC 需要重新适应
- NPC 髓鞘化成长方向和玩家同构——使用即增长

## 十二、设计师工作流

### 12.1 必需步骤（4 步）

| 步骤 | 操作 | 复杂度 |
|------|------|--------|
| 1 | **选概念标签（设计师简写）**：从 6 个中选 1-3 个（或组合以产生复杂性格） | 低 |
| 2 | **设 SAN 基线**：默认 50，可调 | 低 |
| 3 | **选角色类别**：基础 NPC / 高级 NPC（有感知链路）/ 友方 NPC | 低 |
| 4 | **勾选浮现技能**：如有满足前置条件的浮现技能，勾选启用 | 中 |

### 12.2 脚本自动完成

- 概念标签 → tone baseline + CSTC bias 参数
- 参数 + SAN 基线 + 角色类别 → Affordance Competition salience 计算（运行时，无需离线烘焙）
- 满足条件的浮现技能列表

### 12.3 可选手动覆盖

- 逐链路调整髓鞘化（精细打磨 Boss）
- 特定情境下的强制行为（"SAN<30% 一定逃跑，不随机"）
- 添加病理标签（强迫症/躁狂/PTSD 等——特定链路的冲突激活）

## 十三、性能考量

| 层面 | 方案 | 运行时成本 |
|------|------|-----------|
| 行为选择 | Affordance Competition salience 计算 | mean(a_j) × gate × (1+tone_bias)——几次浮点乘加 |
| 聚焦容量约束 | 编码在 salience 公式中 | 零 |
| 链路→行动结算 | 和玩家端相同管道 | 和 1 个玩家同成本 |
| 杂兵数量 | 所有同模板杂兵共用同一组参数 | O(1) 参数 × N 个独立 salience 计算 |
| 多 NPC 协调 | 自然涌现（无外加层） | 零 |
| 无需离线烘焙 | Affordance Competition 运行时计算 | 零（消除了旧管线的离线计算负担） |
