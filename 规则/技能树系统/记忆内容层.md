# 记忆内容层（MemoryRecord）

## 一、定位与边界

### 1.1 三层分离

| Issue | 管什么 |
|-------|--------|
| #87（生成功能） | 创伤记忆语义 + 人际层内容源 → 产出叙事层创伤记忆 |
| **#90（本文档）** | 内容层**数据结构**（schema）/ 存储位置 / 写入管线 / 检索接口 / 生命周期 |
| #88（转化规则） | 创伤记忆语义 → 病理链路 m 偏移（量化合成） |

### 1.2 黑箱语义（#90-D3）

记忆内容层**不调用海马内部结构**：

- 不建 CA3 回返网络、不引 DG 数据（DK 图谱无亚区分割，CA1/CA3 共享 1 个 OBJ）
- 内容层公式**零解剖数据依赖**——不读 brain_regions.json / tripartite_model.json
- 引擎侧对海马维持正典现状（limbic 环路输入节点 + θ_mem MTL 激活均值）
- 海马内部环路建模 = **推迟项**（未来需 CA3 精细建模时单开 issue，不阻塞本文档）

### 1.3 内容层与权重层分离（#90 澄清修正）

记忆内容**完全由记录承载**，无皮层副本、**不写 m**：

- m = 三体模型边的髓鞘化权重因子（独立机制，非记忆存储，`运行时状态模型.md` §九）
- 文献 CLS「皮层分布式权重」在游戏内不映射到 m（`数学建模-记忆过程.md` §4.2 修正）

## 二、Schema

### 2.1 记录结构（#90-D1/D3/D5/D6/D7/D8 定案）

```
MemoryRecord {
  id: string                              — 唯一标识（可寻址，#90-D3）
  type: enum{behavioral, narrative, generic}    — 载荷分型（#90-D8；trauma 是烈度属性非 type）
  index: T_j ∈ {0,1}ᵈ                     — 二进制稀疏特征向量（收尾点 3）
  created_at: 时间锚                       — 情境向量时间分量（#90-D6）
  source: enum{event, generated, script, observation}  — 写入来源（#90-D5）
  entities: 实体 id 列表                   — 关系索引（收尾点 2）
  access: {
    P_acc: float ∈ [0,1]                  — 可提取性（幂律衰减，#90-D3/D7）
    区隔标记: bool                         — DID 区隔（#90-D7 状态⑦）
    状态: enum{NEW, CONSOLIDATING, STABLE, RECONSOLIDATING, WEAKENED, FORGOTTEN, COMPARTMENTALIZED, RESET}
  }
  payload: 分型载荷
  烈度属性（非 type 字段）：I_mem ∈ [0,1] + 表征 N/F/R（创伤性由高 I_mem 表达）
}
```

### 2.2 载荷分型（#90-D8）

| type | payload 结构 | 判定（结构可核验） | 来源 |
|------|-------------|-------------------|------|
| behavioral | {链路偏好, 行动模式, SAN 习惯, 上次结果} | 四件套结构完整 | `敌人与事件.md` §4.6 |
| narrative | Conway 3 层 {人生阶段, 一般事件, 事件细节} | 三层完整 | Conway & Pleydell-Pearce 2000 |
| generic | ∅（显式空载荷） | `payload = ∅`（正面定义，非排除法补集） | #90-D8 |

- **trauma 不作为 type**：创伤 = 烈度属性（I_mem 高 + 表征 N/F/R 形态），一条记录可为 generic/behavioral + 高烈度 = 创伤记忆；剂量-反应累积（`L = ΣΔI_i×g`）后 I_mem 增长，无需改 type
- **判定主体 = 写入管线**（内容层），生成端（#87/#86）只提供输入数据不标注类型
- 事件快照字段清单、A_trauma 判定阈值 = **#88 定义**，本文档不引入

### 2.3 字段语义要点

- **index**（二进制）：相似度 s 计算源；特征强度由载荷 I_mem 承载（不重复存，防双源）；稀疏度 `a_j = |T_j|/D` 无阈值截断模糊
- **entities**（关系索引）：与 index 几何用途互补——DID 记忆共享矩阵（决策树 :1294）、触发源分离"在场人物"分量（#90-D6）、NPC 社交记忆检索
- **access.状态**：八状态生命周期（§四）

## 三、六阶段状态机

> 完整公式与推导见 [数学建模工作稿](../../.scratch/grilling-90-memory-storage/数学建模-记忆过程.md) §三-§八。

### 3.1 E 编码（事件 → 记录，#88 输入约定 + #87-D6）

```
ΔI = k × A                    — 单次事件强度增量
L = Σ_i ΔI_i × g              — 总负荷（剂量-反应累积）
T_j = threshold_s(f(e_j))     — 稀疏索引（二进制）
写入 ⟺ α≠0 ∧ a_j ≥ a_write    — Hebbian 与门
T_tag < 3h 内强化 → 弱记忆升级  — 突触标签捕获（Frey & Morris 1997）
```

### 3.2 C 巩固（#90 澄清修正：不写 m）

```
T_syn ∈ [分钟, 小时] / T_sys ∈ [天, 年]      — 双尺度（Dudai 2004）
P_hip(n) = P_hip(0) × (1 − 1/N_target)^n     — 回放蒸馏 = 记录内部稳定化，不产生 m 变化
γ(e) = 1 + γ_max·overlap(e, schema)          — 图式加速（Tse 2007）
睡眠/休息 = 巩固触发事件                     — 不休息 → 记录停留易失态
```

### 3.3 S 存储（#90-D3/D4）

- 存储位置：**构建层持久**（NPC 参数/角色档案，与 m 同层）+ **战斗层快照**（battle_active_memories 只存 id + 激活强度，战斗结束并入构建层）
- 容量（方案 B 去神经化）：`cost_j = α/a_j`，`Σ_j cost_j ≤ Cap_max`

### 3.4 R 检索（#90-D1/D6）

```
s_j = w₁·(P·T_j)/N + w₂·(c_R·c_E,j)          — w₁+w₂=1（内容 + 情境加权）
P_trigger,j = σ(κ·s_j³ − θ_g)                — 勾起概率（n=3 固定，κ/θ_g [NEW]）
P_success = σ(mean(MTL) − θ_mem)             — 引擎层检索成功（正典公式，SDT 解释）
```

### 3.5 RC 再巩固（#90-D2）

```
T_re ≤ 6h × τ_scale            — 窗口（Nader 2000；人类侧复现争议默认取动物侧）
窗口内：ΔI ← ΔI + ΔI_int       — 创伤大幅改写 / 普通记忆轻微改写（烈度分级）
成功提取：P_acc += δ_test      — 测试效应（全类型适用）
```

### 3.6 F 遗忘（#90-D3/D7，#87-D8）

```
P_acc(t) = P_acc(0)·(t/t_ref)^(−b)    — 幂律衰减（1 天剩 ≈0.34，Murre & Dros 2015）
主动遗忘：P_acc × (1 − Δ_forget)      — PFC 抑制（记录保留，可提取性下降）
干扰：overlap(T_j, T_k) > θ_confuse   — 相似新记忆压制旧记忆
铁律：遗忘不作用于 m
```

## 四、生命周期

### 4.1 八状态（#90-D7）

```
NEW → CONSOLIDATING → STABLE ⇄ RECONSOLIDATING → WEAKENED
                      │                        （窗口内稳定化 → STABLE）
                      ├── P_acc < ε_forget ──→ FORGOTTEN（保留但不可访问，可恢复）
                      ├── DID 区隔标记置位 ──→ COMPARTMENTALIZED
                      └── Boss 战击败清零 ──→ RESET（终态）
```

### 4.2 三条铁律

1. **遗忘不作用于 m**（#87-D8）：⑥⑦⑧ 全部是访问层操作，m 不衰退
2. **提取 = 写操作**（#90-D2）：④ 是所有 STABLE 记录提取后的必经之路
3. **同一状态机覆盖全部类型**（#90-D2/D7）：差异只在参数（b、ΔI_int、a_j）

### 4.3 敌人跨战斗记忆统一（#90-D7）

- 敌人四件套 = behavioral payload，走同一 MemoryRecord
- `P_acc(t) = P_acc(0)·t^(−b)` 一套机制；Boss 差异 = b 参数化（A 院长 b 小=精确、B 传销 b 大=弱）
- 「完整/50%/遗忘」档位 = 幂律曲线的叙事化采样点；「击败后清零」= RESET 转移

## 五、检索接口

### 5.1 两层分家（#90-D1/D6）

| 概率 | 公式 | 层 | 消费者 |
|------|------|-----|--------|
| P_trigger（勾起） | `σ(κ·s_j³ − θ_g)` | 内容层（线索 vs 记录 index） | NPC 创伤触发/情境触发（#87-D7 g） |
| P_success（检索成功） | `σ(mean(MTL) − θ_mem)` | 引擎层（节点激活） | 记忆类技能（P1c D5 预留接口） |

### 5.2 触发源分离（#90-D6）

- 外部知觉线索（视觉/听觉/人物在场）→ 内容项 `(P·T_j)`
- 内部情绪/生理状态 → 情境项 `(c_R·c_E,j)`
- 情境向量 `c_t` = 时间 + 地点 + 情绪 + 在场人物（[NEW]）
