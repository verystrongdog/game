## 一、背景与动机

项目需要一套数学工具来描述游戏世界中的时空分布量——场、密度、状态分布——但不假设连续时空对称性（无连续平移/旋转/标度不变性）。初始目标：构建一个「无连续对称性的时空分布量」的通用数学理论。

五个数学框架各自独立构建理论结构，完成交叉验证（19/20 交叉一致），然后接受三路反例攻击（数学、逻辑、物理）。最终结论：结构不是通用理论，而是特化类的晶格化版本。

本框架定位为**设计验证工具**——用于数值模拟和参数校准，不直接进入游戏运行时。最终 Unity 实装时，本框架的公式和边界声明为数值系统的设计提供约束。

## 二、五框架构建过程

五个框架各自从第一原理出发，独立构建「无连续对称性的时空分布量」的数学描述：

| 框架 | 核心工具 | 关键贡献 |
|------|---------|---------|
| 离散外微积分 (DEC) | 上链/Hodge星/d/δ/⋆/Whitney形式 | 离散复形上无需连续对称性的几何算子 |
| 因果集理论 | BD层加权和/序论算符/生长转移核 | 偏序集的generic刚性——无连续自同构是定理而非假设 |
| 概率测度/随机过程 | 鞅问题/Fokker-Planck/Wasserstein梯度流/两参数转移核 | 非平稳是默认模式，不需要Lagrangian |
| 分数阶/非局域PDE | Caputo导数/幂律核/扩散表示/从属原理 | α连续参数化取代硬边界，记忆是核心不是缺失 |
| 信息几何 | Fisher度量/统计流形/测地极坐标/规范固定 | 参考测度=区分工作的唯一入口；U(1)=测地极角 |

交叉验证结果：19/20 一致。唯一分歧点——DEC 的离散 Laplace 与信息几何的 Fisher 拉普拉斯在连续极限下的对应关系——后确认为表示等价（不同坐标下的同一算子）。

## 三、收敛结构

五框架收敛到以下统一形式：

```
M φ̈ + d(φ) M φ̇ + S φ = F(t)
```

其中：
- **φ(x,t)**：复值场，每空间位点 2 实自由度（振幅 a + 相位 θ）
- **M**：正定质量算子（离散形式：对角质量矩阵）
- **S**：空间耦合算子（离散形式：图 Laplacian / Hodge Laplacian）
- **d(φ)**：标量阻尼系数，所有位点共享同一值
- **F(t)**：外部源项

阻尼系数的形式：

```
d(φ) = d_max · h((E_c − E(φ)) / ε)
```

其中：
- **E(φ)**：全局能量泛函，E(φ) = ½⟨φ̇, Mφ̇⟩ + ½⟨φ, Sφ⟩
- **E_c**：临界能量（壳能量）
- **ε**：门控锐度（ε → 0 → 硬开关；ε > 0 → 光滑过渡）
- **d_max**：最大阻尼/增益幅度
- **h**：形状函数，见 §四

能量壳引理：

```
dE/dt = −d(E) · φ̇†Mφ̇
```

在持久轨道上 d(E_c) = 0，壳动力学退化为线性：

```
M φ̈ + S φ = 0    （旋转通道，无阻尼）
```

持久机制：d < 0（零态排斥/增益）→ 振幅增长 → d → 0（钉扎在 E = E_c 壳）→ 壳上自由旋转。

## 四、D1 — h 的双零点族

> **决策**：h 从单调单零点放宽为双零点族，E_th 作为自由参数。

### 形状

h 有两个横截零点：

1. **E = E_th**（阈值零点）：不稳定，势垒顶部。h(E_th) = 0，h'(E_th) > 0（自下而上穿零）
2. **E = E_c**（壳零点）：稳定，钉扎阱底。h(E_c) = 0，h'(E_c) < 0（自上而下穿零）

E_th 是自由参数，决定零态的行为：

### (A) 族：E_th < 0 —— 零态排斥（超临界）

- 物理范围 E ≥ 0，而 E_th < 0 → 零态处 h(E=0) < 0 → d(0) < 0
- 零态自动排斥：小扰动 → 振幅自动增长
- P5（持久性·零态排斥）属于此族
- 超临界分岔：零态在参数穿过阈值时失稳

### (B) 族：E_th > 0 —— 零态稳定 + 源门控硬自激

- 零态处 h(E=0) > 0 → d(0) > 0
- 零态稳定：小扰动衰减回零
- 需要外部源 F(t) 将振幅「踢过阈值」E_th 后才能自持
- P9（源门控硬自激）属于此族

### 边界

(A) 族和 (B) 族的边界是 **transcritical 分岔**：E_th 穿过 0 时，零态的稳定性翻转。(A) 和 (B) 不是两个互斥的机制，而是同一双零点 h 族的两个参数区域。

### 验证

五框架独立审查，全部收敛到同一结论。分数阶 PDE 框架进一步指出：Caputo 固定下限（t = 0 为时间原点）的因果结构中，(A) 和 (B) 在记忆效应下形成滞回环——不是两个分离的 regime，是一个连续参数空间中的路径依赖切换。

## 五、D2 — P1 保留无需修正

> **决策**：P1 保留。基础层无连续时间平移（结构自同构意义）；有效层 R 平移是参数化规范/定律时间齐次性的影子，不是结构对称性。采用 (a)+(b) 联合表述。

### P1 的精确内容

**(a) 基础层（离散因果结构）**：有限偏序集 generic 刚性（几乎所有有限偏序集的自同构群平凡）。无连续时间平移——这是定理，不是假设。信息几何确认：有限分类的 Fisher 等距群是离散 S_n，无连续规范，与因果集的 generic 刚性完全一致。

**(b) 有效层（连续极限）**：R 时间平移的出现是定律时间齐次性在自治方程中的影子。它不是结构的对称性——它是参数化规范。信息几何的精确对应：R 平移 = 参数化规范（沿测地极坐标的极角方向，对应于 U(1) 旋转通道），不是参考测度的等距。

### 为什么 (c) 方案被否决

方案 (c) 提议用状态依赖的 λ(φ) 来打破自治性。五框架一致否决：
- 概率：状态依赖不打破自治性（自治性 = 不显含 t，与状态依赖无关）
- 信息几何：完成的记忆系统仍然自治——λ(φ) 是状态空间坐标的函数，方程右侧不显含 t
- R 平移不可能通过状态依赖来消除——它在有效层的出现是参数化规范的结构推论

## 六、D3 — 结构身份判定

> **决策**：收敛结构 `M φ̈ + d(φ) M φ̇ + S φ = F(t)` 不是「无连续对称性的时空分布量」的通用理论，而是**近 Hopf 分岔弱非线性振荡介质的晶格化版本（CGL 普适类 + 全局 AGC 反馈）**。

### 判定依据

三路反例攻击的结果一致：

1. **数学反例**：随机行走在离散图上的概率分布演化——完全落在结构声称的描述范围内（无连续对称性、时空分布量），但无法写入 M φ̈ + dMφ̇ + Sφ 形式（无惯性、一阶弛豫）→ 结构不是通用的
2. **逻辑反例**：(A)/(B) 的张力被 D1 解决——表面矛盾来自「单调单零点」的隐含假设，放宽为双零点族后张力消失。但这同时也意味着：结构排除了更复杂的多零点/非单调阻尼景观
3. **物理反例**：分类器识别——结构的算子形式、全局 AGC、能量壳钉扎，三者联合唯一地确定了 CGL 普适类

### CGL 普适类

CGL（Complex Ginzburg-Landau）方程的标准形式：

```
∂_t A = μA + (1 + ic₁)∇²A − (1 − ic₂)|A|²A
```

结构是 CGL 的以下特化：
- **γ = 0（纯实增益）**：非线性只调制衰减率 d(φ)，不调制频率（无非线性频移 iγ|z|²z）
- **全局 AGC**：阻尼系数 d(φ) 依赖全局能量 E(φ)，是全对全耦合，非局域 |φ|²
- **晶格化**：空间离散为图/复形，连续 ∇² → 离散 Hodge Laplacian

### 这带来的限制

- 全局 AGC 抑制振幅缺陷湍流（标准 CGL 的某些现象可能不出现）
- 无立方相位项 → 频率不随振幅偏移
- 晶格化引入了空间拓扑敏感依赖（见 §八）

## 七、D4 — 边界与范围声明

> **决策**：五框架综合裁决后的边界/范围声明。三条「边界」是模型族范围声明，不是理论边界。「无连续对称性不承担区分工作」删除，替换为正面特征描述。

### 正面特征描述（替换空洞声明）

> 本框架描述 **U(1) 等变的、近 Hopf 的、弱非线性振荡介质**，带 **全局 AGC 反馈**、空间离散耦合与**可选因果记忆**（幂律）。持久性由振幅-相位分解承载——旋转通道是 U(1) 作用在能量壳上的轨道。

### 范围声明（模型族选择，非理论边界）

> **元声明（2026-08-12 Grilling #41）**：本框架描述**世界内容的内容骨架**——φ 场方程、d(φ) 全局调节、E_c 能量壳是容器内一致性约束骨架。容器的**现象壳**（意识包裹的本体论层）为元前提，非导出量。本框架不描述、不推导、不验证现象壳。按 #40 D9 先例（现象壳=元前提+边界声明），意识包裹对 CGL+AGC 零数学要求。术语说明（2026-08-21 #38）：CGL+AGC 称「内容骨架」，不再称「结构核」——后者专指 #40 意识义。见 [世界观与叙事](../事件/世界观与叙事.md) §世界观地基：意识包裹。

| 声明 | 内容 | 孔隙/限定 |
|------|------|----------|
| **方程形式** | 二阶惯性振荡介质（M φ̈ + dMφ̇ + Sφ），近 Hopf 弱非线性 | 过阻尼极限 d→∞ 退化为一阶弛豫（结构内点）；分数阶 α→1 连续过渡 |
| **序参量** | 复标量（U(1) 等变），每点 2 实自由度（振幅+相位） | Z₂ 实场是机制排除（无相位→无旋转通道）；O(2) ≈ U(1) 可归入；O(n≥3) 是机制排除（非阿贝尔旋转通道，维度和几何不同） |
| **空间** | 离散图/复形，固定拓扑，离散平移不变背景 | 空间拓扑变化（连通/断开）会改变谐和扇区维数，持久通道数量跳变——此为结构对空间拓扑的敏感依赖，未在方程中显式建模 |
| **耦合** | 二阶空间耦合（离散 Laplacian）+ 全局 AGC（全对全能量耦合） | 无局域非线性反馈（|φ|²φ 被全局 AGC 替代） |
| **参数区域** | (A) 族 E_th < 0（超临界·零态排斥）或 (B) 族 E_th > 0（源门控·硬自激）| d(0) 符号是自由参数，非结构固定 |

### 持久性分类（四分法，替换原三分法）

| 类 | 描述 | 结构中的位置 |
|----|------|------------|
| **吸收** | 一旦归零永不返回 | 不在结构内（需乘性噪声打开）；确定性结构的「稳定零态」在噪声下变为吸收态 |
| **唯一平稳** | 唯一不变测度（含静态图案） | 静态持久 = 壳上 ω=0 极限（结构内点）；Turing 图案被排除（需模式选择性增益） |
| **振荡** | 极限环 | 壳上 ω≠0 旋转通道——结构的核心持久机制 |
| **双稳-亚稳** | 两个吸引子、中间势垒 | **(B) 族结构自身就在此类**——稳定零态 + 自持壳，势垒 = E_th |

### 「无连续对称性」的修订

原声明「无连续对称性不承担区分工作」**删除**。替换为：

- **基础层**：离散结构的 generic 刚性（自同构群平凡）是定理，保证框架不引入伪对称——承担认证工作，不承担区分工作
- **有效层**：区分工作由以下结构承担，按权重排序：

1. **内部 U(1) 相位规范**（最重）：振幅-相位分解 = 复序参量 = U(1) 等变。旋转通道**就是** U(1) 群作用在 E = E_c 壳上的轨道。持久机制本身是 U(1) 对称现象
2. **谱扇形几何**：稳定扇形 |arg λ| > απ/2 的楔角 (2−α)π 承担稳定性/振荡性分类（分数阶框架）
3. **核的齐次性**：幂律核 t^{−α} 是唯一齐次记忆核——决定尾巴、谱密度、解的自相似（RG 意义下的普适性载体）
4. **从属原理**：分数阶动力学 = 整数阶动力学在随机慢时钟上运行——记忆的精确数学内容
5. **因果边界**：被破缺的时间平移（固定时间原点）——区分「有起点的过程」与「永恒平稳过程」
6. **Lyapunov/梯度结构**：弛豫类 vs 振荡类的正确切割面——穿阶数而过

## 八、被排除的系统与未被选取的通道

### 被结构形式排除（机制性）

| 系统/通道 | 排除理由 |
|----------|---------|
| **实标量弛豫场（无相位）** | 无旋转自由度 → 持久机制不可行 |
| **O(n≥3) 矢量场** | 非阿贝尔旋转通道——壳几何和通道维度不同 |
| **Turing 图案（静态模式选择）** | 需模式选择性增益（微分扩散系数/双场），全局标量门控 + 单复场无法实现 |
| **立方相位项（非线性频移 iγ\|z\|²z）** | 结构非线性只有实标量增益 d(φ)（γ = 0） |

### 未被选取的通道（框架层面可用，结构层面未选）

| 通道 | 说明 |
|------|------|
| **守恒律/平流（∂ₜρ + ∇·j = 0）** | 框架层面存在（Fokker-Planck 天然是连续性方程、分数阶 Laplacian 有散度形式、DEC 有离散 Stokes），结构选择非守恒梯度流动力学 |
| **记忆/延迟** | 整数结构无记忆（一阶马尔可夫）。分数阶化可填补代数/无标度记忆子通道（幂律核 t^{−α}）；刚性延迟（u(t−τ₀)）和有限秩指数记忆不在覆盖范围内。K_{s,t} 处理的是非齐次（日历时间依赖），不是非马尔可夫（历史依赖）——二者不同 |
| **多场耦合** | 结构是单场方程；DEC 的算子逐分量、耦合项可加，但未被使用 |
| **长程非局部空间核** | 与全局 AGC 的全对全耦合区分——前者是卷积核（空间上的非局部积分），后者是标量全局反馈 |
| **空间异质性**（逐位点参数） | 当前假设系数均匀（离散平移不变），DEC 的逐单形参数化是其自然扩展 |
| **乘性噪声/涨落** | **最大的缺失通道**（概率框架）。确定性结构是随机理论的退化切片。打开噪声后：稳定零态 → 吸收态、壳 → 平稳带、双稳 → 亚稳——确定性分类在噪声下不稳定 |
| **吸收/灭绝（准平稳分布 QSD）** | 噪声下的独立理论对象，无确定性对应物 |
| **临界/相变** | 结构用光滑 ε 处理阈值，无临界词汇（标度、指数、普适类） |

## 九、对下游设计的影响

### 当前可用

- 数值模拟脚本可复用本框架的收敛结构作为验证工具
- 能量壳引理（dE/dt = −d(E)·φ̇†Mφ̇）为持久性机制的数值验证提供定量判据
- D1 的 h 双零点族 + E_th 参数为设计提供了 (A)/(B) 两种 regime 的统一参数化

### 不应做的事

- 不要把本框架当作「通用场论」来推导新机制——它只覆盖 CGL + AGC 子类
- 不要用「无连续对称性」作为任何分类判据——它不做区分工作
- 不要假设分数阶化是「免费扩展」——它带来 α 连续参数化和记忆效应，同时改变了稳定性结构和壳守恒性

### 如果设计需要超出本框架范围

- 需要守恒律 → 转用分数阶 Cahn-Hilliard（散度形式）或 DEC 的离散 Stokes
- 需要多场耦合 → DEC 的逐分量算子或概率框架的多物种 McKean-Vlasov
- 需要噪声 → 概率框架的鞅问题/Fokker-Planck/准平稳分布
- 需要延迟 → DDE 结构（C([−τ₀,0]) 半群），非分数阶核

## 十一、月光场实例化 φ_moon（Grilling #38，2026-09-02）

> 本框架的第一个 CGL+AGC 实例化：月光场。经实例化判据 C1-C8 全硬门槛入族，确定本体/regime/初始化/月相/空间/源项/三层结构/观察者职责，并给出理论→游戏接口的完整数学形态。**数值全部待校准**（§十一.6 实验轨 → #35 校准轨）。本实例化未反向修改框架本体。

### 11.1 实例化判据 C_{CGL+AGC}

候选时空分布量 X ∈ C_{CGL+AGC} **当且仅当 C1∧C2∧…∧C8 全部成立**（全硬门槛；软性入族 = v2 式漏洞）：

| 判据 | 内容 |
|------|------|
| C1 本体类型 | X 是世界的时空分布量（场/密度/状态分布），非离散实体或单体状态 |
| C2 动力学可写性 | ∃ 正定 M、半正定 S：X 的运动方程可写为 `Mφ̈ + d(φ)Mφ̇ + Sφ = F(t)`（二阶惯性振荡；一阶弛豫排除） |
| C3 序参量 | 态空间含 U(1) 等变复标量（每点振幅+相位 2 实自由度）；Z₂ 实场、O(n≥3) 排除 |
| C4 非线性类 | 近 Hopf 弱非线性，γ=0（非线性仅调制阻尼 d(φ)，无立方相位项） |
| C5 耦合结构 | 空间二阶耦合（离散 Laplacian）+ 全局 AGC 全对全能量反馈；无局域 \|φ\|² 反馈 |
| C6 持久性 | 能量壳引理 dE/dt = −d(E)·φ̇†Mφ̇ 成立，持久行为由振幅-相位分解承载（U(1) 旋转通道） |
| C7 去噪不变性 | 关闭机制层噪声 ξ_game 后，核心确定性性质（月相驱动参数变化/壳钉扎/regime/持久动力学结构）仍可观测 |
| C8 固定拓扑 | 定义域可晶格化为固定图 G（一次动力学运行期间 K(t)=K） |

任一失败 → X ∉ C_{CGL+AGC} → 按 §九 路由换族；「不满足但可近似使用」≠「属于 CGL+AGC」（前者走近似/降阶接口，后者必须全判据通过）。

**月光场自检**：C1-C6 ✅（复标量二阶振荡 + 全局 AGC + 壳钉扎）；C7 ✅（去噪不变性——月相调制/壳钉扎在 ξ_game 关闭后完整）；C8 ✅（固定拓扑假设下）。**通过入族**。动态拓扑（K(t)≠K 致连通性/持久通道数结构性改变）→ 当前实例降级/出族，未来扩展属独立理论工作。

### 11.2 本体与驱动（Q3.1-Q3.2）

- **中性强度场**：φ_moon 机制侧仅携带强度/能量动力学。A/B/C 三重叠加 = 观察侧读出（(φ_moon, O_i) → V_i ∈ {A,B,C}），不进动力学、不进 m_field——取版本发生在观察侧，不是共享基质本身。
- **B 族**（E_th > 0，零态稳定 d(E=0)>0）：需源项 F(t) 把系统推过 E_th → AGC 自持 → 收敛 E_c。d(φ) 符号由 E 相对 E_th/E_c 的位置决定（公式事实），「满月 d<0 / 弦月 d≈0 / 新月 d>0」= 待校准验证的预期 regime 映射，非公理。
- **月相 = 确定性慢周期参数调制**：λ_moon(t) = f_lunar(phase(t)) 调制 E_c(λ)/E_th(λ)（壳高度 + 激活难度两通道独立），**非能量源**。
- **F(t) = F_collective(t)·1 + F_local(x,t)**：群体精神事件（拜月祭礼/大规模精神事件/Boss 战胜利/SAN 归零/信念聚集）+ 局部事件注入。「信念是物理力」= 信念聚集 → F(t) → E → regime（不是 信念 → A/B/C 版本）。个体心想事成 = F_individual = η_i·F_collective（0≤η_i≪1，同通道不同源强，不另造机制）。
- **初始化（A1）**：历史上某次大规模精神事件把场踢入 E>E_th → 场常态在壳上（E≈E_c）；F(t)=0 不人为拉回零态；**无背景源 F_bg**；不恢复零号病人（v2 已废弃）。「月光恒在」= 系统历史条件/初始条件，非永久能量源（需 E1 验证 F=0 时壳态保持）。

### 11.3 空间结构（Q3.3-Q3.5）

- **单全局场**：φ_moon: G → ℂ，G = G_0（物理层）∪ G_1（扭曲空间）∪ G_2（患者世界）——三层 = **同一个场的三个空间区域**，非三个场；单一全局 E(φ)、单一 d(φ)，无每层 regime；三层共享同一 AGC 状态。
- **M = I**（均匀惯性基线选择）；**S = L(G)** 组合 Laplacian（L_ij = −w_ij，w_ij ≥ 0 边权待校准，**不附加「鬼打墙强度」等世界观解释**——数学自由度 ≠ 叙事属性）。
- **C8 执行**：G(t) = G_0 ∪ G_1 ∪ G_2 = constant（运行期固定拓扑）；层间边可不同权重，但不动态增删边表达鬼打墙/门控——空间切换由上层空间/关卡系统改变可达性语义。
- **医院主导观察者不进主链**：走两条既有通道——情境基线（核心机制 §6.2）+ 观察侧 A/B/C 读出；不添加 O_hospital → m_field⁽ⁱ⁾（防三渠道职责重叠）。
- **锁定接口规则**：**局部增强 ≠ 局部 AGC**——E(φ) 全局能量、d(φ) 全局决定；局部源只改局部振幅动力学，经 S 耦合全场，不存在独立 E_x/局部 regime。

### 11.4 理论投影（Q4）

```
q_i(t)  = ½|φ̇_i|² + ¼Σ_j w_ij|φ_i − φ_j|²      （正定局部能量密度，边能量均分两端）
r(t)    = E(φ)/E_c(λ(t))                       （全局相对壳能量诊断，壳上 r≈1）
q̂_i(t) = q_i(t)/q_i^base(λ(t))                （节点基线归一，q̂≈1 = 正常月光强度）
```

- Σ_i q_i = E(φ)；q_i ≥ 0（正定——否决 ½φ†Sφ 单节点可为负的局部势能形式）。
- 三层分离：**φ → q_i（理论投影）→ q̂_i（接口归一化）→ m_field（游戏语义量）**。
- 否决：q/E_c 直接作节点相对强度（均匀壳态下 Σq̂≈1 而非每节点≈1）、|φ_i|²（接口弱）、多观测量（复杂化）。

### 11.5 游戏接口（Q5）

```
m_field_vec⁽ⁱ⁾(t) = q̂_{x_i(t)}(t) · g(SAN_i, state_i) · R_i
```

- **q̂** = 理论投影输出（个体当前位置 x_i(t) 的节点场效应）；**g** = 机制层调制函数（方向不定死：SAN↓→g↑/↓ 均不预设，待校准；不得声称"CGL+AGC 推导出 SAN 效应"）；**R_i ∈ ℝ^69** = 神经节点落点向量（只定接口存在，未填=0，functional_id 留独立 grilling）。三职责不可互换。
- **单向接口**：m_field_vec ↛ φ_moon——神经空间/观察者/69 fid 不反向倒灌理论场。
- 演进：MFieldStrength=0 占位 → q̂(x,t) 理论投影 → ×g 个体机制 → ×R_i[69] 神经映射 → m_field_vec[69]（s_total = s_事件 + s_env + m_field，运行时状态模型 §4.5）。
- 更新时序：#69 D7——空间切换 + 月相/昼夜节点刷新。

### 11.6 结构锁定 vs 待校准（Q6）与实验轨（Q7）
