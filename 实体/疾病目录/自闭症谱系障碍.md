# 自闭症谱系障碍 (ASD)

> 父类: 社会认知障碍 | CGI-S范围: 3-7
> 核心病理: 自我社会域↓ 结构异常 + 语言社会域 结构异常 + 感觉域 过度耦合。ENIGMA 结构模式独立——不是"变弱"而是"连接方式不同"。

## 行为覆盖

| 条件 | 约束 |
|------|------|
| DMN+OFC ← 颞极 (L) \|m\| > 0.3 | L4 读意图·主动 不可用——无法从面部表情/动作推断意图 |
| 感觉域 m_max > 0.3 | 感官过载——每回合 10% 概率额外激活一条感觉域链路（消耗认知槽） |
| 角回 → TPJ (L) \|m\| > 0.3 | L5 换位·主动 不可用——无法以他人视角看世界 |

## 思路链

**方向判断依据：**
- **自我社会域↓(结构异常)**：社会脑网络（颞极/ACC/mPFC/后扣带）连接路径异常。ENIGMA ASD 结构独立于四病共享因子
- **语言社会域↓(结构异常)**：TPJ（换位思考）+ Broca-Wernicke（语言社会功能）异常连接。RDoC 社会过程域
- **感觉域↑(过度耦合)**：上丘→丘脑枕→皮层 感觉中继过度——感官过敏。蓝斑→V1 感觉信噪比异常
- **识别域↓(结构异常)**：纺锤体回→颞中回 生物运动/面孔识别异常
- **认知控制域↑(过度耦合)**：额中回尾部↔dlPFC 过度——僵化/刻板行为。与 OCD 共享过度耦合特征但限于 routine/特殊兴趣

**病理类型特色**：
- ASD 是**结构异常**的核心示例：不是"信号减弱"而是"连接路径异常"——替代回路、代偿性连接、或缺失标准连接
- 与 ASPD 的差异：ASD 为社会认知域**结构异常**（先天），ASPD 为社会认知域**解耦沉默**（后天共情缺失）
