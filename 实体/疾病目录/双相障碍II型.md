# 双相障碍 II 型 (BD-II)

> 父类: 奖赏系统障碍 | CGI-S范围: 3-6（不达 CGI-S 7——无完全精神病性躁狂）
> 核心病理: 奖赏域轻度双向振荡 + 自我社会域↑（轻躁狂期自我膨胀）+ 内感受域异常。BD-II 以抑郁为主导，轻躁狂不达精神病水平。效应量 < BD-I。

## 思路链

**方向判断依据：**
- **奖赏域 轻度振荡**：效应量 < BD-I——轻躁狂（非精神病性）→ 抑郁（主导）。ENIGMA BD-II 结构效应量 < BD-I (Hibar 2016)
- **自我社会域↑**：后扣带→mPFC 过度——轻躁狂期自我膨胀/目标驱动过度
- **认知控制域↓(轻度)**：抑郁主导→dlPFC↓ < BD-I
- **整合域 边界崩溃(极轻度)**：效应量 < BD-I，仅在重度抑郁期显现
