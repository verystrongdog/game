# 双相障碍 I 型 (BD-I)

> 父类: 奖赏系统障碍 | CGI-S范围: 3-7
> 核心病理: 奖赏域双向振荡（躁狂↑/抑郁↓）+ 唤醒域蓝斑振荡 + 整合域边界崩溃（<精分）。躁狂-抑郁交替的振荡动力学。

## 默认标签

## 行为覆盖

| 条件 | 约束 |
|------|------|
| 奖赏域 净方向 > 0（躁狂相；奖赏域双向边群躁狂极 e01/e02/e03/e15/e16 取极 m） | 物理攻击 +20%，精神攻击 −20%；防御不可用 |
| 奖赏域 净方向 < 0（抑郁相；奖赏域双向边群抑郁极同上） | 物理攻击 −20%，精神攻击 +20%；趋近·主动 不可用 |
| 唤醒域 m_max > 0.3（唤醒域边群 e05/e06，m_max 取两条最大值） | 每 3 回合检查一次奖赏域净方向——20% 概率翻转（躁狂↔抑郁） |

## 思路链

**方向判断依据：**
- **奖赏域 双向振荡（e01/e02/e03/e15/e16）**：躁狂期 VTA→NAcc 过度耦合（e01 躁狂极，奖赏敏感性↑↑→冲动/欣快/目标驱动），抑郁期 VTA→NAcc 解耦沉默（e01 抑郁极，奖赏↓→快感缺失/意志缺乏）。锂盐保护海马体积（e11）但不改变振荡动力学
- **唤醒域↑(过度耦合)**：蓝斑 NE 振荡（e05 LC→杏仁核 + e06 LC→ACC，两相均↑）——躁狂期↑（睡眠需求↓），抑郁期也可↑（激越性抑郁）
- **认知控制域↓(解耦沉默)**：dlPFC-ACC 调控减弱（e08 ACC→额极 + e09 mOFC→dlPFC）——冲动控制↓（躁狂）+ 决策↓（抑郁）
- **整合域 边界崩溃(轻，e09 解耦沉默)**：DMN-FPN 反相关减弱，效应量 < 精分——状态依赖（躁狂/抑郁方向相反，静息态残余）
- **双向振荡边标注**：`+X/−Y` = 躁狂极/抑郁极（e01-e04/e07/e15/e16），结算按当前心境相位取对应极（相位状态机见 pilot §五.3）；单一值 = 相位无关（e05/e06/e13）
