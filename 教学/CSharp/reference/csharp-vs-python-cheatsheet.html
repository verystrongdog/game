二、C# 术语中英对照

术语含义别用
record值型数据类：装数据、不可变、自带相等比较（≈ dataclass + 不可变）「结构体」
property 属性类的数据成员，带 get/set/init 访问器「字段」「变量」
static 静态属于类型本身而非某个对象（≈ 类方法）「全局」
interface 接口只声明签名不实现的类型契约（≈ 抽象基类）「协议」
namespace 命名空间组织类型的名字空间（≈ 包/模块的轻量版）「包」
generic 泛型List<T> 中的 T——类型参数「模板」
MonoBehaviourUnity 脚本基类：挂到 GameObject 上被引擎驱动「脚本父类」

三、三个最容易踩的坑

  1. 忘了分号：每条语句结尾要 ;。报错 CS1002。
  2. float 要 f 后缀：78.5f；写 78.5 默认是 double，赋给 float 会报错。
  3. 字符串用双引号："abc"；单引号 'a' 是字符（char），两者不同。
