# Mission: C#（面向 Unity）

## Why

「面具」的最终形态是 Unity 游戏，而 C# 已经在你脚下：`src/YouAreNotTheFish.Core` 的战斗引擎就是 C# 写的，它正在验证项目最核心的神经动力学公式。学会 C#，你才能读懂、质疑、参与这套引擎，并最终把纸面设计变成可玩的 Unity 原型——而不是永远停在 Python 模拟脚本。

## Success looks like

- 能独立读懂 `src/YouAreNotTheFish.Core` 里的任意一个文件（record、interface、static 类、测试），说出它在引擎里的职责
- 能给引擎补一个 xUnit 测试并跑绿（如给 ToneUpdater 加边界用例）
- 能用 C# 把一段 Python 模拟逻辑翻译成等价类（如 SAN 结算）
- 在 Unity 里做出「面具」的一个可玩机制原型（如 SAN 消耗 + 观察者效应演示）

## Constraints

- 中文授课，代码用英文
- 已有 Python 编程基础（写过模拟脚本）→ 优先 Python→C# 对照，降低认知负担
- 面向 Unity 优先，纯语言细节按需补充
- 每课要小、要快、要有具体收获（teach 技能要求）

## Out of scope

- 图形学 / Shader 编写（先用 Unity 现成材质）
- 引擎底层原理（资源管线、物理引擎内部实现）
- 与 Unity 无关的 C# 框架（ASP.NET、WPF、MAUI 等）
