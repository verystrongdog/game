第 1 课 · 从 Python 到 C#：你的第一个程序

课程编号：0001 · 阶段 1（语法基础）· 预计 15–20 分钟

本课收获：写出你的第一个 C# 程序；知道 C# 与 Python 的 3 个关键区别；读一段你自己项目里的真实 C# 代码。

为什么学这个

「面具」的最终形态是 Unity 游戏，而 src/YouAreNotTheFish.Core 的战斗引擎已经用 C# 写好了。C# 语法对写过 Python 的你来说会很眼熟——本课从你熟悉的东西出发，建立第一座桥。

1. Hello World：两个世界

Python 里你写过：

print("你好，面具")

C# 里对应的是（控制台程序）：

Console.WriteLine("你好，面具");

三个立即注意到的区别：

  • Console.WriteLine 是「调用 Console 类的静态方法」——Python 的 print 是内置函数，C# 里功能都挂在类上。
  • 每条语句以 ; 结尾。
  • C# 是编译型语言：先编译再运行；Python 是解释型。所以 C# 在编译阶段就能抓住很多类型错误。

2. 入口点 Main：程序从哪开始

Python 脚本从上往下执行；C# 程序从 Main 方法开始。你项目里 src/YouAreNotTheFish.Console/Program.cs 第 14–16 行就是这样：

public static class Program
{
    public static int Main(string[] args)
    {

解读这一小段（这就是你将来要天天见的东西）：

  • public：公开的——别的代码能访问。
  • static：静态的——不创建对象就能调用（对照 Python 的类方法）。
  • int：返回类型——方法结束后返回一个整数（退出码 0/1，见 Program.cs 第 16/29/41 行）。
  • string[] args：参数——命令行参数数组（Python 里是 sys.argv）。

3. 变量与类型：C# 是「强类型」的

Python 里一个变量可以装任何东西：

san = 100        # int
san = "很多"     # 突然变成 str，没问题

C# 里每个变量在声明时就要定下类型，之后不能变：

int san = 100;         // 整数
string mood = "恐惧";  // 字符串
float hp = 78.5f;      // 浮点数，注意 f 后缀
bool isDefending = false;

类型对照表（完整版见速查卡）：

PythonC#说明
intint整数
floatfloat / doublefloat 要加 f 后缀
strstring字符串
boolbool布尔
listList<T>泛型列表（后几课讲）
dictDictionary<K,V>字典（后几课讲）

偷懒写法：var san = 100; ——让编译器推断类型，但类型仍然是固定的 int，不是 Python 的动态类型。

4. 字符串插值

Python 3.6+ 有 f-string：f"{name} 的 SAN 是 {san}"。C# 用 $ 前缀：

string name = "玩家";
int san = 100;
Console.WriteLine($"{name} 的 SAN 是 {san}");

6. 读一段你自己的真实代码

打开 src/YouAreNotTheFish.Core/Types/ToneState.cs（20 行，很短）。现在你已能读懂它的大部分：

public sealed record ToneState
{
    public float Ne { get; init; }
    public float DaVta { get; init; }
    public float DaSnc { get; init; }
    public float Ht5 { get; init; }
}

新东西只有一个半：

  • record：C# 9 引入的「值型数据类」——用来装数据、不可变、自带相等比较。现在只需知道：它像 Python 的 dataclass + 不可变。
  • { get; init; }：属性（property）。get 表示可读；init 表示只能在创建时赋值一次（不可变）。

试试：不看注释，你能说出 ToneState 装的是哪 4 个脑干 tone 吗？（提示：NE、DA_VTA、DA_SNc、5HT——你在设计文档里见过它们。）

测验

  1. C# 程序最先执行的是？
    • A. Main 方法
    • B. 顶部代码
    查看答案

    A。每个控制台程序从 Main 方法开始（Program.cs 第 16 行）。

  2. 声明整数变量用的类型是？
    • A. int
    • B. string
    查看答案

    A。float 是浮点、bool 是布尔、string 是字符串。

  3. Unity 里挂在物体上的脚本类必须继承自？
    • A. MonoBehaviour
    • B. GameObject
    查看答案

    A。GameObject 是物体本身；脚本是挂在物体上的组件，必须继承 MonoBehaviour（阶段 3 会讲）。
