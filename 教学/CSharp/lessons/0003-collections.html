第 3 课 · 集合：数组、List 和 Dictionary

课程编号：0003 · 阶段 1（语法基础）· 预计 20–25 分钟 · 前置：[第 2 课](../lessons/0002-control-flow-methods.html)

本课收获：分清 C# 的三种「装一堆东西」的容器——数组、List<T>、Dictionary<K,V>；看懂引擎里真实的集合代码；用它们完成一个「数 SAN 高的人」的小程序。

为什么这课对你特别顺

Python 里你用惯了 list 和 dict。C# 的三种容器就是它们的「定类型」版本——你把「Python 的容器」翻译成「C# 的容器」即可，概念零新增。

1. 数组 float[] —— 定长、同类型

引擎真实代码 src/YouAreNotTheFish.Core/Types/WcState.cs 第 11 行——69 个脑区激活值：

public float[] A { get; }   // 69 个 a_j(t)，值域 [0,1]

数组特点（对照 Python list）：

  • 定长：创建后长度不变。Python list 可随意 append，C# 数组不行。
  • 同类型：float[] 里只能装 float。Python list 能混装，C# 不行。
  • 下标从 0 开始：delta[0] 是第一个元素——引擎 ToneUpdater.cs 第 56 行 Apply(tone.Ne, delta[0], ...) 就是这样按位置取值的。
  • 长度用 a.Length（≈ Python len(a)）。

创建数组：float[] scores = { 0.1f, 0.5f, 0.9f };

var events = new List<CombatEvent>();
var actions = new List<(int Participant, CombatAction Action)>();
...

<T> 叫泛型——「T」是占位符：List<string> 装字符串、List<float> 装浮点、List<CombatEvent> 装引擎事件。它让「列表」这个概念不绑定任何具体类型。

3. Dictionary<K,V> —— 键值对（≈ Python dict）

引擎真实代码 src/YouAreNotTheFish.Core/Data/BrainRegionsData.cs 第 11 行——按脑区 id 查脑区数据：

public Dictionary<string, BrainRegion> Regions { get; init; } = new();

4. 把三者串起来读（引擎真实逻辑）

引擎 src/YouAreNotTheFish.Core/Engine/NpcSalience.cs 第 123–128 行的 Mean 方法（第 2 课见过）——这次注意它的参数就是数组：

private static float Mean(params float[] values)
{
    float sum = 0f;
    foreach (var v in values) sum += v;
    return sum / values.Length;
}

三种容器在引擎里各司其职：数组装定长数值序列（69 个激活值）、List 装动态收集的结果（回合事件）、Dictionary 装按名字查数据（fid → 脑区 / 行号）。

6. 测验（先想答案，再点开）

测验

  1. 要按「名字」快速查「数值」，用哪种容器？
    • A. Dictionary
    • B. foreach
    查看答案

    A。Dictionary 按键 O(1) 查找；foreach 是循环语句不是容器。

  2. 定长、元素同类型、用 Length 的容器是？
    • A. 数组
    • B. 字典
    查看答案

    A。数组创建后长度不变；字典按键存取，没有「长度固定」概念（它也有 Count）。

  3. 给 List 加元素用哪个方法？
    • A. Add
    • B. Push
    查看答案

    A。List 用 Add（对照 Python 的 append）；Push 是 Stack（栈）的方法。
