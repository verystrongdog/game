回顾 + 上节课的悬念：Main 去哪了？

第 1 课说「C# 程序从 Main 开始」，但你新建的 HelloMask 里根本没有 Main——因为 .NET 6+ 的模板用顶层语句：你写在文件顶部的代码，编译器会悄悄包进一个自动生成的 Main 里。引擎的 src/YouAreNotTheFish.Console/Program.cs 用的是显式写法：

public static class Program
{
    public static int Main(string[] args)
    { ... }
}

两种写法等价。引擎选显式写法是为了让「入口点」一目了然。以后在 Unity 里你写的类甚至没有 Main——那是引擎在替你调用，阶段 3 再讲。

1. if —— 让代码做判断

Python：

if san >= 80:
    print("精神稳定")
else:
    print("需要休息")

C#（注意圆括号 + 花括号）：

if (san >= 80)
{
    Console.WriteLine("精神稳定");
}
else
{
    Console.WriteLine("需要休息");
}

引擎里的真实例子 src/YouAreNotTheFish.Core/Engine/ToneUpdater.cs 第 48–51 行——先检查参数再干活：

if (delta.Length != 4)
{
    throw new ArgumentException($"delta 长度必须为 4（当前 {delta.Length}）", nameof(delta));
}

throw 是「抛异常」——程序在这里主动报错退出，让错误尽早暴露。nameof(delta) 只是把变量名转成字符串「delta」，防止手写拼错。

2. for —— 数着次数循环

引擎里 src/YouAreNotTheFish.Console/Program.cs 第 70–71 行的真实代码（静息 trace 模式，跑 N 个回合）：

for (var i = 0; i < rounds; i++)
    tm.StepRound(state, ctx);

拆解三段（对照 Python 的 for i in range(rounds)）：

段代码含义
初始化var i = 0从 0 开始
条件i < roundsi 小于 rounds 就继续
步进i++每次 +1（++ 就是自增）

3. foreach —— 遍历集合（最常用）

Python 的 for x in items 在 C# 里就是 foreach。引擎里 src/YouAreNotTheFish.Core/Engine/NpcSalience.cs 第 123–128 行的真实方法——算平均值：

private static float Mean(params float[] values)
{
    float sum = 0f;
    foreach (var v in values) sum += v;
    return sum / values.Length;
}

逐行读懂它（这就是你「读引擎代码」的第一个完整方法）：

  • private：私有——只有本类能调用。
  • static：静态——不建对象直接 NpcSalience.Mean(...)。
  • float：返回类型——方法结束时交出一个 float。
  • params float[] values：可变参数数组——可以传任意多个数：Mean(0.1f, 0.5f, 0.9f)。
  • foreach (var v in values)：把 values 里的每个元素依次放进 v。
  • return sum / values.Length;：返回平均值。Length 是数组元素个数（对照 Python len）。

另一个真实例子 src/YouAreNotTheFish.Core/Flow/TurnManager.cs 第 109–112 行——循环里还能提前跳过：

foreach (var p in order)
{
    if (state.Participants[p].Hp <= 0f)
        continue; // 被击杀者跳过，不行动
    state.TickWindow(p);
    ...
}

continue = 跳过本次，继续下一次循环（Python 里一模一样）。

4. while —— 直到条件不满足

引擎主循环 src/YouAreNotTheFish.Console/Program.cs 第 56 行的真实代码——战斗直到结束：

while (!tm.IsOver(state))
{
    var result = tm.StepRound(state, ctx);
    Console.Write(RoundRenderer.RenderRound(...));
}

!tm.IsOver(state) 读作「战斗没结束就继续」——! 是取反（对照 Python 的 not）。只要有人 HP/SAN 归零，IsOver 返回 true，!true = false，循环停。

5. 方法 —— 你自己写函数

Python：

def judge_san(san):
    if san >= 80: return "精神稳定"
    if san >= 50: return "心神不宁"
    return "濒临崩溃"

C#（注意：返回类型写在名字前面、参数要声明类型）：

static string JudgeSan(int san)
{
    if (san >= 80) return "精神稳定";
    if (san >= 50) return "心神不宁";
    return "濒临崩溃";
}

调用：string mood = JudgeSan(65); ——和 Python 调用方式一样。

string name = "玩家";

7. 测验（先想答案，再点开）

测验

  1. 判断条件用哪个关键字？
    • A. if
    • B. do
    查看答案

    A。do 是 do-while 循环的关键字，判断用 if。

  2. 遍历一个集合最常用的循环是？
    • A. foreach
    • B. switch
    查看答案

    A。引擎里到处是 foreach (var x in ...)；switch 是多分支判断，不是循环。

  3. C# 方法的返回类型写在哪？
    • A. 名字前面
    • B. 参数后面
    查看答案

    A。比如 static string JudgeSan(int san)——string 是返回类型，写在方法名前面（和 Python 相反，Python 不写返回类型）。
