# C# 课程大纲（面向 Unity）

> 总目标：能看懂并编写 Unity 游戏逻辑，把「面具」的设计翻译成 C#。路线：环境 → 语法基础（Python 对照）→ OOP → Unity 脚本 → 小实战 → 面具原型。每课产出见 `lessons/`。

## 一、阶段 0 环境准备

- 安装 .NET SDK；安装 Unity Hub + Unity 编辑器（LTS）
- 会用 SharpLab 在线跑代码
- 产出：命令行跑起 Hello World

## 二、阶段 1 C# 语法基础（Python→C# 对照）

- 入口点 Main、Console 输出
- 变量与类型：int/float/string/bool vs Python 动态类型；var
- 方法（函数）、参数、返回
- 控制流：if/for/foreach/while
- 字符串与插值 $""；数组、List&lt;T&gt;、Dictionary&lt;K,V&gt; vs Python list/dict
- 记录（record）与属性的最小认识（为 OOP 铺垫）
- 产出：控制台小工具（如打印角色属性表）；能读懂 ToneState / ToneUpdater 这类引擎文件

## 三、阶段 2 面向对象（OOP）

- class/对象/字段/属性/方法；构造
- 访问修饰符 public/private；static 成员 vs 实例成员
- 继承、多态、接口（对照 Python 抽象基类）
- 产出：用 C# 写「面具」角色类（HP/SAN/技能）

## 四、阶段 3 Unity 脚本

- MonoBehaviour、GameObject 与组件
- Start/Update 生命周期、Time.deltaTime
- Transform 移动、Input 输入；触发/碰撞（OnTriggerEnter）
- 产出：可移动的小方块

## 五、阶段 4 Unity 小实战

- 极简小游戏（收集/躲避）
- UI（Canvas、Text）、场景切换
- 产出：一个可玩小原型

## 六、阶段 5 面具原型 C# 化

- 把 Python 模拟的核心结算（SAN 消耗、技能树查表、观察者效应概率）移植成 C# 类
- 在 Unity 场景里演示一个核心机制
- 产出：面具第一个可玩机制原型
