# C# 学习资源

> 本工作区的可信来源清单。讲解必须从这里取知识，不凭记忆讲。按 teach 技能格式分 Knowledge / Wisdom。

## Knowledge

- [Microsoft Learn: .NET 训练（中文）](https://learn.microsoft.com/zh-cn/training/dotnet/)
  微软官方交互式课程入口，含「使用 C# 编写第一个代码」等学习路径。用：课程主线的配套官方教程。
- [A tour of C#（交互式教程，中文）](https://learn.microsoft.com/zh-cn/dotnet/csharp/tour-of-csharp/tutorials/)
  浏览器内可运行的基础语法教程。用：语法速览、复习。
- [适用于初学者的 C#（视频系列，中文）](https://learn.microsoft.com/zh-cn/shows/csharp-for-beginners/)
  微软官方入门视频。用：概念讲解的补充。
- [C# 语言参考（中文）](https://learn.microsoft.com/zh-cn/dotnet/csharp/language-reference/)
  语言规范级参考。用：遇到「为什么这样写」时查证。
- [.NET 下载页](https://dotnet.microsoft.com/zh-cn/download)
  用：安装 .NET SDK，本地跑控制台程序。
- [SharpLab](https://sharplab.io/)
  在线 C# 编译/运行/反编译工具。用：没装 SDK 时跑课上的小代码。
- [Unity Learn](https://learn.unity.com/)
  Unity 官方课程平台（含 Junior Programmer 学习路径）。用：阶段 3 起的 Unity 脚本课程。
- [Unity 手册（中文）](https://docs.unity3d.com/cn/current/Manual/index.html)
  用：编辑器操作、组件概念。
- [Unity 脚本 API 参考](https://docs.unity3d.com/ScriptReference/)
  用：查 MonoBehaviour、Time.deltaTime 等 API 签名。

## Wisdom (Communities)

- [Unity 官方论坛](https://forum.unity.com/)
  用：Unity 报错与设计取舍咨询。
- [Microsoft Q&A: C# 学习起点讨论](https://learn.microsoft.com/en-sg/answers/questions/5884975/where-to-start-if-i-want-to-learn-c)
  用：语言疑问。
- [r/csharp](https://www.reddit.com/r/csharp/)
  用：社区最佳实践讨论。
- 本地：csharp-engine 项目本身 + 面具设计文档
  用：把每个概念落到自己项目里讨论——这是最有效的练习场。

## Gaps
