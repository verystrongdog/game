# 基础行动 — 物理与精神攻击

> 基础行动不来自任何解锁——它们是角色的**身体和声音**，开局即存在。所有链路的调制最终汇入两条输出通道：**M1（骨骼运动）**输出身体动作，**Broca（语言）**输出有意识说出的话。物理攻击走 CSTC 感觉运动环路（M1+壳核，认知槽=0），精神攻击需要初级执行控制参与（L5 dlPFC/ACC 的最简形式，认知槽=1）。链路的髓鞘化增强、调制或暂时压制这些基础行动。
>
> **设计原则**: 身体不需要大脑许可就能出拳。但要让对方的精神崩溃，你需要集中注意力。

## 二、行动设计

### 行动 1: 物理攻击

```
脑区: M1 + 壳核 (CSTC 感觉运动环路)
类型: 物理伤害 — 开局可用
```

**效果:** 对单个敌方造成 4 物理伤害。

**命中判定:**
- 基础命中率 85%
- 受 L0 趋向 回避状态影响: -10%
- 受 L1 失望标记影响: -5%/层
- 受 L3 执行动作(精准模式)影响: +20%

**消耗:** AP 1, 认知槽 0, 冷却 0

**武器加成（延后设计）:**
- 武器在战斗外装备，改变物理攻击的伤害/命中/AP/特效
- 当前设计阶段仅保留空手基线

---

### 行动 2: 精神攻击

```
脑区: dlPFC/ACC → 无特定运动输出（精神攻击没有"运动通路"）
类型: 精神伤害 — 开局可用
```

**效果:** 对单个敌方造成 2 精神伤害 → 敌方 SAN -2, HP -1。

**精神攻击的本质:**
- 不是"发出精神波"——是"你的存在、你的凝视、你的意志对他人构成的精神压力"
- 在月光下，这种压力变得物理上真实（观察者效应）
- 精神攻击无视物理防御（闪避/格挡无效——对方的言语/凝视必然进入感知）

**命中:** 精神攻击**永远命中**——你无法选择不听别人的话、不看别人的眼神。但你是否被它动摇，取决于你当下的认知状态。

**防御（认知槽负载惩罚）:**
- 精神防御不是闪避——是前额叶对情绪信号的**认知重评**（reappraisal）
- 认知重评需要 dlPFC 有空闲处理槽位——槽越满，精神防御越弱
- 公式:
  ```
  精神攻击实际伤害 = base × (1 + motivation_mod)
                     × (1 + 敌方认知槽负载惩罚)
                     - 敌方忍耐被动减免

  敌方认知槽负载惩罚 = occupied / max × 0.5
    例: 3/5 槽已占用 → +30% 精神伤害
    例: 0/5 槽 (空载) → 无惩罚
  ```
- **忍耐·主动**: 占用 1 认知槽 → SAN 减免翻倍（-2 而非 -1），持续 1 回合。冷却 2 回合。
- **低 SAN 穿透**: 敌方 SAN < 30 时 → 精神攻击额外 +30% 效果（防线已崩溃）

**消耗:** AP 1, 认知槽 1, 冷却 0

**认知槽为什么是 1:**
- 精神攻击需要"集中注意力给对方施加压力"——这是简化版的执行控制
- L1-L5 的链路髓鞘化后，精神攻击可以通过各种调制降低槽成本或提升效果

---

### 行动 3: 防御

```
脑区: M1 + 苍白球 (CSTC 间接通路 → 运动抑制)
类型: 防御 — 开局可用
```

**效果:**
- 本回合受到的所有物理伤害 -50%
- 本回合不能使用物理攻击（防御和进攻共用 M1 输出通路）
- 本回合可以同时使用精神攻击或感知类技能
- 不能减少精神伤害

**消耗:** AP 1, 认知槽 0, 冷却 1 回合

**冷却设计意图:**
- 不能连续防御——身体需要切换回进攻状态
- 1 回合冷却意味着：防御→暴露→防御→暴露 的节奏
- L5 控制 可以花 2 认知槽延长防御 1 回合（打破冷却限制）

## 三、链路调制如何增强基础行动

| 层级 | 操作 | 对物理攻击 | 对精神攻击 | 对防御 |
|------|------|----------|----------|--------|
| L0 | 趋向(趋近) | 伤害 +10% | — | — |
| L0 | 趋向(回避) | 命中 -10% | — | 减伤 +10% (总 -60%) |
| L0 | 熟练 | 连续物理攻击第3次 AP-1 | — | — |
| L0 | 激活(蓝斑) | — | 精神伤害 +1 | — |
| L1 | 期待(每层) | 伤害 +1/层 | 精神伤害 +1/层 | — |
| L1 | 失望(每层) | 命中 -5%/层 | 命中 -5%/层 | — |
| L1 | 习惯化 | 物理攻击 AP 减免加速 | 精神攻击 AP 减免加速 | — |
| L2 | 价值直觉 | 高亮"该攻击还是该防御" | — | — |
| L3 | 执行动作(精准) | 命中 +20% | — | — |
| L3 | 身体感知 | 揭示弱点→伤害 +2 | — | 减伤 +10% |
| L4 | 读意图 | 读到攻击→可提前防御 | — | 防御当回合无冷却 |
| L4 | 识别 | 揭示物理弱点→暴击率↑ | 揭示精神弱点→效果↑ | — |
| L5 | 命名 | 命名后对该敌方的物理+精神伤害 +20% | — | — |
| L5 | 决策 | 锁定攻击→伤害 +20% | 锁定攻击→伤害 +20% | 锁定防御→减伤 +10% |
| L5 | 控制 | 压制回避→物理攻击正常命中 | 压制忍耐→敌方 SAN 减免失效 | 延长防御 1 回合 (2槽) |
| L5 | 计划 | 预设"攻→防"序列→第2步AP-1 | — | — |
| L6 | 叙事重构 A | — | — | 忍耐 SAN 减免翻倍 |
| L6 | 叙事重构 B | 友方受伤→攻击 +25% | — | 防御时可分担友方伤害 |
| L6 | 叙事重构 C | 一回合双攻击 | — | — |
| L6 | 全脑协调 | 一回合攻击+防御各1次 | — | — |
| L6 | 裁决(自动模式) | 交给身体→命中+20% | — | 交给身体→减伤+10% |

## 四、参数速查

| 参数 | 值 | 说明 |
|------|-----|------|
| 物理攻击 AP | 1 | |
| 物理攻击 认知槽 | 0 | CSTC环路自动化 |
| 物理攻击 基础伤害 | 4 | 空手 |
| 物理攻击 伤害公式 | `4 × (1 + force_mod + motivation_mod)` | force cap +50%, motivation cap +100% |
| 物理攻击 基础命中 | 85% | 受执行动作/读意图/失望调制 |
| 精神攻击 AP | 1 | |
| 精神攻击 认知槽 | 1 | 需要集中注意力 |
| 精神攻击 SAN伤害 | 2 | |
| 精神攻击 HP伤害 | SAN伤害的 1/2（向下取整） | |
| 精神攻击 命中 | 永远命中 | 无命中率判定 |
| 精神攻击 伤害公式 | `2 × (1 + motivation_mod) × (1 + 敌方认知槽负载) - 敌方忍耐` | |
| 敌方认知槽负载惩罚 | occupied/max × 0.5 | 槽越满，精神防御越弱 |
| 敌方低SAN穿透 | SAN<30→+30%, SAN<15→×2 | 精神防线崩溃加速 |

| 防御 认知槽 | 0 | |
| 防御 减伤 | -50% | 仅物理伤害 |
