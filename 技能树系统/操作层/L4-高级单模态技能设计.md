# L4 高级单模态 — 模式识别与分类

> L3 给你像素和声波。L4 给你"那是一只老虎"——模式识别、特征绑定、分类。L4 的核心操作是**贴标签**：这个东西属于什么类别。标签一旦贴上，会向下改变 L1-L2 的反应（杏仁核对"蛇"的反应取决于 L4 有没有认出它是蛇）。
>
> **设计原则**: L4 操作不直接产生伤害或防御，但决定了下层反应的质量。"认错东西"和"认对东西"的后果完全不同。L4 是浮现式技能的主要触发层——当 L4 识别 + L5 命名 + L1 恐惧条件化同时激活 → 浮现"猎手"等命名技能。

## 一、L4 操作总览

15 个 L4 脑区合并为 **4 个操作**，2 主动 + 2 被动：

| # | 操作 | 脑区 | 性质 | 激活点 | 核心效果 |
|---|------|------|------|--------|---------|
| 1 | **识别** | 颞下回 + 纺锤体回 + 外侧枕叶 + 舌回 | 主动 | 1 | 判断敌方类别→揭示弱点/抗性 |
| 2 | **读意图** | 颞上沟岸 + 颞中回(MT) | 被动始终 | 0（自动） | 从动作预读敌方下回合行为 |
| 3 | **比喻** | 角回 | 被动始终 | 0（自动） | 跨域映射→同类技能连携加成 |
| 4 | **想象** | 楔前叶 + 顶内沟 + 顶叶 | 主动 | 1 | 脑内模拟一个可能的未来回合 |

**合并说明:**
- 纺锤体回(面孔识别) + 颞下回(物体识别) + 外侧枕叶(LO物体区) + 舌回(颜色/文字) → 合并为"识别"——都是视觉分类，分类对象不同
- 颞上沟岸(生物运动) + 颞中回(运动处理MT) → 合并为"读意图"——从运动推断意图
- 楔前叶(视觉意象) + 顶内沟(空间注意) + 顶叶(体感整合) → 合并为"想象"——多模态心理模拟

## 二、操作设计

### 操作 1: 识别 (Identify)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: 颞下回 + 纺锤体回 + 外侧枕叶 + 舌回
MNI:  颞下回 (-48, -50, -18)    → 游戏 (-0.72, 0.18, -0.27)
      纺锤体回 (-40, -50, -22)   → 游戏 (-0.44, 0.31, -0.34)
      外侧枕叶 (-30, -82, 12)    → 游戏 (-0.33, 0.68, -0.55)
      舌回 (-16, -78, -6)        → 游戏 (-0.18, 0.48, -0.53)
类型: 主动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

选择一个敌方进行识别判定：
- **首次识别**（该类型敌人第一次遇到）：AP 2，揭示敌方类别名称 + 1 个随机属性
- **重复识别**（该类型敌人遇到过）：AP 1，揭示 1 个指定属性（抗性/弱点/技能/状态）
- **纺锤体回组件**（面孔识别）：如果敌方是"人物"类 → 额外揭示其身份/名字（"我见过他"）
  - 如果之前见过 → 触发 L1 回忆的被动效果（警觉+1 标记）

**失败条件:**
- SAN < 30% 时：识别有概率给出错误信息——L4 在精神不稳时会"看错"
- 错误率 = (30 - SAN) / 30 × 100% （SAN=20 时 ~33% 错误率）

**对 L3 的调制:**
- 识别成功后，注视 AP 消耗 -1（"已经知道它是什么了，不需要盯那么仔细"）

**对 L1-L2 的调制:**
- 成功识别敌方 → 恐惧条件化对该敌方的标记获取速度 +50%（"我知道你是什么——学会怕你更快"）
- 如果 L2 识人已解锁 → 识别同时触发识人的社会角色判断——"不只知道你是谁，还知道你的身份"

**AP 消耗:** 2（首次）/ 1（重复）
**认知槽占用:** 1
**冷却:** 0（可连续识别不同目标；同一目标每 3 回合可重新识别）

**设计依据:**
颞下回: 腹侧视觉通路("what"通路)的终点——物体识别和精细分类。纺锤体回: FFA(面孔区)
和 VWFA(视觉词形区)——面孔和文字的专门识别区。外侧枕叶: LO区，物体级别的形状识别。
舌回: 颜色处理和文字处理。四者构成完整的视觉分类管线：形状(LO)→颜色(舌回)→
类别(IT)→身份(纺锤体回)。

### 操作 2: 读意图 (Read Intent)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: 颞上沟岸 + 颞中回(MT/MST)
MNI:  颞上沟岸 (-52, -44, 8)   → 游戏 (-0.58, 0.64, -0.30)
      颞中回 (-54, -42, -6)     → 游戏 (-0.60, 0.48, -0.28)
类型: 被动(始终生效)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

解锁后，敌方准备技能时：
- 以概率揭示敌方下回合要用的技能类别（攻击/防御/支援/特殊）
- "他动了——他的身体在告诉你他要做什么。不需要说话。"

**概率基于:**
- 基础 40%
- 如果该敌方被 L3 注视 → +25%
- 如果之前成功识别过该敌方 → +25%
- 如果该敌方在上一回合做了类似动作 → +15%
- 上限 85%

**对 L0-L2 的调制:**
- 读意图成功 → 对该敌方的 警觉 标记 +1（"我知道你要干嘛"）
- 读意图揭示"攻击"→ 应激反应的触发阈值临时 +5%（"攻击要来了，提前准备"）
- 读意图 + L2 冲突感知：如果读到的意图与敌方实际行为不符 → 冲突标记自动触发
  "你以为他要攻击——结果他在保护队友。你的模式识别出错了。"

**AP 消耗:** 0（被动）
**认知槽占用:** 0（自动运作——生物运动检测不需要执行控制）
**冷却:** N/A

**设计依据:**
颞上沟岸(STS bank): 生物运动检测——从光点移动就能判断"这是一个在走路的人"
(Johansson 1973 的光点实验)。STS 还参与意图感知和心智化(mind in the eyes test)。
颞中回(MT/MST): 运动处理——MT 编码运动方向和速度，MST 编码复杂运动模式(如旋转、缩放)。
两者结合：MT告诉你"东西在动"，STS告诉"动的东西是不是活的、它想干嘛"。

### 操作 3: 比喻 (Metaphor)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: 角回 (Angular Gyrus)
MNI:  (-44, -62, 36) → 游戏 (-0.51, 0.84, -0.43)
类型: 被动(始终生效)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

解锁后获得"比喻连携"能力：
- 使用某个技能后，如果快捷槽中有另一个技能与该技能**共享一个特征**
  （如同一脑区、同一伤害类型、同一效果类别）→ 该另一个技能在本回合被"点亮"
- 点亮的技能：AP 消耗 -1，效果 +15%

**比喻连携的判定特征:**
1. 同一脑区（如两个都是 dlPFC 技能）
2. 同一效果类型（如两个都是"揭示信息"类）
3. 同一目标（两个技能都针对同一个敌方）

  "角回把 A 映射到 B——'这不只是一拳，这是你欠我的。'
   语言上的隐喻和技能上的连携是同一回事。"

**AP 消耗:** 0（被动）
**认知槽占用:** 0
**冷却:** 每回合最多触发 1 次比喻连携

**设计依据:**
角回: 跨模态语义整合。角回损伤→阅读障碍(失读症)、计算障碍(失算症)、
隐喻理解困难。角回在"概念 A 映射到概念 B"中激活——无论是语言隐喻("时间是金钱")
还是数学类比(2:4=3:x)。"比喻连携"正是这种跨域映射的游戏化表达——把 A 技能
的特征映射到 B 技能上。

### 操作 4: 想象 (Imagine)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: 楔前叶 + 顶内沟 + 顶叶
MNI:  楔前叶 (-8, -60, 40)     → 游戏 (-0.12, 0.88, -0.35)
      顶内沟 (-30, -55, 45)     → 游戏 (-0.28, 0.99, -0.38)
      顶叶 (-35, -60, 40)       → 游戏 (-0.51, 0.84, -0.43)
类型: 主动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

在脑中模拟一个可能的未来：
- 选择一个本回合**不会执行**的技能 → 预览如果执行它会发生什么
- 预览内容：敌方的可能反应（概率分布）、该技能是否命中、预期伤害值
- 预览消耗 AP 但不算入"连续使用"——不影响熟练计数

  "楔前叶在想象未来时激活。你还没做，但你看到了结果。"

**限制:**
- 每场战斗最多使用 2 次
- 预览结果有概率偏差（基础准确度 80%，SAN < 50% → 60%）
- 预览不准时 → 战斗结束后显示"实际 vs 想象"的差异

**对 L2 的调制:**
- 想象成功预测敌方反应 → 冲突感知对该敌方的敏感度 +20%（"我预判了你的预判"）

**AP 消耗:** 1
**认知槽占用:** 2（心理模拟需要大量执行控制资源）
**冷却:** 5 回合

**设计依据:**
楔前叶: 视觉意象和情景记忆——当人"想象未来"时楔前叶和默认网络一起激活。
顶内沟: 空间注意和视觉-运动协调——提供"想象的动作在空间中如何展开"。
顶叶: 体感整合——提供"如果被击中，身体哪个部位会受伤"的模拟。
三者结合构成"在脑内做一次试运行"的完整管线。

## 三、L4 调制矩阵

### L4 → L3-L0

| L4 技能 | → 调制目标 | 调制方式 |
|---------|----------|---------|
| 识别 | L3 注视 | 识别成功→注视AP-1 |
| 识别 | L1 恐惧条件化 | 识别后恐惧标记获取+50% |
| 识别 | L2 识人 | 识别触发识人的社会角色判断 |
| 读意图 | L0 警觉 | 读成功→警觉+1 |
| 读意图 | L0 应激反应 | 读到攻击→应激阈值临时+5% |
| 读意图 | L2 冲突感知 | 意图≠实际→自动冲突标记 |
| 比喻 | L1 熟练 | 比喻连携算作连续使用(不重置计数) |
| 想象 | L2 冲突感知 | 成功预测→冲突敏感度+20% |

### L4 → L5 (前向连接)

| L4 技能 | → L5 技能(待设计) | 关系 |
|---------|-----------------|------|
| 识别 | 命名(Broca) | 识别→贴上类别标签→命名将标签固化为语言 |
| 读意图 | 换位(TPJ) | 读身体意图→换位读心理意图 |
| 比喻 | 隐喻(Broca) | 概念映射→语言表达 |
| 想象 | 计划(dlPFC) | 单步模拟→多步规划 |
