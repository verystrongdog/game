## 一、设计动机

认知神经科学的核心发现：前额叶-顶叶多重需求网络（MD network）一次只能处理**一个**需要意识控制的任务（Psychological Refractory Period）。知觉阶段可以并行，自动行为可以并行。

这解释了"一边深度思考一边转笔"——转笔走小脑+壳核（L0-L1 自动化），不经过中央瓶颈。深度思考（L5 dlPFC）独占瓶颈。

设计含义：
- L0-L2 自动链路：不占槽位（身体替你并行处理）
- L3-L4 感知链路：轻量，可同时 2-3 个
- L5 控制链路：占用中央瓶颈——基础 1 个
- 髓鞘化后的链路：从"占槽"降为"不占槽"——自动化释放瓶颈

## 二、链路槽位规则

### 2.1 槽位预算

```
基础槽位: 4（Cowan 2001 工作记忆容量 3-4）
SAN 加成: 基础 + floor(SAN / 30)
  SAN = 60  → 4 + 2 = 6 槽
  SAN = 90  → 4 + 3 = 7 槽
  SAN < 30  → 4 + 0 = 4 槽（恐慌收缩）
```

### 2.2 各层级槽位占用

| 层级 | 槽占用 | 说明 |
|------|--------|------|
| L0-L2 自动链路 | 0 | 情境自动激活，不占槽 |
| L3 感知 | 1 | 注视/聆听/身体感知 |
| L4 识别 | 1 | 识别/读意图/比喻 |
| L5 控制 | 1-2 | 计划/命名/控制/换位 |
| L6 叙事 | 2-3 | 叙事重构/全脑协调/裁决 |

### 2.3 髓鞘化释放槽位

| 髓鞘化程度 | 槽位变化 | 说明 |
|-----------|---------|------|
| m < 0.5 | 正常占用 | 需要执行控制参与 |
| m 0.5-0.7 | L3-L4 链路槽位减半（向下取整，min=0） | 半自动化 |
| m ≥ 0.7 | L3-L4 链路 → 0 槽，L5 链路 → 槽位 -1 | 自动化 |
| m = 1.0 | L5 链路 → 0 槽（完全自动化） | 精通 |

### 2.4 持续占用

某些操作激活后跨回合持续——持续占用槽位，直到释放或操作结束：

| 操作 | 持续槽 | 释放条件 |
|------|--------|---------|
| 命名（L5） | 1 | 敌方倒地 / 主动撤销 |
| 计划（L5） | 1 | 计划执行完毕 |
| 压制恐慌（忍耐·主动） | 1 | 持续 1 回合 |
| 激活·疲劳回合 | 1 | 1 回合后自动释放 |
| 叙事重构（L6） | 2-3 | 2 回合后释放 |
| 全脑协调·烧脑 | 2 | 2 回合后释放 |

**槽位不足时不能激活需要持续占用的操作。**

## 三、情境 → 自动激活

### 3.1 主导观察源

**医院**是主导观察者，施加共享的情境基线。玩家/NPC 的个体差异是基线之上的小扰动。

### 3.2 情境生成流程

```
空间类型（物理医院/扭曲空间/患者世界/轮回）
  → 医院对该空间的"观察向量"
    → 主导情境原型（27 原型之一）
    → RDoC 6 领域权重偏置
  → 个体扰动叠加
    → SAN 状态（越低越诡异）
    → L1 经验调制（恐惧条件化/辨别/识景）
    → L3 感知精度
  → 最终情境向量
    → 确定激活的 Kroell 功能网络
    → 网络中 L0-L2 链路自动激活（免费，不占槽）
```

### 3.3 扰动规则

- SAN ≥ 60：个体情境 ≈ 医院基线（扰动 < 5%）
- SAN 30-59：应对能力维度向"低应对能力"偏移；新颖性维度随机 ±10%
- SAN < 30：应对能力严重偏移 + 规范兼容性偏移（"这不符合我的价值观"）；L0-L2 自动激活可能额外触发焦虑/恐慌相关链路
- SAN < 15：医院观察开始动摇——L0-L2 自动激活可能随机触发不应激活的链路（幻觉）

### 3.4 月光调制

月光强度 1.0-2.0×：放大所有情境的情绪维度（RDoC 负价/正价领域权重 × 月光倍率）。月光满月时，医院的观察不稳定，情境基线可能偏移。

## 四、手动激活流程

### 4.1 回合流程

```
1. 情境触发 → 自动激活 L0-L2 链路（免费，不占槽）
2. 玩家在槽位预算内选择激活 L3-L6 链路
3. 持续占用从上一回合继承
4. 新激活 + 持续占用 ≤ 当前槽位上限
5. 所有激活链路调制汇总 → M1/Broca → 动作品质
6. 回合结束：非持续链路释放槽位
```

### 4.2 玩家视角

- 大脑视图打开 → 可点击的 L3-L6 脑区高亮
- 已由情境激活的 L0-L2 脑区 = 发光但不可点击（已自动激活）
- 槽位计数器显示：已用/上限
- 持续占用的链路 = 特殊高亮 + 锁图标

### 4.3 NPC AI 版本

> 详见 [NPC AI 行为模型](../NPC%20AI%20行为模型.md) — 完整设计文档。

NPC 行为 = 情境基线激活 + 预烘焙查表（离线加权采样）+ 髓鞘化模式（= 性格标签偏移）+ 在槽位约束下从分布中采样。NPC 不和玩家一样在线逐链路搜索——预烘焙表已编码槽位约束，运行时只做 O(1) 查表。

## 五、SAN 恢复机制

### 5.1 战斗内 — 主动操作

| 操作 | SAN 恢复 | 成本 | 限制 |
|------|---------|------|------|
| L2 内省 | +5 | AP 1, 占 1 槽, CD 4 | 恐慌状态不可用 |
| L5 自省（元认知） | +3 | AP 1, 占 1 槽, CD 5 | 可清除负面标签 |

### 5.2 战斗内 — 条件触发

| 条件 | SAN 恢复 |
|------|---------|
| 成功压制恐慌强制（忍耐·主动） | +2 |

## 六、休息与偷袭

### 6.1 触发

玩家主动宣布休息——进入休息回合制。本回合不行动。

### 6.2 恢复公式

```
每休息回合: SAN +5
持续休息: 无 CD 限制
恢复速度 = 和内省相同（+5/回合），但不受 CD 限制
```

### 6.3 偷袭概率

```
第 1 回合休息: 基础概率
第 2 回合: ×2
第 3 回合: ×3
第 4 回合及以后: ×4（封顶）
```

**基础概率由以下因素决定（相乘）：**
- 空间属性：扭曲空间 > 患者世界 > 物理医院
- 最近敌人距离：越近越高
- 自身 SAN 状态：SAN < 30 时基础概率 +50%（感知精度低 → 更容易被发现）

### 6.4 偷袭后果

- 敌方获得 1 回合先手
- 休息被打断（已恢复的 SAN 不损失）
- 玩家被迫进入战斗
