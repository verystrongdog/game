# 大脑形态技能树 — 设计文档

> 技能树从"三根主干晶体树"重构为"玻璃大脑"形态。态度模型的 3D 空间 (valence × intensity × autonomy) 成为技能树的底层坐标系，每个脑区对应一类技能，点亮脑区 = 激活技能。

## 一、设计动机

旧树形态的问题：
- 认知和行为节点位置由螺旋角度机械决定，缺乏语义依据
- 态度模型已有成熟的 3D 空间，但技能树完全没利用
- 树形拓扑无法表达"不同功能脑区协同工作"

大脑形态的优势：
- 态度模型的 3 个轴天然对应大脑解剖轴
- 7 个驱动极在空间中形成清晰的解剖学聚类
- "玻璃大脑 + 发光脑区"视觉直觉强，符合游戏心理学主题
- 态度模型从"独立可视化"变成"技能树的底层坐标系"

## 二、坐标映射：态度空间 → 大脑解剖轴

态度模型的坐标系来自 Frijda 行为输出空间：

```
B_raw = (V, |A|, D)   ← NRC VAD
驱动极 ← RST + 催产素-多巴胺通路
B_out = w_raw·B_raw + w_drive·drive_pole
```

三个轴直接映射到大脑解剖轴：

| 态度轴 | 符号 | 范围 | 大脑轴 | 解剖含义 |
|--------|------|------|--------|---------|
| Valence (效价) | X | [-0.92, +1.0] | 左右 (lateral) | 左半球 = 回避/负面 (V<0)，右半球 = 趋近/正面 (V>0) |
| Intensity (强度) | Y | [0.11, 0.93] | 上下 (vertical) | 底部 = 脑干/基础反射，顶部 = 皮层/复杂加工 |
| Autonomy (自主性) | Z | [-0.64, +0.73] | 前后 (anterior-posterior) | 后部 = 被动/感官 (D<0)，前部 = 主动控制 (D>0) |

**A 轴的特殊处理：** 唤醒度 (A) 不参与位置映射，改为编码节点发光强度——高 A（如恐惧 A=0.68）= 亮白光，低 A（如平静 A=-0.76）= 暗柔光。

## 三、脑区 → 技能映射

### 3.1 认知分支 → 态度空间三轴映射

认知节点在态度空间中使用三轴映射，每个轴对应态度模型的一个维度，数据来源为 `data/cognition_cards.json` 和 CPM 步骤表（见 [态度系统/态度系统.md](../态度系统/态度系统.md) §①）：

| 态度轴 | 认知映射 | 数据来源 | 范围 |
|--------|---------|---------|------|
| Z (自主性 D) | CPM 步骤主映射——Step1 最被动→后部，Step4 最主动→前部 | `态度系统.md` §① CPM 步骤表 | [−0.60, +0.50] |
| Y (强度 \|A\|) | 加工深度 depth_alpha——System1 浅层→低Y，System2 深层→高Y | `cognition_cards.json` → depth_alpha | [0.38, 0.88] |
| X (效价 V) | 判断偏向 criterion——criterion<0 (宽松/外向)→左，criterion>0 (保守/内向)→右 | `cognition_cards.json` → criterion | [−0.48, +0.36] |

**模块 Z 值（CPM 步骤主映射）：**

| 层级 | 模块 | CPM 步骤 | Z |
|------|------|---------|-----|
| L1 | 知觉与注意 | Step 1 (Relevance) — 最被动，检测输入 | −0.60 |
| L2 | 记忆 | Step 2 (Implications) — 提取经验 | −0.35 |
| L3 | 知识表征与分类 | Step 2+4 (Implications + Normative) — 归类与判定 | −0.10 |
| L4 | 表象与语言 | Step 3+4 (Coping + Normative) — 命名赋予现实性 | +0.15 |
| L5 | 推理与决策 | Step 2+3 (Implications + Coping) — 规划与控制 | +0.50 |

**节点 X、Y 计算公式：**
```
Y = 0.20 + depth_alpha × 0.90
X = criterion × 1.2  (clamped to [−0.55, +0.55])
```

每个模块内 5 个节点按各自的 criterion 和 depth_alpha 在 X、Y 上展开，产生模块内节点间的有意义间距。具体坐标见 §5.3。

### 3.2 情绪分支 → 态度空间直接映射

情绪节点直接使用态度模型中的 B_raw = (V, |A|, D) 坐标（见 §5.1）。这是最精确的放置——每个情绪在其 PAD 空间中的原始位置。A 轴编码为节点发光强度：

|------|------|------|-----|------|-----|----------|
| L1 | 杏仁核+下丘脑+PAG | 快乐 | +0.96 | 0.65 | +0.59 | 高亮 |
| L1 | | 恐惧 | −0.85 | 0.68 | −0.41 | 高亮 |
| L1 | | 平静 | +0.60 | 0.76 | +0.11 | 暗柔 |
| L2 | 腹侧纹状体/NAcc+BNST | 希望 | +0.85 | 0.37 | +0.48 | 暗柔 |
| L2 | | 愤怒 | −0.67 | 0.73 | +0.31 | 高亮 |
| L2 | | 悲痛 | −0.90 | 0.42 | −0.67 | 暗柔 |
| L3 | 前脑岛+ACC | 共情 | +0.46 | 0.30 | +0.09 | 暗柔 |
| L3 | | 爱 | +1.00 | 0.04 | +0.35 | 中亮 |
| L3 | | 焦虑 | −0.71 | 0.73 | −0.32 | 高亮 |
| L3 | | 厌恶 | −0.90 | 0.55 | −0.37 | 高亮 |
| L4 | OFC+mPFC+颞极 | 绝望 | −0.77 | 0.59 | −0.51 | 高亮 |
| L4 | | 内疚 | −0.58 | 0.13 | −0.59 | 中亮 |
| L4 | | 敬畏 | −0.06 | 0.48 | −0.40 | 中亮 |
| L4 | | 孤独 | −0.50 | 0.55 | −0.52 | 暗柔 |
| L5 | mPFC-杏仁核耦合 | 恐怖 | −0.77 | 0.70 | −0.12 | 高亮 |

> **注意：** 上表中的 V、|A|、D 即为节点在态度空间中的 (X, Y, Z) 坐标。情绪节点坐标 = (V, |A|, D)，精确对应态度模型 §② 的 NRC VAD 数据。层级是解锁先后顺序，不是空间层级——例如爱(V=+1.00, |A|=0.04, D=+0.35)在空间上位于大脑底部右前方，而平静(|A|=0.76)位于大脑顶部。

### 3.3 行为分支 → 态度空间驱动质心

行为节点放置在态度模型中该驱动下所有自然态态度行为输出的质心位置（见 §5.2 的质心计算公式）。每个驱动的 3 个节点在质心周围小幅偏移：

| 层级 | 脑区 | 驱动 | 节点 | 质心 (X, Y, Z) | 偏移范围 |
|------|------|------|------|----------------|---------|
| L1 | PAG+上丘+脑干 | 反射 | 逃跑/僵住/闪避 | (−0.85, **0.71**, −0.52) | ±0.02 |
| L2 | 基底节+杏仁核 | 惩罚机制 | 回避/妥协/克制 | (−0.54, **0.52**, −0.34) | ±0.02 |
| L2 | NAcc+VTA/多巴胺 | 奖励机制 | 试探/追求/坚持 | (+0.61, **0.54**, +0.17) | ±0.02 |
| L3 | vmPFC+TPJ+楔前叶 | 道德驱动 | 自责/维护/坚守 | (+0.17, **0.46**, +0.39) | ±0.02 |
| L3 | mPFC+颞极+后扣带 | 文化习俗 | 遵从/从众/运用仪式 | (−0.09, **0.36**, −0.07) | ±0.02 |
| L4 | ACC+额顶控制网络 | 价值驱动 | 牺牲/对抗/突破 | (+0.58, **0.78**, +0.59) | ±0.02 |
| L4 | 前脑岛+ACC+VTA | 照护 | 安抚/保护/舍身 | (+0.41, **0.71**, +0.28) | ±0.02 |

> **注意：** Y = |A|（行为强度），不是神经层级。反射驱动有最高行为强度(Y=0.71)，因为它是最激烈的身体反应。文化习俗有最低行为强度(Y=0.36)，因为它是外部脚本驱动的低强度行为。这与神经解剖学自下而上的"控制层级"是**不同的轴**——不要混淆。

### 3.4 终极技能 → 全脑整合网络

13 个终极技能放在三个大规模脑网络的交汇处——大脑前额叶极：

| 网络 | 说明 |
|------|------|
| 默认模式网络 (DMN) | 自我叙事、人格一致的行动 |
| 额顶控制网络 (FPN) | 跨脑区协调、执行控制 |
| 突显网络 (SN) | 检测关键信号、切换网络 |

终极技能位置：Y≈0.96, Z≈0.60, X 由对应态度组合决定。详见 [终极技能设计](./终极技能设计.md)。

## 四、大脑 3D 形态

### 4.1 玻璃大脑几何体

使用 BigBrain 3D 打印 STL 模型（CC BY-SA 4.0, ~16K 顶点, 9 脑区顶点着色）——真实大脑曲面，非椭球近似：

| 组件 | 数据来源 | 顶点数 | 原始范围 |
|------|---------|--------|---------|
| 左半球 | BigBrain 左半脑 STL | 8,000 | X[-0.99, +0.27] Y[0.01, 1.02] Z[-0.73, +0.65] |
| 右半球 | BigBrain 右半脑 STL | 8,000 | X[0.00, +1.10] Y[0.01, 1.03] Z[-0.74, +0.67] |
| 小脑 | 程序化生成 (褶皱球体) | ~400 | 附加于后下方 |
| 脑干 | 程序化锥台 | 80 | 附加于底部 |

**态度空间居中变换：** BigBrain 原始数据不完全居中（纵裂偏右 ~0.14，整体偏后 ~0.08）。通过 `brainGroup`（Three.js Group）应用平移 `(−0.14, +0.03, +0.08)` 将大脑几何体居中于态度空间原点，使纵裂对齐 X=0、脑中心对齐 Y=0.55。

所有技能节点保持在 `brainGroup` 之外的根组 `G` 中，使用态度空间绝对坐标——节点不受大脑几何体的居中变换影响。

### 4.2 材质

- **主体**：半透明玻璃 (MeshPhysicalMaterial: opacity=0.15, roughness=0.3, metalness=0.0)
- **线框叠加**：wireframe geometry (opacity=0.06, color=#4488aa)
- **脑沟纹理**：用 noise-based displacement 或简化——线框密度表示脑沟

### 4.3 包围盒

适配态度空间范围：X∈[-1.1, +1.1], Y∈[0, 1.1], Z∈[-0.8, +0.9]

## 五、节点放置规则

### 5.1 情绪节点 (15)

直接使用 B_raw = (V, |A|, D) 坐标。这是最精确的放置——每个情绪在其态度空间中的原始位置。

```
node.position = (V, |A|, D)
```

### 5.2 行为节点 (21)

每个行为节点放置在对应驱动极方向，沿 B_raw 到 drive_pole 的连线上。具体位置 = 该驱动下所有有效态度的行为输出 B(t) 的质心。

**质心计算公式：**
```
对每个驱动 d 和每个情绪 e：
  若该组合有效（自然/硬解锁/情境）：
    B_raw = (V_e, |A_e|, D_e)
    pole  = drivePole[d]
    权重: natural=0.8/0.2, forced=0.3/0.7, situational=0.5/0.5
    B(t) = w_raw × B_raw + w_drive × pole
质心 = 所有有效 B(t) 的平均值
```

**验证后的驱动质心（态度模型精确计算）：**

| 驱动 | 质心 (V, I, D) | 有效态度数 | 来源 |
|------|---------------|-----------|------|
| 反射 | (−0.85, 0.71, −0.52) | 4 (仅自然) | 恐惧/焦虑/厌恶/绝望 + 反射 natural |
| 惩罚 | (−0.54, 0.52, −0.34) | 15 (自然+硬解锁) | V<0自然, V>0硬解锁 |
| 奖励 | (+0.61, 0.54, +0.17) | 15 (自然+硬解锁) | V>0自然, V<0硬解锁 |
| 道德 | (+0.17, 0.46, +0.39) | 15 (自然+硬解锁) | D>−0.3自然, D≤−0.3硬解锁 |
| 文化习俗 | (−0.09, 0.36, −0.07) | 15 (全部情境) | 全部 0.5/0.5 混合 |
| 价值 | (+0.58, 0.78, +0.59) | 15 (自然+硬解锁) | D>0.3自然, D≤0.3硬解锁 |
| 照护 | (+0.41, 0.71, +0.28) | 15 (全部情境) | 读他人PAD, 0.5/0.5 混合 |

每个驱动的 3 个节点在质心周围小幅偏移（偏移量 ≤ 0.02），方向各异以区分节点。

### 5.3 认知节点 (25)

认知节点使用态度空间的三轴映射（详见 §3.1）。每个节点坐标从其 JSON 数据派生：

**Z 轴（自主性 D — CPM 步骤主映射）：**
```
Z 按模块 CPM 主步骤确定（同模块内所有节点共享）：
  Step 1 (知觉与注意):           Z = −0.60  (最被动)
  Step 2 (记忆):                 Z = −0.35
  Step 2+4 (知识表征):           Z = −0.10
  Step 3+4 (表象与语言):         Z = +0.15
  Step 2+3 (推理与决策):         Z = +0.50  (最主动)
```

**Y 轴（强度 — 加工深度 depth_alpha）：**
```
Y = 0.20 + depth_alpha × 0.90
范围: depth_alpha ∈ [0.20, 0.75] → Y ∈ [0.38, 0.88]
```

**X 轴（效价 — 判断偏向 criterion）：**
```
X = criterion × 1.2  (clamped to [−0.55, +0.55])
criterion < 0 → 宽松/左 (更易报告信号)
criterion > 0 → 保守/右 (更严格过滤)
```

数据来源：`data/cognition_cards.json` 中各卡片的 `cognitive_quality.depth_alpha` 和 `cognitive_quality.criterion`。

### 5.4 终极技能 (13)

放置在其对应态度组合的行为输出坐标 B(t) = w_raw × B_raw + w_drive × drive_pole。从 `data/attitudes.json` 中读取 emotion×drive 组合，按态度模型可视化中的行为输出公式计算。详见 [终极技能设计](./终极技能设计.md)。

> **已验证：** HTML 中 13 个终极技能坐标已从 `data/attitudes.json` 的 behavior_output 字段同步更新（2026-07-11），与态度模型公式 B(t) = w_raw × B_raw + w_drive × drive_pole 完全一致。

## 六、解锁可视化

### 6.1 状态 → 视觉映射

| 状态 | 节点外观 | 脑组织光晕 |
|------|---------|----------|
| 未解锁 | 暗灰色小点 (opacity=0.3)，在玻璃脑内几乎不可见 | 无 |
| 可解锁 | 微弱脉冲光点 (opacity=0.6, pulse 1Hz) | 无 |
| 已解锁 | 明亮发光球体 (opacity=1.0) + 分支色 | 周围脑组织产生 fMRI 式热力光晕——从节点中心向外扩散的暖色半透明球 (radius≈0.15, opacity=0.15) |
| 冷却中 | 半透明灰色覆盖 + 蓝色冷光晕 + 旋转粒子 | 光晕变冷色调 (蓝→紫) |
| 终极技能 | 大型多棱晶体 (radius×1.6) + 金色粒子环绕 | 十字形光柱 + 全脑微闪 |

### 6.2 脑区激活

当一个脑区的节点全部解锁时，该脑区的玻璃材质颜色从冷灰变为该分支的暖色调（认知→蓝紫暖化，情绪→暖橙暖化，行为→青蓝暖化）。

### 6.3 解锁动画

```
0.0s  点击解锁
0.0-0.3s  节点从灰→色（色相旋转 + 饱和度上升）
0.1-0.5s  fMRI 光晕从节点中心向外扩散（半径 0→0.15）
0.2-0.6s  沿白质纤维束的光脉冲传播到前置节点
0.5-1.0s  光晕稳定到默认强度
```

## 七、连接线设计

### 7.1 纤维束式弧线

前置关系连线使用 Bezier 曲线，模仿脑成像中的 DTI tractography（弥散张量纤维束成像）：

- **已解锁连线**：发光管道 (TubeGeometry, radius=0.008)，颜色 = 起点节点分支色
- **未解锁连线**：暗灰色虚线 (LineDashedMaterial, opacity=0.2)
- **正在传播脉冲**：沿管道移动的光点（解锁动画期间）

### 7.2 前置关系类型

| 类型 | 示例 | 弧线弯曲 |
|------|------|---------|
| 同分支内 | 情绪 L1→L2 | 小弯曲 (midpoint offset=0.05) |
| 跨分支 | 行为 L2→认知 L2 记忆 | 大弯曲 (midpoint offset=0.15) |
| 终极技能 | 三枝汇聚到终极节点 | 三条弧线从不同方向汇聚 |

## 八、与旧树形态的对比

| 维度 | 旧树形态 | 大脑形态 |
|------|---------|---------|
| 空间坐标 | 螺旋角度 + 层级高度 | 态度模型 3D 空间 (V, |A|, D) |
| 语义依据 | 无——机械放置 | 有——神经解剖学对应 |
| 态度模型关系 | 独立，不互通 | 技能树直接使用态度空间作为坐标系 |
| 三大分支 | 三根分立的树干 | 三个梯度嵌入同一大脑（后→前, 深→浅, 底→顶） |
| 技能交互 | 前置连线穿过虚空 | 白质纤维束在脑内连接 |
| 视觉直觉 | "晶体树" | "点亮脑区" |
| 终极技能 | 树顶交汇光环 | 前额叶极——全脑网络整合 |
