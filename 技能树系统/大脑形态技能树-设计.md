# 大脑形态技能树 — 设计文档

> 技能树从"三根主干晶体树"重构为"玻璃大脑"形态。态度模型的 3D 空间 (valence × intensity × autonomy) 成为技能树的底层坐标系，每个脑区对应一类技能，点亮脑区 = 激活技能。

## 一、设计动机

旧树形态的问题：
- 认知和行为节点位置由螺旋角度机械决定，缺乏语义依据
- 态度模型已有成熟的 3D 空间，但技能树完全没利用
- 树形拓扑无法表达"不同功能脑区协同工作"

大脑形态的优势：
- 态度模型的 3 个轴天然对应大脑解剖轴
- 7 个驱动极在空间中形成清晰的解剖学聚类
- "玻璃大脑 + 发光脑区"视觉直觉强，符合游戏心理学主题
- 态度模型从"独立可视化"变成"技能树的底层坐标系"

## 二、坐标映射：态度空间 → 大脑解剖轴

态度模型的坐标系来自 Frijda 行为输出空间：

```
B_raw = (V, |A|, D)   ← NRC VAD
驱动极 ← RST + 催产素-多巴胺通路
B_out = w_raw·B_raw + w_drive·drive_pole
```

三个轴直接映射到大脑解剖轴：

| 态度轴 | 符号 | 范围 | 大脑轴 | 解剖含义 |
|--------|------|------|--------|---------|
| Valence (效价) | X | [-0.92, +1.0] | 左右 (lateral) | 左半球 = 回避/负面 (V<0)，右半球 = 趋近/正面 (V>0) |
| Intensity (强度) | Y | [0.11, 0.93] | 上下 (vertical) | 底部 = 脑干/基础反射，顶部 = 皮层/复杂加工 |
| Autonomy (自主性) | Z | [-0.64, +0.73] | 前后 (anterior-posterior) | 后部 = 被动/感官 (D<0)，前部 = 主动控制 (D>0) |

**A 轴的特殊处理：** 唤醒度 (A) 不参与位置映射，改为编码节点发光强度——高 A（如恐惧 A=0.68）= 亮白光，低 A（如平静 A=-0.76）= 暗柔光。

## 三、脑区 → 技能映射

### 3.1 认知分支 → 新皮层（后→前梯度）

认知 5 模块沿皮层后→前轴排列，对应信息加工从感觉到推理的层级：

| 层级 | 模块 | 脑区 | 节点 | Y | Z |
|------|------|------|------|---|---|
| L1 | 知觉与注意 | 枕叶+顶叶 (V1-V5, 顶内沟) | 洞见/凝神/察微/纵观/警觉 | 0.25 | -0.60 |
| L2 | 记忆 | 颞叶/海马体+内嗅皮层 | 拾遗/追忆/闪回/铭刻/释怀 | 0.45 | -0.35 |
| L3 | 知识表征 | 颞顶联合区(TPJ)+颞下回 | 甄别/定性/归因/正名/类比 | 0.65 | -0.10 |
| L4 | 表象与语言 | Wernicke区+Broca区+角回 | 隐喻/白描/构想/转述/命名 | 0.82 | +0.15 |
| L5 | 推理与决策 | 前额叶(dlPFC+vmPFC+额极) | 预判/决意/筹算/推演/权衡 | 0.95 | +0.50 |

**X 轴分布：** 认知节点在 X 轴上按唯物/唯心倾向分布。唯物倾向偏左（外部世界→客观），唯心倾向偏右（内部世界→主观）。5 个节点在 X∈[-0.5, +0.5] 范围内均匀分布。

### 3.2 情绪分支 → 边缘系统（深→浅梯度）

情绪沿脑深部→皮层表面梯度排列，A 轴编码为发光强度：

| 层级 | 脑区 | 情绪 | Y | X (V 值) | 发光 (A) |
|------|------|------|---|----------|---------|
| L1 | 杏仁核+下丘脑+PAG | 快乐 | 0.10 | +0.96 | 高亮 |
| L1 | | 恐惧 | 0.10 | -0.85 | 高亮 |
| L1 | | 平静 | 0.10 | +0.60 | 暗柔 |
| L2 | 腹侧纹状体/NAcc+BNST | 希望 | 0.28 | +0.85 | 暗柔 |
| L2 | | 愤怒 | 0.28 | -0.67 | 高亮 |
| L2 | | 悲痛 | 0.28 | -0.90 | 暗柔 |
| L3 | 前脑岛+ACC | 共情 | 0.50 | +0.46 | 暗柔 |
| L3 | | 爱 | 0.50 | +1.00 | 中亮 |
| L3 | | 焦虑 | 0.50 | -0.71 | 高亮 |
| L3 | | 厌恶 | 0.50 | -0.90 | 高亮 |
| L4 | OFC+mPFC+颞极 | 绝望 | 0.70 | -0.77 | 高亮 |
| L4 | | 内疚 | 0.70 | -0.58 | 中亮 |
| L4 | | 敬畏 | 0.70 | -0.06 | 中亮 |

**Z 轴（前后）：** 情绪节点 Z 坐标 = D 值 × 0.6。愤怒 (D=+0.31→Z=+0.19) 是唯一 D>0 的情绪——唯一主动靠近威胁源的情绪。

### 3.3 行为分支 → 基底节+运动系统+前额叶

行为沿脑干→前额叶的"控制梯度"排列：

| 层级 | 脑区 | 驱动 | 节点 | Y | Z | X 聚类 |
|------|------|------|------|---|---|--------|

| L2 | NAcc+VTA/多巴胺 | 奖励机制 | 试探/追求/坚持 | 0.35 | 0.00 | X≈+0.61 |
| L3 | vmPFC+TPJ+楔前叶 | 道德驱动 | 自责/维护/坚守 | 0.60 | +0.25 | X≈+0.16 |
| L3 | mPFC+颞极+后扣带 | 文化习俗 | 遵从/从众/运用仪式 | 0.55 | -0.05 | X≈0.0 |

### 3.4 终极技能 → 全脑整合网络

13 个终极技能放在三个大规模脑网络的交汇处——大脑前额叶极：

| 网络 | 说明 |
|------|------|
| 默认模式网络 (DMN) | 自我叙事、人格一致的行动 |
| 额顶控制网络 (FPN) | 跨脑区协调、执行控制 |
| 突显网络 (SN) | 检测关键信号、切换网络 |

终极技能位置：Y≈0.96, Z≈0.60, X 由对应态度组合决定。详见 [终极技能设计](./终极技能设计.md)。

## 四、大脑 3D 形态

### 4.1 玻璃大脑几何体

使用 Three.js 几何体近似——不追求解剖学精度，追求一眼认出是"大脑"：

| 组件 | 几何体 | 参数 | 位置 |
|------|--------|------|------|
| 左半球 | 椭球体 (scaled sphere) | rx=0.55, ry=0.90, rz=0.70 | X=-0.55, Y=0.55, Z=0.0 |
| 右半球 | 椭球体 (scaled sphere) | rx=0.55, ry=0.90, rz=0.70 | X=+0.55, Y=0.55, Z=0.0 |
| 纵裂间隙 | — | gap=0.08 | X=0 |
| 小脑 | 扁椭球体 | rx=0.35, ry=0.20, rz=0.30 | X=0, Y=0.15, Z=-0.55 |
| 脑干 | 锥台 (tapered cylinder) | r_top=0.08, r_bot=0.12, h=0.20 | X=0, Y=0.02, Z=-0.15 |

### 4.2 材质

- **主体**：半透明玻璃 (MeshPhysicalMaterial: opacity=0.15, roughness=0.3, metalness=0.0)
- **线框叠加**：wireframe geometry (opacity=0.06, color=#4488aa)
- **脑沟纹理**：用 noise-based displacement 或简化——线框密度表示脑沟

### 4.3 包围盒

适配态度空间范围：X∈[-1.1, +1.1], Y∈[0, 1.1], Z∈[-0.8, +0.9]

## 五、节点放置规则

### 5.1 情绪节点 (15)

直接使用 B_raw = (V, |A|, D) 坐标。这是最精确的放置——每个情绪在其态度空间中的原始位置。

```
node.position = (V, |A|, D)
```

### 5.2 行为节点 (21)

放置在对应驱动极方向，沿 B_raw 到 drive_pole 的连线上。具体位置 = 该驱动下所有自然态态度的质心：

| 驱动 | 质心 (V, I, D) |
|------|---------------|
| 反射 | (-0.85, 0.71, -0.52) |
| 惩罚 | (-0.65, 0.54, -0.38) |
| 奖励 | (+0.61, 0.54, +0.17) |
| 道德 | (+0.16, 0.46, +0.39) |
| 文化习俗 | (-0.09, 0.36, -0.07) |
| 价值 | (+0.58, 0.78, +0.58) |
| 照护 | (+0.41, 0.71, +0.28) |

每个驱动的 3 个节点在质心周围沿驱动极方向小幅偏移（间距 0.08）。

### 5.3 认知节点 (25)

按模块的脑区位置 (Y, Z) 放置。X 按节点在该模块内的序号均匀分布 (X∈[-0.5, +0.5])。具体坐标见 §3.1。

### 5.4 终极技能 (13)

放置在其对应态度组合在态度空间中的 behavior_output 坐标。从 `data/attitudes.json` 中直接读取。

## 六、解锁可视化

### 6.1 状态 → 视觉映射

| 状态 | 节点外观 | 脑组织光晕 |
|------|---------|----------|
| 未解锁 | 暗灰色小点 (opacity=0.3)，在玻璃脑内几乎不可见 | 无 |
| 可解锁 | 微弱脉冲光点 (opacity=0.6, pulse 1Hz) | 无 |
| 已解锁 | 明亮发光球体 (opacity=1.0) + 分支色 | 周围脑组织产生 fMRI 式热力光晕——从节点中心向外扩散的暖色半透明球 (radius≈0.15, opacity=0.15) |
| 冷却中 | 半透明灰色覆盖 + 蓝色冷光晕 + 旋转粒子 | 光晕变冷色调 (蓝→紫) |
| 终极技能 | 大型多棱晶体 (radius×1.6) + 金色粒子环绕 | 十字形光柱 + 全脑微闪 |

### 6.2 脑区激活

当一个脑区的节点全部解锁时，该脑区的玻璃材质颜色从冷灰变为该分支的暖色调（认知→蓝紫暖化，情绪→暖橙暖化，行为→青蓝暖化）。

### 6.3 解锁动画

```
0.0s  点击解锁
0.0-0.3s  节点从灰→色（色相旋转 + 饱和度上升）
0.1-0.5s  fMRI 光晕从节点中心向外扩散（半径 0→0.15）
0.2-0.6s  沿白质纤维束的光脉冲传播到前置节点
0.5-1.0s  光晕稳定到默认强度
```

## 七、连接线设计

### 7.1 纤维束式弧线

前置关系连线使用 Bezier 曲线，模仿脑成像中的 DTI tractography（弥散张量纤维束成像）：

- **已解锁连线**：发光管道 (TubeGeometry, radius=0.008)，颜色 = 起点节点分支色
- **未解锁连线**：暗灰色虚线 (LineDashedMaterial, opacity=0.2)
- **正在传播脉冲**：沿管道移动的光点（解锁动画期间）

### 7.2 前置关系类型

| 类型 | 示例 | 弧线弯曲 |
|------|------|---------|
| 同分支内 | 情绪 L1→L2 | 小弯曲 (midpoint offset=0.05) |
| 跨分支 | 行为 L2→认知 L2 记忆 | 大弯曲 (midpoint offset=0.15) |
| 终极技能 | 三枝汇聚到终极节点 | 三条弧线从不同方向汇聚 |

## 八、与旧树形态的对比

| 维度 | 旧树形态 | 大脑形态 |
|------|---------|---------|
| 空间坐标 | 螺旋角度 + 层级高度 | 态度模型 3D 空间 (V, |A|, D) |
| 语义依据 | 无——机械放置 | 有——神经解剖学对应 |
| 态度模型关系 | 独立，不互通 | 技能树直接使用态度空间作为坐标系 |
| 三大分支 | 三根分立的树干 | 三个梯度嵌入同一大脑（后→前, 深→浅, 底→顶） |
| 技能交互 | 前置连线穿过虚空 | 白质纤维束在脑内连接 |
| 视觉直觉 | "晶体树" | "点亮脑区" |
| 终极技能 | 树顶交汇光环 | 前额叶极——全脑网络整合 |
