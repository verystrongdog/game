## 一、总体定位

3D 技能树是一个**独立的 UI 界面**——不是镜子房间的附属物，不绑定任何特定场景。在战斗间隙通过菜单或快捷键打开。

**设计目标：**
- 一棵抽象的晶体/光树，悬浮在虚空中
- 认知/情绪/行为三大分支从同一根基长出
- 物理距离近的节点 = 概念关系近的节点
- 未解锁节点可见但灰色（全景可见）
- 颜色仅用于 UI 区分分支（不使用颜色表示态度/情绪语义）

## 二、空间结构

### 2.1 整体布局

```
                     ┌── 终极技能层 ──┐     ← Z+ (顶部)
                    /      |      \     \
                   /       |       \     \
              认知枝     情绪枝     行为枝    ← 高层技能
                /          |          \
               /           |           \
           [认知主干]   [情绪主干]   [行为主干]  ← 中层
               \           |           /
                \          |          /
                 \         |         /
                  └────────┴────────┘
                      根基 (Z=0)
```

- **坐标系**：Z 轴 = 高度（技能层级），XY 平面 = 分支之间的空间关系
- **根基**：Z=0 处，三根主干汇聚，直径约 0.3 视觉单位
- **顶层**：Z ≈ 1.0 视觉单位处，终极技能层
- **分支间距**：三根主干在 XY 平面上呈等边三角形（中心到各主干距离约 0.5 单位）

### 2.2 认知分支空间排列

线性垂直排列，5 层子枝：

```
Z 坐标:
  1.00 — L5 推理与决策 (5 节点，水平展开)
  0.75 — L4 表象与语言 (5 节点)
  0.55 — L3 知识表征 (5 节点)
  0.35 — L2 记忆 (5 节点)
  0.15 — L1 知觉与注意 (5 节点)
  0.00 — 认知主干根部
```

每层 5 个节点沿水平方向均匀分布，间距 0.12 单位。

### 2.3 情绪分支空间排列

非线性的 PAD 拓扑投影：

```
PAD 空间 → 3D 位置映射:
  P (V)  → Y 轴（P+ 朝上，P- 朝下）
  D      → X 轴（D+ 朝右，D- 朝左）
  A      → Z 轴偏移（A+ 朝前/观察者方向，A- 朝后）

Z 坐标 (情绪层级):
  0.85 — L5 恐怖
  0.65 — L4 绝望、内疚、敬畏、孤独
  0.45 — L3 共情、爱、焦虑、厌恶
  0.25 — L2 希望、愤怒、悲痛
  0.10 — L1 快乐、恐惧、平静
```

### 2.4 行为分支空间排列

线性垂直，按 S1 快→S2 慢：

```
Z 坐标:
  0.85 — L4 价值、照护 (6 节点)
  0.55 — L3 道德、文化 (6 节点)
  0.30 — L2 惩罚、奖励 (6 节点)
  0.10 — L1 反射 (3 节点)
  0.00 — 行为主干根部
```

### 2.5 连线规则

- **主干**：粗发光线条（宽度 0.02），颜色 = 分支标识色
- **子枝**：中发光线条（宽度 0.01），从主干的对应层级分叉
- **节点连线**：细发光线条（宽度 0.005），从子枝连到各节点
- **跨分支连线**：虚线（仅在选中节点时显示），表示前置关系
- **终极技能**：三根主干的延伸线在顶部交汇点的光芒中汇聚

## 三、节点视觉语言

### 3.1 基本形态

- 所有节点 = 发光晶体球体（基本半径 0.03）
- 认知分支节点 = 多面体形状（呼应复平面 C⁵ 的几何感）
- 情绪分支节点 = 光滑球体（PAD 空间的连续感）
- 行为分支节点 = 棱柱体（驱动方向感）
- 终极技能节点 = 大型多棱面晶体（半径 0.06，粒子环绕）

### 3.2 颜色方案

| 分支 | 主色 | 色值 |
|------|------|------|
| 认知 | 蓝紫 | #6B7FFF → #B388FF |
| 情绪 | 暖色渐变 | 各节点根据 PAD 坐标：P+ → 金色/暖黄，P- → 深红/紫黑, 中性 → 银灰 |
| 行为 | 冷色 | #4FC3F7 → #00BCD4 |

**重要：颜色仅用于 UI 区分分支。** 不使用颜色表示态度/情绪语义（已废弃的颜色系统不可恢复）。

### 3.3 状态视觉

| 状态 | 视觉效果 |
|------|---------|
| **未解锁** | 灰色半透明（α=0.3），轮廓可见，无发光 |
| **可解锁**（有足够点数）| 闪烁微光（频率 1Hz），轻微脉动（scale 1.0→1.1），外环发光 |
| **已解锁** | 颜色饱满（α=0.9），发光，缓慢脉动（频率 0.3Hz） |
| **选中** | 高亮光环（外圈 2× 半径），节点放大（scale 1.3） |
| **冷却中** | 半透明覆盖层（α=0.5 灰色蒙版），旋转沙漏粒子 |
| **强制激活**（恐慌） | 快速闪烁（频率 3Hz），红边脉冲 |

### 3.4 信息面板

点击节点时弹出信息面板（半透明，悬浮在节点旁）：

```
┌─────────────────────┐
│ 决意  [推理 L5]      │  ← 技能名 + 层级
│ ⚡被动               │  ← 主动/被动 图标
│                     │
│ HP < 30% 时          │
│ 所有主动技能冷却 -1   │  ← 效果描述
│                     │
│ 前置: 表象与语言 L4   │  ← 前置条件
│ 解锁: 8 技能点       │  ← 成本
│                     │
│ [解锁] (可解锁时高亮)  │
└─────────────────────┘
```

## 四、交互方式

### 4.1 视角控制

| 输入 | 操作 |
|------|------|
| 鼠标拖动 / 触屏滑动 | 绕树旋转视角（以当前注视点为中心） |
| 滚轮 / 双指缩放 | 缩放（范围：0.3× → 3×） |
| 右键拖动 / 双指平移 | 平移视角 |
| 点击空白处 | 取消选中 |
| F 键 / 双击空白 | 重置视角（回到默认俯瞰角度） |

### 4.2 节点交互

| 操作 | 效果 |
|------|------|
| 悬停 | 节点微微放大（scale 1.1），显示简化提示（技能名 + AP/冷却） |
| 点击 | 选中节点，弹出完整信息面板 |
| 双击（已解锁） | 将技能加入/移出快捷槽 |
| 点击 [解锁] 按钮 | 消费技能点，播放解锁动画 |
| 右键 | 取消选中 |

### 4.3 快捷槽编排

在技能树界面的底部或侧边栏显示 6 个快捷槽：
- 拖拽已解锁节点到槽位 = 装备技能
- 拖出槽位 = 卸下
- 战斗中使用的技能来自快捷槽

### 4.4 搜索和导航

- **搜索栏**：输入技能名快速定位（镜头自动飞向该节点）
- **分支折叠**：点击主干可折叠/展开整根子枝
- **层级高亮**：悬停在快捷槽上时高亮该技能在树上的位置
- **前置高亮**：选中未解锁节点时，高亮所有未满足的前置节点（红色虚线连接）

## 五、成长可视化

### 5.1 解锁动画

```
时间线 (1.0 秒):
  0.0s  点击 [解锁]
  0.0-0.3s  节点从灰色过渡到目标颜色（色相旋转 + 饱和度上升）
  0.1-0.5s  光脉冲从节点沿子枝传播到主干（速度: 0.5单位/秒）
  0.2-0.6s  节点发光强度从 0 上升到 100%
  0.5-1.0s  节点脉动稳定到默认频率
```

### 5.2 子枝点亮

当一根子枝的全部节点被解锁时：
- 该子枝的连线变亮（从暗灰到分支标识色）
- 子枝顶端出现小型结晶（视觉奖励标记）

### 5.3 终极技能解锁

```
时间线 (2.0 秒):
  0.0s   点击解锁终极技能
  0.0-0.5s  三根主干的顶部延伸线亮起
  0.3-1.0s  三条光流从认知/情绪/行为三枝沿主干向上流动
  0.5-1.2s  三道光在顶部交汇——交汇点的晶体生成
  1.0-2.0s  共振光波从晶体向外扩散（覆盖整棵树）
  1.5s     镜头自动推近交汇点
```

### 5.4 树的全景成长

树的整体外观随解锁进度变化：
- **0-20% 解锁**：一棵暗色的骨架，只有少量光点
- **20-50% 解锁**：主干变亮，多条子枝发光
- **50-80% 解锁**：大部分树体发光，多种颜色交织
- **80-100% 解锁**：全树通体发光，三枝交汇处璀璨

## 六、技术约束

### 6.1 性能

- 节点总数：73 个（25 认知 + 15 情绪 + 21 行为 + 12 终极）
- 所有节点使用 Instanced Rendering（共享材质球）
- 发光效果使用 Bloom Post-Processing（不用每节点独立光照）
- 粒子效果仅在冷却中和终极技能节点启用

### 6.2 文件组织

```
/Assets/SkillTree/
  Models/
    node_cognition.fbx      ← 认知节点（多面体）
    node_emotion.fbx        ← 情绪节点（球体）
    node_behavior.fbx       ← 行为节点（棱柱）
    node_ultimate.fbx       ← 终极节点（大晶体）
    branch_trunk.fbx        ← 主干
    branch_sub.fbx          ← 子枝
  Materials/
    mat_cognition.mat
    mat_emotion.mat
    mat_behavior.mat
    mat_locked.mat          ← 未解锁材质
    mat_cooldown.mat        ← 冷却中材质
  Prefabs/
    SkillTree.prefab
    SkillNode.prefab
  Scripts/
    SkillTreeController.cs
    SkillNode.cs
    SkillTreeCamera.cs
    SkillSlotBar.cs
  Data/
    SkillTreeData.cs        ← 技能树拓扑数据（从 JSON 导入）
```

### 6.3 数据驱动

技能树的拓扑结构（节点位置、连线关系、前置条件）应从数据文件（JSON/ScriptableObject）加载，不硬编码。这样设计迭代时只需修改数据文件，无需改动场景。
