## 一、核心矛盾

- 物理约束：一栋精神专科医院，住院部绝大部分房间是 6.9×6.9m 四人间。没有"外面"可去（世界观 §空间扭曲）。
- 内容需求：RPG 需要足够多的战斗场景、探索区域、叙事空间。物理空间很快会耗尽。
- 解决方案：**空间密度 × 空间复用**——同一物理坐标下塞入更多内容（扭曲 + 患者世界），空间昼夜变化和月光强度自然驱动内容变化。**⚠️ "轮回"方案已废除。**

## 二、三层空间模型

> **⚠️ 已废弃（2026-07-28）**：第四层"轮回层"随"局"和"轮回"概念一同废除。空间复用由月光强度和昼夜周期自然驱动。

```
┌──────────────────────────────────────────┐
│  L0: 物理医院（约 50-80 个房间）          │
│  走廊、病房、活动室、食堂、庭院、楼顶      │
│  功能：探索、NPC 对话、资源收集、支线      │
│  规模：固定，手动建模                      │
├──────────────────────────────────────────┤
│  L1: 扭曲空间（物理空间的"膨胀"）          │
│  某些房间内部被月光扭曲——比外面大得多      │
│  功能：战斗场景、隐藏区域、解谜            │
│  规模：在物理房间模型基础上做变体           │
├──────────────────────────────────────────┤
│  L2: 患者内心世界（穿过病房门 = 进入异世界） │
│  每个重要患者对应一个完整的内心关卡         │
│  功能：Boss 战、剧情推进、技能解锁          │
│  规模：独立场景，创作自由度最高             │
└──────────────────────────────────────────┘
```

## 三、L0 物理医院

### 3.1 定位

物理医院是玩家的"基地"和"入口大厅"。所有探索从这里开始，也在这里结束（随身镜子作为回归锚点）。它是所有其他层的锚点。

### 3.2 真实空间利用

| 空间 | 典型尺寸 | 战斗适配 |
|------|---------|---------|
| 走廊 | 宽 2.5-3.5m，长可达几十米 | 杂兵遭遇——走廊两侧的门/窗作为战术掩体 |
| 病房（四人间）| 6.9×6.9m | 探索/叙事/补给——不安排战斗 |
| 活动室/工娱疗室 | 8×12m+ | 精英战斗——每层至少一间 |
| 食堂/餐厅 | 10×15m+ | 精英战斗 |
| 庭院/中庭 | 20×30m+（如有围合式布局）| 关键剧情战 |
| 楼梯间 | 3×6m | 纵向追逐战/逃生 |
| 楼顶天台 | 整栋楼面积 | 关键剧情战 |

### 3.3 病房的角色

- 病房保持真实尺寸，用于 NPC 对话、道具拾取、支线触发、叙事
- 大部分病房（约 70-80%）不安排战斗——它们的功能是**建立"这是一家真实医院"的基线**
- 正是因为有大量"正常"病房，少数扭曲病房才有冲击力
- 病房门面沿走廊排列——门关闭时是立面装饰，门打开时是场景入口

### 3.4 建筑组成与玩家动线

医院由三栋建筑组成：

| 建筑 | 层数 | 定位 |
|------|------|------|
| **住院楼** | 4F，U 形 | 玩家出生点，病房/护士站/诊室/公共空间 |
| **门诊楼** | 3F | 门诊/影像/急诊/心理门诊/行政科研 |
| **供应中心** | 1F | 食堂/洗衣/水电 + 中央露天庭院 |

- **连接方式**：住院楼南连门诊楼，北连供应中心，均通过一层走廊直连
- **出生点**：住院楼 1F
- **房间可入性**：全部房间可进入。锁门留给剧情设定（钥匙/事件解锁）
- **具体房间坐标**：等待点位数据后补充，不在当前设计范围

### 3.5 安全梯度

物理医院不是绝对安全区——安全 = 遭遇但打得过。

| 区域 | 安全等级 | 规则 |
|------|---------|------|
| **住院楼 1F** | 新手村 | 出生点，最低级遭遇，教学引导 |
| **门诊楼 1F** | 稍高 | 出门诊大门 = 第一个"走出去"的挑战 |
| **供应中心** | 独立难度岛 | 不跟楼层梯度，预留 Boss 战空间（剧情设定） |
| **2F** | 中期 | 轻度扭曲空间入口开始出现 |
| **3F** | 后期 | 重度扭曲、Boss 患者世界入口 |
| **4F** | 终局 | 顶层天台关键战 |

### 3.6 楼层门控

- **无硬锁**：玩家技术上可以第一天就上 4F
- **敌人强度自然劝退**：上楼 → 遭遇高级怪 → 被打死 → 读档 → 知道"这里还来早了"
- **红骷髅预警**：若敌方最强链路髓鞘化总值 / 玩家已激活链路髓鞘化总值 > 2.0，该敌人/房间入口显示红色骷髅标记
- **骷髅不等于不可战胜**：只警告差距过大，不暴露具体数值，保持不确定性

### 3.7 护士站——楼层休息节点

护士站贯通所有楼层，是主要的休息/存档点。**不是所有护士站都是安全的**：

| 状态 | 表现 | 频率 |
|------|------|------|
| **正常** | 可休息、可存档、SAN 恢复、NPC 服务 | 多数 |
| **沦陷** | 被敌人占据（含 Boss），触发遭遇战 | 少数，随楼层升高增多 |
| **废弃** | 无人但可休息——无 NPC 服务（不能补给/接任务） | 极少数 |

- 护士站内休息**始终安全**——不会在休息中被偷袭（沦陷护士站需先清场才能使用）
- 走出护士站立即回到该楼层的危险等级
- 休息规则详见 [游戏循环](../事件/游戏循环.md) §三

## 四、L1 扭曲空间

### 4.1 设计意图

物理房间的门推开来，内部比外面大得多。月光下的空间拓扑异常——这是世界观已有的设定，直接用在关卡设计上。

### 4.2 规模与数量

- 10-15 个扭曲房间，分布在医院各层
- 每个在物理房间模型基础上做变体，不是从零开始
- 扭曲程度分层：
  - **轻度扭曲**（2-3 倍物理面积）：战斗场景，如病房内变成小型竞技场
  - **中度扭曲**（5-10 倍物理面积）：探索+战斗，如走廊延伸出不存在的分支
  - **重度扭曲**（无边界/循环）：解谜，如无限循环的楼梯间、不断重复的同一间病房

### 4.3 扭曲的表现形式

| 类型 | 表现 | 示例 |
|------|------|------|
| 尺度膨胀 | 房间等比放大 | 6.9×6.9m → 20×20m |
| 拓扑异常 | 空间连接关系改变 | 左转两次回到原点，走廊两端通向彼此 |
| 循环空间 | 同一空间无限重复 | 推开 302 的门 → 又是 302 → 又是 302 |
| 物理异常 | 重力/方向改变 | 墙壁变地板，天花板有门 |
| 时间异常 | 空间内时间流速不同 | 房间内部时间循环重放同一时刻 |

### 4.4 建模策略

- 在物理房间模型基础上修改——保留墙壁/门窗位置作为锚点，内部替换
- 扭曲房间的入口（门）和物理医院保持一致——从走廊看是普通门，推开来才显异常
- 过渡区域：门框 + 短暂走廊 + 视觉特效（月光粒子/画面撕裂）

## 五、L2 患者内心世界

### 5.1 核心概念

世界观设定：**"精神病患者们的怪诞思想在月光下被具象化了"**。

一个患者不只是敌人——他是一个**可进入的关卡**。穿过病房门，就进入了患者的主观现实。

### 5.2 患者 → 关卡映射

| 患者类型 | 内心世界 | 关卡主题 |
|---------|---------|---------|
| 偏执型妄想 | 被迫害的追猎场景 | 恐怖追逐、隐形敌人、到处都是陷阱 |
| 重度抑郁 | 灰暗、不断崩塌的世界 | 环境本身在消解，需要不断前进才能维持立足 |
| PTSD | 不断重演的创伤记忆碎片 | 同一场景反复循环，每次细节不同，需要找出破绽 |
| 精神分裂 | 多重人格叠加的现实 | 同一空间的多层版本叠加，需要在不同人格视角间切换 |
| 强迫症 | 仪式化的重复空间 | 必须按特定顺序穿过的对称空间 |
| 躁狂 | 狂乱无序的色彩风暴 | 高速变化的混乱空间，需要快速决策 |

### 5.3 规模与数量

- 5-8 个核心患者（对应主要 Boss/剧情角色）
- 每个内心世界：独立关卡，创作自由度最高
- 建模：每个集中资源做，场景主题明确

### 5.4 与物理医院的连接

- 入口：患者所在的病房门（或患者本人的某种物品/记忆锚点）
- 出口：完成内心世界后，返回物理医院——但物理医院可能因为这次"经历"而发生变化
- 患者内心世界的状态反映在物理病房中——患者病情好转/恶化 → 病房内物品/灯光/交互物变化

## 六、关卡流程与玩家推进路径

> 2026-07-30 grilling — 关卡流程与进度。空间切换、钥匙门控、推进弧线、进度度量、护士站昼夜等 39 项决策。

### 6.1 核心流程：鬼打墙式空间切换

空间之间的切换采用**鬼打墙式无缝过渡**——场景变化不应被玩家轻易察觉，就像人在梦境中不会意识到梦境的荒诞。物理地图不变，但**门的另一侧在变化**——这是鬼打墙的核心诡计。

```
走廊（正常）→ 进门 → L1 扭曲房间（单节点）→ 门关上（不可逆）
→ 战斗/探索结束 → 门/窗再打开：
  ├── L1-only: 扭曲消散，房间恢复正常 → 开门回走廊
  └── L1→L2: 门外是患者精神世界（L2）→ 找出口 → 回到同一扇门外的走廊
```

**关键约束**：
- 进入扭曲房间后门关上，**不可回头**——只能向前。这强化鬼打墙的不可逆感。
- L1→L2 房间**出去后回不来**——患者世界已经打完，门变回普通病房门。
- L1 扭曲房间内部是**单节点**（一个战斗场景），不是节点链。
- L2 患者精神世界是**一个大场景**，不是多个节点串联。小头目在场景内某处。

### 6.2 扭曲房间的出入规则

**进入前**：玩家在走廊面对一排病房门。大部分门后是正常病房（6.9×6.9m），少数是扭曲房间。开门前**不能完全分辨**哪些是扭曲房间，但有微妙线索（门缝透光/月光粒子浓度/温度异常）。剧情未到位前，扭曲房间的分布采用**随机方式**安排。

**L1-only 退出**：战斗/探索结束后，扭曲消散，房间恢复正常，开门走回走廊。同一间病房**可能复发**——休息几次/月光强度变化后，可能再次扭曲，可能连接不同的内容。

**L1→L2 退出**：在 L2 中找到出口（完成战斗/击败小头目），回到物理走廊——**同一扇门外**。鬼打墙只体现在"门再打开时外面已不是走廊"这一点上。

**月光强度影响**：月光越强 → 扭曲房间越多/越容易复发。满月夜晚大门也可能临时扭曲；新月白天异常的门减少。月光周期自然控制可探索内容的节律——白天安全但内容少，夜晚危险但内容多。

### 6.3 楼层推进与钥匙系统

楼层之间通过**钥匙门控**——不是硬等级锁，而是探索驱动的推进。

| 规则 | 说明 |
|------|------|
| **钥匙来源** | 每层的小头目（藏在 L1→L2 患者精神世界中） |
| **门控位置** | 楼层间楼梯间，钥匙打开后**永久通行** |
| **可往返** | 上楼后可随时下楼回护士站休息/补给 |
| **一层多门** | 一层楼有多个异常门，只有一扇通往带钥匙的 L2 |
| **辨别方式** | 无法提前分辨，只能一间间试 |
| **L1-only 收益** | 组件/消耗品掉落 + 髓鞘化成长 + 叙事碎片（环境叙事） |

**一层楼的典型体验**：
```
探索走廊 → 发现异常的门 → 进 L1 → 门关上 → 战斗
→ 如果是 L1-only: 扭曲消散，回走廊，继续找
→ 如果是 L1→L2: 进患者世界 → 找到小头目 → 拿钥匙 → 出门回走廊 → 上楼
```

一层楼需要**多次/多天**推完——反复进出、休息、再尝试。

### 6.4 三栋建筑的推进弧线

医院三栋建筑各自有独立的钥匙链，入口锁门。

| 建筑 | 层数 | 入口钥匙位置 | 内部推进 | 顶层 |
|------|------|-------------|---------|------|
| **住院楼** | 4F+天台 | 无需入口钥匙 | 1F全开放 → 2F钥匙(1F小头目) → 3F钥匙(2F) → 4F钥匙(3F) | 天台=拜月教根据地 |
| **门诊楼** | 3F | **住院楼2F** | 1F→2F钥匙(门诊1F小头目) → 3F钥匙(门诊2F) | 顶层=思潮Boss A |
| **供应中心** | 1F | **门诊楼3F** | 内部分区×小头目(纯掉落) | 中央区=思潮Boss C |

**住院楼 1F 全开放**：玩家醒来的楼层全部可走——自由探索、学习基础战斗、发现第一间扭曲病房。这是唯一完全属于玩家的楼层。

**三栋楼可自由选择推进顺序**：拿到住院楼 2F 钥匙后，可选择继续上楼推进住院楼，或取门诊楼入口钥匙转去门诊楼。

**三 Boss 分布**：

| Boss | 思潮 | 月光观 | 位置 |
|------|------|--------|------|
| B | 神明 | 月光是有意志的神明——会回应、会选择、是活的 | 住院楼天台（拜月教根据地） |
| A | 物理场 | 月光是可量化、可测量、可破解的自然力 | 门诊楼顶层 |
| C | 催化媒介 | 月光是无声的催化媒介——不强加意义，只是放大 | 供应中心 |

C Boss 暂定基底：求生的本能被月光催化放大到扭曲自身——一个只想活下去的人，被放大成了吞噬一切来维持自己存在的东西。后续叙事设计可迭代。

**天台拜月教根据地**：不是强制战斗区。玩家到达 4F 天台后，拜月教态度取决于玩家行为/声望/之前的选择。

**结局**：暂按三 Boss 全部打完之后结束。结局由条件自动触发（髓鞘化模式 + 见证的 Boss 故事 + 探索深度），非玩家主动选择。

**玩家推进总览**：
```
醒来(住院1F病房)
→ 探索1F, 进扭曲房间(L1-only=资源/叙事, L1→L2=小头目+钥匙)
→ 拿1F钥匙 → 上住院2F
→ 找到门诊楼入口钥匙 → 可选: 继续住院楼 或 转门诊楼
→ 住院(1F→2F→3F→4F天台/拜月教B)
→ 门诊(入口在住院2F→1F→2F→3F/A Boss)
→ 供应中心(入口在门诊3F→内部/C Boss)
→ 三Boss打完 → 结局
```

### 6.5 进度度量

没有"局"、没有等级、扭曲房间会复发——进度**纯靠玩家自身变化体现**：

- **红骷髅逐渐消失**：之前打不过的敌人现在可以挑战
- **髓鞘化 m 值持续增长**：使用即成长
- **随身镜子中自我认知深化**：能看到更多链路/信息
- **能去的楼层/建筑越来越多**：钥匙系统提供结构性进度感

探索引导无需强制——**楼梯间锁门 + 好奇心 = 自然驱动力**。玩家探索走廊发现楼梯间打不开，自然去找钥匙。

### 6.6 护士站昼夜变化

| 时段 | 护士站状态 |
|------|-----------|
| **白天** | 真人护士——可对话、补给、任务线索。可能沦陷（被敌人占据），需清场才能使用。 |
| **夜晚** | 护士变成**投影**——中立单位，不会受伤，没有情绪反应。更接近一种自然现象。休息功能依然可用。 |

夜晚护士站可有以护士为原型的小头目——护士的负面情绪在月光下扭曲现实的具象化，非三大思潮 Boss 级别，属于支线/可选内容。

## 七、轮回层（已废弃）

> **⚠️ 已废弃（2026-07-28）**："轮回"概念来自旧卡牌 Roguelike 框架，已被废除。连续世界中空间复用由月光周期自然驱动。废弃原因详见 [游戏循环](../事件/游戏循环.md) §1.2。

### 6.1 设计意图（废弃）

即使有扭曲空间和患者世界，固定物理空间仍然有限。轮回让**同一批空间在不同轮次中承载不同内容**。

### 6.2 软轮回（同一物理空间，不同状态）

- 同一间病房，第一轮住的是抑郁症患者 A → 房间灰暗、寒冷、物品沉重
- 下一轮，同一间病房住了精神分裂患者 B → 房间在几个人格主题之间切换
- 房间建模不变，换天空盒/灯光/粒子/交互物 = 不同的探索体验
- 某些 NPC 只在特定轮回出现，需要多轮才能拼出完整剧情

### 6.3 硬轮回（空间拓扑重组）

- 走廊的连接关系改变——上一轮 302 通向楼梯间，这一轮 302 通向一条不存在的走廊
- 楼层顺序重组——一楼可能是二楼，地下室出现在顶楼上面
- 镜子房间（世界观已有概念）作为轮回锚点——玩家在镜子房间中可以"看到"拓扑的真相

### 6.4 叙事轮回

- 玩家每次轮回保留部分记忆/技能/物品
- 累计多轮才能解锁完整剧情
- 某些选择在 A 轮做的后果在 B 轮体现
- 轮回不是简单的"重来"——每次轮回推进对医院真相的理解

### 6.5 变量配置（不占建模工时）

| 变量 | 每轮可能取值 | 影响 |
|------|------------|------|
| 病房患者分配 | N 种患者 × M 间病房 | 探索内容、敌人配置 |
| 走廊连接关系 | 3-5 种拓扑变体 | 可通行路径 |
| 扭曲房间位置 | 哪些房间扭曲 | 战斗场景分布 |
| NPC 出现/状态 | 谁在、什么状态 | 对话、支线 |
| 物品位置 | 关键道具在哪个房间 | 探索动力 |
| 月光强度 | 弱→强 | 扭曲程度、敌人强度 |

## 八、对建模工作的指导

### 8.1 当前阶段优先级

| 优先级 | 内容 | 说明 |
|--------|------|------|
| P0 | L0 物理医院建筑结构 | 你现在在做的事——一次建完 |
| P1 | L0 物理医院道具/装饰 | 模块化，可复用 |
| P2 | L1 扭曲空间（10-15 个） | 在 L0 基础上改 |
| P3 | L2 患者内心世界（5-8 个） | 独立场景，每个集中资源 |

### 8.2 建模时的预留接口

- 某些病房门后面不建真实房间内景——留一个过渡空间（loading 或视觉过渡的锚点）
- 走廊连接处预留"可变化"节点（随月光强度变化通向不同方向）
- **⚠️ 镜子房间已废弃**：随身镜子是 UI 界面，不需要建模

### 8.3 内容估算

假设一层楼 20 间病房：

- 18 间保持真实尺寸（L0），用于 NPC、道具、支线
- 1-2 间有扭曲变体（L1）
- 302 室：门推开后是一整个废弃游乐园（L2 患者世界）
- 307 室：内部是无限循环的审讯室（L1 重度扭曲）
- 走廊尽头：本该是死路，月光强烈时出现不存在的门（L1 扭曲空间）

物理上建了 20 间病房的走廊立面 + 走廊 + 2 个异空间关卡 + 1 个走廊变体。玩家体验："这个医院深不见底"。
