# 玫瑰株丛密度与覆盖率 — 商业化种植口径

> 玫瑰花海实验场景（Grilling #126）的株数密度来源、布置方式与「整片区域完全覆盖」的几何判据推导。

**维度: 呈现 + 管线** — Issue [#126](https://github.com/verystrongdog/game/issues/126)。

## 一、密度文献口径（两源互印）

| 源 | 原文记载 | 出处 |
|----|---------|------|
| 平阴县人民政府《玫瑰的栽培种植》 | 一般采用 2.0—2.5 × 1.0—1.5 米的栽植密度，**每亩栽植 180—330 株** | http://www.pingyin.gov.cn/col82932/art/2023/art_82932_4784335.html |
| 农博数据中心《平阴玫瑰栽培技术》 | 密植园栽植：株距 0.8～1.2 米，行距 2.5～3 米，**每 1/15 公顷（1 亩）栽 180～330 株** | http://shuju.aweb.com.cn/technology/20121014/242529.html |

> HTML 原文（`pingyin_rose.html`、`aweb_564ee3.html`、`aweb_3df0b0.html`）属本地存档、不入库；上表 URL 为可追溯来源。（2026-09-12：原存于 `.scratch/grilling-126-rosefield/ref/`，随仓库重构 Phase 2 迁出；该目录内容不随仓库分发。）

**算术交叉校验**：`密度 = 1 / (行距 × 株距)`，1 亩 = 666.6667 m²

| 端点 | 计算 | 结果 |
|------|------|------|
| 密端 | `1 / (2.5 × 0.8) = 0.5 株/m²` | 333 株/亩 |
| 疏端 | `1 / (3.0 × 1.2) = 0.278 株/m²` | 185 株/亩 |

→ 与文献区间 [180, 330] 自洽 ✅

## 二、本实验取值

| 参数 | 符号 | 取值 | 推导 |
|------|------|------|------|
| 种植密度 | ρ | **300 株/亩** | 取文献区间中位偏密端 |
| 株数 | N | **4563** | 六角错行网格在 10⁴ m² 内的实际落点数 |
| 单株占地 | a | 2.1912 m² | 10⁴ / 4563 |
| 错行间距 | s | **1.602 m** | `√(a / (√3/2))` |

> 实测密度 `4563 / (10⁴ / 666.6667) = 304.2 株/亩` ∈ [180, 330] ✅

| 参数 | 值 | 推导 |
|------|-----|------|
| 行距 | 1.3874 m | `s·√3/2` |

## 四、「整片区域完全覆盖」的几何判据

商业条栽在行间留通道，文字意义上的「完全覆盖」需要一个显式判据。三角格的**覆盖半径**（离最近格点的最远距离）为其外接圆半径：

```
R_cover = s / √3
```

故地面无裸露（覆盖率 = 1.0）的充要条件是单株冠层投影半径 ≥ 覆盖半径：

```
D ≥ 2s / √3
```

| 量 | 值 |
|----|-----|
| 覆盖半径 `s/√3` | 0.9249 m |
| **全覆盖最小蓬径 `2s/√3`** | **1.8498 m** |
| 本实验蓬径 D | **1.85 m** |
| 冠层投影比 `π(D/2)² / ((√3/2)s²)` | 1.209（≥ 1 → 冠层闭合） |

→ **覆盖率 1.0 与 300 株/亩同时成立**，无需超出文献密度。

## 五、渲染口径

| 项 | 值 |
|----|-----|
| 单株网格 | 程序化低模，53 四边形 / 106 三角形（5 茎 + 8 叶 + 5 花 × 6 瓣） |
| 总三角形 | ≈ 4.8 × 10⁵ |
| 绘制方式 | 每株一个 GameObject（MeshFilter + MeshRenderer），共享同一网格与材质；材质开 GPU Instancing → Unity 自动合批 |
| 碰撞体 | 无（「穿行」语义：玫瑰不阻挡小人） |
| 逐株变化 | 确定性伪随机偏航（种子 `roseSeed`）+ 缩放 1.00—1.15（缩放 ≥ 1 保证蓬径不低于判据 D） |

> 为何不用 `Graphics.DrawMeshInstanced` 即时模式：实测其绘制**不进 `capture_game_view --source camera` 的抓帧路径**，且无法在编辑器 Scene View 里直接看到（详见 [unity/README.md](README.md) §二·F 踩坑记录）。
