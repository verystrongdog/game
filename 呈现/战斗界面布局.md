## 一、核心区分：三个独立系统

战斗中有三套独立系统，不可混淆：

| 系统 | 来源 | 数量 | 战斗中入口 | 消耗 |
|------|------|------|-----------|------|
| **基础行动** | 开局即存在 | 3 | 底部行动栏按钮 | AP |
| **技能** | 技能树学习 | 37 (L0-L6) | 底部快捷槽栏 (6 个) | AP |
| **链路** | 脑区承载 | 228 | 展开底部面板 → 3D 脑区 | 激活点 (AcP) |

**快捷槽装的是技能，不是链路。脑区承载链路，技能树承载技能。** 两套基础设施层（脑区→链路）和操作层（技能树→技能）各自独立。

### 资源

| 资源 | 每回合 | 用途 |
|------|--------|------|
| AP | 6 | 基础行动 + 技能 |
| 激活点 (AcP) | 4 | 手动激活 L3-L6 链路 |
| L0-L2 链路 | 免费 | 情境自动激活 |

│  ┌─ 状态面板 ─┐ ┌─ 行动栏 ────────────┐   │

### 2.2 展开/折叠

- 底部面板平时折叠（仅显示行动栏 + 快捷槽栏 + 状态面板）
- 中上方拉拽按钮 [🧠] 向上展开 → 显示 **3D 脑区面板**
- 展开后战场被脑区面板覆盖，变成链路选择模式
- 再次点击按钮或按 `B` 收起

## 三、战场视角与操作

### 3.1 相机

- **自由 3D 旋转**：鼠标中键按住拖动 / `Alt` + 左键
- **缩放**：滚轮
- **平移**：`WASD` 或鼠标移到屏幕边缘
- **聚焦当前角色**：`Home` 或双击角色头像

室内场景（层高 3.6m，走廊 3m 宽）需要遮挡处理：相机与角色之间的墙壁/天花板自动半透明化（Cinemachine Collider + layer mask 切换）。

### 3.2 操作流（方案 C：先选动作，自动寻路）

```
1. 点击底部 M1/Broca 按钮 → 光标变为对应动作模式
2. 点击目标 → 系统自动规划路径
3. 路径用颜色区分：
   - 白线 = 安全路径
   - 黄线 = 经过敌方控制区（显示借机攻击警告图标）
   - 红线 = 不可通行
4. 玩家看到黄线后可选择：接受路径 / 手动调整走位
5. 调 M1-Broca 先后顺序
6. 点"确认声明"→ 进入响应窗口 → 结算
```

### 3.3 移动力

- 移动是独立配额（基准 12 格，速度偏移 ±30%），不占 M1/Broca 通道
- 底部状态面板显示 `步伐: 8/12`
- 手动走位扣移动力，确认攻击后系统自动补完剩余路径

### 3.4 网格与控制区

- **网格**：只在移动时显示（1m × 1m 方格，蓝色高亮可走范围）
- **控制区**：不显示 3D 球体。用脚下光圈替代——进入敌方控制区时，移动范围格变黄色
- 借机攻击触发时弹出警告图标在路径上

### 3.5 目标选择

- 点击 M1/Broca 按钮后光标变为对应动作光标
- 鼠标悬停可攻击目标 → 目标脚下光圈高亮
- 点击确认

### 3.6 AOE/多目标

AOE 需要特定链路激活后赋予（非基础能力）：
- **锥形 AOE**（横扫）：光标变锥形放置器 → 滚轮/Q-E 旋转方向 → 点击确认
- **圆形 AOE**：拖拽调整半径
- **多目标**（选 2 目标）：依次点击两个敌人
- 友军火力：AOE 覆盖友方时显示黄色警告，伤害按难度分级（低=关闭/中=50%/高=100%）

### 3.7 环境交互

归类为 M1 杂项动作。触发方式二选一（后续 UI 迭代定）：
- A. 光标悬停可交互物体 → 高亮 → 右键菜单 → 推倒/开门/破坏
- B. M1 按钮下拉菜单包含攻击/防御/交互选项

### 3.8 敌方信息查看

- 右键点击敌人 → 菜单 → "查看" → 信息面板
- 信息用自然语言而非机械术语（"病情：中度"而非"CGI-S: 中度"）
- HP 用模糊描述（满/大半/一半/低/濒危），不显示精确值
- SAN 不显示数值，通过行为观察推断（SAN<30 时行为怪异）
- 敌方激活的链路默认不可见——需 L4 读意图激活后才部分揭露

## 四、底部 HUD

### 4.1 行动栏

底部右侧。两个通道的按钮 + 顺序切换 + 确认：

```
[M1: 物理攻击] [M1: 防御]  |  [Broca: 精神攻击]
             顺序: [M1 先] ⟷ [Broca 先]
             步伐: 8/12            [确认声明]
```

- 点击 M1/Broca 按钮 → 光标变对应动作模式 → 点击目标选取
- M1 物理攻击 ↔ 防御互斥（共享 M1 输出通路）
- 顺序切换按钮：点 `[M1 先]` 变为 `[Broca 先]`，反之亦然

### 4.2 快捷槽栏

行动栏下方。6 个已预装技能图标：

```
[✦期待] [◇读意图] [◆忍耐(冷却2)] [·恐惧条件化] [·内省] [·识别]
 可用     可用       冷却中              可用         可用     可用
```

- 点击触发技能效果（如有目标指向则选目标）
- 状态显示：**可用**（正常颜色）/ **冷却中**（暗化 + 冷却数字倒计时）
- 快捷槽配置在非战斗时通过技能树界面管理

### 4.3 状态面板

底部左侧。我方当前选中角色信息：

```
┌─────────────────────┐
│ ☻ 角色名            │
│ HP ████████░░ 45/60 │
│ SAN ██████░░░░ 38/100│
│ 激活点 ●●○○ (2/4)   │
│ 步伐: 8/12          │
│ 防御中 🛡 (持续状态)  │
└─────────────────────┘
```

- HP 条红色、SAN 条蓝色——颜色仅用于血条区分，不用颜色表情绪
- 激活点用圆点（●已用 ○剩余），每回合重置
- 防御中、回避中等持续状态单独标注

### 4.4 消耗品

独立按钮 [💊] 放在快捷槽栏右侧 → 点开弹出物品列表 → 选物品 → 选目标。

## 五、脑区面板

### 5.1 展开

底部面板中上方的 [🧠] 按钮 → 向上展开 3D 脑区面板。

### 5.2 交互

- 完整 3D 玻璃脑，自由旋转/缩放
- 脑区按解剖位置排布（89 脑区，MNI 坐标）
- L0-L2 自动激活链路：脑区自动发光（不消耗激活点），玩家可见但不可手动操作
- L3-L6 手动激活：**点击脑区** → 右下角弹出展示面板

### 5.3 展示面板（右下角）

```
┌── 展示面板 ──────────────────┐
│  [人偶动作示意 / 动画预览]     │
│                              │
│  脑区: dlPFC (L5 跨模态皮层)  │
│  链路: 控制·压制回避          │
│  效果: 压制敌方的回避状态      │
│        物理攻击命中恢复正常     │
│  激活点消耗: 1               │
│  冷却: 无                    │
│                              │
│  [◀ 上一条] [激活] [下一条 ▶]  │
└──────────────────────────────┘
```

- 人偶动画展示链路效果（比纯文字直观）
- 一个脑区有多条链路时可翻页切换
- 已激活链路不可再次选（直到下回合释放）
- 激活点不足时全部链路灰色不可选

## 六、信息展示

### 6.1 时间线

顶部横向头像排列：

```
[敌A(暗)] [玩家B(暗)] [玩家A(亮·当前)] [敌B] [敌C] [敌D]
 物理攻击    防御中       ← 当前行动        等待中  等待中  等待中
```

- 头像为圆形图标 + HP/SAN 缩略条
- 已完成行动者：暗化 + 简短动作标签
- 当前行动者：放大 + 发光边框
- 等待中：正常亮度
- 后动者能看到前方所有已完成的公开行动
- 悬停已完成头像 → 弹窗显示详细动作记录

### 6.2 敌方行动窗口

相机切换到正在行动的敌人附近。HUD 底部显示简化信息条：

```
┌─────────────────────────────────────────┐
│ 偏执型精神病患者                           │
│ M1: 物理攻击 → 玩家B                       │
│ [ 可用响应: 忍耐·主动 ]  ← 如果可响应则显示   │
└─────────────────────────────────────────┘
```

敌方激活的链路默认不显示（信息不对称），除非玩家已激活 L4 读意图。

### 6.3 响应窗口

敌方攻击声明后，如果玩家有可用响应：

- 弹窗暂停游戏（无倒计时——回合制不需要）
- 显示可用响应选项
- 玩家选择或点"不响应"后继续

```
┌──────────────────────────────────┐
│ 敌方A 对你发起物理攻击！           │
│                                  │
│ 可用响应：                        │
│ [忍耐·主动 -2SAN减免] [不响应]    │
└──────────────────────────────────┘
```

### 6.4 伤害数字与战斗日志

- **浮动数字**：伤害值从角色头上飘出（红=物理伤害，蓝=SAN伤害）
- **战斗日志**：左侧边栏，可折叠，默认收起，展开时半透明覆盖战场边缘

### 6.5 SAN 状态视觉反馈

不依赖纯数值——多层感官反馈：

| SAN | 视觉反馈 |
|-----|---------|
| ≥90 | 画面清澈，轻微柔光 |
| ≥60 | 正常 |
| 30-59 | 屏幕边缘轻微暗角 + 情境扰动（颜色微偏） |
| <30 | 暗角加重 + 屏幕偶尔微颤 + 呼吸声 |
| <15 | 画面扭曲/边缘模糊 + 幻听（随机低语） |

### 6.6 角色视觉区分

| 元素 | 效果 |
|------|------|
| 脚下光圈颜色 | 我方蓝色 / 敌方红色 / 中立黄色 |
| 当前行动者 | 脚下光圈扩大 + 发光脉冲 |
| 可选为目标的敌方 | 悬停时光圈高亮 |
| 角色头顶 | 我方角色名 / 敌方模糊描述（如"偏执型患者"） |
| HP/SAN 条 | 不飘在头上，通过时间线头像缩略条查看 |

### 6.7 小队切换

- 转到自己的角色时：相机自动平滑飞到该角色身后/上方（0.3-0.5s 过渡），高亮其控制区
- 非当前角色状态面板暗化但可见
- 时间线上可点击任意角色头像切换视角（即使不是当前行动窗口）

## 七、过渡与反馈

### 7.1 探索 → 战斗

直接切入战斗 UI。时间线 + HUD 出现，画面不设过渡动画。

### 7.2 战斗 → 探索

直接切入探索 UI。HUD 消失，恢复自由行走。

### 7.3 回合切换

旁白式情境标签显示——短暂展示当前情境（如"压抑""恐慌蔓延"），字幕风格淡入淡出，营造叙事氛围。L0-L2 在情境更新后自动激活。

### 7.4 战斗结束

- 最后一名敌人倒下时 **1-2 秒慢动作**（可触发处决动画——特定条件：近战最后一击、BOSS 战等）
- 弹出**战斗结算面板**：
  - 参与角色
  - 髓鞘化增长（哪些技能提升了）
  - 可拾取掉落预览
- 面板关闭后回到探索视角

### 7.5 部署阶段

- 无特殊 UI
- 常态遭遇：角色脚下显示移动范围（减半），"就绪"按钮在底部
- 伏击：察觉方自由走位不消耗移动力，"就绪"后开始战斗
