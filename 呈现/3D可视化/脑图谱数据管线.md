## 一、设计动机

旧方案：技能 3D 坐标由 PAD 心理学公式推导 → 将真实脑 mesh 旋转缩放去"套"节点位置。

问题：
- 技能位置是 PAD 概念空间的投影，不是真实脑区位置
- 脑 mesh (BigBrain) 与节点坐标系之间的关系是人为变换
- 无法在 Blender 中做精确的脑区-节点对应

新方案：
```
脑图谱 (Harvard-Oxford/AAL3/DK) → 脑区 MNI 质心坐标
→ 归一化到游戏世界空间
→ 技能放置在真实解剖位置上
→ 脑 mesh (brain-for-blender) 直接在 Blender 中原生使用
```

**态度空间的三轴映射保留为设计语义层**——解释为什么某类技能在某脑区，但坐标数据来源于脑图谱。

brain-for-blender 是首选——它直接提供按脑区分割的 OBJ 文件，皮层下结构独立下载。

## 三、管线步骤

```
Phase 1: 脑区坐标建立
  tools/brain_atlas_to_blender.py
  → data/brain_regions.json (57脑区 + MNI坐标 + 游戏空间坐标)

Phase 2: 技能→脑区映射
  tools/map_skills_to_regions.py
  → data/skill_coords.json (74技能 + 新旧坐标对比)

Phase 3: Blender 建模
  下载 brain-for-blender OBJ → 导入 Blender
  tools/place_skill_nodes_blender.py (bpy) → 批量放置节点
  → 导出 FBX/GLTF → Unity
```

## 四、关键脚本

### `tools/brain_atlas_to_blender.py`

脑区坐标数据生成器。

```
用法:
  python tools/brain_atlas_to_blender.py              # 生成 brain_regions.json (文献坐标)
  python tools/brain_atlas_to_blender.py --obj-dir DIR # 从 OBJ mesh 质心更新坐标
  python tools/brain_atlas_to_blender.py --blender      # 额外生成 Blender bpy 放置脚本
```

输入: 内嵌的 REGION_MAP 字典 (57脑区 → MNI坐标 + brain-for-blender 对应名)

输出: `data/brain_regions.json`

### `tools/map_skills_to_regions.py`

技能→脑区映射器。

```
用法:
  python tools/map_skills_to_regions.py
```

输入:
- `技能树系统/大脑技能树3D.html` (74技能 + region 字段)
- `data/brain_regions.json` (脑区坐标)

输出: `data/skill_coords.json`

### `tools/place_skill_nodes_blender.py` (待生成)

Blender Python 脚本。用法:

```
blender --background --python tools/place_skill_nodes_blender.py
```

## 五、坐标转换公式

### MNI → 游戏世界空间

```
MNI152 空间 (mm, RAS+):
  X = 右(+)/左(-)
  Y = 前(+)/后(-)
  Z = 上(+)/下(-)
  范围: X∈[-90,90], Y∈[-126,90], Z∈[-72,108]

游戏世界空间:
  X = 右(+)/左(-)  (原PAD Valence轴)
  Y = 上(+)/下(-)  (原PAD Intensity轴)
  Z = 前(+)/后(-)  (原PAD Autonomy轴)
  范围: X∈[-1.1,+1.1], Y∈[0,1.1], Z∈[-0.8,+0.9]

转换:
  game_X = (mni_X / 90) × 1.0
  game_Y = (mni_Z / 90) × 1.0 + 0.55
  game_Z = (mni_Y / 126) × 0.85
```

解释:
- MNI X→游戏X: 左右直接对应，除以90归一化
- MNI Z→游戏Y: 上下对应（MNI的上下=游戏的上下），+0.55使底部≥0
- MNI Y→游戏Z: 前后对应（MNI的前后=游戏的前后），除以126(≈max)、乘0.85放缩

### 半球处理

技能在原PAD空间的 X 坐标符号决定半球:
- `pad_x > 0`: 右半球 → MNI X = +|x|
- `pad_x < 0`: 左半球 → MNI X = -|x|
- `pad_x ≈ 0`: 中线 → MNI X = 0

### 视角对齐

标准神经影像使用 RAS (Right-Anterior-Superior) 坐标系:
- 上方 = 头顶方向
- 前方 = 面部方向
- 与 3D 引擎的 Y-up / Z-forward 惯例不完全一致

上述转换公式处理了轴交换和归一化。如果你使用不同的 3D 引擎坐标惯例，需相应调整。
