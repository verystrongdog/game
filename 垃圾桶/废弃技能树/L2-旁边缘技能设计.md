# L2 旁边缘调制 — 内感受与突显

> L1 告诉你"这是什么感觉"。L2 告诉你"这个感觉有多重要，我应该在意吗"。旁边缘皮层是**内感受**（读取身体信号）和**突显检测**（什么值得关注）的中枢。
>
> **设计原则**: L2 调制不直接产生行动——它们改变信息的权重和注意力的方向。L2 的决策是直觉的、前语言化的。被动调制由情境自动激活（激活点=0），内省是唯一的主动操作（激活点=1）。

## 一、L2 调制总览

L2 功能脑区 9 个（前脑岛、ACC×3、OFC、后扣带、颞极、峡部扣带、岛叶-ACC），合并为 **6 种调制**（5 被动 + 1 主动）：

| # | 调制 | 脑区 | 性质 | 激活点 | 核心效果 |
|---|------|------|------|--------|---------|
| 1 | **内感受** | 前脑岛 | 被动始终 | 0（自动） | 精确显示自身 HP/SAN 阈值触发点 |
| 2 | **共感** | 前脑岛(社会端) | 被动始终 | 0（自动） | 映射友方/敌方的身体情绪状态 |
| 3 | **冲突感知** | ACC + ACC背侧 | 被动始终 | 0（自动） | 检测敌方行为与模式的不一致 |
| 4 | **价值直觉** | OFC | 被动始终 | 0（自动） | 不花 AP 快速比较两个选项的价值 |
| 5 | **内省** | 后扣带 + 峡部扣带 | 主动 | 1 | SAN 恢复 + 释放认知槽 |
| 6 | **识人** | 颞极 + ACC吻侧 | 被动始终 | 0（自动） | 理解敌方社会角色、预测行为倾向 |

**合并说明:**
- ACC 吻侧（社会评价/归属感）→ 并入"识人"
- ACC 背侧（努力评估/认知控制分配）→ 并入"冲突感知"
- 岛叶-ACC（突显网络白质通路）→ 作为"内感受"和"冲突感知"之间的连接通路，不独立为技能

## 二、调制设计

### 调制 1: 内感受 (Interoception)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: 前脑岛 (Anterior Insula)
MNI:  (-34, 16, 6) → 游戏 (-0.53, 0.39, -0.02)
类型: 被动(始终生效)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

解锁后，HUD 上精确显示以下触发阈值：
- 应激反应触发线（当前是 HP < X%）
- 恐慌强制触发线（SAN < 30%、崩溃 SAN < 15%）
- BNST 激活状态（焦虑是否已上线）
- 认知槽使用情况（X/Y 槽被占用）

"解锁前，你只能模糊地感觉到'不太对劲'。
 解锁后，你知道自己的极限在哪里——
 '我的心跳在加速，但不是恐惧，只是兴奋。'"

**对 L0-L1 的调制:**
- 内感受精度让恐惧条件化的 BNST 激活可以被区分——"心跳快 ≠ 应该恐慌"
  - BNST 激活条件从 恐惧标记 ≥3 变为 恐惧标记 ≥4
- 应激反应的连续衰减从 -5%/次 变为 -3%/次
  - "你知道身体什么时候还有余力"

**AP 消耗:** 0（被动）
**认知槽占用:** 0
**冷却:** N/A

**设计依据:**
前脑岛是内感受(interoception)的中枢——Craig (2009): 前脑岛接收来自丘脑和脑干的
内脏感觉输入(心跳、呼吸、胃、温度)，将这些身体信号整合为"当下的身体状态"。
fMRI 研究: 心跳检测任务中前脑岛激活强度与内感受精度正相关。
岛叶损伤 → 内感受精度下降 → 情绪体验也变模糊（Damasio 的躯体标记假说）。
```

### 调制 2: 共感 (Empathy)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: 前脑岛(社会端) + 岛叶-ACC 通路
MNI:  前脑岛 (-34, 16, 6) → 游戏 (-0.53, 0.39, -0.02)
      岛叶-ACC (-20, 20, 14) → 游戏 (-0.22, 0.71, 0.13)
类型: 被动(始终生效)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

解锁后，战斗中可以看到：
- 友方的简化身体状态（HP 区间: 安全/受伤/危急）
- 友方是否处于恐慌状态
- 敌方受到伤害时，显示其 SAN 波动方向（↑/↓/—）
  "你感觉到他也在痛。他的恐惧和你的恐惧是同一种东西。"

**对 L0-L1 的调制:**
- 友方受伤 → 自动触发 趋向 的回避方向（优先级提升至第2位）
  - 但如果 L5 价值框架正在激活 → 不受影响（"我知道他受伤了，但我选择继续前进"）
- 读取敌方 SAN↓ → 期待的趋近加成额外 +5%（"他怕了——追"）

**AP 消耗:** 0（被动）
**认知槽占用:** 0
**冷却:** N/A

**设计依据:**
前脑岛是共情的核心节点——Singer et al. (2004): 观看爱人受到疼痛刺激时，前脑岛和 ACC
同时激活。"共感"本质上是内感受的延伸——用自己的身体模拟他人的身体状态。
岛叶-ACC 连接构成突显网络的核心——检测"什么最重要"并切换注意力。
```

### 调制 3: 冲突感知 (Conflict Detection)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: ACC + ACC背侧
MNI:  ACC (-5, 22, 28)     → 游戏 (-0.08, 0.59, 0.15)
      ACC背侧 (-6, 16, 32)   → 游戏 (-0.08, 0.59, 0.15)
类型: 被动(始终生效)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

- 敌方做出与其之前行为模式不一致的行动时 → 自动标记"冲突"
  - 例：一直进攻的敌人突然防御 → 冲突标记
  - 例：自称"友方"的 NPC 做出攻击动作 → 冲突标记
- 冲突标记持续 1 回合
- 有冲突标记时：
  - 对该敌方的 警觉 标记获取 +1（"不对劲...注意看"）
  - 对该敌方的 应激反应 触发提前 5%（"可能有诈"）

**对 L1 的调制:**
- 冲突标记出现时，恐惧条件化的标记获取暂停 1 回合
  - "等一下——这可能不是真正的威胁，先看清楚"
  - 如果冲突确认是威胁 → 恐惧标记 +2（"果然是危险！"加倍学习）
- 冲突标记出现时，习惯化自动被打断——连续使用计数重置
  - ACC 检测到"当前模式不对"→ 身体不能再自动执行

**AP 消耗:** 0（被动）
**认知槽占用:** 0（自动运作）
**冷却:** N/A（但同一敌方连续2回合触发冲突→冷却1回合）

**ACC背侧扩展（努力评估）:**
- 解锁冲突感知后自动获得：
  - 高 AP 技能（AP ≥ 3）使用前，显示预计的认知槽占用
  - "你知道这个操作要花多少心力"

**设计依据:**
ACC 的核心功能: 冲突监测和错误检测。Botvinick et al. (2001): 冲突监测理论——ACC 检测
"预期反应"与"实际反应"之间的不一致。fMRI: Stroop任务中不一致试次→ACC激活。
ACC→dlPFC→行为调整的级联。ACC背侧: 努力评估和认知控制的分配——
Shenhav et al. (2013) 的预期价值控制(EVC)模型。
ACC 与前脑岛的连接构成突显网络——检测到冲突→切换网络(DMN↔FPN)。
```

### 调制 4: 价值直觉 (Value Intuition)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: OFC (Orbitofrontal Cortex, 眶额皮层)
MNI:  (-22, 34, -16) → 游戏 (-0.35, 0.12, 0.20)
类型: 被动(始终生效)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

- 每回合开始时，如果快捷槽中有 ≥2 个可用主动技能 → 自动高亮其中"价值最高"的 1 个
- "价值最高"的判断依据：
  - 对当前敌方类型的克制效果
  - 需要的 AP / 获得的收益比
  - 是否触发连携（L3+ 功能）
  - 冷却是否即将就绪

  ——"你不一定选它，但你知道它是最好的。OFC 替你做了前语言的比较。"

**对 L1 的调制:**
- 价值直觉让期待和趋向的方向更精准：
  - 期待标记的方向加成从 +5%/层 → +8%/层（max 2层: +16% + 基础10% = 26%趋近加成）
  - 趋向的主动干预（L5 vmPFC）的认知槽成本从 1 降为 0（OFC 已经做了预判）

**代价:**
- OFC 受损时——SAN < 50% → 价值直觉暂时失效
- "精神不稳时，OFC 的直觉比较变模糊——你不知道哪个选择更好"

**AP 消耗:** 0（被动）
**认知槽占用:** 0（直觉操作，不需要执行控制）
**冷却:** N/A

**设计依据:**
OFC: 价值评估和比较。Padoa-Schioppa & Assad (2006): OFC 神经元编码"选项 A 好于选项 B"
的主观价值——甚至在猴子做出选择之前就已经编码了。OFC 的价值比较是前语言化/直觉的
（"我知道哪个更好，但说不清为什么"）。vmPFC 做的是"最终价值整合和决策确认"，
OFC 做的是"并列比较"。Tremblay & Schultz (1999): OFC 编码相对奖赏偏好。
```

### 调制 5: 内省 (Introspection)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: 后扣带 + 峡部扣带 (Retrosplenial)
MNI:  后扣带 (-4, -44, 28) → 游戏 (-0.09, 0.82, -0.10)
      峡部扣带 (-8, -46, 10) → 游戏 (-0.09, 0.66, -0.31)
类型: 主动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

- 主动使用：将注意力从外部世界转向内部
- 本回合不能执行攻击性行动
- 获得：
  - SAN 恢复 +5
  - 立即释放 2 个认知槽
  - 清除自身 1 个负面标签（"罪责""羞耻""污染"等）
  - 如果有失望标记 → 清除 1 层

**AP 消耗:** 1
**认知槽占用:** 使用时占用 1 槽（但释放 2 槽 → 净释放 1 槽）
**冷却:** 4 回合

**限制:**
- 不能在恐慌强制状态下使用
- 不能在敌方攻击动画播放期间使用（需要短暂的平静）

**设计依据:**
后扣带: 自传记忆检索和内部指向注意。fMRI: 当人做"回想过去"或"想象未来"时
后扣带和内侧前额叶一起激活——这是 DMN 的核心节点。峡部扣带(Retrosplenial):
海马→DMN 的接口，场景构建和空间记忆的回忆。"内省"本质上是主动切换
从 FPN（外部任务）到 DMN（内部自我）——让执行控制系统暂时休息。
```

### 调制 6: 识人 (Read Person)

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
脑区: 颞极 + ACC吻侧
MNI:  颞极 (-36, 10, -34)  → 游戏 (-0.48, -0.05, 0.04)
      ACC吻侧 (-6, 36, 14)  → 游戏 (-0.07, 0.28, 0.21)
类型: 被动(始终生效)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**效果:**

解锁后，敌方入场时自动显示：
- 敌方的"社会角色"标签（如果有）——如"施暴者""守护者""骗子""受害者"
- 敌方的粗略行为倾向（偏进攻 / 偏防御 / 偏支援）
- "你知道他是谁。你知道他大概想做什么。"

**对 L1 的调制:**
- 识人后，对该敌方的趋近/回避判断增加一层"社会维度"：
  - 看到"守护者"→ 回避方向弱化（"他不是冲我来的"）
  - 看到"骗子"→ 冲突感知触发更敏感（可疑行为更快标记）
  - 看到"受害者"→ 共感效果翻倍

**ACC吻侧扩展（归属感）:**
- 战斗中如果有友方在场：
  - 自身 SAN 消耗 -1（"不是一个人扛"）
  - 认知槽上限临时 +1（"分担了认知负荷"）
  - 友方被击杀 → 此加成永久消失 + 获得 2 层失望标记

**AP 消耗:** 0（被动）
**认知槽占用:** 0
**冷却:** N/A

**设计依据:**
颞极: 社会语义处理——Olson et al. (2007): 颞极在人脸识别、社会知识提取、
人物身份识别中激活。颞极是"人是什么社会角色"的知识库。
ACC吻侧(rACC): 情绪调节和社会评价——Eisenberger et al. (2003): rACC
在社会排斥(Cyberball任务)中激活，与归属感密切相关。rACC→杏仁核的
自上而下通路参与情绪调节（"他在生气但不是针对我"）。
```

## 三、L2 → L1+L0 调制矩阵

| L2 技能 | → 调制的 L0/L1 | 调制方式 |
|---------|--------------|---------|
| **内感受** | 恐惧条件化(BNST) | BNST激活条件 +1层（更不易焦虑） |
| **内感受** | 应激反应 | 连续衰减 -3%/次（从 -5%） |
| **共感** | 趋向(回避) | 友方受伤→回避优先级升至第2 |
| **共感** | 期待 | 敌方SAN↓→趋近加成额外+5% |
| **冲突感知** | 恐惧条件化 | 冲突时暂停标记获取; 确认后+2 |
| **冲突感知** | 习惯化 | 冲突时自动打断连续计数 |
| **冲突感知** | 警觉 | 冲突→警觉标记+1 |
| **价值直觉** | 期待 | 趋近/回避加成 +7%/层（从5%） |
| **价值直觉** | 趋向(主动干预) | 认知槽成本 1→0 |
| **内省** | 失望 | 可清除1层失望标记 |
| **内省** | 认知槽 | 净释放1槽 + SAN+5 |
| **识人** | 应激反应 | "守护者"→不触发; "骗子"→提前触发 |
| **识人** | 共感 | "受害者"→共感翻倍 |
| **识人** | SAN + 认知槽 | 友方在场→SAN消耗-1, 槽+1 |

## 四、被动效果汇总

| 技能 | 触发 | 效果 | 认知槽占用 |
|------|------|------|----------|
| 内感受 | 始终 | 显示精确HP/SAN阈值; BNST激活延后; 应激衰减减缓 | 0 |
| 共感 | 始终 | 看到友方HP区间/恐慌; 敌方SAN波动方向 | 0 |
| 冲突感知 | 敌方行为异常 | 暂停恐惧学习+警觉+打断习惯; 确认威胁→双倍恐惧 | 0 |
| 价值直觉 | 每回合开始 | 高亮最优技能选项; 期待加成+2%/层; 趋向干预槽→0 | 0 |
| 识人 | 敌方入场 | 显示社会角色+行为倾向; 角色类型改变L0-L1反应 | 0 |
| 识人(归属) | 友方在场 | SAN消耗-1; 认知槽上限+1 | 0 |

## 五、L2 与 L3-L5 的接口

| L2 技能 | → 高层调制者 | 调制方式 |
|---------|------------|---------|
| 内感受 | L3 S1(体感) | 体感输入精度↑→内感受精度↑（"身体感觉更清晰了"） |
| 内感受 | L5 dlPFC | 认知槽充裕时→dlPFC可花1槽主动提升内感受精度 |
| 共感 | L4 颞上沟(读意图) | 共感+读意图→可预测敌方下回合行动 |
| 冲突感知 | L5 vmPFC(决策) | 冲突标记→触发vmPFC重新评估（"需要换策略"） |
| 冲突感知 | L5 TPJ(换位) | 冲突标记可触发换位——"从对方角度看，他的行为可能合理" |
| 价值直觉 | L5 vmPFC(决策) | 价值直觉提供输入→vmPFC做最终确认 |
| 内省 | L3 楔前叶(想象) | 内省+想象→更丰富的内部场景构建 |
| 识人 | L5 TPJ(换位) | 识人+换位→理解对方行为背后的意图 |

## 六、参数速查
