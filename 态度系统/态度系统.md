## 态度形成 — 单回合线性链路

```
认知卡 → 情绪卡 → 行为卡 → 态度结算
```

玩家依次打出三张卡。每步即时计算，上一步的产出喂给下一步。

---

### ① 认知卡 — "你怎么看"

认知卡最先打出。它设定解释框架，决定后续情绪和行为的走向。

**模块归属：** 5 模块之一（知觉与注意 / 记忆 / 知识表征与分类 / 表象与语言 / 推理与决策）。

**CPM 步骤推进：** 认知卡激活对应模块 → 该模块参与对应 CPM 步骤的 SEC 子检查 → SEC 到达"初步闭合" → 触发情绪信号。

```
Step 1 (Relevance):     知觉与注意 + 知识表征
Step 2 (Implications):  记忆 + 知识表征 + 推理
Step 3 (Coping):        表象与语言 + 推理
Step 4 (Normative):     知识表征 + 表象与语言
```

**认知→情绪接口：** SEC 闭合时，认知模块的模长和偏向决定情绪信号。

```
|z_k| = √(d'² + criterion²)     → SEC 闭合强度
arg(z_k) = atan2(criterion, d')  → 偏向方向

SEC 闭合信号 × 偏向方向 → 调节情绪卡的 PAD 输出
```

d'（辨别力）决定认知精度，criterion（判断标准）决定偏向方向。认知框架可以放大、压制或偏移后续情绪卡的 PAD 效果。

**卡面效果：** 认知卡同时执行其具体效果——揭示属性、回收弃牌、添加/替换标签、预览敌方意图、强制解锁行为卡等（唯物/唯心两套工具）。

**人物基线认知在战斗中不变。** d' 和 criterion 的基线值取决于角色病情（见下文文献锚定部分），认知卡打出时在此基础上偏移。

### ② 情绪卡 — "你感受到什么"

**PAD 确定：** 在认知框架内，情绪卡产生 PAD 三值。

```
V (Pleasure/效价):  愉悦度 [-1, +1] — 正=趋近, 负=回避
A (Arousal/唤醒):   激活度 [-1, +1] — 正=高强度, 负=冻结
D (Dominance/控制): 掌控感 [-1, +1] — 正=主动, 负=被动
```

每张情绪卡携带 NRC VAD 实测值（15 种情绪，归一化到 [-1, +1]）：

| 情绪 | V | A | D |
|------|---|---|---|
| 恐惧 | −0.854 | +0.680 | −0.414 |
| 愤怒 | −0.666 | +0.730 | +0.314 |
| 焦虑 | −0.708 | +0.730 | −0.316 |
| 厌恶 | −0.896 | +0.550 | −0.366 |
| 恐怖 | −0.770 | +0.700 | −0.124 |
| 绝望 | −0.770 | +0.588 | −0.510 |
| 内疚 | −0.584 | +0.134 | −0.588 |
| 悲痛 | −0.896 | −0.424 | −0.672 |
| 孤独 | −0.500 | −0.548 | −0.524 |
| 快乐 | +0.960 | +0.648 | +0.588 |
| 爱 | +1.000 | +0.038 | +0.346 |
| 共情 | +0.458 | −0.302 | +0.090 |
| 平静 | +0.600 | −0.756 | +0.114 |
| 希望 | +0.854 | −0.366 | +0.478 |
| 敬畏 | −0.062 | +0.480 | −0.400 |

**认知框架调节：** 同一张恐惧卡，认知框架不同 → PAD 效果不同。

```
认知 "审慎归类: 这是绳子不是蛇"    → A 被压降, D 回升
认知 "灾难推演: 最坏的情况是..."    → A 被放大, D 更负
```

调节幅度取决于认知模块的 |z_k|（框架越"确信"，调节越强）。

### ③ 驱动激活 — PAD → 7 个 g_i

PAD 三值送入 sigmoid 函数，计算每个驱动的原始激活强度。

```
g_reflex  = σ( 2.0 × max(0, A-0.3) + 1.5 × max(0, 0.5-D) − 0.5 )
g_punish  = σ( 2.5 × min(0, V)     + 1.0 × max(0, A-0.2) − 0.3 )
g_reward  = σ( 2.5 × max(0, V)     + 0.8 × max(0, A-0.2) − 0.35 )
g_moral   = σ( 2.0 × max(0, D-0.1) + 1.0 × (1−|A|)        − 0.4 )
g_culture = σ( 1.5 × (1−|D|)       + 2.0 × C_score         − 0.3 )
g_value   = σ( 1.5 × max(0, D-0.4) + 3.0 × Override_signal − 0.7 )
g_care    = σ( w_vuln×Vulnerability + w_attach×Attachment   − θ_care )
```

σ(x) = 1 / (1 + e^(−x))

**照护驱动的特殊性：** 不读自身 PAD，读的是被共情传递的**他人 PAD**。自身在恐惧中仍可激活照护。

**自然激活条件（设计阈值）：**

| 驱动 | 自然激活 | 硬解锁 |
|------|---------|--------|
| 反射 | A>0.5 且 D<−0.3 | — (不可意志控制) |
| 惩罚 | V<0 | V>0 (意志力强制) |
| 奖励 | V>0 | V<0 (意志力强制) |
| 道德 | D>−0.3 | D≤−0.3 (意志力坚守) |
| 文化 | C_score 门控 | 全情绪可走 |
| 价值 | D>0.3 | D≤0.3 (意志力覆盖) |
| 照护 | Vuln+Attach | — |

**恐惧为例：** V=−0.85, A=+0.68, D=−0.41

```
g_reflex  ≈ 0.9  (A高 + D低 → 强激活)
g_punish  ≈ 0.8  (V负 → 强激活)
g_reward  ≈ 0.1  (V负 → 几乎不激活)
g_moral   ≈ 0.15 (D负 → 弱激活)
g_culture ≈ 0.5  (|D|中等 → 中等)
g_value   ≈ 0.1  (D负 → 几乎不激活)
```

恐惧自然激活 反射+惩罚。要打价值类行为卡（如"牺牲"），需要硬解锁。

---

### ④ 行为卡 — "你做什么"

**驱动归属：** 每张行为卡属于一个驱动。

```
僵住/逃跑 → 反射     回避/妥协 → 惩罚     趋近/坚持 → 奖励
坚守/纠正 → 道德     遵从/礼仪 → 文化     牺牲/超越 → 价值
安抚/保护 → 照护
```

**可用性判定：**

```
行为卡 (驱动 i) 自然可用 ⇔ g_i ≥ θ_play_i

θ_play: 反射 0.15, 惩罚 0.20, 奖励 0.25, 道德 0.35, 文化 0.15, 价值 0.50
```

**激活档位：**

| 档位 | 条件 | 表现 |
|------|------|------|
| 优势卡 | g_i 远高于 θ_play | AP 降低, 效果增强 |
| 劣势卡 | g_i 勉强过 θ_play | AP 升高, 费力但能做 |
| 惩罚卡 | g_i < θ_play | 灰掉, 需硬解锁 |

**成本与效果调制：**

```
cost_modifier_i = 1 + β_i × (1 − g_i)
effect_mod_i    = 1 + γ_i × (g_i − θ_play_i)

β: 反射0.5, 惩罚1.0, 奖励1.2, 道德0.8, 文化0.3, 价值1.5, 照护0.6
γ: 反射0.2, 惩罚0.5, 奖励0.6, 道德0.7, 文化0.2, 价值1.0, 照护0.5
```

**强制行为（恐慌规则）：** g_reflex > 0.85 → 本回合必须至少打一张反射行为卡。手牌无反射卡 → "僵住"强制打出。

### ⑤ 硬解锁（行为卡灰了时）

**C_control 查表（情绪 × 驱动）：**

```
C_resistance = 2.0 × σ( |V − V_drive| × |A| × 3.0 − 1.5 )
C_control    = C_base + C_resistance
```

| 情绪 | 反射 | 惩罚 | 奖励 | 道德 | 文化 | 价值 | 照护 |
|------|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 快乐 | ✕ | ✕ | 0 | 0 | 1.2 | 0 | 1.4 |
| 爱 | ✕ | ✕ | 0 | 0 | 0.4 | 0 | 1.4 |
| 愤怒 | ✕ | 0 | 2.8 | 0 | 1.0 | **0** | 2.8 |
| 恐惧 | 0 | 0 | 2.8 | 2.4 | 1.1 | **3.8** | 2.8 |
| 焦虑 | 0 | 0 | 2.8 | 2.3 | 1.0 | **3.8** | 2.8 |
| 厌恶 | 0 | 0 | 2.7 | 2.2 | 1.0 | **3.7** | 2.7 |
| 绝望 | 0 | 0 | 2.7 | 2.2 | 0.9 | **3.7** | 2.7 |
| 内疚 | ✕ | 0 | 1.6 | 1.5 | 0.4 | 2.6 | 1.6 |
| 悲痛 | ✕ | 0 | 2.4 | 2.0 | 0.8 | 3.4 | 2.4 |
| … | | | | | | | |

(完整 15×7 表见 行为系统.md 意志力系统 §二)

恐惧+价值 C=3.8 — 全游戏最贵。愤怒+价值 C=0 — 愤怒时价值驱动免费。

**EVC 判定：**

```
benefit ∝ (SAN + HP) / (maxSAN + maxHP) × 2

EVC = benefit − C_control − effort_discount + ε
ε ~ Logistic(0, 0.3)

硬解锁通过 ⇔ EVC > θ_initiation (默认 1.0)
```

**硬解锁代价：**

```
AP 溢价  = floor(C_control)          — 额外行动点
SAN 磨损 = max(0, C_control − 1.5)   — 精神护盾消耗
效果折扣 = 1 − 0.15 × C_control      — 态度效果打折
```

### ⑥ 行为输出 — B(t)

**B_raw — 直接情绪推力：**

```
B_raw = (V, |A|, D)
         ↑   ↑    ↑
       趋近/ 行为  主动/
       回避  强度  被动
```

愤怒的矛盾：V<0 说"回避"，D>0 说"主动"。同时回避又主动 = 主动逼近威胁源——唯一使人主动靠近威胁的情绪。

**B_drive — 驱动加工输出：**

```
B_drive = (drive_valence, intensity, autonomy)

驱动方向: 反射=−1, 惩罚=−1, 奖励=+1, 道德=0, 文化=0, 价值=±1, 照护=+1
```

**混合：**

```
λ_raw   = exp(−cog_progress)
λ_drive = 1 − λ_raw

B(t) = λ_raw × B_raw + λ_drive × B_drive
```

cog_progress 低 → λ_raw 高 → 身体冲动主导。cog_progress 高 → λ_drive 高 → 驱动加工主导。

---

### ⑦ 态度结算

三卡汇总：

```
态度 = {
  认知效果: 卡面效果的结果 (揭示/归类/命名/预览…)
  情绪 PAD: 当前 (V, A, D)
  行为输出: B(t) = (valence, intensity, autonomy)
}
```

硬解锁的 SAN 磨损直接从 SAN 护盾扣除。HP 归零 = 战斗结束。

态度碰撞（双方态度如何互相影响）→ 待定。

## 态度生成过程（流程图）

```
① 认知卡
   ├─ 模块归属 → CPM 步骤 → SEC 闭合
   ├─ |z_k| × arg(z_k) → 调节情绪卡 PAD 输出
   └─ 执行卡面效果
         │
         ↓
② 情绪卡
   ├─ 在认知框架内确定 PAD (V,A,D)
   └─ PAD → sigmoid → g_reflex ~ g_care
         │
         ↓
③ 驱动激活
   └─ 7 个 g_i 确定
         │
         ↓
④ 行为卡
   ├─ g_i vs θ_play → 自然可用? / 灰?
   ├─ 灰 → C_control 查表 → EVC → 硬解锁?
   └─ B(t) = λ_raw·B_raw + λ_drive·B_drive
         │
         ↓
⑤ 态度 = 认知效果 + 情绪 PAD + 行为输出 B(t)
   └─ SAN 磨损 + 行为惯性更新
```

## 关键参数速查

| 参数 | 含义 | 位置 |
|------|------|------|
| V, A, D | 效价/唤醒/控制 [-1,+1] | 情绪卡 (NRC VAD) |
| d', criterion | 认知精度/判断偏向 | 认知卡 (SDT) |
| g_i | 驱动原始激活 [0,1] | sigmoid(PAD) |
| θ_play_i | 行为卡可用阈值 | 查表 (驱动) |
| C_control | 硬解锁总成本 [0~3.8] | 查表 (情绪×驱动) |
| EVC | 期望控制价值 | benefit−C_control−effort_discount+ε |
| θ_initiation | 启动阈限 (默认 1.0) | 跨战斗漂移 |
| effort_discount | 努力折扣 (默认 0.5) | 跨战斗漂移 |
| λ_raw/λ_drive | 身体/驱动混合权重 | exp(−cog_progress) |
| B(t) | 最终行为向量 | λ_raw·B_raw + λ_drive·B_drive |

### PAD 动态参数

**累积 (ln 边际递减):** ΔPAD_n = PAD_anchor × [ln(1+k·n) − ln(1+k·(n−1))], k = 0.3 + 0.7×|A|

**衰减:** PAD(t+1) = PAD(t) × (1−δ), δ = (0.30 + 0.25×|A|) + (0.10 − 0.10×D)

文献: Verduyn 2015 (情感时间测量学), Davidson 1998 (上升/恢复时间独立维度).
