## 1. Varela (2014) — 半经典场论作为退相干自由子空间

**标题**: Semi-Classical Field Theory as Decoherence Free Subspaces
**出处**: arXiv:1404.3498
**文件**: `Varela-2014-DFS-semiclassical-gravity.pdf`

**核心主张**：
- 总希尔伯特空间分解为 ℋ = ℋ_E ⊗ ℋ_sc = ℋ_E ⊗ (ℋ_s^⊥ ⊕ ℋ_s)，其中 ℋ_E 为引力环境，ℋ_s 为退相干自由子空间（DFS）
- DFS 条件：物质态必须是所有误差生成元 F_α 的**同时本征态**。满足此条件时物质在自身哈密顿量下幺正演化——不受引力环境退相干影响
- 互补性变换 = 改变 DFS 的幺正变换 → 产生不同的时空 g'_μν 和 Fock 空间
- 相互作用取 Lindblad 形式：H_int = Σ_α B_α ⊗ F_α，B_α 仅作用于环境

**对月光场设计的贡献**：
- DFS 为月光场的"几何涂抹"提供了**严格数学框架**——场的存在使物质态进入 DFS（所有 F_α 同时本征），从而保护叠加态免受退相干
- 互补性变换 = 不同观察者坍缩不同月光版本的数学表达（不同 DFS 选段 = 不同"现实"）
- 引力环境 ⇒ 月光场的额外维几何。DFS 的精度取决于环境耦合——对应月光场强度

## 2. Zaino (2025) — 4D 量子投影框架

**标题**: A Unified 4D Quantum Projection Framework of Space, Time, and Measurement
**出处**: Zenodo, v1.1, 2025-09 | DOI: 10.5281/zenodo.17114143
**文件**: `Zaino-2025-4D-Quantum-Projection-Framework.pdf`

**核心主张**：
- 第四个空间维 w（紧致化）。4D 波函数 Ψ(x^μ, w, t) 在 4D+1 中幺正演化
- 观察到的 3D 态通过**高斯投影核** P(x^μ, t) = ∫ Ψ(x^μ, w, t) · G(w, σ_w(t)) dw 获得
- 投影宽度 σ_w(t) 由**熵子场**（entropion field）φ 驱动——σ_w 越窄，额外维信息越不可区分 → 退相干越强
- 量子现象（波函数坍缩、叠加、纠缠、隧穿）均为 4D→3D 投影的涌现性质——非内在随机性，是低维视角的局限
- 修改的爱因斯坦场方程含熵子应力-能张量

**对月光场设计的贡献**：
- **月光场 = σ_w 保持异常宽大的局域条件**——熵子场被局部压制，使路径信息在额外维中被"涂抹"开
- 太阳光（外部观察）驱动熵子场活性 → σ_w 收缩 → 退相干 → 经典世界。夜晚熵子场松弛 → σ_w 宽 → 叠加存活
- 零号病人 = 在熵子场中打出局部"凹陷"——凹陷内 σ_w 始终比外界宽

## 3. Zaino (2025) — 熵子场专论

**标题**: The Entropion Field: A Scalar Mediator of Decoherence and Time Flow
**出处**: Zenodo, v1.1, 2025-06 | DOI: 10.5281/zenodo.15839140
**文件**: `Zaino-2025-Entropion-Field.pdf`

**核心主张**：
- 熵子场 φ(x^μ) 是标量场——同时支配量子退相干速率和热力学时间箭头
- 退相干速率 γ_E 是空间位置的函数——取决于局部熵子场梯度
- 熵子场耦合到已知量子场和引力曲率
- 提出可检验预测：4D 投影系统中的干涉特征修改、熵子驱动的退相干速率、隧穿增强等

**对月光场设计的贡献**：
- γ_E(位置) = **局部退相干速率**——月光场的游戏映射：不同区域的月光强度 = 不同的 γ_E 值
- "月光强度" = σ_w / σ_w^baseline = f(φ_local)，由局部熵子场值决定
- 熵子场的空间变化 = 月光在空间中分布不均的物理基础

## 综合映射：月光场几何操作

```
额外维 w（始终存在，始终垂直于所有已知维度）
        │
        ├── σ_w 宽（熵子场被压制）→ 路径信息在 w 中被涂抹 → 叠加态存活 → 超自然现象
        │
        └── σ_w 窄（熵子场活跃）→ 路径信息保存 → 退相干 → 经典世界

驱动 σ_w 变化的因素：
  1. 外部观察通量（太阳光子↑ → 熵子场↑ → σ_w↓）
  2. 局部耦合密度（在场中暴露的人越多 → 凹陷越深 → σ_w↑）
  3. 零号病人初始凹陷（场的种子——第一个 σ_w 异常区域）
```

**与已有设定的整合**：
- M1（场源=零号病人）→ 第一个熵子场局部凹陷
- M2（传染模型）→ 耦合个体集体压制局部熵子场 → 凹陷扩大/加深
- M3（昼夜=表观）→ 太阳光子通量驱动的 σ_w 振荡——非"场相变"
- M4（月相=拍频）→ 需在此框架下重新审查
- M5（玩家=感染者）→ 玩家的 σ_w 比正常人宽——已耦合进场的凹陷
