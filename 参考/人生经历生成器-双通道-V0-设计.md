## 一、目标与轨道

**目标形式化**：生成器 `G: (S₀, θ_ind) → P(τ)`，其中 `τ = (S₀, E₁, S₁, …, E_T, S_T)` 为一条人生经历轨迹（状态-事件交替链），`θ_ind` 为个体参数。需求：

- **R1（强式随机性）**：固定 `(S₀, θ_ind)` 下，`|supp P(τ)| ≥ 2`——同人同起点仍可分化，分化来源 = 随机源 ξ^W/ξ^A/ξ^R + 状态依赖反馈（非平凡个体差异）。

**轨道**：纯学术研讨（#93/#97/#117 先例），不入游戏正典；关联 #116（同源游戏侧，另行推进）。本 issue 范围 = V0 规格；模拟实现批次另开。

**核心科学断言（H1）**：分歧主要在**决策点**累积，且**记忆调制放大分歧**——由检验设计（§十）以效应量报告，不预设结论。

## 三、对象层：双通道轨迹律

每步（被动通道默认）：

```
S_t（当前状态）
   ↓ 决策窗开启？────────────────────┐
   否：世界采样事件 E_t ~ P_W(E | S_t, R_t, G_t)    是：见 §六（动作可选）
   ↓ 应用 ΔS + 更新记忆（§八）         ↓
S_{t+1} ─────────────────────────────→ 判断触发（§六）
```

**双通道**：被动通道 = 事件发生在人身上（`E_t ~ P_W(E|S_t,R_t,G_t)`）；主动通道 = 人选择、世界回应（`A_t ~ π(S_t,R_t,G_t;驱力)` → 成功概率由 P_W 裁决）。模式差异的唯一语义 = **A_t 是否可用**。

> 术语注：本轨「双通道」= 被动/主动通道（轨迹律语义），与游戏正典「双通道」（M1/Broca 战斗通道）**同名不同义**——学术轨词条不入注册表（#117 D 裁决），以本文档为词典。

**记忆双层**：被动段记录（δ 打结果标签）→ 决策点消费（检索既往结果 → 调制 π → 世界回应 → 新标签）。

## 四、状态空间

`S_t = (E, R, H, D₁, D₂)`，各轴 3 离散档（0 低 / 1 中 / 2 高）。语义：

| 轴 | 含义 | 被动可改 | 主动可改 |
|----|------|:---:|:---:|
| E | 经济/资源 | ✓ | ✓（投入） |
| R | 社会关系 | ✓ | ✓（投入） |
| H | 健康 | ✓ | ✓（养病投入） |
| D₁ | 驱力-生存缺口（E 低/事件 → 升；满足 → 降） | 派生 | 间接（E↑ 满足）∨ 消费 |
| D₂ | 驱力-社会缺口（R 低/事件 → 升） | 派生 | 间接（R↑）∨ 消费 |

扩展声明（不入 v0 轴）：外部风险/机遇轴（与事件发生器职责重叠）、能力轴（v0 无消费者）。

## 五、事件与动作

**事件** `E_t = (type, s, ΔS)`：
- type ∈ {经济冲击, 经济机遇, 关系冲突, 关系增益, 健康事件, 复合重大事件}（开放集合）
- s ∈ [0,1] 强度；ΔS ∈ {−1,0,+1}^5 按原型预设稀疏效应模式 × s（映射表 [NEW 待标定]）
- 重大性：type = 复合重大 ∨ s ≥ θ_maj（决策窗触发输入 + 记忆标签类别）

**动作** `A_t ∈ {∅} ∪ {target ∈ {E,R,H} × 投入档 l ∈ {1,2}} ∪ {D₁消费, D₂消费}`：
- 结果轴动作：目标轴 +l，成功概率 p(target, l) ∈ (0,1)（世界通道裁决）；无论成败按副作用表触发代价（如投入 E ⇒ H 或 R −1 风险）
- 消费动作：即时降 D 缺口（−1），代价映射表（酗酒/暴食/冲动消费/放纵类：ΔH/ΔE/ΔR 延迟 −1）
- ∅ = 维持现状（也是选择）
- 结果随机性全部归 P_W，π 不带结果噪声（归因纪律）

## 六、切换规则（决策窗）

**触发**：`决策窗开启 ⟺ (前一步事件重大) ∨ (当前驱力缺口 ≥ θ_D)`——被逼（重大事件后必须回应）与内在不满（驱力求变）两类抉择源。

**窗口**：开启后持续 k 步（v0 默认 k = 3）；窗口内每步仍采样被动事件（世界不因抉择暂停），结算顺序默认 = 先事件后动作；满 k 步关闭（除非再次触发）。

## 七、驱力动力学与行为策略

**驱力动力学**：缺口每步按缺失源轴状态递增（E 低 → D₁ 升；R 低 → D₂ 升）；满足来源：结果轴改善（E↑ → D₁↓；R↑ → D₂↓）、健康/资源事件、消费动作（即时 ↓）。越阈值 θ_D → 触发决策窗（§六）并为 π 提供输入。

**行为策略 π v0（两段式静态，否决 RL——需标量回报 U（D3 外部依赖）+ 长时程信用分配不可行 + 最优性杀死 R1）**：

```
段 1（驱力贪心 + 探索）：π₀(A) ∝ (1−ε)·exp(β·V_drive(A, S)) + ε/|A|
    V_drive：动作指向缺口最大的结果轴时取高值
段 2（记忆调制）：π(A) ∝ π₀(A) · exp(ζ·mean_v(检索集(A, S_t)))   ← 决策点消费记忆
```

- ε（探索）个体参数 ε_i 采样；β（理性温度）个体参数 β_i 采样
- 检索集 = §八 检索规则；ζ 调制强度（v0 全局参数）
- **对比设计**：无记忆组（ζ=0，检索关闭）vs 有记忆组（ζ>0）——H1 检验

## 八、记忆子系统

**记忆对象** `r_j = (id, t, c, s, ΔS, S_before, v, m)`（Q7-A）：

| 字段 | 语义 |
|------|------|
| c | 类别 ∈ 事件 6 原型 ∪ 动作 3 轴 ∪ 消费 |
| S_before | 创建时 5 轴状态（检索键——情境绑定唤起） |
| v | 结果标签：被动事件 = ΔS 净方向符号；决策动作 = sign(实际 − 预期成功概率 p)（RPE 语义） |
| m | 记忆强度 ∈ (0,1]（寿命 + 检索权重） |

**操作规则包 v0（Q8-A，参数见表 §十一）**：

```
显著性：被动 δ = s·‖ΔS‖；决策 δ = |v|；δ < θ_sal → 丢弃（平庸不入记忆）
编码：f_θ 确定性映射（同输入同记忆；编码随机源 = 0）
冗余：sim(r, r_j) = 同类别 ∧ 情境轴距(S_before, S_before_j) ≤ θ_ctx
      sim ≥ θ_merge → merge 入最近记忆（更新 m/v）；sim ∈ [θ_create, θ_merge) → 以 p_merge 选 merge 否则 create（ξ^R 位）
寿命：每步 m ← m·(1−λ)；m < θ_forget → 删除（forget）
连边 ρ v0：边 = 时间邻近（|t_i − t_j| ≤ τ_near）∨ (同类别 ∧ 同 v 方向)；G = (R, E^G)
检索：对候选动作 A：检索 {r_j : c_j 相关 ∧ 轴距(S_before_j, S_t) ≤ θ_ctx}
      调制 = mean_v 按 m 加权 → 进 π 段 2；检索权重加小噪声 σ_ret（ξ^R 位 2）
```

## 九、随机源与初始条件

**随机源（分离可归因，#117 D4 纪律）**：

| 源 | 内容 | 位置 |
|----|------|------|
| ξ^W | 世界事件采样 `E_t ~ P_W(·|S_t,R_t,G_t)`；动作成功裁决 p(target,l) | 每被动步 / 每次动作 |
| ξ^A | π 选择（ε 探索） | 决策窗每步 |
| ξ^R | merge/create 边界（p_merge）+ 检索噪声 | 记忆操作时 |
| （编码源） | **= 0**（f_θ 确定性） | — |

**初始条件（双维）**：个体层 `θ_ind = (S₀ 五轴初值, ε_i ∈ [0, ε_max], β_i > 0)` 从总体先验采样（先验分布入参数表）；R1 强式检验固定 (S₀, θ_ind)。

## 十、检验设计与门禁

**条件矩阵（≈6 条件 × N = 200 条轨迹/条件）**：主跑（三源全开 + 记忆调制）｜消融 ξ^W=0｜消融 ξ^A=0｜消融 ξ^R=0｜确定性对照（三源全关）｜无记忆组（ζ=0）。

**T 扫参 ∈ {200, 1000, 5000}**（须容纳 ≥ 数个决策窗 + 记忆积累期）。

**度量**：
- 主：状态轨迹成对距离 `D̄ = (1/N²)Σ_{i<j} (1/T)Σ_t ‖S_tⁱ − S_tʲ‖`
- 决策点距离增量 `ΔD_decision`（决策窗内外的距离增长对比——直接检验"分歧在决策点累积"）
- 辅：事件序列相似度（Jaccard/编辑距离）——区分状态分化与事件结构分化

**门禁（指标锁、数值不锁——#87 Q6 先例，首跑后标定）**：
- G1 非退化：成对距离分布下分位 > 0
- G2 不坍缩：D̄(t) 随 t 非降（差异不回归均值）
- G3 消融可归因：各单源关闭后 D̄ 变化可解释（全开 ≥ 各关，至少非退化）

**科学检验 H1（非门禁）**：有记忆组 ΔD_decision 与无记忆组之差——报告效应量，不设 PASS/FAIL（预设结论的检验污染实验）。
