## 定位声明

本研讨从"用哥德尔定理推导体验侧"（已否决：方向反了，不可判定 ≠ 越界）出发，历经"定义体验侧"（已否决：F4 无公共外延）→"完整定义意识"（已否决：定义=公共判别规则，与第一人称互斥）→ 收敛到"**结构侧**"可定义、体验侧是公设（#40 三件套的正式化）。

**v5.3 最终定位**：三要件合取判定的是「**意识候选结构**」C_candidate(S)——它是一个**充分条件**（满足 ⟹ 至少是意识的候选结构），**必要条件未知**（意识 ⟹ 是否必满足三要件，未证明）。体验侧的收窄**不**由本定义承担，由桥接公设承担（F4，数学外）。

## 定义

```
C_candidate(S) ⟺ Int(S) > 0 ∧ Diff(S) ≥ θ_D ∧ ∃ SelBroadcast(S)

Int(S)         = sup{ KL_μ(F‖F₁×⋯×Fₖ) : supp(μ) ⊆ Reach(S), μ ∈ ℳ_info, KL 有限 } > 0
Diff(S)        = log₂|ReachableSet| ≥ θ_D（θ_D = 3 bit；连续状态空间超出定义域）
SelBroadcast   = ∃I₀ ⊆ V, |I₀| = 2, J ⊆ V∖I₀, |J| ≥ 2：
                   联合读出 ≥ 3 值（非退化）
                   ∧ ∀j∈J: TE(I₀→j | j_past) > 0
                   ∧ SelRatio(I₀→j) ≥ θ_S
```

**符号**：
- S = (X, F, Δ)：X 状态空间（有限）、F 转移、Δ 可达关系；V = 分量集
- ℳ_info：满足 DPI ∧ 链式 ∧ 置换不变（A4）的信息测度族——非空（互信息 I）
- F₁×⋯×Fₖ：F 的分量 marginalization 之积（解耦动力学；partition = 分量划分，已声明）
- Reach(S)：可达状态集；supp(μ) ⊆ Reach(S) 为类型正确写法（μ 是测度，非状态）
- TE(I₀→j | j_past)：转移熵（源过去 → 目标未来 | 目标过去）——含条件项
- SelRatio(I₀→j) = TE(I₀→j) / max{ TE(K→j) : K ⊆ V∖I₀, |K| = |I₀| }（背景对比；背景=0 时 = ∞ 即完全选择性）

## 性质清单

1. **纯数学**：集合、映射、测度、不等式——零生物/神经词
2. **跨基底**：X 任意有限集合；置换不变（A4）保证命名无关
3. **哥德尔中性**：不含算术、无编码、无证明理论；判定全程有限可计算（S\*₃ 为 16 状态）
4. **判定唯一（U1）**：sup 吸收测度选择，不依赖观察者/运行条件（μ_S 方案否决）
5. **反例免疫（有限）**：麻醉态/展开/开关耦合/局部网络四类攻击面被拒；计数器/垃圾变量**有意宽泛接受**
6. **测度客观**：公理集（DPI/链式/置换不变）+ 极值原则（sup）
