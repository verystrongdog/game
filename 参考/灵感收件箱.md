### 2026-08-06 — 摇摇欲坠的积木塔（精神武器灵感）

**形态**：一座永远在倒塌边缘的积木塔——每一块积木都是一段髓鞘化的神经链路，最底下的那块已经裂了。塔不倒——它只是在不停地摇晃。

**能力：破坏敌人链路稳定性**。攻击敌方神经链路的髓鞘化结构——使目标已髓鞘化的链路暂时退化（m 值临时降低），或使正在使用的链路在动作中途"断开"（动作被打断）。

**可能的机制方向**：
- 使敌方一条链路的 m 值临时 −Δm，持续 N 回合（髓鞘化被月光场的退相干效应暂时瓦解）
- 打断敌方正在执行的 M1/Broca 动作——"你正要挥拳，但你的手忘记了为什么挥"
- 如果目标链路 m < 阈值 → 链路完全不可用 1 回合
- 对完整体造物/思维造物额外有效（它们的链路本身就是月光凝结的）

**临床锚点方向**：解离障碍中"动作中断"体验——患者执行一个动作时突然"忘记为什么做这个动作"，运动计划在意识层面断裂。或精神分裂症中连贯思维被"切断"（thought blocking / Sperrung）的体验。

**分类归属**：精神武器的四个方向中，可能属于**力**（改变场内力——这里的"力"是链路耦合力）或**新方向**（作用于链路结构的武器）。

- 关联：精神武器 §5（`实体/武器与装备.md`）、月光场退相干模型（`事件/月光场-标量场模型.md` §六）、脑区链路髓鞘化模型
- 可能落点：作为第 13 件精神武器（需临床文献锚定）、或作为已有精神武器「原始人的眼睛」的变体效果
- 待确定：具体的临床文献锚点、形态的感官细节、m 阈值、冷却时间

## 🆕 确定的痛苦 vs 不确定的希望

> "人宁愿要确定的痛苦，也不要不确定的希望。"

### 心理学锚点

这是一个经过大量实证检验的现象：

- **Ambiguity Aversion (Ellsberg 1961)**：人在已知概率的坏结果和未知概率的好结果之间，系统性地偏好前者。即使期望值相同。
- **Temporal Discounting + Uncertainty**：未来奖励不仅要被折扣（delay discounting），还要被不确定性再次折扣。两次折扣叠加后，眼前的确定痛苦比未来的不确定希望"便宜"得多。
- **Learned Helplessness (Seligman 1972)**：反复失败后，"尝试"本身变成了不确定的痛苦——不做尝试反而成了确定的解脱。
- **Depressive Realism (Alloy & Abramson 1979)**：抑郁者在评估自身控制力时比正常人更准确。正常人的"乐观偏见"是一种保护性的认知扭曲——抑郁者失去了这层滤镜。

### 与游戏系统的接口

这条洞察可以穿透多个子系统：

**1. EVC 公式的"不确定性罚金"**

当前 EVC = benefit − C_control − effort_discount + ε。但 benefit 在 helplessness > 0.5 时显示为 ???。可以加一个"确定性偏好"参数：

```
如果 benefit 不可见（???状态）:
  有效 benefit = 已知 benefit × (1 − uncertainty_penalty)
  
uncertainty_penalty 随 helplessness 增长:
  helplessness = 0.0 → penalty = 0.1（轻微厌恶模糊性）
  helplessness = 1.0 → penalty = 0.5（极度厌恶不确定性）
  helplessness = 2.0 → penalty = 0.8（几乎把希望折到零）
```

这样，"确定的痛苦"（C_control 可见、已知代价）会比"不确定的希望"（benefit 显示为 ???）在 EVC 中更有竞争力——准确地模拟了玩家的感性偏好。

**2. 心境漂移的方向性不对称**

```
确定痛苦 → 心境快速下行（η_mood × 1.5？）
不确定希望 → 心境缓慢上行（η_mood × 0.5？）

不对称比率 3:1 —— 一次确定的失败需要三次不确定的成功来抵消。
```

这与临床观察一致：负面事件对心境的影响强度约为正面事件的 3 倍（Baumeister et al., 2001, "Bad is stronger than good"）。

**3. 照护驱动的悖论**

照护驱动（读他人 PAD）在此框架下产生一个有趣矛盾：你共情到对方正在"确定痛苦"中 → 照护驱动激活 → 你想帮。但如果你自己也处于不确定希望中（benefit=???），你帮的代价是放弃自己仅有的"确定"——即使那是痛苦。

这就是"共情疲劳"的计算路径：照护驱动反复激活 + 自身 benefit 不可见 → EVC 倾向于不帮 → 玩家选择"袖手旁观" → 认知失调 → SAN 下降。

**4. 心境的"确定性偏倚"参数**

不同角色的心境设定点（PAD_set）可以隐含一个"确定性偏好"参数：

| 角色类型 | 确定性偏好 | 行为表现 |
|---------|-----------|---------|
| 焦虑症 | 极高 | "不确定的希望比确定的痛苦更可怕"——宁可回避一切不确定性 |
| 抑郁症 | 高 | "反正希望也是假的"——把不确定性全部折成零 |
| 正常人 | 中等 | 正常的不确定性厌恶 |
| 躁狂症 | 低 | "不确定才刺激"——拥抱不确定性，甚至低估风险 |
| PTSD | 极高（特定领域）| 对与创伤相关的希望极度不信任 |

这个参数可以直接作用在 EVC 的 `uncertainty_penalty` 上。

**5. 作为叙事工具**

"确定的痛苦"是治疗中心里很多角色不离开的原因——不是因为他们喜欢痛苦，而是因为痛苦是他们唯一确定的东西。月光下的希望是危险的——你相信了，它可能成真，也可能不。但痛苦是可靠的。

一个关键叙事节点：角色必须在"确定的痛苦"和"不确定的希望"之间做出选择。这个选择的时刻就是镜子房间的核心功能之一——你选择如何叙述你的处境，月光就会响应你的叙述。
