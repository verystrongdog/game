## 二、判据结构级不变性（Q2）

**决策 D2**（链接 2）：CS′ 判定对象从「整个系统」改为「系统中**是否存在**一个满足候选结构的因果单元」：

```
CS'(S) = ⋁_{C∈𝒞(S)} CS'_local(C)
𝒞(S⊕R) = 𝒞(S) ∪ 𝒞(R)   （R⊥S 独立）
⟹  CS'(S⊕R) = CS'(S) ∨ CS'(R)
```

- **Replication Invariance**（复制不变性）：独立复制不新增候选结构（CS′(S)=0 ∧ CS′(R)=0 ⟹ CS′(S⊕R)=0）；无关模块不稀释意识（CS′(S)=1 ⟹ 加任意独立惰性系统仍为 1）。**两性质均无需改动 θ_D。**
- 方案否决：B（稀释反噬 + θ_D 退化为规模依赖经验参数）、C（混淆「判定对象」与「分量内 Diff 归一化」两问题）、D（复制攻击是已精确定位的判据缺陷，不再是「有意宽泛」）。
- 实测锚点：S(F8): Diff=2.70 → S⊕S: Diff=5.33，CS′ 0→1（`sim_consciousness_cs4_test.py` 复制攻击段）。

## 三、因果分量分解（Q2.1）

**决策 D3**（链接 3）：分量边 = **一阶结构依赖**，分量 = 无向图弱连通分量。

边定义（规范层，Layer 0/1）：

```
(i,j) ∈ E_S ⟺ ∃ y,y' ∈ Reach(S):
    y_{-i} = y'_{-i} ∧ y_i ≠ y'_i ∧ P_F(X'_j|y) ≠ P_F(X'_j|y')
```

```
𝒞(S) = CC(G_S^u)   （无向化依赖图的弱连通分量；非强连通——强连通会错误拆开 A→B→C）
```

- **规范定义 = A**（完整模型 F 可访问时精确计算）；**观测估计 = D**（Layer 3 无模型访问时用 TE/cTE，显式 `Ĉ_obs ≠ 𝒞(S)`，是估计器而非第二套定义）。
- 三性质为 A 的推论：①复制稳定性（E_{S⊕R}=E_S∪E_R）②单调性（加边只合并分量，无统计偶然拆开）③同构不变性（G_S≅G_{S'} ⟹ 𝒞(S)≅𝒞(S′)）。
- 冗余副本变量不产生边（Reach 内无单坐标翻转对）——结构性区分「相关性/信息冗余」与「结构依赖」。
- 选择 A 的理由：Layer 0 已给出完整 F，用 TE 阈值猜测因果结构是「用统计估计器替代已有本体结构」；A 无阈值（ε/τ/历史长度全免）。

## 四、Reach 定义（Q2.2）

**决策 D4**（链接 4）：

```
Reach(S) = { y : ∃ y₀ ∈ supp(μ₀), ∃ t ∈ ℕ₀, P(Y_t = y | Y_0 = y₀) > 0 }
```

- 正概率、μ₀ 锚定、无界时域、**含瞬态**（瞬态结构不得因最终进入简单吸引子而被丢弃）。
- 否决：R2（平稳集，丢瞬态——S₀→S₁→S₂→S* 反例）、R3（全空间 Ω——已实测退化：`sim_consciousness_v5_check.py` :104-121 的 `full_reachable` 实现使 Diff=log₂|Ω|=N，判定为 **Reach 定义缺失导致的实现错误**，非 Diff 本身问题）、R4（任意初态并集，与 Layer 0 外生 μ₀ 语义冲突）。
- **S1（一阶边边界）**：当前边定义只认单坐标翻转（`E_S = E_S^(1)`）；纯高阶交互（如 Reach 内 i₁、i₂ 完全相关时 j′=i₁⊕i₂）**不在本版**，标注为明确边界；高阶依赖 `E^(k)`/超图留作 anomaly-triggered 扩展（§八）。
- **S2（规范基本核）**：边判定使用 Layer 0 规定的基本转移核 F；多时间尺度系统必须预先规定规范基本时间步（F_{Δt_min} 或明确规范化核），**不得由 CS′ 判定过程动态选择**（否则时间尺度成为隐藏自由参数）。
- **定义域限定**：当前版本仅限离散/可枚举状态空间；连续域（可达开集/support）另开定义。

## 五、分量内 Diff 定义域（Q2.3）

**决策 D5**（链接 5）：

```
Diff(C) = (1/(T+1)) · Σ_{t=0}^{T} H((π_C)_* μ_t)
        = (1/(T+1)) · Σ_{t=0}^{T} H(μ_t^C)     （O_t^C = π_C(O_t) 外生投影到 C）
```

- 度量**实际运行轨迹中展开的分化**，非理论容量；`Capacity(C) = log₂|Reach(C)|` **保留为诊断量**，不参与 CS′ 判定（可观察 `Diff/Capacity` 利用率）。
- 否决：D-A（可达集容量——sim 中 μ₀ 均匀 → Reach≈Ω → Diff≈|C|，θ_D=3bit 退化为「分量≥3 变量」，修不掉）、D-C（平稳分布熵——丢瞬态，与 D4/R1 冲突）、D-D（双测度并列——定义膨胀）。
- 理论定义 vs 有限样本估计分离：`Diff`（定义）与 `Diff̂`（估计，含置信区间/置换检验）分属规范层与统计层。
- **μ₀ 基准 = Unif(Ω)**：实验控制条件，非理论公设（Layer 0 中 μ₀ 仍是外生输入）；任务化 μ₀ 作为后续 robustness/任务条件实验轨，暂不进入主 benchmark（避免污染 F_A vs F_B 的因果比较）。
- 与 Q2/D2 的配套关系：两个独立分量合并不再计算整体 Diff（熵可加性不再造成虚假增益）——**D2 与 D5 相互配套，非两个独立修补**。

## 六、SM 重建（Q4、Q4.1）

**决策 D6**（链接 9）：SM 拆为三要件：

```
SM' = SelfRep(M) ∧ SelfUse(M) ∧ AgencyUse(M)
```

- **语义四元组（身体状态/行动能力/内部目标/自身未来）不得进入规范判据**——违反跨基底（对 CA/数字电路无法无语义地标定「身体/目标/未来」；否则 CS′(C) 变成 CS′(C, researcher's semantic labeling)）；保留为**构造/解释指南**（Construction Heuristic），须翻译成 状态变量+转移结构+干预效应 才能入判据。
- **SelfUse**：行为生成使用 M（M→A 边，do 干预改变行为分布）。
- **AgencyUse**：do 干预作用于**外显动作/环境作用变量 A**（非任意内部变量——否则「改内部寄存器→后续寄存器变」被误判为 agency）；`Δ_A(M) = D(P(A|do(M=m)), P(A|do(M=m'))) > 0` 为结构性候选条件；「系统性/显著」阈值留统计层（与 D 条款一致：规范定义与观测估计分离）。
- **M 的自反结构**（M_{t+1} 对 M_t 的结构依赖）保留，但单独不构成 SelfRep（M_{t+1}=M_t 简单记忆也满足）。

**决策 D7**（链接 10）：**SelfRep = R-B 内部因果穿透**：

```
V = M ⊍ A ⊍ I
SelfRep 必要条件: ∃m ≠ m', ∃k ∈ I:
    P_F(X'_k | do(M=m)) ≠ P_F(X'_k | do(M=m'))
    （即 M --causal--> I，I = V∖(M∪A)）
```

- 排除「干预效应只停留于外显动作接口」：F9（m₁←s、a′=m₁）满足 M→A 但缺 M→I → SelfRep=0（状态估计+反馈控制的精确结构画像）。
- **A=∅ 退化条款**（封闭系统如 CA）：I=V∖M，条件退化为「do(M) 改变任一非 M 内部变量的转移」——跨基底保持，无需强行指定「哪个格子是身体」。
- **R-B 是必要条件/候选条件，不单独声称充分**（防 M→Z→A 中普通计算中间变量冒充）；完整 SelfRep 的充分定义仍开放。
- R-C（预测性 `I(M_t; Y_{t+1}|(Y∖M)_t)>0`）否决为规范 SelfRep（预测信息 ≠ 自我表征，F9 即反例），保留为辅助预测性指标。
- **判别三角**（最小判别集，三系统实测为本框架第一条实证线）：

| 系统 | Y∖M→M 表征形成 | M→I 内部穿透 | M→A AgencyUse | SelfRep |
|------|:---:|:---:|:---:|:---:|
| F1 计数控制器（死端投影）| ✓ | ✗ | ✗ | 0 |
| F9 伪自模型（状态估计器）| ✓ | ✗ | ✓ | 0 |
| F8′ 表征+因果使用 | ✓ | ✓ | ✓ | 1 |

## 七、跨系统 benchmark 协议（Q3、Q3.1、Q3.2）

**决策 D8**（链接 6）：

- **B1 结构**：正类 = **candidate-positive / prior-positive**（桥接公设预期含候选结构：生物神经网络/人脑数据/自模型控制器——非「真意识」标签，避免循环验证）；负类 = **anti-complexity controls**（随机系统/纯前馈/数字电路/通信网络——可高 Diff 但预期无候选结构）；判别组 = **{反馈控制器, 细胞自动机, RL 智能体}**（无先验，画边界用）。
- **失败线**：F+ = 任一明确负对照 CS′=1（假阳性）；F− = **全部**正类 CS′=0（假阴性；单个判 0 不失败——异质性）。判别组**不设失败线**。
- **双轨对照**（第一项实验）：CS′_old（整体式）vs CS′_new（分量级 OR），报告 ΔCS′ 及全要件对照表（Int_global vs max_C Int(C)；Diff 逐分量；SB/SM 的 ∃C 形式）。
- **Sanity suite**：S1 独立复制（CS′(S⊕R)=CS′(S)∨CS′(R) 等式断言）；S2 无关惰性模块（CS′(S⊕Z)=CS′(S)，稀释反噬检查）；S3 真正耦合（**只验证分解合并性质** 𝒞(S↔R)={S∪R} 与合并后正常执行，**不预设 CS′ 方向**——防止 Replication Invariance 被错误实现成「规模永不可增」杀掉真实整合；S3 是实现正确性测试，非理论预测）。
- 否决：B2（无失败线，不可证伪）、B3（「复杂度匹配」本身未定义，暂缓）。

**决策 D9**（链接 7）：

- **A1：F+/F− 只作用于 simulation 轨**（规范定义可精确计算时才判定理论失败）。Observation 轨（仅 Ĉ_obs）报告估计值 + 不确定度 + **estimator validity**（Ĉ_obs ≈ 𝒞 何时成立），不触发失败线——把「估计误差」与「理论失败」分离。
- S1/S2 等式断言、S3 实现正确性（见 D8）；**骨架锁定 ≠ 参数冻结**（θ/N/p/τ/CA rule/controller gain 等走脚本配置，防「参数挑选实验」）。

**决策 D10**（链接 8）：

- **H1：人脑数据轨 = synthetic observation / estimator-validity benchmark**——`F_known → 𝒞_exact → synthetic trajectory → Ĉ_obs`，测 `Ĉ_obs ≈ 𝒞_exact` 何时成立（样本量/噪声/时间分辨率/观测缺失/隐变量/耦合强度梯度）；**严禁「synthetic trajectory ≡ human brain」**；三标签：Simulation-positive / Synthetic observation benchmark / Real human data = future extension。
- **Paired / mechanism-matched control**：每类 ≥2 变体（representative + 预期负控制；最平凡版是**预期负控制**非硬标签，判 1 反而是有价值结果）；配对仅改变一个目标机制（F_open↔F_closed、Rule0↔Rule30/110、random policy↔Q-learning、F9↔F8′），保持状态数/更新频率/观测数/噪声/运行时间接近。
- **n ≤ 8 为 v1 exact simulation 计算预算**（非理论定义域；|Ω|=2^n，n=8→256 舒适）；大系统（n≫8）走 **scaled observation track**（采样估计）。
- 关键输出：`Δ(Int,Diff,SB,SM)` 随目标机制系统性变化，而非单个系统「得 1」。

## 八、L4 收束声明（Q5）

**决策 D11**（链接 11）：**L4 = 边界/收束层**，非指标搜索层、非 benchmark。

- 两层结构：结构层（(Int,Diff,SB,SM,𝒞) 能否稳定区分候选系统）vs 现象层（第一人称体验是否还有结构量未决定的部分）。
- 收紧表述：「**在当前框架中，若两个系统在规范第三人称结构描述下完全同构，则第一人称现象是否随之相同，并未由 L1–L3 的结构定义与实验结果推出；任何相反主张都需要额外的现象—结构桥接公设**」。不声称「结构原则上不可能解释意识」。
- **L4 无失败线**：L1–L3 的 F+/F− 触发 → 优先修正 L1–L3；全部通过 → 只能得到「当前指标集与当前先验假设一致」，**不能**得到「CS′=consciousness」或「现象意识已被证明」。
- **B（指标完备性研究线）= anomaly-triggered route**：仅当系统性异常（某类机制稳定产生未解释的 CS′ 模式 / ΔCS′ 与理论预期稳定偏离且现有指标无法解释）才启动 E^(k)/高阶协同/时序结构等候选性质——「实验结果迫使我们增加结构描述」而非「觉得指标不够」。

## 九、L5 边界声明（Q6）

**决策 D12**（用户确认 Q6=A）：**T_CS 构造超出当前框架定义域**，不进定义、不进 benchmark。

- #40 D8（决策树 :2154）：哥德尔只提供类比不提供定理；F 可加 Con(F) 得 F′——「T_CS 内部不能证自身全部命题」若成立也只是哥德尔 II 的平凡例。

**T_CS 内部一致性检验记入推迟清单**（非否决），与 #40 D8「彭罗斯论证失败边界」衔接：不是「哥德尔证明意识不可数学化」，而是「当前框架不承载证明理论」。
