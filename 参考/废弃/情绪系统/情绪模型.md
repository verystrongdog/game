## 一、情绪分类

card.md 中定义了 9 种情绪，每种情绪在态度晶体中对应情绪轴上的取值倾向。以下逐项展开其心理学特征、触发条件和行为表现，作为后续态度子类匹配的基础。

### 恐惧

- **心理学定位**：人类最古老的情绪，源于对威胁的感知——无论威胁是真实的还是想象的。恐惧的生理基础是杏仁核的快速激活，在认知评估完成之前即可触发。
- **触发条件**：感知到具体威胁（蛇、坠落、刀锋）、未知事物（黑暗、陌生环境）、失去控制（无法预测的结果）、侵入性思维（"万一……"）
- **主观体验**：心跳加速、肌肉紧绷、注意窄化——将全部认知资源集中于威胁源，忽略周边信息。时间感变慢。
- **行为倾向**：僵住→逃跑→战斗，按此顺序触发。恐惧状态下人倾向于高估威胁概率、低估自身应对能力。
- **与其他情绪的区分**：恐惧指向**当下的具体威胁**，焦虑指向未来的不确定威胁，惊愕指向认知框架被击碎的瞬间空白。
- **在态度体系中的角色**：恐惧是负向情绪中最古老的一层，几乎不经过认知处理即可触发。它与反射行为天然亲和（恐惧→僵住/逃跑），但也可以被认知重新解释（"这不是蛇，是绳子"）或被价值驱动覆盖（"我害怕但我还是要做"）。
- **古典参照系**：杞人忧天（无对象的恐惧）、草木皆兵（知觉扭曲引发恐惧）、惊弓之鸟（创伤记忆触发恐惧）

### 愤怒

- **心理学定位**：对感知到的侵犯、不公或阻碍的回应。愤怒激活交感神经系统，提升痛阈，窄化认知至"侵犯来源"。愤怒是**穿上铠甲的恐惧**——底层往往是受到了伤害或威胁，但愤怒通过向外投射来恢复控制感。
- **触发条件**：被侵犯（边界的跨越）、被不公对待（期望的违背）、被阻碍（目标受阻）、被轻视（地位受威胁）
- **主观体验**：热感（面部、手掌）、能量涌动、思维被反复拉回侵犯源。注意集中在惩罚或纠正侵犯者。认知倾向于将对方意图解读为恶意。
- **行为倾向**：趋近（愤怒是唯一使人主动靠近威胁源的情绪）、表达（语言或肢体的对抗）、纠正（消除不公的驱动力）。高愤怒状态下对风险的评估显著降低。
- **与其他情绪的区分**：愤怒向外，内疚向内；愤怒是"你错了"，内疚是"我错了"。愤怒与厌恶经常共现（义愤），但愤怒针对行为，厌恶针对存在。
- **古典参照系**：怒发冲冠（蔺相如）、匹夫之怒流血五步（唐雎）、冲冠一怒为红颜（吴三桂）

### 内疚

- **心理学定位**：对自己违反道德标准或伤害他人的反应的自我意识情绪。内疚要求自我反思能力——必须能将自己评估为"做错事的人"。card.md 描述为"鞋子里的石头，牙缝里的菜叶"——微小但持续的刺痛，无法忽略。
- **触发条件**：伤害了他人（真实的或想象的）、违反了自己的道德标准、没有做到应该做的事（不作为的内疚）、幸存者内疚（在他人受难时自己安全）
- **主观体验**：胸口的沉重感、反复回放错误场景、自我贬低的想法。内疚的特点是**特定的**——关于某件具体的事，不像羞耻那样指向整体自我（"我做了坏事"vs"我是个坏人"）。
- **行为倾向**：弥补（试图修复伤害）、自我惩罚（以痛苦赎罪）、回避（不敢面对被伤害的人）、坦白（说出错误以减轻负担）。在态度体系中，内疚典型地驱动道德行为和惩罚机制。
- **与羞耻的区分**：内疚是"我做错了一件事"，尚可修复；羞耻是"我是一个错误"，修复无门。card.md 只纳入了内疚，羞耻不在情绪列表中。
- **古典参照系**：负荆请罪（廉颇）、自惭形秽（王济）、愧对江东父老（项羽）

### 焦虑

- **心理学定位**：对未来的、不确定的威胁的预期性恐惧。与恐惧共享生理基础（杏仁核-肾上腺素轴）但触发源不同：恐惧面对**确定的当下威胁**，焦虑面对**不确定的未来威胁**。
- **触发条件**：不确定性（结果未知）、不可控性（无法影响结果）、预期负面事件（"可能会发生不好的事"）、认知失调（两个矛盾的信念或选择之间的拉扯）
- **主观体验**：坐立不安、肌肉紧张但无明确对象、注意弥散（无法集中，不断扫视环境寻找威胁线索）、反复思考最坏情况。过度警觉——将中性刺激也解读为威胁信号。
- **行为倾向**：回避（远离可能触发焦虑的情境）、过度准备（反复检查，试图消除不确定性）、寻求确认（向他人求证）、犹豫不决（因害怕错误选择而迟迟不行动）。在态度体系中，焦虑经常触发惩罚机制（为防最坏情况而退缩）或反射（僵住）。
- **与恐惧的区分**：恐惧有明确对象（"我怕这条蛇"），焦虑无明确对象或对象过于弥散（"我总觉得要出事"）。
- **古典参照系**：杞人忧天、患得患失（孔子论鄙夫）、如坐针毡、芒刺在背

### 悲痛

- **心理学定位**：对失去的反应。失去可以是人的死亡、关系的结束、机会的错失、身份的瓦解。悲痛不仅是情绪，也是一个过程——从否认到接受，可能经历漫长的哀悼。
- **触发条件**：丧失（死亡、分离、失去身体功能）、希望的破灭（努力后失败）、共情他人痛苦（传递性悲痛）
- **主观体验**：空虚感、时间变慢、对周围世界的距离感（解离）。身体感觉包括胸闷、泪腺压力、疲劳。认知上反复回到丧失的场景，但也可能出现对死者的理想化记忆。
- **行为倾向**：退缩（减少社交，从日常活动中撤退）、寻求慰藉（接近能提供安慰的人或物）、仪式化行为（葬礼、纪念）、表达（哭泣、诉说）。在态度体系中，悲痛可以使行为降至 0（冻结）或被价值驱动拉回 +1（化悲痛为行动）。
- **与其他情绪的区分**：悲痛是**对已经发生的丧失**的反应（过去导向），焦虑是对尚未发生的丧失的反应（未来导向）。悲痛与内疚经常共现——丧失之后的自责。
- **古典参照系**：泣不成声（蔡琰）、肝肠寸断（桓温）、伯牙绝弦（以行动终止回应丧失）

### 共情

- **心理学定位**：理解和分享他人情绪状态的能力。分为认知共情（理解他人的感受）和情绪共情（分享他人的感受）。card.md 说"可以传递其它情绪，不管是积极的还是消极的"——共情是情绪的管道，本身不带方向。
- **触发条件**：感知到他人的情绪表达（表情、声音、姿势）、想象自己在他人的处境中、与他人建立了情感纽带
- **主观体验**：自身情绪被他人情绪染色——看到别人痛苦感到痛苦，看到别人快乐感到快乐。伴随"镜像"身体反应（别人哭你也眼眶发酸）。与自身情绪的区别在于：你清楚这份情绪**属于对方**，你只是共享了它。
- **行为倾向**：关心（对对方福祉的关注）、帮助（减轻对方痛苦的行动）、回避（共情痛苦超过自身承受能力时选择不看——共情疲劳）、传递（将接收到的情绪传递给第三方）。在态度体系中，共情是唯一可以改变他人情绪向量的卡牌（传递积极情绪可减轻对方的恐惧/愤怒/悲痛）。
- **与其他情绪的区分**：共情是**中介**而非**终点**——它本身不痛苦也不快乐，它传递的内容才是。这与所有其他情绪都不同。
- **古典参照系**：恻隐之心人皆有之（孟子）、推己及人（孔子）、己所不欲勿施于人

### 快乐

- **心理学定位**：对正面事件、目标达成、需求满足的即时反应。多巴胺系统参与奖励预期和满足。card.md 说"幸福的碎片"——快乐是短暂的、具体的、依附于某个时刻的，不同于持久的幸福感。
- **触发条件**：目标达成（考了满分、完成了任务）、获得奖励（收到礼物、被夸奖）、积极社交互动（朋友相聚、被理解）、审美体验（美景、音乐）、意外的好运
- **主观体验**：轻盈感、能量上升、时间飞逝、注意拓宽（相比于恐惧的注意窄化）。面部肌肉激活（微笑、眼角的笑纹）。对周围世界的正面评估倾向。
- **行为倾向**：趋近（想要延续或重复快乐来源）、分享（告知他人，传递快乐）、探索（在安全状态下扩大活动范围）、冒进（快乐状态下倾向于低估风险）
- **与其他情绪的区分**：快乐是**事件驱动的瞬时反应**，幸福是持续的心境底色。card.md 的体系里没有"幸福"，只有快乐的碎片——这有意为之：玩家可以收集碎片，但无法永远快乐。
- **古典参照系**：春风得意马蹄疾（孟郊及第）、乐不思蜀（刘禅）、幸灾乐祸、陶然忘机

### 爱

- **心理学定位**：爱在心理学的定义中一直存在争议。依恋理论将其定位为对特定对象的亲密纽带；三元理论将其分为激情、亲密和承诺。card.md 说"疯狂的别称"——强调了爱的非理性面和超越功利计算的特质。在态度体系中，爱是唯一可以使人主动选择对自身不利选项的正向情绪。
- **触发条件**：长期积极互动、对对象价值的认可、依恋纽带的形成、自我边界的扩展（将对方纳入"自我"的范围）
- **主观体验**：将对方的福祉视为自己的福祉、对分离的抗拒、面对对象时的生理反应（心跳加快、瞳孔放大）。认知倾向于美化对象、忽略其缺点。
- **行为倾向**：趋近与保护（想要接近并保护所爱对象）、牺牲（愿意为对象放弃自身利益）、独占（想要拥有对象的全部注意）、给予（不求等值回报的付出）。在态度体系中，爱 + 价值驱动可以让人做出在其他四个维度上都是负分的选择。
- **与其他情绪的区分**：爱不是"更强烈的喜欢"——喜欢是评估性的（"这个好"），爱是关系性的（"这是我的"）。爱的反面不是恨，而是漠然。
- **古典参照系**：飞蛾扑火（爱中的自我毁灭倾向）、爱屋及乌（认知偏向的泛化）、愿得一心人白首不相离（卓文君）、情不知所起一往而深（杜丽娘）

### 厌恶

- **心理学定位**：对有害或污染的回避反应。进化上最初与腐烂食物、排泄物、尸体等感染源相关（核心厌恶），后来扩展到道德领域（道德厌恶——对某些行为感到"恶心"）。card.md 说"希望这个东西从世界上消失"——厌恶的独特之处在于它不是逃跑（恐惧是逃跑），而是**排斥和消灭**。
- **触发条件**：腐烂物、排泄物、体液（核心厌恶）、违反道德规范的行为（道德厌恶）、被污染或可能被污染的物体（污染厌恶）、某些动物（蟑螂、老鼠——动物厌恶）
- **主观体验**：恶心感（实际可能引发呕吐）、想要清洗或清除被污染区域的冲动、对面部表情的独特影响（皱鼻、上唇上提）。认知上会将被厌恶对象归入"不可接触"类别，且这种归类极难被理性论据改变。
- **行为倾向**：推开或扔掉、清洗（仪式化清洁行为）、回避接触、公开排斥（表达厌恶以划定道德边界）。在态度体系中，厌恶 + 惩罚机制会使人远离，厌恶 + 道德驱动会使人主动排斥（嫉恶如仇）。
- **与其他情绪的区分**：厌恶是**排斥**（"让它消失"），恐惧是**逃离**（"我要安全"），愤怒是**攻击**（"我要纠正"）。三者经常共现，但驱动方向不同。
- **古典参照系**：掩鼻而过（孟子论西施蒙不洁）、嫉恶如仇（傅咸）、割席断交（管宁——道德厌恶切断社会关系）

> **注意**：以上向量倾向是"默认"方向。在角色病情、事件和敌方干预下，某些情绪在特定情境中的向量值可能发生变化（如躁狂症可能将愤怒变为 +1）。

## 二、PAD 情绪空间：从标量到三维向量

将 9 种情绪压进 +1/0/-1 一根轴，会丢失关键信息：愤怒和恐惧都是"负面"，但愤怒推人逼近，恐惧推人逃跑——方向完全相反。需要更多维度来区分它们。

Mehrabian & Russell (1977) 的 **PAD 模型**用三个近乎正交的维度描述情绪，原论文为 151 个情绪词提供了三维坐标：

| 维度 | 含义 | 两极 |
|---|---|---|
| **Pleasure** 愉悦度 | 好受还是难受 | +1 愉悦 / -1 不悦 |
| **Arousal** 唤醒度 | 有多强烈 | +1 高度激活 / -1 低度激活 |
| **Dominance** 控制感 | 谁在掌控 | +1 我掌控 / -1 我被掌控 |

两两正交已被 fMRI 研究独立验证。

### 2.1 9 种情绪在 PAD 空间中的定位

基于 Valdez & Mehrabian (1994) 的八分区分类 + 现有实测数据：

| 情绪 | P (愉悦) | A (唤醒) | D (控制) |
|---|---|---|---|
| 快乐 | + | + | + |
| 爱 | + | + | ~0 |
| 共情 | ~0/+ | ~0/+ | ~0 |
| 愤怒 | **−** | **+** | **+** |
| 恐惧 | **−** | **+** | **−** |
| 焦虑 | − | + | − |
| 厌恶 | − | + | ~0 |
| 内疚 | − | ~0 | − |
| 悲痛 | − | **−** | − |

### 2.2 旧系统（+1/0/-1）的三处致命压缩

| 压缩 | 丢掉了什么 |
|---|---|
| 愤怒和恐惧都是 −1 | P: 都是负 ✓。A: 都是高 ✓。**D: 愤怒是掌控(+)，恐惧是被控(−)**——完全相反。愤怒让人逼近，恐惧让人逃跑。压成一个值等于砍掉了行为方向。 |
| 悲痛和焦虑都是 −1 | P: 都是负 ✓。**A: 悲痛是低唤醒，焦虑是高唤醒**。一个让人不想动，一个让人坐立不安。压成同一个值。 |
| 快乐和爱都是 +1 | P: 都是正 ✓。A: 都偏高 ✓。**D: 快乐是"我得到了"（掌控），爱是"我被牵引"（半失控）**。飞蛾扑火和春风得意不能用同一个值。 |

### 2.3 PAD 空间的物理性质

**性质 1：距离 = 情绪相似度。** 恐惧和焦虑在 PAD 空间里挨得近（都是 −P +A −D，焦虑只是 D 稍高一点）。恐惧和愤怒隔得远——D 轴上一正一负。

**性质 2：维度独立。** 改变 Arousal 不强制改变 Pleasure（可以从"平静的快乐"变成"兴奋的快乐"）。改变 Dominance 不强制改变另两个轴（恐惧→愤怒 = 只翻转 D 轴，P 和 A 不变）。

**性质 3：情绪可以在空间中移动。** PAD 空间中的矢量过渡有心理学意义：恐惧→愤怒是沿着 D 轴正向移动，恐惧→悲痛是沿着 A 轴负向移动。

**性质 4：情绪可以叠加。** 多张情绪卡在手 → 多个 PAD 向量取加权平均 → 当前情绪的 PAD 坐标。又怕又怒 = 恐惧和愤怒在 PAD 空间的中间位置。

### 2.4 PAD 分量对行为的推力

| PAD 分量 | 行为含义 |
|---|---|
| P + | 趋近推力 |
| P − | 回避推力 |
| A + | 行为强度 ↑，但精度 ↓ |
| A − | 行为强度 ↓，或行为冻结 |
| D + | 主动行为（"我做"） |
| D − | 被动行为（"发生在我身上" / "我放弃了"） |

### 2.5 行为驱动的 PAD 激活条件

| 行为驱动 | PAD 条件 |
|---|---|
| 反射 | A > 阈值 且 D < 阈值（高唤醒 + 失控 → 身体替你做决定） |
| 惩罚机制 | P < 0（效价负 → 预判负面后果 → 回避） |
| 奖励机制 | P > 0（效价正 → 预判正面结果 → 趋近） |
| 道德驱动 | D > 0（有控制感才能选择"做对的事"） |
| 文化习俗 | D ~ 0（不主动掌控也不失控 → 按外部脚本执行） |
| 价值驱动 | D > 阈值（最高控制感 → 可以违背 P 和 A 的推力，突破向量限制） |

### 2.6 与态度体系的关系

PAD 坐标替代了旧的"情绪轴 ±1/0"标量。情绪卡不再写 `情绪 +1`，而是写 `PAD 向量 (P, A, D)`。态度晶体仍然保留三维结构，但情绪轴的"积极/中性/消极"切换为从 PAD 空间中导出的综合值。情绪之间不再只有 +1/0/-1 三种位置——9 种情绪在三维空间中各居其位，距离和过渡都有了计算基础。
