# 认知卡模板

> **⚠️ 已废弃**：认知卡不再作为玩家交互手段。认知技能设计见 [技能树系统/认知技能设计](../技能树系统/认知技能设计.md)。25 张认知卡的参数（d', criterion, 模块归属）已映射为认知技能节点。本文档保留供设计参考。

> 认知卡的设计规格书。每张认知卡归属 5 模块之一，以 C⁵ 复平面坐标（d' + i·criterion）量化操作质量，以加工深度 α 决定 System 1/2 走向。认知卡不消耗 AP（"看清不需要费力"），但受 CPM 评估序列约束——高阶认知操作需要前置模块先闭合。认知卡储存在背包中，战斗间持久保留。

## 一、字段规范

### 静态字段（卡面，永远不变）

| 字段 | 类型 | 说明 |
|------|------|------|
| `卡名` | string | 中文卡名，2 字动词。体现认知操作的本质 |
| `模块` | enum | 知觉与注意 / 记忆 / 知识表征与分类 / 表象与语言 / 推理问题解决与决策（5 选 1） |
| `倾向` | enum | 唯物 / 唯心 — 同一模块的两条设计路线。唯物偏"更准更清晰"，唯心偏"重构意义" |
| `时间导向` | enum | 过去 / 现在 / 未来 — 认知操作指向的时间方向 |
| `效果描述` | string | 一句话，玩家可见。如 "揭示敌人一个隐藏属性" |
| `基础效果` | string | 机械描述，模拟脚本用。如 "揭示敌方 1 个隐藏标签，d' 临时 +0.2" |
| `AP消耗` | int | 固定 0（认知卡不消耗 AP） |

### 认知质量字段（C⁵ 复平面参数）

| 字段 | 类型 | 说明 |
|------|------|------|
| `d'` | float | 精度（灵敏度），范围通常 -1.0 ~ +1.0。正=从噪声中区分信号的能力增强 |
| `criterion` | float | 判断偏向，范围 -1.0 ~ +1.0。正=保守（不容易说"是"），负=宽松（容易说"是"）。零=无偏向 |
| `加工深度 α` | float | 0~1，0=纯 System 1（直觉扫过），1=全 System 2（深度审慎）。作用于 |z_k| 作为标量增益 |

### CPM 相关字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `CPM步骤` | enum | Relevance / Implications / Coping / Normative — 此认知卡在 CPM 四步中的位置 |
| `CPM_SEC` | list | 此卡参与的 SEC 子检查（如 Novelty / Causal Attribution / Control / Internal Standards） |
| `前置模块` | list | 打出此卡前需要哪些模块已激活（空=无前置，可随时打出） |

### 效果类型

| 字段 | 类型 | 说明 |
|------|------|------|
| `效果类型` | enum | 揭示 / 重评 / 拓宽 / 窄化 / 重构 / 预览 / 回收 / 命名 / 归类 / 推演（按模块不同） |
| `效果目标` | enum | 自身 / 敌方 / 环境 / 卡牌 — 效果作用的对象 |
| `效果持续` | enum | 即时 / 本回合 / N 回合 / 整场 — 效果持续时间 |

### 联动字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `情绪扭曲` | string | 当前情绪对此认知操作的干扰/增益。如 "恐惧→注意窄化，d' 对威胁源 +0.3，对其他 -0.3" |
| `强化行为卡` | list | 此认知卡为哪些行为卡降低 φ 门控要求 |
| `combo_emotion` | list | 与哪些情绪卡 combo 有额外效果 |
| `门控解锁` | list | 此认知卡完成后为哪些驱动解除 φ 门控（如 "知识表征完成 → 解锁惩罚机制 φ"） |

## 二、填写示例

### 示例 1：知觉与注意（唯物）— 洞见

```yaml
卡名: 洞见
模块: 知觉与注意
倾向: 唯物
时间导向: 现在
效果描述: "揭示敌人一个隐藏属性。"
基础效果: "揭示敌方 1 个隐藏标签/属性。若敌方无隐藏属性，改为 d' 临时 +0.3（本回合）。"
AP消耗: 0

# 认知质量
d': +0.2         # 精度小幅提升——"看得更清楚"
criterion: 0.0   # 无偏向——只是收集信息，不做判断
加工深度 α: 0.3  # System 1 为主——知觉不需要深度加工，但比纯反射多了一点注意分配

# CPM
CPM步骤: Relevance
CPM_SEC: [Novelty]
前置模块: []     # 无前置——知觉是第一关

# 效果
效果类型: 揭示
效果目标: 敌方
效果持续: 即时

# 联动
情绪扭曲: >
  恐惧→注意窄化：d' 对威胁源 +0.3 但对非威胁源 -0.3
  快乐→注意拓宽：criterion 临时 -0.1（更容易注意到细节）
强化行为卡: [回避, 面对]
combo_emotion: [恐惧, 焦虑]  # 恐惧 + 洞见 → 确认威胁来源
门控解锁: []  # 知觉是第一关，不解锁其他门控

# 设计备忘
设计备忘: "第一关认知卡。成本最低、最先可用。效果温和但信息价值高。"
```

### 示例 2：表象与语言（唯心）— 隐喻

```yaml
卡名: 隐喻
模块: 表象与语言
倾向: 唯心
时间导向: 现在
效果描述: "给敌人一个临时标签，改变其行为倾向。"
基础效果: "为敌方添加 1 个临时标签（3 回合），敌方 AI 行为受标签影响。标签类型取决于当前情绪状态。"
AP消耗: 0

# 认知质量
d': 0.0          # 精度不变——命名不改变信息质量
criterion: -0.3  # 偏向宽松——"我愿意相信这个名字"
加工深度 α: 0.5  # System 1/2 之间——需要语言产生，但也需要直觉

# CPM
CPM步骤: Coping / Normative  # 命名参与 Adjusting 和 Standards 步骤
CPM_SEC: [Adjustment, Internal Standards, External Standards]
前置模块: [知觉与注意, 知识表征与分类]  # 需要先看到、先归类，才能命名

# 效果
效果类型: 命名
效果目标: 敌方
效果持续: 3 回合

# 联动
情绪扭曲: >
  愤怒→标签偏向"敌人/威胁"
  爱→标签偏向"可拯救/误入歧途"
  恐惧→标签偏向"怪物/不可名状"
强化行为卡: [对峙, 安抚, 说服]
combo_emotion: [共情]  # 共情 + 命名 → 更深的理解
门控解锁: []  # 表象与语言参与 Normative 闭合

# 设计备忘
设计备忘: >
  月光下，语言有创造现实的重量。"给它起个名字，它就不一样了。"
  隐喻的效果取决于标签是否被"相信"——角色 CHC 晶体知识 (Gc) 影响标签粘性。
```

## 四、5 模块参数速查表

### 4.1 模块特性一览

| 模块 | 心理学来源 | 核心问题 | 效果类型 | 时间导向 | CPM 主步骤 |
|------|----------|---------|---------|---------|-----------|
| 知觉与注意 | 知觉、模式识别、选择性注意 | 我看见了什么，忽略了什么 | 揭示、锁定、抽牌、检索 | 现在 | Relevance (Step 1) |
| 记忆 | 工作记忆、长时记忆、提取、遗忘 | 过去的什么正在影响现在 | 回收、闪回、重复结算、遗忘 | 过去 | Implications (Step 2) 辅助 |
| 知识表征与分类 | 知识表征、概念形成、图式/脚本 | 我把眼前的事归到哪一类 | 归类、重评、改标签 | 现在 | Relevance + Normative (Step 1+4) |
| 表象与语言 | 视觉表象、空间认知、语言理解/产生 | 我脑中浮现什么，如何命名 | 命名、触发幻象、重新表述 | 现在/未来 | Coping + Normative (Step 3+4) |
| 推理问题解决与决策 | 思维、推理、问题解决、决策 | 我如何得出结论并决定下一步 | 预览、推演、连携、AP 调整 | 未来 | Implications + Coping (Step 2+3) |

### 4.3 唯物 vs 唯心设计路线

| 模块 | 唯物卡方向 | 唯心卡方向 |
|------|----------|----------|

### 4.5 模块激活顺序约束

```
知觉与注意 → 知识表征 → 推理 → 表象与语言
  (Step1)     (Step1/4)  (Step2/3)  (Step3/4)
```

- 不能跳过知觉直接推理（必须先看到，再判断，再推演，最后命名意义）
- 同一回合内越靠后的模块，AP 消耗越高（推理比知觉贵，表象比推理贵）——但认知卡当前 AP=0，此约束留待后续设计
- 角色病情可以打断或扭曲这个序列

## 五、C⁵ 复平面与认知操作量化

### 5.1 单模块复平面

```
z_k = d' + i·criterion

|z_k|    = √(d'² + criterion²)   → 综合质量（模长）
arg(z_k) = atan2(criterion, d')   → 偏向方向
  - 正虚部（criterion > 0）：偏向保守（多容易漏掉）
  - 负虚部（criterion < 0）：偏向宽松（多容易误报）
  - arg = 0：无偏（criterion = 0）
```

### 5.2 加工深度 α 作为标量增益

```
z'_k = α · z_k

|z'_k| = α · |z_k|  → 深度越浅，有效质量越低
arg(z'_k) = arg(z_k) → 深度不改变偏向方向，只改变强度
```

### 5.3 CHC 角色能力修正

```
角色 CHC 向量 = (w_Gf, w_Gc, w_Gsm, w_Glr, w_Gv, w_Gs)

z_推理_有效 = z_推理 × (1 + β·w_Gf)
z_记忆_有效 = z_记忆 × (1 + β·w_Gsm + β·w_Glr)
z_知觉_有效 = z_知觉 × (1 + β·w_Gv + β·w_Gs)

β = 0.2（能力修正系数，小值确保能力是调节器而非主引擎）
```

### 5.4 认知故障的精确诊断（旧 "认知 -1" 的分解）

| 故障路径 | d' | criterion | α | 示例 |
|---------|-----|-----------|-----|------|
| 真算错了 | 低 | 正常 | 深 | 认真推但能力有限 |
| 不想推 | 正常 | 正常 | 浅 | 懒得想，随便捡了个结论 |
| 确认偏向 | 正常 | 高确认偏向 | 深 | 努力推，但只搜索支持性证据 |
| 灾难化 | 正常 | 严重悲观偏向 | 深 | 推演正常，但所有可能性指向最坏 |
| 自欺 | 低 | 高乐观偏向 | 浅 | 不想深想，选最舒服的结论 |

## 六、CPM 激活顺序与门控

### 6.1 CPM 四步

| 步骤 | 问题 | 主模块 | SEC 子检查 |
|------|------|--------|-----------|
| Step 1: Relevance | 跟我有关吗？ | 知觉与注意, 知识表征 | Novelty, Intrinsic Pleasantness, Goal Relevance |
| Step 2: Implications | 对我意味着什么？ | 推理, 记忆, 知识表征 | Causal Attribution, Outcome Probability, Discrepancy, Goal Conductiveness, Urgency |
| Step 3: Coping | 我能应对吗？ | 推理, 表象与语言 | Control, Power, Adjustment |
| Step 4: Normative | 这对吗？ | 知识表征, 表象与语言 | Internal Standards, External Standards |

### 6.2 SEC 闭合 → 情绪信号 → 驱动解锁

```
Step 1 闭合 → 情绪初步激活（效价 + 唤醒）→ 反射可用（如果威胁信号足够强）
Step 2 闭合 → 后果清晰 → 惩罚机制 / 奖励机制可用
Step 3 闭合 → 掌控感明确 → 道德驱动 / 文化习俗可用
Step 4 闭合 → 意义确认 → 价值驱动可用
```

### 6.3 回合内驱动解锁时序

| 回合 | 可用驱动 | 所需认知卡 |
|------|---------|-----------|
| 1 | 反射, 文化习俗 | 知觉与注意（Step 1） |
| 2 | + 奖励机制 | 推理（Step 2） |
| 3 | + 道德驱动 | 表象与语言（Step 3） |
| 4+ | + 价值驱动 | 全部 5 模块（Step 4） |

## 七、设计约束清单

填写认知卡时必须检查以下约束：

- [ ] 模块归属是否准确？（一个认知操作可能涉及多模块，选"主导模块"）
- [ ] d' 和 criterion 是否独立设定？（高 d' + 极端 criterion 是合理的设计——"看得很清但只信想信的"）
- [ ] 加工深度 α 是否与效果类型匹配？（揭示/重评可以浅，推演/重构应该深）
- [ ] CPM 步骤是否与模块的 CPM 参与度矩阵一致？
- [ ] 前置模块是否遵循激活顺序？（不能跳过知觉直接推理）
- [ ] 唯物/唯心路线是否清晰？（不要混——同一张卡不能既是"如实描述"又是"重构叙事"）
- [ ] 情绪扭曲是否指向具体的 PAD 维度？（不能只说"情绪影响认知"，要说哪个 PAD 分量影响哪个 C⁵ 参数）
- [ ] 效果类型是否与模块的效果类型表一致？
- [ ] 同一模块下唯物卡和唯心卡是否形成了有意义的对比？（差异不能只是"一个 +0.2 一个 -0.2"）
- [ ] 门控解锁是否正确？（检查 drives.json 中各驱动的 φ 前置条件）
