## 一、出牌区交互

### 1.1 核心规则

- **出牌区为自由区**：无固定槽位，不限放入卡牌类型和张数
- **逐张拖入**：玩家每次从手牌拖一张卡到出牌区
- **实时检测**：出牌区中的卡能形成有效组合时，自动显示组合名称、效果预览、代价
- **玩家确认**：预览后玩家选择确认打出、换卡、或全部撤回
- **结算后清空**：组合打出后出牌区立即清空
- **同回合可继续**：清空后可继续拖入新卡，形成下一组组合（AP 允许即可）

### 1.2 卡牌去路（结算后）

| 卡牌类型 | 去路 | 说明 |
|---------|------|------|
| 情绪卡 | 消耗（本场战斗移除） | 情绪是暂时性资源，打出即消失 |
| 认知卡 | 回牌库 | 持久保留，可在后续回合再次抽到 |
| 行为卡 | 回牌库 | 持久保留，同上 |

### 1.3 故障处理

**无法形成组合时**：
- 出牌区仅显示已放入的卡牌列表，不显示组合名称和效果
- 不阻止玩家继续拖入更多卡（可能在第三张形成组合）
- 不阻止玩家撤回卡牌
- 如果玩家在无法形成组合的状态下尝试确认打出 → 提示"当前卡牌无法形成有效组合"

## 二、组合检测与优先级

### 2.1 检测时机

每次有卡牌拖入或移出出牌区时，系统重新检测。

### 2.2 检测优先级

```
优先级 1: 完整态度 — 出牌区含 ≥1 认知 + ≥1 情绪 + ≥1 行为
优先级 2: 酝酿     — 出牌区含 ≥1 认知 + ≥1 情绪，且不含行为卡
优先级 3: 冲动     — 出牌区含 ≥1 情绪 + ≥1 行为，且不含认知卡
优先级 4: 执行     — 出牌区含 ≥1 认知 + ≥1 行为，且不含情绪卡
优先级 5: 无组合   — 出牌区只有单张卡，或只有同类型多张卡
```

### 2.3 同类型多张卡的情况

如果出牌区中有同类型多张卡（如 2 张认知 + 1 张情绪 + 1 张行为），系统应：

- 按"当前选中/最近放入的那张"优先参与组合
- 给出提示"另有 1 张认知卡未参与组合"
- 未参与组合的卡留在出牌区，玩家可：手动撤回、或继续拖入新卡尝试形成第二组组合

### 2.4 组合预览内容

确认打出前，预览面板必须显示：

```
┌──────────────────────────┐
│ 组合: [组合叙事名称]       │
│ 类型: 完整态度 / 酝酿 / 冲动 / 执行 │
│                          │
│ 参与卡牌:                 │
│   洞见(认知)    去路: 回牌库│
│   恐惧(情绪)    去路: 消耗 │
│   面对(行为-价值) 去路: 回牌库│
│                          │
│ 总 AP: 3                 │
│ 意志力: -2（价值驱动硬解锁）│
│ SAN 磨损: 0              │
│                          │
│ 效果预览:                 │
│   揭示敌方 1 属性          │
│   PAD 偏移: 恐惧爆发       │
│   心灵震慑 4 点            │
│                          │
│  [确认打出]  [换卡]  [撤回] │
└──────────────────────────┘
```

**代价不可支付时**：[确认打出] 灰色 + 原因文字（"行动力不足：需要 3，剩余 1"）

## 三、完整态度（三类组合）

完整态度 = 认知 + 情绪 + 行为。规则已健全，此处仅列出与两类组合的接口规则。

### 3.1 一回合限制

- 完整态度每回合最多 1 次
- 两类组合无此限制

### 3.2 完整态度附带产牌

- 根据态度效果，可能附带产生情绪卡加入手牌
- 产生的情绪卡类型 = 态度结算后的 PAD 坐标最近的情绪锚点

### 3.3 与两类组合的时序关系

- 如果一回合内先打出完整态度，后续仍可打出两类组合
- 如果先打出两类组合，后续仍可打出完整态度（只要 AP 足够且手牌支持）
- 两类组合产生的情绪卡可以在同一回合的后续组合中使用（立刻进手牌）

## 四、酝酿 — 认知+情绪

> **"我看清了，我也感受到了，但我没有行动。"**

### 4.1 触发条件

- 出牌区含 ≥1 认知卡 + ≥1 情绪卡
- 不含行为卡

### 4.2 管道状态

CPM 推进了，PAD 偏移了，但行为张力没有释放出口。情绪被"憋住"。

### 4.3 效果

```
1. 认知卡正常执行卡面效果（揭示/归类/预览等）

2. 情绪卡产生 PAD 偏移
   - 偏移量 = κ_base × (PAD_card - PAD_curr)
   - κ_base = 0.30（与完整态度中的情绪偏移一致）

3. 额外产 1 张情绪卡加入手牌
   - 产生的情绪卡类型 = 当前 PAD 坐标（偏移后）最近的情绪锚点
   - 距离公式: dist = sqrt((V-V_anchor)² + (A-A_anchor)² + (D-D_anchor)²)
   - 如果 PAD 接近中性（|V|, |A|, |D| 均 < 0.2），改为产 1 张"平静"
   - 产生的情绪卡使用对应情绪卡模板的完整数据（包含 PAD、打出效果、手牌压力等）

4. 本回合 PAD 衰减减半
   - δ_酝酿 = δ_normal × 0.5
   - 理由：情绪没有通过行为释放 → 消退更慢 → 为后续回合积累 PAD 动能
```

### 4.4 AP 消耗

- 认知卡 AP = 0
- 情绪卡 AP = 0
- **总 AP = 0**

### 4.5 风险链（连续酝酿）

```
连续酝酿（同回合多次打出认知+情绪）
  → PAD 累积加速（衰减减半 + 多次偏移叠加）
  → |PAD_curr| > 1.0 → 触发暴走
  → 本回合剩余行为被强制锁定为 B_raw 方向
  → 暴走后 3 回合萎靡（κ_eff × 0.3，|A| 被压低 0.3）
```

暴走机制为连续酝酿提供了自然刹车。0 AP 不意味着无风险。

### 4.6 设计意图

- **情绪卡生产引擎**：为后续完整态度储备情绪资源
- **AP 不足回合的合法操作**：不消耗 AP，可以做点什么而不是空过
- **代价**：放弃了本回合的行为输出（不造成任何行为效果）
- **叙事**：你看到了、感受到了，但没有动。感受不会消失——它留在你手里，等待下一次机会

## 五、冲动 — 情绪+行为

> **"我感觉到了，我做了——但没来得及想清楚。"**

### 5.1 触发条件

- 出牌区含 ≥1 情绪卡 + ≥1 行为卡
- 不含认知卡

### 5.2 管道状态

没有认知卡推进 CPM。行为直接由情绪 PAD 驱动，跳过了认知框架。

### 5.3 驱动限制

由于 CPM 未推进，φ 门控未解除。只能使用满足以下条件的行为卡：

| 驱动 | 是否可用 | φ 条件 |
|------|---------|--------|
| 反射 | ✅ 可用 | φ = 1.0（无前置） |
| 惩罚机制 | ✅ 可用 | φ fallback = 0.3（可部分通过） |
| 奖励机制 | ❌ 不可用 | φ 需要知识表征 ∧ 推理（均未完成） |
| 文化习俗 | ✅ 可用 | φ fallback = 0.4 |
| 道德驱动 | ❌ 不可用 | φ 需要规范性评估（未完成） |
| 价值驱动 | ❌ 不可用 | φ 需要五模块全部完成 |
| 照护 | ⚠️ 条件可用 | φ 需要知觉与注意 + 知识表征。如果玩家之前回合已激活这两个模块（且 φ 条件持续有效），则可用 |

### 5.4 效果

```
1. 情绪卡 PAD 偏移量 × 1.5
   - 偏移量 = 1.5 × κ_base × (PAD_card - PAD_curr)
   - 理由：没有认知框架缓冲 → 情绪冲击更直接

2. 行为卡正常执行，但 λ 权重固定为：
   - λ_raw = 1.0（直接情绪推力）
   - λ_drive = 0（驱动加工不参与）
   - 行为方向 = B_raw(PAD) 方向
   
3. 行为卡效果 × 1.2（情绪直接灌入行为，不加过滤）

4. 冲动一致性检测：
   - 情绪的行为推力方向 vs 行为卡的 valence 方向
   - 一致（如 恐惧→回避 + 行为valence=-1）→ 无惩罚
   - 不一致（如 恐惧→回避 + 行为valence=+1）→ 
       效果 × 0.7（打折）
       AP 额外 +1
       SAN 磨损 +1
```

### 5.5 一致性检测矩阵

| 情绪推力方向 | 一致的行为卡 valence | 冲突的行为卡 valence |
|------------|-------------------|-------------------|
| approach (+1) | +1 | -1 |
| avoid (-1) | -1 | +1 |
| approach_threat（主动靠近威胁源，如愤怒） | ±1 均可 | 无冲突（愤怒的 D>0 使其具有特殊灵活性） |
| slight_approach（微弱趋近） | +1, 0 | -1 |
| neutral（中性） | 任意 | 无冲突 |

### 5.6 设计意图

- **高风险高回报的快攻选项**
- 适合早期回合（CPM 未推进时）快速打出伤害或防御
- 情绪效果放大 + 行为效果放大，但只能选 S1 驱动
- **代价**：放弃了认知卡的信息和控制效果（不能揭示/预览/归因/重评）
- **叙事**：不假思索的冲动——力量更强，但方向不受控制

## 六、执行 — 认知+行为

> **"我看清了，我去做了——但我没什么感觉。"**

### 6.1 触发条件

- 出牌区含 ≥1 认知卡 + ≥1 行为卡
- 不含情绪卡

### 6.2 管道状态

CPM 推进了，行为执行了，但没有情绪卡提供 PAD 驱动力。行为缺乏情绪推力。

### 6.3 效果

```
1. 认知卡正常执行卡面效果，且效果 × 1.3
   - 理由：没有情绪干扰 → 认知更冷静精准

2. 行为卡正常执行，但 cost_modifier 取以下两者中较高的值：
   - 正常计算的 cost_modifier（基于当前 α_i）
   - 1 + β_i × (1 - 0.3)（相当于 α_i 上限被压到 0.3）
   - 例外：文化习俗驱动不适用此压制（不依赖 PAD）
   - 例外：照护驱动不适用此压制（读他人 PAD，非自身情绪状态）

3. 意志力回复：+1
   - 同一回合内第二次执行：意志力回复 +0
   - 同一回合内第三次及以后：无意志力回复
   - 理由：第一次冷静执行回收精神能量；连续冷酷行为的边际效益递减

4. 本回合 PAD 偏移减半
   - 没有情绪卡提供主动 PAD 偏移
   - 回合间 PAD 自然衰减照常
```

### 6.4 行为卡成本表（情绪缺失的影响）

| 驱动 | 正常 cost_modifier | 执行中 cost_modifier | 说明 |
|------|-------------------|---------------------|------|
| 反射 | 1 + 0.5·(1-α) | 1 + 0.5·(1-min(α,0.3)) | α 被压制 → 成本可能略高 |
| 惩罚机制 | 1 + 1.0·(1-α) | 1 + 1.0·(1-min(α,0.3)) | α 被压到 0.3 → 最低 cost = 1.7 |
| 奖励机制 | 1 + 1.2·(1-α) | 1 + 1.2·(1-min(α,0.3)) | α 被压到 0.3 → 最低 cost = 1.84 |
| 道德驱动 | 1 + 0.8·(1-α) | 1 + 0.8·(1-min(α,0.3)) | α 被压到 0.3 → 最低 cost = 1.56 |
| 文化习俗 | 1 + 0.3·(1-α) | **不压制** | 社会脚本不需要情绪推动 |
| 价值驱动 | 1 + 1.5·(1-α) | 1 + 1.5·(1-min(α,0.3)) | 最贵——无情绪推力的信念坚守 |
| 照护 | 1 + 0.6·(1-α) | **不压制** | 读他人 PAD，不依赖自身情绪 |

### 6.5 意志力回复的边际递减

```
同回合内：
  第 1 次执行打出: 意志力 +1  ← "我在冷静做事"
  第 2 次执行打出: 意志力 +0  ← "惯性"
  第 3 次及以后:   意志力 +0  ← "麻木了"
```

### 6.6 设计意图

- **意志力回收引擎**：战斗中的意志力恢复途径
- **精准控制选项**：适合需要精确认知效果但不想被情绪干扰的回合
- **代价**：行为卡成本偏高（缺少情绪推力），放弃了 PAD 爆发
- **叙事**：你知道该做什么，你去做——不带感情。效率更高但更费力

## 七、多组打出与时序

### 7.1 一回合内打出限制

| 限制维度 | 规则 |
|---------|------|
| 完整态度 | 每回合最多 1 次 |
| 两类组合 | 不限次数 |
| AP | 行为卡 AP 消耗照常从当前 AP 池扣除，AP 不足时无法打出含行为卡的组合 |
| 手牌 | 自然手牌数量为唯一瓶颈 |
| 意志力 | 硬解锁成本照常消耗意志力，不足时行为卡灰色 |

### 7.2 组合间结算顺序

- 每个组合确认后**立即结算**（不等待回合结束）
- 结算顺序 = 玩家打出的顺序
- 前一组组合的结算结果（PAD 偏移、产生的情绪卡、意志力回复）**立刻生效**，影响后续组合的选择

### 7.3 时序示例

```
回合开始:
  手牌: [洞见, 恐惧, 逃跑, 凝神, 面对]
  AP: 4, 意志力: 2, PAD: (0, 0, 0)

玩家操作:
  1. 拖入 [洞见, 恐惧] → 检测到"酝酿"
     → 预览确认 → 打出
     → 结算: PAD → (-0.2, +0.17, -0.1), 产 1 张"焦虑"加入手牌
     → AP 剩余: 4（酝酿 0 AP）
     → 出牌区清空 → 洞见回牌库, 恐惧消耗

  2. 拖入 [凝神, 焦虑, 面对] → 检测到"完整态度"
     → 预览确认 → 打出
     → 结算: 完整态度效果
     → AP 剩余: 1（面对 AP 3）
     → 出牌区清空 → 凝神,面对回牌库, 焦虑消耗

  3. AP 剩余 1，手牌仅剩 [逃跑]（行为卡 反射 AP 1）
     → 单张行为卡无法形成组合
     → 回合结束

回合结束:
  手牌: 补充抽牌
  PAD: 残留（衰减后）
  意志力: 根据本回合消耗更新
```

## 八、强制规则（恐慌/暴走）

### 8.1 恐慌强制（g_reflex > 0.85）

当反射驱动激活度超过恐慌阈值时：

- 出牌区交互不变，但系统额外高亮/脉冲手牌中的反射行为卡
- 如果玩家尝试确认打出不含反射行为卡的组合 → 警告提示"恐慌状态下必须打出反射行为卡"
- 玩家可花 3 意志力压制此强制（将 g_reflex 临时压至 0.8，允许不打反射卡）
- 如果玩家不选任何卡直接结束回合 → "僵住"自动打出（反射行为卡，基础 AP 0，效果：跳过回合）

### 8.2 暴走强制（|PAD_curr| > 1.0）

当任意 PAD 维度超出 ±1 时：

- 本回合剩余所有含行为卡的组合，行为方向被强制为 B_raw 方向
- 玩家仍可打出酝酿（无行为卡，不受影响）
- 暴走持续至回合结束
- 狂暴后 3 回合萎靡：
  - κ_eff × 0.3（情绪卡 PAD 偏移大幅降低）
  - |A| 被压低 0.3（唤醒度被抑制）
  - 意志力回复效果减半

## 九、敌方 AI 组合策略

### 9.1 AI 类型

敌方 AI 分为两种基础类型：

#### 激进型

- **偏好**：冲动（情绪+行为）> 完整态度 > 执行（认知+行为）> 酝酿（认知+情绪）
- **特征**：频繁使用冲动组合进行快攻，追求短期爆发
- **触发模式**：
  - 手牌满足冲动条件 → 优先打出冲动
  - 手牌满足完整态度条件 + AP 充足 → 打出完整态度
  - 意志力低时 → 较少使用冲动（避免冲动惩罚）

#### 保守型

- **偏好**：酝酿（认知+情绪）> 完整态度 > 执行（认知+行为）> 冲动（情绪+行为）
- **特征**：偏好攒资源和精准控制，早期回合酝酿攒情绪卡，后期完整态度爆发
- **触发模式**：
  - 手牌满足酝酿条件 → 优先酝酿（攒情绪卡）
  - 手牌满足完整态度条件 + 情绪卡储备 ≥2 → 打出完整态度
  - 优先使用执行回收意志力

### 9.2 状态切换条件

| 原类型 | 切换条件 | 切换为 |
|--------|---------|--------|

### 9.3 敌我同构

- 敌人使用与玩家完全相同的组合规则
- 敌人受到相同的 AP/意志力约束
- 敌人的卡牌去路规则与玩家一致（情绪卡消耗、认知/行为回库）
- 敌人的组合偏好由其 AI 类型决定，而非独立规则

### 11.5 态度碰撞公式（B(t) 三轴）

```
va, ia, aa = B(t)_A  (valence, intensity, autonomy)
vb, ib, ab = B(t)_B

同向共振: sign(va)==sign(vb) 且 |va-vb|<0.3 → 双方回复 SAN
方向冲突: damage_to_B = (ia+ib) × (1+|va-vb|) × (1+max(0,aa-ab)) × 2.5
           damage_to_A = (ia+ib) × (1+|va-vb|) × (1+max(0,ab-aa)) × 2.5
```
