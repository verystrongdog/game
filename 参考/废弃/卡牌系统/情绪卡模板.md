# 情绪卡模板

> **⚠️ 已废弃**：情绪卡不再作为玩家交互手段。情绪技能设计见 [技能树系统/情绪技能设计](../../../%E8%A7%84%E5%88%99/%E6%8A%80%E8%83%BD%E6%A0%91%E7%B3%BB%E7%BB%9F/%E5%B7%B2%E5%BA%9F%E5%BC%83/%E6%83%85%E7%BB%AA%E6%8A%80%E8%83%BD%E8%AE%BE%E8%AE%A1.md)。15 张情绪卡的 PAD 坐标和效果已映射为情绪技能节点。本文档保留供设计参考。

> 情绪卡的设计规格书。每张情绪卡锚定 15 种情绪之一，打出时产生 PAD 爆发，留在手牌产生轻度压力，战末残留影响角色倾向。情绪卡为暂时性卡牌（战终消失），不消耗 AP，来源多样（态度产/组合产/环境产/NPC 塞）。

## 一、字段规范

### 静态字段（卡面，永远不变）

| 字段 | 类型 | 说明 |
|------|------|------|
| `卡名` | string | 情绪名称，2 字（恐惧/愤怒/内疚/焦虑/悲痛/共情/快乐/爱/厌恶/敬畏/恐怖/绝望/希望/平静/孤独） |
| `锚点情绪ID` | string | emotions.json 中的 id 字段：fear/anger/guilt/anxiety/sorrow/empathy/joy/love/disgust/awe/terror/despair/hope/calm/loneliness |
| `PAD` | object | `{V, A, D}`，来自 `data/emotions.json`，精确到 3 位小数 |
| `类别` | enum | 情绪 |
| `AP消耗` | int | 固定 0（情绪卡不消耗 AP） |
| `标签` | list | 固定含 "暂时性卡牌（战终消失）" |

### 打出效果（PAD 爆发）

| 字段 | 类型 | 说明 |
|------|------|------|
| `打出PAD偏移` | object | `{ΔV, ΔA, ΔD}`，打出时 PAD 瞬时偏移量。`PAD_curr += κ_eff × (PAD_card - PAD_curr)`，κ_base = 0.30 |
| `打出描述` | string | flavor text，"强烈恐惧爆发" / "怒火喷涌" 等 |
| `行为推力方向` | string | 来自 emotion.behavior_thrust.direction：approach / avoid / approach_threat / slight_approach / neutral |

### 留在手牌效果（轻度压力）

| 字段 | 类型 | 说明 |
|------|------|------|
| `手牌压力PAD` | object | `{ΔV, ΔA, ΔD}`，每回合末在手牌中产生的轻度 PAD 偏移（远小于打出偏移） |
| `手牌压力描述` | string | flavor text，"轻度恐惧压力" / "隐隐不安" 等 |
| `压力累积` | enum | 是否随回合累积（大多数情绪累积，共情传递内容不累积自身） |
| `压力上限` | int | 最大累积回合数，超出后自动触发 mini 爆发或转化为心境偏移 |

### 战末残留效果

| 字段 | 类型 | 说明 |
|------|------|------|
| `残留倾向` | string | 战斗结束后对角色面板的长期影响，如 "惊觉倾向 ↑" / "控制感 ↑" / "愉悦基线 ↑" |
| `残留量` | float | 残留偏移量（小值，0.01-0.05），多次战斗累积 |
| `残留方向` | enum | positive / negative / neutral — 对角色长期有益/有害/中性 |

### 获得条件

| 字段 | 类型 | 说明 |
|------|------|------|
| `获得方式` | list | 态度产 / 两类组合产 / 环境产 / NPC 塞 / 初始牌库（每项可独立启用） |
| `自然触发` | string | 什么情况下自动塞入手牌（如 "角色认知到危险时" / "角色遭受不公时"） |
| `塞入数量` | string | 塞入张数公式或范围（如 "取决于恐慌程度" / "1-2 张"） |
| `获得难度` | enum | common / uncommon / rare — 游戏平衡用 |

### 联动字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `自然激活驱动` | list | 此情绪下哪些驱动自然激活（来自 emotions.json 的 activates_drives） |
| `强化行为卡` | list | 与此情绪 combo 打出时获得加成的行为卡类型 |
| `冲突行为卡` | list | 与此情绪冲突的行为卡类型（硬解锁 C_control 更高） |
| `传递情绪` | list | 仅共情：可通过共情传递的情绪列表 |
| `心境耦合` | enum | 是否与心境系统耦合（大多数是，共情特殊——传递的是被共情情绪） |

## 二、填写示例

### 示例：恐惧

```yaml
卡名: 恐惧
锚点情绪ID: fear
PAD: {V: -0.854, A: 0.680, D: -0.414}
类别: 情绪
AP消耗: 0
标签: [被动获得, 暂时性卡牌（战终消失）]

# 打出效果
打出PAD偏移: {ΔV: -0.25, ΔA: +0.20, ΔD: -0.12}    # κ_eff ≈ 0.30 × PAD_card
打出描述: "强烈恐惧爆发——心跳骤停，世界收窄为一条逃生通道。"
行为推力方向: avoid  # 高回避 + 高强度 + 被动

# 留在手牌
手牌压力PAD: {ΔV: -0.05, ΔA: +0.04, ΔD: -0.02}     # 约为打出偏移的 1/5
手牌压力描述: "轻度恐惧压力——你总觉得有什么在暗处。"
压力累积: 是
压力上限: 5  # 5 回合后自动触发 mini 爆发

# 战末残留
残留倾向: "惊觉倾向 ↑"
残留量: 0.02   # 每次战斗残留约 +0.02 到 Arousal 基线
残留方向: negative  # 长期抬高 Arousal 基线可能导致过度警觉

# 获得条件
获得方式: [态度产, NPC 塞, 环境产]
自然触发: "角色认知到危险时自动塞入手牌（CPM Step 1 Novelty 检测到威胁信号）"
塞入数量: "1 + floor(恐慌程度 / 3)，恐慌程度 = 威胁强度 × (1 - D_current)"
获得难度: common

# 联动
自然激活驱动: [反射, 惩罚机制]
强化行为卡: [逃跑, 僵住, 闪避, 回避]
冲突行为卡: [追求, 坚持, 牺牲, 突破]  # 恐惧 + 价值 C=3.8
传递情绪: []  # 非共情情绪
心境耦合: 是

# 设计备忘
设计备忘: >
  恐惧卡的价值在于它在正确时机被"转化"而非单纯打出。
  拥有恐惧卡的人不一定输——知道如何面对恐惧的人可能反败为胜。
  考虑后续配合认知卡来重新解释恐惧（如用"正名"将恐惧转为行动力）。
  恐惧 + 愤怒 D 轴互相抵消 → 行为"对峙"（想逃又想打，僵住了）。
```

### 4.2 自然激活驱动 + 特殊说明

| 情绪 | 自然激活驱动 | 特殊说明 |
|------|------------|---------|
| 快乐 | 奖励机制, 道德驱动 | 注意拓宽、风险低估 |
| 爱 | 奖励机制, 价值驱动, 照护 | 唯一可主动选择对自身不利选项的正向情绪 |
| 共情 | （无直接激活） | 推力接近零——传递的是被共情情绪的方向 |
| 平静 | （无强激活） | 治疗目标象限——最低唤醒安宁 |
| 希望 | 奖励机制, 价值驱动 | 低唤醒 + 高控制——"知道会好起来" |
| 敬畏 | 反射 | 稀有区（NRC 仅 26 词）——顿悟/超越体验 |
| 愤怒 | 惩罚机制, 奖励机制, 道德驱动 | **唯一主动靠近威胁源的情绪**（P<0 但 D>0） |
| 恐惧 | 反射, 惩罚机制 | 人类最古老的情绪——杏仁核-PAG 短路通道 |
| 焦虑 | 惩罚机制 | "对未来的恐惧"——A≈恐惧但 D 稍高 |
| 厌恶 | 惩罚机制, 文化习俗 | 要清除而非避开——"你不该存在" |
| 恐怖 | 反射, 惩罚机制 | 见证不可名状——D 轴高于恐惧（-0.124 vs -0.414） |
| 绝望 | 惩罚机制 | 认知闭合——"没有出路"，D 轴最低（-0.510） |
| 内疚 | 道德驱动 | 道德情绪——内疚耦合直接短路激活道德驱动 |
| 悲痛 | （行为冻结） | 所有驱动激活不足→"动不了" |
| 孤独 | （无强激活） | 区别于悲痛（丧失 vs 隔离） |

### 4.3 PAD 距离参考（情绪相似度）

```
距离公式: dist(E1, E2) = sqrt((V1-V2)² + (A1-A2)² + (D1-D2)²)

情绪对             距离    说明
恐惧 ↔ 焦虑        0.18    最近邻居——都是 -P+A-D，焦虑 D 稍高
恐惧 ↔ 恐怖        0.30    相近——恐怖 D 更高（见证不可名状）
恐惧 ↔ 愤怒        1.14    隔得远——D 轴一正一负
悲痛 ↔ 孤独        0.44    相近——都是 -P-A-D
恐惧 ↔ 悲痛        1.17    隔得远——A 轴一高一低
```

## 五、PAD 偏移与残留计算

### 5.1 打出偏移公式

```
PAD_curr += κ_eff × (PAD_card - PAD_curr)

κ_eff = κ_base × repetition_factor
κ_base = 0.30
repetition_factor = 1 / (1 + 0.5 × ln(n + 1))  # n = 本场已打出同情绪卡次数
```

### 5.2 回合间衰减（向心境回归）

```
δ = 0.20 + 0.15 × |A_current| - 0.10 × D_current
PAD_curr = PAD_curr + δ × (PAD_mood - PAD_curr)
```

### 5.3 暴走机制

```
条件: |PAD_curr| > 1.0（任一维度超出 ±1）
触发: 本回合行为强制为该情绪的 B_raw 方向
后果: 宣泄后 3 回合萎靡（κ_eff × 0.3, |A| 被压低 0.3）
```

### 5.4 战末残留

```
PAD_mood += λ_residual × (PAD_curr_end - PAD_mood)
λ_residual = 残留量（0.01-0.05，取决于情绪类型和本场强度）
```

## 六、获得条件分类

| 来源 | 说明 | 示例 |
|------|------|------|
| 态度产 | 打出完整态度（认知+情绪+行为）后，根据态度效果产生新情绪卡 | 态度"逆流而上"→ 产 1 张 希望 |
| 两类组合产 | 打出两类组合（认知+情绪 → 酝酿，情绪+行为 → 冲动，认知+行为 → 执行）后产情绪卡 | 详见 [卡牌组合逻辑](./卡牌组合逻辑.md) |
| 环境产 | 场景/事件自动触发 | 黑暗房间 → 恐惧；治疗室 → 平静 |
| NPC 塞 | 敌方/友方 NPC 将情绪卡强行塞入玩家手牌 | 敌人使用"恐惧光环"→ 玩家手牌 +1 恐惧 |
| 初始牌库 | 战斗开始时手牌中的情绪卡 | 角色被动决定初始情绪配置 |
| 共情传递 | 通过共情接收到他人的情绪 → 转化为对应情绪卡 | 队友受伤 → 共情传递痛苦 → +1 悲痛 |

## 七、设计约束清单

填写情绪卡时必须检查以下约束：

- [ ] PAD 坐标是否严格来自 `data/emotions.json`？（不能手写坐标）
- [ ] 打出 PAD 偏移量是否合理？（Δ 值通常不超过 ±0.3，κ_base=0.30）
- [ ] 手牌压力 PAD 是否约为打出偏移的 1/5？
- [ ] 残留量是否在 0.01-0.05 范围内？
- [ ] 自然激活驱动是否与 emotions.json 的 activates_drives 一致？
- [ ] 行为推力方向是否与 emotion.behavior_thrust.direction 一致？
- [ ] 获得方式是否至少填了一种？
- [ ] 共情（empathy）的情绪卡是否特殊处理了"传递"机制？
- [ ] 冲突行为卡是否与 C_control 速查表（行为卡模板 §五）的高值区域一致？
- [ ] 是否与已有图鉴条目重复？（当前仅 恐惧 一张已登记）
