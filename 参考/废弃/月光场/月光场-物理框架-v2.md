## 一、物理目标

### 我们不是在追求

- 阻止环境退相干
- 让宏观物体处于位置叠加态
- 让椅子同时出现在两个房间

### 我们在追求

**物质因为人的主观意愿发生改变。**

物理翻译：环境仍然在退相干系统。叠加态照常死亡。但**死在哪一边——往哪个经典态坍缩——可以被观察者的认知状态偏转。**

### 为什么这个方向避免了一个致命硬伤

旧方向（方案 C：DFS + 集体退相干 + Zeno 抑制）试图阻止退相干——需要在所有环境通道上压制标记。宏观物体的位置退相干速率 ~10²⁰ Hz，环境相干长度 ~10⁻⁵ m——任何已知物理机制在这些数量级下都无法成立。

新方向：退相干照常生效，不做压制。只做一件事——**修改环境选出来的指针基是哪一个。** 这是 Kofman & Kurizki (2022) 提供的理论入口。

## 二、理论骨架 1：退相干不唯一确定指针基

### 2.1 标准图景（Zurek einselection）

```
系统 ──H_SM──→ 仪器 ──H_MB──→ 环境
                 ↑                  ↑
            P（仪器指针基）    Q（环境锁定指针基）
```

环境通过连续监控仪器 → 仪器的某些态存活、其余退相干 → **Q** 被确定为仪器-环境相互作用的稳定基（= pointer states）→ 系统被"强制"进入 Q 的本征态之一 → 经典现实涌现。

标准图景隐含假设：**Q 是唯一的。** 环境无歧义地选出一个指针基。

### 2.2 Kofman & Kurizki (2022) 的修正

**如果允许广义测量（POVM 而非仅投影测量），Q 不是唯一的。**

| 基底 | 符号 | 来源 | 是否唯一 |
|------|------|------|---------|
| 仪器指针基 | P | 系统-仪器相互作用 H_SM | 是 |
| 环境锁定基 | Q | 仪器-环境退相干 H_MB | **否。存在多个替代 Q，都提供相同的被测可观测量信息** |
| 观察者米尺基 | R | 观察者可以任意选择——不受环境约束 | 否 |

**核心结论**：退相干确定了"哪些信息被保留"（被测可观测量），但**不唯一确定"信息以什么基底被编码"**（指针基）。替代 Q 的存在是 POVM 数学的必然——不需要外部场。

但**哪个替代 Q 被实际使用**——论文留给"观察者的选择"。

### 2.3 月光场在公式中的位置

月光场把"观察者的选择"从自由意志变为物理过程：**场的 H_field 耦合到观察者的认知状态 → 自动将观察者路由到其认知态对应的替代 Q → 不同观察者被路由到不同的 Q → 不同版本的现实。**

```
正常世界：
  H_SM → P → H_MB → 唯一 Q → 所有观察者共享同一客观现实

月光场中：
  H_SM → P → H_MB + H_field(ρ_O^(obs)) → 替代 Q 流形
  → 不同 ρ_O^(obs) → 不同的有效 Q → 不同的坍缩结果
  → 不同版本现实同时为真
```

## 三、物理层：月光场 = 标量场 φ(x) 耦合到局部相干性

### 3.1 什么是月光场——物理定义

月光场是一个**标量场 φ(x)**。x 是三维空间中的位置。φ(x) 在空间中有值、有梯度、有动力学——它是一个真实的物理场，和 Higgs 场一样的数学类型，但耦合到不同的物理量。

### 3.2 它耦合到什么

正常世界的物质-环境相互作用 H_int 是一切退相干的来源——环境通过这些通道"问询"系统。

月光场引入一个**额外的相互作用项**：

```
H_field = g_0 · φ(x) · Ô_coherence(ρ(x))
```

- **φ(x)**：标量场在位置 x 的值——场的"强度"
- **ρ(x)**：位置 x 处局部物质的约化密度矩阵——积掉微观自由度后的宏观有效态
- **Ô_coherence(ρ)**：一个作用于 ρ 的算符——提取 ρ 在环境指针基 Q⁰ 下的**非对角元**——即 ρ 的量子相干性
- **g_0**：基础耦合常数——由零号病人初始场激发时锁定

### 3.3 它做什么

H_field 不阻止 H_int 造成的退相干。退相干照常发生。

H_field 做的是：**修改退相干后存活的经典态。** 正常世界 —— H_int 单独作用 → 退相干后 → 环境选定位置本征态（"椅子在 A"）。场存在时 —— H_int + H_field 联合作用 → 退相干后 → 环境选定的是"位置 + 相干偏转"的混合本征态。

**"指针基偏转"是这个物理过程的 einselection 语言翻译。** 物理本身不需要"指针基"这个概念——只有 H_int + H_field 的联合本征结构。只是恰好，这个结构在 einselection 框架下被解释为"Q 不唯一"——但那个是解释层。物理层只有场、耦合、本征态。

### 3.4 场的空间结构

标量场 φ(x) 在三维空间中的值由两个因素决定：

1. **源项**：每个耦合观察者贡献 g_0 × C(ρ_O) 的"场荷"——产生 φ
2. **衰减**：Yukawa 衰减 e^(−r/R)/r——R = 场相干半径（§十）

```
φ(x) = Σ_i η_i × e^(−|x − x_i|/R) / |x − x_i|
```

其中 η_i = g_0 × C(ρ_O^(i)) / C_max，x_i = 观察者 i 的位置。

**φ(x) 大 → 该位置场强 → H_field 效应强 → 偏转强。**
**φ(x) ≈ 0 → 该位置场弱 → H_field 效应弱 → 接近正常世界。**

### 3.5 "指针基"的语言还保留吗

保留——但只作为翻译层。在 Kofman & Kurizki 的框架下：

- Q⁰ = H_int 单独作用时的指针基 = 位置基（环境问"你在哪"）
- Q^α = H_int + H_field 联合作用时的指针基 = 位置 + 相干偏转
- Q^α 偏离 Q⁰ 的角度 = f(η, ρ_O)

但在底层物理上，没有"Q^α 被选中"——只有联合哈密顿量的本征态。我们说"指针基偏转"是为了用 einselection 的词汇来沟通——物理本身更直接：**场改变了系统-环境的有效相互作用，导致退相干后存活的经典态不同。**

## 四、理论骨架：量子相干性 = 认知结构度

### 4.1 Baumgratz, Cramer, Plenio (2014) — 量子相干性资源理论

> 物理背景：在微观领域，粒子在"被观测时不干涉及弹坑状"，与未被观测时干涉的波粒二象性，体现了观察者效应——观测在物理上编码了路径信息，信息的存在改变了系统的行为模式。宏观物质被环境持续"观测"（~10²³ 次分子碰撞/秒），物质波属性被永久禁锢。**月光场不打开这个禁锢——它改变禁锢的方向。**

在给定的参考基 {|i⟩}（即 Q 基——环境锁定的指针基）下：

- **非相干态**：ρ 在 Q 基下是对角的 → ρ = Σ p_i |i⟩⟨i|。纯经典概率分布。没有量子相干性。**等价于环境随机噪声。**
- **相干态**：ρ 有非对角元 → ρ_ij ≠ 0 for i≠j。非对角元 = 量子相干性 = **结构**。

### 4.2 相干性度量

**相对熵相干性**（满足全部资源论公理）：

```
C_r(ρ) = S(ρ_diag) − S(ρ)
```

- S = von Neumann 熵
- ρ_diag = ρ 在 Q 基下只保留对角元的态（完全去相干操作 Δ(ρ)）
- 物理含义：态偏离"被退相干杀死后剩的经典分布"的信息量
- 有明确的操作解释（渐近相干性蒸馏率）

**ℓ₁-范数相干性**（直接可计算）：

```
C_ℓ₁(ρ) = Σ_{i≠j} |ρ_ij|
```

- 所有非对角元绝对值之和
- 物理含义：干涉条纹可见度的总和
- 不需要本征分解——矩阵元素的直接求和

**相干性鲁棒性**（Napoli et al. 2016）——操作上可实验观测。

### 4.3 映射：相干性 → 认知结构度 → 场耦合强度

| ρ_O 的类型 | ρ_O 在 Q 基下的形式 | C_r(ρ_O) | 认知结构度 | 场耦合 ξ |
|-----------|-------------------|----------|-----------|---------|
| 环境随机噪声（光子/分子散射） | 对角——ρ_diag = ρ → C_r = 0 | 0 | 无结构 | ξ = 0 |
| 正常人（SAN 高，灵活） | 部分非对角——中等相干 | 中等 | 中等 | ξ 弱 |
| 精神病人（SAN 低，固化） | 高度非对角——少数元素主导 | 高 | 高 | ξ 强 |
| 纯态信念（零号病人） | 秩-1 → C_r = log(d) | 理论最大 | 最大 | ξ = ξ_max |

**"结构化认知"的操作定义**：C(ρ_O) > 0（在 Q 基下有非对角元）。
**"随机标记"的操作定义**：C(ρ_O) = 0（在 Q 基下对角——等价于经典概率分布）。

## 五、场如何介入

### 5.1 有效指针基

场的存在修改了仪器-环境的有效相互作用：

```
H_MB^eff = H_MB + η · H_field
```

其中 H_field 的耦合强度由观察者态的相干性决定：

```
η = g_0 × C(ρ_O) / C_max
```

- **g_0**：场的基础耦合常数（由零号病人的初始场锁定）
- **C(ρ_O)**：观察者在 Q 基下的量子相干性
- **C_max** = log(d)：d 维希尔伯特空间中理论最大相干性

### 5.2 ρ_O 和认知空间维度 d

ρ_O 的维度 d 是**认知系统在指针基 Q 下可区分的宏观认知状态数**。

**d 不是固有属性——由两个因素共同决定**：

1. **基础维度 d_0**：认知系统固有的宏观状态数——由系统复杂度决定。人脑 ~10³-10⁴ 个可区分的宏观认知态，高等动物 ~10²，思维造物取决于创建者的精神状态。
2. **有效维度 d_eff**：d_0 在场中被 Q 投影后的可用维度。如果 Q 和认知系统的内部基对齐 → d_eff ≈ d_0。如果 Q 和内部基错位 → d_eff < d_0——只有 Q 能分辨的那些态参与场耦合。

```
正常世界（无月光场）：Q = Q⁰（环境唯一指针基——位置基）
  → 认知内部基和 Q⁰ 有大量重叠（人脑被环境训练）
  → d_eff 大 → C(ρ_O) 分散在很大空间 → 耦合被稀释 → 弱偏转

月光场中：Q 被场偏转 → 和认知内部基的特定子空间高度对齐
  → d_eff 集中在执念/信念相关的子空间
  → C(ρ_O) 集中 → 耦合放大 → 强偏转
```

**d_0 是游戏层参数**：不同实体类型（正常人/病人/思维造物/动物/拜月教徒）分配不同的 d_0 值。d_eff 是运行态——由场的 Q 偏转动态决定。

**基底独立原则**：d_0 不绑定于人脑解剖——任何认知系统都有宏观状态数。

### 5.3 偏转机制——η = 环境监控基的粗粒化程度

旧理解：η 偏转指针基的"角度"——Q⁰ 旋转到 Q^α。

**修正（2026-08-04）**：物理构型空间 H_pos 是无限维的（连续密度场 ρ(x)）。语义内容 = 这个无限维空间中的密度场模式。但观察者的认知系统只有有限的分辨率——人脑将无限维的 H_pos 压缩到 d 个可区分的粗粒化等价类。ρ_O 的基矢 |i⟩ 就是这 d 个等价类：

```
|1⟩ = "走廊空无一人"     ← 无穷多微观构型的等价类
|2⟩ = "走廊有迫害者"     ← 另一个等价类
|3⟩ = "墙上出现文字"     ← 又一个
...
|d⟩ = …                  ← 观察者认知可分辨的全部世界构型
```

η 不添加新的空间维度。η 控制**环境监控基的精细度**：

```
正常世界（η = 0）：
  环境监控基 = {|x⟩} —— 所有微观位置构型完全分辨
  → 每个粒子独立被锁定 → 宏观叠加完全禁止
  → 迫害者构型和空走廊构型之间的差异不被环境"看见"——因为环境在比这更细的粒度上操作

月光场中（η > 0）：
  环境监控基 = {|x⟩} 和 ρ_O 等价类的混合
  → 环境开始分辨粗粒化的等价类之间的差异
  → |迫害者⟩ 和 |无迫害者⟩ 开始变得可区分
  → η = 语义等价类在环境监控中的权重
```

**η 是一个分辨率调节器——从微观粒子粒度拉向宏观认知粒度。**

## 六、形式化模型

### 6.1 符号定义

| 符号 | 含义 | 定义来源 |
|------|------|---------|
| Q⁰ | 无场时环境锁定的基——基矢 = \|x⟩ 纯位置构型。作用在 H_pos 上 | H_MB 的本征基 |
| H_semantic | 语义自由度空间——基矢 = \|x, s⟩ 位置 + 语义联合标记 | 本模型 |
| η | **语义维度在环境退相干中的参与权重**——不是偏转角度 | η = g_0 × C(ρ_O) / log(d) |
| ρ_O | 观察者的认知密度矩阵（d × d） | 观察者内在状态的量子描述 |
| C(ρ_O) | ρ_O 在 Q⁰ 下的量子相干性（BCP 框架） | Baumgratz et al. (2014) |
| g_0 | 场的本征耦合常数 ≈ 0.9，无量纲 | 零号病人激发时锁定 |
| d | d_0 × Q 投影效率。d_0 = 认知系统宏观状态数 | §5.2 |
| R | 场相干半径（空间范围） | §十（月光场主文档） |

### 6.2 核心公式

**耦合强度（= 语义维度激活权重 = 坍缩强度）**：

```
η = g_0 × C(ρ_O) / log(d)

0 ≤ η ≤ g_0 ≈ 0.9
```

**坍缩方向**：

```
direction = 主导语义标签(ρ_off)

ρ_off = ρ_O − Δ(ρ_O)           ← 非对角部分
主导对 = argmax_{i≠j} |ρ_ij|   ← 最强认知张力轴
语义标签 = map(主导对)          ← 映射到语义内容（威胁/自责/神明/...）
```

**物理含义**：

```
η = 0（环境噪声/正常认知）：H_MB 只作用在 H_pos → 语义自由度不被环境监控 → 纯客观现实
η > 0（结构化认知）：H_MB + H_field 作用在 H_pos ⊗ H_semantic → 语义内容被环境锁定 → 思维影响现实
η → g_0（零号病人）：语义维度的退相干权重最大化 → 几乎完全的替代现实
```

**场总效应**（空间叠加）：

```
Φ(location) = Σ_i η_i × e^(−r_i/R) / r_i

η_i = 观察者 i 的语义维度激活权重
r_i = 观察者 i 到场中某点的距离
R = 场相干半径（Yukawa 衰减长度）
```

### 6.3 回桥到游戏层

物理模型（C(ρ_O)、d_0、ρ_off 方向）和游戏架构（SAN、tone baseline + CSTC bias（7参数化性格）、三体模型连接权重、疾病）之间的映射：

```
C(ρ_O) = C_baseline(SAN) × κ_structure(标签, 疾病)

  C_baseline(SAN):
    SAN ≥ 60：0.1-0.5 nats（灵活）
    SAN 30-60：0.5-2.0 nats（开始固化）
    SAN < 30：2.0-5.0 nats（严重固化）
    SAN = 0：C_max = log(d_0)

  κ_structure：概念标签集中度 × 疾病固化度
    标签均衡 → 多重非对角元 → κ ≈ 1
    单一概念标签极度偏移 + 疾病 → 非对角元集中 → κ > 1

ρ_off 主导方向 = 概念标签偏移方向（6维语义方向，底层 = 4 tone baseline + 3 CSTC bias）× 疾病链路 m 分布模式
  敏化-威胁 ↑ → "威胁"语义权重 +
  过度抑制 ↑ → "自否定"语义权重 +
  反刍 ↑ → "过去创伤"语义权重 +
  疾病 → 具体语义内容锚定（偏执型→迫害；抑郁→无价值；PTSD→重演）

d_0 ← 实体类型表（§5.2 已锚定）
```

## 八、随机标记 vs 结构化凝视——操作定义

### 老问题

### 新定义

在相干性框架中，这个区分有了直接的操作定义：

```python
def collapse_strength(state_rho, field_g0, Q_basis):
    """坍缩强度 = 态在指针基下的量子相干性 × 场耦合常数"""
    C = relative_entropy_coherence(state_rho, Q_basis)
    d = state_rho.shape[0]
    return field_g0 * C / log(d)

# 环境随机噪声
random_noise = max_mixed_state(d)  # ρ = I/d, 对角
assert collapse_strength(random_noise, g0, Q) == 0  # 不坍缩——被擦除
```
