# 被枪毙的想法

这里放置曾经探索过但最终被放弃的设计方向。保留下来作为参考，避免重复踩坑。

---

## 颜色系统（已放弃）

### 放弃原因

card.md 中的结论：
> "我觉得不好实现，因为如果给卡牌赋予过多的颜色会让游戏显得过于臃肿（但是使用原色解决的话，就可以使用少量的颜色构建出丰富的效果）"

最终判定：即使走原色路线，颜色系统仍然与新的超自然观察者效应世界观不兼容。态度计算改用三维向量模型 (+1/0/-1)。

### 十六进制颜色表

```text
#FFFFFF  纯白   癫狂
#000000  纯黑   本色 / 空洞 / 冻结候选
#0000FF  纯蓝
#0055AA  深青色
#00AA55  青绿色
#00FF00  纯绿
#5500AA  蓝紫色
#555555  中灰色
#55AA00  黄绿色
#AA0055  紫红色
#AA5500  橙黄色
#FF0000  纯红   欢欣
#550000  深红   积极
#005500  深绿   中性
#000055  深蓝   消极
```

### 颜色设计方向

- 不直接把"积极 / 消极 / 平和"当最终情绪，而是把它们当底层倾向
- 考虑把三原色绑定为更底层的心理过程，而不是结果标签
- 目标是用少量基础颜色生成丰富但可理解的情绪组合

### 精神条（已放弃）

- 精神条拥有三个空位
- 空位被不同颜色染色后，触发对应情绪效果
- 精神条是游戏的核心机制
- 待明确问题：
  - 颜色叠加发生在什么层级
  - 颜色如何映射为情绪
  - 数值和颜色如何共同决定状态强度

### 颜色承载体讨论

- 卡牌本身已经有颜色需求，若再叠加复杂颜色，可能导致信息过载
- 如果让整屏变色，表现会太花哨
- 如果只让角色变色，沉浸感可能不足
- 需要决定颜色变化的承载体：
  - 精神条本身
  - 角色外观特效
  - UI 边缘反馈
  - 卡牌结算动画

### 颜色与情绪触发（已放弃）

- "纯红色 = 欢欣"：行动卡拥有双倍效果
- "灰色 = 惘然"：将手牌洗回抽牌堆并重抽相同数量
- "蓝色 = 忧郁"：待补充
- "深红 = 积极" / "深绿 = 中性" / "深蓝 = 消极"

### 颜色在态度结算中的角色（已放弃）

旧版设计中，认知/情绪/行为三类卡牌都各自带有三种基础颜色，最终态度先视作一种"颜色结构"而不是一句完整台词。

角色能力中也大量依赖颜色：
- 医生：在态度结算时可以将行为卡转变为任意颜色
- 躁狂症：在态度结算时可以将任意态度卡转变为红色
- 抑郁症：在态度结算时可以将任意态度卡转变为蓝色

这些能力在新的向量模型下需要用 +1/0/-1 来重新表述。

### 颜色相关待解决问题（随颜色系统一同放弃）

- 如何通过精神条的数值与颜色表达不同情绪
- 三种纯色态度卡最终组合出的态度是否一定为正面态度
- 颜色如何"染"到认知 / 情绪 / 行为或最终态度上

## 治疗模拟框架（已放弃）

### 放弃原因

旧版世界观中，战斗场景被解释为治疗中心搭建或诱发的"治疗方案"——工作人员扮演角色，重现患者恐惧的情境。card.md 的世界观改为超自然观察者效应设定后，这个框架不再适用。

### 旧版单局流程

```
入院评估 / 镜子房间 → 方案生成 → 进入模拟场景 → 场景战斗 / 态度干预 → 场间结算 → 分支升级 → 最终重现场景 → 出院小结 / 本局结算
```

### 旧版单场流程

```
场景说明 → 初始态度生成 → 回合对抗 → 态度重组 → 场景推进 → 达成条件判定
```

### 放弃原因

新世界观下，敌人是精神病患者幻觉在观察者效应下的具象化，不再是"工作人员扮演的角色"。战斗是真实的心理对抗，不是治疗模拟。"入院/出院"的框架也不适用于空间扭曲、无法离开的治疗中心。

---

## 精神病/非精神病状态切换（已放弃）

旧版设计中，玩家与敌人都有"精神病状态"和"非精神病状态"两种基础状态，影响可用卡牌、态度染色、情绪触发等。card.md 中未提及此机制，角色病情改为直接体现在角色被动能力上，不再做全局状态切换。
