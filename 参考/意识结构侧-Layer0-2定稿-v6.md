## 四层理论结构

```
Layer 0 系统本体:  S = (B, V_all, X, Ω, P, μ₀, τ, T_obs)    系统是什么
Layer 1 结构量:    Int, Diff, SelBroadcast, SM               第三人称动力学结构
Layer 2 结构判据:  CS'(S) = Int ∧ Diff(S;O) ∧ SB ∧ SM        复杂自适应自我建模信息处理结构
Layer 3 现象意识:  PhenomenalConsciousness —— 需桥接 H: CS' → Phenomenal，H 未知
```

**Layer 3 的关键声明**（GPT 第十四份修正）：严格结论是「当前结构侧形式化无法从其四类第三人称动力学性质推出第一人称主体性」——**不是**「主体性原则上不可数学化」，更**不是**「哥德尔 ⟹ 主体性不可数学化」。

## Layer 0 系统本体

**系统模型**：S = (B, V_all, {Xᵢ}, Ω, P, μ₀, τ, T_obs)

| 成分 | 定义 |
|---|---|
| V_all | 有限元件全集 {1,…,n}，n 由建模层级指定 |
| Xᵢ | 元件状态空间，2 ≤ \|Xᵢ\| < ∞，异构允许 |
| Yᵢ = (Aᵢ, Zᵢ) | 活动变量对：Aᵢ ∈ {0,1}（参与动力学），Zᵢ ∈ Xᵢ（实际状态）|
| Ω = ∏({0,1}×Xᵢ) | 固定状态空间，\|Ω\| < ∞ |
| V_t = {i:Aᵢ(t)=1} | 动态参与集合（状态派生量，非定义域）|
| P(y′\|y) | 随机 Markov kernel（确定性 δ_F 是特例）|
| μ₀ | 初始分布 |
| t_k = kτ, T_obs = mτ | 时间步长 + 观察窗口 |
| B ⊆ V_all | 模型指定边界（外生，先于 CS——消除循环）|
| C_in/C_out/Closure | 系统分类属性（非意识成立条件）|

**关键性质**：马尔可夫性（Ω/P 固定）✅｜有限可机检 ✅｜动态 V 保持（V_t = f(Y_t)）✅｜边界客观（B 外生）✅｜存在/活动/可观测三区分 ✅

## 诚实结论

1. **结构侧可定义**：CS′ = 四要件合取，定义"复杂自适应自我建模信息处理结构"——纯数学、可机检、跨基底。
2. **结构侧有极限**：四要件无法区分 F1/F9（复杂控制）与"直觉上的意识"——**停止加指标**（GPT 指引），差异点是"主体性"。
3. **主体性不可由结构侧推出**：严格表述为"当前形式化无法从第三人称结构推出第一人称"，非"原则上不可数学化"。
4. **哥德尔不构成证明**：本研讨从哥德尔出发，最终停在比"哥德尔证明意识不可数学化"严谨得多的位置——哥德尔只提供类比（D8），不提供定理。
5. **Layer 3 是公设层**：桥接 H 是公设/经验假设，未证明、未否定——这是 F4（现象壳）的精确位置。
