# C 阶段诊断：周卫国（PTSD）/ 杨秀兰（SSD）资格门逐环检查

> Grilling #89 素材库内容生产 · 病种同质化生态诊断（C 方案，外审 t6a97a957 建议）
> **目的**：判断两个"非心境谱"老骨架在现有正典下是**漏接**（接口覆盖遗漏，可复活）还是**需解锁**（资格条件未定义，走 B/A）。
> 方法：`疾病候选 → 资格原子 → 已有证据 → 现有阈值/判定规则 → EligibilityStatus` 逐环拆解。

---

## 一、周卫国（PTSD）

### 1.1 候选召回（§3.2.1）

E1 事件类型 = 威胁/暴力 → C(E1) = {PTSD 主, 惊恐, 特定恐惧, 偏执型 SZ 卫} → **PTSD 被召回** ✓

### 1.2 资格原子（§3.2.2 五基础原子表 + E_d 证据域）

| 环 | 检查 | 结果 |
|----|------|------|
| 五基础原子 | DEPRESSIVE / SUBSTANCE / MANIA / HYPOMANIA / CYCLIC | **均不适用于 PTSD**——PTSD 不在五原子核验名单（#113 首批只覆盖 MDD/SUD/BD-I/BD-II/环性） |
| E_d^hist（记忆外临床史） | PTSD 的临床史资格原子 | **未定义**——#113 未核验 PTSD 需要哪些临床史原子 |
| **E_d^mem（记忆内表征域）** | 转化接口 §3.2.2 :174 明确点名 **"PTSD→F"** 为记忆内通道例子 | **接口存在！** 但**只有点名，无数值化阈值/判定规则** |

### 1.3 已有证据

周卫国 E1：F=0.95，N=0.15，D_seg=0.05——对照 §3.2.3 表征偏好表 PTSD=(0.15, 0.95, 0.10)，**F 高度吻合**（0.95=0.95，N 0.15=0.15，仅 D_seg 差 0.05）。

### 1.4 现有阈值/判定规则

- §3.2.2 资格门组合规则（∃P_i=0→INELIGIBLE 等）**要求先有 P_i/N_j 原子定义**——PTSD 无原子 → 组合规则无法执行
- §3.2.3 的 N/F/R 主病选择是"候选过滤后"的 argmax sim，**不是资格判定**——F 匹配度高只说明"表征像 PTSD"，不构成资格

### 1.5 EligibilityStatus 判定

```
PTSD 资格原子：未核验（#113 延迟项，~19 病之一）
E_d^mem（PTSD→F）：接口已点名但无数值化规则
→ EligibilityStatus = UNDETERMINED
→ input_source=canonical → 正式生成 FAIL
```

### 1.6 结论：**半漏接（接口存在、规则缺失）**

- ✅ **漏接部分**：E_d^mem 通道**明确点名 PTSD→F**（转化接口 :174），说明 #113 设计时已预留 PTSD 走表征通道——这不是"资格条件未定义"（需 A），而是"**资格原子已提名但未完成阈值化**"
- ⚠️ **缺的部分**：PTSD 的 F 表征资格阈值未定（F ≥ ? → ELIGIBLE？是否需要排除原子？）
- **复活路径**：走 **B 方案**——把 §3.2.2 :174 的"PTSD→F"从"点名"升级为"正式资格原子"，核验 F 阈值（如 F ≥ 0.8 且事件类型 ∈ {威胁/暴力, 性创伤} → ELIGIBLE）。这是**最短路径**，且不污染资格语义（F 是 PTSD 表征域事实，非"表征强→推疾病"的循环——F 由 #90 记忆层提供，是临床史级证据）

## 二、杨秀兰（SSD 躯体症状障碍）

### 2.1 候选召回（§3.2.1）

E1-E4 事件类型 = 生理/疾病 → C = {躯体症状 主, 惊恐, MDD} → **SSD 被召回** ✓

### 2.2 资格原子（§3.2.2）

| 环 | 检查 | 结果 |
|----|------|------|
| 五基础原子 | 同上 | 均不适用 |
| E_d^hist | SSD 临床史资格原子 | **未定义** |
| **E_d^mem** | 转化接口 :174 只点名 "DID→D_seg、PTSD→F" | **SSD 未被点名**——无记忆内通道预留 |

### 2.3 已有证据

杨秀兰 E1-E4：F=0.75-0.8，N=0.3-0.35——对照 SSD 表征偏好=(0.30, 0.75, 0.05)，**表征高度吻合**。但这是 §3.2.3 主病选择维度，非资格维度。

### 2.4 结论：**完全未覆盖（需解锁）**

- ❌ E_d^mem 通道**未点名 SSD**——没有任何"SSD 走什么资格通道"的预留
- ❌ E_d^hist 资格原子未定义
- **复活路径**：SSD 无法走 B 的捷径（无记忆内通道提名）→ 需 **A 方案**（五步核验协议：DSM/ICD 定位 → d⟹X 必要性 → X⟹d 充分性 → 组合 → 归位表）。SSD 临床史原子候选：SOMATIC_SYMPTOM_HISTORY（持续躯体症状史，DSM-5 SSD 核心）——但这是"症状史"型原子，与 PTSD 的"表征域"型不同

## 三、诊断汇总

| 患者 | 病种 | 资格通道现状 | 判定 | 复活路径 |
|------|------|-------------|------|---------|
| 周卫国 | PTSD | E_d^mem 点名"PTSD→F"但无数值规则 | **半漏接** | B（F 阈值化，最短） |
| 杨秀兰 | SSD | 无任何资格通道预留 | **需解锁** | A（五步核验协议） |

## 四、对"病种同质化"的意义

按外审 C 方案，先复活能复活的：

1. **周卫国 PTSD（走 B）**：若 F≥阈值规则落地，他 ELIGIBLE → 6 人结构变为：MDD×2 / 双相谱×3 / SUD / **PTSD** = 7 人，非心境谱 +1
2. **杨秀兰 SSD（走 A）**：需完整核验，周期较长 → 暂缓，或先以"骨架保留"状态挂着

**关键认知修正**（来自诊断）：
- PTSD 和 SSD 的"无法生成"**不是同一个原因**——PTSD 是"接口半开"（已提名未阈值化），SSD 是"完全未覆盖"（从未提名）。所以不能笼统说"解锁 ~19 病"，而要**逐病诊断**——这正是外审"C→B→A"顺序的价值：先查漏接，再走通道，最后才做完整核验。

## 五、下一步建议

1. **立即**：核验 PTSD 的 F 表征资格阈值（B 方案，最短路径）——需用户裁决阈值取多少（如 F ≥ 0.8？）
2. **随后**：SSD 是否值得走 A 完整核验（工作量大，看生态是否需要躯体化谱）
3. **待验证**：其他 ~17 病（BPD/精神分裂谱/焦虑谱/进食障碍等）逐病诊断——不急，等生态结构先观察
